Security Operations

Day-to-day security operations, incident response, and continuous security monitoring.

Overview​

Security operations (SecOps) encompasses the processes, tools, and practices for detecting, responding to, and recovering from security incidents while maintaining ongoing security monitoring and threat intelligence.

Contents​

  • Security Operations Overview - SecOps fundamentals and organization
  • Incident Management - Comprehensive incident response and management

Security Operations Center (SOC)​

SOC Functions​

24/7 Monitoring

  • Security event monitoring
  • Alert triage and analysis
  • Threat detection
  • Incident escalation

Incident Response

  • Initial response coordination
  • Evidence collection
  • Containment and eradication
  • Recovery and remediation

Threat Intelligence

  • Threat feed monitoring
  • Indicator of Compromise (IOC) tracking
  • Vulnerability intelligence
  • Threat actor profiling

Security Analysis

  • Log analysis
  • Anomaly detection
  • Pattern recognition
  • Root cause analysis

Security Monitoring​

What to Monitor​

Application Layer

  • Authentication attempts (successful/failed)
  • Authorization failures
  • Input validation errors
  • Application errors and exceptions
  • API rate limiting violations
  • Data access patterns

Infrastructure Layer

  • Network traffic anomalies
  • Firewall rule violations
  • Intrusion detection alerts
  • System resource usage
  • Configuration changes
  • Patch status

Data Layer

  • Database access patterns
  • Data exfiltration attempts
  • Encryption status
  • Backup completion
  • Data integrity checks

Identity & Access

  • Privilege escalations
  • New account creations
  • Permission changes
  • MFA enrollment/usage
  • Session anomalies

Monitoring Tools​

  • Splunk
  • Elastic Security (ELK Stack)
  • Google Chronicle
  • Azure Sentinel

Log Management

  • CloudWatch (AWS)
  • Stackdriver (GCP)
  • Azure Monitor
  • Datadog

Intrusion Detection/Prevention

  • Snort
  • Suricata
  • Zeek (formerly Bro)
  • Cloud-native IDS/IPS

Endpoint Detection & Response (EDR)

  • CrowdStrike Falcon
  • Carbon Black
  • SentinelOne
  • Microsoft Defender for Endpoint

Incident Response​

Incident Response Lifecycle​

1. Preparation​

  • Incident response plan
  • Team roles and responsibilities
  • Communication channels
  • Tools and resources
  • Runbooks and playbooks

2. Detection & Analysis​

  • Event correlation
  • Alert validation
  • Incident classification
  • Impact assessment
  • Scope determination

3. Containment​

  • Short-term: Isolate affected systems
  • Long-term: Implement temporary fixes
  • Preserve evidence
  • Prevent spread

4. Eradication​

  • Remove threat actor access
  • Eliminate malware
  • Close vulnerabilities
  • Patch systems
  • Reset credentials

5. Recovery​

  • Restore from clean backups
  • Rebuild compromised systems
  • Validate system integrity
  • Return to normal operations
  • Enhanced monitoring

6. Post-Incident​

  • Incident report
  • Lessons learned
  • Process improvements
  • Update playbooks
  • Team debriefing

Incident Severity Levels​

Critical (P0)

  • Active data breach
  • Ransomware encryption
  • Production system compromise
  • Response Time: Immediate
  • Escalation: C-level, all hands

High (P1)

  • Confirmed security incident
  • Potential data exposure
  • Service disruption
  • Response Time: < 1 hour
  • Escalation: Security team, management

Medium (P2)

  • Suspicious activity
  • Policy violations
  • Minor security issues
  • Response Time: < 4 hours
  • Escalation: Security team

Low (P3)

  • Security alerts
  • False positives
  • Information requests
  • Response Time: < 24 hours
  • Escalation: On-call engineer

Security Metrics & KPIs​

Detection Metrics​

  • Mean Time to Detect (MTTD) - Average time to identify incidents
  • Alert Volume - Number of security alerts
  • True Positive Rate - Percentage of valid alerts
  • False Positive Rate - Percentage of invalid alerts

Response Metrics​

  • Mean Time to Respond (MTTR) - Average time to respond to incidents
  • Mean Time to Contain (MTTC) - Average time to contain threats
  • Mean Time to Recover (MTTR) - Average time to full recovery
  • Incident Escalation Rate - Percentage requiring escalation

Operational Metrics​

  • Security Event Volume - Total security events processed
  • Coverage - Percentage of assets monitored
  • Uptime - Monitoring system availability
  • Staff Utilization - SOC analyst workload

Business Metrics​

  • Incidents Prevented - Attacks blocked
  • Compliance Score - Adherence to security policies
  • Security Debt - Outstanding security issues
  • Cost per Incident - Average incident handling cost

On-Call Rotation​

On-Call Schedule​

  • Primary: First responder
  • Secondary: Backup support
  • Escalation: Management/specialist

On-Call Responsibilities​

  • Monitor security alerts
  • Respond to incidents
  • Escalate as needed
  • Document actions
  • Post-incident handoff

On-Call Tools​

  • PagerDuty / Opsgenie
  • Slack / Microsoft Teams
  • VPN access
  • Mobile device
  • Laptop with tools

Runbooks & Playbooks​

Security Playbooks​

Malware Incident

  1. Isolate affected systems
  2. Identify malware variant
  3. Check for data exfiltration
  4. Remove malware
  5. Restore from backup
  6. Update signatures

DDoS Attack

  1. Confirm DDoS attack
  2. Enable rate limiting
  3. Activate CDN/WAF protections
  4. Scale infrastructure
  5. Contact ISP if needed
  6. Monitor and adjust

Data Breach

  1. Confirm unauthorized access
  2. Assess data exposure
  3. Contain breach
  4. Notify stakeholders
  5. Legal/compliance review
  6. Public disclosure if required

Credential Compromise

  1. Disable compromised accounts
  2. Force password reset
  3. Review access logs
  4. Check for lateral movement
  5. Enable MFA
  6. Notify affected users
