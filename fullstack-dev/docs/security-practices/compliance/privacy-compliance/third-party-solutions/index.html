Third-Party Cookie Consent Solutions Evaluation

Overview​

This guide provides a comprehensive evaluation of leading third-party cookie consent management platforms (CMPs) to help you choose the right solution for your distributed system.

Evaluation Criteria​

Must-Have Features​

  • ✅ GDPR, CCPA, and multi-jurisdiction compliance
  • ✅ Customizable banner UI
  • ✅ Granular consent categories
  • ✅ Consent logging and audit trails
  • ✅ API access for programmatic control
  • ✅ Cookie scanning and categorization

Nice-to-Have Features​

  • 🎯 Multi-language support
  • 🎯 A/B testing capabilities
  • 🎯 Consent rate analytics
  • 🎯 IAB TCF 2.0 compliance
  • 🎯 Geo-targeting rules
  • 🎯 Integration with analytics platforms

React Integration​

// React Hook for Cookiebot
import { useEffect, useState } from 'react';

export const useCookiebot = () => {
  const [consent, setConsent] = useState(null);
  const [isReady, setIsReady] = useState(false);

  useEffect(() => {
    const handleConsentReady = () => {
      setConsent({
        essential: true,
        functional: window.Cookiebot.consent.preferences,
        analytics: window.Cookiebot.consent.statistics,
        marketing: window.Cookiebot.consent.marketing,
      });
      setIsReady(true);
    };

    window.addEventListener('CookiebotOnConsentReady', handleConsentReady);

    // If already loaded
    if (window.Cookiebot?.consent) {
      handleConsentReady();
    }

    return () => {
      window.removeEventListener('CookiebotOnConsentReady', handleConsentReady);
    };
  }, []);

  const renew = () => {
    if (window.Cookiebot) {
      window.Cookiebot.renew();
    }
  };

  return { consent, isReady, renew };
};

API Integration​

// Osano API Client
import axios from 'axios';

class OsanoClient {
  private apiKey: string;
  private baseURL = 'https://api.osano.com/consent/v1';

  constructor(apiKey: string) {
    this.apiKey = apiKey;
  }

  async getConsent(customerId: string) {
    const response = await axios.get(`${this.baseURL}/customers/${customerId}/consents`, {
      headers: {
        Authorization: `Bearer ${this.apiKey}`,
      },
    });
    return response.data;
  }

  async recordConsent(data: { customerId: string; purposes: string[]; ipAddress: string }) {
    return axios.post(`${this.baseURL}/consents`, data, {
      headers: {
        Authorization: `Bearer ${this.apiKey}`,
        'Content-Type': 'application/json',
      },
    });
  }

  // Webhook verification
  verifyWebhook(payload: string, signature: string): boolean {
    const crypto = require('crypto');
    const hmac = crypto.createHmac('sha256', this.apiKey);
    const digest = hmac.update(payload).digest('hex');
    return signature === digest;
  }
}

// Usage
const osano = new OsanoClient(process.env.OSANO_API_KEY);

// Webhook handler
app.post('/webhooks/osano', async (req, res) => {
  const signature = req.headers['x-osano-signature'];

  if (!osano.verifyWebhook(JSON.stringify(req.body), signature)) {
    return res.status(401).send('Invalid signature');
  }

  const { event, data } = req.body;

  if (event === 'consent.updated') {
    await consentService.updateConsent(data.customerId, data.purposes);
  }

  res.status(200).send('OK');
});

Integration Patterns​

Pattern 1: Frontend-Only (Simple)​

// Use CMP as source of truth
// No backend synchronization
// Good for: Simple sites, low compliance risk

window.addEventListener('consent-changed', (event) => {
  const consent = event.detail;

  // Load scripts conditionally
  if (consent.analytics) {
    loadGoogleAnalytics();
  }

  if (consent.marketing) {
    loadFacebookPixel();
  }
});

Pattern 2: Dual Storage (Recommended)​

// Store consent in both CMP and your backend
// Good for: Most businesses, balanced approach

window.addEventListener('consent-changed', async (event) => {
  const consent = event.detail;

  // Save to your backend
  await fetch('/api/v1/consent', {
    method: 'POST',
    body: JSON.stringify({
      sessionId: getSessionId(),
      userId: getUserId(),
      preferences: consent,
      timestamp: new Date().toISOString(),
    }),
  });

  // CMP handles the banner UI
  // Your backend handles consent propagation
});

Pattern 3: Backend-First (Complex)​

// Your backend is source of truth
// CMP syncs from your API
// Good for: Distributed systems, complex flows

// On page load
const consent = await fetch('/api/v1/consent/current').then((r) => r.json());

// Initialize CMP with your consent state
CMP.setConsent(consent);

// When user updates via CMP
CMP.onConsentChange(async (newConsent) => {
  // Update your backend
  await fetch('/api/v1/consent', {
    method: 'PUT',
    body: JSON.stringify(newConsent),
  });

  // Propagate to all services
  await propagateConsent(newConsent);
});
