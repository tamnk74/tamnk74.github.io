Cookie Consent Management for Distributed Systems

Overview​

Cookie consent management is a critical compliance requirement for distributed systems operating globally. This guide covers implementing a robust, scalable cookie consent solution across microservices architectures while ensuring GDPR, CCPA, and other privacy regulations compliance.

Privacy Regulations Overview​

GDPR (General Data Protection Regulation)​

  • Scope: EU residents
  • Requirements: Explicit consent before non-essential cookies
  • Penalties: Up to €20M or 4% of annual global turnover
  • Key Principles: Consent must be freely given, specific, informed, and unambiguous

CCPA/CPRA (California Consumer Privacy Act)​

  • Scope: California residents
  • Requirements: Right to opt-out of data selling
  • Penalties: Up to $7,500 per intentional violation
  • Key Principles: Notice and opt-out mechanisms required

Other Regulations​

  • LGPD (Brazil): Similar to GDPR
  • POPIA (South Africa): Personal information protection
  • PIPEDA (Canada): Privacy principles for commercial activities

Cookie Categories​

Essential Cookies​

  • Session management
  • Authentication tokens
  • Security tokens (CSRF)
  • Load balancing
  • No consent required

Functional Cookies​

  • Language preferences
  • UI customization
  • Location selection
  • Consent recommended

Analytics Cookies​

  • Google Analytics
  • Mixpanel
  • Hotjar
  • User behavior tracking
  • Consent required

Marketing Cookies​

  • Advertising pixels
  • Retargeting
  • Social media tracking
  • Consent required

Consent Storage​

// consent-service/src/repositories/consent.repository.ts
import { Injectable } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import { ConsentRecord } from '../entities/consent.entity';
import { ConsentPreferences } from '../types/consent.types';

@Injectable()
export class ConsentRepository {
  constructor(
    @InjectRepository(ConsentRecord)
    private readonly repository: Repository<ConsentRecord>,
  ) {}

  async saveConsent(sessionId: string, preferences: ConsentPreferences, userId?: string): Promise<ConsentRecord> {
    const existing = await this.findBySession(sessionId);

    if (existing) {
      return this.updateConsent(existing.id, preferences);
    }

    const consent = this.repository.create({
      userId,
      sessionId,
      preferences,
      auditLog: [
        {
          timestamp: new Date(),
          action: 'granted',
          preferences,
        },
      ],
    });

    return this.repository.save(consent);
  }

  async updateConsent(consentId: string, preferences: ConsentPreferences): Promise<ConsentRecord> {
    const consent = await this.repository.findOne({
      where: { id: consentId },
    });

    if (!consent) {
      throw new Error('Consent record not found');
    }

    consent.preferences = preferences;
    consent.auditLog.push({
      timestamp: new Date(),
      action: 'updated',
      preferences,
    });

    return this.repository.save(consent);
  }

  async findBySession(sessionId: string): Promise<ConsentRecord | null> {
    return this.repository.findOne({
      where: { sessionId },
      order: { createdAt: 'DESC' },
    });
  }

  async findByUser(userId: string): Promise<ConsentRecord | null> {
    return this.repository.findOne({
      where: { userId },
      order: { createdAt: 'DESC' },
    });
  }

  async withdrawConsent(consentId: string): Promise<void> {
    const consent = await this.repository.findOne({
      where: { id: consentId },
    });

    if (!consent) {
      throw new Error('Consent record not found');
    }

    consent.preferences = {
      ...consent.preferences,
      functional: false,
      analytics: false,
      marketing: false,
    };

    consent.auditLog.push({
      timestamp: new Date(),
      action: 'withdrawn',
      preferences: consent.preferences,
    });

    await this.repository.save(consent);
  }
}

Consent Service API​

// consent-service/src/controllers/consent.controller.ts
import { Controller, Post, Get, Put, Delete, Body, Param, Req } from '@nestjs/common';
import { ConsentService } from '../services/consent.service';
import { ConsentPreferences } from '../types/consent.types';
import { Request } from 'express';

@Controller('api/v1/consent')
export class ConsentController {
  constructor(private readonly consentService: ConsentService) {}

  @Post()
  async createConsent(@Body() preferences: ConsentPreferences, @Req() request: Request) {
    const sessionId = request.session.id;
    const userId = request.user?.id;
    const ipAddress = request.ip;
    const userAgent = request.headers['user-agent'];

    return this.consentService.saveConsent(sessionId, preferences, userId, { ipAddress, userAgent });
  }

  @Get('session/:sessionId')
  async getConsentBySession(@Param('sessionId') sessionId: string) {
    return this.consentService.getConsentBySession(sessionId);
  }

  @Get('user/:userId')
  async getConsentByUser(@Param('userId') userId: string) {
    return this.consentService.getConsentByUser(userId);
  }

  @Put(':consentId')
  async updateConsent(@Param('consentId') consentId: string, @Body() preferences: ConsentPreferences) {
    return this.consentService.updateConsent(consentId, preferences);
  }

  @Delete(':consentId')
  async withdrawConsent(@Param('consentId') consentId: string) {
    return this.consentService.withdrawConsent(consentId);
  }

  @Get('audit/:consentId')
  async getAuditLog(@Param('consentId') consentId: string) {
    return this.consentService.getAuditLog(consentId);
  }
}

Cookie Consent Hook​

// frontend/src/hooks/useCookieConsent.ts
import { useState, useEffect } from 'react';
import { ConsentPreferences } from '../types/consent.types';
import { consentApi } from '../api/consent.api';

const CONSENT_COOKIE_NAME = 'user_consent';
const CONSENT_VERSION = '1.0';

export const useCookieConsent = () => {
  const [consent, setConsent] = useState<ConsentPreferences | null>(null);

  useEffect(() => {
    loadConsent();
  }, []);

  const loadConsent = async () => {
    const storedConsent = getCookie(CONSENT_COOKIE_NAME);

    if (storedConsent) {
      try {
        const parsed = JSON.parse(storedConsent);
        setConsent(parsed);
      } catch (e) {
        console.error('Failed to parse consent cookie', e);
      }
    }

    // Fetch from server
    try {
      const serverConsent = await consentApi.getConsent();
      if (serverConsent) {
        setConsent(serverConsent.preferences);
      }
    } catch (e) {
      console.error('Failed to fetch consent from server', e);
    }
  };

  const updateConsent = async (preferences: Partial<ConsentPreferences>) => {
    const fullPreferences: ConsentPreferences = {
      ...consent,
      essential: true,
      functional: preferences.functional ?? false,
      analytics: preferences.analytics ?? false,
      marketing: preferences.marketing ?? false,
      timestamp: new Date(),
      expiresAt: new Date(Date.now() + 365 * 24 * 60 * 60 * 1000), // 1 year
      consentVersion: CONSENT_VERSION,
      sessionId: getSessionId(),
      consentId: consent?.consentId || generateConsentId(),
    };

    // Save to cookie
    setCookie(CONSENT_COOKIE_NAME, JSON.stringify(fullPreferences), 365);

    // Save to server
    try {
      await consentApi.saveConsent(fullPreferences);
    } catch (e) {
      console.error('Failed to save consent to server', e);
    }

    setConsent(fullPreferences);

    // Trigger consent change event
    window.dispatchEvent(
      new CustomEvent('consentChanged', {
        detail: fullPreferences,
      }),
    );
  };

  const hasConsent = () => {
    return consent !== null;
  };

  const hasCategory = (category: keyof ConsentPreferences) => {
    return consent?.[category] === true;
  };

  return {
    consent,
    updateConsent,
    hasConsent,
    hasCategory,
  };
};

// Utility functions
function getCookie(name: string): string | null {
  const value = `; ${document.cookie}`;
  const parts = value.split(`; ${name}=`);
  if (parts.length === 2) {
    return parts.pop()?.split(';').shift() || null;
  }
  return null;
}

function setCookie(name: string, value: string, days: number) {
  const expires = new Date(Date.now() + days * 24 * 60 * 60 * 1000);
  document.cookie = `${name}=${value}; expires=${expires.toUTCString()}; path=/; secure; samesite=strict`;
}

function getSessionId(): string {
  let sessionId = sessionStorage.getItem('session_id');
  if (!sessionId) {
    sessionId = generateId();
    sessionStorage.setItem('session_id', sessionId);
  }
  return sessionId;
}

function generateConsentId(): string {
  return generateId();
}

function generateId(): string {
  return `${Date.now()}-${Math.random().toString(36).substr(2, 9)}`;
}

Consent Propagation via Headers​

// shared/middleware/consent-propagation.middleware.ts
import { Injectable, NestMiddleware } from '@nestjs/common';
import { Request, Response, NextFunction } from 'express';
import { ConsentService } from '../services/consent.service';

@Injectable()
export class ConsentPropagationMiddleware implements NestMiddleware {
  constructor(private readonly consentService: ConsentService) {}

  async use(req: Request, res: Response, next: NextFunction) {
    const sessionId = req.session?.id;

    if (sessionId) {
      const consent = await this.consentService.getConsentBySession(sessionId);

      if (consent) {
        // Add consent to request context
        req['consent'] = consent.preferences;

        // Add header for downstream services
        req.headers['x-consent-preferences'] = JSON.stringify(consent.preferences);
      }
    }

    next();
  }
}

Service-to-Service Consent Check​

// shared/guards/consent.guard.ts
import { Injectable, CanActivate, ExecutionContext } from '@nestjs/common';
import { Reflector } from '@nestjs/core';
import { ConsentCategory } from '../decorators/consent.decorator';

@Injectable()
export class ConsentGuard implements CanActivate {
  constructor(private reflector: Reflector) {}

  canActivate(context: ExecutionContext): boolean {
    const requiredCategories = this.reflector.get<ConsentCategory[]>('consentCategories', context.getHandler());

    if (!requiredCategories || requiredCategories.length === 0) {
      return true; // No consent required
    }

    const request = context.switchToHttp().getRequest();
    const consent = request.consent;

    if (!consent) {
      return false; // No consent information
    }

    // Check if all required categories are granted
    return requiredCategories.every((category) => consent[category] === true);
  }
}

Redis-Based Consent Cache​

// consent-service/src/cache/consent.cache.ts
import { Injectable } from '@nestjs/common';
import { InjectRedis } from '@nestjs-modules/ioredis';
import Redis from 'ioredis';
import { ConsentPreferences } from '../types/consent.types';

@Injectable()
export class ConsentCache {
  private readonly CACHE_TTL = 3600; // 1 hour
  private readonly CACHE_PREFIX = 'consent:';

  constructor(@InjectRedis() private readonly redis: Redis) {}

  async getConsent(sessionId: string): Promise<ConsentPreferences | null> {
    const key = `${this.CACHE_PREFIX}${sessionId}`;
    const cached = await this.redis.get(key);

    if (cached) {
      return JSON.parse(cached);
    }

    return null;
  }

  async setConsent(sessionId: string, preferences: ConsentPreferences): Promise<void> {
    const key = `${this.CACHE_PREFIX}${sessionId}`;
    await this.redis.setex(key, this.CACHE_TTL, JSON.stringify(preferences));
  }

  async invalidateConsent(sessionId: string): Promise<void> {
    const key = `${this.CACHE_PREFIX}${sessionId}`;
    await this.redis.del(key);
  }

  async invalidateUserConsent(userId: string): Promise<void> {
    // Invalidate all sessions for a user
    const pattern = `${this.CACHE_PREFIX}*:user:${userId}`;
    const keys = await this.redis.keys(pattern);

    if (keys.length > 0) {
      await this.redis.del(...keys);
    }
  }
}

Conditional Script Loading​

// frontend/src/utils/scriptLoader.ts
import { ConsentPreferences } from '../types/consent.types';

interface ScriptConfig {
  src: string;
  id: string;
  category: keyof ConsentPreferences;
  async?: boolean;
  defer?: boolean;
  attributes?: Record<string, string>;
}

export class ConditionalScriptLoader {
  private loadedScripts: Set<string> = new Set();

  constructor() {
    // Listen for consent changes
    window.addEventListener('consentChanged', (event: CustomEvent) => {
      this.handleConsentChange(event.detail);
    });
  }

  loadScript(config: ScriptConfig, consent: ConsentPreferences): void {
    if (!consent[config.category]) {
      return; // No consent for this category
    }

    if (this.loadedScripts.has(config.id)) {
      return; // Already loaded
    }

    const script = document.createElement('script');
    script.src = config.src;
    script.id = config.id;

    if (config.async) script.async = true;
    if (config.defer) script.defer = true;

    if (config.attributes) {
      Object.entries(config.attributes).forEach(([key, value]) => {
        script.setAttribute(key, value);
      });
    }

    document.head.appendChild(script);
    this.loadedScripts.add(config.id);
  }

  removeScript(scriptId: string): void {
    const script = document.getElementById(scriptId);
    if (script) {
      script.remove();
      this.loadedScripts.delete(scriptId);
    }
  }

  handleConsentChange(consent: ConsentPreferences): void {
    // Reload page if consent changes significantly
    const scriptsToLoad = this.getRequiredScripts(consent);
    const shouldReload = scriptsToLoad.some((config) => !this.loadedScripts.has(config.id));

    if (shouldReload) {
      window.location.reload();
    }
  }

  private getRequiredScripts(consent: ConsentPreferences): ScriptConfig[] {
    const scripts: ScriptConfig[] = [];

    if (consent.analytics) {
      scripts.push({
        src: 'https://www.googletagmanager.com/gtag/js?id=GA_MEASUREMENT_ID',
        id: 'google-analytics',
        category: 'analytics',
        async: true,
      });
    }

    if (consent.marketing) {
      scripts.push({
        src: 'https://connect.facebook.net/en_US/fbevents.js',
        id: 'facebook-pixel',
        category: 'marketing',
        async: true,
      });
    }

    return scripts;
  }
}

Consent Synchronization​

User Login Consent Merge​

// consent-service/src/services/consent-sync.service.ts
import { Injectable } from '@nestjs/common';
import { ConsentRepository } from '../repositories/consent.repository';
import { ConsentPreferences } from '../types/consent.types';

@Injectable()
export class ConsentSyncService {
  constructor(private readonly consentRepository: ConsentRepository) {}

  async syncConsentOnLogin(userId: string, sessionId: string): Promise<ConsentPreferences> {
    // Get session consent (anonymous)
    const sessionConsent = await this.consentRepository.findBySession(sessionId);

    // Get user consent (authenticated)
    const userConsent = await this.consentRepository.findByUser(userId);

    if (!sessionConsent && !userConsent) {
      // No consent exists
      return null;
    }

    if (!userConsent) {
      // Promote session consent to user consent
      sessionConsent.userId = userId;
      await this.consentRepository.repository.save(sessionConsent);
      return sessionConsent.preferences;
    }

    if (!sessionConsent) {
      // Use existing user consent
      return userConsent.preferences;
    }

    // Merge: prefer most recent with most permissions
    const merged = this.mergePreferences(sessionConsent.preferences, userConsent.preferences);

    // Update user consent
    await this.consentRepository.updateConsent(userConsent.id, merged);

    return merged;
  }

  private mergePreferences(session: ConsentPreferences, user: ConsentPreferences): ConsentPreferences {
    // Use most recent timestamp
    const mostRecent = session.timestamp > user.timestamp ? session : user;

    // Combine permissions (grant if either has it)
    return {
      ...mostRecent,
      functional: session.functional || user.functional,
      analytics: session.analytics || user.analytics,
      marketing: session.marketing || user.marketing,
      timestamp: new Date(),
    };
  }
}

Data Deletion (GDPR Right to Erasure)​

// consent-service/src/services/data-deletion.service.ts
import { Injectable } from '@nestjs/common';
import { ConsentRepository } from '../repositories/consent.repository';
import { EventEmitter2 } from '@nestjs/event-emitter';

@Injectable()
export class DataDeletionService {
  constructor(private readonly consentRepository: ConsentRepository, private readonly eventEmitter: EventEmitter2) {}

  async deleteUserData(userId: string): Promise<void> {
    // Emit event for other services to delete their data
    await this.eventEmitter.emitAsync('user.data-deletion.requested', {
      userId,
      timestamp: new Date(),
    });

    // Delete consent records
    const consent = await this.consentRepository.findByUser(userId);
    if (consent) {
      await this.consentRepository.repository.remove(consent);
    }

    // Emit completion event
    await this.eventEmitter.emitAsync('user.data-deletion.completed', {
      userId,
      timestamp: new Date(),
    });
  }
}

Consent Metrics​

// consent-service/src/services/consent-metrics.service.ts
import { Injectable } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import { ConsentRecord } from '../entities/consent.entity';

@Injectable()
export class ConsentMetricsService {
  constructor(
    @InjectRepository(ConsentRecord)
    private readonly repository: Repository<ConsentRecord>,
  ) {}

  async getConsentRates(startDate: Date, endDate: Date) {
    const totalConsents = await this.repository.count({
      where: {
        createdAt: Between(startDate, endDate),
      },
    });

    const acceptedAnalytics = await this.repository.count({
      where: {
        createdAt: Between(startDate, endDate),
        'preferences.analytics': true,
      },
    });

    const acceptedMarketing = await this.repository.count({
      where: {
        createdAt: Between(startDate, endDate),
        'preferences.marketing': true,
      },
    });

    return {
      total: totalConsents,
      analyticsRate: (acceptedAnalytics / totalConsents) * 100,
      marketingRate: (acceptedMarketing / totalConsents) * 100,
      period: {
        start: startDate,
        end: endDate,
      },
    };
  }

Best Practices​

1. Granular Control​

  • Offer users fine-grained control over cookie categories
  • Provide clear descriptions of what each category does
  • Allow users to change preferences at any time

2. Explicit Consent​

  • Don't use pre-checked boxes for non-essential cookies
  • Require explicit action from users
  • Make "Reject All" as easy as "Accept All"

3. Consent Versioning​

  • Track consent version to handle policy updates
  • Re-prompt users when privacy policy changes significantly
  • Maintain audit trails for compliance

4. Performance​

  • Cache consent decisions to minimize database queries
  • Use Redis for fast consent lookups
  • Propagate consent efficiently across services

5. Security​

  • Encrypt consent data in transit and at rest
  • Use secure cookies (Secure, HttpOnly, SameSite)
  • Implement proper authentication for consent management APIs

6. User Experience​

  • Non-intrusive banner placement
  • Clear, simple language
  • Quick access to change preferences
  • Respect user decisions immediately

7. Documentation​

  • Maintain clear privacy policy
  • Document all cookies used by your system
  • Provide cookie policy with detailed explanations

8. Compliance Automation​

  • Automated consent expiration handling
  • Regular compliance audits
  • Automated data deletion workflows

Common Pitfalls​

❌ Loading analytics before consent

// Bad
useEffect(() => {
  initAnalytics(); // Loads immediately
}, []);

✅ Load after consent granted

// Good
useEffect(() => {
  if (consent?.analytics) {
    initAnalytics();
  }
}, [consent]);

❌ Setting cookies before consent

// Bad
app.use(
  session({
    /* stores cookie immediately */
  }),
);

✅ Conditional cookie setting

// Good
app.use((req, res, next) => {
  if (hasConsent(req, 'functional')) {
    // Set functional cookies
  }
  next();
});

❌ Not handling consent withdrawal

// Bad - no cleanup when user withdraws consent

✅ Proper cleanup on withdrawal

// Good
const withdrawConsent = async () => {
  await consentService.withdrawConsent(consentId);
  // Clear all non-essential cookies
  clearAnalyticsCookies();
  clearMarketingCookies();
  // Reload to stop running scripts
  window.location.reload();
};

Summary​

Implementing cookie consent management in distributed systems requires:

  1. Centralized consent service for storing and retrieving user preferences
  2. Frontend components for collecting and displaying consent
  3. Consent propagation across microservices via headers and context
  4. Conditional loading of third-party scripts based on consent
  5. Compliance features for data export and deletion
  6. Monitoring and metrics for consent rates and compliance reporting
  7. Regular audits to ensure ongoing compliance

By following this guide, you can build a robust, compliant cookie consent management system that respects user privacy while meeting legal requirements across multiple jurisdictions.
