Hands-On Security Labs

Overview​

This document provides a reference implementation for a hands-on lab platform used to teach and assess secure engineering practices. It includes vulnerable apps for safe practice, secure demos, and CTF-style challenges.

Implementation Reference​

Interactive Lab Platform​

// src/training/lab-platform.service.ts
import { Injectable, Logger } from '@nestjs/common';

interface LabEnvironment {
  id: string;
  name: string;
  description: string;
  type: 'VULNERABLE_APP' | 'SECURE_DEMO' | 'CTF_CHALLENGE';
  technologies: string[];
  difficulty: 'BEGINNER' | 'INTERMEDIATE' | 'ADVANCED';
  estimatedTime: number;
  objectives: string[];
  setup: LabSetup;
  exercises: LabExercise[];
}

interface LabSetup {
  dockerImages: string[];
  environmentVariables: Record<string, string>;
  networkConfiguration: string;
  volumes: string[];
}

interface LabExercise {
  id: string;
  title: string;
  description: string;
  type: 'FIND_VULNERABILITY' | 'FIX_CODE' | 'IMPLEMENT_SECURITY' | 'EXPLOIT_DEMO';
  instructions: string[];
  hints: string[];
  solution: string;
  verificationScript: string;
}

async validateUser(username: string, password: string) {
  const user = await this.userRepository.findOne({
    where: { username },
    select: ['id', 'username', 'passwordHash']
  });

  if (!user) return null;

  const isValid = await bcrypt.compare(password, user.passwordHash);
  return isValid ? user : null;
}

    return {

      name: 'Secure Implementation Laboratory',

      type: 'SECURE_DEMO',
      technologies: ['NestJS', 'Next.js', 'JWT', 'bcrypt'],
      difficulty: 'ADVANCED',
      estimatedTime: 180,
      objectives: [
        'Implement secure authentication from scratch',
        'Build role-based access control',
        'Create secure API endpoints',
        'Implement proper error handling',

      setup: {
        dockerImages: ['node:18', 'postgres:13'],
        environmentVariables: {
          NODE_ENV: 'development',
        },
        networkConfiguration: 'bridge',
        volumes: [],

      exercises: [
        {

          title: 'Secure Authentication Implementation',
          description: 'Build a complete secure authentication system',
          type: 'IMPLEMENT_SECURITY',

            'Implement secure password hashing',

Minimum Deliverables​

  • An isolated lab environment (no production connectivity)
  • Verification scripts to confirm fixes/learning outcomes
  • Clear rules of engagement for safe exploit demos
  • Reportable outcomes (completion, time spent, score)
