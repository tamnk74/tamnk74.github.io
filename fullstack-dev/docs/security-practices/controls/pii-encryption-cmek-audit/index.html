PII Encryption at Rest (CMEK) & Audit Logging

Customer-Managed Encryption Keys (CMEK) give your organisation full control over the cryptographic keys protecting PII at rest. Combined with a tamper-evident audit log on every data access, this satisfies GDPR Art. 32 technical safeguards, CCPA, and PCI-DSS requirements in a GCP environment.

Architecture Overview​

Envelope Encryption Model​

PII value (plaintext)
        ↓ encrypted by
   DEK (data encryption key, 256-bit AES)
        ↓ encrypted by
  CMEK (key in Cloud KMS, hardware-backed)
        ↓ stored in
   Cloud SQL / Firestore alongside ciphertext

You rotate only the CMEK — Cloud KMS re-wraps all DEKs automatically, without touching stored ciphertext.

GCP Setup: Cloud KMS Key Ring​

1. Terraform provisioning​

# infra/kms.tf
resource "google_kms_key_ring" "pii_ring" {
  name     = "pii-keyring-${var.env}"
  location = var.region   # use regional, not global, for GDPR data residency
}

resource "google_kms_crypto_key" "pii_key" {
  name            = "pii-cmek"
  key_ring        = google_kms_key_ring.pii_ring.id
  rotation_period = "7776000s"   # 90-day automatic rotation

  purpose = "ENCRYPT_DECRYPT"

  version_template {
    algorithm        = "GOOGLE_SYMMETRIC_ENCRYPTION"
    protection_level = "HSM"   # hardware security module — required for PCI-DSS
  }

  lifecycle {
    prevent_destroy = true
  }
}

# Allow the service account to use—but not manage—the key
resource "google_kms_crypto_key_iam_member" "app_encrypter" {
  crypto_key_id = google_kms_crypto_key.pii_key.id
  role          = "roles/cloudkms.cryptoKeyEncrypterDecrypter"
  member        = "serviceAccount:${var.app_service_account}"
}

2. Cloud SQL CMEK binding​

resource "google_sql_database_instance" "main" {
  name             = "ecommerce-${var.env}"
  database_version = "POSTGRES_15"

  encryption_key_name = google_kms_crypto_key.pii_key.id  # CMEK binding

  settings {
    tier = "db-custom-4-15360"
  }
}

NestJS Implementation​

KMS Service​

// src/security/kms.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { KeyManagementServiceClient } from '@google-cloud/kms';

@Injectable()
export class KmsService {
  private readonly logger = new Logger(KmsService.name);
  private readonly client = new KeyManagementServiceClient();

  private get keyName(): string {
    return this.client.cryptoKeyPath(
      process.env.GCP_PROJECT_ID!,
      process.env.KMS_LOCATION!,        // e.g. 'us-central1'
      process.env.KMS_KEY_RING!,        // e.g. 'pii-keyring-prod'
      process.env.KMS_CRYPTO_KEY!,      // e.g. 'pii-cmek'
    );
  }

  async encrypt(plaintext: string): Promise<string> {
    const [result] = await this.client.encrypt({
      name: this.keyName,
      plaintext: Buffer.from(plaintext),
    });

    if (!result.ciphertext) {
      throw new Error('KMS encryption returned empty ciphertext');
    }

    return Buffer.from(result.ciphertext).toString('base64');
  }

  async decrypt(ciphertext: string): Promise<string> {
    const [result] = await this.client.decrypt({
      name: this.keyName,
      ciphertext: Buffer.from(ciphertext, 'base64'),
    });

    if (!result.plaintext) {
      throw new Error('KMS decryption returned empty plaintext');
    }

    return Buffer.from(result.plaintext).toString('utf8');
  }
}

PII Field Encryption Interceptor​

Automatically encrypt/decrypt designated PII fields on any entity:

// src/security/pii-field.decorator.ts
export const PII_FIELDS_KEY = 'pii_fields';

export function PiiField(): PropertyDecorator {
  return (target, propertyKey) => {
    const existing: string[] =
      Reflect.getMetadata(PII_FIELDS_KEY, target.constructor) ?? [];
    Reflect.defineMetadata(PII_FIELDS_KEY, [...existing, propertyKey], target.constructor);
  };
}

// src/users/user.entity.ts
@Entity()
export class User {
  @PrimaryGeneratedColumn('uuid')
  id: string;

  @Column()
  @PiiField()
  email: string;

  @Column()
  @PiiField()
  phoneNumber: string;

  @Column()
  @PiiField()
  shippingAddress: string;

  @Column({ nullable: true })
  @PiiField()
  dateOfBirth: string;
}

// src/security/pii-encryption.subscriber.ts
import { PII_FIELDS_KEY } from './pii-field.decorator';

@Injectable()
export class PiiEncryptionSubscriber implements EntitySubscriberInterface {
  constructor(
    private readonly kms: KmsService,
    dataSource: DataSource,
  ) {
    dataSource.subscribers.push(this);
  }

  async beforeInsert(event: InsertEvent<any>): Promise<void> {
    await this.encryptPiiFields(event.entity);
  }

  async beforeUpdate(event: UpdateEvent<any>): Promise<void> {
    if (event.entity) await this.encryptPiiFields(event.entity);
  }

  async afterLoad(entity: any): Promise<void> {
    await this.decryptPiiFields(entity);
  }

  private async encryptPiiFields(entity: any): Promise<void> {
    const fields: string[] =
      Reflect.getMetadata(PII_FIELDS_KEY, entity.constructor) ?? [];

    await Promise.all(
      fields.map(async (field) => {
        if (entity[field]) {
          entity[field] = await this.kms.encrypt(entity[field]);
        }
      }),
    );
  }

  private async decryptPiiFields(entity: any): Promise<void> {
    const fields: string[] =
      Reflect.getMetadata(PII_FIELDS_KEY, entity.constructor) ?? [];

    await Promise.all(
      fields.map(async (field) => {
        if (entity[field]) {
          entity[field] = await this.kms.decrypt(entity[field]);
        }
      }),
    );
  }
}

Audit Log on Data Access​

Every read or write of a PII field produces an immutable audit event in BigQuery.

BigQuery Audit Table Schema​

CREATE TABLE `project.security.pii_access_log` (
  event_id        STRING  NOT NULL,
  timestamp       TIMESTAMP NOT NULL,
  user_id         STRING,           -- authenticated principal
  service_account STRING,           -- service identity
  action          STRING  NOT NULL, -- READ | WRITE | DELETE | EXPORT
  resource_type   STRING  NOT NULL, -- 'User' | 'Order' | 'Payment'
  resource_id     STRING  NOT NULL,
  fields_accessed ARRAY<STRING>,    -- which PII fields were touched
  request_id      STRING,           -- trace ID from OpenTelemetry
  ip_address      STRING,
  justification   STRING            -- business reason (optional, for DSAR ops)
)
PARTITION BY DATE(timestamp)
OPTIONS (require_partition_filter = true);

Audit Service​

// src/security/pii-audit.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { BigQuery } from '@google-cloud/bigquery';

export type PiiAction = 'READ' | 'WRITE' | 'DELETE' | 'EXPORT';

export interface PiiAccessEvent {
  resourceType: string;
  resourceId: string;
  fieldsAccessed: string[];
  action: PiiAction;
  userId?: string;
  requestId?: string;
  justification?: string;
}

@Injectable()
export class PiiAuditService {
  private readonly logger = new Logger(PiiAuditService.name);
  private readonly bq = new BigQuery();
  private readonly table = this.bq
    .dataset(process.env.BQ_DATASET!)
    .table('pii_access_log');

  async log(event: PiiAccessEvent): Promise<void> {
    const row = {
      event_id: crypto.randomUUID(),
      timestamp: new Date().toISOString(),
      user_id: event.userId ?? null,
      service_account: process.env.K8S_SERVICE_ACCOUNT ?? null,
      action: event.action,
      resource_type: event.resourceType,
      resource_id: event.resourceId,
      fields_accessed: event.fieldsAccessed,
      request_id: event.requestId ?? null,
      ip_address: null, // populated by calling code when available
      justification: event.justification ?? null,
    };

    try {
      await this.table.insert([row]);
    } catch (err) {
      // Audit failures must never swallow the original request — log and alert
      this.logger.error('PII audit log write failed', err);
      // Emit metric so alert fires if audit logging is degraded
      // metrics.increment('pii_audit.write_failure');
    }
  }
}

NestJS Interceptor — auto-audit on controller calls​

// src/security/pii-audit.interceptor.ts
import {
  CallHandler, ExecutionContext, Injectable, NestInterceptor,
} from '@nestjs/common';
import { Observable, tap } from 'rxjs';
import { Reflector } from '@nestjs/core';
import { PiiAuditService, PiiAction } from './pii-audit.service';

export const AUDIT_PII = 'audit_pii';

// Decorator for controllers
export const AuditPii = (
  resourceType: string,
  fields: string[],
  action: PiiAction = 'READ',
) =>
  SetMetadata(AUDIT_PII, { resourceType, fields, action });

@Injectable()
export class PiiAuditInterceptor implements NestInterceptor {
  constructor(
    private readonly audit: PiiAuditService,
    private readonly reflector: Reflector,
  ) {}

  intercept(ctx: ExecutionContext, next: CallHandler): Observable<any> {
    const meta = this.reflector.get<{
      resourceType: string;
      fields: string[];
      action: PiiAction;
    }>(AUDIT_PII, ctx.getHandler());

    if (!meta) return next.handle();

    const req = ctx.switchToHttp().getRequest();

    return next.handle().pipe(
      tap(() => {
        this.audit.log({
          resourceType: meta.resourceType,
          fieldsAccessed: meta.fields,
          action: meta.action,
          userId: req.user?.sub,
          requestId: req.headers['x-request-id'],
          resourceId: req.params?.id ?? 'bulk',
        });
      }),
    );
  }
}

// Usage on a controller method:
@Get(':id')
@AuditPii('User', ['email', 'phoneNumber', 'shippingAddress'])
getUser(@Param('id') id: string) {
  return this.usersService.findOne(id);
}

GCP Cloud Audit Logs (Infrastructure Layer)​

Enable Data Access audit logs on all PII-adjacent GCP services via the org policy:

# infra/audit-policy.tf
resource "google_project_iam_audit_config" "pii_audit" {
  project = var.project_id
  service = "allServices"

  audit_log_config {
    log_type = "ADMIN_READ"
  }
  audit_log_config {
    log_type = "DATA_READ"
  }
  audit_log_config {
    log_type = "DATA_WRITE"
  }
}

# Route all audit logs to a dedicated, immutable bucket
resource "google_logging_project_sink" "audit_sink" {
  name        = "pii-audit-sink"
  destination = "storage.googleapis.com/${google_storage_bucket.audit_bucket.name}"
  filter      = "logName:\"cloudaudit.googleapis.com\""

  unique_writer_identity = true
}

resource "google_storage_bucket" "audit_bucket" {
  name          = "audit-logs-${var.project_id}"
  location      = var.region
  force_destroy = false

  retention_policy {
    retention_period = 31536000  # 1 year (GDPR minimum)
    is_locked        = true      # immutable — cannot be deleted early
  }

  uniform_bucket_level_access = true
}

Key Rotation Procedure​

Cloud KMS handles DEK re-wrapping automatically. After a rotation:

  1. New encrypt operations use the new CMEK version automatically
  2. Existing ciphertext remains decryptable — old key versions stay enabled until you disable them
  3. Disabling old version: only after re-encrypting all stored DEKs
# Verify current key version
gcloud kms keys versions list \
  --location=us-central1 \
  --keyring=pii-keyring-prod \
  --key=pii-cmek

# Manually trigger rotation (outside 90-day schedule)
gcloud kms keys update pii-cmek \
  --location=us-central1 \
  --keyring=pii-keyring-prod \
  --next-rotation-time=$(date -d '+1 day' --rfc-3339=seconds)

Compliance Checklist​

  • CMEK key ring provisioned in the same region as the database (data residency)
  • HSM protection level enabled on all PII keys
  • 90-day automatic key rotation configured
  • Cloud SQL instance bound to CMEK key
  • PiiField decorator applied to all PII entity columns
  • PiiEncryptionSubscriber registered in the TypeORM data source
  • BigQuery audit table partitioned with retention ≥ 1 year
  • GCP Data Access Audit Logs enabled for allServices
  • Audit log sink bucket set with immutable retention policy
  • Alert rules deployed for KMS errors and bulk export
  • DSAR (Data Subject Access Request) runbook documents how to use justification field
