Why Privacy & Security Matters​

What is Personal Data?​

Personal data is any information that relates to an identified or identifiable living individual. Even data that has been de-identified or anonymized can often still be used to re-identify a person, especially when combined with a secondary data set.

This could be:

  • Sensitive documents - Medical records, bank statements, card numbers
  • User-generated content - Messages, emails, photos, search history, home CCTV
  • Metadata - Mouse clicks, typing patterns, time spent on each web page

How is Data Collected?​

One of the most common data collection methods is web tracking. This is when websites use cookies, device fingerprints, and other methods to identify you and follow you around the web. When aggregated together, this data can paint a very detailed picture of who you are.

How is Data Stored?​

Data is typically stored in databases on servers. 56% of servers are owned by Amazon AWS, Google Cloud, and Microsoft Azure. Large data leaks occur almost daily. Check if you've been in a breach at Have I Been Pwned.

What is Personal Data Used For?​

Government Mass Surveillance​

Intelligence and law enforcement agencies conduct mass surveillance on the entire population, not just those suspected of wrongdoing. Mass surveillance is a means of control and suppression - when we know we are being watched, we subconsciously change our behavior.

Corporations​

Tech giants (Google, Facebook, Apple, Amazon, Microsoft) build billion-dollar businesses from data that our interactions with digital devices create. We have:

  • No guarantees about secure storage
  • No way to verify deletion
  • No access to what their AI systems have inferred

Cybercriminals​

Hackers pose an ongoing threat. With increasing amounts of personal data being collected, we are more vulnerable to:

  • Data breaches
  • Identity fraud
  • Ransomware
  • Impersonation
  • Profile building and selling

Why Data Privacy Matters​

Key Points

Privacy is a fundamental right - As Edward Snowden said: "Arguing that you don't care about the right to privacy because you have nothing to hide is no different than saying you don't care about free speech because you have nothing to say."

Data gives control over you - Knowledge is power; Knowledge about you is power over you. Your information will be used to anticipate your actions and manipulate how you shop, vote, and think.

Data can be used against you - Personal information can be "cherry-picked" to paint a misleading picture. Behavior deemed acceptable today may be held against you tomorrow.

Data collection has no boundaries - Once you share personal data, it is out of your control forever and at risk of being hacked, leaked, or sold.

Data discriminates - Aggregated data profiles influence decisions about insurance premiums, job prospects, loans, and what content you see online.

What Should We Do?​

  1. Educate yourself about what's happening and why it matters
  2. Stay aware of policy changes, revelations, breaches and news
  3. Take steps to secure online accounts and protect devices
  4. Learn how to communicate privately and browse anonymously
  5. Use software that respects your privacy and keeps data safe
  6. Support organizations fighting for privacy and internet freedom
  7. Make your voice heard and stand up for what you believe in

Quick Start Guide (TLDR)​

Personal Security Checklist​

A summarized version of the most essential steps to protect your digital life.

Authentication​

  • ✅ Use a long, strong and unique password for each account (How Secure Is My Password?)
  • ✅ Use a secure password manager like Bitwarden or KeePass
  • ✅ Enable 2-Factor authentication with an authenticator app
  • ✅ Store backup codes safely on paper or encrypted storage
  • ✅ Sign up for breach alerts (Firefox Monitor or HaveIBeenPwned)

Browsing​

  • ✅ Use privacy-respecting browsers like Brave or Firefox
  • ✅ Set default search to DuckDuckGo
  • ✅ Only visit HTTPS websites (check for lock icon)
  • ✅ Block trackers with Privacy Badger or uBlock Origin
  • ✅ Keep browser up-to-date
  • ✅ Use compartmentalization (Firefox Containers)
  • ✅ Don't save passwords in browser - use password manager instead
  • ✅ Clear cookies regularly with Cookie-Auto-Delete
  • ✅ Use Tor Browser for anonymous browsing

Mobile Phone​

  • ✅ Set a long device PIN or passphrase
  • ✅ Enable fingerprint authentication (avoid face unlock)
  • ✅ Encrypt your device (Settings → Security → Encryption)
  • ✅ Keep device updated
  • ✅ Review and limit app permissions
  • ✅ Disable unused connectivity features (WiFi, Bluetooth, NFC)
  • ✅ Disable location tracking history
  • ✅ Use app firewall like NetGuard (Android) or Lockdown (iOS)
  • ✅ Check apps for trackers using Exodus

Email​

  • ✅ Use long, strong, unique password and enable 2FA
  • ✅ Consider secure email providers like ProtonMail or Tutanota
  • ✅ Use email aliasing (Anonaddy or SimpleLogin)
  • ✅ Disable automatic loading of remote content
  • ✅ Use custom domain for email independence
  • ✅ Backup with IMAP client like Thunderbird

Secure Messaging​

  • ✅ Use end-to-end encrypted apps like Signal
  • ✅ Ensure devices are secure and encrypted
  • ✅ Disable cloud services and backups
  • ✅ Strip metadata from media before sharing
  • ✅ Verify recipient identity
  • ✅ Avoid SMS - use encrypted messaging instead

Networking​

  • ✅ Use reputable VPN like ProtonVPN or Mullvad
  • ✅ Change router's default password
  • ✅ Use WPA2/WPA3 with strong password
  • ✅ Use secure DNS provider like Cloudflare 1.1.1.1

Choosing Secure Messaging​

Key Considerations​

End-to-End Encryption​

Messages are encrypted locally on your device before being sent. Neither the service provider nor any interceptor can decrypt the content. Avoid apps where E2E is optional.

Open Source​

Without open source code, you cannot verify true security. The complete source code must be public and thoroughly documented.

Code Audit​

Code should be regularly audited by independent security specialists with published reports.

Active Maintenance​

Security updates must be pushed quickly. A stable public release with secure auto-updating is essential.

Reproducible Builds​

Allows verification that binaries are built directly from public source code without backdoors.

Meta Data Protection​

Check what is collected, how long stored, with whom shared, and for what purposes. Best policy: "We do not collect any user metadata."

Anonymity​

Ability to sign up without phone number or email is critical for vulnerable users. Anonymous platforms protect against targeted attacks.

Contact Verification​

Fingerprint verification prevents account hijacking and man-in-the-middle attacks.

Ephemeral Messages​

Self-destructing messages protect data if device is lost or stolen.

Forward Secrecy​

New encryption key for every message means compromised keys cannot decrypt previous messages.

Decentralization​

Peer-to-peer systems eliminate single points of failure and reduce trust requirements.

Additional Settings​

  • Disable read receipts
  • Disable last online indicators
  • Disable typing notifications
  • Disable cloud sync/backup
Remember

The weakest point in any system is the user. Follow good security practices and ensure your contacts do the same.
