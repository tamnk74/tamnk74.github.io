CQRS — Read / Write Split

Command Query Responsibility Segregation at e-commerce scale: separate write models (PostgreSQL), read models (Elasticsearch + Redis), CDC-based sync via Debezium and Kafka, and NestJS implementation with @nestjs/cqrs.

Problem Statement​

A single database serving both reads and writes creates coupling that breaks at scale:

  • Write model needs strong consistency, complex validation, and transactional integrity
  • Read model needs denormalized, pre-joined data optimised for specific query shapes (product listing page, order history, search)
  • Contention: write-heavy operations (flash sale reservations) compete with read-heavy product page loads on the same DB connections

Solution: CQRS separates the write path (Commands → PostgreSQL) from the read path (Queries → Redis / Elasticsearch). Updates propagate asynchronously via CDC (Change Data Capture) through Kafka.

Architecture​

Consistency model: eventual consistency between write and read models (typical lag: 100–500 ms via Kafka). For payment and order status, the write model is queried directly to guarantee strong consistency.

When to Use CQRS (and When Not To)​

Use CQRSAvoid CQRS
High read/write ratio (e.g. 100:1 product reads to inventory writes)Simple CRUD — overhead outweighs benefit
Read model needs different shape than write model (denormalized joins)Single team with simple domain
Independent read/write scalability requiredStrong consistency required for reads (use DB directly instead)
Multiple read models per aggregate (search, listing, detail)Real-time read-after-write requirements

Write Side: Command Handlers (NestJS)​

// src/orders/commands/create-order.command.ts
export class CreateOrderCommand {
  constructor(
    public readonly userId: string,
    public readonly cartId: string,
    public readonly addressId: string,
  ) {}
}

// src/orders/commands/create-order.handler.ts
import { CommandHandler, ICommandHandler, EventBus } from '@nestjs/cqrs';
import { InjectDataSource } from '@nestjs/typeorm';
import { DataSource } from 'typeorm';
import { CreateOrderCommand } from './create-order.command';
import { Order } from '../entities/order.entity';
import { Outbox } from '../../outbox/outbox.entity';

@CommandHandler(CreateOrderCommand)
export class CreateOrderHandler implements ICommandHandler<CreateOrderCommand> {
  constructor(
    @InjectDataSource() private readonly ds: DataSource,
    private readonly eventBus: EventBus,
  ) {}

  async execute(command: CreateOrderCommand): Promise<string> {
    return this.ds.transaction(async (em) => {
      // Write model: normalized, transactionally consistent
      const order = em.create(Order, {
        userId:    command.userId,
        cartId:    command.cartId,
        addressId: command.addressId,
        status:    'PENDING',
      });
      await em.save(order);

      // Outbox row in same transaction — guarantees at-least-once delivery
      await em.save(Outbox, {
        aggregateType: 'Order',
        aggregateId:   order.id,
        eventType:     'order.created',
        payload:       JSON.stringify({ orderId: order.id, userId: order.userId }),
      });

      return order.id;
    });
  }
}

import { OrdersController } from './orders.controller';

// src/orders/orders.controller.ts
import { Controller, Post, Get, Body, Param } from '@nestjs/common';
import { CommandBus, QueryBus } from '@nestjs/cqrs';
import { CreateOrderCommand } from './commands/create-order.command';
import { GetOrderQuery } from './queries/get-order.query';

@Controller('orders')
export class OrdersController {
  constructor(
    private readonly commandBus: CommandBus,
    private readonly queryBus: QueryBus,
  ) {}

  @Post()
  async create(@Body() dto: CreateOrderDto): Promise<{ orderId: string }> {
    const orderId = await this.commandBus.execute(
      new CreateOrderCommand(dto.userId, dto.cartId, dto.addressId)
    );
    return { orderId };
  }

  @Get(':id')
  async getOne(@Param('id') id: string) {
    // Read path — queries Redis first, falls back to Elasticsearch
    return this.queryBus.execute(new GetOrderQuery(id));
  }
}

Read Side: Query Handlers​

// src/orders/queries/get-order.query.ts
export class GetOrderQuery {
  constructor(public readonly orderId: string) {}
}

// src/orders/queries/get-order.handler.ts
import { IQueryHandler, QueryHandler } from '@nestjs/cqrs';
import { InjectRedis } from '@liaoliaots/nestjs-redis';
import { ElasticsearchService } from '@nestjs/elasticsearch';
import { InjectDataSource } from '@nestjs/typeorm';
import { DataSource } from 'typeorm';
import Redis from 'ioredis';
import { GetOrderQuery } from './get-order.query';

@QueryHandler(GetOrderQuery)
export class GetOrderHandler implements IQueryHandler<GetOrderQuery> {
  constructor(
    @InjectRedis() private readonly redis: Redis,
    private readonly es: ElasticsearchService,
    @InjectDataSource() private readonly ds: DataSource,
  ) {}

  async execute(query: GetOrderQuery): Promise<OrderReadModel | null> {
    // Layer 1: Redis hot cache (TTL 60 s)
    const cached = await this.redis.get(`order:${query.orderId}`);
    if (cached) return JSON.parse(cached);

    // Layer 2: Elasticsearch read model
    try {
      const hit = await this.es.get({
        index: 'orders-read',
        id: query.orderId,
      });
      const order = hit._source as OrderReadModel;
      await this.redis.set(`order:${query.orderId}`, JSON.stringify(order), 'EX', 60);
      return order;
    } catch {
      // ES miss — fall through to primary DB (strong consistency fallback)
    }

    // Layer 3: PostgreSQL (strong consistency — reserved for order placement confirmation)
    const row = await this.ds.query(
      `SELECT o.*, u.email, u.name
       FROM orders o JOIN users u ON u.id = o.user_id
       WHERE o.id = $1`,
      [query.orderId]
    );
    if (!row[0]) return null;

    const order = this.toReadModel(row[0]);
    await this.redis.set(`order:${query.orderId}`, JSON.stringify(order), 'EX', 60);
    return order;
  }

  private toReadModel(row: any): OrderReadModel {
    return {
      orderId:    row.id,
      status:     row.status,
      userId:     row.user_id,
      userEmail:  row.email,
      userName:   row.name,
      createdAt:  row.created_at,
      totalAmount: parseFloat(row.total_amount),
    };
  }
}

interface OrderReadModel {
  orderId:    string;
  status:     string;
  userId:     string;
  userEmail:  string;
  userName:   string;
  createdAt:  string;
  totalAmount: number;
}

Read model projector (NestJS consumer)​

// src/projectors/order-projector.consumer.ts
import { Controller, Logger } from '@nestjs/common';
import { EventPattern, Payload } from '@nestjs/microservices';
import { ElasticsearchService } from '@nestjs/elasticsearch';
import { InjectRedis } from '@liaoliaots/nestjs-redis';
import Redis from 'ioredis';

@Controller()
export class OrderProjectorConsumer {
  private readonly logger = new Logger(OrderProjectorConsumer.name);

  constructor(
    private readonly es: ElasticsearchService,
    @InjectRedis() private readonly redis: Redis,
  ) {}

  @EventPattern('cdc.public.orders')
  async onOrderChange(@Payload() event: CdcEvent): Promise<void> {
    const { op, after, before } = event;

    if (op === 'd') {
      // Soft-delete in read model
      await this.es.update({
        index: 'orders-read',
        id: before.id,
        doc: { deleted: true },
      });
      await this.redis.del(`order:${before.id}`);
      return;
    }

    // Create or update — project to denormalized read model
    const readModel = {
      orderId:     after.id,
      userId:      after.user_id,
      status:      after.status,
      totalAmount: after.total_amount,
      createdAt:   after.created_at,
      updatedAt:   after.updated_at,
    };

    await this.es.index({
      index:  'orders-read',
      id:     after.id,
      document: readModel,
    });

    // Invalidate Redis so next read gets fresh data
    await this.redis.del(`order:${after.id}`);

    this.logger.debug(`Projected order ${after.id} op=${op}`);
  }
}

interface CdcEvent {
  op: 'c' | 'u' | 'd' | 'r';
  before?: Record<string, any>;
  after?: Record<string, any>;
}

Cache Invalidation Strategy​

// src/cache/cache-invalidation.service.ts
import { Injectable } from '@nestjs/common';
import { OnEvent } from '@nestjs/event-emitter';
import { InjectRedis } from '@liaoliaots/nestjs-redis';
import Redis from 'ioredis';

@Injectable()
export class CacheInvalidationService {
  constructor(@InjectRedis() private readonly redis: Redis) {}

  @OnEvent('product.updated')
  async onProductUpdated(event: { sku: string }): Promise<void> {
    // Invalidate all read-layer caches for this product
    await this.redis.del(`product:${event.sku}`);
    await this.redis.del(`price:${event.sku}`);
    await this.redis.del(`product:listing:*`);  // pattern — use SCAN in production
  }

  @OnEvent('inventory.updated')
  async onInventoryUpdated(event: { sku: string }): Promise<void> {
    await this.redis.del(`stock:cached:${event.sku}`);
    // Note: stock:${sku} (atomic counter) is NOT deleted — it IS the source of truth
  }

  @OnEvent('order.status.changed')
  async onOrderStatusChanged(event: { orderId: string }): Promise<void> {
    await this.redis.del(`order:${event.orderId}`);
  }
}

Pattern-based invalidation with SCAN (production-safe)​

async invalidatePattern(pattern: string): Promise<void> {
  let cursor = '0';
  do {
    const [nextCursor, keys] = await this.redis.scan(cursor, 'MATCH', pattern, 'COUNT', 100);
    cursor = nextCursor;
    if (keys.length > 0) {
      await this.redis.del(...keys);
    }
  } while (cursor !== '0');
}

Read Model Rebuild (Rehydration)​

When Elasticsearch index is lost or a new projection is added:

// src/projectors/rehydration.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { InjectDataSource } from '@nestjs/typeorm';
import { DataSource } from 'typeorm';
import { ElasticsearchService } from '@nestjs/elasticsearch';

@Injectable()
export class RehydrationService {
  private readonly logger = new Logger(RehydrationService.name);
  private readonly BATCH_SIZE = 500;

  constructor(
    @InjectDataSource() private readonly ds: DataSource,
    private readonly es: ElasticsearchService,
  ) {}

  async rehydrateOrders(): Promise<void> {
    let offset = 0;
    let total = 0;
    this.logger.log('Starting order read-model rehydration...');

    while (true) {
      const rows = await this.ds.query(
        `SELECT o.id, o.user_id, o.status, o.total_amount, o.created_at, o.updated_at
         FROM orders o
         ORDER BY o.created_at
         LIMIT $1 OFFSET $2`,
        [this.BATCH_SIZE, offset]
      );
      if (rows.length === 0) break;

      // Bulk index into Elasticsearch
      const body = rows.flatMap((row: any) => [
        { index: { _index: 'orders-read', _id: row.id } },
        {
          orderId:     row.id,
          userId:      row.user_id,
          status:      row.status,
          totalAmount: parseFloat(row.total_amount),
          createdAt:   row.created_at,
          updatedAt:   row.updated_at,
        },
      ]);
      await this.es.bulk({ body });

      total += rows.length;
      offset += this.BATCH_SIZE;
      this.logger.log(`Rehydrated ${total} orders...`);
    }

    this.logger.log(`Rehydration complete — ${total} orders indexed`);
  }
}

Failure Modes​

FailureDetectionMitigation
Elasticsearch cluster unavailableQuery handler catch block; alertFall back to PostgreSQL for all reads; write model unaffected
Redis failoverCache miss spike; Memorystore alertQueries fall through to Elasticsearch; Cloud Memorystore HA auto-promotes
CDC pipeline lag (Kafka connector paused)Consumer lag alertRead models become stale; tolerable for product data; payment/order queries already use PostgreSQL
Read model corruption (bad projection)Data mismatch alert via reconciliation jobTrigger RehydrationService.rehydrateOrders() from admin endpoint; zero-downtime (writes unaffected)
Debezium slot bloat (replication slot not consumed)PostgreSQL WAL disk usage alertMonitor pg_replication_slots; set max_slot_wal_keep_size to cap WAL retention
