Payment Service — PSP Integration & Stripe

Charge, refund, dispute handling: Stripe as PSP, webhook-driven async events, idempotent charge flow, PCI-DSS compliance via tokenization, and Saga integration.

Responsibilities​

  • Process charge and refund via Stripe (no raw card data ever touches our servers)
  • Handle async payment events from Stripe webhooks (capture, failure, dispute, refund)
  • Guarantee idempotent charges — network retries never result in double charges
  • Participate in the checkout Saga as step 2 (after inventory reservation)
  • Maintain an immutable audit log of every payment state transition

PCI-DSS Compliance Boundary​

Key rule: Raw card data (PAN, CVV) never reaches our infrastructure. Stripe.js tokenizes on the client; we receive only a paymentMethodId string, then confirm the PaymentIntent server-side.

For namespace isolation and Kubernetes network policy enforcement, see PCI-DSS: Payment Service Isolation.

Data Model​

CREATE TABLE payment_intents (
  id                UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  order_id          UUID NOT NULL UNIQUE,
  stripe_intent_id  TEXT NOT NULL UNIQUE,
  amount_cents      BIGINT NOT NULL,
  currency          CHAR(3) NOT NULL DEFAULT 'USD',
  status            TEXT NOT NULL DEFAULT 'pending'
                    CHECK (status IN (
                      'pending','processing','captured',
                      'failed','refunded','disputed'
                    )),
  failure_reason    TEXT,
  idempotency_key   TEXT NOT NULL UNIQUE,
  created_at        TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at        TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE TABLE payment_events (
  id                UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  payment_intent_id UUID NOT NULL REFERENCES payment_intents(id),
  stripe_event_id   TEXT NOT NULL UNIQUE, -- webhook dedup
  event_type        TEXT NOT NULL,
  payload           JSONB NOT NULL,
  processed_at      TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
CREATE INDEX idx_payment_events_intent ON payment_events (payment_intent_id);

NestJS Payment Service​

// src/payment/payment.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';
import Stripe from 'stripe';
import { InjectDataSource } from '@nestjs/typeorm';
import { DataSource } from 'typeorm';
import { EventEmitter2 } from '@nestjs/event-emitter';

@Injectable()
export class PaymentService {
  private readonly stripe: Stripe;
  private readonly logger = new Logger(PaymentService.name);

  constructor(
    private readonly config: ConfigService,
    @InjectDataSource() private readonly ds: DataSource,
    private readonly events: EventEmitter2,
  ) {
    this.stripe = new Stripe(this.config.getOrThrow('STRIPE_SECRET_KEY'), {
      apiVersion: '2024-04-10',
    });
  }

  /**
   * Create a Stripe PaymentIntent for the order.
   * Called when the order is created (before payment method is confirmed).
   */
  async createIntent(
    orderId: string,
    amountCents: number,
    currency: string,
    idempotencyKey: string,
  ): Promise<string> {
    const existing = await this.ds.query(
      `SELECT stripe_intent_id FROM payment_intents WHERE idempotency_key = $1`,
      [idempotencyKey]
    );
    if (existing.length > 0) return existing[0].stripe_intent_id;

    const intent = await this.stripe.paymentIntents.create(
      {
        amount:   amountCents,
        currency,
        metadata: { orderId },
        automatic_payment_methods: { enabled: true },
      },
      { idempotencyKey }
    );

    await this.ds.query(
      `INSERT INTO payment_intents
         (order_id, stripe_intent_id, amount_cents, currency, idempotency_key)
       VALUES ($1, $2, $3, $4, $5)`,
      [orderId, intent.id, amountCents, currency, idempotencyKey]
    );

    return intent.client_secret!;
  }

  /**
   * Confirm capture (called by order-service Saga consumer on payment.captured webhook).
   * Updates status and emits Kafka event.
   */
  async markCaptured(stripeIntentId: string): Promise<void> {
    await this.ds.query(
      `UPDATE payment_intents
       SET status = 'captured', updated_at = NOW()
       WHERE stripe_intent_id = $1`,
      [stripeIntentId]
    );
    const [intent] = await this.ds.query(
      `SELECT order_id FROM payment_intents WHERE stripe_intent_id = $1`,
      [stripeIntentId]
    );
    this.events.emit('payment.captured', { orderId: intent.order_id, stripeIntentId });
  }

  /**
   * Issue a full or partial refund.
   */
  async refund(orderId: string, amountCents?: number): Promise<void> {
    const [intent] = await this.ds.query(
      `SELECT stripe_intent_id, amount_cents FROM payment_intents
       WHERE order_id = $1 AND status = 'captured'`,
      [orderId]
    );
    if (!intent) throw new Error(`No captured payment for order ${orderId}`);

    const refund = await this.stripe.refunds.create({
      payment_intent: intent.stripe_intent_id,
      amount:         amountCents, // undefined = full refund
    });

    await this.ds.query(
      `UPDATE payment_intents SET status = 'refunded', updated_at = NOW()
       WHERE stripe_intent_id = $1`,
      [intent.stripe_intent_id]
    );
    this.events.emit('payment.refunded', { orderId, refundId: refund.id });
    this.logger.log(`Refund issued for order ${orderId}: refund ${refund.id}`);
  }
}

Stripe Webhook Handler​

Stripe notifies our service asynchronously of payment events. Signature verification prevents spoofing:

// src/payment/webhook.controller.ts
import {
  Controller, Post, Headers, Req, RawBodyRequest, Logger, BadRequestException
} from '@nestjs/common';
import { Request } from 'express';
import Stripe from 'stripe';
import { ConfigService } from '@nestjs/config';
import { InjectDataSource } from '@nestjs/typeorm';
import { DataSource } from 'typeorm';
import { PaymentService } from './payment.service';

@Controller('webhooks/stripe')
export class StripeWebhookController {
  private readonly stripe: Stripe;
  private readonly logger = new Logger(StripeWebhookController.name);

  constructor(
    private readonly config: ConfigService,
    @InjectDataSource() private readonly ds: DataSource,
    private readonly paymentService: PaymentService,
  ) {
    this.stripe = new Stripe(this.config.getOrThrow('STRIPE_SECRET_KEY'), {
      apiVersion: '2024-04-10',
    });
  }

  @Post()
  async handleWebhook(
    @Headers('stripe-signature') sig: string,
    @Req() req: RawBodyRequest<Request>,
  ): Promise<{ received: boolean }> {
    let event: Stripe.Event;
    try {
      event = this.stripe.webhooks.constructEvent(
        req.rawBody!,
        sig,
        this.config.getOrThrow('STRIPE_WEBHOOK_SECRET'),
      );
    } catch {
      throw new BadRequestException('Invalid Stripe webhook signature');
    }

    // Dedup: skip already-processed events (Stripe delivers at least once)
    const [exists] = await this.ds.query(
      `SELECT 1 FROM payment_events WHERE stripe_event_id = $1`, [event.id]
    );
    if (exists) return { received: true };

    // Record event
    const intent = event.data.object as Stripe.PaymentIntent;
    await this.ds.query(
      `INSERT INTO payment_events (payment_intent_id, stripe_event_id, event_type, payload)
       SELECT id, $1, $2, $3 FROM payment_intents WHERE stripe_intent_id = $4`,
      [event.id, event.type, JSON.stringify(event.data), intent.id]
    );

    switch (event.type) {
      case 'payment_intent.succeeded':
        await this.paymentService.markCaptured(intent.id);
        break;
      case 'payment_intent.payment_failed':
        await this.ds.query(
          `UPDATE payment_intents SET status = 'failed',
             failure_reason = $1, updated_at = NOW()
           WHERE stripe_intent_id = $2`,
          [intent.last_payment_error?.message, intent.id]
        );
        break;
      case 'charge.dispute.created':
        await this.ds.query(
          `UPDATE payment_intents SET status = 'disputed', updated_at = NOW()
           WHERE stripe_intent_id = $1`,
          [intent.id]
        );
        this.logger.warn(`Dispute opened for PaymentIntent ${intent.id}`);
        break;
    }

    return { received: true };
  }
}

Failure Modes​

FailureMitigation
Double charge on network timeoutIdempotency key on both our DB and Stripe API — second call returns existing intent
Webhook delivered twicestripe_event_id UNIQUE constraint — second insert skipped
Stripe outage during capturePaymentIntent remains pending; Stripe retries webhook up to 3 days
Refund after partial fulfilmentamountCents parameter supports partial refund to correct amount
