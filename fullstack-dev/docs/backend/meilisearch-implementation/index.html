MeiliSearch Implementation Guide for E-commerce

Overview​

MeiliSearch is a lightning-fast, open-source search engine that delivers search-as-you-type results in less than 50 milliseconds. This guide provides a comprehensive implementation for integrating MeiliSearch into your NestJS e-commerce microservices architecture, enabling powerful product search, faceted filtering, and hybrid semantic search capabilities.

Why MeiliSearch?​

Key Benefits​

  • ⚡ Lightning Fast: Sub-50ms search results with search-as-you-type
  • 🎯 Ultra Relevant: Advanced full-text search with great out-of-the-box relevancy
  • 🔌 Plug-n-Play: Deploy in minutes with zero configuration
  • 🎨 Developer Friendly: Intuitive API and excellent SDKs
  • 🔍 Typo Tolerant: Built-in typo tolerance for better UX
  • 🌍 Multi-language: Supports 28+ languages out of the box
  • 📊 Faceting & Filtering: Advanced filtering and faceted search
  • 🧠 Hybrid Search: Combines full-text and semantic search
  • 📍 Geosearch: Location-based search and filtering

Use Cases in E-commerce​

  1. Product Search: Fast, relevant product discovery
  2. Autocomplete: Real-time search suggestions
  3. Faceted Navigation: Filter by price, category, brand, etc.
  4. Similar Products: Find related items using semantic search
  5. Store Locator: Location-based store search
  6. Order Search: Quick order lookup for customers and admins

// src/search/meilisearch.service.ts
import { Injectable, Logger, OnModuleInit } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';
import { MeiliSearch, Index } from 'meilisearch';

@Injectable()
export class MeiliSearchService implements OnModuleInit {
  private readonly logger = new Logger(MeiliSearchService.name);
  private client: MeiliSearch;
  private indexes: Map<string, Index> = new Map();

  constructor(private configService: ConfigService) {
    const host = this.configService.get('MEILISEARCH_HOST', 'http://localhost:7700');
    const apiKey = this.configService.get('MEILISEARCH_MASTER_KEY');

    this.client = new MeiliSearch({
      host,
      apiKey,
    });
  }

  async onModuleInit() {
    try {
      await this.client.health();
      this.logger.log('✅ MeiliSearch connection established');
      await this.initializeIndexes();
    } catch (error) {
      this.logger.error('❌ Failed to connect to MeiliSearch', error);
      throw error;
    }
  }

  private async initializeIndexes() {
    const indexConfigs = [
      { name: 'products', primaryKey: 'id' },
      { name: 'orders', primaryKey: 'id' },
      { name: 'customers', primaryKey: 'id' },
      { name: 'stores', primaryKey: 'id' },
    ];

    for (const config of indexConfigs) {
      try {
        const index = await this.client.createIndex(config.name, {
          primaryKey: config.primaryKey,
        });
        this.indexes.set(config.name, index);
        this.logger.log(`📑 Index created: ${config.name}`);
      } catch (error) {
        if (error.code === 'index_already_exists') {
          const index = this.client.index(config.name);
          this.indexes.set(config.name, index);
          this.logger.log(`📑 Index loaded: ${config.name}`);
        } else {
          this.logger.error(`Failed to create index: ${config.name}`, error);
        }
      }
    }
  }

  getIndex(name: string): Index {
    const index = this.indexes.get(name);
    if (!index) {
      throw new Error(`Index ${name} not found`);
    }
    return index;
  }

  getClient(): MeiliSearch {
    return this.client;
  }

  async addDocuments(indexName: string, documents: any[]) {
    const index = this.getIndex(indexName);
    return await index.addDocuments(documents);
  }

  async updateDocuments(indexName: string, documents: any[]) {
    const index = this.getIndex(indexName);
    return await index.updateDocuments(documents);
  }

  async deleteDocument(indexName: string, documentId: string | number) {
    const index = this.getIndex(indexName);
    return await index.deleteDocument(documentId);
  }

  async deleteDocuments(indexName: string, documentIds: (string | number)[]) {
    const index = this.getIndex(indexName);
    return await index.deleteDocuments(documentIds);
  }

  async search<T = any>(indexName: string, query: string, options?: any): Promise<T> {
    const index = this.getIndex(indexName);
    return await index.search(query, options);
  }

  async clearIndex(indexName: string) {
    const index = this.getIndex(indexName);
    return await index.deleteAllDocuments();
  }
}

Product Search Implementation​

1. Product Search Service​

// src/search/product-search.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { MeiliSearchService } from './meilisearch.service';
import { SearchResponse } from 'meilisearch';

export interface ProductSearchDocument {
  id: string;
  name: string;
  description: string;
  price: number;
  discountedPrice?: number;
  category: string;
  brand: string;
  sku: string;
  stock: number;
  rating: number;
  reviewCount: number;
  tags: string[];
  images: string[];
  attributes: Record<string, any>;
  createdAt: number;
  updatedAt: number;
}

export interface ProductSearchOptions {
  query?: string;
  page?: number;
  limit?: number;
  filters?: {
    category?: string[];
    brand?: string[];
    priceMin?: number;
    priceMax?: number;
    rating?: number;
    inStock?: boolean;
  };
  sort?: string[];
  facets?: string[];
}

@Injectable()
export class ProductSearchService {
  private readonly logger = new Logger(ProductSearchService.name);
  private readonly indexName = 'products';

  constructor(private readonly meilisearch: MeiliSearchService) {}

  async configureIndex() {
    const index = this.meilisearch.getIndex(this.indexName);

    // Configure searchable attributes (in order of importance)
    await index.updateSearchableAttributes(['name', 'brand', 'category', 'description', 'sku', 'tags']);

    // Configure filterable attributes
    await index.updateFilterableAttributes([
      'category',
      'brand',
      'price',
      'discountedPrice',
      'rating',
      'stock',
      'tags',
    ]);

    // Configure sortable attributes
    await index.updateSortableAttributes([
      'price',
      'discountedPrice',
      'rating',
      'reviewCount',
      'createdAt',
      'updatedAt',
    ]);

    // Configure ranking rules
    await index.updateRankingRules([
      'words',
      'typo',
      'proximity',
      'attribute',
      'sort',
      'exactness',
      'rating:desc',
      'reviewCount:desc',
    ]);

    // Configure typo tolerance
    await index.updateTypoTolerance({
      enabled: true,
      minWordSizeForTypos: {
        oneTypo: 4,
        twoTypos: 8,
      },
    });

    // Configure faceting
    await index.updateFaceting({
      maxValuesPerFacet: 100,
    });

    this.logger.log('✅ Product index configured successfully');
  }

  async indexProduct(product: ProductSearchDocument) {
    return await this.meilisearch.addDocuments(this.indexName, [product]);
  }

  async indexProducts(products: ProductSearchDocument[]) {
    return await this.meilisearch.addDocuments(this.indexName, products);
  }

  async updateProduct(product: Partial<ProductSearchDocument> & { id: string }) {
    return await this.meilisearch.updateDocuments(this.indexName, [product]);
  }

  async deleteProduct(productId: string) {
    return await this.meilisearch.deleteDocument(this.indexName, productId);
  }

  async search(options: ProductSearchOptions): Promise<SearchResponse<ProductSearchDocument>> {
    const { query = '', page = 1, limit = 20, filters, sort, facets } = options;

    // Build filter string
    const filterParts: string[] = [];

    if (filters) {
      if (filters.category && filters.category.length > 0) {
        const categoryFilter = filters.category.map((cat) => `category = "${cat}"`).join(' OR ');
        filterParts.push(`(${categoryFilter})`);
      }

      if (filters.brand && filters.brand.length > 0) {
        const brandFilter = filters.brand.map((b) => `brand = "${b}"`).join(' OR ');
        filterParts.push(`(${brandFilter})`);
      }

      if (filters.priceMin !== undefined) {
        filterParts.push(`price >= ${filters.priceMin}`);
      }

      if (filters.priceMax !== undefined) {
        filterParts.push(`price <= ${filters.priceMax}`);
      }

      if (filters.rating !== undefined) {
        filterParts.push(`rating >= ${filters.rating}`);
      }

      if (filters.inStock) {
        filterParts.push('stock > 0');
      }
    }

    const searchParams: any = {
      limit,
      offset: (page - 1) * limit,
      filter: filterParts.length > 0 ? filterParts : undefined,
      sort: sort || ['rating:desc', 'reviewCount:desc'],
      attributesToHighlight: ['name', 'description'],
      highlightPreTag: '<mark>',
      highlightPostTag: '</mark>',
    };

    if (facets && facets.length > 0) {
      searchParams.facets = facets;
    }

    return await this.meilisearch.search<SearchResponse<ProductSearchDocument>>(this.indexName, query, searchParams);
  }

  async autocomplete(query: string, limit = 10) {
    return await this.meilisearch.search(this.indexName, query, {
      limit,
      attributesToRetrieve: ['id', 'name', 'price', 'images'],
      attributesToHighlight: ['name'],
    });
  }

  async getSimilarProducts(productId: string, limit = 10) {
    const product = await this.getProductById(productId);
    if (!product) {
      return { hits: [], estimatedTotalHits: 0 };
    }

    // Search using product category and tags
    const searchQuery = `${product.category} ${product.tags.join(' ')}`;

    const results = await this.search({
      query: searchQuery,
      limit: limit + 1, // +1 to exclude the current product
      filters: {
        category: [product.category],
      },
    });

    // Filter out the current product
    results.hits = results.hits.filter((hit) => hit.id !== productId);

    return results;
  }

  private async getProductById(productId: string) {
    const index = this.meilisearch.getIndex(this.indexName);
    try {
      return await index.getDocument(productId);
    } catch (error) {
      this.logger.error(`Product not found: ${productId}`, error);
      return null;
    }
  }

  async getFacets(facetNames: string[]): Promise<Record<string, any>> {
    const result = await this.search({
      query: '',
      limit: 0,
      facets: facetNames,
    });

    return result.facetDistribution || {};
  }
}

2. Product Search Controller​

// src/search/product-search.controller.ts
import { Controller, Get, Query, Param, Post, Body, UseGuards } from '@nestjs/common';
import { ProductSearchService } from './product-search.service';
import { JwtAuthGuard } from '../auth/guards/jwt-auth.guard';
import { RolesGuard } from '../auth/guards/roles.guard';
import { Roles } from '../auth/decorators/roles.decorator';

@Controller('search/products')
export class ProductSearchController {
  constructor(private readonly productSearchService: ProductSearchService) {}

  @Get()
  async search(
    @Query('q') query: string,
    @Query('page') page: number = 1,
    @Query('limit') limit: number = 20,
    @Query('category') category?: string,
    @Query('brand') brand?: string,
    @Query('priceMin') priceMin?: number,
    @Query('priceMax') priceMax?: number,
    @Query('rating') rating?: number,
    @Query('inStock') inStock?: boolean,
    @Query('sort') sort?: string,
  ) {
    const filters: any = {};

    if (category) {
      filters.category = category.split(',');
    }

    if (brand) {
      filters.brand = brand.split(',');
    }

    if (priceMin !== undefined) {
      filters.priceMin = Number(priceMin);
    }

    if (priceMax !== undefined) {
      filters.priceMax = Number(priceMax);
    }

    if (rating !== undefined) {
      filters.rating = Number(rating);
    }

    if (inStock !== undefined) {
      filters.inStock = inStock === true || inStock === 'true';
    }

    const sortArray = sort ? sort.split(',') : undefined;

    return await this.productSearchService.search({
      query,
      page: Number(page),
      limit: Number(limit),
      filters,
      sort: sortArray,
      facets: ['category', 'brand', 'rating'],
    });
  }

  @Get('autocomplete')
  async autocomplete(@Query('q') query: string, @Query('limit') limit: number = 10) {
    return await this.productSearchService.autocomplete(query, limit);
  }

  @Get('facets')
  async getFacets(@Query('facets') facets?: string) {
    const facetNames = facets ? facets.split(',') : ['category', 'brand', 'rating'];
    return await this.productSearchService.getFacets(facetNames);
  }

  @Get(':id/similar')
  async getSimilarProducts(@Param('id') productId: string, @Query('limit') limit: number = 10) {
    return await this.productSearchService.getSimilarProducts(productId, limit);
  }

  @Post('index')
  @UseGuards(JwtAuthGuard, RolesGuard)
  @Roles('admin')
  async indexProduct(@Body() product: any) {
    return await this.productSearchService.indexProduct(product);
  }

  @Post('configure')
  @UseGuards(JwtAuthGuard, RolesGuard)
  @Roles('admin')
  async configureIndex() {
    await this.productSearchService.configureIndex();
    return { message: 'Index configured successfully' };
  }
}

Synchronization Strategy​

1. Real-time Sync with Database Triggers​

// src/products/products.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import { Product } from './entities/product.entity';
import { ProductSearchService } from '../search/product-search.service';

@Injectable()
export class ProductsService {
  private readonly logger = new Logger(ProductsService.name);

  constructor(
    @InjectRepository(Product)
    private readonly productRepository: Repository<Product>,
    private readonly productSearchService: ProductSearchService,
  ) {}

  async create(createProductDto: any): Promise<Product> {
    const product = this.productRepository.create(createProductDto);
    const savedProduct = await this.productRepository.save(product);

    // Sync to MeiliSearch
    try {
      await this.syncProductToSearch(savedProduct);
    } catch (error) {
      this.logger.error('Failed to sync product to MeiliSearch', error);
      // Don't fail the request, log and continue
    }

    return savedProduct;
  }

  async update(id: string, updateProductDto: any): Promise<Product> {
    await this.productRepository.update(id, updateProductDto);
    const updatedProduct = await this.productRepository.findOne({ where: { id } });

    // Sync to MeiliSearch
    try {
      await this.syncProductToSearch(updatedProduct);
    } catch (error) {
      this.logger.error('Failed to sync product update to MeiliSearch', error);
    }

    return updatedProduct;
  }

  async remove(id: string): Promise<void> {
    await this.productRepository.delete(id);

    // Remove from MeiliSearch
    try {
      await this.productSearchService.deleteProduct(id);
    } catch (error) {
      this.logger.error('Failed to remove product from MeiliSearch', error);
    }
  }

  private async syncProductToSearch(product: Product) {
    const searchDocument = {
      id: product.id,
      name: product.name,
      description: product.description,
      price: product.price,
      discountedPrice: product.discountedPrice,
      category: product.category.name,
      brand: product.brand.name,
      sku: product.sku,
      stock: product.stock,
      rating: product.rating || 0,
      reviewCount: product.reviewCount || 0,
      tags: product.tags || [],
      images: product.images || [],
      attributes: product.attributes || {},
      createdAt: product.createdAt.getTime(),
      updatedAt: product.updatedAt.getTime(),
    };

    await this.productSearchService.indexProduct(searchDocument);
    this.logger.log(`Product synced to search: ${product.id}`);
  }
}

2. Bulk Sync Service​

// src/search/sync.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { Cron, CronExpression } from '@nestjs/schedule';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import { Product } from '../products/entities/product.entity';
import { ProductSearchService } from './product-search.service';

@Injectable()
export class SearchSyncService {
  private readonly logger = new Logger(SearchSyncService.name);
  private isSyncing = false;

  constructor(
    @InjectRepository(Product)
    private readonly productRepository: Repository<Product>,
    private readonly productSearchService: ProductSearchService,
  ) {}

  @Cron(CronExpression.EVERY_DAY_AT_2AM)
  async fullSync() {
    if (this.isSyncing) {
      this.logger.warn('Sync already in progress, skipping...');
      return;
    }

    this.isSyncing = true;
    this.logger.log('🔄 Starting full search index sync...');

    try {
      const batchSize = 1000;
      let offset = 0;
      let totalSynced = 0;

      while (true) {
        const products = await this.productRepository.find({
          take: batchSize,
          skip: offset,
          relations: ['category', 'brand'],
        });

        if (products.length === 0) {
          break;
        }

        const searchDocuments = products.map((product) => ({
          id: product.id,
          name: product.name,
          description: product.description,
          price: product.price,
          discountedPrice: product.discountedPrice,
          category: product.category.name,
          brand: product.brand.name,
          sku: product.sku,
          stock: product.stock,
          rating: product.rating || 0,
          reviewCount: product.reviewCount || 0,
          tags: product.tags || [],
          images: product.images || [],
          attributes: product.attributes || {},
          createdAt: product.createdAt.getTime(),
          updatedAt: product.updatedAt.getTime(),
        }));

        await this.productSearchService.indexProducts(searchDocuments);

        totalSynced += products.length;
        offset += batchSize;

        this.logger.log(`Synced ${totalSynced} products...`);
      }

      this.logger.log(`✅ Full sync completed: ${totalSynced} products synced`);
    } catch (error) {
      this.logger.error('❌ Full sync failed', error);
      throw error;
    } finally {
      this.isSyncing = false;
    }
  }

  async syncProduct(productId: string) {
    const product = await this.productRepository.findOne({
      where: { id: productId },
      relations: ['category', 'brand'],
    });

    if (!product) {
      this.logger.warn(`Product not found: ${productId}`);
      return;
    }

    const searchDocument = {
      id: product.id,
      name: product.name,
      description: product.description,
      price: product.price,
      discountedPrice: product.discountedPrice,
      category: product.category.name,
      brand: product.brand.name,
      sku: product.sku,
      stock: product.stock,
      rating: product.rating || 0,
      reviewCount: product.reviewCount || 0,
      tags: product.tags || [],
      images: product.images || [],
      attributes: product.attributes || {},
      createdAt: product.createdAt.getTime(),
      updatedAt: product.updatedAt.getTime(),
    };

    await this.productSearchService.indexProduct(searchDocument);
    this.logger.log(`Product synced: ${productId}`);
  }
}

1. Search Component (React/Next.js)​

// components/ProductSearch.tsx
'use client';

import { useState, useEffect, useCallback } from 'react';
import { useDebounce } from '@/hooks/useDebounce';

interface SearchFilters {
  category?: string[];
  brand?: string[];
  priceMin?: number;
  priceMax?: number;
  rating?: number;
  inStock?: boolean;
}

export function ProductSearch() {
  const [query, setQuery] = useState('');
  const [results, setResults] = useState<any>(null);
  const [filters, setFilters] = useState<SearchFilters>({});
  const [loading, setLoading] = useState(false);
  const [facets, setFacets] = useState<any>(null);

  const debouncedQuery = useDebounce(query, 300);

  const search = useCallback(async () => {
    setLoading(true);
    try {
      const params = new URLSearchParams({
        q: debouncedQuery,
        ...(filters.category && { category: filters.category.join(',') }),
        ...(filters.brand && { brand: filters.brand.join(',') }),
        ...(filters.priceMin && { priceMin: filters.priceMin.toString() }),
        ...(filters.priceMax && { priceMax: filters.priceMax.toString() }),
        ...(filters.rating && { rating: filters.rating.toString() }),
        ...(filters.inStock !== undefined && { inStock: filters.inStock.toString() }),
      });

      const response = await fetch(`/api/search/products?${params}`);
      const data = await response.json();

      setResults(data);
      if (data.facetDistribution) {
        setFacets(data.facetDistribution);
      }
    } catch (error) {
      console.error('Search failed:', error);
    } finally {
      setLoading(false);
    }
  }, [debouncedQuery, filters]);

  useEffect(() => {
    if (debouncedQuery || Object.keys(filters).length > 0) {
      search();
    }
  }, [debouncedQuery, filters, search]);

  return (
    <div className="container mx-auto p-4">
      <div className="flex gap-4">
        {/* Filters Sidebar */}
        <aside className="w-64 space-y-4">
          <div>
            <h3 className="font-semibold mb-2">Category</h3>
            {facets?.category &&
              Object.entries(facets.category).map(([cat, count]) => (
                <label key={cat} className="flex items-center gap-2">
                  <input
                    type="checkbox"
                    checked={filters.category?.includes(cat)}
                    onChange={(e) => {
                      const newCategories = e.target.checked
                        ? [...(filters.category || []), cat]
                        : filters.category?.filter((c) => c !== cat);
                      setFilters({ ...filters, category: newCategories });
                    }}
                  />
                  {cat} ({count})
                </label>
              ))}
          </div>

          <div>
            <h3 className="font-semibold mb-2">Price Range</h3>
            <div className="flex gap-2">
              <input
                type="number"
                placeholder="Min"
                value={filters.priceMin || ''}
                onChange={(e) => setFilters({ ...filters, priceMin: Number(e.target.value) })}
                className="w-24 px-2 py-1 border rounded"
              />
              <input
                type="number"
                placeholder="Max"
                value={filters.priceMax || ''}
                onChange={(e) => setFilters({ ...filters, priceMax: Number(e.target.value) })}
                className="w-24 px-2 py-1 border rounded"
              />
            </div>
          </div>

          <div>
            <h3 className="font-semibold mb-2">Rating</h3>
            {[5, 4, 3, 2, 1].map((rating) => {
              return (
                <label key={rating} className="flex items-center gap-2">
                  <input
                    type="radio"
                    name="rating"
                    checked={filters.rating === rating}
                    onChange={() => setFilters({ ...filters, rating })}
                  />
                  {'⭐'.repeat(rating)} & up
                </label>
              );
            })}
          </div>

          <div>
            <label className="flex items-center gap-2">
              <input
                type="checkbox"
                checked={filters.inStock}
                onChange={(e) => setFilters({ ...filters, inStock: e.target.checked })}
              />
              In Stock Only
            </label>
          </div>
        </aside>

        {/* Search Results */}
        <main className="flex-1">
          <div className="mb-4">
            <input
              type="search"
              placeholder="Search products..."
              value={query}
              onChange={(e) => setQuery(e.target.value)}
              className="w-full px-4 py-2 border rounded-lg"
            />
          </div>

          {loading && <div className="text-center py-8">Loading...</div>}

          {results && (
            <>
              <div className="mb-4 text-sm text-gray-600">
                {results.estimatedTotalHits} results found in {results.processingTimeMs}ms
              </div>

              <div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4">
                {results.hits.map((product: any) => (
                  <div key={product.id} className="border rounded-lg p-4 hover:shadow-lg transition">
                    <img src={product.images[0]} alt={product.name} className="w-full h-48 object-cover rounded mb-2" />
                    <h3
                      className="font-semibold"
                      dangerouslySetInnerHTML={{
                        __html: product._formatted?.name || product.name,
                      }}
                    />
                    <p className="text-sm text-gray-600 line-clamp-2">{product.description}</p>
                    <div className="mt-2 flex items-center justify-between">
                      <span className="text-lg font-bold">${product.discountedPrice || product.price}</span>
                      {product.discountedPrice && (
                        <span className="text-sm text-gray-500 line-through">${product.price}</span>
                      )}
                    </div>
                    <div className="mt-1 text-sm text-gray-600">
                      ⭐ {product.rating} ({product.reviewCount} reviews)
                    </div>
                  </div>
                ))}
              </div>
            </>
          )}
        </main>
      </div>
    </div>
  );
}

2. Autocomplete Component​

// components/SearchAutocomplete.tsx
'use client';

import { useState, useEffect, useRef } from 'react';
import { useDebounce } from '@/hooks/useDebounce';

export function SearchAutocomplete() {
  const [query, setQuery] = useState('');
  const [suggestions, setSuggestions] = useState<any[]>([]);
  const [isOpen, setIsOpen] = useState(false);
  const [loading, setLoading] = useState(false);
  const wrapperRef = useRef<HTMLDivElement>(null);

  const debouncedQuery = useDebounce(query, 200);

  useEffect(() => {
    const fetchSuggestions = async () => {
      if (!debouncedQuery) {
        setSuggestions([]);
        return;
      }

      setLoading(true);
      try {
        const response = await fetch(
          `/api/search/products/autocomplete?q=${encodeURIComponent(debouncedQuery)}&limit=8`,
        );
        const data = await response.json();
        setSuggestions(data.hits);
        setIsOpen(true);
      } catch (error) {
        console.error('Autocomplete failed:', error);
      } finally {
        setLoading(false);
      }
    };

    fetchSuggestions();
  }, [debouncedQuery]);

  useEffect(() => {
    function handleClickOutside(event: MouseEvent) {
      if (wrapperRef.current && !wrapperRef.current.contains(event.target as Node)) {
        setIsOpen(false);
      }
    }

    document.addEventListener('mousedown', handleClickOutside);
    return () => document.removeEventListener('mousedown', handleClickOutside);
  }, []);

  return (
    <div ref={wrapperRef} className="relative">
      <input
        type="search"
        placeholder="Search products..."
        value={query}
        onChange={(e) => setQuery(e.target.value)}
        onFocus={() => suggestions.length > 0 && setIsOpen(true)}
        className="w-full px-4 py-2 border rounded-lg"
      />

      {isOpen && suggestions.length > 0 && (
        <div className="absolute z-50 w-full mt-1 bg-white border rounded-lg shadow-lg max-h-96 overflow-y-auto">
          {suggestions.map((product) => (
            <a
              key={product.id}
              href={`/products/${product.id}`}
              className="flex items-center gap-3 p-3 hover:bg-gray-50 transition"
              onClick={() => setIsOpen(false)}
            >
              <img src={product.images[0]} alt={product.name} className="w-12 h-12 object-cover rounded" />
              <div className="flex-1">
                <div
                  className="font-medium"
                  dangerouslySetInnerHTML={{
                    __html: product._formatted?.name || product.name,
                  }}
                />
                <div className="text-sm text-gray-600">${product.price}</div>
              </div>
            </a>
          ))}
        </div>
      )}

      {loading && (
        <div className="absolute right-3 top-3">
          <div className="animate-spin h-5 w-5 border-2 border-blue-500 rounded-full border-t-transparent" />
        </div>
      )}
    </div>
  );
}

import { Injectable, Inject } from '@nestjs/common';
import { CACHE_MANAGER } from '@nestjs/cache-manager';
import { Cache } from 'cache-manager';
import * as crypto from 'crypto';

@Injectable()
export class SearchCacheService {
  constructor(@Inject(CACHE_MANAGER) private cacheManager: Cache) {}

  private generateCacheKey(query: string, filters: any): string {
    const data = JSON.stringify({ query, filters });
    return `search:${crypto.createHash('md5').update(data).digest('hex')}`;
  }

  async get(query: string, filters: any): Promise<any> {
    const key = this.generateCacheKey(query, filters);
    return await this.cacheManager.get(key);

// src/search/search-metrics.service.ts
import { Injectable } from '@nestjs/common';
import { Counter, Histogram, register } from 'prom-client';

@Injectable()
export class SearchMetricsService {
  private readonly searchCounter = new Counter({
    name: 'search_queries_total',
    help: 'Total number of search queries',
    labelNames: ['index', 'status'],
  });

  private readonly searchDuration = new Histogram({
    name: 'search_query_duration_ms',
    help: 'Search query duration in milliseconds',
    labelNames: ['index'],
    buckets: [10, 25, 50, 100, 250, 500, 1000],
  });

  private readonly searchResults = new Histogram({
    name: 'search_results_count',
    help: 'Number of search results returned',
    labelNames: ['index'],
    buckets: [0, 10, 50, 100, 500, 1000, 5000],
  });

  recordSearch(index: string, duration: number, resultCount: number, status: 'success' | 'error') {
    this.searchCounter.inc({ index, status });
    this.searchDuration.observe({ index }, duration);
    this.searchResults.observe({ index }, resultCount);
  }

  getMetrics() {
    return register.metrics();
  }
}

Best Practices​

1. Index Configuration​

✅ Do:

  • Configure searchable attributes in order of importance
  • Use filterable attributes for facets
  • Enable typo tolerance for better UX
  • Set appropriate ranking rules
  • Use sortable attributes for sorting options

❌ Don't:

  • Index sensitive data (passwords, tokens)
  • Make all fields searchable (affects relevancy)
  • Ignore index size limits
  • Skip index optimization

2. Synchronization​

✅ Do:

  • Sync in real-time for critical operations
  • Use bulk operations for large datasets
  • Implement retry logic for failures
  • Log sync errors for monitoring
  • Schedule full reindexing periodically

❌ Don't:

  • Sync synchronously in request handlers
  • Block user requests for indexing
  • Ignore sync failures
  • Overload MeiliSearch with too many concurrent updates

3. Search Queries​

✅ Do:

  • Implement debouncing for autocomplete
  • Use pagination for large result sets
  • Cache frequent queries
  • Use appropriate filters
  • Implement rate limiting

❌ Don't:

  • Send every keystroke to the server
  • Return unlimited results
  • Ignore query performance
  • Skip result highlighting

Troubleshooting​

Common Issues​

1. Slow Indexing​

Symptoms: Documents taking too long to index

Solutions:

# Increase indexing memory
MEILI_MAX_INDEXING_MEMORY=4gb

# Increase indexing threads
MEILI_MAX_INDEXING_THREADS=4

# Use bulk operations
# Index in batches of 1000-10000 documents

2. High Memory Usage​

Symptoms: MeiliSearch consuming too much memory

Solutions:

  • Reduce MEILI_MAX_INDEXING_MEMORY
  • Implement index compaction
  • Remove unnecessary fields
  • Use smaller documents

3. Search Relevancy Issues​

Symptoms: Poor search results

Solutions:

// Adjust ranking rules
await index.updateRankingRules([
  'words', // Number of matched words
  'typo', // Typo tolerance
  'proximity', // Word proximity
  'attribute', // Attribute order
  'sort', // Custom sort
  'exactness', // Exact matches
]);

// Adjust searchable attributes order
await index.updateSearchableAttributes([
  'name', // Most important
  'brand',
  'category',
  'description', // Least important
]);
