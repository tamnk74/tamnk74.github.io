Protecting Non-Production Environments

Overview​

Requirement: All non-production environments must be protected under Basic Authentication, IP Whitelist or equivalent, and web crawlers (Google, Yahoo, Bing) must not be able to index the contents.

Why This Matters​

If non-production environments are not protected accordingly, critical incidents may occur:

  • Leakage of sensitive data or credentials
  • Non-production content getting indexed by search engines
  • Unauthorized access to development/staging features
  • Exposure of debug information and internal APIs

Protection Strategy​

We implement a multi-layered approach:

  1. Basic Authentication - Application-level password protection
  2. IP Whitelisting - Network-level access control via GCP Cloud Armor
  3. Crawler Prevention - Dynamic robots.txt and meta tags
  4. Monitoring & Alerts - Automated detection of security breaches

1. Environment Configuration​

Environment Variables​

Set up environment-specific configuration:

# .env.production
NODE_ENV=production
ENVIRONMENT=production

# .env.staging
NODE_ENV=production
ENVIRONMENT=staging
IS_NON_PRODUCTION=true
BASIC_AUTH_USER=admin
BASIC_AUTH_PASSWORD=<stored-in-secret-manager>
ALLOWED_IPS=203.0.113.0,198.51.100.0

# .env.development
NODE_ENV=development
ENVIRONMENT=development
IS_NON_PRODUCTION=true
Security Best Practice

Never commit credentials to version control. Use GCP Secret Manager for sensitive values.

2. Basic Authentication Implementation​

Next.js Middleware Approach​

Create middleware.ts in your Next.js project root:

import { NextResponse } from 'next/server';
import type { NextRequest } from 'next/server';

export function middleware(request: NextRequest) {
  // Only apply to non-production environments
  if (process.env.IS_NON_PRODUCTION !== 'true') {
    return NextResponse.next();
  }

  const basicAuth = request.headers.get('authorization');
  const url = request.nextUrl;

  if (basicAuth) {
    const authValue = basicAuth.split(' ')[1];
    const [user, pwd] = atob(authValue).split(':');

    if (user === process.env.BASIC_AUTH_USER && pwd === process.env.BASIC_AUTH_PASSWORD) {
      return NextResponse.next();
    }
  }

  url.pathname = '/api/auth';
  return NextResponse.rewrite(url);
}

export const config = {
  matcher: ['/((?!api/auth|_next/static|_next/image|favicon.ico).*)'],
};

Create the authentication API route pages/api/auth.ts:

import { NextApiRequest, NextApiResponse } from 'next';

export default function handler(req: NextApiRequest, res: NextApiResponse) {
  res.setHeader('WWW-Authenticate', 'Basic realm="Secure Area"');
  res.status(401).json({ message: 'Authentication required' });
}

NestJS Global Guard​

Create src/guards/basic-auth.guard.ts:

import { Injectable, CanActivate, ExecutionContext, UnauthorizedException } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';

@Injectable()
export class BasicAuthGuard implements CanActivate {
  constructor(private configService: ConfigService) {}

  canActivate(context: ExecutionContext): boolean {
    const isNonProduction = this.configService.get('IS_NON_PRODUCTION') === 'true';

    if (!isNonProduction) {
      return true; // Skip auth in production
    }

    const request = context.switchToHttp().getRequest();
    const authHeader = request.headers.authorization;

    if (!authHeader) {
      throw new UnauthorizedException('Basic authentication required');
    }

    const [scheme, credentials] = authHeader.split(' ');

    if (scheme !== 'Basic') {
      throw new UnauthorizedException('Basic authentication required');
    }

    const [username, password] = Buffer.from(credentials, 'base64').toString().split(':');

    const validUser = this.configService.get('BASIC_AUTH_USER');
    const validPassword = this.configService.get('BASIC_AUTH_PASSWORD');

    if (username !== validUser || password !== validPassword) {
      throw new UnauthorizedException('Invalid credentials');
    }

    return true;
  }
}

Apply globally in main.ts:

import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { BasicAuthGuard } from './guards/basic-auth.guard';
import { ConfigService } from '@nestjs/config';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  const configService = app.get(ConfigService);
  app.useGlobalGuards(new BasicAuthGuard(configService));

  await app.listen(3000);
}
bootstrap();

3. IP Whitelisting​

GCP Cloud Armor (Recommended)​

Cloud Armor provides network-level IP filtering at the load balancer, preventing unauthorized traffic from reaching your application.

Create Security Policy​

# Create security policy
gcloud compute security-policies create staging-policy \
    --description "Staging environment IP whitelist"

# Add allowed IPs (office/VPN addresses)
gcloud compute security-policies rules create 1000 \
    --security-policy staging-policy \
    --action "allow" \
    --src-ip-ranges "203.0.113.0/24,198.51.100.0/24" \
    --description "Office IPs"

# Default deny rule
gcloud compute security-policies rules create 2147483647 \
    --security-policy staging-policy \
    --action "deny-403" \
    --description "Default deny"

# Attach to backend service
gcloud compute backend-services update staging-backend \
    --security-policy staging-policy \
    --global

Update Existing Rules​

# Add new IP range
gcloud compute security-policies rules update 1000 \
    --security-policy staging-policy \
    --src-ip-ranges "203.0.113.0/24,198.51.100.0/24,192.0.2.0/24"

# List current rules
gcloud compute security-policies rules list staging-policy

Application-Level IP Filtering​

As a secondary layer or for environments without Cloud Armor:

Next.js Middleware​

// middleware.ts
import { NextResponse } from 'next/server';
import type { NextRequest } from 'next/server';

const ALLOWED_IPS = process.env.ALLOWED_IPS?.split(',') || [];

export function middleware(request: NextRequest) {
  if (process.env.IS_NON_PRODUCTION !== 'true') {
    return NextResponse.next();
  }

  const ip = request.ip || request.headers.get('x-forwarded-for')?.split(',')[0] || request.headers.get('x-real-ip');

  if (ip && !ALLOWED_IPS.includes(ip)) {
    return new NextResponse('Access Denied', { status: 403 });
  }

  return NextResponse.next();
}

NestJS IP Whitelist Guard​

import { Injectable, CanActivate, ExecutionContext, ForbiddenException } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';

@Injectable()
export class IpWhitelistGuard implements CanActivate {
  private allowedIps: string[];

  constructor(private configService: ConfigService) {
    this.allowedIps = this.configService.get('ALLOWED_IPS')?.split(',') || [];
  }

  canActivate(context: ExecutionContext): boolean {
    const isNonProduction = this.configService.get('IS_NON_PRODUCTION') === 'true';

    if (!isNonProduction) {
      return true;
    }

    const request = context.switchToHttp().getRequest();
    const clientIp = request.ip || request.headers['x-forwarded-for']?.split(',')[0] || request.headers['x-real-ip'];

    if (!this.allowedIps.includes(clientIp)) {
      throw new ForbiddenException('Access denied from your IP address');
    }

    return true;
  }
}

Apply in main.ts:

app.useGlobalGuards(new BasicAuthGuard(configService), new IpWhitelistGuard(configService));

4. Preventing Web Crawler Indexing​

Dynamic robots.txt​

Next.js Implementation​

For Next.js 13+ with App Router, create app/robots.ts:

import { MetadataRoute } from 'next';

export default function robots(): MetadataRoute.Robots {
  const isNonProduction = process.env.IS_NON_PRODUCTION === 'true';

  if (isNonProduction) {
    return {
      rules: {
        userAgent: '*',
        disallow: '/',
      },
    };
  }

  return {
    rules: {
      userAgent: '*',
      allow: '/',
      disallow: ['/admin/', '/api/'],
    },
    sitemap: `${process.env.NEXT_PUBLIC_SITE_URL}/sitemap.xml`,
  };
}

For Pages Router, create pages/api/robots.ts:

import { NextApiRequest, NextApiResponse } from 'next';

export default function handler(req: NextApiRequest, res: NextApiResponse) {
  const isNonProduction = process.env.IS_NON_PRODUCTION === 'true';

  res.setHeader('Content-Type', 'text/plain');

  if (isNonProduction) {
    res.send('User-agent: *\nDisallow: /\n');
  } else {
    res.send('User-agent: *\nAllow: /\nDisallow: /admin/\n');
  }
}

NestJS Implementation​

Create src/controllers/robots.controller.ts:

import { Controller, Get, Header } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';

@Controller()
export class RobotsController {
  constructor(private configService: ConfigService) {}

  @Get('robots.txt')
  @Header('Content-Type', 'text/plain')
  getRobots(): string {
    const isNonProduction = this.configService.get('IS_NON_PRODUCTION') === 'true';

    if (isNonProduction) {
      return 'User-agent: *\nDisallow: /\n';
    }

    return [
      'User-agent: *',
      'Allow: /',
      'Disallow: /admin/',
      'Disallow: /api/internal/',
      `Sitemap: ${this.configService.get('SITE_URL')}/sitemap.xml`,
    ].join('\n');
  }
}

NestJS Interceptor​

import { Injectable, NestInterceptor, ExecutionContext, CallHandler } from '@nestjs/common';
import { Observable } from 'rxjs';
import { ConfigService } from '@nestjs/config';

@Injectable()
export class NoIndexInterceptor implements NestInterceptor {
  constructor(private configService: ConfigService) {}

  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    const isNonProduction = this.configService.get('IS_NON_PRODUCTION') === 'true';

    if (isNonProduction) {
      const response = context.switchToHttp().getResponse();
      response.setHeader('X-Robots-Tag', 'noindex, nofollow, noarchive');
    }

    return next.handle();
  }
}

Apply in main.ts:

app.useGlobalInterceptors(new NoIndexInterceptor(configService));

6. Monitoring and Alerting​

Cloud Monitoring Alerts​

Alert for Authentication Failures​

# Create notification channel first (Slack, Email, PagerDuty)
gcloud alpha monitoring channels create \
    --display-name="Security Alerts" \
    --type=email \
    --channel-labels=email_address=security@example.com

# Get channel ID
CHANNEL_ID=$(gcloud alpha monitoring channels list \
    --filter="displayName:'Security Alerts'" \
    --format="value(name)")

# Create alert policy for 401/403 responses
gcloud alpha monitoring policies create \
    --notification-channels=$CHANNEL_ID \
    --display-name="Non-Production Auth Failures" \
    --condition-display-name="High authentication failures" \
    --condition-threshold-value=10 \
    --condition-threshold-duration=60s \
    --condition-filter='
      resource.type="cloud_run_revision"
      AND metric.type="run.googleapis.com/request_count"
      AND (metric.labels.response_code="401" OR metric.labels.response_code="403")

    --condition-aggregation-per-series-aligner=ALIGN_RATE

# Alert if basic auth environment variable is missing

Application-Level Monitoring​

NestJS Security Monitor Service​

Create src/services/security-monitor.service.ts:

import { Injectable, Logger } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';
import { Cron, CronExpression } from '@nestjs/schedule';

interface SecurityEvent {
  event: string;
  ip: string;
  reason: string;
  timestamp: Date;
  environment: string;
}

@Injectable()
export class SecurityMonitorService {
  private readonly logger = new Logger(SecurityMonitorService.name);

  constructor(private configService: ConfigService) {}

  logAuthFailure(ip: string, reason: string, userAgent?: string) {
    const event: SecurityEvent = {
      event: 'auth_failure',
      ip,
      reason,
      timestamp: new Date(),
      environment: this.configService.get('ENVIRONMENT'),
    };

    this.logger.warn('Security: Authentication failure', {
      ...event,
      userAgent,
    });

    // Send to external monitoring (Datadog, New Relic, etc.)
    this.sendToMonitoring(event);
  }

  logIpBlocked(ip: string) {
    const event: SecurityEvent = {
      event: 'ip_blocked',
      ip,
      reason: 'Not in whitelist',
      timestamp: new Date(),
      environment: this.configService.get('ENVIRONMENT'),
    };

    this.logger.warn('Security: IP blocked', event);
    this.sendToMonitoring(event);
  }

  @Cron(CronExpression.EVERY_6_HOURS)
  async checkSecuritySettings() {
    const isNonProduction = this.configService.get('IS_NON_PRODUCTION') === 'true';
    const hasBasicAuth = !!this.configService.get('BASIC_AUTH_PASSWORD');
    const hasIpWhitelist = !!this.configService.get('ALLOWED_IPS');

    if (isNonProduction && !hasBasicAuth && !hasIpWhitelist) {
      this.logger.error('CRITICAL: Non-production environment without protection!');
      await this.sendCriticalAlert({
        severity: 'CRITICAL',
        message: 'Non-production environment is not protected',
        environment: this.configService.get('ENVIRONMENT'),
        timestamp: new Date(),
      });
    }
  }

  private sendToMonitoring(event: SecurityEvent) {
    // Implementation for your monitoring service
    // Examples: Datadog, New Relic, Cloud Logging
  }

  private async sendCriticalAlert(alert: any) {
    // Send to Slack, PagerDuty, email, etc.
    this.logger.error('Critical alert sent', alert);
  }
}

Update your guards to use the monitoring service:

@Injectable()

    if (!authHeader) {
      this.securityMonitor.logAuthFailure(request.ip, 'No authorization header', request.headers['user-agent']);
      throw new UnauthorizedException('Basic authentication required');

      this.securityMonitor.logAuthFailure(request.ip, 'Invalid credentials', request.headers['user-agent']);
      throw new UnauthorizedException('Invalid credentials');
    }

    return true;
  }
}

Test basic authentication:

# Should return 401
curl -i https://staging.example.com

curl -i -H "Authorization: Basic $(echo -n 'admin:password' | base64)" \

# Should show: User-agent: * Allow: /

curl -i https://staging.example.com
# Should return 403 Forbidden

Automated Testing​

Create integration tests:

// test/security.e2e.spec.ts
import { Test, TestingModule } from '@nestjs/testing';
import { INestApplication } from '@nestjs/common';
import * as request from 'supertest';
import { AppModule } from '../src/app.module';

describe('Security Protection (e2e)', () => {
  let app: INestApplication;

  beforeAll(async () => {
    process.env.IS_NON_PRODUCTION = 'true';
    process.env.BASIC_AUTH_USER = 'testuser';
    process.env.BASIC_AUTH_PASSWORD = 'testpass';

    const moduleFixture: TestingModule = await Test.createTestingModule({
      imports: [AppModule],
    }).compile();

    app = moduleFixture.createNestApplication();
    await app.init();
  });

  it('should require authentication for non-production', () => {
    return request(app.getHttpServer()).get('/').expect(401);
  });

  it('should allow access with valid credentials', () => {
    const auth = Buffer.from('testuser:testpass').toString('base64');

    return request(app.getHttpServer()).get('/').set('Authorization', `Basic ${auth}`).expect(200);
  });

  it('should reject invalid credentials', () => {
    const auth = Buffer.from('wrong:credentials').toString('base64');

    return request(app.getHttpServer()).get('/').set('Authorization', `Basic ${auth}`).expect(401);
  });

  it('should return noindex in robots.txt', () => {
    return request(app.getHttpServer())
      .get('/robots.txt')
      .expect(200)
      .expect(/Disallow: \//);
  });

  afterAll(async () => {
    await app.close();
  });
});

8. CI/CD Integration​

GitHub Actions Example​

# .github/workflows/deploy-staging.yml
name: Deploy to Staging

on:
  push:
    branches: [develop]

env:
  GCP_PROJECT_ID: ${{ secrets.GCP_PROJECT_ID }}
  GCP_REGION: us-central1
  SERVICE_NAME: myapp-staging

jobs:
  deploy:
    runs-on: ubuntu-latest

    steps:
      - uses: actions/checkout@v3

      - name: Authenticate to Google Cloud
        uses: google-github-actions/auth@v1
        with:
          credentials_json: ${{ secrets.GCP_SA_KEY }}

      - name: Set up Cloud SDK
        uses: google-github-actions/setup-gcloud@v1

      - name: Build and push Docker image
        run: |
          gcloud builds submit \
            --tag gcr.io/$GCP_PROJECT_ID/$SERVICE_NAME:${{ github.sha }}

      - name: Deploy to Cloud Run
        run: |
          gcloud run deploy $SERVICE_NAME \
            --image gcr.io/$GCP_PROJECT_ID/$SERVICE_NAME:${{ github.sha }} \
            --region $GCP_REGION \
            --platform managed \
            --set-env-vars "IS_NON_PRODUCTION=true,ENVIRONMENT=staging" \
            --set-secrets "BASIC_AUTH_USER=basic-auth-username:latest,BASIC_AUTH_PASSWORD=basic-auth-password:latest"

      - name: Verify security settings
        run: |
          # Test that authentication is required
          STATUS=$(curl -s -o /dev/null -w "%{http_code}" https://$SERVICE_NAME-xxx.run.app)
          if [ "$STATUS" != "401" ]; then
            echo "ERROR: Staging environment is not protected!"
            exit 1
          fi
          echo "✓ Basic authentication is active"

          # Check robots.txt
          ROBOTS=$(curl -s https://$SERVICE_NAME-xxx.run.app/robots.txt)
          if [[ "$ROBOTS" != *"Disallow: /"* ]]; then
            echo "ERROR: robots.txt is not blocking crawlers!"
            exit 1
          fi
          echo "✓ Crawler blocking is active"

      - name: Notify deployment
        if: success()
        run: |
          echo "Staging deployed successfully with security protections enabled"

9. Compliance Checklist​

Use this checklist to verify protection is properly configured:

  • Environment Detection

    • IS_NON_PRODUCTION environment variable set
    • Different configurations for staging/production

  • Basic Authentication

    • Credentials stored in GCP Secret Manager
    • Middleware/Guard applied globally
    • 401 response returned without credentials
    • Authentication tested manually

  • IP Whitelisting

    • Cloud Armor security policy created
    • Office/VPN IPs added to allowlist
    • Default deny rule configured
    • Policy attached to backend service

  • Crawler Prevention

    • Dynamic robots.txt implemented
    • Returns "Disallow: /" for non-production
    • X-Robots-Tag header set
    • Meta robots tags added to HTML

  • Monitoring

    • Cloud Monitoring alerts configured
    • Application-level logging active
    • Periodic security checks scheduled
    • Alert notifications tested

  • Testing

    • Manual curl tests passed
    • Automated tests added to CI/CD
    • Verified from external IP
    • Robots.txt tested

  • Documentation

    • Team notified of credentials
    • Access instructions documented
    • IP whitelist process documented
    • Runbook created for incidents

10. Troubleshooting​

Common Issues​

Authentication Not Working​

Symptom: No authentication prompt appears

Solutions:

  1. Check environment variable: echo $IS_NON_PRODUCTION
  2. Verify middleware/guard is registered globally
  3. Check middleware matcher pattern isn't excluding routes
  4. Review Cloud Run logs for errors
gcloud logging read "resource.type=cloud_run_revision AND \
  resource.labels.service_name=myapp-staging" \
  --limit 50 \
  --format json

IP Whitelisting Issues​

Symptom: Authorized IPs getting blocked

Solutions:

  1. Check actual client IP in logs (may be different from expected)
  2. Verify Cloud Armor rule priority
  3. Check for NAT/proxy IP addresses
  4. Test with x-forwarded-for header
# Get your current IP
curl https://api.ipify.org

# Test from specific IP
curl -H "X-Forwarded-For: 203.0.113.5" https://staging.example.com

Robots.txt Not Updating​

Symptom: Wrong robots.txt content served

Solutions:

  1. Clear CDN cache if applicable
  2. Verify environment variable in deployment
  3. Check route is not cached by middleware
  4. Test directly: curl https://staging.example.com/robots.txt

Production Accidentally Protected​

Symptom: Production requires authentication

Solutions:

  1. Immediately verify IS_NON_PRODUCTION is not set
  2. Check environment-specific .env file
  3. Review Cloud Run environment variables
  4. Redeploy with correct configuration
# Check current environment variables
gcloud run services describe myapp-production \
  --region us-central1 \
  --format="value(spec.template.spec.containers[0].env)"

Summary​

This protection strategy ensures non-production environments are secure:

  1. Multi-Layer Security: Basic auth + IP whitelist + crawler prevention
  2. GCP Integration: Cloud Armor, Secret Manager, Cloud Monitoring
  3. Framework Support: Native Next.js and NestJS implementations
  4. Automated Monitoring: Alerts for breaches or misconfigurations
  5. CI/CD Validation: Automated testing of security controls

All non-production environments should be treated as potentially vulnerable and protected accordingly. Regular audits and monitoring ensure protection remains in place.
