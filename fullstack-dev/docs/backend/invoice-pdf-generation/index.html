Invoice Generation & PDF Download

Generating tax-compliant PDF invoices on order.confirmed events, storing them in GCS, and serving secure signed-URL downloads — using Puppeteer (headless Chrome) in a NestJS worker service.

Problem Statement​

When an order is confirmed, the platform must:

  • Generate a legally compliant PDF invoice (order lines, tax breakdown, seller details, buyer address)
  • Store the PDF durably in Google Cloud Storage (not in the DB)
  • Notify the customer via email with a download link
  • Allow customers to re-download invoices at any time from their account page
  • Generate invoices in <2 s to avoid blocking the Saga flow
  • Handle 500,000 invoices/day without impacting the order-service critical path

Architecture principle: invoice generation is a side effect — it runs in a dedicated worker, triggered by a Kafka event, never on the checkout critical path.

Architecture​

Key design decisions:

  • PDF generation uses Puppeteer (renders HTML → PDF via headless Chrome) — full CSS support, pixel-perfect output
  • PDFs are stored in GCS — cheap, durable, immutable; never stored in PostgreSQL
  • Downloads use GCS Signed URLs — time-limited, authenticated, served directly from GCS CDN without proxying through the API
  • Kafka decouples invoice generation from the Saga — a generation failure never blocks order confirmation

Database Schema​

CREATE TABLE invoices (
  id            UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  order_id      UUID NOT NULL UNIQUE,
  user_id       UUID NOT NULL,
  invoice_number TEXT NOT NULL UNIQUE,   -- e.g. INV-2026-0000001 (sequential)
  gcs_path      TEXT NOT NULL,           -- invoices/{orderId}.pdf
  status        TEXT NOT NULL DEFAULT 'pending'
                CHECK (status IN ('pending', 'ready', 'failed')),
  amount_total  NUMERIC(12,2) NOT NULL,
  currency      TEXT NOT NULL DEFAULT 'USD',
  issued_at     TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  created_at    TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_invoices_user ON invoices (user_id, issued_at DESC);
CREATE INDEX idx_invoices_order ON invoices (order_id);

-- Invoice number sequence (atomic, gap-free)
CREATE SEQUENCE invoice_number_seq START 1;

Kafka Consumer​

// src/consumers/order-confirmed.consumer.ts
import { Controller, Logger } from '@nestjs/common';
import { EventPattern, Payload, Ctx, KafkaContext } from '@nestjs/microservices';
import { InjectRedis } from '@liaoliaots/nestjs-redis';
import Redis from 'ioredis';
import { InvoiceService } from '../invoice.service';

@Controller()
export class OrderConfirmedConsumer {
  private readonly logger = new Logger(OrderConfirmedConsumer.name);

  constructor(
    private readonly invoiceService: InvoiceService,
    @InjectRedis() private readonly redis: Redis,
  ) {}

  @EventPattern('order-events')
  async handleOrderEvent(
    @Payload() event: OrderEvent,
    @Ctx() ctx: KafkaContext,
  ): Promise<void> {
    if (event.type !== 'order.confirmed') return;

    // Idempotency: skip if already generated
    const dedupKey = `invoice:generated:${event.orderId}`;
    const isNew = await this.redis.set(dedupKey, '1', 'EX', 86400, 'NX');
    if (!isNew) {
      this.logger.debug(`Invoice already generated for order ${event.orderId}`);
      return;
    }

    try {
      await this.invoiceService.generateInvoice(event);
    } catch (err) {
      // Release dedup key so a retry can re-attempt
      await this.redis.del(dedupKey);
      this.logger.error(`Failed to generate invoice for ${event.orderId}`, err);
      throw err; // Kafka will retry via consumer group offset
    }
  }
}

interface OrderEvent {
  type: string;
  orderId: string;
  userId: string;
  userEmail: string;
  userName: string;
  billingAddress: Address;
  items: OrderItem[];
  subtotal: number;
  taxAmount: number;
  total: number;
  currency: string;
  confirmedAt: string;
}

interface OrderItem {
  sku: string;
  name: string;
  qty: number;
  unitPrice: number;
  totalPrice: number;
}

interface Address {
  line1: string;
  line2?: string;
  city: string;
  state: string;
  zip: string;
  country: string;
}

Invoice Service (orchestrator)​

// src/invoice.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { InjectDataSource } from '@nestjs/typeorm';
import { DataSource } from 'typeorm';
import { KafkaProducerService } from './kafka/kafka-producer.service';
import { PdfGeneratorService } from './generators/pdf.generator';
import { GcsStorageService } from './storage/gcs.storage.service';

@Injectable()
export class InvoiceService {
  private readonly logger = new Logger(InvoiceService.name);

  constructor(
    @InjectDataSource() private readonly ds: DataSource,
    private readonly pdfGenerator: PdfGeneratorService,
    private readonly gcs: GcsStorageService,
    private readonly kafka: KafkaProducerService,
  ) {}

  async generateInvoice(event: OrderEvent): Promise<void> {
    // 1. Reserve sequential invoice number (atomic)
    const [{ invoice_number }] = await this.ds.query(
      `SELECT 'INV-' || TO_CHAR(NOW(), 'YYYY') || '-' || LPAD(nextval('invoice_number_seq')::text, 7, '0') AS invoice_number`
    );

    // 2. Insert pending row (reserves the invoice number)
    const [invoice] = await this.ds.query(
      `INSERT INTO invoices (order_id, user_id, invoice_number, gcs_path, status, amount_total, currency)
       VALUES ($1, $2, $3, '', 'pending', $4, $5)
       ON CONFLICT (order_id) DO NOTHING
       RETURNING id`,
      [event.orderId, event.userId, invoice_number, event.total, event.currency]
    );
    if (!invoice) return; // already exists (concurrent consumer)

    // 3. Generate PDF
    const pdfBuffer = await this.pdfGenerator.generate({
      invoiceNumber: invoice_number,
      ...event,
    });

    // 4. Upload to GCS
    const gcsPath = `invoices/${event.orderId}.pdf`;
    await this.gcs.upload(gcsPath, pdfBuffer, 'application/pdf');

    // 5. Mark ready
    await this.ds.query(
      `UPDATE invoices SET gcs_path = $1, status = 'ready' WHERE order_id = $2`,
      [gcsPath, event.orderId]
    );

    // 6. Emit invoice.ready → notification-service will email the customer
    await this.kafka.send('invoice-events', {
      type:          'invoice.ready',
      orderId:       event.orderId,
      userId:        event.userId,
      userEmail:     event.userEmail,
      invoiceNumber: invoice_number,
      downloadPath:  gcsPath,
    });

    this.logger.log(`Invoice ${invoice_number} generated for order ${event.orderId}`);
  }
}

PDF Generator (Puppeteer)​

// src/generators/pdf.generator.ts
import { Injectable, Logger, OnModuleDestroy } from '@nestjs/common';
import puppeteer, { Browser } from 'puppeteer';
import { HtmlRendererService } from './html.renderer';

@Injectable()
export class PdfGeneratorService implements OnModuleDestroy {
  private readonly logger = new Logger(PdfGeneratorService.name);
  private browser: Browser | null = null;

  constructor(private readonly htmlRenderer: HtmlRendererService) {}

  private async getBrowser(): Promise<Browser> {
    if (!this.browser || !this.browser.connected) {
      this.browser = await puppeteer.launch({
        headless: true,
        args: [
          '--no-sandbox',              // required in Kubernetes
          '--disable-setuid-sandbox',
          '--disable-dev-shm-usage',   // avoid /dev/shm OOM in containers
          '--disable-gpu',
        ],
      });
    }
    return this.browser;
  }

  async generate(data: InvoiceData): Promise<Buffer> {
    const html = await this.htmlRenderer.render(data);
    const browser = await this.getBrowser();
    const page = await browser.newPage();

    try {
      await page.setContent(html, { waitUntil: 'networkidle0' });

      const pdfBuffer = await page.pdf({
        format:    'A4',
        printBackground: true,
        margin: { top: '20mm', right: '20mm', bottom: '20mm', left: '20mm' },
      });

      return Buffer.from(pdfBuffer);
    } finally {
      await page.close();
    }
  }

  async onModuleDestroy(): Promise<void> {
    if (this.browser) await this.browser.close();
  }
}

export interface InvoiceData {
  invoiceNumber:  string;
  orderId:        string;
  userEmail:      string;
  userName:       string;
  billingAddress: Address;
  items:          OrderItem[];
  subtotal:       number;
  taxAmount:      number;
  total:          number;
  currency:       string;
  confirmedAt:    string;
}

HTML Renderer (Handlebars helpers)​

// src/generators/html.renderer.ts
import { Injectable } from '@nestjs/common';
import Handlebars from 'handlebars';
import * as fs from 'fs/promises';
import * as path from 'path';
import type { InvoiceData } from './pdf.generator';

@Injectable()
export class HtmlRendererService {
  private template: HandlebarsTemplateDelegate | null = null;

  constructor() {
    Handlebars.registerHelper('formatCurrency', (amount: number) =>
      new Intl.NumberFormat('en-US', { style: 'currency', currency: 'USD' }).format(amount)
    );
    Handlebars.registerHelper('formatDate', (iso: string) =>
      new Date(iso).toLocaleDateString('en-US', { year: 'numeric', month: 'long', day: 'numeric' })
    );
  }

  async render(data: InvoiceData): Promise<string> {
    if (!this.template) {
      const src = await fs.readFile(
        path.join(process.cwd(), 'templates', 'invoice.html.hbs'),
        'utf8'
      );
      this.template = Handlebars.compile(src);
    }
    return this.template(data);
  }
}

GCS Storage Service​

// src/storage/gcs.storage.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { Storage } from '@google-cloud/storage';
import { ConfigService } from '@nestjs/config';

@Injectable()
export class GcsStorageService {
  private readonly logger = new Logger(GcsStorageService.name);
  private readonly storage = new Storage();
  private readonly bucket: string;

  constructor(private readonly config: ConfigService) {
    this.bucket = this.config.getOrThrow('GCS_INVOICE_BUCKET'); // e.g. ecom-invoices-prod
  }

  async upload(
    gcsPath: string,
    buffer: Buffer,
    contentType: string,
  ): Promise<void> {
    const file = this.storage.bucket(this.bucket).file(gcsPath);
    await file.save(buffer, {
      contentType,
      metadata: { cacheControl: 'private, no-store' },
    });
    this.logger.debug(`Uploaded ${gcsPath} to gs://${this.bucket}`);
  }

  /** Generate a signed URL valid for 15 minutes */
  async getSignedUrl(gcsPath: string): Promise<string> {
    const [url] = await this.storage
      .bucket(this.bucket)
      .file(gcsPath)
      .getSignedUrl({
        version: 'v4',
        action:  'read',
        expires: Date.now() + 15 * 60 * 1000,  // 15 min
        responseDisposition: `attachment; filename="invoice-${gcsPath.split('/').pop()}"`,
      });
    return url;
  }
}

Download Endpoint (order-service)​

// src/orders/orders.controller.ts (add to existing controller)
import { Controller, Get, Param, Redirect, Req, UnauthorizedException, NotFoundException } from '@nestjs/common';
import { InjectDataSource } from '@nestjs/typeorm';
import { DataSource } from 'typeorm';
import { GcsStorageService } from '../storage/gcs.storage.service';
import { JwtPayload } from '../auth/jwt.decorator';

@Controller('orders')
export class OrdersController {
  constructor(
    @InjectDataSource() private readonly ds: DataSource,
    private readonly gcs: GcsStorageService,
  ) {}

  /**
   * GET /orders/:id/invoice
   * Returns a 302 redirect to a 15-minute GCS Signed URL.
   * The PDF is served directly from GCS — no proxying through the API.
   */
  @Get(':id/invoice')
  @Redirect()
  async downloadInvoice(
    @Param('id') orderId: string,
    @JwtPayload() jwt: { sub: string; role: string },
  ) {
    const [invoice] = await this.ds.query(
      `SELECT gcs_path, user_id, status FROM invoices WHERE order_id = $1`,
      [orderId]
    );

    if (!invoice) {
      throw new NotFoundException('Invoice not yet generated — try again in a few seconds');
    }

    // Authorization: customer can only download their own invoice; admin can download any
    if (jwt.role !== 'admin' && invoice.user_id !== jwt.sub) {
      throw new UnauthorizedException();
    }

    if (invoice.status !== 'ready') {
      throw new NotFoundException(`Invoice status is '${invoice.status}' — not ready`);
    }

    const url = await this.gcs.getSignedUrl(invoice.gcs_path);
    return { url };
  }
}

Frontend (Next.js) — Trigger download​

// app/account/orders/[orderId]/page.tsx (Next.js App Router)
'use client';

async function downloadInvoice(orderId: string): Promise<void> {
  const res = await fetch(`/api/orders/${orderId}/invoice`, {
    headers: { Authorization: `Bearer ${getAccessToken()}` },
    redirect: 'manual',  // follow the 302 ourselves so we can open in new tab
  });

  if (res.status === 302 || res.ok) {
    // The response headers contain Location on 302, or body contains url on 200
    const { url } = await res.json().catch(() => ({ url: res.headers.get('location') }));
    if (url) window.open(url, '_blank');
  } else {
    const body = await res.json();
    alert(body.message ?? 'Invoice not ready yet');
  }
}

GCS Bucket with lifecycle & IAM​

# Create bucket (private, regional, versioned)
gcloud storage buckets create gs://ecom-invoices-prod \
  --location=us-central1 \
  --uniform-bucket-level-access

# invoice-service workload identity (write-only)
gcloud storage buckets add-iam-policy-binding gs://ecom-invoices-prod \
  --member="serviceAccount:invoice-service@ecom-prod.iam.gserviceaccount.com" \
  --role="roles/storage.objectCreator"

gcloud iam service-accounts add-iam-policy-binding \
  invoice-service@ecom-prod.iam.gserviceaccount.com \
  --member="serviceAccount:invoice-service@ecom-prod.iam.gserviceaccount.com" \
