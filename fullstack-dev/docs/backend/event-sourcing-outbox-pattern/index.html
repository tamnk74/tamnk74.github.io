Event Sourcing and Outbox Pattern Guide

Overview​

Event Sourcing and the Outbox pattern are crucial architectural patterns for building reliable, event-driven microservices. Event Sourcing stores state as a sequence of events, while the Outbox pattern ensures reliable event publishing without dual-write problems. This guide covers implementation strategies, best practices, and production patterns.

Event Sourcing Fundamentals​

What is Event Sourcing?​

Benefits and Drawbacks​

Benefits:

  • Complete audit trail of all changes
  • Time travel - reconstruct state at any point
  • Event replay for debugging
  • Natural fit for event-driven architectures
  • No data loss - all events preserved

Drawbacks:

  • Complexity in querying current state
  • Storage growth over time
  • Learning curve for developers
  • Eventual consistency
  • Schema evolution challenges

Event Store Service​

// shared/event-sourcing/src/event-store.service.ts
import { Injectable, Logger, ConflictException } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository, DataSource } from 'typeorm';
import { EventStoreEvent } from './entities/event-store.entity';
import { OutboxEvent, OutboxEventStatus } from '@ecommerce/outbox';

export interface DomainEvent {
  aggregateId: string;
  aggregateType: string;
  eventType: string;
  eventData: any;
  metadata?: any;
}

@Injectable()
export class EventStoreService {
  private readonly logger = new Logger(EventStoreService.name);

  constructor(
    @InjectRepository(EventStoreEvent)
    private eventStoreRepository: Repository<EventStoreEvent>,
    @InjectRepository(OutboxEvent)
    private outboxRepository: Repository<OutboxEvent>,
    private dataSource: DataSource,
  ) {}

  /**
   * Append event to event store and outbox in a single transaction
   * This ensures atomicity - both or neither are saved
   */
  async appendEvent(event: DomainEvent): Promise<EventStoreEvent> {
    return this.dataSource.transaction(async (manager) => {
      // Get current version for this aggregate
      const currentVersion = await this.getCurrentVersion(event.aggregateId, manager);
      const newVersion = currentVersion + 1;

      // Save to event store
      const eventStoreEvent = manager.create(EventStoreEvent, {
        aggregateId: event.aggregateId,
        aggregateType: event.aggregateType,
        eventType: event.eventType,
        eventData: event.eventData,
        metadata: event.metadata,
        version: newVersion,
      });

      let savedEvent: EventStoreEvent;
      try {
        savedEvent = await manager.save(eventStoreEvent);
      } catch (error) {
        if (error.code === '23505') {
          // Unique constraint violation
          throw new ConflictException(`Version ${newVersion} already exists for aggregate ${event.aggregateId}`);
        }
        throw error;
      }

      // Save to outbox for reliable publishing
      const outboxEvent = manager.create(OutboxEvent, {
        aggregateId: event.aggregateId,
        aggregateType: event.aggregateType,
        eventType: event.eventType,
        eventData: event.eventData,
        metadata: event.metadata,
        status: OutboxEventStatus.PENDING,
        version: newVersion,
      });

      await manager.save(outboxEvent);

      this.logger.log(
        `Event stored: ${event.eventType} for ${event.aggregateType}:${event.aggregateId} (v${newVersion})`,
      );

      return savedEvent;
    });
  }

  /**
   * Append multiple events in a single transaction
   */
  async appendEvents(events: DomainEvent[]): Promise<EventStoreEvent[]> {
    if (events.length === 0) return [];

    // Verify all events are for the same aggregate
    const aggregateId = events[0].aggregateId;
    if (!events.every((e) => e.aggregateId === aggregateId)) {
      throw new Error('All events must belong to the same aggregate');
    }

    return this.dataSource.transaction(async (manager) => {
      const currentVersion = await this.getCurrentVersion(aggregateId, manager);
      const savedEvents: EventStoreEvent[] = [];

      for (let i = 0; i < events.length; i++) {
        const event = events[i];
        const newVersion = currentVersion + i + 1;

        // Save to event store
        const eventStoreEvent = manager.create(EventStoreEvent, {
          aggregateId: event.aggregateId,
          aggregateType: event.aggregateType,
          eventType: event.eventType,
          eventData: event.eventData,
          metadata: event.metadata,
          version: newVersion,
        });

        const savedEvent = await manager.save(eventStoreEvent);
        savedEvents.push(savedEvent);

        // Save to outbox
        const outboxEvent = manager.create(OutboxEvent, {
          aggregateId: event.aggregateId,
          aggregateType: event.aggregateType,
          eventType: event.eventType,
          eventData: event.eventData,
          metadata: event.metadata,
          status: OutboxEventStatus.PENDING,
          version: newVersion,
        });

        await manager.save(outboxEvent);
      }

      this.logger.log(`${events.length} events stored for aggregate ${aggregateId}`);

      return savedEvents;
    });
  }

  /**
   * Get all events for an aggregate
   */
  async getEvents(aggregateId: string): Promise<EventStoreEvent[]> {
    return this.eventStoreRepository.find({
      where: { aggregateId },
      order: { version: 'ASC' },
    });
  }

  /**
   * Get events since a specific version
   */
  async getEventsSince(aggregateId: string, version: number): Promise<EventStoreEvent[]> {
    return this.eventStoreRepository
      .createQueryBuilder('event')
      .where('event.aggregateId = :aggregateId', { aggregateId })
      .andWhere('event.version > :version', { version })
      .orderBy('event.version', 'ASC')
      .getMany();
  }

  /**
   * Get events by type for analytics/reporting
   */
  async getEventsByType(eventType: string, startDate?: Date, endDate?: Date): Promise<EventStoreEvent[]> {
    const query = this.eventStoreRepository
      .createQueryBuilder('event')
      .where('event.eventType = :eventType', { eventType });

    if (startDate) {
      query.andWhere('event.createdAt >= :startDate', { startDate });
    }

    if (endDate) {
      query.andWhere('event.createdAt <= :endDate', { endDate });
    }

    return query.orderBy('event.createdAt', 'DESC').getMany();
  }

  /**
   * Stream events (for large datasets)
   */
  async *streamEvents(aggregateType: string, batchSize: number = 100): AsyncGenerator<EventStoreEvent[]> {
    let lastId = '';

    while (true) {
      const query = this.eventStoreRepository
        .createQueryBuilder('event')
        .where('event.aggregateType = :aggregateType', { aggregateType })
        .orderBy('event.id', 'ASC')
        .take(batchSize);

      if (lastId) {
        query.andWhere('event.id > :lastId', { lastId });
      }

      const events = await query.getMany();

      if (events.length === 0) {
        break;
      }

      yield events;

      lastId = events[events.length - 1].id;

      if (events.length < batchSize) {
        break;
      }
    }
  }

  private async getCurrentVersion(aggregateId: string, manager?: any): Promise<number> {
    const repo = manager ? manager.getRepository(EventStoreEvent) : this.eventStoreRepository;

    const lastEvent = await repo
      .createQueryBuilder('event')
      .where('event.aggregateId = :aggregateId', { aggregateId })
      .orderBy('event.version', 'DESC')
      .getOne();

    return lastEvent ? lastEvent.version : 0;
  }
}

Aggregate Design​

Base Aggregate Root​

// shared/event-sourcing/src/aggregate-root.ts
import { AggregateRoot as NestAggregateRoot } from '@nestjs/cqrs';

export abstract class AggregateRoot extends NestAggregateRoot {
  private version: number = 0;
  private uncommittedEvents: any[] = [];

  protected apply(event: any): void {
    this.applyEvent(event);
    this.uncommittedEvents.push(event);
  }

  protected abstract applyEvent(event: any): void;

  loadFromHistory(events: any[]): void {
    events.forEach((event) => {
      this.applyEvent(event);
      this.version++;
    });
  }

  getUncommittedEvents(): any[] {
    return this.uncommittedEvents;
  }

  markEventsAsCommitted(): void {
    this.uncommittedEvents = [];
  }

  getVersion(): number {
    return this.version;
  }
}

Order Aggregate Example​

// services/order-service/src/aggregates/order.aggregate.ts
import { AggregateRoot } from '@ecommerce/event-sourcing';

// Domain Events
export class OrderCreatedEvent {
  constructor(
    public readonly orderId: string,
    public readonly userId: string,
    public readonly items: OrderItem[],
    public readonly totalAmount: number,
  ) {}
}

export class OrderItemAddedEvent {
  constructor(public readonly orderId: string, public readonly item: OrderItem) {}
}

export class OrderItemRemovedEvent {
  constructor(public readonly orderId: string, public readonly itemId: string) {}
}

export class PaymentReceivedEvent {
  constructor(public readonly orderId: string, public readonly paymentId: string, public readonly amount: number) {}
}

export class OrderShippedEvent {
  constructor(public readonly orderId: string, public readonly trackingNumber: string) {}
}

export class OrderCancelledEvent {
  constructor(public readonly orderId: string, public readonly reason: string) {}
}

// Aggregate
export class OrderAggregate extends AggregateRoot {
  private id: string;
  private userId: string;
  private items: Map<string, OrderItem> = new Map();
  private totalAmount: number = 0;
  private status: OrderStatus = OrderStatus.DRAFT;
  private paymentId?: string;
  private trackingNumber?: string;

  constructor(id: string) {
    super();
    this.id = id;
  }

  // Commands

  static create(orderId: string, userId: string, items: OrderItem[]): OrderAggregate {
    const order = new OrderAggregate(orderId);
    const totalAmount = items.reduce((sum, item) => sum + item.price * item.quantity, 0);

    order.apply(new OrderCreatedEvent(orderId, userId, items, totalAmount));
    return order;
  }

  addItem(item: OrderItem): void {
    if (this.status !== OrderStatus.DRAFT) {
      throw new Error('Cannot add items to a non-draft order');
    }

    this.apply(new OrderItemAddedEvent(this.id, item));
  }

  removeItem(itemId: string): void {
    if (this.status !== OrderStatus.DRAFT) {
      throw new Error('Cannot remove items from a non-draft order');
    }

    if (!this.items.has(itemId)) {
      throw new Error('Item not found in order');
    }

    this.apply(new OrderItemRemovedEvent(this.id, itemId));
  }

  receivePayment(paymentId: string, amount: number): void {
    if (this.status !== OrderStatus.PENDING_PAYMENT) {
      throw new Error('Order is not awaiting payment');
    }

    if (amount < this.totalAmount) {
      throw new Error('Payment amount is insufficient');
    }

    this.apply(new PaymentReceivedEvent(this.id, paymentId, amount));
  }

  ship(trackingNumber: string): void {
    if (this.status !== OrderStatus.PAID) {
      throw new Error('Order must be paid before shipping');
    }

    this.apply(new OrderShippedEvent(this.id, trackingNumber));
  }

  cancel(reason: string): void {
    if (this.status === OrderStatus.SHIPPED || this.status === OrderStatus.DELIVERED) {
      throw new Error('Cannot cancel a shipped or delivered order');
    }

    this.apply(new OrderCancelledEvent(this.id, reason));
  }

  // Event Handlers (State Mutations)

  protected applyEvent(event: any): void {
    if (event instanceof OrderCreatedEvent) {
      this.onOrderCreated(event);
    } else if (event instanceof OrderItemAddedEvent) {
      this.onOrderItemAdded(event);
    } else if (event instanceof OrderItemRemovedEvent) {
      this.onOrderItemRemoved(event);
    } else if (event instanceof PaymentReceivedEvent) {
      this.onPaymentReceived(event);
    } else if (event instanceof OrderShippedEvent) {
      this.onOrderShipped(event);
    } else if (event instanceof OrderCancelledEvent) {
      this.onOrderCancelled(event);
    }
  }

  private onOrderCreated(event: OrderCreatedEvent): void {
    this.id = event.orderId;
    this.userId = event.userId;
    event.items.forEach((item) => this.items.set(item.id, item));
    this.totalAmount = event.totalAmount;
    this.status = OrderStatus.DRAFT;
  }

  private onOrderItemAdded(event: OrderItemAddedEvent): void {
    this.items.set(event.item.id, event.item);
    this.totalAmount += event.item.price * event.item.quantity;
  }

  private onOrderItemRemoved(event: OrderItemRemovedEvent): void {
    const item = this.items.get(event.itemId);
    if (item) {
      this.totalAmount -= item.price * item.quantity;
      this.items.delete(event.itemId);
    }
  }

  private onPaymentReceived(event: PaymentReceivedEvent): void {
    this.paymentId = event.paymentId;
    this.status = OrderStatus.PAID;
  }

  private onOrderShipped(event: OrderShippedEvent): void {
    this.trackingNumber = event.trackingNumber;
    this.status = OrderStatus.SHIPPED;
  }

  private onOrderCancelled(event: OrderCancelledEvent): void {
    this.status = OrderStatus.CANCELLED;
  }

  // Getters

  getId(): string {
    return this.id;
  }

  getStatus(): OrderStatus {
    return this.status;
  }

  getTotalAmount(): number {
    return this.totalAmount;
  }

  getItems(): OrderItem[] {
    return Array.from(this.items.values());
  }
}

enum OrderStatus {
  DRAFT = 'DRAFT',
  PENDING_PAYMENT = 'PENDING_PAYMENT',
  PAID = 'PAID',
  SHIPPED = 'SHIPPED',
  DELIVERED = 'DELIVERED',
  CANCELLED = 'CANCELLED',
}

interface OrderItem {
  id: string;
  productId: string;
  name: string;
  price: number;
  quantity: number;
}

Outbox Processor​

// shared/outbox/src/outbox-processor.service.ts
import { Injectable, Logger, OnModuleInit, OnModuleDestroy } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository, LessThan } from 'typeorm';
import { Cron, CronExpression } from '@nestjs/schedule';
import { OutboxEvent, OutboxEventStatus } from './entities/outbox-event.entity';
import { KafkaService } from '@ecommerce/kafka';

@Injectable()
export class OutboxProcessorService implements OnModuleInit, OnModuleDestroy {
  private readonly logger = new Logger(OutboxProcessorService.name);
  private isProcessing = false;
  private processingInterval: NodeJS.Timer;

  constructor(
    @InjectRepository(OutboxEvent)
    private outboxRepository: Repository<OutboxEvent>,
    private kafkaService: KafkaService,
  ) {}

  async onModuleInit() {
    // Start immediate processing
    this.processOutbox();

    // Set up periodic processing
    this.processingInterval = setInterval(() => {
      if (!this.isProcessing) {
        this.processOutbox();
      }
    }, 5000); // Process every 5 seconds
  }

  onModuleDestroy() {
    if (this.processingInterval) {
      clearInterval(this.processingInterval);
    }
  }

  /**
   * Process pending outbox events
   */
  @Cron(CronExpression.EVERY_10_SECONDS)
  async processOutbox(): Promise<void> {
    if (this.isProcessing) {
      return;
    }

    this.isProcessing = true;

    try {
      const batchSize = 100;
      const events = await this.outboxRepository.find({
        where: { status: OutboxEventStatus.PENDING },
        order: { createdAt: 'ASC' },
        take: batchSize,
      });

      if (events.length === 0) {
        return;
      }

      this.logger.debug(`Processing ${events.length} outbox events`);

      for (const event of events) {
        await this.processEvent(event);
      }

      // Retry failed events
      await this.retryFailedEvents();
    } catch (error) {
      this.logger.error('Error processing outbox', error.stack);
    } finally {
      this.isProcessing = false;
    }
  }

  private async processEvent(event: OutboxEvent): Promise<void> {
    try {
      // Publish to Kafka
      await this.kafkaService.publish(event.eventType, {
        aggregateId: event.aggregateId,
        aggregateType: event.aggregateType,
        eventType: event.eventType,
        eventData: event.eventData,
        metadata: {
          ...event.metadata,
          version: event.version,
          publishedAt: new Date(),
        },
      });

      // Mark as published
      await this.outboxRepository.update(event.id, {
        status: OutboxEventStatus.PUBLISHED,
        publishedAt: new Date(),
      });

      this.logger.debug(`Published event: ${event.eventType} (${event.id})`);
    } catch (error) {
      this.logger.error(`Failed to publish event ${event.id}: ${error.message}`, error.stack);

      // Update retry count
      const retryCount = event.retryCount + 1;
      const status = retryCount >= event.maxRetries ? OutboxEventStatus.FAILED : OutboxEventStatus.PENDING;

      await this.outboxRepository.update(event.id, {
        retryCount,
        status,
        failedAt: status === OutboxEventStatus.FAILED ? new Date() : undefined,
        errorMessage: error.message,
      });
    }
  }

  private async retryFailedEvents(): Promise<void> {
    // Retry events that failed less than max retries
    const retryableEvents = await this.outboxRepository.find({
      where: {
        status: OutboxEventStatus.PENDING,
        retryCount: LessThan(3),
      },
      order: { createdAt: 'ASC' },
      take: 10,
    });

    for (const event of retryableEvents) {
      await this.processEvent(event);
    }
  }

  /**
   * Clean up old published events (optional)
   */
  @Cron(CronExpression.EVERY_DAY_AT_MIDNIGHT)
  async cleanupOldEvents(): Promise<void> {
    const retentionDays = 30;
    const cutoffDate = new Date();
    cutoffDate.setDate(cutoffDate.getDate() - retentionDays);

    const result = await this.outboxRepository
      .createQueryBuilder()
      .delete()
      .where('status = :status', { status: OutboxEventStatus.PUBLISHED })
      .andWhere('publishedAt < :cutoffDate', { cutoffDate })
      .execute();

    this.logger.log(`Cleaned up ${result.affected} old outbox events`);
  }
}

Repository with Event Publishing​

// services/order-service/src/repositories/order.repository.ts
import { Injectable, Logger } from '@nestjs/common';
import { EventStoreService, DomainEvent } from '@ecommerce/event-sourcing';
import { OrderAggregate } from '../aggregates/order.aggregate';

@Injectable()
export class OrderRepository {
  private readonly logger = new Logger(OrderRepository.name);

  constructor(private eventStore: EventStoreService) {}

  /**
   * Load aggregate from event store
   */
  async load(orderId: string): Promise<OrderAggregate> {
    const events = await this.eventStore.getEvents(orderId);

    if (events.length === 0) {
      throw new Error(`Order ${orderId} not found`);
    }

    const order = new OrderAggregate(orderId);
    order.loadFromHistory(events.map((e) => this.toDomainEvent(e)));

    return order;
  }

  /**
   * Save aggregate (append new events)
   */
  async save(order: OrderAggregate): Promise<void> {
    const uncommittedEvents = order.getUncommittedEvents();

    if (uncommittedEvents.length === 0) {
      return;
    }

    const domainEvents: DomainEvent[] = uncommittedEvents.map((event) => ({
      aggregateId: order.getId(),
      aggregateType: 'Order',
      eventType: event.constructor.name,
      eventData: this.serializeEvent(event),
      metadata: {
        // Add correlation metadata
        traceId: '...', // From correlation service
        userId: '...',
      },
    }));

    // Save events (both event store and outbox in transaction)
    await this.eventStore.appendEvents(domainEvents);

    // Mark events as committed
    order.markEventsAsCommitted();

    this.logger.log(`Saved ${uncommittedEvents.length} events for order ${order.getId()}`);
  }

  private toDomainEvent(eventStoreEvent: any): any {
    // Reconstruct domain event from stored event
    const EventClass = this.getEventClass(eventStoreEvent.eventType);
    return Object.assign(new EventClass(), eventStoreEvent.eventData);
  }

  private serializeEvent(event: any): any {
    // Convert domain event to plain object for storage
    const { constructor, ...data } = event;
    return data;
  }

  private getEventClass(eventType: string): any {
    // Map event type name to class
    const eventClasses = {
      OrderCreatedEvent: require('../aggregates/order.aggregate').OrderCreatedEvent,
      OrderItemAddedEvent: require('../aggregates/order.aggregate').OrderItemAddedEvent,
      // ... other events
    };

    return eventClasses[eventType];
  }
}

import { Injectable, Logger } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import { OnEvent } from '@nestjs/event-emitter';
import { OrderReadModel } from './entities/order-read-model.entity';

@Injectable()
export class OrderProjectionService {
  private readonly logger = new Logger(OrderProjectionService.name);

  constructor(
    @InjectRepository(OrderReadModel)
    private orderReadModelRepository: Repository<OrderReadModel>,
  ) {}

  @OnEvent('OrderCreatedEvent')
  async handleOrderCreated(event: any): Promise<void> {
    await this.orderReadModelRepository.save({
      id: event.orderId,
      userId: event.userId,
      items: event.items,
      totalAmount: event.totalAmount,
      status: 'DRAFT',
      createdAt: new Date(),
      updatedAt: new Date(),
    });

    this.logger.debug(`Projected OrderCreatedEvent: ${event.orderId}`);
  }

  @OnEvent('PaymentReceivedEvent')
  async handlePaymentReceived(event: any): Promise<void> {
    await this.orderReadModelRepository.update(event.orderId, {
      paymentId: event.paymentId,
      status: 'PAID',
      updatedAt: new Date(),
    });

    this.logger.debug(`Projected PaymentReceivedEvent: ${event.orderId}`);
  }

  @OnEvent('OrderShippedEvent')
  async handleOrderShipped(event: any): Promise<void> {
    await this.orderReadModelRepository.update(event.orderId, {
      trackingNumber: event.trackingNumber,
      status: 'SHIPPED',
      shippedAt: new Date(),
      updatedAt: new Date(),
    });

    this.logger.debug(`Projected OrderShippedEvent: ${event.orderId}`);
  }

  @OnEvent('OrderCancelledEvent')
  async handleOrderCancelled(event: any): Promise<void> {
    await this.orderReadModelRepository.update(event.orderId, {
      status: 'CANCELLED',
      cancelledAt: new Date(),
      cancellationReason: event.reason,
      updatedAt: new Date(),
    });

    this.logger.debug(`Projected OrderCancelledEvent: ${event.orderId}`);
  }

  /**
   * Rebuild projection from event store
   */
  async rebuildProjection(orderId: string): Promise<void> {
    this.logger.log(`Rebuilding projection for order ${orderId}`);

    // Delete existing read model
    await this.orderReadModelRepository.delete(orderId);

    // Replay events
    const aggregate = await this.orderRepository.load(orderId);

    // Project current state
    await this.orderReadModelRepository.save({
      id: aggregate.getId(),
      status: aggregate.getStatus(),
      totalAmount: aggregate.getTotalAmount(),
      items: aggregate.getItems(),
      // ... other fields
    });

    this.logger.log(`Rebuilt projection for order ${orderId}`);
  }

  /**
   * Rebuild all projections
   */
  async rebuildAllProjections(): Promise<void> {
    this.logger.log('Rebuilding all order projections');

    // Clear all read models
    await this.orderReadModelRepository.clear();

    // Stream all events and replay
    for await (const eventBatch of this.eventStore.streamEvents('Order')) {
      for (const event of eventBatch) {
        // Process each event
        const eventHandler = this[`handle${event.eventType}`];
        if (eventHandler) {
          await eventHandler.call(this, event.eventData);
        }
      }
    }

    this.logger.log('Finished rebuilding all order projections');
  }
}

Snapshot Service​

// shared/event-sourcing/src/snapshot.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import { Snapshot } from './entities/snapshot.entity';
import { EventStoreService } from './event-store.service';

@Injectable()
export class SnapshotService {
  private readonly logger = new Logger(SnapshotService.name);
  private readonly snapshotInterval = 10; // Take snapshot every 10 events

  constructor(
    @InjectRepository(Snapshot)
    private snapshotRepository: Repository<Snapshot>,
    private eventStore: EventStoreService,
  ) {}

  async saveSnapshot(aggregateId: string, aggregateType: string, state: any, version: number): Promise<void> {
    await this.snapshotRepository.save({
      aggregateId,
      aggregateType,
      state,
      version,
    });

    this.logger.debug(`Snapshot saved for ${aggregateType}:${aggregateId} at version ${version}`);
  }

  async getSnapshot(aggregateId: string): Promise<Snapshot | null> {
    return this.snapshotRepository.findOne({
      where: { aggregateId },
      order: { version: 'DESC' },
    });
  }

  async shouldTakeSnapshot(version: number): boolean {
    return version % this.snapshotInterval === 0;
  }

  /**
   * Load aggregate with snapshot optimization
   */
  async loadAggregateWithSnapshot<T>(
    aggregateId: string,
    aggregateFactory: (state?: any) => T,
    applyEvents: (aggregate: T, events: any[]) => void,
  ): Promise<T> {
    // Try to load from snapshot
    const snapshot = await this.getSnapshot(aggregateId);

    let aggregate: T;
    let startVersion = 0;

    if (snapshot) {
      // Restore from snapshot
      aggregate = aggregateFactory(snapshot.state);
      startVersion = snapshot.version;
      this.logger.debug(`Loaded snapshot at version ${startVersion} for ${aggregateId}`);
    } else {
      // No snapshot, create new
      aggregate = aggregateFactory();
    }

    // Load events since snapshot
    const events = await this.eventStore.getEventsSince(aggregateId, startVersion);

    if (events.length > 0) {
      applyEvents(aggregate, events);
      this.logger.debug(`Applied ${events.length} events since snapshot for ${aggregateId}`);
    }

    return aggregate;
  }
}

Command Handler​

// services/order-service/src/commands/create-order.handler.ts
import { CommandHandler, ICommandHandler, EventPublisher } from '@nestjs/cqrs';
import { OrderRepository } from '../repositories/order.repository';
import { OrderAggregate } from '../aggregates/order.aggregate';

export class CreateOrderCommand {
  constructor(public readonly orderId: string, public readonly userId: string, public readonly items: OrderItem[]) {}
}

@CommandHandler(CreateOrderCommand)
export class CreateOrderHandler implements ICommandHandler<CreateOrderCommand> {
  constructor(private orderRepository: OrderRepository, private publisher: EventPublisher) {}

  async execute(command: CreateOrderCommand): Promise<void> {
    // Create aggregate
    const order = OrderAggregate.create(command.orderId, command.userId, command.items);

    // Merge with event publisher for auto-publishing
    const orderWithPublisher = this.publisher.mergeObjectContext(order);

    // Save (appends events to event store and outbox)
    await this.orderRepository.save(order);

    // Commit (publishes events to event bus)
    orderWithPublisher.commit();
  }
}

Best Practices​

1. Event Design​

✅ Do:

  • Name events in past tense (OrderCreated, not CreateOrder)
  • Make events immutable
  • Include all necessary data in events
  • Use semantic versioning for event schemas
  • Keep events small and focused

❌ Don't:

  • Change published event structures
  • Include sensitive data without encryption
  • Create overly generic events
  • Forget correlation metadata
  • Mix commands and events

2. Aggregate Design​

✅ Do:

  • Keep aggregates focused and small
  • Enforce business rules in aggregates
  • Use value objects for complex data
  • Make state changes only through events
  • Implement proper validation

❌ Don't:

  • Create god aggregates
  • Access other aggregates directly
  • Perform I/O in aggregates
  • Skip event versioning
  • Expose mutable state

3. Event Store​

✅ Do:

  • Use optimistic locking (version numbers)
  • Index by aggregate ID
  • Partition by aggregate type
  • Implement snapshots for long-lived aggregates
  • Monitor event store performance

❌ Don't:

  • Delete events
  • Modify published events
  • Skip version checks
  • Ignore concurrency conflicts
  • Forget about storage growth

4. Outbox Pattern​

✅ Do:

  • Process outbox in background
  • Implement retry logic
  • Monitor outbox lag
  • Clean up old published events
  • Use database transactions

❌ Don't:

  • Publish events directly from business logic
  • Skip error handling
  • Let outbox table grow indefinitely
  • Forget idempotency
  • Ignore failed events

5. Projections​

✅ Do:

  • Build projections asynchronously
  • Support projection rebuilds
  • Version projection schemas
  • Use separate databases for reads
  • Monitor projection lag

❌ Don't:

  • Query event store directly for reads
  • Couple projections to event store schema
  • Skip error handling
  • Forget about eventual consistency
  • Build real-time projections without caching

Summary​

Event Sourcing and Outbox pattern provide:

  • Complete Audit Trail - Every state change is recorded
  • Reliable Event Publishing - No dual-write problems
  • Temporal Queries - Reconstruct state at any point
  • Event Replay - Rebuild projections from events
  • Scalability - Separate read and write models
  • Debugging - Full history for troubleshooting

Key implementation points:

  • Store all state changes as immutable events
  • Use outbox pattern for reliable publishing
  • Implement CQRS for read/write separation
  • Use snapshots for performance optimization
  • Monitor outbox processing lag
  • Support projection rebuilds

Remember: Event Sourcing adds complexity but provides powerful capabilities for audit, compliance, and debugging!
