Data Consistency and Saga Pattern Guide

Overview​

Maintaining data consistency across distributed microservices is one of the most challenging aspects of microservices architecture. This guide covers distributed transaction management using the Saga pattern, eventual consistency strategies, and implementing reliable data workflows across service boundaries.

Data Consistency Challenges​

The Distributed Transaction Problem​

CAP Theorem Trade-offs​

/**
 * CAP Theorem in Microservices:
 * - Consistency: All nodes see the same data at the same time
 * - Availability: Every request receives a response
 * - Partition Tolerance: System continues despite network partitions
 *
 * In distributed systems, you can only guarantee 2 out of 3
 */

// E-commerce Example: Order Processing
interface OrderProcessing {
  // CP (Consistency + Partition Tolerance)
  // Choose when: Financial transactions, inventory updates
  // Trade-off: May sacrifice availability during network issues
  strictConsistency: {
    approach: 'Two-Phase Commit (2PC)';
    impact: 'Blocking operations, lower availability';
  };

  // AP (Availability + Partition Tolerance)
  // Choose when: Social features, analytics, recommendations
  // Trade-off: Eventual consistency, temporary inconsistencies
  eventualConsistency: {
    approach: 'Saga Pattern, Event Sourcing';
    impact: 'Higher availability, complex error handling';
  };
}

Saga Pattern Fundamentals​

What is a Saga?​

A Saga is a sequence of local transactions where each transaction updates data within a single service. If a step fails, the saga executes compensating transactions to undo the changes made by preceding steps.

// services/order-service/src/sagas/order-saga.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { OnEvent } from '@nestjs/event-emitter';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import { KafkaService } from '@ecommerce/kafka';
import { Order, OrderStatus } from '../entities/order.entity';
import {
  OrderEventType,
  OrderCreatedEvent,
  InventoryReservedEvent,
  PaymentProcessedEvent,
  ShipmentCreatedEvent,
} from '@ecommerce/events';

@Injectable()
export class OrderSagaService {
  private readonly logger = new Logger(OrderSagaService.name);

  constructor(
    @InjectRepository(Order)
    private orderRepository: Repository<Order>,
    private kafkaService: KafkaService,
  ) {}

  // Step 1: Handle new order creation
  async createOrder(createOrderDto: CreateOrderDto): Promise<Order> {
    this.logger.log(`Creating order for user ${createOrderDto.userId}`);

    // Create order in pending state
    const order = await this.orderRepository.save({
      userId: createOrderDto.userId,
      items: createOrderDto.items,
      totalAmount: createOrderDto.totalAmount,
      status: OrderStatus.PENDING,
      sagaState: 'ORDER_CREATED',
    });

    // Publish OrderCreated event to start the saga
    const event: OrderCreatedEvent = {
      orderId: order.id,
      userId: order.userId,
      items: order.items,
      totalAmount: order.totalAmount,
      timestamp: new Date(),
    };

    await this.kafkaService.publish(OrderEventType.ORDER_CREATED, event);

    this.logger.log(`Order ${order.id} created, saga initiated`);
    return order;
  }

  // Step 2: Handle inventory reservation success
  @OnEvent(OrderEventType.INVENTORY_RESERVED)
  async handleInventoryReserved(event: InventoryReservedEvent): Promise<void> {
    this.logger.log(`Inventory reserved for order ${event.orderId}`);

    await this.orderRepository.update(event.orderId, {
      sagaState: 'INVENTORY_RESERVED',
      reservationId: event.reservationId,
    });

    // Saga continues automatically when Payment Service receives the event
  }

  // Step 3: Handle inventory reservation failure (compensation)
  @OnEvent(OrderEventType.INVENTORY_RESERVATION_FAILED)
  async handleInventoryReservationFailed(event: any): Promise<void> {
    this.logger.error(`Inventory reservation failed for order ${event.orderId}`);

    await this.orderRepository.update(event.orderId, {
      status: OrderStatus.CANCELLED,
      sagaState: 'FAILED_INVENTORY',
      failureReason: event.reason,
    });

    // Publish cancellation event
    await this.kafkaService.publish(OrderEventType.ORDER_CANCELLED, {
      orderId: event.orderId,
      reason: 'Insufficient inventory',
      timestamp: new Date(),
    });
  }

  // Step 4: Handle payment success
  @OnEvent(OrderEventType.PAYMENT_PROCESSED)
  async handlePaymentProcessed(event: PaymentProcessedEvent): Promise<void> {
    this.logger.log(`Payment processed for order ${event.orderId}`);

    await this.orderRepository.update(event.orderId, {
      sagaState: 'PAYMENT_PROCESSED',
      paymentId: event.paymentId,
    });
  }

  // Step 5: Handle payment failure (compensation)
  @OnEvent(OrderEventType.PAYMENT_FAILED)
  async handlePaymentFailed(event: any): Promise<void> {
    this.logger.error(`Payment failed for order ${event.orderId}`);

    const order = await this.orderRepository.findOne({
      where: { id: event.orderId },
    });

    // Trigger compensation: Release inventory
    if (order.reservationId) {
      await this.kafkaService.publish('inventory.release', {
        reservationId: order.reservationId,
        orderId: event.orderId,
        timestamp: new Date(),
      });
    }

    await this.orderRepository.update(event.orderId, {
      status: OrderStatus.CANCELLED,
      sagaState: 'FAILED_PAYMENT',
      failureReason: event.reason,
    });

    await this.kafkaService.publish(OrderEventType.ORDER_CANCELLED, {
      orderId: event.orderId,
      reason: 'Payment failed',
      timestamp: new Date(),
    });
  }

  // Step 6: Handle shipment creation success
  @OnEvent(OrderEventType.SHIPMENT_CREATED)
  async handleShipmentCreated(event: ShipmentCreatedEvent): Promise<void> {
    this.logger.log(`Shipment created for order ${event.orderId}`);

    await this.orderRepository.update(event.orderId, {
      status: OrderStatus.CONFIRMED,
      sagaState: 'COMPLETED',
      shipmentId: event.shipmentId,
    });

    // Saga completed successfully
    await this.kafkaService.publish(OrderEventType.ORDER_COMPLETED, {
      orderId: event.orderId,
      timestamp: new Date(),
    });

    this.logger.log(`Order ${event.orderId} saga completed successfully`);
  }

  // Step 7: Handle shipment failure (compensation)
  @OnEvent(OrderEventType.SHIPMENT_FAILED)
  async handleShipmentFailed(event: any): Promise<void> {
    this.logger.error(`Shipment failed for order ${event.orderId}`);

    const order = await this.orderRepository.findOne({
      where: { id: event.orderId },
    });

    // Trigger compensations in reverse order
    // 1. Refund payment
    if (order.paymentId) {
      await this.kafkaService.publish('payment.refund', {
        paymentId: order.paymentId,
        orderId: event.orderId,
        amount: order.totalAmount,
        timestamp: new Date(),
      });
    }

    // 2. Release inventory
    if (order.reservationId) {
      await this.kafkaService.publish('inventory.release', {
        reservationId: order.reservationId,
        orderId: event.orderId,
        timestamp: new Date(),
      });
    }

    await this.orderRepository.update(event.orderId, {
      status: OrderStatus.CANCELLED,
      sagaState: 'FAILED_SHIPMENT',
      failureReason: event.reason,
    });

    await this.kafkaService.publish(OrderEventType.ORDER_CANCELLED, {
      orderId: event.orderId,
      reason: 'Shipment creation failed',
      timestamp: new Date(),
    });
  }
}
// services/inventory-service/src/sagas/inventory-saga.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { OnEvent } from '@nestjs/event-emitter';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import { KafkaService } from '@ecommerce/kafka';
import { InventoryReservation } from '../entities/inventory-reservation.entity';
import { Product } from '../entities/product.entity';
import { OrderCreatedEvent, OrderEventType } from '@ecommerce/events';

@Injectable()
export class InventorySagaService {
  private readonly logger = new Logger(InventorySagaService.name);

  constructor(
    @InjectRepository(InventoryReservation)
    private reservationRepository: Repository<InventoryReservation>,
    @InjectRepository(Product)
    private productRepository: Repository<Product>,
    private kafkaService: KafkaService,
  ) {}

  @OnEvent(OrderEventType.ORDER_CREATED)
  async handleOrderCreated(event: OrderCreatedEvent): Promise<void> {
    this.logger.log(`Handling order created: ${event.orderId}`);

    try {
      // Check inventory availability
      for (const item of event.items) {
        const product = await this.productRepository.findOne({
          where: { id: item.productId },
        });

        if (!product || product.availableQuantity < item.quantity) {
          throw new Error(`Insufficient inventory for product ${item.productId}`);
        }
      }

      // Reserve inventory
      const reservation = await this.reservationRepository.save({
        orderId: event.orderId,
        items: event.items,
        status: 'RESERVED',
        expiresAt: new Date(Date.now() + 15 * 60 * 1000), // 15 minutes
      });

      // Update product quantities
      for (const item of event.items) {
        await this.productRepository.decrement({ id: item.productId }, 'availableQuantity', item.quantity);
      }

      // Publish success event
      await this.kafkaService.publish(OrderEventType.INVENTORY_RESERVED, {
        orderId: event.orderId,
        reservationId: reservation.id,
        items: event.items,
        timestamp: new Date(),
      });

      this.logger.log(`Inventory reserved for order ${event.orderId}`);
    } catch (error) {
      this.logger.error(`Failed to reserve inventory: ${error.message}`);

      // Publish failure event
      await this.kafkaService.publish(OrderEventType.INVENTORY_RESERVATION_FAILED, {
        orderId: event.orderId,
        reason: error.message,
        timestamp: new Date(),
      });
    }
  }

  // Compensation: Release inventory
  @OnEvent('inventory.release')
  async handleInventoryRelease(event: any): Promise<void> {
    this.logger.log(`Releasing inventory for order ${event.orderId}`);

    const reservation = await this.reservationRepository.findOne({
      where: { id: event.reservationId },
    });

    if (reservation && reservation.status === 'RESERVED') {
      // Restore product quantities
      for (const item of reservation.items) {
        await this.productRepository.increment({ id: item.productId }, 'availableQuantity', item.quantity);
      }

      await this.reservationRepository.update(reservation.id, {
        status: 'RELEASED',
      });

      this.logger.log(`Inventory released for order ${event.orderId}`);
    }
  }
}

// services/order-service/src/workflows/order-saga.workflow.ts
import { proxyActivities, sleep } from '@temporalio/workflow';
import type * as activities from '../activities';

const { createOrder, reserveInventory, processPayment, createShipment, releaseInventory, refundPayment, cancelOrder } =
  proxyActivities<typeof activities>({
    startToCloseTimeout: '5 minutes',
    retry: {
      initialInterval: '1s',
      backoffCoefficient: 2,
      maximumAttempts: 3,
    },
  });

export interface OrderSagaInput {
  userId: string;
  items: Array<{
    productId: string;
    quantity: number;
    price: number;
  }>;
  totalAmount: number;
  paymentMethod: string;
}

export interface OrderSagaResult {
  orderId: string;
  status: 'completed' | 'failed';
  failureReason?: string;
}

export async function orderSagaWorkflow(input: OrderSagaInput): Promise<OrderSagaResult> {
  let orderId: string;
  let reservationId: string;
  let paymentId: string;

  try {
    // Step 1: Create Order
    const orderResult = await createOrder({
      userId: input.userId,
      items: input.items,
      totalAmount: input.totalAmount,
    });
    orderId = orderResult.orderId;

    // Step 2: Reserve Inventory
    const inventoryResult = await reserveInventory({
      orderId,
      items: input.items,
    });
    reservationId = inventoryResult.reservationId;

    // Step 3: Process Payment
    const paymentResult = await processPayment({
      orderId,
      userId: input.userId,
      amount: input.totalAmount,
      paymentMethod: input.paymentMethod,
    });
    paymentId = paymentResult.paymentId;

    // Step 4: Create Shipment
    await createShipment({
      orderId,
      userId: input.userId,
      items: input.items,
    });

    return {
      orderId,
      status: 'completed',
    };
  } catch (error) {
    // Compensation logic (executed in reverse order)
    console.error('Saga failed, executing compensations:', error);

    // Compensate Shipment (if it was created)
    // Shipping service handles this internally

    // Compensate Payment
    if (paymentId) {
      try {
        await refundPayment({ paymentId, orderId });
      } catch (refundError) {
        console.error('Refund failed:', refundError);
        // Log for manual intervention
      }
    }

    // Compensate Inventory
    if (reservationId) {
      try {
        await releaseInventory({ reservationId, orderId });
      } catch (releaseError) {
        console.error('Inventory release failed:', releaseError);
      }
    }

    // Compensate Order
    if (orderId) {
      try {
        await cancelOrder({ orderId, reason: error.message });
      } catch (cancelError) {
        console.error('Order cancellation failed:', cancelError);
      }
    }

    return {
      orderId,
      status: 'failed',
      failureReason: error.message,
    };
  }
}

import { Injectable } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import { HttpService } from '@nestjs/axios';
import { Order, OrderStatus } from '../entities/order.entity';

@Injectable()
export class OrderActivities {
  constructor(
    @InjectRepository(Order)
    private orderRepository: Repository<Order>,
    private httpService: HttpService,
  ) {}

  async createOrder(input: { userId: string; items: any[]; totalAmount: number }): Promise<{ orderId: string }> {
    const order = await this.orderRepository.save({
      userId: input.userId,
      items: input.items,
      totalAmount: input.totalAmount,
      status: OrderStatus.PENDING,
    });

    return { orderId: order.id };
  }

  async reserveInventory(input: { orderId: string; items: any[] }): Promise<{ reservationId: string }> {
    const response = await this.httpService
      .post('http://inventory-service/reservations', {
        orderId: input.orderId,
        items: input.items,
      })
      .toPromise();

    if (response.status !== 200) {
      throw new Error('Failed to reserve inventory');
    }

    return { reservationId: response.data.reservationId };
  }

  async processPayment(input: {
    orderId: string;
    userId: string;
    amount: number;
    paymentMethod: string;
  }): Promise<{ paymentId: string }> {
    const response = await this.httpService
      .post('http://payment-service/payments', {
        orderId: input.orderId,
        userId: input.userId,
        amount: input.amount,
        paymentMethod: input.paymentMethod,
      })
      .toPromise();

    if (response.status !== 200) {
      throw new Error('Payment processing failed');
    }

    return { paymentId: response.data.paymentId };
  }

  async createShipment(input: { orderId: string; userId: string; items: any[] }): Promise<{ shipmentId: string }> {
    const response = await this.httpService
      .post('http://shipping-service/shipments', {
        orderId: input.orderId,
        userId: input.userId,
        items: input.items,
      })
      .toPromise();

    if (response.status !== 200) {
      throw new Error('Shipment creation failed');
    }

    return { shipmentId: response.data.shipmentId };
  }

  // Compensation Activities

  async releaseInventory(input: { reservationId: string; orderId: string }): Promise<void> {
    await this.httpService.delete(`http://inventory-service/reservations/${input.reservationId}`).toPromise();
  }

  async refundPayment(input: { paymentId: string; orderId: string }): Promise<void> {
    await this.httpService
      .post(`http://payment-service/payments/${input.paymentId}/refund`, {
        orderId: input.orderId,
      })
      .toPromise();
  }

  async cancelOrder(input: { orderId: string; reason: string }): Promise<void> {
    await this.orderRepository.update(input.orderId, {
      status: OrderStatus.CANCELLED,
      failureReason: input.reason,
    });
  }
}

      address: process.env.TEMPORAL_ADDRESS || 'localhost:7233',

    this.client = new Client({

      namespace: 'ecommerce',

    this.logger.log('Temporal client initialized');

  private async initializeWorker() {
    this.worker = await Worker.create({
      connection: await Connection.connect({
        address: process.env.TEMPORAL_ADDRESS || 'localhost:7233',
      }),
      namespace: 'ecommerce',
      taskQueue: 'order-saga',
      workflowsPath: require.resolve('../workflows'),
      activities: new OrderActivities(),
      // Inject dependencies
    });

    await this.worker.run();
    this.logger.log('Temporal worker started');
  }

    const handle = await this.client.workflow.start(orderSagaWorkflow, {
      taskQueue: 'order-saga',

      args: [input],
    });

    this.logger.log(`Started order saga workflow: ${handle.workflowId}`);
    return handle.workflowId;
  }

  async getWorkflowResult(workflowId: string): Promise<any> {
    const handle = this.client.workflow.getHandle(workflowId);
    return await handle.result();
  }
}

Compensation Patterns​

// shared/saga/src/compensation-manager.ts
import { Injectable, Logger } from '@nestjs/common';

export interface CompensationAction {
  actionName: string;
  execute: () => Promise<void>;
  retries?: number;
  timeout?: number;
}

@Injectable()
export class CompensationManager {
  private readonly logger = new Logger(CompensationManager.name);
  private compensationStack: CompensationAction[] = [];

  // Register a compensation action
  registerCompensation(action: CompensationAction): void {
    this.compensationStack.push(action);
    this.logger.debug(`Registered compensation: ${action.actionName}`);
  }

  // Execute all compensations in reverse order (LIFO)
  async executeCompensations(): Promise<void> {
    this.logger.log(`Executing ${this.compensationStack.length} compensations`);

    const errors: Array<{ action: string; error: Error }> = [];

    // Execute in reverse order
    while (this.compensationStack.length > 0) {
      const action = this.compensationStack.pop();

      try {
        this.logger.log(`Executing compensation: ${action.actionName}`);
        await this.executeWithRetry(action);
        this.logger.log(`Compensation completed: ${action.actionName}`);
      } catch (error) {
        this.logger.error(`Compensation failed: ${action.actionName}`, error.stack);
        errors.push({ action: action.actionName, error });
      }
    }

    if (errors.length > 0) {
      this.logger.error('Some compensations failed:', errors);
      // Alert operations team for manual intervention
      throw new Error(`Compensations failed: ${errors.map((e) => e.action).join(', ')}`);
    }
  }

  private async executeWithRetry(action: CompensationAction): Promise<void> {
    const maxRetries = action.retries || 3;
    let lastError: Error;

    for (let attempt = 1; attempt <= maxRetries; attempt++) {
      try {
        const timeoutPromise = new Promise((_, reject) =>
          setTimeout(() => reject(new Error('Compensation timeout')), action.timeout || 30000),
        );

        await Promise.race([action.execute(), timeoutPromise]);
        return; // Success
      } catch (error) {
        lastError = error;
        this.logger.warn(`Compensation attempt ${attempt}/${maxRetries} failed: ${action.actionName}`);

        if (attempt < maxRetries) {
          await this.delay(Math.pow(2, attempt) * 1000); // Exponential backoff
        }
      }
    }

    throw lastError;
  }

  private delay(ms: number): Promise<void> {
    return new Promise((resolve) => setTimeout(resolve, ms));
  }

  clear(): void {
    this.compensationStack = [];
  }
}

// services/order-service/src/sagas/order-saga-with-compensation.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { CompensationManager } from '@ecommerce/saga';

@Injectable()
export class OrderSagaWithCompensation {
  private readonly logger = new Logger(OrderSagaWithCompensation.name);

  constructor(
    private compensationManager: CompensationManager,
    private inventoryService: InventoryService,
    private paymentService: PaymentService,
    private shippingService: ShippingService,
  ) {}

  async executeOrderSaga(orderData: CreateOrderDto): Promise<Order> {
    this.compensationManager.clear();

    try {
      // Step 1: Create Order
      const order = await this.createOrder(orderData);
      this.compensationManager.registerCompensation({
        actionName: 'Cancel Order',
        execute: async () => {
          await this.cancelOrder(order.id);
        },
      });

      // Step 2: Reserve Inventory
      const reservation = await this.inventoryService.reserve(order.items);
      this.compensationManager.registerCompensation({
        actionName: 'Release Inventory',
        execute: async () => {
          await this.inventoryService.release(reservation.id);
        },
      });

      // Step 3: Process Payment
      const payment = await this.paymentService.process({
        orderId: order.id,
        amount: order.totalAmount,
      });

      throw error;

// shared/event-sourcing/src/event-store.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import { EventStoreEvent } from './entities/event-store-event.entity';

export interface DomainEvent {
  aggregateId: string;
  aggregateType: string;
  eventType: string;
  eventData: any;
  metadata?: any;
}

@Injectable()
export class EventStoreService {
  private readonly logger = new Logger(EventStoreService.name);

  constructor(
    @InjectRepository(EventStoreEvent)
    private eventRepository: Repository<EventStoreEvent>,
  ) {}

  async append(event: DomainEvent): Promise<void> {
    const storedEvent = await this.eventRepository.save({
      aggregateId: event.aggregateId,
      aggregateType: event.aggregateType,
      eventType: event.eventType,
      eventData: event.eventData,
      metadata: event.metadata,
      version: await this.getNextVersion(event.aggregateId),
      timestamp: new Date(),
    });

    this.logger.debug(`Event stored: ${event.eventType} for ${event.aggregateType}:${event.aggregateId}`);
  }

  async getEvents(aggregateId: string): Promise<EventStoreEvent[]> {
    return this.eventRepository.find({
      where: { aggregateId },
      order: { version: 'ASC' },
    });
  }

  async getEventsSince(aggregateId: string, version: number): Promise<EventStoreEvent[]> {
    return this.eventRepository.find({
      where: { aggregateId },
      order: { version: 'ASC' },
    });
  }

  private async getNextVersion(aggregateId: string): Promise<number> {
    const lastEvent = await this.eventRepository.findOne({
      where: { aggregateId },
      order: { version: 'DESC' },
    });

    return lastEvent ? lastEvent.version + 1 : 1;
  }
}

import { AggregateRoot } from '@nestjs/cqrs';

export class OrderCreatedEvent {
  constructor(
    public readonly orderId: string,
    public readonly userId: string,
    public readonly items: any[],
    public readonly totalAmount: number,
  ) {}
}

export class InventoryReservedEvent {
  constructor(public readonly orderId: string, public readonly reservationId: string) {}
}

export class PaymentProcessedEvent {
  constructor(public readonly orderId: string, public readonly paymentId: string) {}
}

export class OrderCompletedEvent {
  constructor(public readonly orderId: string) {}
}

export class OrderCancelledEvent {
  constructor(public readonly orderId: string, public readonly reason: string) {}
}

export class OrderAggregate extends AggregateRoot {
  private id: string;
  private userId: string;
  private items: any[];
  private totalAmount: number;
  private status: string;
  private reservationId?: string;
  private paymentId?: string;

  constructor(id?: string) {
    super();
    this.id = id;
  }

  // Command: Create Order
  createOrder(userId: string, items: any[], totalAmount: number): void {
    this.apply(new OrderCreatedEvent(this.id, userId, items, totalAmount));
  }

  // Command: Reserve Inventory
  reserveInventory(reservationId: string): void {
    this.apply(new InventoryReservedEvent(this.id, reservationId));
  }

  // Command: Process Payment
  processPayment(paymentId: string): void {
    this.apply(new PaymentProcessedEvent(this.id, paymentId));
  }

  // Command: Complete Order
  completeOrder(): void {
    if (this.status === 'PAYMENT_PROCESSED') {
      this.apply(new OrderCompletedEvent(this.id));
    }
  }

  // Command: Cancel Order
  cancelOrder(reason: string): void {
    this.apply(new OrderCancelledEvent(this.id, reason));
  }

  // Event Handlers (State Mutations)

  onOrderCreatedEvent(event: OrderCreatedEvent): void {
    this.id = event.orderId;
    this.userId = event.userId;
    this.items = event.items;
    this.totalAmount = event.totalAmount;
    this.status = 'CREATED';
  }

  onInventoryReservedEvent(event: InventoryReservedEvent): void {
    this.reservationId = event.reservationId;
    this.status = 'INVENTORY_RESERVED';
  }

  onPaymentProcessedEvent(event: PaymentProcessedEvent): void {
    this.paymentId = event.paymentId;
    this.status = 'PAYMENT_PROCESSED';
  }

  onOrderCompletedEvent(event: OrderCompletedEvent): void {
    this.status = 'COMPLETED';
  }

  onOrderCancelledEvent(event: OrderCancelledEvent): void {
    this.status = 'CANCELLED';
  }

  // Getters
  getId(): string {
    return this.id;
  }

  getStatus(): string {
    return this.status;
  }
}

Saga State Tracking​

// shared/saga/src/saga-state-tracker.ts
import { Injectable, Logger } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import { SagaExecution } from './entities/saga-execution.entity';

export enum SagaStatus {
  STARTED = 'STARTED',
  IN_PROGRESS = 'IN_PROGRESS',
  COMPLETED = 'COMPLETED',
  COMPENSATING = 'COMPENSATING',
  COMPENSATION_COMPLETED = 'COMPENSATION_COMPLETED',
  FAILED = 'FAILED',
}

@Injectable()
export class SagaStateTracker {
  private readonly logger = new Logger(SagaStateTracker.name);

  constructor(
    @InjectRepository(SagaExecution)
    private sagaRepository: Repository<SagaExecution>,
  ) {}

  async startSaga(sagaId: string, sagaType: string, input: any): Promise<void> {
    await this.sagaRepository.save({
      sagaId,
      sagaType,
      status: SagaStatus.STARTED,
      input,
      steps: [],
      startedAt: new Date(),
    });

    this.logger.log(`Saga started: ${sagaType}:${sagaId}`);
  }

  async recordStep(sagaId: string, stepName: string, status: 'success' | 'failed', data?: any): Promise<void> {
    const saga = await this.sagaRepository.findOne({ where: { sagaId } });

    if (saga) {
      saga.steps.push({
        name: stepName,
        status,
        data,
        timestamp: new Date(),
      });

      saga.currentStep = stepName;
      saga.status = status === 'failed' ? SagaStatus.COMPENSATING : SagaStatus.IN_PROGRESS;

      await this.sagaRepository.save(saga);

      this.logger.debug(`Saga ${sagaId} step recorded: ${stepName} - ${status}`);
    }
  }

  async completeSaga(sagaId: string, result: any): Promise<void> {
    await this.sagaRepository.update(sagaId, {
      status: SagaStatus.COMPLETED,
      result,
      completedAt: new Date(),
    });

    this.logger.log(`Saga completed: ${sagaId}`);
  }

  async failSaga(sagaId: string, error: string): Promise<void> {
    await this.sagaRepository.update(sagaId, {
      status: SagaStatus.FAILED,
      error,
      completedAt: new Date(),
    });

    this.logger.error(`Saga failed: ${sagaId} - ${error}`);
  }

  async getSagaState(sagaId: string): Promise<SagaExecution> {
    return this.sagaRepository.findOne({ where: { sagaId } });
  }

  async getStuckSagas(timeoutMinutes: number = 30): Promise<SagaExecution[]> {
    const cutoffTime = new Date(Date.now() - timeoutMinutes * 60 * 1000);

    return this.sagaRepository
      .createQueryBuilder('saga')
      .where('saga.status IN (:...statuses)', {
        statuses: [SagaStatus.STARTED, SagaStatus.IN_PROGRESS],
      })
      .andWhere('saga.startedAt < :cutoffTime', { cutoffTime })
      .getMany();
  }
}

// services/order-service/src/monitoring/saga-metrics.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { Counter, Histogram, Gauge } from 'prom-client';

@Injectable()
export class SagaMetricsService {
  private readonly logger = new Logger(SagaMetricsService.name);

  private sagaStartedCounter = new Counter({
    name: 'saga_started_total',
    help: 'Total number of sagas started',
    labelNames: ['saga_type'],
  });

  private sagaCompletedCounter = new Counter({
    name: 'saga_completed_total',
    help: 'Total number of sagas completed',
    labelNames: ['saga_type', 'status'],
  });

  private sagaDurationHistogram = new Histogram({
    name: 'saga_duration_seconds',
    help: 'Saga execution duration in seconds',
    labelNames: ['saga_type', 'status'],
    buckets: [1, 5, 10, 30, 60, 120, 300],
  });

  private sagaCompensationsCounter = new Counter({
    name: 'saga_compensations_total',
    help: 'Total number of saga compensations executed',
    labelNames: ['saga_type', 'step'],
  });

  private activeSagasGauge = new Gauge({
    name: 'saga_active_count',
    help: 'Number of currently active sagas',
    labelNames: ['saga_type'],
  });

  recordSagaStarted(sagaType: string): void {
    this.sagaStartedCounter.inc({ saga_type: sagaType });
    this.activeSagasGauge.inc({ saga_type: sagaType });
  }

  recordSagaCompleted(sagaType: string, status: 'success' | 'failed', durationMs: number): void {
    this.sagaCompletedCounter.inc({ saga_type: sagaType, status });
    this.sagaDurationHistogram.observe({ saga_type: sagaType, status }, durationMs / 1000);
    this.activeSagasGauge.dec({ saga_type: sagaType });
  }

  recordCompensation(sagaType: string, step: string): void {
    this.sagaCompensationsCounter.inc({ saga_type: sagaType, step });
  }
}

Best Practices​

1. Saga Design Principles​

✅ Do:

  • Keep sagas simple and focused on a single business process
  • Design compensations for every forward transaction
  • Use idempotent operations (can be safely retried)
  • Track saga state for observability
  • Set timeouts for saga steps

❌ Don't:

  • Create deeply nested or overly complex sagas
  • Assume all operations will succeed
  • Ignore partial failure scenarios
  • Skip compensation logic
  • Let sagas run indefinitely

2. Choosing Between Choreography and Orchestration​

Use Choreography When:

  • Services are loosely coupled
  • Saga has few steps (2-4)
  • Team prefers event-driven architecture
  • Services can autonomously make decisions

Use Orchestration When:

  • Complex business logic with many steps (5+)
  • Need centralized visibility and control
  • Require strict ordering of operations
  • Need to modify saga flow frequently

3. Error Handling​

✅ Do:

  • Implement retry logic with exponential backoff
  • Use circuit breakers for external service calls
  • Log all saga events and state transitions
  • Alert on stuck or failed sagas
  • Plan for manual intervention

❌ Don't:

  • Retry indefinitely without backoff
  • Ignore compensation failures
  • Leave sagas in limbo state
  • Skip error logging
  • Assume compensations always succeed

4. Data Consistency​

✅ Do:

  • Accept eventual consistency
  • Use versioning for concurrent updates
  • Implement optimistic locking
  • Validate state before compensation
  • Use correlation IDs across services

❌ Don't:

  • Expect immediate consistency
  • Allow lost updates
  • Skip conflict detection
  • Assume strong consistency
  • Create tight coupling between services

5. Testing Strategies​

6. Monitoring and Observability​

✅ Do:

  • Track saga execution time
  • Monitor compensation rates
  • Alert on stuck sagas
  • Visualize saga flows
  • Log correlation IDs

❌ Don't:

  • Run sagas without monitoring
  • Ignore high compensation rates
  • Skip timeout configuration
  • Lose track of saga state
  • Forget distributed tracing

Summary​

Key takeaways for implementing sagas:

  • Saga Pattern - Sequence of local transactions with compensations
  • Two Approaches - Choreography (event-driven) vs Orchestration (workflow)
  • Eventual Consistency - Accept that data will be consistent eventually
  • Compensation Logic - Every step needs a rollback mechanism
  • Idempotency - Operations must be safely retryable
  • Monitoring - Track saga state, duration, and failures
  • Testing - Test both happy path and compensation scenarios

Remember: Sagas trade immediate consistency for availability and partition tolerance. Design compensations carefully and monitor saga health!
