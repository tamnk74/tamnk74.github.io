Distributed Tracing and Context Propagation Guide

Overview​

Distributed tracing enables tracking requests across multiple microservices, providing visibility into system behavior, performance bottlenecks, and failure points. This guide covers implementing distributed tracing with OpenTelemetry, context propagation patterns, and integration with observability platforms.

// shared/tracing/src/tracing.service.ts
import { Injectable, Inject, OnModuleInit, Logger } from '@nestjs/common';
import { NodeSDK } from '@opentelemetry/sdk-node';
import { getNodeAutoInstrumentations } from '@opentelemetry/auto-instrumentations-node';
import { Resource } from '@opentelemetry/resources';
import { SemanticResourceAttributes } from '@opentelemetry/semantic-conventions';
import { JaegerExporter } from '@opentelemetry/exporter-jaeger';
import { OTLPTraceExporter } from '@opentelemetry/exporter-trace-otlp-http';
import { BatchSpanProcessor } from '@opentelemetry/sdk-trace-base';
import { trace, context, propagation, SpanStatusCode, Span } from '@opentelemetry/api';
import { W3CTraceContextPropagator } from '@opentelemetry/core';
import { B3Propagator } from '@opentelemetry/propagator-b3';
import { TRACING_OPTIONS } from './tracing.constants';
import { TracingModuleOptions } from './interfaces/tracing-options.interface';

@Injectable()
export class TracingService implements OnModuleInit {
  private readonly logger = new Logger(TracingService.name);
  private sdk: NodeSDK;
  private tracer: any;

  constructor(@Inject(TRACING_OPTIONS) private options: TracingModuleOptions) {}

  async onModuleInit() {
    await this.initializeTracing();
  }

  private async initializeTracing(): Promise<void> {
    const resource = Resource.default().merge(
      new Resource({
        [SemanticResourceAttributes.SERVICE_NAME]: this.options.serviceName,
        [SemanticResourceAttributes.SERVICE_VERSION]: this.options.serviceVersion || '1.0.0',
        [SemanticResourceAttributes.DEPLOYMENT_ENVIRONMENT]:
          this.options.environment || process.env.NODE_ENV || 'development',
      }),
    );

    // Configure exporters
    const exporters = this.getExporters();

    // Configure propagators for context propagation
    const propagators = this.getPropagators();

    this.sdk = new NodeSDK({
      resource,
      spanProcessor: new BatchSpanProcessor(exporters[0]),
      instrumentations: [
        getNodeAutoInstrumentations({
          '@opentelemetry/instrumentation-http': {
            enabled: true,
            ignoreIncomingPaths: ['/health', '/metrics'],
          },
          '@opentelemetry/instrumentation-express': {
            enabled: true,
          },
          '@opentelemetry/instrumentation-nestjs-core': {
            enabled: true,
          },
          '@opentelemetry/instrumentation-pg': {
            enabled: true,
          },
          '@opentelemetry/instrumentation-redis': {
            enabled: true,
          },
          '@opentelemetry/instrumentation-kafkajs': {
            enabled: true,
          },
        }),
      ],
      textMapPropagator: propagators,
    });

    await this.sdk.start();
    this.tracer = trace.getTracer(this.options.serviceName, this.options.serviceVersion);

    this.logger.log(`Tracing initialized for service: ${this.options.serviceName}`);
  }

  private getExporters(): any[] {
    const exporters = [];

    if (this.options.jaeger?.enabled) {
      exporters.push(
        new JaegerExporter({
          endpoint: this.options.jaeger.endpoint || 'http://localhost:14268/api/traces',
        }),
      );
    }

    if (this.options.otlp?.enabled) {
      exporters.push(
        new OTLPTraceExporter({
          url: this.options.otlp.endpoint || 'http://localhost:4318/v1/traces',
          headers: this.options.otlp.headers || {},
        }),
      );
    }

    // Default to console if no exporter configured
    if (exporters.length === 0) {
      this.logger.warn('No trace exporter configured, using console');
    }

    return exporters.length > 0 ? exporters : [new JaegerExporter()];
  }

  private getPropagators(): any {
    const propagators = [];

    // W3C Trace Context (recommended standard)
    if (this.options.propagators?.w3c !== false) {
      propagators.push(new W3CTraceContextPropagator());
    }

    // B3 Propagator (Zipkin compatible)
    if (this.options.propagators?.b3) {
      propagators.push(new B3Propagator());
    }

    return propagators.length > 1
      ? new CompositePropagator({ propagators })
      : propagators[0] || new W3CTraceContextPropagator();
  }

  getTracer() {
    return this.tracer;
  }

  startSpan(name: string, options?: any): Span {
    return this.tracer.startSpan(name, options);
  }

  startActiveSpan<T>(name: string, fn: (span: Span) => T): T {
    return this.tracer.startActiveSpan(name, (span: Span) => {
      try {
        return fn(span);
      } catch (error) {
        span.recordException(error);
        span.setStatus({ code: SpanStatusCode.ERROR, message: error.message });
        throw error;
      } finally {
        span.end();
      }
    });
  }

  async startActiveSpanAsync<T>(name: string, fn: (span: Span) => Promise<T>): Promise<T> {
    return this.tracer.startActiveSpan(name, async (span: Span) => {
      try {
        return await fn(span);
      } catch (error) {
        span.recordException(error);
        span.setStatus({ code: SpanStatusCode.ERROR, message: error.message });
        throw error;
      } finally {
        span.end();
      }
    });
  }

  getCurrentSpan(): Span | undefined {
    return trace.getSpan(context.active());
  }

  addEvent(name: string, attributes?: any): void {
    const span = this.getCurrentSpan();
    if (span) {
      span.addEvent(name, attributes);
    }
  }

  setAttribute(key: string, value: any): void {
    const span = this.getCurrentSpan();
    if (span) {
      span.setAttribute(key, value);
    }
  }

  setAttributes(attributes: Record<string, any>): void {
    const span = this.getCurrentSpan();
    if (span) {
      span.setAttributes(attributes);
    }
  }

  recordException(error: Error): void {
    const span = this.getCurrentSpan();
    if (span) {
      span.recordException(error);
      span.setStatus({ code: SpanStatusCode.ERROR, message: error.message });
    }
  }

  async shutdown(): Promise<void> {
    await this.sdk.shutdown();
    this.logger.log('Tracing shutdown complete');
  }
}

Context Propagation​

1. HTTP Context Propagation​

// shared/tracing/src/interceptors/tracing.interceptor.ts
import { Injectable, NestInterceptor, ExecutionContext, CallHandler, Logger } from '@nestjs/common';
import { Observable } from 'rxjs';
import { tap } from 'rxjs/operators';
import { TracingService } from '../tracing.service';
import { context, trace, propagation, SpanKind, SpanStatusCode } from '@opentelemetry/api';

@Injectable()
export class TracingInterceptor implements NestInterceptor {
  private readonly logger = new Logger(TracingInterceptor.name);

  constructor(private readonly tracingService: TracingService) {}

  intercept(executionContext: ExecutionContext, next: CallHandler): Observable<any> {
    const request = executionContext.switchToHttp().getRequest();
    const response = executionContext.switchToHttp().getResponse();
    const { method, url, headers } = request;

    // Extract trace context from incoming headers
    const parentContext = propagation.extract(context.active(), headers);

    const tracer = this.tracingService.getTracer();
    const span = tracer.startSpan(
      `${method} ${url}`,
      {
        kind: SpanKind.SERVER,
        attributes: {
          'http.method': method,
          'http.url': url,
          'http.target': request.path,
          'http.host': headers.host,
          'http.scheme': request.protocol,
          'http.user_agent': headers['user-agent'],
        },
      },
      parentContext,
    );

    // Activate the span context
    return context.with(trace.setSpan(parentContext, span), () => {
      const startTime = Date.now();

      return next.handle().pipe(
        tap({
          next: (data) => {
            span.setAttribute('http.status_code', response.statusCode);
            span.setStatus({ code: SpanStatusCode.OK });
          },
          error: (error) => {
            span.setAttribute('http.status_code', response.statusCode || 500);
            span.recordException(error);
            span.setStatus({
              code: SpanStatusCode.ERROR,
              message: error.message,
            });
          },
          finalize: () => {
            const duration = Date.now() - startTime;
            span.setAttribute('http.response_time_ms', duration);
            span.end();
          },
        }),
      );
    });
  }
}

2. HTTP Client Context Propagation​

// shared/tracing/src/interceptors/http-client.interceptor.ts
import { Injectable, Logger } from '@nestjs/common';
import { HttpService } from '@nestjs/axios';
import { AxiosRequestConfig } from 'axios';
import { context, trace, propagation, SpanKind, SpanStatusCode } from '@opentelemetry/api';
import { TracingService } from '../tracing.service';

@Injectable()
export class TracedHttpService {
  private readonly logger = new Logger(TracedHttpService.name);

  constructor(private readonly httpService: HttpService, private readonly tracingService: TracingService) {}

  async get<T = any>(url: string, config?: AxiosRequestConfig): Promise<T> {
    return this.request<T>('GET', url, config);
  }

  async post<T = any>(url: string, data?: any, config?: AxiosRequestConfig): Promise<T> {
    return this.request<T>('POST', url, { ...config, data });
  }

  async put<T = any>(url: string, data?: any, config?: AxiosRequestConfig): Promise<T> {
    return this.request<T>('PUT', url, { ...config, data });
  }

  async delete<T = any>(url: string, config?: AxiosRequestConfig): Promise<T> {
    return this.request<T>('DELETE', url, config);
  }

  private async request<T = any>(method: string, url: string, config?: AxiosRequestConfig): Promise<T> {
    const tracer = this.tracingService.getTracer();
    const span = tracer.startSpan(`HTTP ${method} ${url}`, {
      kind: SpanKind.CLIENT,
      attributes: {
        'http.method': method,
        'http.url': url,
      },
    });

    return context.with(trace.setSpan(context.active(), span), async () => {
      try {
        // Inject trace context into headers
        const headers = { ...config?.headers };
        propagation.inject(context.active(), headers);

        const startTime = Date.now();
        const response = await this.httpService
          .request<T>({
            ...config,
            method,
            url,
            headers,
          })
          .toPromise();

        const duration = Date.now() - startTime;

        span.setAttributes({
          'http.status_code': response.status,
          'http.response_time_ms': duration,
        });
        span.setStatus({ code: SpanStatusCode.OK });

        return response.data;
      } catch (error) {
        span.recordException(error);
        span.setAttributes({
          'http.status_code': error.response?.status || 0,
          'error.type': error.name,
        });
        span.setStatus({
          code: SpanStatusCode.ERROR,
          message: error.message,
        });
        throw error;
      } finally {
        span.end();
      }
    });
  }
}

3. Kafka Context Propagation​

// shared/tracing/src/kafka/kafka-tracing.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { context, trace, propagation, SpanKind, SpanStatusCode } from '@opentelemetry/api';
import { TracingService } from '../tracing.service';

@Injectable()
export class KafkaTracingService {
  private readonly logger = new Logger(KafkaTracingService.name);

  constructor(private readonly tracingService: TracingService) {}

  injectTraceContext(headers: any = {}): any {
    // Inject current trace context into Kafka message headers
    const carrier = {};
    propagation.inject(context.active(), carrier);

    return {
      ...headers,
      ...carrier,
    };
  }

  extractTraceContext(headers: any = {}): any {
    // Extract trace context from Kafka message headers
    return propagation.extract(context.active(), headers);
  }

  async produceWithTracing(topic: string, message: any, producer: any): Promise<void> {
    const tracer = this.tracingService.getTracer();
    const span = tracer.startSpan(`Kafka Produce ${topic}`, {
      kind: SpanKind.PRODUCER,
      attributes: {
        'messaging.system': 'kafka',
        'messaging.destination': topic,
        'messaging.destination_kind': 'topic',
      },
    });

    return context.with(trace.setSpan(context.active(), span), async () => {
      try {
        // Inject trace context into message headers
        const headers = this.injectTraceContext(message.headers);

        await producer.send({
          topic,
          messages: [
            {
              ...message,
              headers,
            },
          ],
        });

        span.setStatus({ code: SpanStatusCode.OK });
      } catch (error) {
        span.recordException(error);
        span.setStatus({
          code: SpanStatusCode.ERROR,
          message: error.message,
        });
        throw error;
      } finally {
        span.end();
      }
    });
  }

  consumeWithTracing(topic: string, message: any, handler: () => Promise<void>): Promise<void> {
    const tracer = this.tracingService.getTracer();

    // Extract parent context from message headers
    const parentContext = this.extractTraceContext(message.headers);

    const span = tracer.startSpan(
      `Kafka Consume ${topic}`,
      {
        kind: SpanKind.CONSUMER,
        attributes: {
          'messaging.system': 'kafka',
          'messaging.destination': topic,
          'messaging.destination_kind': 'topic',
          'messaging.operation': 'receive',
          'messaging.message_id': message.key,
          'messaging.kafka.partition': message.partition,
          'messaging.kafka.offset': message.offset,
        },
      },
      parentContext,
    );

    return context.with(trace.setSpan(parentContext, span), async () => {
      try {
        await handler();
        span.setStatus({ code: SpanStatusCode.OK });
      } catch (error) {
        span.recordException(error);
        span.setStatus({
          code: SpanStatusCode.ERROR,
          message: error.message,
        });
        throw error;
      } finally {
        span.end();
      }
    });
  }
}

4. Database Query Tracing​

// shared/tracing/src/database/database-tracing.interceptor.ts
import { Injectable, Logger } from '@nestjs/common';
import { context, trace, SpanKind, SpanStatusCode } from '@opentelemetry/api';
import { TracingService } from '../tracing.service';

@Injectable()
export class DatabaseTracingService {
  private readonly logger = new Logger(DatabaseTracingService.name);

  constructor(private readonly tracingService: TracingService) {}

  async traceQuery<T>(operation: string, query: string, params: any[], executor: () => Promise<T>): Promise<T> {
    const tracer = this.tracingService.getTracer();
    const span = tracer.startSpan(`DB ${operation}`, {
      kind: SpanKind.CLIENT,
      attributes: {
        'db.system': 'postgresql',
        'db.operation': operation,
        'db.statement': this.sanitizeQuery(query),
      },
    });

    return context.with(trace.setSpan(context.active(), span), async () => {
      const startTime = Date.now();

      try {
        const result = await executor();
        const duration = Date.now() - startTime;

        span.setAttributes({
          'db.duration_ms': duration,
          'db.rows_affected': this.getRowCount(result),
        });
        span.setStatus({ code: SpanStatusCode.OK });

        return result;
      } catch (error) {
        span.recordException(error);
        span.setAttributes({
          'error.type': error.name,
          'db.error_code': error.code,
        });
        span.setStatus({
          code: SpanStatusCode.ERROR,
          message: error.message,
        });
        throw error;
      } finally {
        span.end();
      }
    });
  }

  private sanitizeQuery(query: string): string {
    // Remove sensitive data from query (simplified version)
    return query
      .replace(/password\s*=\s*'[^']*'/gi, "password='***'")
      .replace(/token\s*=\s*'[^']*'/gi, "token='***'")
      .substring(0, 500); // Limit query length
  }

  private getRowCount(result: any): number {
    if (Array.isArray(result)) {
      return result.length;
    }
    if (result && typeof result === 'object' && 'rowCount' in result) {
      return result.rowCount;
    }
    return 0;
  }
}

Instrumentation Patterns​

1. Service-Level Instrumentation​

// services/user-service/src/users/users.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import { TracingService } from '@ecommerce/tracing';
import { DatabaseTracingService } from '@ecommerce/tracing/database';
import { User } from './entities/user.entity';
import { CreateUserDto } from './dto/create-user.dto';

@Injectable()
export class UsersService {
  private readonly logger = new Logger(UsersService.name);

  constructor(
    @InjectRepository(User)
    private usersRepository: Repository<User>,
    private tracingService: TracingService,
    private dbTracingService: DatabaseTracingService,
  ) {}

  async create(createUserDto: CreateUserDto): Promise<User> {
    return this.tracingService.startActiveSpanAsync('UsersService.create', async (span) => {
      span.setAttributes({
        'user.email': createUserDto.email,
        'user.username': createUserDto.username,
      });

      // Hash password with tracing
      const passwordHash = await this.tracingService.startActiveSpanAsync('hash.password', async () => {
        return await bcrypt.hash(createUserDto.password, 10);
      });

      // Database operation with tracing
      const user = await this.dbTracingService.traceQuery(
        'INSERT',
        'INSERT INTO users ...',
        [createUserDto.username, createUserDto.email, passwordHash],
        async () => {
          return await this.usersRepository.save({
            username: createUserDto.username,
            email: createUserDto.email,
            passwordHash,
          });
        },
      );

      span.addEvent('user.created', {
        'user.id': user.id,
      });

      return user;
    });
  }

  async findOne(id: string): Promise<User> {
    return this.tracingService.startActiveSpanAsync('UsersService.findOne', async (span) => {
      span.setAttribute('user.id', id);

      const user = await this.dbTracingService.traceQuery(
        'SELECT',
        'SELECT * FROM users WHERE id = $1',
        [id],
        async () => {
          return await this.usersRepository.findOne({ where: { id } });
        },
      );

      if (!user) {
        span.addEvent('user.not_found');
        throw new NotFoundException('User not found');
      }

      return user;
    });
  }

  async findAll(page: number = 1, limit: number = 10): Promise<{ users: User[]; total: number }> {
    return this.tracingService.startActiveSpanAsync('UsersService.findAll', async (span) => {
      span.setAttributes({
        'pagination.page': page,
        'pagination.limit': limit,
      });

      const [users, total] = await this.dbTracingService.traceQuery(
        'SELECT',
        'SELECT * FROM users LIMIT $1 OFFSET $2',
        [limit, (page - 1) * limit],
        async () => {
          return await this.usersRepository.findAndCount({
            skip: (page - 1) * limit,
            take: limit,
          });
        },
      );

      span.setAttributes({
        'result.count': users.length,
        'result.total': total,
      });

      return { users, total };
    });
  }
}

2. Controller Instrumentation​

// services/user-service/src/users/users.controller.ts
import { Controller, Get, Post, Body, Param, Query, UseInterceptors } from '@nestjs/common';
import { ApiTags, ApiOperation } from '@nestjs/swagger';
import { TracingInterceptor } from '@ecommerce/tracing';
import { TracingService } from '@ecommerce/tracing';
import { UsersService } from './users.service';
import { CreateUserDto } from './dto/create-user.dto';

@ApiTags('Users')
@Controller('users')
@UseInterceptors(TracingInterceptor)
export class UsersController {
  constructor(private readonly usersService: UsersService, private readonly tracingService: TracingService) {}

  @Post()
  @ApiOperation({ summary: 'Create user' })
  async create(@Body() createUserDto: CreateUserDto) {
    // Add custom attributes to current span
    this.tracingService.setAttributes({
      'business.operation': 'user.registration',
      'user.source': 'web',
    });

    const user = await this.usersService.create(createUserDto);

    // Add event to span
    this.tracingService.addEvent('user.registration.completed', {
      'user.id': user.id,
    });

    return user;
  }

  @Get(':id')
  @ApiOperation({ summary: 'Get user by ID' })
  async findOne(@Param('id') id: string) {
    this.tracingService.setAttribute('user.lookup.type', 'by_id');
    return this.usersService.findOne(id);
  }

  @Get()
  @ApiOperation({ summary: 'Get all users' })
  async findAll(@Query('page') page: number = 1, @Query('limit') limit: number = 10) {
    this.tracingService.setAttributes({
      'query.type': 'pagination',
      'pagination.requested.page': page,
      'pagination.requested.limit': limit,
    });

    return this.usersService.findAll(page, limit);
  }
}

// services/order-service/src/orders/orders.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { TracingService } from '@ecommerce/tracing';
import { TracedHttpService } from '@ecommerce/tracing';
import { KafkaTracingService } from '@ecommerce/tracing/kafka';

@Injectable()
export class OrdersService {
  private readonly logger = new Logger(OrdersService.name);

  constructor(
    private tracingService: TracingService,
    private httpService: TracedHttpService,
    private kafkaTracingService: KafkaTracingService,
  ) {}

  async createOrder(createOrderDto: CreateOrderDto): Promise<Order> {
    return this.tracingService.startActiveSpanAsync('OrdersService.createOrder', async (span) => {
      span.setAttributes({
        'order.user_id': createOrderDto.userId,
        'order.item_count': createOrderDto.items.length,
        'order.total_amount': createOrderDto.totalAmount,
      });

      // Step 1: Validate user (HTTP call to user-service)
      const user = await this.tracingService.startActiveSpanAsync('validate.user', async (userSpan) => {
        userSpan.setAttribute('user.id', createOrderDto.userId);

        const userData = await this.httpService.get(`http://user-service/users/${createOrderDto.userId}`);

        userSpan.addEvent('user.validated');
        return userData;
      });

      // Step 2: Check inventory (HTTP call to product-service)
      await this.tracingService.startActiveSpanAsync('check.inventory', async (inventorySpan) => {
        for (const item of createOrderDto.items) {
          const product = await this.httpService.get(`http://product-service/products/${item.productId}/inventory`);

          inventorySpan.addEvent('inventory.checked', {
            'product.id': item.productId,
            'inventory.available': product.quantity,
          });

          if (product.quantity < item.quantity) {
            throw new BadRequestException('Insufficient inventory');
          }
        }
      });

      // Step 3: Create order in database
      const order = await this.tracingService.startActiveSpanAsync('create.order', async () => {
        return await this.ordersRepository.save({
          userId: createOrderDto.userId,
          items: createOrderDto.items,
          totalAmount: createOrderDto.totalAmount,
          status: 'PENDING',
        });
      });

      // Step 4: Publish order created event to Kafka
      await this.kafkaTracingService.produceWithTracing(
        'order-events',
        {
          key: order.id,
          value: JSON.stringify({
            eventType: 'order.created',
            orderId: order.id,
            userId: order.userId,
            totalAmount: order.totalAmount,
          }),
        },
        this.kafkaProducer,
      );

      span.addEvent('order.created', {
        'order.id': order.id,
        'order.status': order.status,
      });

      return order;
    });
  }
}

// shared/tracing/src/datadog/datadog-tracing.service.ts
import { Injectable, OnModuleInit, Logger } from '@nestjs/common';
import tracer from 'dd-trace';

@Injectable()
export class DatadogTracingService implements OnModuleInit {
  private readonly logger = new Logger(DatadogTracingService.name);

  onModuleInit() {
    if (process.env.DD_TRACE_ENABLED === 'true') {
      tracer.init({
        service: process.env.DD_SERVICE || 'ecommerce-service',
        env: process.env.DD_ENV || process.env.NODE_ENV || 'development',
        version: process.env.DD_VERSION || '1.0.0',
        logInjection: true,
        runtimeMetrics: true,
        profiling: true,
        analytics: true,
        tags: {
          team: process.env.TEAM_NAME || 'platform',
          region: process.env.REGION || 'us-east-1',
        },
      });

      this.logger.log('Datadog tracing initialized');
    }
  }

  createCustomSpan(name: string, options?: any) {
    const span = tracer.startSpan(name, options);
    return {
      setTag: (key: string, value: any) => span.setTag(key, value),
      addTags: (tags: Record<string, any>) => span.addTags(tags),
      log: (fields: Record<string, any>) => span.log(fields),
      finish: () => span.finish(),
    };
  }

  getActiveSpan() {
    return tracer.scope().active();
  }

  injectTraceContext(carrier: any = {}): any {
    const span = this.getActiveSpan();
    if (span) {
      tracer.inject(span, 'http_headers', carrier);
    }
    return carrier;
  }

  extractTraceContext(carrier: any): any {
    return tracer.extract('http_headers', carrier);
  }
}

// shared/tracing/src/decorators/trace.decorator.ts
import { TracingService } from '../tracing.service';

export function Trace(spanName?: string) {
  return function (target: any, propertyKey: string, descriptor: PropertyDescriptor) {
    const originalMethod = descriptor.value;
    const name = spanName || `${target.constructor.name}.${propertyKey}`;

    descriptor.value = async function (...args: any[]) {
      const tracingService: TracingService = this.tracingService;

      if (!tracingService) {
        return originalMethod.apply(this, args);
      }

      return tracingService.startActiveSpanAsync(name, async (span) => {
        try {
          const result = await originalMethod.apply(this, args);
          return result;
        } catch (error) {
          span.recordException(error);
          throw error;
        }
      });
    };

    return descriptor;
  };
}
// Usage example
@Injectable()
export class PaymentService {
  constructor(private tracingService: TracingService) {}

  @Trace('PaymentService.processPayment')
  async processPayment(paymentData: PaymentDto): Promise<Payment> {
    this.tracingService.setAttributes({
      'payment.amount': paymentData.amount,
      'payment.currency': paymentData.currency,
      'payment.method': paymentData.method,
    });

    // Processing logic
    const payment = await this.createPayment(paymentData);

    this.tracingService.addEvent('payment.processed', {
      'payment.id': payment.id,
      'payment.status': payment.status,
    });

    return payment;
  }
}

2. Error Tracking​

// shared/tracing/src/filters/tracing-exception.filter.ts
import { ExceptionFilter, Catch, ArgumentsHost, HttpException, HttpStatus, Logger } from '@nestjs/common';
import { TracingService } from '../tracing.service';

@Catch()
export class TracingExceptionFilter implements ExceptionFilter {
  private readonly logger = new Logger(TracingExceptionFilter.name);

  constructor(private tracingService: TracingService) {}

  catch(exception: Error, host: ArgumentsHost) {
    const ctx = host.switchToHttp();
    const response = ctx.getResponse();
    const request = ctx.getRequest();

    const status = exception instanceof HttpException ? exception.getStatus() : HttpStatus.INTERNAL_SERVER_ERROR;

    const errorResponse = {
      statusCode: status,
      timestamp: new Date().toISOString(),
      path: request.url,
      message: exception.message,
    };

    // Record exception in current span
    this.tracingService.recordException(exception);
    this.tracingService.setAttributes({
      'error.type': exception.constructor.name,
      'error.message': exception.message,
      'http.status_code': status,
    });

    this.logger.error(`${request.method} ${request.url} - ${status}`, exception.stack);

    response.status(status).json(errorResponse);
  }
}

Performance Optimization​

1. Sampling Strategy​

// shared/tracing/src/sampling/custom-sampler.ts
import { Sampler, SamplingDecision, SamplingResult } from '@opentelemetry/sdk-trace-base';
import { Context, SpanKind, Attributes } from '@opentelemetry/api';

export class CustomSampler implements Sampler {
  private defaultSamplingRate: number;
  private highPrioritySamplingRate: number;

  constructor(defaultRate: number = 0.1, highPriorityRate: number = 1.0) {
    this.defaultSamplingRate = defaultRate;
    this.highPrioritySamplingRate = highPriorityRate;
  }

  shouldSample(
    context: Context,
    traceId: string,
    spanName: string,
    spanKind: SpanKind,
    attributes: Attributes,
  ): SamplingResult {
    // Always sample errors
    if (attributes['http.status_code'] >= 400) {
      return {
        decision: SamplingDecision.RECORD_AND_SAMPLED,
      };
    }

    // High priority endpoints
    const highPriorityPaths = ['/checkout', '/payment', '/order'];
    const path = attributes['http.target'] as string;

    if (highPriorityPaths.some((p) => path?.startsWith(p))) {
      return this.makeSamplingDecision(this.highPrioritySamplingRate);
    }

    // Health checks - don't sample
    if (path === '/health' || path === '/metrics') {
      return {
        decision: SamplingDecision.NOT_RECORD,
      };
    }

    // Default sampling rate
    return this.makeSamplingDecision(this.defaultSamplingRate);
  }

  private makeSamplingDecision(rate: number): SamplingResult {
    const shouldSample = Math.random() < rate;
    return {
      decision: shouldSample ? SamplingDecision.RECORD_AND_SAMPLED : SamplingDecision.NOT_RECORD,
    };
  }

  toString(): string {
    return `CustomSampler{default=${this.defaultSamplingRate}, high=${this.highPrioritySamplingRate}}`;
  }
}

2. Span Processor Optimization​

// shared/tracing/src/processors/filtered-span-processor.ts
import { ReadableSpan, SpanProcessor } from '@opentelemetry/sdk-trace-base';
import { Context } from '@opentelemetry/api';

export class FilteredSpanProcessor implements SpanProcessor {
  private delegate: SpanProcessor;
  private excludePatterns: RegExp[];

  constructor(delegate: SpanProcessor, excludePatterns: string[] = []) {
    this.delegate = delegate;
    this.excludePatterns = excludePatterns.map((pattern) => new RegExp(pattern));
  }

  onStart(span: ReadableSpan, parentContext: Context): void {
    if (!this.shouldFilter(span)) {
      this.delegate.onStart(span, parentContext);
    }
  }

  onEnd(span: ReadableSpan): void {
    if (!this.shouldFilter(span)) {
      this.delegate.onEnd(span);
    }
  }

  shutdown(): Promise<void> {
    return this.delegate.shutdown();
  }

  forceFlush(): Promise<void> {
    return this.delegate.forceFlush();
  }

  private shouldFilter(span: ReadableSpan): boolean {
    const spanName = span.name;
    return this.excludePatterns.some((pattern) => pattern.test(spanName));
  }
}

Best Practices​

1. Trace Context Management​

✅ Do:

  • Always propagate trace context across service boundaries
  • Use standard propagation formats (W3C Trace Context)
  • Include trace IDs in logs for correlation
  • Preserve trace context in async operations
  • Use context.with() for manual span management

❌ Don't:

  • Break trace context chain
  • Create orphaned spans
  • Ignore parent context
  • Mix different propagation formats
  • Forget to activate spans

2. Span Naming and Attributes​

✅ Do:

  • Use descriptive, consistent span names
  • Follow semantic conventions for attributes
  • Include business-relevant metadata
  • Set appropriate span kinds (SERVER, CLIENT, etc.)
  • Record meaningful events

❌ Don't:

  • Use generic span names like "process" or "handle"
  • Include sensitive data in span attributes
  • Create too many spans (performance impact)
  • Forget to set span status on errors
  • Include large payloads in attributes

3. Error Handling​

✅ Do:

  • Always record exceptions in spans
  • Set appropriate span status codes
  • Include error context in attributes
  • Maintain trace through error handlers
  • Log errors with trace IDs

❌ Don't:

  • Swallow exceptions without recording
  • Mark failed operations as successful
  • Lose trace context in error paths
  • Skip error attributes
  • Ignore downstream errors

4. Performance​

✅ Do:

  • Use sampling for high-volume services
  • Implement span filtering
  • Batch span exports
  • Monitor tracing overhead
  • Use async span processors

❌ Don't:

  • Sample critical business transactions
  • Export every span in high traffic
  • Create deeply nested spans unnecessarily
  • Block on span operations
  • Forget to set resource limits

5. Security​

✅ Do:

  • Sanitize sensitive data in spans
  • Use secure transport for exports
  • Implement access controls on trace data
  • Redact PII from attributes
  • Encrypt trace data at rest

❌ Don't:

  • Include passwords or tokens in spans
  • Expose trace endpoints publicly
  • Log full request/response bodies
  • Share trace data without authorization
  • Skip encryption for sensitive traces

Summary​

Effective distributed tracing provides:

  • End-to-end visibility - Track requests across all services
  • Performance insights - Identify bottlenecks and latency issues
  • Error tracking - Quickly locate failure points
  • Service dependencies - Understand service interactions
  • Business metrics - Track business-relevant operations

Key implementation points:

  • Use OpenTelemetry for vendor-neutral instrumentation
  • Implement proper context propagation across all boundaries
  • Follow semantic conventions for consistency
  • Use appropriate sampling strategies
  • Integrate with observability platforms (Jaeger, Datadog, etc.)

Remember: Good tracing is invisible to users but invaluable to developers!
