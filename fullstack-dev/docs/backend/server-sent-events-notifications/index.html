Server-Sent Events for Real-Time Notifications

📖 Overview​

Server-Sent Events (SSE) is a server push technology that enables a server to push real-time updates to clients over a single HTTP connection. Unlike WebSockets, SSE is unidirectional (server to client) and uses standard HTTP, making it ideal for notifications, live updates, and real-time feeds.

🎯 When to Use SSE​

✅ Best Use Cases​

  • Real-time notifications (order updates, inventory alerts)
  • Live dashboards (analytics, monitoring)
  • News feeds (social media updates)
  • Progress tracking (upload/download status)
  • Stock tickers (price updates)
  • Server monitoring (logs, metrics)

❌ When to Use Alternatives​

TechnologyUse Case
WebSocketsBidirectional communication, chat apps, gaming
Long PollingLegacy browser support
GraphQL SubscriptionsComplex data requirements
WebhooksServer-to-server communication

1. SSE Controller​

import { Controller, Sse, UseGuards, Req, MessageEvent, Logger } from '@nestjs/common';
import { Observable, fromEvent, map, filter } from 'rxjs';
import { EventEmitter2 } from '@nestjs/event-emitter';
import { JwtAuthGuard } from '../auth/guards/jwt-auth.guard';
import { Request } from 'express';

interface NotificationEvent {
  userId: string;
  type: string;
  data: any;
  timestamp: Date;
}

@Controller('notifications')
export class NotificationsController {
  private readonly logger = new Logger(NotificationsController.name);

  constructor(private eventEmitter: EventEmitter2) {}

  @Sse('stream')
  @UseGuards(JwtAuthGuard)
  streamNotifications(@Req() request: Request): Observable<MessageEvent> {
    const userId = request.user['id'];

    this.logger.log(`SSE connection established for user: ${userId}`);

    // Send heartbeat every 30 seconds to keep connection alive
    const heartbeat$ = this.createHeartbeat();

    // Listen to user-specific notification events
    const notifications$ = fromEvent(this.eventEmitter, `notification.${userId}`).pipe(
      map((event: NotificationEvent) => ({
        id: event.timestamp.getTime().toString(),
        type: event.type,
        data: event.data,
        retry: 10000, // Retry connection after 10 seconds
      })),
    );

    // Merge heartbeat and notifications
    return merge(heartbeat$, notifications$);
  }

  private createHeartbeat(): Observable<MessageEvent> {
    return interval(30000).pipe(
      map(() => ({
        type: 'heartbeat',
        data: { timestamp: new Date() },
      })),
    );
  }
}

import { Injectable, Logger } from '@nestjs/common';
import { EventEmitter2 } from '@nestjs/event-emitter';
import { InjectRedis } from '@liaoliaots/nestjs-redis';
import Redis from 'ioredis';

export enum NotificationType {
  ORDER_CREATED = 'order.created',
  ORDER_UPDATED = 'order.updated',
  ORDER_SHIPPED = 'order.shipped',
  ORDER_DELIVERED = 'order.delivered',
  INVENTORY_LOW = 'inventory.low',
  INVENTORY_OUT = 'inventory.out',
  PAYMENT_SUCCESS = 'payment.success',
  PAYMENT_FAILED = 'payment.failed',
}

export interface Notification {
  userId: string;
  type: NotificationType;
  title: string;
  message: string;
  data?: any;
  timestamp: Date;
  read: boolean;
}

@Injectable()
export class NotificationService {
  private readonly logger = new Logger(NotificationService.name);
  private readonly NOTIFICATION_CHANNEL = 'notifications';

  constructor(private eventEmitter: EventEmitter2, @InjectRedis() private readonly redis: Redis) {
    this.subscribeToRedis();
  }

  /**
   * Subscribe to Redis pub/sub for distributed notifications
   */
  private async subscribeToRedis(): Promise<void> {
    const subscriber = this.redis.duplicate();

    await subscriber.subscribe(this.NOTIFICATION_CHANNEL);

    subscriber.on('message', (channel, message) => {
      if (channel === this.NOTIFICATION_CHANNEL) {
        const notification: Notification = JSON.parse(message);
        this.emitToClient(notification);
      }
    });

    this.logger.log('Subscribed to Redis notifications channel');
  }

  /**
   * Send notification to specific user
   */
  async sendNotification(notification: Notification): Promise<void> {
    // Persist notification to database (optional)
    await this.saveNotification(notification);

    // Broadcast via Redis for multi-instance support
    await this.redis.publish(this.NOTIFICATION_CHANNEL, JSON.stringify(notification));

    this.logger.log(`Notification sent to user ${notification.userId}: ${notification.type}`);
  }

  /**
   * Send notification to multiple users
   */
  async sendBulkNotification(
    userIds: string[],

@Injectable()
export class OrderService {
  constructor(private notificationService: NotificationService) {}

  async createOrder(userId: string, orderData: any): Promise<Order> {
    // Create order logic
    const order = await this.orderRepository.save({
      userId,
      ...orderData,
    });

    // Send notification
    await this.notificationService.sendNotification({
      userId,
      type: NotificationType.ORDER_CREATED,
      title: 'Order Confirmed',
      message: `Your order #${order.id} has been confirmed`,
      data: { orderId: order.id, total: order.total },
      timestamp: new Date(),
      read: false,
    });

    return order;
  }

  async updateOrderStatus(orderId: string, status: OrderStatus): Promise<void> {
    const order = await this.orderRepository.findOne(orderId);

    await this.orderRepository.update(orderId, { status });

    // Send status update notification
    let notificationType: NotificationType;
    let message: string;

    switch (status) {
      case OrderStatus.SHIPPED:
        notificationType = NotificationType.ORDER_SHIPPED;
        message = `Your order #${orderId} has been shipped`;
        break;
      case OrderStatus.DELIVERED:
        notificationType = NotificationType.ORDER_DELIVERED;
        message = `Your order #${orderId} has been delivered`;
        break;
      default:
        notificationType = NotificationType.ORDER_UPDATED;
        message = `Your order #${orderId} status updated to ${status}`;
    }

    await this.notificationService.sendNotification({
      userId: order.userId,
      type: notificationType,
      title: 'Order Update',
      message,
      data: { orderId, status },
      timestamp: new Date(),
      read: false,
    });
  }
}

1. SSE Hook​

import { useEffect, useState, useCallback, useRef } from 'react';

interface UseSSEOptions {
  url: string;
  token: string;
  onMessage?: (event: MessageEvent) => void;
  onError?: (error: Event) => void;
  reconnectInterval?: number;
}

interface SSEState {
  isConnected: boolean;
  error: Error | null;
  lastEvent: MessageEvent | null;
}

export function useSSE({ url, token, onMessage, onError, reconnectInterval = 5000 }: UseSSEOptions) {
  const [state, setState] = useState<SSEState>({
    isConnected: false,
    error: null,
    lastEvent: null,
  });

  const eventSourceRef = useRef<EventSource | null>(null);
  const reconnectTimeoutRef = useRef<NodeJS.Timeout>();

  const connect = useCallback(() => {
    // Close existing connection
    if (eventSourceRef.current) {
      eventSourceRef.current.close();
    }

    // Create new EventSource with authorization
    const eventSource = new EventSource(`${url}?token=${token}`);

    eventSource.onopen = () => {
      console.log('SSE connection established');
      setState((prev) => ({ ...prev, isConnected: true, error: null }));
    };

    eventSource.onmessage = (event: MessageEvent) => {
      console.log('SSE message received:', event.data);
      setState((prev) => ({ ...prev, lastEvent: event }));
      onMessage?.(event);
    };

    eventSource.onerror = (error: Event) => {
      console.error('SSE connection error:', error);
      setState((prev) => ({
        ...prev,
        isConnected: false,
        error: new Error('SSE connection failed'),
      }));

      onError?.(error);
      eventSource.close();

      // Attempt to reconnect
      reconnectTimeoutRef.current = setTimeout(() => {
        console.log('Attempting to reconnect SSE...');
        connect();
      }, reconnectInterval);
    };

    // Handle custom event types
    eventSource.addEventListener('heartbeat', (event: MessageEvent) => {
      console.log('Heartbeat received:', event.data);
    });

    eventSourceRef.current = eventSource;
  }, [url, token, onMessage, onError, reconnectInterval]);

  const disconnect = useCallback(() => {
    if (reconnectTimeoutRef.current) {
      clearTimeout(reconnectTimeoutRef.current);
    }

    if (eventSourceRef.current) {
      eventSourceRef.current.close();
      eventSourceRef.current = null;
    }

    setState({
      isConnected: false,
      error: null,
      lastEvent: null,
    });
  }, []);

  useEffect(() => {
    connect();

    return () => {
      disconnect();
    };
  }, [connect, disconnect]);

  return {
    ...state,
    reconnect: connect,
    disconnect,
  };
}

'use client';

import { useEffect, useState } from 'react';
import { useSSE } from '@/hooks/useSSE';
import { toast } from 'sonner';

interface Notification {
  id: string;
  type: string;
  title: string;
  message: string;
  data?: any;
  timestamp: Date;
  read: boolean;
}

export function NotificationCenter() {
  const [notifications, setNotifications] = useState<Notification[]>([]);
  const [unreadCount, setUnreadCount] = useState(0);
  const [isOpen, setIsOpen] = useState(false);

  const token = localStorage.getItem('accessToken') || '';

  const { isConnected, error } = useSSE({
    url: `${process.env.NEXT_PUBLIC_API_URL}/notifications/stream`,
    token,
    onMessage: (event) => {
      try {
        const data = JSON.parse(event.data);

        // Ignore heartbeat events
        if (event.type === 'heartbeat') return;

        const notification: Notification = {
          id: event.lastEventId || Date.now().toString(),
          type: data.type || event.type,
          title: data.title,
          message: data.message,
          data: data.data,
          timestamp: new Date(),
          read: false,
        };

        // Add to notification list
        setNotifications((prev) => [notification, ...prev]);
        setUnreadCount((prev) => prev + 1);

        // Show toast notification
        toast(notification.title, {
          description: notification.message,
          action: {
            label: 'View',
            onClick: () => handleNotificationClick(notification),
          },
        });

        // Play notification sound
        playNotificationSound();
      } catch (err) {
        console.error('Failed to parse notification:', err);
      }
    },
    onError: (error) => {
      console.error('SSE Error:', error);
      toast.error('Connection lost', {
        description: 'Trying to reconnect...',
      });
    },
  });

  const handleNotificationClick = (notification: Notification) => {
    // Mark as read
    markAsRead(notification.id);

    // Handle notification action based on type
    switch (notification.type) {
      case 'order.created':
      case 'order.updated':
        window.location.href = `/orders/${notification.data.orderId}`;
        break;
      case 'payment.success':
        window.location.href = `/payments/${notification.data.paymentId}`;
        break;
      default:
        break;
    }
  };

  const markAsRead = async (notificationId: string) => {
    try {
      await fetch(`/api/notifications/${notificationId}/read`, {
        method: 'PATCH',
        headers: {
          Authorization: `Bearer ${token}`,
        },
      });

      setNotifications((prev) => prev.map((n) => (n.id === notificationId ? { ...n, read: true } : n)));
      setUnreadCount((prev) => Math.max(0, prev - 1));
    } catch (err) {
      console.error('Failed to mark notification as read:', err);
    }
  };

  const playNotificationSound = () => {
    const audio = new Audio('/sounds/notification.mp3');
    audio.volume = 0.5;
    audio.play().catch(console.error);
  };

  return (
    <div className="relative">
      {/* Connection indicator */}
      <div className="flex items-center gap-2 text-sm">
        <div className={`h-2 w-2 rounded-full ${isConnected ? 'bg-green-500' : 'bg-red-500'}`} />
        <span className="text-gray-600">{isConnected ? 'Connected' : 'Disconnected'}</span>
      </div>

      {/* Notification bell */}
      <button onClick={() => setIsOpen(!isOpen)} className="relative p-2 hover:bg-gray-100 rounded-full">
        <BellIcon className="h-6 w-6" />
        {unreadCount > 0 && (
          <span className="absolute top-0 right-0 h-5 w-5 rounded-full bg-red-500 text-white text-xs flex items-center justify-center">
            {unreadCount > 9 ? '9+' : unreadCount}
          </span>
        )}
      </button>

      {/* Notification dropdown */}
      {isOpen && (
        <div className="absolute right-0 mt-2 w-80 bg-white rounded-lg shadow-lg border border-gray-200 max-h-96 overflow-y-auto">
          <div className="p-4 border-b border-gray-200">
            <h3 className="font-semibold">Notifications</h3>
          </div>

          {notifications.length === 0 ? (
            <div className="p-8 text-center text-gray-500">No notifications</div>
          ) : (
            <ul>
              {notifications.map((notification) => (
                <li
                  key={notification.id}
                  onClick={() => handleNotificationClick(notification)}
                  className={`p-4 border-b border-gray-100 hover:bg-gray-50 cursor-pointer ${
                    !notification.read ? 'bg-blue-50' : ''
                  }`}
                >
                  <div className="font-medium">{notification.title}</div>
                  <div className="text-sm text-gray-600">{notification.message}</div>
                  <div className="text-xs text-gray-400 mt-1">{formatTimestamp(notification.timestamp)}</div>
                </li>
              ))}
            </ul>
          )}
        </div>
      )}
    </div>
  );
}

function formatTimestamp(date: Date): string {
  const now = new Date();
  const diff = now.getTime() - date.getTime();
  const minutes = Math.floor(diff / 60000);

  if (minutes < 1) return 'Just now';
  if (minutes < 60) return `${minutes}m ago`;

  const hours = Math.floor(minutes / 60);
  if (hours < 24) return `${hours}h ago`;

  const days = Math.floor(hours / 24);
  return `${days}d ago`;
}

// JWT Guard for SSE endpoint
@Injectable()
export class SseJwtAuthGuard extends AuthGuard('jwt') {
  // Allow token in query parameter for SSE (EventSource doesn't support headers)
  async canActivate(context: ExecutionContext): Promise<boolean> {
    const request = context.switchToHttp().getRequest();

    // Get token from query parameter
    const token = request.query.token;

    if (token) {
      request.headers.authorization = `Bearer ${token}`;
    }

    return super.canActivate(context) as Promise<boolean>;
  }
}

Connection Management​

@Injectable()
export class SseConnectionManager {
  private connections = new Map<string, Response>();
  private readonly MAX_CONNECTIONS_PER_USER = 5;

  addConnection(userId: string, response: Response): void {
    const userConnections = this.getUserConnections(userId);

    if (userConnections.length >= this.MAX_CONNECTIONS_PER_USER) {
      // Close oldest connection
      const oldest = userConnections[0];
      oldest.end();
      this.connections.delete(this.getConnectionKey(userId, oldest));
    }

    this.connections.set(this.getConnectionKey(userId, response), response);
  }

  removeConnection(userId: string, response: Response): void {
    this.connections.delete(this.getConnectionKey(userId, response));
  }

  private getUserConnections(userId: string): Response[] {
    return Array.from(this.connections.entries())
      .filter(([key]) => key.startsWith(`${userId}:`))
      .map(([, response]) => response);
  }

  private getConnectionKey(userId: string, response: Response): string {
    return `${userId}:${response.connection.remoteAddress}`;
  }
}

import { Injectable } from '@nestjs/common';
import { Counter, Gauge, Histogram } from 'prom-client';

@Injectable()
export class SseMetrics {
  private readonly activeConnections = new Gauge({
    name: 'sse_active_connections',
    help: 'Number of active SSE connections',
    labelNames: ['user_id'],
  });

  private readonly messagesPublished = new Counter({
    name: 'sse_messages_published_total',
    help: 'Total number of messages published',
    labelNames: ['type', 'user_id'],
  });

  private readonly connectionDuration = new Histogram({
    name: 'sse_connection_duration_seconds',
    help: 'Duration of SSE connections',
    buckets: [60, 300, 900, 1800, 3600, 7200, 14400, 28800, 43200, 86400],
  });

  private readonly reconnections = new Counter({
    name: 'sse_reconnections_total',
    help: 'Total number of SSE reconnections',
    labelNames: ['user_id'],
  });

  recordConnection(userId: string): void {
    this.activeConnections.inc({ user_id: userId });
  }

  recordDisconnection(userId: string, duration: number): void {
    this.activeConnections.dec({ user_id: userId });
    this.connectionDuration.observe(duration);
  }

  recordMessage(type: string, userId: string): void {
    this.messagesPublished.inc({ type, user_id: userId });
  }

  recordReconnection(userId: string): void {
    this.reconnections.inc({ user_id: userId });
  }
}

  it('should send notification', async () => {
    const notification = {
      userId: 'user-123',
      type: NotificationType.ORDER_CREATED,
      title: 'Order Confirmed',
      message: 'Your order has been confirmed',
      timestamp: new Date(),
      read: false,
    };

    await service.sendNotification(notification);

    expect(redis.publish).toHaveBeenCalledWith('notifications', JSON.stringify(notification));
  });
});

Integration Tests​

import { INestApplication } from '@nestjs/common';
import * as request from 'supertest';
import { EventSource } from 'eventsource';

describe('SSE Notifications (e2e)', () => {
  let app: INestApplication;
  let authToken: string;

  beforeAll(async () => {
    // Initialize app and get auth token
  });

  it('should establish SSE connection', (done) => {
    const eventSource = new EventSource(`http://localhost:3000/notifications/stream?token=${authToken}`);

    eventSource.onopen = () => {
      expect(eventSource.readyState).toBe(EventSource.OPEN);
      eventSource.close();
      done();
    };

    eventSource.onerror = (error) => {
      eventSource.close();
      done(error);
    };
  });

  it('should receive notifications', (done) => {
    const eventSource = new EventSource(`http://localhost:3000/notifications/stream?token=${authToken}`);

    eventSource.onmessage = (event) => {
      const data = JSON.parse(event.data);
      expect(data).toHaveProperty('title');
      expect(data).toHaveProperty('message');
      eventSource.close();
      done();
    };

    // Trigger notification
    setTimeout(() => {
      request(app.getHttpServer())
        .post('/orders')
        .set('Authorization', `Bearer ${authToken}`)
        .send({ items: [] })
        .expect(201);
    }, 100);
  });
});

🚨 Common Pitfalls & Solutions​

ProblemSolution
Connection dropsImplement heartbeat mechanism (ping every 30s)
Load balancer issuesEnable sticky sessions or use Redis pub/sub
Memory leaksProperly clean up event listeners and connections
Browser limitsMaximum 6 connections per domain - use single SSE connection
CORS errorsConfigure proper CORS headers on SSE endpoint
AuthenticationPass token via query parameter (EventSource doesn't support headers)
BufferingDisable proxy buffering for SSE endpoints
ScalabilityUse Redis pub/sub for multi-instance deployments

🎯 Best Practices​

  1. Connection Management

    • Limit concurrent connections per user
    • Implement connection timeout and cleanup
    • Use heartbeat to detect stale connections

  2. Message Format

    • Use consistent event types and data structure
    • Include event ID for replay capability
    • Add timestamp for client-side ordering

  3. Error Handling

    • Implement automatic reconnection with exponential backoff
    • Handle connection errors gracefully
    • Log all connection events for debugging

  4. Performance

    • Use Redis pub/sub for horizontal scaling
    • Implement message batching for high-frequency updates
    • Monitor connection count and message throughput

  5. Security

    • Always authenticate SSE connections
    • Validate user authorization for events
    • Implement rate limiting
    • Use HTTPS in production

Summary​

Server-Sent Events provide an efficient, standardized way to implement real-time notifications in web applications. By combining SSE with Redis pub/sub, NestJS microservices, and proper load balancing, you can build a scalable, production-ready notification system that works seamlessly across multiple backend instances.
