API Versioning and Deprecation Policy Guide

Overview​

Proper API versioning and deprecation policies are essential for maintaining backward compatibility while evolving microservices. This guide covers versioning strategies, deprecation workflows, migration paths, and communication best practices for managing API lifecycle changes.

API Versioning Strategies​

Comparison of Versioning Approaches​

URI Versioning (Recommended)​

// Most common and recommended approach
// Pros: Simple, visible, cacheable, documentation-friendly
// Cons: Multiple endpoints, URL pollution

// v1/users.controller.ts
@Controller('api/v1/users')
export class UsersV1Controller {
  @Get()
  async findAll(): Promise<UserV1Dto[]> {
    // V1 implementation
    return this.usersService.findAllV1();
  }

  @Get(':id')
  async findOne(@Param('id') id: string): Promise<UserV1Dto> {
    return this.usersService.findOneV1(id);
  }
}

// v2/users.controller.ts
@Controller('api/v2/users')
export class UsersV2Controller {
  @Get()
  async findAll(@Query() query: PaginationDto): Promise<PaginatedResponse<UserV2Dto>> {
    // V2 implementation with pagination
    return this.usersService.findAllV2(query);
  }

  @Get(':id')
  async findOne(@Param('id') id: string): Promise<UserV2Dto> {
    return this.usersService.findOneV2(id);
  }
}

Header Versioning​

// Uses custom headers or Accept header
// Pros: Clean URLs, flexible, standard-compliant
// Cons: Not visible in URL, harder to test in browser

// Decorator for version extraction
export const ApiVersion = createParamDecorator((data: unknown, ctx: ExecutionContext): string => {
  const request = ctx.switchToHttp().getRequest();
  const version = request.headers['api-version'] || request.headers['accept']?.match(/version=(\d+)/)?.[1] || '1';
  return version;
});

// Single controller with version handling
@Controller('api/users')
export class UsersController {
  @Get()
  async findAll(@ApiVersion() version: string): Promise<any> {
    if (version === '2') {
      return this.usersService.findAllV2();
    }
    return this.usersService.findAllV1();
  }
}

// Middleware to validate version
@Injectable()
export class ApiVersionMiddleware implements NestMiddleware {
  use(req: Request, res: Response, next: NextFunction) {
    const version = req.headers['api-version'];

    if (version && !['1', '2'].includes(version)) {
      throw new BadRequestException('Unsupported API version');
    }

    next();
  }
}

Content Negotiation​

// Uses Accept header with media type versioning
// Pros: RESTful, flexible, standard-compliant
// Cons: Complex, harder to document

@Controller('api/users')
export class UsersController {
  @Get()
  @Header('Vary', 'Accept')
  async findAll(@Headers('accept') accept: string): Promise<any> {
    if (accept.includes('application/vnd.api.v2+json')) {
      return this.usersService.findAllV2();
    }

    if (accept.includes('application/vnd.api.v1+json')) {
      return this.usersService.findAllV1();
    }

    // Default to latest
    return this.usersService.findAllV2();
  }
}

Semantic Versioning for APIs​

Versioning Rules​

/**
 * Semantic Versioning: MAJOR.MINOR.PATCH
 *
 * MAJOR version (v1, v2, v3):
 * - Breaking changes that require client updates
 * - Changes to request/response structure
 * - Removal of endpoints or fields
 *
 * MINOR version (v1.1, v1.2):
 * - New features that are backward compatible
 * - New optional fields
 * - New endpoints
 *
 * PATCH version (v1.1.1, v1.1.2):
 * - Bug fixes
 * - Performance improvements
 * - Internal changes
 */

export interface ApiVersionInfo {
  version: string; // "2.1.0"
  releaseDate: Date;
  deprecationDate?: Date;
  sunsetDate?: Date;
  status: 'current' | 'deprecated' | 'retired';
  breakingChanges: string[];
  newFeatures: string[];
}

// Version info endpoint
@Controller('api')
export class ApiInfoController {
  @Get('versions')
  getVersions(): ApiVersionInfo[] {
    return [
      {
        version: '2.1.0',
        releaseDate: new Date('2024-01-15'),
        status: 'current',
        breakingChanges: [],
        newFeatures: ['Pagination support', 'Filtering'],
      },
      {
        version: '1.0.0',
        releaseDate: new Date('2023-01-01'),
        deprecationDate: new Date('2024-01-15'),
        sunsetDate: new Date('2024-07-15'),
        status: 'deprecated',
        breakingChanges: [],
        newFeatures: [],
      },
    ];
  }
}

Data Transformation Between Versions​

// shared/transformers/user-v1.transformer.ts
@Injectable()
export class UserV1Transformer {
  toDto(user: User): UserV1Dto {
    return {
      id: user.id,
      name: `${user.firstName} ${user.lastName}`, // Combined in V1
      email: user.email,
      created: user.createdAt.toISOString(),
    };
  }

  fromDto(dto: UserV1Dto): Partial<User> {
    const [firstName, ...lastNameParts] = dto.name.split(' ');
    return {
      firstName,
      lastName: lastNameParts.join(' '),
      email: dto.email,
    };
  }
}

// shared/transformers/user-v2.transformer.ts
@Injectable()
export class UserV2Transformer {
  toDto(user: User): UserV2Dto {
    return {
      id: user.id,
      firstName: user.firstName, // Separated in V2
      lastName: user.lastName,
      email: user.email,
      metadata: {
        createdAt: user.createdAt.toISOString(),
        updatedAt: user.updatedAt.toISOString(),
      },
    };
  }

  fromDto(dto: UserV2Dto): Partial<User> {
    return {
      firstName: dto.firstName,
      lastName: dto.lastName,
      email: dto.email,
    };
  }
}

// modules/users/shared/users-base.service.ts
@Injectable()
export class UsersBaseService {
  constructor(
    @InjectRepository(User)
    private usersRepository: Repository<User>,
  ) {}

  // Shared business logic
  async findById(id: string): Promise<User> {
    return this.usersRepository.findOneOrFail({ where: { id } });
  }

  async create(userData: Partial<User>): Promise<User> {
    const user = this.usersRepository.create(userData);
    return this.usersRepository.save(user);
  }

  async update(id: string, userData: Partial<User>): Promise<User> {
    await this.usersRepository.update(id, userData);
    return this.findById(id);
  }
}

@Injectable()
export class UsersV1Service {

    private baseService: UsersBaseService,
    @Inject('USER_TRANSFORMER') private transformer: UserV1Transformer,
  ) {}

    const users = await this.baseService.findAll();
    return users.map((user) => this.transformer.toDto(user));
  }
}

// modules/users/v2/users-v2.service.ts
@Injectable()

  ) {}

    const users = await this.baseService.findAllPaginated(pagination);
    return {
      data: users.data.map((user) => this.transformer.toDto(user)),
      meta: users.meta,
    };
  }
}

Deprecation Interceptor​

// shared/deprecation/deprecation.interceptor.ts
import { Injectable, NestInterceptor, ExecutionContext, CallHandler, Logger } from '@nestjs/common';
import { Observable } from 'rxjs';
import { tap } from 'rxjs/operators';

@Injectable()
export class DeprecationInterceptor implements NestInterceptor {
  private readonly logger = new Logger(DeprecationInterceptor.name);

  constructor(private readonly version: string, private readonly policy: DeprecationPolicy) {}

  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    const response = context.switchToHttp().getResponse();
    const request = context.switchToHttp().getRequest();

    const now = new Date();
    const daysUntilSunset = Math.floor((this.policy.sunsetDate.getTime() - now.getTime()) / (1000 * 60 * 60 * 24));

    // Add deprecation headers
    response.setHeader('X-API-Deprecated', 'true');
    response.setHeader('X-API-Deprecation-Date', this.policy.deprecationDate.toISOString());
    response.setHeader('X-API-Sunset-Date', this.policy.sunsetDate.toISOString());
    response.setHeader('X-API-Days-Until-Sunset', daysUntilSunset.toString());
    response.setHeader('X-API-Migration-Guide', this.policy.migrationGuideUrl);

    // Add warning header (RFC 7234)
    response.setHeader(
      'Warning',
      `299 - "This API version is deprecated and will be removed on ${this.policy.sunsetDate.toISOString()}"`,
    );

    // Log usage for analytics
    this.logger.warn({
      message: 'Deprecated API version accessed',
      version: this.version,
      path: request.path,
      method: request.method,
      userAgent: request.headers['user-agent'],
      ip: request.ip,
      daysUntilSunset,
    });

    return next.handle();
  }
}

// Apply to V1 controllers
@Controller('api/v1/users')
@UseInterceptors(
  new DeprecationInterceptor(
    'v1',
    DEPRECATION_POLICIES.find((p) => p.version === 'v1'),
  ),
)
export class UsersV1Controller {
  // ... controller methods
}

Sunset Middleware​

// shared/deprecation/sunset.middleware.ts
import { Injectable, NestMiddleware, HttpException, HttpStatus } from '@nestjs/common';
import { Request, Response, NextFunction } from 'express';

@Injectable()
export class SunsetMiddleware implements NestMiddleware {
  constructor(private readonly policies: DeprecationPolicy[]) {}

  use(req: Request, res: Response, next: NextFunction) {
    // Extract version from URL
    const versionMatch = req.path.match(/\/api\/(v\d+)\//);

    if (!versionMatch) {
      return next();
    }

    const version = versionMatch[1];
    const policy = this.policies.find((p) => p.version === version);

    if (!policy) {
      return next();
    }

    const now = new Date();

    // Block requests after sunset date
    if (now > policy.sunsetDate) {
      throw new HttpException(
        {
          statusCode: HttpStatus.GONE,
          message: `API version ${version} has been sunset and is no longer available`,
          deprecationDate: policy.deprecationDate,
          sunsetDate: policy.sunsetDate,
          migrationGuide: policy.migrationGuideUrl,
          supportContact: policy.supportContactEmail,
        },
        HttpStatus.GONE,
      );
    }

    next();
  }
}

Breaking vs Non-Breaking Changes​

Breaking Changes (Require New Major Version)​

/**
 * BREAKING CHANGES - Require new major version (v1 → v2)
 */

// ❌ Removing a field
// V1
interface UserV1 {
  id: string;
  name: string;
  email: string;
  phone: string; // Removed in V2
}

// V2
interface UserV2 {
  id: string;
  name: string;
  email: string;
  // phone removed - BREAKING
}

// ❌ Changing field type
// V1
interface OrderV1 {
  totalAmount: number; // cents
}

// V2
interface OrderV2 {
  totalAmount: string; // decimal string - BREAKING
}

// ❌ Renaming fields
// V1
interface ProductV1 {
  productId: string;
}

// V2
interface ProductV2 {
  id: string; // renamed from productId - BREAKING
}

// ❌ Making optional field required
// V1
interface CreateUserV1 {
  email: string;
  phone?: string; // optional
}

// V2
interface CreateUserV2 {
  email: string;
  phone: string; // now required - BREAKING
}

// ❌ Changing URL structure
// V1: GET /api/v1/users/123/orders
// V2: GET /api/v2/orders?userId=123 - BREAKING

// ❌ Removing endpoints
// V1: DELETE /api/v1/users/:id
// V2: Endpoint removed - BREAKING

Non-Breaking Changes (Same Version)​

/**
 * NON-BREAKING CHANGES - Can be done in same version
 */

// ✅ Adding optional fields
interface UserV1 {
  id: string;
  name: string;
  email: string;
  avatarUrl?: string; // new optional field - OK
}

// ✅ Adding new endpoints
// Existing: GET /api/v1/users
// New: GET /api/v1/users/search - OK

// ✅ Adding new query parameters (optional)
// Existing: GET /api/v1/users
// Enhanced: GET /api/v1/users?filter=active - OK

// ✅ Relaxing validation (making required field optional)
interface CreateUserV1Before {
  email: string;
  phone: string;
}

interface CreateUserV1After {
  email: string;
  phone?: string; // now optional - OK
}

// ✅ Adding new optional headers
// New header: X-Request-ID (optional) - OK

// ✅ Bug fixes that don't change contract
// Fix: Return 404 instead of 500 for not found - OK

// ✅ Performance improvements
// Optimize query without changing response - OK

Change Detection​

// shared/versioning/change-detector.ts
@Injectable()
export class ApiChangeDetector {
  detectBreakingChanges(oldSchema: any, newSchema: any): BreakingChange[] {
    const changes: BreakingChange[] = [];

    // Check for removed fields
    const removedFields = this.findRemovedFields(oldSchema, newSchema);
    changes.push(...removedFields);

    // Check for type changes
    const typeChanges = this.findTypeChanges(oldSchema, newSchema);
    changes.push(...typeChanges);

    // Check for required field additions
    const newRequiredFields = this.findNewRequiredFields(oldSchema, newSchema);
    changes.push(...newRequiredFields);

    return changes;
  }

  private findRemovedFields(oldSchema: any, newSchema: any): BreakingChange[] {
    const changes: BreakingChange[] = [];

    for (const field of Object.keys(oldSchema.properties || {})) {
      if (!newSchema.properties?.[field]) {
        changes.push({
          type: 'FIELD_REMOVED',
          field,
          severity: 'BREAKING',
          description: `Field '${field}' was removed`,
        });
      }
    }

    return changes;
  }

  // ... other detection methods
}

Migration Helper Service​

// shared/migration/migration-helper.service.ts
@Injectable()
export class MigrationHelperService {
  private readonly logger = new Logger(MigrationHelperService.name);

  /**
   * Track which clients are using which versions
   */
  async trackVersionUsage(clientId: string, version: string, endpoint: string): Promise<void> {
    await this.analyticsService.track({
      event: 'api_version_usage',
      properties: {
        clientId,
        version,
        endpoint,
        timestamp: new Date(),
      },
    });
  }

  /**
   * Get migration status for a client
   */
  async getMigrationStatus(clientId: string): Promise<MigrationStatus> {
    const usageData = await this.analyticsService.query({
      event: 'api_version_usage',
      filters: { clientId },
      timeRange: '30d',
    });

    const versionsUsed = new Set(usageData.map((d) => d.properties.version));

    return {
      clientId,
      versionsUsed: Array.from(versionsUsed),
      currentVersion: this.getCurrentVersion(),
      recommendedVersion: this.getRecommendedVersion(),
      migrationRequired: versionsUsed.has('v1'),
      daysUntilSunset: this.getDaysUntilSunset('v1'),
    };
  }

  /**
   * Send migration reminders
   */
  async sendMigrationReminders(): Promise<void> {
    const clients = await this.getClientsUsingDeprecatedVersions();

    for (const client of clients) {
      const status = await this.getMigrationStatus(client.id);

      if (status.daysUntilSunset <= 30) {
        await this.notificationService.send({
          to: client.email,
          template: 'urgent_migration_reminder',
          data: {
            version: 'v1',
            daysRemaining: status.daysUntilSunset,
            migrationGuide: this.getMigrationGuideUrl('v1'),
          },
        });
      }
    }
  }
}

Gradual Migration with Feature Flags​

// shared/migration/feature-flag.service.ts
@Injectable()
export class FeatureFlagService {
  constructor(private configService: ConfigService) {}

  /**
   * Check if client should use new version
   */
  shouldUseV2(clientId: string): boolean {
    // Gradual rollout: 10% -> 50% -> 100%
    const rolloutPercentage = this.configService.get('V2_ROLLOUT_PERCENTAGE', 0);
    const clientHash = this.hashClientId(clientId);

    return clientHash % 100 < rolloutPercentage;
  }

  private hashClientId(clientId: string): number {
    let hash = 0;
    for (let i = 0; i < clientId.length; i++) {
      hash = (hash << 5) - hash + clientId.charCodeAt(i);
      hash = hash & hash;
    }
    return Math.abs(hash);
  }
}

// Usage in controller
@Controller('api/users')
export class UsersController {
  @Get()
  async findAll(@Headers('x-client-id') clientId: string): Promise<any> {
    if (this.featureFlags.shouldUseV2(clientId)) {
      return this.usersV2Service.findAll();
    }
    return this.usersV1Service.findAll();
  }
}

Version Usage Analytics​

// shared/analytics/version-analytics.service.ts
@Injectable()
export class VersionAnalyticsService {
  private readonly logger = new Logger(VersionAnalyticsService.name);

  constructor(
    private metricsService: MetricsService,
    @InjectRepository(ApiUsageLog)
    private usageLogRepository: Repository<ApiUsageLog>,
  ) {}

  async trackRequest(version: string, endpoint: string, clientId: string, responseTime: number): Promise<void> {
    // Log to database
    await this.usageLogRepository.save({
      version,
      endpoint,
      clientId,
      responseTime,
      timestamp: new Date(),
    });

    // Track metrics
    this.metricsService.recordApiCall(version, endpoint, responseTime);
  }

  async getVersionUsageReport(days: number = 30): Promise<VersionUsageReport> {
    const startDate = new Date();
    startDate.setDate(startDate.getDate() - days);

    const usageData = await this.usageLogRepository
      .createQueryBuilder('log')
      .select('log.version', 'version')
      .addSelect('COUNT(*)', 'requestCount')
      .addSelect('COUNT(DISTINCT log.clientId)', 'uniqueClients')
      .addSelect('AVG(log.responseTime)', 'avgResponseTime')
      .where('log.timestamp >= :startDate', { startDate })
      .groupBy('log.version')
      .getRawMany();

    return {
      periodDays: days,
      versions: usageData.map((data) => ({
        version: data.version,
        requestCount: parseInt(data.requestCount),
        uniqueClients: parseInt(data.uniqueClients),
        avgResponseTime: parseFloat(data.avgResponseTime),
      })),
    };
  }

  async getClientsByVersion(version: string): Promise<ClientInfo[]> {
    const clients = await this.usageLogRepository
      .createQueryBuilder('log')
      .select('log.clientId', 'clientId')
      .addSelect('MAX(log.timestamp)', 'lastSeen')
      .addSelect('COUNT(*)', 'requestCount')
      .where('log.version = :version', { version })
      .andWhere('log.timestamp >= :cutoff', {
        cutoff: new Date(Date.now() - 30 * 24 * 60 * 60 * 1000),
      })
      .groupBy('log.clientId')
      .getRawMany();

    return clients.map((c) => ({
      clientId: c.clientId,
      lastSeen: new Date(c.lastSeen),
      requestCount: parseInt(c.requestCount),
    }));
  }

  /**
   * Alert when deprecated version usage is high
   */
  @Cron(CronExpression.EVERY_DAY_AT_9AM)
  async checkDeprecatedVersionUsage(): Promise<void> {
    const report = await this.getVersionUsageReport(7);
    const v1Usage = report.versions.find((v) => v.version === 'v1');

    if (v1Usage && v1Usage.requestCount > 10000) {
      await this.alertService.send({
        severity: 'warning',
        title: 'High usage of deprecated API v1',
        message: `V1 API received ${v1Usage.requestCount} requests in the last 7 days from ${v1Usage.uniqueClients} clients`,
        action: 'Review migration status and contact clients',
      });
    }
  }
}

// Prometheus metrics for version tracking
@Injectable()
export class ApiVersionMetrics {
  private requestCounter = new Counter({
    name: 'api_requests_total',
    help: 'Total API requests by version',
    labelNames: ['version', 'endpoint', 'status'],
  });

  private responseTimeHistogram = new Histogram({
    name: 'api_response_time_seconds',
    help: 'API response time by version',
    labelNames: ['version', 'endpoint'],
    buckets: [0.1, 0.5, 1, 2, 5],
  });

  private deprecatedVersionGauge = new Gauge({
    name: 'api_deprecated_version_clients',
    help: 'Number of clients using deprecated versions',
    labelNames: ['version'],
  });

  recordRequest(version: string, endpoint: string, status: number): void {
    this.requestCounter.inc({ version, endpoint, status: status.toString() });
  }

  recordResponseTime(version: string, endpoint: string, durationSeconds: number): void {
    this.responseTimeHistogram.observe({ version, endpoint }, durationSeconds);
  }

  updateDeprecatedVersionClients(version: string, count: number): void {
    this.deprecatedVersionGauge.set({ version }, count);
  }
}

Best Practices​

1. Version Strategy​

✅ Do:

  • Use URI versioning for simplicity and visibility
  • Version only when breaking changes occur
  • Support at least 2 versions simultaneously
  • Plan deprecation timeline (6-12 months)
  • Document all changes clearly

❌ Don't:

  • Version for every minor change
  • Support more than 3 versions at once
  • Break backward compatibility without warning
  • Use different versioning strategies in same API
  • Forget to sunset old versions

2. Deprecation Process​

✅ Do:

  • Announce deprecation at least 6 months in advance
  • Add deprecation headers to responses
  • Send email notifications to API consumers
  • Provide migration guides and examples
  • Monitor usage of deprecated versions
  • Offer migration support

❌ Don't:

  • Remove versions without warning
  • Skip deprecation period
  • Ignore clients still using old versions
  • Forget to update documentation
  • Remove endpoints on deprecation date

3. Communication​

✅ Do:

  • Maintain a public changelog
  • Send deprecation emails
  • Update API documentation
  • Provide migration examples
  • Offer developer support
  • Create migration guides

❌ Don't:

  • Communicate only through code
  • Assume clients will discover changes
  • Skip release notes
  • Use technical jargon in communications
  • Forget to notify stakeholders

4. Testing​

✅ Do:

  • Test all versions independently
  • Verify backward compatibility
  • Test migration paths
  • Monitor version-specific errors
  • Load test each version

❌ Don't:

  • Test only the latest version
  • Skip regression testing
  • Ignore version-specific bugs
  • Forget edge cases
  • Deploy without testing migration

5. Monitoring​

✅ Do:

  • Track version usage metrics
  • Monitor deprecated version usage
  • Alert on high deprecated usage
  • Track client migration progress
  • Measure API performance by version

❌ Don't:

  • Deploy without analytics
  • Ignore usage patterns
  • Skip client identification
  • Forget to alert on anomalies
  • Sunset without verifying client migration

Summary​

Effective API versioning and deprecation provides:

  • Backward Compatibility - Existing clients continue working
  • Smooth Evolution - Introduce changes without breaking clients
  • Clear Communication - Clients know what to expect
  • Managed Sunset - Graceful retirement of old versions
  • Better Developer Experience - Clear migration paths

Key implementation points:

  • Use URI versioning (recommended)
  • Follow semantic versioning principles
  • Maintain clear deprecation policy (6+ months)
  • Communicate changes proactively
  • Monitor version usage analytics
  • Provide migration guides and support
  • Test all versions thoroughly
  • Sunset old versions responsibly

Remember: Good API versioning is about balancing innovation with stability!
