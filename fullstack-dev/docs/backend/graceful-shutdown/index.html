Graceful Shutdown in Node.js

Overview​

Graceful shutdown is a critical pattern for Node.js applications, especially in microservices architectures, that ensures your application properly completes ongoing operations and releases resources before terminating. This guide covers implementing graceful shutdown in NestJS microservices deployed on Kubernetes.

Why Graceful Shutdown Matters​

In production environments, applications need to handle shutdown signals properly to:

  • Complete In-Flight Requests: Finish processing active HTTP requests and background jobs
  • Close Database Connections: Prevent connection leaks and data corruption
  • Release Resources: Clean up file handles, network sockets, and message queue connections
  • Prevent Data Loss: Ensure all pending writes are flushed
  • Zero-Downtime Deployments: Enable seamless rolling updates in Kubernetes
  • Maintain Service Health: Avoid cascading failures in microservices

Understanding Shutdown Signals​

Common Signals​

SignalDescriptionSourceDefault Action
SIGTERMTermination signalKubernetes, Docker, process managersGraceful termination
SIGINTInterrupt signalCtrl+C in terminalGraceful termination
SIGKILLKill signalCannot be caughtImmediate termination
SIGQUITQuit signalCtrl+\ in terminalDump core and quit
SIGHUPHangup signalTerminal closedReload configuration

Advanced Graceful Shutdown with Custom Cleanup​

// main.ts
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { Logger } from '@nestjs/common';

const logger = new Logger('Bootstrap');

async function bootstrap() {
  const app = await NestFactory.create(AppModule, {
    logger: ['error', 'warn', 'log', 'debug'],
  });

  // Enable graceful shutdown
  app.enableShutdownHooks();

  // Track active connections
  let isShuttingDown = false;

  // Setup shutdown handlers
  const gracefulShutdown = async (signal: string) => {
    if (isShuttingDown) {
      logger.warn(`${signal} received again, forcing shutdown...`);
      process.exit(1);
    }

    isShuttingDown = true;
    logger.log(`${signal} received, starting graceful shutdown...`);

    try {
      // Stop accepting new connections
      await app.close();
      logger.log('Application closed successfully');
      process.exit(0);
    } catch (error) {
      logger.error('Error during shutdown:', error);
      process.exit(1);
    }
  };

  // Register signal handlers
  process.on('SIGTERM', () => gracefulShutdown('SIGTERM'));
  process.on('SIGINT', () => gracefulShutdown('SIGINT'));

  await app.listen(3000);
  logger.log(`Application is running on port 3000`);
}

HTTP Server Graceful Shutdown​

Express with Connection Tracking​

// main.ts
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { Logger } from '@nestjs/common';
import * as http from 'http';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  const logger = new Logger('Bootstrap');

  // Track active connections
  const connections = new Set<http.Socket>();
  let isShuttingDown = false;

  await app.init();
  const server = app.getHttpServer() as http.Server;

  // Track connections
  server.on('connection', (socket: http.Socket) => {
    connections.add(socket);
    socket.on('close', () => {
      connections.delete(socket);
    });
  });

  const gracefulShutdown = async () => {
    if (isShuttingDown) return;
    isShuttingDown = true;

    logger.log('Graceful shutdown initiated');
    logger.log(`Active connections: ${connections.size}`);

    // Stop accepting new connections
    server.close(async () => {
      logger.log('Server closed, no new connections accepted');

      try {
        await app.close();
        logger.log('Application closed successfully');
        process.exit(0);
      } catch (error) {
        logger.error('Error during shutdown:', error);
        process.exit(1);
      }
    });

    // Force close idle connections after timeout
    setTimeout(() => {
      logger.warn(`Forcing closure of ${connections.size} remaining connections`);
      connections.forEach((socket) => socket.destroy());
      process.exit(1);
    }, 30000); // 30 seconds
  };

  process.on('SIGTERM', gracefulShutdown);
  process.on('SIGINT', gracefulShutdown);

  await app.listen(3000);
  logger.log('Application started on port 3000');
}

bootstrap();

Kafka Consumer Graceful Shutdown​

// kafka/kafka.service.ts
import { Injectable, OnApplicationShutdown, Logger } from '@nestjs/common';
import { Kafka, Consumer } from 'kafkajs';

@Injectable()
export class KafkaService implements OnApplicationShutdown {
  private readonly logger = new Logger(KafkaService.name);
  private consumer: Consumer;
  private isShuttingDown = false;

  constructor() {
    const kafka = new Kafka({
      clientId: 'my-app',
      brokers: ['kafka:9092'],
    });

    this.consumer = kafka.consumer({ groupId: 'my-group' });
  }

  async onApplicationShutdown(signal?: string) {
    if (this.isShuttingDown) return;
    this.isShuttingDown = true;

    this.logger.log(`Shutting down Kafka consumer (${signal})`);

    try {
      // Stop consuming messages
      await this.consumer.pause([{ topic: 'my-topic' }]);
      this.logger.log('Kafka consumer paused');

      // Wait for in-flight messages to complete (with timeout)
      await this.waitForInFlightMessages(10000);

      // Disconnect consumer
      await this.consumer.disconnect();
      this.logger.log('Kafka consumer disconnected successfully');
    } catch (error) {
      this.logger.error('Error during Kafka shutdown:', error);
      throw error;
    }
  }

  private async waitForInFlightMessages(timeout: number): Promise<void> {
    return new Promise((resolve) => {
      const startTime = Date.now();
      const checkInterval = setInterval(() => {
        // Check if all messages are processed
        // This is application-specific logic
        const hasInFlightMessages = false; // Your logic here

        if (!hasInFlightMessages || Date.now() - startTime > timeout) {
          clearInterval(checkInterval);
          resolve();
        }
      }, 100);
    });
  }
}

Health Checks During Shutdown​

// health/health.controller.ts
import { Controller, Get } from '@nestjs/common';
import { HealthCheck, HealthCheckService, TypeOrmHealthIndicator } from '@nestjs/terminus';
import { ShutdownService } from './shutdown.service';

@Controller('health')
export class HealthController {
  constructor(
    private health: HealthCheckService,
    private db: TypeOrmHealthIndicator,
    private shutdownService: ShutdownService,
  ) {}

  @Get()
  @HealthCheck()
  check() {
    return this.health.check([() => this.db.pingCheck('database'), () => this.shutdownService.isHealthy()]);
  }

  @Get('ready')
  ready() {
    // Return 503 if shutting down
    if (this.shutdownService.isShuttingDown()) {
      throw new Error('Application is shutting down');
    }
    return { status: 'ready' };
  }

  @Get('live')
  live() {
    // Always return 200 unless process is dead
    return { status: 'live' };
  }
}

// shutdown.service.ts

      },
    };
  }

          livenessProbe:
            httpGet:
              path: /health/live
              port: 3000
            initialDelaySeconds: 30
            periodSeconds: 10
            timeoutSeconds: 5
            failureThreshold: 3

          # Readiness probe - checks if container can accept traffic
          readinessProbe:
            httpGet:
              path: /health/ready
              port: 3000
            initialDelaySeconds: 10
            periodSeconds: 5
            timeoutSeconds: 3
            failureThreshold: 3

          # Startup probe - for slow starting applications
          startupProbe:
            httpGet:
              path: /health/live
              port: 3000
            initialDelaySeconds: 0
            periodSeconds: 5
            timeoutSeconds: 3
            failureThreshold: 30

          # PreStop hook - runs before SIGTERM
          lifecycle:
            preStop:
              exec:
                command: ['/bin/sh', '-c', 'sleep 15']

          resources:
            requests:
              memory: '256Mi'
              cpu: '250m'
            limits:
              memory: '512Mi'
              cpu: '500m'

Why PreStop Hook?​

The preStop hook with sleep 15 gives time for:

  1. Kubernetes Service to remove the pod from its endpoints
  2. Load balancer to stop routing traffic to the pod
  3. Client connections to drain naturally

This prevents the "race condition" where SIGTERM is sent before all traffic is drained.

Advanced Patterns​

Graceful Shutdown with Worker Pool​

// worker/worker-pool.service.ts
import { Injectable, OnApplicationShutdown, Logger } from '@nestjs/common';

interface Job {
  id: string;
  execute: () => Promise<void>;
}

@Injectable()
export class WorkerPoolService implements OnApplicationShutdown {
  private readonly logger = new Logger(WorkerPoolService.name);
  private readonly activeJobs = new Map<string, Promise<void>>();
  private isShuttingDown = false;

  async executeJob(job: Job): Promise<void> {
    if (this.isShuttingDown) {
      throw new Error('Worker pool is shutting down');
    }

    const jobPromise = job.execute();
    this.activeJobs.set(job.id, jobPromise);

    try {
      await jobPromise;
    } finally {
      this.activeJobs.delete(job.id);
    }
  }

  async onApplicationShutdown(signal?: string) {
    this.isShuttingDown = true;
    this.logger.log(`Shutting down worker pool (${signal})`);
    this.logger.log(`Active jobs: ${this.activeJobs.size}`);

    if (this.activeJobs.size === 0) {
      this.logger.log('No active jobs, shutdown complete');
      return;
    }

    // Wait for all jobs to complete
    try {
      await Promise.all(this.activeJobs.values());
      this.logger.log('All jobs completed successfully');
    } catch (error) {
      this.logger.error('Some jobs failed during shutdown:', error);
      throw error;
    }
  }
}

Graceful Shutdown with Timeout​

// shutdown/shutdown-manager.service.ts
import { Injectable, Logger } from '@nestjs/common';

interface ShutdownTask {
  name: string;
  handler: () => Promise<void>;
  timeout?: number;
}

@Injectable()
export class ShutdownManager {
  private readonly logger = new Logger(ShutdownManager.name);
  private readonly tasks: ShutdownTask[] = [];

  registerTask(task: ShutdownTask) {
    this.tasks.push(task);
  }

  async executeShutdown(signal: string): Promise<void> {
    this.logger.log(`Starting graceful shutdown (${signal})`);
    this.logger.log(`Registered shutdown tasks: ${this.tasks.length}`);

    const results = await Promise.allSettled(this.tasks.map((task) => this.executeTask(task)));

    const failed = results.filter((r) => r.status === 'rejected');

    if (failed.length > 0) {
      this.logger.error(`${failed.length} shutdown tasks failed`);
      throw new Error('Shutdown failed');
    }

    this.logger.log('All shutdown tasks completed successfully');
  }

  private async executeTask(task: ShutdownTask): Promise<void> {
    const timeout = task.timeout || 30000;
    this.logger.log(`Executing shutdown task: ${task.name}`);

    const timeoutPromise = new Promise<never>((_, reject) => {
      setTimeout(() => reject(new Error(`Task ${task.name} timed out`)), timeout);
    });

    try {
      await Promise.race([task.handler(), timeoutPromise]);
      this.logger.log(`Task completed: ${task.name}`);
    } catch (error) {
      this.logger.error(`Task failed: ${task.name}`, error);
      throw error;
    }
  }
}

Using Shutdown Manager​

// main.ts
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { ShutdownManager } from './shutdown/shutdown-manager.service';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  const shutdownManager = app.get(ShutdownManager);

  // Register shutdown tasks
  shutdownManager.registerTask({
    name: 'HTTP Server',
    handler: async () => {
      await app.close();
    },
    timeout: 30000,
  });

  // Setup signal handlers
  const handleShutdown = async (signal: string) => {
    try {
      await shutdownManager.executeShutdown(signal);
      process.exit(0);
    } catch (error) {
      console.error('Shutdown failed:', error);
      process.exit(1);
    }
  };

  process.on('SIGTERM', () => handleShutdown('SIGTERM'));
  process.on('SIGINT', () => handleShutdown('SIGINT'));

  await app.listen(3000);
}

bootstrap();

Best Practices​

1. Set Appropriate Timeouts​

// Good: Reasonable timeouts
const SHUTDOWN_TIMEOUT = 30000; // 30 seconds
const CONNECTION_DRAIN_TIMEOUT = 20000; // 20 seconds
const JOB_COMPLETION_TIMEOUT = 25000; // 25 seconds

// Bad: Too short or too long
const SHUTDOWN_TIMEOUT = 5000; // May not be enough
const SHUTDOWN_TIMEOUT = 300000; // Too long (5 minutes)

2. Use Structured Logging​

// Good: Structured logs
logger.log({
  message: 'Graceful shutdown initiated',
  signal,
  activeConnections: connections.size,
  activeTasks: tasks.length,
  timestamp: new Date().toISOString(),
});

// Bad: Unstructured logs
logger.log('Shutdown started');

3. Handle Shutdown Idempotently​

// Good: Idempotent shutdown
private isShuttingDown = false;

async onApplicationShutdown(signal?: string) {
  if (this.isShuttingDown) {
    this.logger.warn('Shutdown already in progress');
    return;
  }
  this.isShuttingDown = true;
  // ... shutdown logic
}

4. Implement Health Check Changes​

// Update readiness probe to fail during shutdown
@Get('health/ready')
ready() {
  if (this.shutdownService.isShuttingDown()) {
    throw new ServiceUnavailableException('Shutting down');
  }
  return { status: 'ready' };
}

5. Kubernetes Configuration Alignment​

# Ensure grace period > shutdown timeout
terminationGracePeriodSeconds: 60  # Kubernetes timeout

# In your code
const SHUTDOWN_TIMEOUT = 50000;  # 50s - less than Kubernetes

Common Pitfalls​

❌ Not Handling SIGTERM​

// Bad: No signal handlers
async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  await app.listen(3000);
}

✅ Proper Signal Handling​

// Good: Handle signals
async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  app.enableShutdownHooks();

  process.on('SIGTERM', async () => {
    await app.close();
    process.exit(0);
  });

  await app.listen(3000);
}

❌ Ignoring In-Flight Requests​

// Bad: Immediate shutdown
process.on('SIGTERM', () => {
  process.exit(0); // Kills in-flight requests
});

✅ Waiting for Completion​

// Good: Wait for requests to complete
process.on('SIGTERM', async () => {
  server.close(async () => {
    await app.close();
    process.exit(0);
  });
});

import { Injectable } from '@nestjs/common';
import { Counter, Histogram } from 'prom-client';

@Injectable()

  });

  private readonly shutdownDuration = new Histogram({
    name: 'app_shutdown_duration_seconds',
    help: 'Time taken to complete graceful shutdown',
    labelNames: ['signal'],

    this.shutdownCounter.inc({ signal, status });
  }

  recordDuration(signal: string, duration: number) {
    this.shutdownDuration.observe({ signal }, duration);
  }
}

import { Logger } from '@nestjs/common';
import { ShutdownManager } from './shutdown/shutdown-manager.service';
import { ShutdownMetrics } from './metrics/shutdown.metrics';

async function bootstrap() {
  const logger = new Logger('Bootstrap');
  const app = await NestFactory.create(AppModule);

  // Enable shutdown hooks
  app.enableShutdownHooks();

  // Get services
  const shutdownManager = app.get(ShutdownManager);
  const metrics = app.get(ShutdownMetrics);

  // Track if shutdown is in progress
  let isShuttingDown = false;

  // Register shutdown tasks
  shutdownManager.registerTask({
    name: 'HTTP Server',
    handler: async () => {
      logger.log('Closing HTTP server...');
      await app.close();
    },
    timeout: 30000,
  });

  // Graceful shutdown handler
  const handleShutdown = async (signal: string) => {
    if (isShuttingDown) {
      logger.warn(`${signal} received again, forcing exit`);
      process.exit(1);
    }

    isShuttingDown = true;
    const startTime = Date.now();

    logger.log(`${signal} received, starting graceful shutdown`);

    try {
      await shutdownManager.executeShutdown(signal);

      const duration = (Date.now() - startTime) / 1000;
      metrics.recordShutdown(signal, 'success');
      metrics.recordDuration(signal, duration);

      logger.log(`Graceful shutdown completed in ${duration}s`);
      process.exit(0);
    } catch (error) {
      metrics.recordShutdown(signal, 'failure');
      logger.error('Graceful shutdown failed:', error);
      process.exit(1);
    }
  };

  // Register signal handlers
  process.on('SIGTERM', () => handleShutdown('SIGTERM'));
  process.on('SIGINT', () => handleShutdown('SIGINT'));

  // Handle uncaught errors
  process.on('uncaughtException', (error) => {
    logger.error('Uncaught exception:', error);
    handleShutdown('UNCAUGHT_EXCEPTION');
  });

  process.on('unhandledRejection', (reason, promise) => {
    logger.error('Unhandled rejection at:', promise, 'reason:', reason);
    handleShutdown('UNHANDLED_REJECTION');
  });

  await app.listen(3000);
  logger.log('Application started successfully on port 3000');
}

bootstrap().catch((error) => {
  console.error('Failed to start application:', error);
  process.exit(1);
});

Conclusion​

Graceful shutdown is essential for production-ready Node.js applications. Key takeaways:

  1. Always handle SIGTERM and SIGINT signals - These are how Kubernetes and Docker terminate your application
  2. Close resources in order - Stop accepting new work, complete in-flight operations, then close connections
  3. Set appropriate timeouts - Balance between completing work and not blocking deployments
  4. Update health checks - Ensure Kubernetes stops routing traffic before shutdown
  5. Monitor shutdown metrics - Track shutdown duration and success rates
  6. Test thoroughly - Verify behavior under load and in Kubernetes

Implementing graceful shutdown ensures:

  • ✅ Zero-downtime deployments
  • ✅ No data loss
  • ✅ Better user experience
  • ✅ Reduced error rates
  • ✅ Easier debugging and operations
