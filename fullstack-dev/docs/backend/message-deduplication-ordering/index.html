Message Deduplication & Ordering Guide

Overview​

Message deduplication and ordering are critical concerns in distributed message-driven systems. This guide covers idempotency patterns, deduplication strategies, message ordering guarantees, exactly-once processing, and conflict resolution for building reliable microservices with Kafka, RabbitMQ, and other message brokers.

Message Deduplication Fundamentals​

Why Message Deduplication?​

Common Causes of Duplicates:

  • Network failures and retries
  • Producer timeouts
  • Broker replication
  • Consumer rebalancing
  • At-least-once delivery semantics

Impact of Duplicates:

  • Incorrect data (double charges, inventory issues)
  • Violated business rules
  • Inconsistent state
  • Downstream cascade effects

Deduplication vs Idempotency​

Deduplication: Preventing duplicate messages from being processed Idempotency: Processing duplicates safely (same result)

// Deduplication - Detect and skip duplicates
if (await this.isDuplicate(messageId)) {
  return; // Skip processing
}
await this.processMessage(message);

// Idempotency - Process safely
await this.processIdempotently(message); // Same result if repeated

Idempotency Service​

// services/idempotency.service.ts
import { Injectable, Logger, ConflictException } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import { IdempotentOperation } from '../entities/idempotent-operation.entity';

@Injectable()
export class IdempotencyService {
  private readonly logger = new Logger(IdempotencyService.name);

  constructor(
    @InjectRepository(IdempotentOperation)
    private idempotentOpsRepository: Repository<IdempotentOperation>,
  ) {}

  /**
   * Execute operation idempotently
   */
  async executeIdempotently<T>(
    idempotencyKey: string,
    clientId: string,
    operationType: string,
    requestPayload: any,
    operation: () => Promise<T>,
  ): Promise<T> {
    // Check if operation already exists
    const existing = await this.idempotentOpsRepository.findOne({
      where: { idempotencyKey },
    });

    if (existing) {
      return this.handleExistingOperation<T>(existing, requestPayload);
    }

    // Create new operation record
    const idempotentOp = this.idempotentOpsRepository.create({
      idempotencyKey,
      clientId,
      operationType,
      requestPayload,
      status: 'processing',
      processingAttempts: 1,
    });

    await this.idempotentOpsRepository.save(idempotentOp);

    try {
      // Execute the operation
      const result = await operation();

      // Mark as completed
      idempotentOp.status = 'completed';
      idempotentOp.responsePayload = result;
      idempotentOp.completedAt = new Date();
      await this.idempotentOpsRepository.save(idempotentOp);

      this.logger.log(`Idempotent operation ${idempotencyKey} completed successfully`);

      return result;
    } catch (error) {
      // Mark as failed
      idempotentOp.status = 'failed';
      idempotentOp.errorMessage = error.message;
      await this.idempotentOpsRepository.save(idempotentOp);

      this.logger.error(`Idempotent operation ${idempotencyKey} failed: ${error.message}`);

      throw error;
    }
  }

  private async handleExistingOperation<T>(existing: IdempotentOperation, requestPayload: any): Promise<T> {
    // Check if request payload matches (idempotency key collision detection)
    if (JSON.stringify(existing.requestPayload) !== JSON.stringify(requestPayload)) {
      throw new ConflictException(`Idempotency key collision: same key with different payload`);
    }

    // If completed, return cached result
    if (existing.status === 'completed') {
      this.logger.log(`Returning cached result for idempotency key ${existing.idempotencyKey}`);
      return existing.responsePayload as T;
    }

    // If processing, wait or throw error
    if (existing.status === 'processing') {
      throw new ConflictException(`Operation ${existing.idempotencyKey} is currently being processed`);
    }

    // If failed, allow retry
    if (existing.status === 'failed') {
      existing.status = 'processing';
      existing.processingAttempts++;
      await this.idempotentOpsRepository.save(existing);

      throw new Error(`Previous attempt failed. Retry attempt ${existing.processingAttempts}`);
    }

    throw new Error(`Unknown operation status: ${existing.status}`);
  }

  /**
   * Clean up old idempotent operations
   */
  async cleanupOldOperations(daysToKeep: number = 30): Promise<number> {
    const cutoffDate = new Date();
    cutoffDate.setDate(cutoffDate.getDate() - daysToKeep);

    const result = await this.idempotentOpsRepository
      .createQueryBuilder()
      .delete()
      .where('completedAt < :cutoffDate', { cutoffDate })
      .andWhere('status = :status', { status: 'completed' })
      .execute();

    this.logger.log(`Cleaned up ${result.affected} idempotent operations older than ${daysToKeep} days`);

    return result.affected;
  }
}

Idempotent Message Handler​

// handlers/idempotent-message.handler.ts
import { Injectable, Logger } from '@nestjs/common';
import { IdempotencyService } from '../services/idempotency.service';

@Injectable()
export class IdempotentMessageHandler {
  private readonly logger = new Logger(IdempotentMessageHandler.name);

  constructor(private idempotencyService: IdempotencyService) {}

  /**
   * Handle message with idempotency guarantee
   */
  async handleMessage(message: any): Promise<void> {
    const idempotencyKey = message.messageId || message.id;
    const clientId = message.userId || message.clientId || 'system';
    const operationType = message.type || 'unknown';

    await this.idempotencyService.executeIdempotently(idempotencyKey, clientId, operationType, message, async () => {
      // Actual message processing logic
      return this.processMessage(message);
    });
  }

  private async processMessage(message: any): Promise<any> {
    this.logger.log(`Processing message: ${JSON.stringify(message)}`);

    // Business logic here
    switch (message.type) {
      case 'order.created':
        return this.handleOrderCreated(message);
      case 'payment.processed':
        return this.handlePaymentProcessed(message);
      default:
        throw new Error(`Unknown message type: ${message.type}`);
    }
  }

  private async handleOrderCreated(message: any): Promise<any> {
    // Process order creation idempotently
    return { orderId: message.orderId, status: 'created' };
  }

  private async handlePaymentProcessed(message: any): Promise<any> {
    // Process payment idempotently
    return { paymentId: message.paymentId, status: 'processed' };
  }
}

Deduplication Strategies​

Message Deduplication Service​

// services/message-deduplication.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { Redis } from 'ioredis';
import { InjectRedis } from '@nestjs-modules/ioredis';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';

export interface DeduplicationConfig {
  strategy: 'redis' | 'database' | 'bloom-filter';
  ttlSeconds: number;
  namespace: string;
}

@Entity('processed_messages')
@Index(['messageId', 'processedAt'])
export class ProcessedMessage {
  @PrimaryColumn()
  messageId: string;

  @Column()
  messageType: string;

  @Column('jsonb')
  messagePayload: any;

  @Column()
  processorId: string;

  @CreateDateColumn()
  processedAt: Date;

  @Column('timestamp')
  expiresAt: Date;
}

@Injectable()
export class MessageDeduplicationService {
  private readonly logger = new Logger(MessageDeduplicationService.name);
  private readonly bloomFilter = new Map<string, Set<string>>(); // Simple in-memory bloom filter

  constructor(
    @InjectRedis() private readonly redis: Redis,
    @InjectRepository(ProcessedMessage)
    private processedMessagesRepository: Repository<ProcessedMessage>,
  ) {}

  /**
   * Check if message has been processed (Redis strategy)
   */
  async isDuplicateRedis(messageId: string, namespace: string, ttlSeconds: number): Promise<boolean> {
    const key = `dedup:${namespace}:${messageId}`;
    const exists = await this.redis.exists(key);

    if (exists) {
      this.logger.warn(`Duplicate message detected: ${messageId}`);
      return true;
    }

    // Mark as processed
    await this.redis.setex(key, ttlSeconds, '1');
    return false;
  }

  /**
   * Check if message has been processed (Database strategy)
   */
  async isDuplicateDatabase(
    messageId: string,
    messageType: string,
    processorId: string,
    ttlSeconds: number,
  ): Promise<boolean> {
    const existing = await this.processedMessagesRepository.findOne({
      where: { messageId },
    });

    if (existing) {
      this.logger.warn(`Duplicate message detected: ${messageId}`);
      return true;
    }

    // Mark as processed
    const expiresAt = new Date();
    expiresAt.setSeconds(expiresAt.getSeconds() + ttlSeconds);

    await this.processedMessagesRepository.save({
      messageId,
      messageType,
      messagePayload: {},
      processorId,
      expiresAt,
    });

    return false;
  }

  /**
   * Check if message has been processed (Bloom Filter strategy)
   */
  isDuplicateBloomFilter(messageId: string, namespace: string): boolean {
    if (!this.bloomFilter.has(namespace)) {
      this.bloomFilter.set(namespace, new Set());
    }

    const filter = this.bloomFilter.get(namespace);

    if (filter.has(messageId)) {
      this.logger.warn(`Duplicate message detected (bloom filter): ${messageId}`);
      return true;
    }

    filter.add(messageId);
    return false;
  }

  /**
   * Generic deduplication check
   */
  async isDuplicate(
    messageId: string,
    config: DeduplicationConfig,
    messageType?: string,
    processorId?: string,
  ): Promise<boolean> {
    switch (config.strategy) {
      case 'redis':
        return this.isDuplicateRedis(messageId, config.namespace, config.ttlSeconds);

      case 'database':
        return this.isDuplicateDatabase(
          messageId,
          messageType || 'unknown',
          processorId || 'default',
          config.ttlSeconds,
        );

      case 'bloom-filter':
        return this.isDuplicateBloomFilter(messageId, config.namespace);

      default:
        throw new Error(`Unknown deduplication strategy: ${config.strategy}`);
    }
  }

  /**
   * Clean up expired processed messages
   */
  async cleanupExpiredMessages(): Promise<number> {
    const result = await this.processedMessagesRepository
      .createQueryBuilder()
      .delete()
      .where('expiresAt < :now', { now: new Date() })
      .execute();

    this.logger.log(`Cleaned up ${result.affected} expired processed messages`);
    return result.affected;
  }

  /**
   * Reset bloom filter (for testing or periodic cleanup)
   */
  resetBloomFilter(namespace?: string): void {
    if (namespace) {
      this.bloomFilter.delete(namespace);
    } else {
      this.bloomFilter.clear();
    }
    this.logger.log(`Bloom filter reset for namespace: ${namespace || 'all'}`);
  }
}

Message Consumer with Deduplication​

// consumers/deduplicated-message.consumer.ts
import { Injectable, Logger, OnModuleInit } from '@nestjs/common';
import { Kafka, Consumer, EachMessagePayload } from 'kafkajs';
import { ConfigService } from '@nestjs/config';
import { MessageDeduplicationService } from '../services/message-deduplication.service';
import { IdempotentMessageHandler } from '../handlers/idempotent-message.handler';

@Injectable()
export class DeduplicatedMessageConsumer implements OnModuleInit {
  private readonly logger = new Logger(DeduplicatedMessageConsumer.name);
  private consumer: Consumer;
  private readonly kafka: Kafka;

  constructor(
    private configService: ConfigService,
    private deduplicationService: MessageDeduplicationService,
    private messageHandler: IdempotentMessageHandler,
  ) {
    this.kafka = new Kafka({
      clientId: 'deduplicated-consumer',
      brokers: this.configService.get('KAFKA_BROKERS').split(','),
    });
  }

  async onModuleInit() {
    this.consumer = this.kafka.consumer({
      groupId: 'deduplicated-consumer-group',
      sessionTimeout: 30000,
      heartbeatInterval: 3000,
    });

    await this.consumer.connect();
    await this.consumer.subscribe({
      topics: ['orders', 'payments'],
      fromBeginning: false,
    });

    await this.consumer.run({
      eachMessage: async (payload) => this.handleMessage(payload),
    });

    this.logger.log('Deduplicated message consumer started');
  }

  private async handleMessage(payload: EachMessagePayload): Promise<void> {
    const { topic, partition, message } = payload;
    const messageId = message.key?.toString() || message.headers?.messageId?.toString();

    if (!messageId) {
      this.logger.error('Message without ID received - cannot deduplicate');
      return;
    }

    try {
      // Check for duplicates
      const isDuplicate = await this.deduplicationService.isDuplicate(
        messageId,
        {
          strategy: 'redis',
          ttlSeconds: 3600, // 1 hour
          namespace: topic,
        },
        topic,
        'kafka-consumer',
      );

      if (isDuplicate) {
        this.logger.warn(`Skipping duplicate message ${messageId} from topic ${topic}`);
        return;
      }

      // Process message idempotently
      const parsedMessage = JSON.parse(message.value.toString());
      await this.messageHandler.handleMessage({
        ...parsedMessage,
        messageId,
        topic,
        partition,
      });

      this.logger.log(`Successfully processed message ${messageId}`);
    } catch (error) {
      this.logger.error(`Error processing message ${messageId}: ${error.message}`, error.stack);
      throw error;
    }
  }

  async onModuleDestroy() {
    await this.consumer.disconnect();
  }
}

Sequential Message Processor​

// services/sequential-message-processor.service.ts
import { Injectable, Logger } from '@nestjs/common';

export interface SequentialMessage {
  messageId: string;
  sequenceNumber: number;
  partitionKey: string;
  payload: any;
}

interface PartitionState {
  lastProcessedSequence: number;
  pendingMessages: Map<number, SequentialMessage>;
}

@Injectable()
export class SequentialMessageProcessorService {
  private readonly logger = new Logger(SequentialMessageProcessorService.name);
  private readonly partitionStates = new Map<string, PartitionState>();

  /**
   * Process message in sequence order
   */
  async processInSequence(
    message: SequentialMessage,
    processor: (msg: SequentialMessage) => Promise<void>,
  ): Promise<void> {
    const { partitionKey, sequenceNumber } = message;

    // Initialize partition state if needed
    if (!this.partitionStates.has(partitionKey)) {
      this.partitionStates.set(partitionKey, {
        lastProcessedSequence: 0,
        pendingMessages: new Map(),
      });
    }

    const state = this.partitionStates.get(partitionKey);

    // Check if this is the next expected sequence
    const expectedSequence = state.lastProcessedSequence + 1;

    if (sequenceNumber === expectedSequence) {
      // Process this message
      await processor(message);
      state.lastProcessedSequence = sequenceNumber;

      this.logger.log(
        `Processed message ${message.messageId} in sequence (${sequenceNumber}) for partition ${partitionKey}`,
      );

      // Process any pending messages that are now in sequence
      await this.processPendingMessages(partitionKey, processor);
    } else if (sequenceNumber > expectedSequence) {
      // Future message - store for later
      state.pendingMessages.set(sequenceNumber, message);

      this.logger.warn(
        `Message ${message.messageId} arrived out of order. Expected ${expectedSequence}, got ${sequenceNumber}. Storing for later.`,
      );
    } else {
      // Old message - already processed or duplicate
      this.logger.warn(
        `Message ${message.messageId} with sequence ${sequenceNumber} is older than last processed ${state.lastProcessedSequence}. Skipping.`,
      );
    }
  }

  private async processPendingMessages(
    partitionKey: string,
    processor: (msg: SequentialMessage) => Promise<void>,
  ): Promise<void> {
    const state = this.partitionStates.get(partitionKey);

    while (true) {
      const nextSequence = state.lastProcessedSequence + 1;
      const nextMessage = state.pendingMessages.get(nextSequence);

      if (!nextMessage) {
        break; // No more sequential messages
      }

      // Process the next message
      await processor(nextMessage);
      state.lastProcessedSequence = nextSequence;
      state.pendingMessages.delete(nextSequence);

      this.logger.log(`Processed pending message ${nextMessage.messageId} in sequence (${nextSequence})`);
    }

    // Check for gaps (missing messages)
    if (state.pendingMessages.size > 0) {
      const minPending = Math.min(...state.pendingMessages.keys());
      const gap = minPending - state.lastProcessedSequence;

      if (gap > 10) {
        this.logger.error(
          `Large gap detected in partition ${partitionKey}. Last processed: ${state.lastProcessedSequence}, next pending: ${minPending}. Gap: ${gap}`,
        );
      }
    }
  }

  /**
   * Get partition state for monitoring
   */
  getPartitionState(partitionKey: string): {
    lastProcessed: number;
    pendingCount: number;
    pendingSequences: number[];
  } {
    const state = this.partitionStates.get(partitionKey);

    if (!state) {
      return {
        lastProcessed: 0,
        pendingCount: 0,
        pendingSequences: [],
      };
    }

    return {
      lastProcessed: state.lastProcessedSequence,
      pendingCount: state.pendingMessages.size,
      pendingSequences: Array.from(state.pendingMessages.keys()).sort((a, b) => a - b),
    };
  }

  /**
   * Clean up partition state
   */
  cleanupPartition(partitionKey: string): void {
    this.partitionStates.delete(partitionKey);
    this.logger.log(`Cleaned up partition state for ${partitionKey}`);
  }
}

Version-Based Ordering​

// services/version-based-ordering.service.ts
import { Injectable, Logger } from '@nestjs/common';

export interface VersionedMessage {
  entityId: string;
  version: number;
  timestamp: Date;
  payload: any;
}

interface EntityState {
  currentVersion: number;
  pendingVersions: Map<number, VersionedMessage>;
  lastUpdated: Date;
}

@Injectable()
export class VersionBasedOrderingService {
  private readonly logger = new Logger(VersionBasedOrderingService.name);
  private readonly entityStates = new Map<string, EntityState>();

  /**
   * Process message based on version
   */
  async processWithVersionCheck(
    message: VersionedMessage,
    processor: (msg: VersionedMessage) => Promise<void>,
  ): Promise<void> {
    const { entityId, version } = message;

    // Initialize entity state if needed
    if (!this.entityStates.has(entityId)) {
      this.entityStates.set(entityId, {
        currentVersion: 0,
        pendingVersions: new Map(),
        lastUpdated: new Date(0),
      });
    }

    const state = this.entityStates.get(entityId);

    // Check if this is the next expected version
    const expectedVersion = state.currentVersion + 1;

    if (version === expectedVersion) {
      // Process this version
      await processor(message);
      state.currentVersion = version;
      state.lastUpdated = message.timestamp;

      this.logger.log(`Processed message for entity ${entityId} at version ${version}`);

      // Process any pending versions that are now ready
      await this.processPendingVersions(entityId, processor);
    } else if (version > expectedVersion) {
      // Future version - store for later
      state.pendingVersions.set(version, message);

      this.logger.warn(
        `Message for entity ${entityId} arrived with future version ${version}. Expected ${expectedVersion}. Storing for later.`,
      );
    } else {
      // Old version - check timestamp for conflict resolution
      if (message.timestamp > state.lastUpdated) {
        this.logger.warn(
          `Message for entity ${entityId} with old version ${version} but newer timestamp. Current version: ${state.currentVersion}`,
        );
        // Optionally handle conflict
      } else {
        this.logger.warn(`Ignoring old message for entity ${entityId}. Version ${version} < ${state.currentVersion}`);
      }
    }
  }

  private async processPendingVersions(
    entityId: string,
    processor: (msg: VersionedMessage) => Promise<void>,
  ): Promise<void> {
    const state = this.entityStates.get(entityId);

    while (true) {
      const nextVersion = state.currentVersion + 1;
      const nextMessage = state.pendingVersions.get(nextVersion);

      if (!nextMessage) {
        break;
      }

      await processor(nextMessage);
      state.currentVersion = nextVersion;
      state.lastUpdated = nextMessage.timestamp;
      state.pendingVersions.delete(nextVersion);

      this.logger.log(`Processed pending message for entity ${entityId} at version ${nextVersion}`);
    }
  }

  /**
   * Get entity state
   */
  getEntityState(entityId: string): {
    currentVersion: number;
    pendingCount: number;
    pendingVersions: number[];
  } {
    const state = this.entityStates.get(entityId);

    if (!state) {
      return {
        currentVersion: 0,
        pendingCount: 0,
        pendingVersions: [],
      };
    }

    return {
      currentVersion: state.currentVersion,
      pendingCount: state.pendingVersions.size,
      pendingVersions: Array.from(state.pendingVersions.keys()).sort((a, b) => a - b),
    };
  }
}

// services/transactional-outbox.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository, EntityManager } from 'typeorm';
import { OutboxMessage } from '../entities/outbox.entity';

@Injectable()
export class TransactionalOutboxService {
  private readonly logger = new Logger(TransactionalOutboxService.name);

  constructor(
    @InjectRepository(OutboxMessage)
    private outboxRepository: Repository<OutboxMessage>,
  ) {}

  /**
   * Save business entity and outbox message in single transaction
   */
  async saveWithOutbox<T>(
    entityManager: EntityManager,
    entity: T,
    entityRepository: Repository<T>,
    outboxData: {
      aggregateId: string;
      aggregateType: string;
      eventType: string;
      payload: any;
    },
  ): Promise<{ entity: T; outboxMessage: OutboxMessage }> {
    // Save entity
    const savedEntity = await entityManager.save(entityRepository.target, entity);

    // Save outbox message in same transaction
    const outboxMessage = entityManager.create(OutboxMessage, {
      ...outboxData,
      status: 'pending',
    });

    const savedOutboxMessage = await entityManager.save(OutboxMessage, outboxMessage);

    this.logger.log(`Saved entity and outbox message in transaction for aggregate ${outboxData.aggregateId}`);

    return {
      entity: savedEntity,
      outboxMessage: savedOutboxMessage,
    };
  }

  /**
   * Get pending outbox messages for publishing
   */
  async getPendingMessages(limit: number = 100): Promise<OutboxMessage[]> {
    return this.outboxRepository.find({
      where: { status: 'pending' },
      order: { createdAt: 'ASC' },
      take: limit,
    });
  }

  /**
   * Mark message as sent
   */
  async markAsSent(messageId: string): Promise<void> {
    await this.outboxRepository.update(messageId, {
      status: 'sent',
      sentAt: new Date(),
    });
  }

  /**
   * Mark message as failed
   */
  async markAsFailed(messageId: string): Promise<void> {
    await this.outboxRepository
      .createQueryBuilder()
      .update(OutboxMessage)
      .set({
        status: 'failed',
        retryCount: () => 'retryCount + 1',
      })
      .where('id = :id', { id: messageId })
      .execute();
  }
}

Outbox Publisher​

// services/outbox-publisher.service.ts
import { Injectable, Logger, OnModuleInit } from '@nestjs/common';
import { Cron, CronExpression } from '@nestjs/schedule';
import { Kafka, Producer } from 'kafkajs';
import { ConfigService } from '@nestjs/config';
import { TransactionalOutboxService } from './transactional-outbox.service';

@Injectable()
export class OutboxPublisherService implements OnModuleInit {
  private readonly logger = new Logger(OutboxPublisherService.name);
  private producer: Producer;
  private readonly kafka: Kafka;

  constructor(private configService: ConfigService, private outboxService: TransactionalOutboxService) {
    this.kafka = new Kafka({
      clientId: 'outbox-publisher',
      brokers: this.configService.get('KAFKA_BROKERS').split(','),
    });
  }

  async onModuleInit() {
    this.producer = this.kafka.producer({
      idempotent: true,
      maxInFlightRequests: 5,
      transactionalId: 'outbox-publisher-tx',
    });

    await this.producer.connect();
    this.logger.log('Outbox publisher connected');
  }

  /**
   * Publish pending outbox messages every 5 seconds
   */
  @Cron(CronExpression.EVERY_5_SECONDS)
  async publishPendingMessages(): Promise<void> {
    const pendingMessages = await this.outboxService.getPendingMessages(100);

    if (pendingMessages.length === 0) {
      return;
    }

    this.logger.log(`Publishing ${pendingMessages.length} pending outbox messages`);

    for (const message of pendingMessages) {
      try {
        await this.producer.send({
          topic: message.eventType,
          messages: [
            {
              key: message.aggregateId,
              value: JSON.stringify(message.payload),
              headers: {
                'message-id': message.id,
                'aggregate-type': message.aggregateType,
                'event-type': message.eventType,
              },
            },
          ],
        });

        await this.outboxService.markAsSent(message.id);

        this.logger.log(`Published outbox message ${message.id} to topic ${message.eventType}`);
      } catch (error) {
        this.logger.error(`Failed to publish outbox message ${message.id}: ${error.message}`);
        await this.outboxService.markAsFailed(message.id);
      }
    }
  }

  async onModuleDestroy() {
    await this.producer.disconnect();
  }
}

// services/kafka-ordering.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { Kafka, Producer, CompressionTypes } from 'kafkajs';
import { ConfigService } from '@nestjs/config';

@Injectable()
export class KafkaOrderingService {
  private readonly logger = new Logger(KafkaOrderingService.name);
  private producer: Producer;
  private readonly kafka: Kafka;

  constructor(private configService: ConfigService) {
    this.kafka = new Kafka({
      clientId: 'ordered-producer',
      brokers: this.configService.get('KAFKA_BROKERS').split(','),
    });

    this.producer = this.kafka.producer({
      // Idempotent producer ensures no duplicates
      idempotent: true,
      // Max in-flight requests = 1 ensures strict ordering per partition
      maxInFlightRequests: 1,
      // Enable transaction support for exactly-once
      transactionalId: 'ordered-producer-tx',
    });
  }

  async onModuleInit() {
    await this.producer.connect();
    this.logger.log('Kafka ordered producer connected');
  }

  /**
   * Send message with partition key for ordering guarantee
   */
  async sendOrdered(
    topic: string,
    message: {
      partitionKey: string; // Messages with same key go to same partition
      data: any;
      sequenceNumber?: number;
    },
  ): Promise<void> {
    try {
      const result = await this.producer.send({
        topic,
        compression: CompressionTypes.GZIP,
        messages: [
          {
            // Partition key ensures ordering
            key: message.partitionKey,
            value: JSON.stringify({
              ...message.data,
              sequenceNumber: message.sequenceNumber,
            }),
            headers: {
              'partition-key': message.partitionKey,
              'sequence-number': message.sequenceNumber?.toString() || '0',
              timestamp: Date.now().toString(),
            },
          },
        ],
      });

      this.logger.log(
        `Sent ordered message to ${topic}, partition ${result[0].partition}, offset ${result[0].baseOffset}`,
      );
    } catch (error) {
      this.logger.error(`Failed to send ordered message: ${error.message}`);
      throw error;
    }
  }

  /**
   * Send batch with transaction for exactly-once
   */
  async sendBatchTransactional(topic: string, messages: Array<{ partitionKey: string; data: any }>): Promise<void> {
    const transaction = await this.producer.transaction();

    try {
      for (const message of messages) {
        await transaction.send({
          topic,
          messages: [
            {
              key: message.partitionKey,
              value: JSON.stringify(message.data),
            },
          ],
        });
      }

      await transaction.commit();
      this.logger.log(`Committed transaction with ${messages.length} messages`);
    } catch (error) {
      await transaction.abort();
      this.logger.error(`Transaction aborted: ${error.message}`);
      throw error;
    }
  }

  async onModuleDestroy() {
    await this.producer.disconnect();
  }
}

Single Partition Consumer for Strict Ordering​

// consumers/single-partition.consumer.ts
import { Injectable, Logger, OnModuleInit } from '@nestjs/common';
import { Kafka, Consumer, EachMessagePayload } from 'kafkajs';
import { ConfigService } from '@nestjs/config';
import { SequentialMessageProcessorService, SequentialMessage } from '../services/sequential-message-processor.service';

@Injectable()
export class SinglePartitionConsumer implements OnModuleInit {
  private readonly logger = new Logger(SinglePartitionConsumer.name);
  private consumer: Consumer;
  private readonly kafka: Kafka;

  constructor(private configService: ConfigService, private sequentialProcessor: SequentialMessageProcessorService) {
    this.kafka = new Kafka({
      clientId: 'single-partition-consumer',
      brokers: this.configService.get('KAFKA_BROKERS').split(','),
    });
  }

  async onModuleInit() {
    this.consumer = this.kafka.consumer({
      groupId: 'single-partition-consumer-group',
      // Process messages one at a time per partition
      maxInFlightRequests: 1,
      sessionTimeout: 30000,
    });

    await this.consumer.connect();

    // Subscribe to specific partition for strict ordering
    await this.consumer.subscribe({
      topic: 'orders',
      fromBeginning: false,
    });

    await this.consumer.run({
      // Process each partition sequentially
      partitionsConsumedConcurrently: 1,
      eachMessage: async (payload) => this.handleMessage(payload),
    });

    this.logger.log('Single partition consumer started');
  }

  private async handleMessage(payload: EachMessagePayload): Promise<void> {
    const { topic, partition, message } = payload;
    const partitionKey = message.key?.toString() || 'unknown';
    const sequenceNumber = parseInt(message.headers?.['sequence-number']?.toString() || '0');

    const sequentialMessage: SequentialMessage = {
      messageId: `${topic}-${partition}-${message.offset}`,
      sequenceNumber,
      partitionKey,
      payload: JSON.parse(message.value.toString()),
    };

    await this.sequentialProcessor.processInSequence(sequentialMessage, async (msg) => {
      // Actual processing logic
      this.logger.log(`Processing message in order: partition=${partition}, sequence=${msg.sequenceNumber}`);
      // Business logic here
    });
  }

  async onModuleDestroy() {
    await this.consumer.disconnect();
  }
}

// services/rabbitmq-ordered.service.ts
import { Injectable, Logger, OnModuleInit } from '@nestjs/common';
import * as amqp from 'amqplib';
import { ConfigService } from '@nestjs/config';

@Injectable()
export class RabbitMQOrderedService implements OnModuleInit {
  private readonly logger = new Logger(RabbitMQOrderedService.name);
  private connection: amqp.Connection;
  private channel: amqp.Channel;

  constructor(private configService: ConfigService) {}

  async onModuleInit() {
    await this.connect();
    await this.setupOrderedQueue();
  }

  private async connect(): Promise<void> {
    this.connection = await amqp.connect(this.configService.get('RABBITMQ_URL'));
    this.channel = await this.connection.createChannel();

    // Set prefetch to 1 for strict ordering
    await this.channel.prefetch(1);

    this.logger.log('RabbitMQ ordered service connected');
  }

  private async setupOrderedQueue(): Promise<void> {
    // Create queue with single active consumer for ordering
    await this.channel.assertQueue('ordered-queue', {
      durable: true,
      arguments: {
        'x-single-active-consumer': true, // Only one consumer at a time
      },
    });
  }

  /**
   * Publish ordered message
   */
  async publishOrdered(queue: string, message: any, sequenceNumber: number): Promise<void> {
    const messageBuffer = Buffer.from(JSON.stringify(message));

    this.channel.sendToQueue(queue, messageBuffer, {
      persistent: true,
      headers: {
        'sequence-number': sequenceNumber,
        timestamp: Date.now(),
      },
      messageId: `${queue}-${sequenceNumber}`,
    });

    this.logger.log(`Published ordered message to ${queue} with sequence ${sequenceNumber}`);
  }

  /**
   * Consume with ordering guarantee
   */
  async consumeOrdered(
    queue: string,
    processor: (message: any, sequenceNumber: number) => Promise<void>,
  ): Promise<void> {
    await this.channel.consume(
      queue,
      async (msg) => {
        if (!msg) return;

        const sequenceNumber = parseInt(msg.properties.headers['sequence-number']?.toString() || '0');
        const content = JSON.parse(msg.content.toString());

        try {
          await processor(content, sequenceNumber);
          this.channel.ack(msg);

          this.logger.log(`Processed ordered message from ${queue} with sequence ${sequenceNumber}`);
        } catch (error) {
          this.logger.error(`Failed to process message: ${error.message}`);
          // Reject and requeue
          this.channel.nack(msg, false, true);
        }
      },
      {
        noAck: false,
        exclusive: true, // Exclusive consumer for ordering
      },
    );
  }

  async onModuleDestroy() {
    await this.channel.close();
    await this.connection.close();
  }
}

Conflict Resolution​

Last-Write-Wins Strategy​

// services/conflict-resolution.service.ts
import { Injectable, Logger } from '@nestjs/common';

export interface ConflictingMessage {
  entityId: string;
  version: number;
  timestamp: Date;
  payload: any;
}

@Injectable()
export class ConflictResolutionService {
  private readonly logger = new Logger(ConflictResolutionService.name);

  /**
   * Last-Write-Wins: Choose message with latest timestamp
   */
  lastWriteWins(current: ConflictingMessage, incoming: ConflictingMessage): ConflictingMessage {
    if (incoming.timestamp > current.timestamp) {
      this.logger.log(`LWW: Incoming message wins for entity ${incoming.entityId}`);
      return incoming;
    }

    this.logger.log(`LWW: Current message wins for entity ${current.entityId}`);
    return current;
  }

  /**
   * Version-Based: Choose message with higher version
   */
  versionBased(current: ConflictingMessage, incoming: ConflictingMessage): ConflictingMessage {
    if (incoming.version > current.version) {
      this.logger.log(`Version-based: Incoming message (v${incoming.version}) wins over current (v${current.version})`);
      return incoming;
    }

    this.logger.log(`Version-based: Current message (v${current.version}) wins over incoming (v${incoming.version})`);
    return current;
  }

  /**
   * Custom merge strategy
   */
  customMerge(
    current: ConflictingMessage,
    incoming: ConflictingMessage,
    mergeStrategy: (current: any, incoming: any) => any,
  ): ConflictingMessage {
    const mergedPayload = mergeStrategy(current.payload, incoming.payload);

    this.logger.log(`Custom merge applied for entity ${current.entityId}`);

    return {
      entityId: current.entityId,
      version: Math.max(current.version, incoming.version) + 1,
      timestamp: new Date(),
      payload: mergedPayload,
    };
  }

  /**
   * Detect conflicts
   */
  hasConflict(current: ConflictingMessage, incoming: ConflictingMessage): boolean {
    // Same version but different timestamps = conflict
    if (current.version === incoming.version) {
      const timeDiffMs = Math.abs(current.timestamp.getTime() - incoming.timestamp.getTime());

      // If messages are within 100ms, consider it a conflict
      if (timeDiffMs < 100) {
        this.logger.warn(
          `Conflict detected for entity ${current.entityId}: same version ${current.version}, timestamps differ by ${timeDiffMs}ms`,
        );
        return true;
      }
    }

    return false;
  }
}

Best Practices​

1. Message Deduplication​

✅ Do:

  • Use unique message IDs
  • Implement idempotent operations
  • Store processed message IDs with TTL
  • Use Redis for high-performance deduplication
  • Use database for audit trail
  • Clean up old deduplication records

❌ Don't:

  • Rely on message broker deduplication alone
  • Skip message ID generation
  • Store deduplication records forever
  • Ignore duplicate detection failures
  • Use only in-memory deduplication (not persistent)
  • Deploy without testing duplicate scenarios

2. Message Ordering​

✅ Do:

  • Use partition keys consistently
  • Set maxInFlightRequests=1 for strict ordering
  • Implement sequence numbers
  • Buffer out-of-order messages
  • Monitor ordering violations
  • Document ordering guarantees

❌ Don't:

  • Assume messages arrive in order
  • Process messages in parallel per partition
  • Ignore sequence numbers
  • Skip gap detection
  • Forget to handle reordering
  • Deploy without ordering tests

3. Idempotency​

✅ Do:

  • Design idempotent operations
  • Store operation results
  • Use idempotency keys
  • Handle concurrent requests
  • Implement optimistic locking
  • Test with duplicates

❌ Don't:

  • Assume exactly-once delivery
  • Skip idempotency checks
  • Perform side effects without guards
  • Ignore race conditions
  • Forget to handle failures
  • Deploy without duplicate testing

4. Exactly-Once Processing​

✅ Do:

  • Use transactional outbox pattern
  • Implement idempotent consumers
  • Use database transactions
  • Enable Kafka transactions
  • Monitor processing guarantees
  • Test failure scenarios

❌ Don't:

  • Rely solely on broker guarantees
  • Skip transaction boundaries
  • Mix transactional and non-transactional operations
  • Ignore partial failures
  • Forget to commit offsets correctly
  • Deploy without end-to-end testing

5. Conflict Resolution​

✅ Do:

  • Choose appropriate strategy (LWW, version-based)
  • Use vector clocks for distributed systems
  • Implement custom merge logic
  • Log all conflicts
  • Monitor conflict rate
  • Provide conflict resolution UI

❌ Don't:

  • Ignore conflicts
  • Always choose latest timestamp
  • Lose data during resolution
  • Skip conflict detection
  • Forget to notify users
  • Deploy without conflict handling

Summary​

Effective message deduplication and ordering provides:

  • Reliability - No duplicate processing
  • Consistency - Correct order of operations
  • Data Integrity - No lost or corrupted data
  • Idempotency - Safe retry operations
  • Exactly-Once - Guaranteed processing semantics

Key implementation points:

  • Idempotent operations with database tracking
  • Message deduplication (Redis, database, bloom filter)
  • Sequential message processing with buffering
  • Version-based ordering with conflict detection
  • Transactional outbox for exactly-once
  • Kafka partition keys for ordering
  • RabbitMQ single active consumer
  • Conflict resolution strategies (LWW, version-based, custom merge)
  • Comprehensive monitoring and gap detection
  • Proper cleanup of deduplication records

Remember: Design for at-least-once delivery and implement idempotency - it's simpler than exactly-once!
