Redis Bloom Filters & Probabilistic Data Structures

📖 Overview​

Redis Bloom (@redis/bloom) provides probabilistic data structures that are space-efficient and blazingly fast for large-scale applications. These data structures trade perfect accuracy for massive memory savings and performance gains.

🎯 What Are Bloom Filters?​

A Bloom filter is a space-efficient probabilistic data structure that tests whether an element is a member of a set. It can have false positives (says "yes" when answer is "no") but never false negatives (never says "no" when answer is "yes").

Key Characteristics​

  • ✅ Extremely fast - O(k) where k is number of hash functions
  • ✅ Space efficient - Uses bits instead of storing actual data
  • ✅ Scalable - Can handle billions of items
  • ❌ Probabilistic - Small false positive rate (configurable)
  • ❌ Cannot delete - Standard Bloom filters don't support removal

📊 Available Data Structures​

StructureUse CaseFalse PositivesDeletions
Bloom FilterMembership testingYesNo

Use Case 1: Prevent Duplicate Content Submissions​

Problem: Users submitting duplicate articles, preventing spam

// duplicate-content-filter.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { createClient, RedisClientType } from 'redis';
import { createHash } from 'crypto';

@Injectable()
export class DuplicateContentFilterService {
  private readonly logger = new Logger('DuplicateContentFilterService');
  private client: RedisClientType;
  private readonly filterKey = 'content:submitted';

  async onModuleInit() {
    this.client = createClient({
      url: process.env.REDIS_URL || 'redis://localhost:6379',
    });

    await this.client.connect();

    // Create Bloom filter with:
    // - Expected 10 million items
    // - 0.01% false positive rate (1 in 10,000)
    try {
      await this.client.bf.reserve(this.filterKey, 0.0001, 10000000);
      this.logger.log('Bloom filter created for duplicate content detection');
    } catch (error) {
      // Filter might already exist
      this.logger.log('Bloom filter already exists');
    }
  }

  /**
   * Check if content has been submitted before
   * Returns: true if possibly duplicate, false if definitely new
   */
  async isDuplicate(content: string): Promise<boolean> {
    const contentHash = this.hashContent(content);
    const exists = await this.client.bf.exists(this.filterKey, contentHash);

    if (exists) {
      this.logger.warn(`Potential duplicate content detected: ${contentHash}`);
    }

    return exists === 1;
  }

  /**
   * Mark content as submitted
   */
  async markAsSubmitted(content: string): Promise<void> {
    const contentHash = this.hashContent(content);
    await this.client.bf.add(this.filterKey, contentHash);
    this.logger.log(`Content marked as submitted: ${contentHash}`);
  }

  /**
   * Check and mark in single operation
   */
  async checkAndMark(content: string): Promise<boolean> {
    const contentHash = this.hashContent(content);

    // BF.MADD returns 1 if item was added, 0 if already existed
    const result = await this.client.bf.mAdd(this.filterKey, [contentHash]);

    const isDuplicate = result[0] === 0;

    if (isDuplicate) {
      this.logger.warn(`Duplicate submission blocked: ${contentHash}`);
    }

    return isDuplicate;
  }

  /**
   * Get filter statistics
   */
  async getStats(): Promise<any> {
    const info = await this.client.bf.info(this.filterKey);
    return {
      capacity: info.capacity,
      size: info.size,
      numberOfFilters: info.numberOfFilters,
      numberOfItemsInserted: info.numberOfItemsInserted,
      expansionRate: info.expansionRate,
    };
  }

  private hashContent(content: string): string {
    // Normalize content before hashing
    const normalized = content.toLowerCase().replace(/\s+/g, ' ').trim();

    return createHash('sha256').update(normalized).digest('hex');
  }
}

Usage in Controller:

@Post('articles')
async createArticle(@Body() createArticleDto: CreateArticleDto) {
  // Check for duplicate before processing
  const isDuplicate = await this.duplicateContentFilter.isDuplicate(
    createArticleDto.content,
  );

  if (isDuplicate) {
    // Could be false positive, so do a real database check
    const existingArticle = await this.articleService.findByContentHash(
      createArticleDto.content,
    );

    if (existingArticle) {
      throw new ConflictException('This article has already been submitted');
    }
  }

  // Create article
  const article = await this.articleService.create(createArticleDto);

  // Mark content as submitted
  await this.duplicateContentFilter.markAsSubmitted(createArticleDto.content);

  return article;
}

Use Case 2: Email Spam Detection​

// spam-detection.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { createClient, RedisClientType } from 'redis';

interface SpamScore {
  isSpam: boolean;
  confidence: number;
  reasons: string[];
}

@Injectable()
export class SpamDetectionService {
  private readonly logger = new Logger('SpamDetectionService');
  private client: RedisClientType;

  // Multiple filters for different spam indicators
  private readonly filters = {
    spamEmails: 'spam:emails',
    spamDomains: 'spam:domains',
    spamIPs: 'spam:ips',
    spamKeywords: 'spam:keywords',
  };

  async onModuleInit() {
    this.client = createClient({
      url: process.env.REDIS_URL || 'redis://localhost:6379',
    });

    await this.client.connect();

    // Initialize Bloom filters
    for (const [name, key] of Object.entries(this.filters)) {
      try {
        await this.client.bf.reserve(key, 0.001, 1000000);
        this.logger.log(`Spam filter initialized: ${name}`);
      } catch (error) {
        this.logger.log(`Spam filter already exists: ${name}`);
      }
    }
  }

  /**
   * Check if email is spam
   */
  async isSpam(email: string, domain: string, ipAddress: string, content: string): Promise<SpamScore> {
    const reasons: string[] = [];
    let spamIndicators = 0;

    // Check email
    if (await this.client.bf.exists(this.filters.spamEmails, email)) {
      reasons.push('Email address is in spam list');
      spamIndicators++;
    }

    // Check domain
    if (await this.client.bf.exists(this.filters.spamDomains, domain)) {
      reasons.push('Domain is in spam list');
      spamIndicators++;
    }

    // Check IP
    if (await this.client.bf.exists(this.filters.spamIPs, ipAddress)) {
      reasons.push('IP address is in spam list');
      spamIndicators++;
    }

    // Check for spam keywords
    const keywords = this.extractKeywords(content);
    const keywordChecks = await Promise.all(keywords.map((kw) => this.client.bf.exists(this.filters.spamKeywords, kw)));

    const spamKeywordsFound = keywordChecks.filter(Boolean).length;
    if (spamKeywordsFound > 0) {
      reasons.push(`Found ${spamKeywordsFound} spam keywords`);
      spamIndicators += spamKeywordsFound;
    }

    const confidence = Math.min(spamIndicators * 0.25, 1.0);
    const isSpam = confidence > 0.5;

    if (isSpam) {
      this.logger.warn(`Spam detected - Email: ${email}, Confidence: ${confidence}`);
    }

    return {
      isSpam,
      confidence,
      reasons,
    };
  }

  /**
   * Report spam (add to filters)
   */
  async reportSpam(email: string, domain: string, ipAddress: string, keywords?: string[]): Promise<void> {
    const operations = [
      this.client.bf.add(this.filters.spamEmails, email),
      this.client.bf.add(this.filters.spamDomains, domain),
      this.client.bf.add(this.filters.spamIPs, ipAddress),
    ];

    if (keywords && keywords.length > 0) {
      operations.push(...keywords.map((kw) => this.client.bf.add(this.filters.spamKeywords, kw)));
    }

    await Promise.all(operations);
    this.logger.log(`Spam reported: ${email}`);
  }

  private extractKeywords(content: string): string[] {
    // Simple keyword extraction (in production, use NLP)
    return content.toLowerCase().match(/\b\w{4,}\b/g) || [];
  }
}

Use Case 3: API Rate Limiting with Count-Min Sketch​

// advanced-rate-limiter.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { createClient, RedisClientType } from 'redis';

interface RateLimitInfo {
  allowed: boolean;
  remaining: number;
  resetAt: Date;
  estimatedCount: number;
}

@Injectable()
export class AdvancedRateLimiterService {
  private readonly logger = new Logger('AdvancedRateLimiterService');
  private client: RedisClientType;
  private readonly sketchKey = 'ratelimit:sketch';

  async onModuleInit() {
    this.client = createClient({
      url: process.env.REDIS_URL || 'redis://localhost:6379',
    });

    await this.client.connect();

    // Initialize Count-Min Sketch
    // Width: 2000, Depth: 7 (good for ~10K unique keys with low error rate)
    try {
      await this.client.cms.initByDim(this.sketchKey, 2000, 7);
      this.logger.log('Count-Min Sketch initialized for rate limiting');
    } catch (error) {
      this.logger.log('Count-Min Sketch already exists');
    }
  }

  /**
   * Check and increment rate limit
   */
  async checkRateLimit(identifier: string, limit: number, windowSeconds: number): Promise<RateLimitInfo> {
    const currentWindow = this.getCurrentWindow(windowSeconds);
    const key = `${identifier}:${currentWindow}`;

    // Increment count
    const newCount = await this.client.cms.incrBy(this.sketchKey, [{ item: key, incrementBy: 1 }]);

    const estimatedCount = newCount[0];
    const allowed = estimatedCount <= limit;
    const remaining = Math.max(0, limit - estimatedCount);

    const resetAt = new Date(Math.ceil(Date.now() / (windowSeconds * 1000)) * windowSeconds * 1000);

    if (!allowed) {
      this.logger.warn(`Rate limit exceeded for ${identifier}: ${estimatedCount}/${limit}`);
    }

    return {
      allowed,
      remaining,
      resetAt,
      estimatedCount,
    };
  }

  /**
   * Check current count without incrementing
   */
  async getCurrentCount(identifier: string, windowSeconds: number): Promise<number> {
    const currentWindow = this.getCurrentWindow(windowSeconds);
    const key = `${identifier}:${currentWindow}`;

    const counts = await this.client.cms.query(this.sketchKey, [key]);
    return counts[0];
  }

  /**
   * Batch check for multiple identifiers
   */
  async batchCheckRateLimit(
    identifiers: string[],
    limit: number,
    windowSeconds: number,
  ): Promise<Map<string, RateLimitInfo>> {
    const currentWindow = this.getCurrentWindow(windowSeconds);
    const keys = identifiers.map((id) => `${id}:${currentWindow}`);

    // Increment all at once
    const increments = keys.map((key) => ({ item: key, incrementBy: 1 }));
    const counts = await this.client.cms.incrBy(this.sketchKey, increments);

    const resetAt = new Date(Math.ceil(Date.now() / (windowSeconds * 1000)) * windowSeconds * 1000);

    const results = new Map<string, RateLimitInfo>();

    identifiers.forEach((identifier, index) => {
      const estimatedCount = counts[index];
      const allowed = estimatedCount <= limit;
      const remaining = Math.max(0, limit - estimatedCount);

      results.set(identifier, {
        allowed,
        remaining,
        resetAt,
        estimatedCount,
      });
    });

    return results;
  }

  private getCurrentWindow(windowSeconds: number): number {
    return Math.floor(Date.now() / (windowSeconds * 1000));
  }

  /**
   * Get sketch statistics
   */
  async getStats(): Promise<any> {
    const info = await this.client.cms.info(this.sketchKey);
    return {
      width: info.width,
      depth: info.depth,
      count: info.count,
    };
  }
}

Use Case 4: Track Top Products with Top-K​

// top-products.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { createClient, RedisClientType } from 'redis';

interface ProductRanking {
  productId: string;
  estimatedViews: number;
  rank: number;
}

@Injectable()
export class TopProductsService {
  private readonly logger = new Logger('TopProductsService');
  private client: RedisClientType;
  private readonly topKKey = 'analytics:top-products';
  private readonly TOP_K_SIZE = 100; // Track top 100 products

  async onModuleInit() {
    this.client = createClient({
      url: process.env.REDIS_URL || 'redis://localhost:6379',
    });

    await this.client.connect();

    // Initialize Top-K
    // k: 100 (track top 100)
    // width: 2000, depth: 7, decay: 0.9
    try {
      await this.client.topK.reserve(this.topKKey, this.TOP_K_SIZE, 2000, 7, 0.9);
      this.logger.log('Top-K initialized for product tracking');
    } catch (error) {
      this.logger.log('Top-K already exists');
    }
  }

  /**
   * Track product view
   */
  async trackProductView(productId: string): Promise<void> {
    // Add returns null if added to top-K, or the item that was removed
    const removed = await this.client.topK.add(this.topKKey, [productId]);

    if (removed[0]) {
      this.logger.debug(`Product ${removed[0]} removed from top-K`);
    }
  }

  /**
   * Track multiple product views at once
   */
  async trackProductViews(productId: string, count: number): Promise<void> {
    const items = Array(count).fill(productId);
    await this.client.topK.add(this.topKKey, items);
  }

  /**
   * Check if product is in top K
   */
  async isTopProduct(productId: string): Promise<boolean> {
    const results = await this.client.topK.query(this.topKKey, [productId]);
    return results[0] === 1;
  }

  /**
   * Get top K products with estimated counts
   */
  async getTopProducts(): Promise<ProductRanking[]> {
    // Get list of top items
    const topItems = await this.client.topK.list(this.topKKey, {
      withCount: true,
    });

    return topItems.map((item, index) => ({
      productId: item.item,
      estimatedViews: item.count || 0,
      rank: index + 1,
    }));
  }

  /**
   * Get top products by category using multiple Top-K structures
   */
  async getTopProductsByCategory(category: string): Promise<ProductRanking[]> {
    const categoryKey = `${this.topKKey}:${category}`;
    const topItems = await this.client.topK.list(categoryKey, {
      withCount: true,
    });

    return topItems.map((item, index) => ({
      productId: item.item,
      estimatedViews: item.count || 0,
      rank: index + 1,
    }));
  }

  /**
   * Track view with category
   */
  async trackCategorizedView(productId: string, category: string): Promise<void> {
    await Promise.all([
      this.client.topK.add(this.topKKey, [productId]),
      this.client.topK.add(`${this.topKKey}:${category}`, [productId]),
    ]);
  }

  /**
   * Get info about Top-K structure
   */
  async getInfo(): Promise<any> {
    const info = await this.client.topK.info(this.topKKey);
    return {
      k: info.k,
      width: info.width,
      depth: info.depth,
      decay: info.decay,
    };
  }
}

Use Case 5: Unique Visitors Counting with HyperLogLog​

// unique-visitors.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { createClient, RedisClientType } from 'redis';

interface VisitorStats {
  uniqueVisitors: number;
  date: string;
}

@Injectable()
export class UniqueVisitorsService {
  private readonly logger = new Logger('UniqueVisitorsService');
  private client: RedisClientType;
  private readonly keyPrefix = 'analytics:visitors';

  async onModuleInit() {
    this.client = createClient({
      url: process.env.REDIS_URL || 'redis://localhost:6379',
    });

    await this.client.connect();
    this.logger.log('HyperLogLog service initialized');
  }

  /**
   * Track visitor
   */
  async trackVisitor(visitorId: string, date?: Date): Promise<void> {
    const dateKey = this.getDateKey(date);
    await this.client.pfAdd(dateKey, [visitorId]);
  }

  /**
   * Track multiple visitors at once
   */
  async trackVisitors(visitorIds: string[], date?: Date): Promise<void> {
    const dateKey = this.getDateKey(date);
    await this.client.pfAdd(dateKey, visitorIds);
  }

  /**
   * Get unique visitor count for a date
   */
  async getUniqueVisitorCount(date?: Date): Promise<number> {
    const dateKey = this.getDateKey(date);
    return await this.client.pfCount([dateKey]);
  }

  /**
   * Get unique visitors for date range
   */
  async getUniqueVisitorCountRange(startDate: Date, endDate: Date): Promise<number> {
    const keys = this.getDateRangeKeys(startDate, endDate);

    if (keys.length === 0) return 0;

    // PFCOUNT can merge multiple HLLs
    return await this.client.pfCount(keys);
  }

  /**
   * Get daily stats for date range
   */
  async getDailyStats(startDate: Date, endDate: Date): Promise<VisitorStats[]> {
    const keys = this.getDateRangeKeys(startDate, endDate);

    const counts = await Promise.all(keys.map((key) => this.client.pfCount([key])));

    return keys.map((key, index) => ({
      uniqueVisitors: counts[index],
      date: key.split(':').pop()!,
    }));
  }

  /**
   * Track visitor by page
   */
  async trackPageVisitor(visitorId: string, page: string, date?: Date): Promise<void> {
    const dateKey = this.getDateKey(date);
    const pageKey = `${dateKey}:page:${page}`;

    await Promise.all([
      this.client.pfAdd(dateKey, [visitorId]), // Overall visitors
      this.client.pfAdd(pageKey, [visitorId]), // Page-specific visitors
    ]);
  }

  /**
   * Get unique visitors for specific page
   */
  async getPageVisitorCount(page: string, date?: Date): Promise<number> {
    const dateKey = this.getDateKey(date);
    const pageKey = `${dateKey}:page:${page}`;
    return await this.client.pfCount([pageKey]);
  }

  /**
   * Get top pages by unique visitors
   */
  async getTopPages(date?: Date, limit = 10): Promise<any[]> {
    const dateKey = this.getDateKey(date);
    const pattern = `${dateKey}:page:*`;

    const keys = await this.client.keys(pattern);

    const counts = await Promise.all(
      keys.map(async (key) => ({
        page: key.split(':').pop()!,
        uniqueVisitors: await this.client.pfCount([key]),
      })),
    );

    return counts.sort((a, b) => b.uniqueVisitors - a.uniqueVisitors).slice(0, limit);
  }

  /**
   * Merge visitor data from multiple sources
   */
  async mergeVisitorData(sourceKeys: string[], destinationKey: string): Promise<void> {
    await this.client.pfMerge(destinationKey, sourceKeys);
    this.logger.log(`Merged visitor data into ${destinationKey}`);
  }

  private getDateKey(date?: Date): string {
    const d = date || new Date();
    const dateStr = d.toISOString().split('T')[0]; // YYYY-MM-DD
    return `${this.keyPrefix}:${dateStr}`;
  }

  private getDateRangeKeys(startDate: Date, endDate: Date): string[] {
    const keys: string[] = [];
    const current = new Date(startDate);

    while (current <= endDate) {
      keys.push(this.getDateKey(current));
      current.setDate(current.getDate() + 1);
    }

    return keys;
  }
}

Use Case 6: Cuckoo Filter for Deletable Membership Testing​

// blocked-users.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { createClient, RedisClientType } from 'redis';

@Injectable()
export class BlockedUsersService {
  private readonly logger = new Logger('BlockedUsersService');
  private client: RedisClientType;
  private readonly filterKey = 'security:blocked-users';

  async onModuleInit() {
    this.client = createClient({
      url: process.env.REDIS_URL || 'redis://localhost:6379',
    });

    await this.client.connect();

    // Initialize Cuckoo Filter
    // Capacity: 1,000,000 items
    try {
      await this.client.cf.reserve(this.filterKey, 1000000);
      this.logger.log('Cuckoo filter initialized for blocked users');
    } catch (error) {
      this.logger.log('Cuckoo filter already exists');
    }
  }

  /**
   * Check if user is blocked
   */
  async isBlocked(userId: string): Promise<boolean> {
    const exists = await this.client.cf.exists(this.filterKey, userId);
    return exists === 1;
  }

  /**
   * Block user
   */
  async blockUser(userId: string, reason?: string): Promise<void> {
    const added = await this.client.cf.add(this.filterKey, userId);

    if (added) {
      this.logger.log(`User blocked: ${userId}${reason ? `, Reason: ${reason}` : ''}`);

      // Store additional metadata in a separate key
      if (reason) {
        await this.client.hSet(`${this.filterKey}:meta:${userId}`, {
          reason,
          blockedAt: new Date().toISOString(),
        });
      }
    }
  }

  /**
   * Unblock user (only possible with Cuckoo Filter, not Bloom Filter)
   */
  async unblockUser(userId: string): Promise<boolean> {
    const deleted = await this.client.cf.del(this.filterKey, userId);

    if (deleted) {
      this.logger.log(`User unblocked: ${userId}`);

      // Remove metadata
      await this.client.del(`${this.filterKey}:meta:${userId}`);
      return true;
    }

    return false;
  }

  /**
   * Block multiple users
   */
  async blockUsers(userIds: string[]): Promise<void> {
    const results = await this.client.cf.addNX(this.filterKey, userIds);

    const blockedCount = results.filter((r) => r === 1).length;
    this.logger.log(`Blocked ${blockedCount} out of ${userIds.length} users`);
  }

  /**
   * Check multiple users at once
   */
  async checkBlockedUsers(userIds: string[]): Promise<Map<string, boolean>> {
    const results = await this.client.cf.mExists(this.filterKey, userIds);

    const map = new Map<string, boolean>();
    userIds.forEach((userId, index) => {
      map.set(userId, results[index] === 1);
    });

    return map;
  }

  /**
   * Get block metadata
   */
  async getBlockMetadata(userId: string): Promise<any> {
    const meta = await this.client.hGetAll(`${this.filterKey}:meta:${userId}`);
    return meta;
  }

  /**
   * Get filter info
   */
  async getFilterInfo(): Promise<any> {
    const info = await this.client.cf.info(this.filterKey);
    return {
      size: info.size,
      bucketSize: info.bucketSize,
      numBuckets: info.numBuckets,
      numFilters: info.numFilters,
      numItemsInserted: info.numItemsInserted,
      numItemsDeleted: info.numItemsDeleted,
      expansionRate: info.expansionRate,
    };
  }
}

🎯 Best Practices​

1. Choosing Error Rates​

// Conservative: Financial systems, security
await client.bf.reserve('financial:transactions', 0.0001, 10000000); // 0.01%

// Balanced: General applications
await client.bf.reserve('general:cache', 0.001, 10000000); // 0.1%

// Aggressive: Non-critical features
await client.bf.reserve('suggestions:seen', 0.01, 10000000); // 1%

2. Capacity Planning​

// Calculate required capacity
function calculateBloomFilterSize(expectedItems: number, falsePositiveRate: number): number {
  // m = -n * ln(p) / (ln(2)^2)
  // where m = bits, n = items, p = false positive rate
  const bits = Math.ceil((-expectedItems * Math.log(falsePositiveRate)) / Math.pow(Math.log(2), 2));

  return bits;
}

// Example: 10M items with 0.1% FP rate
const bits = calculateBloomFilterSize(10000000, 0.001);
console.log(`Required bits: ${bits}`); // ~143M bits ≈ 18 MB

3. Handling False Positives​

// Two-phase check: Bloom filter → Database
async function isUserBanned(userId: string): Promise<boolean> {
  // Phase 1: Quick check with Bloom filter
  const mightBeBanned = await bloomFilter.exists('banned:users', userId);

  if (!mightBeBanned) {
    // Definitely not banned
    return false;
  }

  // Phase 2: Confirm with database (handle false positive)
  const isBanned = await database.query('SELECT 1 FROM banned_users WHERE user_id = ?', [userId]);

  return isBanned.length > 0;
}

4. Expiring Old Data​

// Use time-based keys for automatic cleanup
class TimeWindowedBloomFilter {
  private getHourlyKey(date: Date = new Date()): string {
    const hour = date.toISOString().substring(0, 13); // YYYY-MM-DDTHH
    return `bloom:hourly:${hour}`;
  }

  async add(item: string): Promise<void> {
    const key = this.getHourlyKey();

    // Create filter if not exists
    try {
      await this.client.bf.reserve(key, 0.001, 100000);
    } catch (error) {
      // Already exists
    }

    await this.client.bf.add(key, item);

    // Set expiration (keep for 24 hours)
    await this.client.expire(key, 86400);
  }

  async exists(item: string, hoursBack = 0): Promise<boolean> {
    const date = new Date(Date.now() - hoursBack * 3600000);
    const key = this.getHourlyKey(date);

    const result = await this.client.bf.exists(key, item);
    return result === 1;
  }
}

Metrics Collection​

// bloom-metrics.service.ts
import { Injectable } from '@nestjs/common';
import { Counter, Gauge, Histogram } from 'prom-client';

@Injectable()
export class BloomMetricsService {
  private readonly bloomChecks = new Counter({
    name: 'bloom_filter_checks_total',
    help: 'Total number of Bloom filter checks',
    labelNames: ['filter', 'result'],
  });

  private readonly bloomSize = new Gauge({
    name: 'bloom_filter_size_bytes',
    help: 'Bloom filter size in bytes',
    labelNames: ['filter'],
  });

  private readonly bloomFalsePositives = new Counter({
    name: 'bloom_filter_false_positives_total',
    help: 'Estimated false positives',
    labelNames: ['filter'],
  });

  recordCheck(filter: string, exists: boolean, isFalsePositive = false) {
    this.bloomChecks.inc({
      filter,
      result: exists ? 'positive' : 'negative',
    });

    if (isFalsePositive) {
      this.bloomFalsePositives.inc({ filter });
    }
  }

  async recordFilterSize(filter: string, client: any) {
    const info = await client.bf.info(filter);
    this.bloomSize.set({ filter }, info.size * 8); // bits to bytes
  }
}

Composite Filters​

// Use multiple filters for better accuracy
class CompositeSpamFilter {
  async isSpam(data: any): Promise<boolean> {
    // Combine multiple probabilistic checks
    const checks = await Promise.all([
      this.bloomFilter.exists('spam:emails', data.email),
      this.bloomFilter.exists('spam:ips', data.ip),
      this.cuckooFilter.exists('spam:patterns', data.contentHash),
      this.countMinSketch.query('spam:frequency', data.email) > 10,
    ]);

    const spamSignals = checks.filter(Boolean).length;
    return spamSignals >= 2; // Require 2+ signals
  }
}

📖 Summary​

Redis Bloom filters and probabilistic data structures provide:

✅ Massive memory savings (99%+ reduction)
✅ Blazing fast lookups (microseconds)
✅ Horizontal scalability (billions of items)
✅ Perfect for read-heavy workloads

Trade-offs:

  • Small false positive rate (configurable)
  • Cannot remove items (except Cuckoo filter)
  • Approximate counts (Count-Min Sketch, HyperLogLog)

Perfect for:

  • Duplicate detection
  • Spam/fraud detection
  • Cache optimization
  • Analytics and tracking
  • Rate limiting
  • Security features

Choose probabilistic data structures when approximate answers with massive performance gains are acceptable!
