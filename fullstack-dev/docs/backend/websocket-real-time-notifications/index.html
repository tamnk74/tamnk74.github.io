WebSocket for Real-Time Notifications

📖 Overview​

WebSocket is a communication protocol that provides full-duplex, bidirectional communication channels over a single TCP connection. Unlike Server-Sent Events (SSE), WebSocket enables both client-to-server and server-to-client real-time data transfer, making it ideal for interactive applications requiring two-way communication.

🎯 When to Use WebSocket​

✅ Best Use Cases​

  • Chat applications (messaging, group chats)
  • Collaborative tools (real-time document editing, whiteboards)
  • Multiplayer games (real-time game state synchronization)
  • Trading platforms (live market data with user actions)
  • IoT dashboards (bidirectional device control)
  • Live customer support (agent-customer chat)
  • Real-time notifications with acknowledgments

❌ When to Use Alternatives​

TechnologyUse Case
Server-Sent Events (SSE)Unidirectional updates, simpler implementation
HTTP/2 Server PushStatic resource optimization
Long PollingLegacy browser support
gRPC StreamingMicroservice-to-microservice communication

📊 WebSocket vs SSE Comparison​

import {
  WebSocketGateway,
  WebSocketServer,
  SubscribeMessage,
  OnGatewayConnection,
  OnGatewayDisconnect,
  OnGatewayInit,
  MessageBody,
  ConnectedSocket,
} from '@nestjs/websockets';
import { Server, Socket } from 'socket.io';
import { Logger, UseGuards } from '@nestjs/common';
import { WsJwtGuard } from '../auth/guards/ws-jwt.guard';
import { createAdapter } from '@socket.io/redis-adapter';
import { createClient } from 'redis';

@WebSocketGateway({
  cors: {
    origin: process.env.CORS_ORIGIN?.split(',') || ['http://localhost:3000'],
    credentials: true,
  },
  transports: ['websocket', 'polling'],
  namespace: '/notifications',
})
export class NotificationsGateway implements OnGatewayInit, OnGatewayConnection, OnGatewayDisconnect {
  @WebSocketServer()
  server: Server;

  private logger: Logger = new Logger('NotificationsGateway');

  constructor(
    private readonly notificationService: NotificationService,
    private readonly userPresenceService: UserPresenceService,
  ) {}

  async afterInit(server: Server) {
    // Configure Redis adapter for multi-instance support
    const pubClient = createClient({
      url: process.env.REDIS_URL || 'redis://localhost:6379',
    });
    const subClient = pubClient.duplicate();

    await Promise.all([pubClient.connect(), subClient.connect()]);

    server.adapter(createAdapter(pubClient, subClient));

    this.logger.log('WebSocket Gateway initialized with Redis adapter');
  }

  @UseGuards(WsJwtGuard)
  async handleConnection(@ConnectedSocket() client: Socket) {
    try {
      const userId = client.data.userId;
      this.logger.log(`Client connected: ${client.id}, User: ${userId}`);

      // Join user to their personal room
      await client.join(`user:${userId}`);

      // Update user presence
      await this.userPresenceService.setOnline(userId, client.id);

      // Send pending notifications
      const pendingNotifications = await this.notificationService.getPendingNotifications(userId);

      client.emit('pending_notifications', pendingNotifications);

      // Notify user's contacts that they're online
      this.server.to(`contacts:${userId}`).emit('user_online', { userId, timestamp: new Date() });

      // Send connection acknowledgment
      client.emit('connected', {
        userId,
        timestamp: new Date(),
        pendingCount: pendingNotifications.length,
      });
    } catch (error) {
      this.logger.error(`Connection error: ${error.message}`);
      client.disconnect();
    }
  }

  async handleDisconnect(@ConnectedSocket() client: Socket) {
    const userId = client.data.userId;
    this.logger.log(`Client disconnected: ${client.id}, User: ${userId}`);

    if (userId) {
      // Update user presence
      await this.userPresenceService.setOffline(userId, client.id);

      // Check if user has other active connections
      const isStillOnline = await this.userPresenceService.isOnline(userId);

      if (!isStillOnline) {
        // Notify user's contacts that they're offline
        this.server.to(`contacts:${userId}`).emit('user_offline', { userId, timestamp: new Date() });
      }
    }
  }

  /**
   * Send notification to specific user
   */
  async sendNotificationToUser(userId: string, notification: Notification): Promise<void> {
    this.server.to(`user:${userId}`).emit('notification', notification);
    this.logger.log(`Notification sent to user ${userId}: ${notification.type}`);
  }

  /**
   * Send notification to multiple users
   */
  async sendNotificationToUsers(userIds: string[], notification: Notification): Promise<void> {
    userIds.forEach((userId) => {
      this.server.to(`user:${userId}`).emit('notification', notification);
    });
    this.logger.log(`Notification sent to ${userIds.length} users`);
  }

  /**
   * Broadcast notification to all connected users
   */
  async broadcastNotification(notification: Notification): Promise<void> {
    this.server.emit('notification', notification);
    this.logger.log(`Notification broadcasted: ${notification.type}`);
  }

  /**
   * Client subscribes to specific notification types
   */
  @SubscribeMessage('subscribe')
  @UseGuards(WsJwtGuard)
  async handleSubscribe(@ConnectedSocket() client: Socket, @MessageBody() data: { types: string[] }): Promise<void> {
    const userId = client.data.userId;

    data.types.forEach((type) => {
      client.join(`notifications:${type}`);
    });

    this.logger.log(`User ${userId} subscribed to: ${data.types.join(', ')}`);

    client.emit('subscribed', { types: data.types });
  }

  /**
   * Client unsubscribes from notification types
   */
  @SubscribeMessage('unsubscribe')
  @UseGuards(WsJwtGuard)
  async handleUnsubscribe(@ConnectedSocket() client: Socket, @MessageBody() data: { types: string[] }): Promise<void> {
    const userId = client.data.userId;

    data.types.forEach((type) => {
      client.leave(`notifications:${type}`);
    });

    this.logger.log(`User ${userId} unsubscribed from: ${data.types.join(', ')}`);

    client.emit('unsubscribed', { types: data.types });
  }

  /**
   * Client marks notification as read
   */
  @SubscribeMessage('mark_read')
  @UseGuards(WsJwtGuard)
  async handleMarkRead(
    @ConnectedSocket() client: Socket,
    @MessageBody() data: { notificationId: string },
  ): Promise<void> {
    const userId = client.data.userId;

    await this.notificationService.markAsRead(data.notificationId, userId);

    client.emit('marked_read', { notificationId: data.notificationId });
    this.logger.log(`Notification ${data.notificationId} marked as read by ${userId}`);
  }

  /**
   * Client sends typing indicator
   */
  @SubscribeMessage('typing')
  @UseGuards(WsJwtGuard)
  async handleTyping(
    @ConnectedSocket() client: Socket,
    @MessageBody() data: { chatId: string; isTyping: boolean },
  ): Promise<void> {
    const userId = client.data.userId;

    // Broadcast to other users in the chat
    client.to(`chat:${data.chatId}`).emit('user_typing', {
      userId,
      chatId: data.chatId,
      isTyping: data.isTyping,
    });
  }

  /**
   * Client requests delivery acknowledgment
   */
  @SubscribeMessage('acknowledge')
  @UseGuards(WsJwtGuard)
  async handleAcknowledge(
    @ConnectedSocket() client: Socket,
    @MessageBody() data: { notificationId: string },
  ): Promise<void> {
    const userId = client.data.userId;

    await this.notificationService.markAsDelivered(data.notificationId, userId);

    this.logger.log(`Notification ${data.notificationId} acknowledged by ${userId}`);
  }
}

3. WebSocket Authentication Guard​

import { CanActivate, ExecutionContext, Injectable, Logger } from '@nestjs/common';
import { WsException } from '@nestjs/websockets';
import { Socket } from 'socket.io';
import { JwtService } from '@nestjs/jwt';

@Injectable()
export class WsJwtGuard implements CanActivate {
  private logger = new Logger('WsJwtGuard');

  constructor(private jwtService: JwtService) {}

  async canActivate(context: ExecutionContext): Promise<boolean> {
    try {
      const client: Socket = context.switchToWs().getClient();
      const token = this.extractToken(client);

      if (!token) {
        throw new WsException('Unauthorized: No token provided');
      }

      const payload = await this.jwtService.verifyAsync(token, {
        secret: process.env.JWT_SECRET,
      });

      // Attach user data to socket
      client.data.userId = payload.sub;
      client.data.email = payload.email;
      client.data.role = payload.role;

      return true;
    } catch (error) {
      this.logger.error(`WebSocket authentication failed: ${error.message}`);
      throw new WsException('Unauthorized: Invalid token');
    }
  }

  private extractToken(client: Socket): string | null {
    // Try to get token from handshake auth
    const authToken = client.handshake?.auth?.token;
    if (authToken) {
      return authToken;
    }

    // Try to get token from query parameters
    const queryToken = client.handshake?.query?.token as string;
    if (queryToken) {
      return queryToken;
    }

    // Try to get token from headers
    const headerToken = client.handshake?.headers?.authorization;
    if (headerToken?.startsWith('Bearer ')) {
      return headerToken.substring(7);
    }

    return null;
  }
}

4. User Presence Service​

import { Injectable, Logger } from '@nestjs/common';
import { InjectRedis } from '@liaoliaots/nestjs-redis';
import Redis from 'ioredis';

@Injectable()
export class UserPresenceService {
  private logger = new Logger('UserPresenceService');
  private readonly PRESENCE_KEY = 'user:presence';
  private readonly CONNECTIONS_KEY = 'user:connections';
  private readonly PRESENCE_TTL = 300; // 5 minutes

  constructor(@InjectRedis() private readonly redis: Redis) {}

  /**
   * Set user as online
   */
  async setOnline(userId: string, socketId: string): Promise<void> {
    const multi = this.redis.multi();

    // Add to presence set
    multi.sadd(`${this.PRESENCE_KEY}:${userId}`, socketId);
    multi.expire(`${this.PRESENCE_KEY}:${userId}`, this.PRESENCE_TTL);

    // Store connection timestamp
    multi.hset(`${this.CONNECTIONS_KEY}:${userId}`, socketId, Date.now());
    multi.expire(`${this.CONNECTIONS_KEY}:${userId}`, this.PRESENCE_TTL);

    await multi.exec();
    this.logger.log(`User ${userId} set online with socket ${socketId}`);
  }

  /**
   * Set user as offline
   */
  async setOffline(userId: string, socketId: string): Promise<void> {
    const multi = this.redis.multi();

    // Remove from presence set
    multi.srem(`${this.PRESENCE_KEY}:${userId}`, socketId);
    multi.hdel(`${this.CONNECTIONS_KEY}:${userId}`, socketId);

    await multi.exec();
    this.logger.log(`User ${userId} socket ${socketId} removed from presence`);
  }

  /**
   * Check if user is online
   */
  async isOnline(userId: string): Promise<boolean> {
    const count = await this.redis.scard(`${this.PRESENCE_KEY}:${userId}`);
    return count > 0;
  }

  /**
   * Get all online users
   */
  async getOnlineUsers(): Promise<string[]> {
    const keys = await this.redis.keys(`${this.PRESENCE_KEY}:*`);
    return keys.map((key) => key.replace(`${this.PRESENCE_KEY}:`, ''));
  }

  /**
   * Get user's active connection count
   */
  async getConnectionCount(userId: string): Promise<number> {
    return await this.redis.scard(`${this.PRESENCE_KEY}:${userId}`);
  }

  /**
   * Get users online in last N seconds
   */
  async getRecentlyActive(seconds: number): Promise<string[]> {
    const cutoff = Date.now() - seconds * 1000;
    const users: string[] = [];

    const keys = await this.redis.keys(`${this.CONNECTIONS_KEY}:*`);

    for (const key of keys) {
      const connections = await this.redis.hgetall(key);
      const hasRecentActivity = Object.values(connections).some((timestamp) => parseInt(timestamp) > cutoff);

      if (hasRecentActivity) {
        users.push(key.replace(`${this.CONNECTIONS_KEY}:`, ''));
      }
    }

    return users;
  }
}

5. Notification Service with WebSocket Integration​

import { Injectable, Logger } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import { NotificationsGateway } from '../gateways/notifications.gateway';

export enum NotificationType {
  ORDER_CREATED = 'order.created',
  ORDER_UPDATED = 'order.updated',
  ORDER_SHIPPED = 'order.shipped',
  ORDER_DELIVERED = 'order.delivered',
  PAYMENT_SUCCESS = 'payment.success',
  PAYMENT_FAILED = 'payment.failed',
  MESSAGE_RECEIVED = 'message.received',
  SYSTEM_ALERT = 'system.alert',
}

export interface Notification {
  id: string;
  userId: string;
  type: NotificationType;
  title: string;
  message: string;
  data?: any;
  read: boolean;
  delivered: boolean;
  createdAt: Date;
}

@Injectable()
export class NotificationService {
  private logger = new Logger('NotificationService');

  constructor(
    @InjectRepository(Notification)
    private notificationRepository: Repository<Notification>,
    private notificationsGateway: NotificationsGateway,
  ) {}

  /**
   * Send notification to user via WebSocket
   */
  async sendNotification(
    userId: string,
    type: NotificationType,
    title: string,
    message: string,
    data?: any,
  ): Promise<Notification> {
    // Create and persist notification
    const notification = this.notificationRepository.create({
      userId,
      type,
      title,
      message,
      data,
      read: false,
      delivered: false,
    });

    await this.notificationRepository.save(notification);

    // Send via WebSocket
    await this.notificationsGateway.sendNotificationToUser(userId, notification);

    this.logger.log(`Notification sent to user ${userId}: ${type}`);
    return notification;
  }

  /**
   * Send notification to multiple users
   */
  async sendBulkNotification(
    userIds: string[],
    type: NotificationType,
    title: string,
    message: string,
    data?: any,
  ): Promise<void> {
    const notifications = userIds.map((userId) =>
      this.notificationRepository.create({
        userId,
        type,
        title,
        message,
        data,
        read: false,
        delivered: false,
      }),
    );

    await this.notificationRepository.save(notifications);

    // Send via WebSocket
    await this.notificationsGateway.sendNotificationToUsers(userIds, notifications[0]);

    this.logger.log(`Bulk notification sent to ${userIds.length} users: ${type}`);
  }

  /**
   * Get pending notifications for user
   */
  async getPendingNotifications(userId: string): Promise<Notification[]> {
    return this.notificationRepository.find({
      where: { userId, delivered: false },
      order: { createdAt: 'DESC' },
      take: 50,
    });
  }

  /**
   * Mark notification as read
   */
  async markAsRead(notificationId: string, userId: string): Promise<void> {
    await this.notificationRepository.update({ id: notificationId, userId }, { read: true });
  }

  /**
   * Mark notification as delivered
   */
  async markAsDelivered(notificationId: string, userId: string): Promise<void> {
    await this.notificationRepository.update({ id: notificationId, userId }, { delivered: true });
  }

  /**
   * Get notification history
   */
  async getNotificationHistory(userId: string, limit = 50, offset = 0): Promise<Notification[]> {
    return this.notificationRepository.find({
      where: { userId },
      order: { createdAt: 'DESC' },
      take: limit,
      skip: offset,
    });
  }
}

2. WebSocket Hook​

import { useEffect, useState, useCallback, useRef } from 'react';
import { io, Socket } from 'socket.io-client';

interface UseWebSocketOptions {
  url: string;
  namespace?: string;
  token: string;
  autoConnect?: boolean;
  reconnectionAttempts?: number;
  reconnectionDelay?: number;
  onConnect?: () => void;
  onDisconnect?: () => void;
  onError?: (error: Error) => void;
}

interface WebSocketState {
  isConnected: boolean;
  error: Error | null;
  socket: Socket | null;
}

export function useWebSocket({
  url,
  namespace = '/notifications',
  token,
  autoConnect = true,
  reconnectionAttempts = 5,
  reconnectionDelay = 1000,
  onConnect,
  onDisconnect,
  onError,
}: UseWebSocketOptions) {
  const [state, setState] = useState<WebSocketState>({
    isConnected: false,
    error: null,
    socket: null,
  });

  const socketRef = useRef<Socket | null>(null);
  const reconnectTimeoutRef = useRef<NodeJS.Timeout>();

  const connect = useCallback(() => {
    if (socketRef.current?.connected) {
      return;
    }

    const socket = io(`${url}${namespace}`, {
      auth: {
        token,
      },
      transports: ['websocket', 'polling'],
      reconnection: true,
      reconnectionAttempts,
      reconnectionDelay,
    });

    socket.on('connect', () => {
      console.log('WebSocket connected:', socket.id);
      setState((prev) => ({ ...prev, isConnected: true, error: null }));
      onConnect?.();
    });

    socket.on('disconnect', (reason) => {
      console.log('WebSocket disconnected:', reason);
      setState((prev) => ({ ...prev, isConnected: false }));
      onDisconnect?.();
    });

    socket.on('connect_error', (error) => {
      console.error('WebSocket connection error:', error);
      setState((prev) => ({
        ...prev,
        isConnected: false,
        error: new Error(error.message),
      }));
      onError?.(new Error(error.message));
    });

    socket.on('error', (error) => {
      console.error('WebSocket error:', error);
      setState((prev) => ({ ...prev, error: new Error(error) }));
      onError?.(new Error(error));
    });

    socketRef.current = socket;
    setState((prev) => ({ ...prev, socket }));
  }, [url, namespace, token, reconnectionAttempts, reconnectionDelay, onConnect, onDisconnect, onError]);

  const disconnect = useCallback(() => {
    if (reconnectTimeoutRef.current) {
      clearTimeout(reconnectTimeoutRef.current);
    }

    if (socketRef.current) {
      socketRef.current.disconnect();
      socketRef.current = null;
    }

    setState({
      isConnected: false,
      error: null,
      socket: null,
    });
  }, []);

  const emit = useCallback((event: string, data: any) => {
    if (socketRef.current?.connected) {
      socketRef.current.emit(event, data);
    } else {
      console.warn('Socket not connected. Cannot emit event:', event);
    }
  }, []);

  const on = useCallback((event: string, handler: (...args: any[]) => void) => {
    if (socketRef.current) {
      socketRef.current.on(event, handler);
    }
  }, []);

  const off = useCallback((event: string, handler?: (...args: any[]) => void) => {
    if (socketRef.current) {
      socketRef.current.off(event, handler);
    }
  }, []);

  useEffect(() => {
    if (autoConnect) {
      connect();
    }

    return () => {
      disconnect();
    };
  }, [autoConnect, connect, disconnect]);

  return {
    ...state,
    connect,
    disconnect,
    emit,
    on,
    off,
  };
}

'use client';

import { useEffect, useState, useCallback } from 'react';

export function NotificationCenter() {
  const [notifications, setNotifications] = useState<Notification[]>([]);
  const [unreadCount, setUnreadCount] = useState(0);
  const [isOpen, setIsOpen] = useState(false);
  const [isTyping, setIsTyping] = useState<{ [key: string]: boolean }>({});

  // Handle incoming notifications

      // Send acknowledgment

      setUnreadCount(pending.filter((n) => !n.read).length);

      console.log('Connection established:', data);
    };

          setIsTyping((prev) => ({ ...prev, [data.userId]: false }));
        }, 3000);
      }

    on('pending_notifications', handlePendingNotifications);
    on('connected', handleConnected);
    on('user_typing', handleUserTyping);

      off('notification', handleNotification);
      off('pending_notifications', handlePendingNotifications);
      off('connected', handleConnected);
      off('user_typing', handleUserTyping);

  }, [on, off, emit]);

  const handleNotificationClick = useCallback((notification: Notification) => {
    // Mark as read
    markAsRead(notification.id);

    // Handle notification action based on type
    switch (notification.type) {
      case 'order.created':
      case 'order.updated':
        window.location.href = `/orders/${notification.data?.orderId}`;
        break;
      case 'payment.success':
        window.location.href = `/payments/${notification.data?.paymentId}`;
        break;
      case 'message.received':
        window.location.href = `/chat/${notification.data?.chatId}`;
        break;
      default:
        break;
    }
  }, []);

  const markAsRead = useCallback(
    (notificationId: string) => {
      emit('mark_read', { notificationId });

      setNotifications((prev) => prev.map((n) => (n.id === notificationId ? { ...n, read: true } : n)));
      setUnreadCount((prev) => Math.max(0, prev - 1));
    },
    [emit],
  );

  const markAllAsRead = useCallback(() => {
    notifications.forEach((notification) => {
      if (!notification.read) {
        emit('mark_read', { notificationId: notification.id });
      }
    });

    setNotifications((prev) => prev.map((n) => ({ ...n, read: true })));
    setUnreadCount(0);
  }, [notifications, emit]);

  const clearAll = useCallback(() => {
    setNotifications([]);
    setUnreadCount(0);
    setIsOpen(false);
  }, []);

  const playNotificationSound = () => {
    const audio = new Audio('/sounds/notification.mp3');
    audio.volume = 0.5;
    audio.play().catch(console.error);
  };

  return (
    <div className="relative">
      {/* Connection indicator */}
      <div className="flex items-center gap-2 mb-4">
        <div className={`h-2 w-2 rounded-full ${isConnected ? 'bg-green-500 animate-pulse' : 'bg-red-500'}`} />
        <span className="text-sm text-gray-600">{isConnected ? 'Connected' : 'Disconnected'}</span>
      </div>

      {/* Notification bell */}
      <button
        onClick={() => setIsOpen(!isOpen)}
        className="relative p-2 hover:bg-gray-100 rounded-full transition-colors"
        aria-label="Notifications"
      >
        <Bell className="h-6 w-6 text-gray-700" />
        {unreadCount > 0 && (
          <span className="absolute -top-1 -right-1 h-5 w-5 rounded-full bg-red-500 text-white text-xs flex items-center justify-center font-semibold">
            {unreadCount > 9 ? '9+' : unreadCount}
          </span>
        )}
      </button>

      {/* Notification dropdown */}
      {isOpen && (
        <div className="absolute right-0 mt-2 w-96 bg-white rounded-lg shadow-xl border border-gray-200 max-h-[32rem] overflow-hidden flex flex-col z-50">
          {/* Header */}
          <div className="p-4 border-b border-gray-200 flex items-center justify-between">
            <h3 className="font-semibold text-lg">Notifications</h3>
            <div className="flex gap-2">
              {unreadCount > 0 && (
                <button onClick={markAllAsRead} className="text-sm text-blue-600 hover:text-blue-700">
                  Mark all read
                </button>
              )}
              <button onClick={clearAll} className="text-sm text-gray-600 hover:text-gray-700">
                Clear all
              </button>
            </div>
          </div>

          {/* Notification list */}
          <div className="overflow-y-auto flex-1">
            {notifications.length === 0 ? (
              <div className="p-8 text-center text-gray-500">
                <Bell className="h-12 w-12 mx-auto mb-2 text-gray-300" />
                <p>No notifications</p>
              </div>
            ) : (
              <ul>
                {notifications.map((notification) => (
                  <li
                    key={notification.id}
                    onClick={() => handleNotificationClick(notification)}
                    className={`p-4 border-b border-gray-100 hover:bg-gray-50 cursor-pointer transition-colors ${
                      !notification.read ? 'bg-blue-50' : ''
                    }`}
                  >
                    <div className="flex items-start justify-between gap-2">
                      <div className="flex-1">
                        <div className="flex items-center gap-2">
                          <p className="font-medium text-sm">{notification.title}</p>
                          {!notification.read && <div className="h-2 w-2 rounded-full bg-blue-500" />}
                        </div>
                        <p className="text-sm text-gray-600 mt-1">{notification.message}</p>
                        <p className="text-xs text-gray-400 mt-1">
                          {formatTimestamp(new Date(notification.createdAt))}
                        </p>
                      </div>
                      <button
                        onClick={(e) => {
                          e.stopPropagation();
                          markAsRead(notification.id);
                        }}
                        className="p-1 hover:bg-gray-200 rounded"
                      >
                        {notification.read ? (
                          <Check className="h-4 w-4 text-green-600" />
                        ) : (
                          <X className="h-4 w-4 text-gray-400" />
                        )}
                      </button>
                    </div>
                  </li>
                ))}
              </ul>
            )}
          </div>
        </div>
      )}
    </div>
  );
}

function formatTimestamp(date: Date): string {
  const now = new Date();
  const diff = now.getTime() - date.getTime();
  const minutes = Math.floor(diff / 60000);

  if (minutes < 1) return 'Just now';
  if (minutes < 60) return `${minutes}m ago`;

  const hours = Math.floor(minutes / 60);
  if (hours < 24) return `${hours}h ago`;

  const days = Math.floor(hours / 24);
  return `${days}d ago`;
}

'use client';

import { useEffect, useState } from 'react';
import { useWebSocket } from '@/hooks/useWebSocket';

interface TypingIndicatorProps {
  chatId: string;
}

export function TypingIndicator({ chatId }: TypingIndicatorProps) {
  const [typingUsers, setTypingUsers] = useState<Set<string>>(new Set());
  const token = localStorage.getItem('accessToken') || '';

  const { on, off, emit } = useWebSocket({
    url: process.env.NEXT_PUBLIC_WS_URL || 'http://localhost:3001',
    namespace: '/notifications',
    token,
  });

  useEffect(() => {
    const handleUserTyping = (data: { userId: string; chatId: string; isTyping: boolean }) => {
      if (data.chatId !== chatId) return;

      setTypingUsers((prev) => {
        const newSet = new Set(prev);
        if (data.isTyping) {
          newSet.add(data.userId);
        } else {
          newSet.delete(data.userId);
        }
        return newSet;
      });
    };

    on('user_typing', handleUserTyping);

    return () => {
      off('user_typing', handleUserTyping);
    };
  }, [on, off, chatId]);

  const notifyTyping = (isTyping: boolean) => {
    emit('typing', { chatId, isTyping });
  };

  if (typingUsers.size === 0) return null;

  return (
    <div className="text-sm text-gray-500 italic px-4 py-2">
      {typingUsers.size === 1 ? 'Someone is typing...' : `${typingUsers.size} people are typing...`}
    </div>
  );
}

Custom Metrics​

import { Injectable } from '@nestjs/common';
import { Counter, Gauge, Histogram } from 'prom-client';

@Injectable()
export class WebSocketMetrics {
  private readonly activeConnections = new Gauge({
    name: 'websocket_active_connections',
    help: 'Number of active WebSocket connections',
    labelNames: ['namespace', 'user_id'],
  });

  private readonly messagesReceived = new Counter({
    name: 'websocket_messages_received_total',
    help: 'Total number of messages received',
    labelNames: ['event', 'namespace'],
  });

  private readonly messagesSent = new Counter({
    name: 'websocket_messages_sent_total',
    help: 'Total number of messages sent',
    labelNames: ['event', 'namespace'],
  });

  private readonly messageLatency = new Histogram({
    name: 'websocket_message_latency_seconds',
    help: 'Message delivery latency',
    labelNames: ['event'],
    buckets: [0.001, 0.005, 0.01, 0.05, 0.1, 0.5, 1, 5],
  });

  private readonly connectionDuration = new Histogram({
    name: 'websocket_connection_duration_seconds',
    help: 'Duration of WebSocket connections',
    buckets: [60, 300, 900, 1800, 3600, 7200, 14400, 28800, 86400],
  });

  recordConnection(namespace: string, userId: string): void {
    this.activeConnections.inc({ namespace, user_id: userId });
  }

  recordDisconnection(namespace: string, userId: string, duration: number): void {
    this.activeConnections.dec({ namespace, user_id: userId });
    this.connectionDuration.observe(duration);
  }

  recordMessageReceived(event: string, namespace: string): void {
    this.messagesReceived.inc({ event, namespace });
  }

  recordMessageSent(event: string, namespace: string, latency: number): void {
    this.messagesSent.inc({ event, namespace });
    this.messageLatency.observe({ event }, latency);
  }
}

🚨 Common Pitfalls & Solutions​

ProblemSolution
Connection dropsImplement automatic reconnection with exponential backoff
Message delivery failureUse acknowledgments and retry logic
Memory leaksProperly clean up event listeners and disconnect sockets
Load balancer issuesEnable sticky sessions or use Redis adapter
Scaling challengesUse Redis adapter for multi-instance support
High latencyOptimize message payload size, use binary protocol
Authentication issuesValidate tokens on connection and periodically refresh
CORS errorsConfigure proper CORS settings in gateway

Summary​

WebSocket provides a powerful, bidirectional communication protocol perfect for interactive real-time applications. By combining WebSocket with Socket.IO, Redis adapter, and proper load balancing, you can build a scalable, production-ready notification system that handles millions of concurrent connections with low latency and high reliability.

Key advantages over SSE:

  • Bidirectional communication for interactive features
  • Lower latency for time-critical applications
  • Binary protocol support for efficient data transfer
  • Rich ecosystem with Socket.IO features (rooms, namespaces, acknowledgments)

Choose WebSocket when you need true real-time, bidirectional communication. For simple server-to-client updates, consider Server-Sent Events (SSE) for a simpler implementation.
