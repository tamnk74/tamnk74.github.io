Dead Letter Queues & Poison Message Handling Guide

Overview​

Dead Letter Queues (DLQ) and poison message handling are critical patterns for building resilient message-driven microservices. This guide covers DLQ implementation, poison message detection, retry strategies, error handling, and recovery patterns for Kafka, RabbitMQ, and other message brokers.

Dead Letter Queue Fundamentals​

What is a Dead Letter Queue?​

A Dead Letter Queue (DLQ) is a separate queue where messages that cannot be processed successfully are moved for later analysis and recovery.

Why Use DLQs?​

Benefits:

  • Prevent Message Loss - Failed messages aren't discarded
  • Avoid Blocking - Poison messages don't block queue processing
  • Enable Analysis - Failed messages can be inspected
  • Support Recovery - Messages can be reprocessed after fixes
  • Maintain Throughput - Main queue continues processing

Poison Message Detection​

What is a Poison Message?​

A poison message is a message that repeatedly fails processing and causes the consumer to crash, retry infinitely, or block the queue.

Common Causes:

  • Malformed/corrupted data
  • Missing required fields
  • Invalid data types
  • Incompatible schema versions
  • Business logic violations
  • External dependency failures

Poison Message Detector​

// services/poison-message-detector.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import { DlqMessage } from '../entities/dlq-message.entity';

export interface PoisonMessageCriteria {
  maxRetries: number;
  timeWindowMinutes: number;
  errorPatterns: string[];
}

@Injectable()
export class PoisonMessageDetectorService {
  private readonly logger = new Logger(PoisonMessageDetectorService.name);
  private readonly messageFailures = new Map<string, number>();
  private readonly messageFirstFailure = new Map<string, Date>();

  constructor(
    @InjectRepository(DlqMessage)
    private dlqRepository: Repository<DlqMessage>,
  ) {}

  /**
   * Check if message is poisoned based on retry count and time window
   */
  isPoisonMessage(messageId: string, error: Error, criteria: PoisonMessageCriteria): boolean {
    const failureCount = this.messageFailures.get(messageId) || 0;
    const firstFailure = this.messageFirstFailure.get(messageId);

    // Check retry count
    if (failureCount >= criteria.maxRetries) {
      this.logger.warn(`Message ${messageId} exceeded max retries (${criteria.maxRetries})`);
      return true;
    }

    // Check time window
    if (firstFailure) {
      const minutesSinceFirstFailure = (Date.now() - firstFailure.getTime()) / (1000 * 60);

      if (minutesSinceFirstFailure <= criteria.timeWindowMinutes && failureCount >= 3) {
        this.logger.warn(`Message ${messageId} failed ${failureCount} times in ${minutesSinceFirstFailure} minutes`);
        return true;
      }
    }

    // Check error patterns
    const errorMessage = error.message.toLowerCase();
    const matchesFatalPattern = criteria.errorPatterns.some((pattern) => errorMessage.includes(pattern.toLowerCase()));

    if (matchesFatalPattern) {
      this.logger.warn(`Message ${messageId} matched fatal error pattern: ${error.message}`);
      return true;
    }

    return false;
  }

  /**
   * Record message failure
   */
  recordFailure(messageId: string): void {
    const currentCount = this.messageFailures.get(messageId) || 0;
    this.messageFailures.set(messageId, currentCount + 1);

    if (!this.messageFirstFailure.has(messageId)) {
      this.messageFirstFailure.set(messageId, new Date());
    }
  }

  /**
   * Clear failure tracking for successfully processed message
   */
  clearFailure(messageId: string): void {
    this.messageFailures.delete(messageId);
    this.messageFirstFailure.delete(messageId);
  }

  /**
   * Get poison message statistics
   */
  async getPoisonMessageStats(days: number = 7): Promise<any> {
    const since = new Date();
    since.setDate(since.getDate() - days);

    const stats = await this.dlqRepository
      .createQueryBuilder('dlq')
      .select('dlq.errorType', 'errorType')
      .addSelect('dlq.originalTopic', 'topic')
      .addSelect('COUNT(*)', 'count')
      .addSelect('AVG(dlq.failureCount)', 'avgRetries')
      .where('dlq.createdAt >= :since', { since })
      .groupBy('dlq.errorType')
      .addGroupBy('dlq.originalTopic')
      .orderBy('count', 'DESC')
      .getRawMany();

    return stats;
  }
}

Retry Strategies​

Exponential Backoff​

// services/retry-strategy.service.ts
import { Injectable, Logger } from '@nestjs/common';

export interface RetryConfig {
  maxRetries: number;
  initialDelayMs: number;
  maxDelayMs: number;
  backoffMultiplier: number;
  jitterEnabled: boolean;
}

@Injectable()
export class RetryStrategyService {
  private readonly logger = new Logger(RetryStrategyService.name);

  /**
   * Calculate delay with exponential backoff
   */
  calculateDelay(attemptNumber: number, config: RetryConfig): number {
    const delay = Math.min(
      config.initialDelayMs * Math.pow(config.backoffMultiplier, attemptNumber),
      config.maxDelayMs,
    );

    // Add jitter to prevent thundering herd
    if (config.jitterEnabled) {
      const jitter = Math.random() * delay * 0.1; // 10% jitter
      return Math.floor(delay + jitter);
    }

    return delay;
  }

  /**
   * Determine if error is retryable
   */
  isRetryable(error: Error): boolean {
    // Network errors - retryable
    if (
      error.message.includes('ECONNREFUSED') ||
      error.message.includes('ETIMEDOUT') ||
      error.message.includes('ENOTFOUND')
    ) {
      return true;
    }

    // Database errors - retryable
    if (
      error.message.includes('connection') ||
      error.message.includes('timeout') ||
      error.message.includes('deadlock')
    ) {
      return true;
    }

    // Rate limiting - retryable
    if (
      error.message.includes('rate limit') ||
      error.message.includes('429') ||
      error.message.includes('too many requests')
    ) {
      return true;
    }

    // Validation errors - NOT retryable
    if (
      error.message.includes('validation') ||
      error.message.includes('invalid') ||
      error.message.includes('malformed')
    ) {
      return false;
    }

    // Business logic errors - NOT retryable
    if (
      error.message.includes('not found') ||
      error.message.includes('already exists') ||
      error.message.includes('unauthorized')
    ) {
      return false;
    }

    // Default to retryable for unknown errors
    return true;
  }

  /**
   * Execute with retry logic
   */
  async executeWithRetry<T>(operation: () => Promise<T>, config: RetryConfig, context: string): Promise<T> {
    let lastError: Error;

    for (let attempt = 0; attempt <= config.maxRetries; attempt++) {
      try {
        return await operation();
      } catch (error) {
        lastError = error;

        if (!this.isRetryable(error)) {
          this.logger.error(`Non-retryable error in ${context}: ${error.message}`);
          throw error;
        }

        if (attempt < config.maxRetries) {
          const delay = this.calculateDelay(attempt, config);
          this.logger.warn(
            `Retry ${attempt + 1}/${config.maxRetries} for ${context} after ${delay}ms. Error: ${error.message}`,
          );
          await this.sleep(delay);
        }
      }
    }

    this.logger.error(`Max retries (${config.maxRetries}) exceeded for ${context}`);
    throw lastError;
  }

  private sleep(ms: number): Promise<void> {
    return new Promise((resolve) => setTimeout(resolve, ms));
  }
}

DLQ Implementation - Kafka​

Kafka DLQ Producer​

// kafka/kafka-dlq-producer.service.ts
import { Injectable, Logger, OnModuleInit } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';
import { Kafka, Producer, CompressionTypes } from 'kafkajs';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import { DlqMessage } from '../entities/dlq-message.entity';

@Injectable()
export class KafkaDlqProducerService implements OnModuleInit {
  private readonly logger = new Logger(KafkaDlqProducerService.name);
  private producer: Producer;
  private readonly kafka: Kafka;

  constructor(
    private configService: ConfigService,
    @InjectRepository(DlqMessage)
    private dlqRepository: Repository<DlqMessage>,
  ) {
    this.kafka = new Kafka({
      clientId: 'dlq-producer',
      brokers: this.configService.get('KAFKA_BROKERS').split(','),
    });
  }

  async onModuleInit() {
    this.producer = this.kafka.producer({
      idempotent: true,
      maxInFlightRequests: 5,
      transactionalId: 'dlq-producer-tx',
    });

    await this.producer.connect();
    this.logger.log('Kafka DLQ Producer connected');
  }

  /**
   * Send message to DLQ topic
   */
  async sendToDlq(
    originalTopic: string,
    message: any,
    error: Error,
    metadata: {
      partition?: number;
      headers?: Record<string, string>;
      failureCount: number;
      firstFailureTime: Date;
    },
  ): Promise<void> {
    const dlqTopic = `${originalTopic}.dlq`;
    const messageId = metadata.headers?.messageId || this.generateMessageId();

    try {
      // Save to database
      const dlqMessage = this.dlqRepository.create({
        messageId,
        originalTopic,
        originalPartition: metadata.partition,
        failureCount: metadata.failureCount,
        firstFailureTime: metadata.firstFailureTime,
        lastFailureTime: new Date(),
        errorType: error.constructor.name,
        errorMessage: error.message,
        stackTrace: error.stack,
        headers: metadata.headers || {},
        payload: message,
        status: 'pending',
      });

      await this.dlqRepository.save(dlqMessage);

      // Send to DLQ topic
      await this.producer.send({
        topic: dlqTopic,
        compression: CompressionTypes.GZIP,
        messages: [
          {
            key: messageId,
            value: JSON.stringify({
              originalTopic,
              originalPartition: metadata.partition,
              failureCount: metadata.failureCount,
              firstFailureTime: metadata.firstFailureTime,
              lastFailureTime: new Date(),
              errorType: error.constructor.name,
              errorMessage: error.message,
              stackTrace: error.stack,
              payload: message,
            }),
            headers: {
              'x-original-topic': originalTopic,
              'x-failure-count': metadata.failureCount.toString(),
              'x-error-type': error.constructor.name,
              ...metadata.headers,
            },
          },
        ],
      });

      this.logger.warn(`Message ${messageId} sent to DLQ topic ${dlqTopic} after ${metadata.failureCount} failures`);
    } catch (dlqError) {
      this.logger.error(`Failed to send message to DLQ: ${dlqError.message}`, dlqError.stack);
      // Critical: DLQ itself failed, log to external system
      await this.logToCriticalStorage(messageId, originalTopic, message, error);
    }
  }

  /**
   * Fallback storage when DLQ fails
   */
  private async logToCriticalStorage(messageId: string, topic: string, message: any, error: Error): Promise<void> {
    // Write to file system, S3, or external monitoring system
    this.logger.error({
      type: 'DLQ_FAILURE',
      messageId,
      topic,
      message,
      error: {
        name: error.name,
        message: error.message,
        stack: error.stack,
      },
    });
  }

  private generateMessageId(): string {
    return `${Date.now()}-${Math.random().toString(36).substr(2, 9)}`;
  }

  async onModuleDestroy() {
    await this.producer.disconnect();
  }
}

// kafka/kafka-consumer-with-dlq.service.ts
import { Injectable, Logger, OnModuleInit } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';
import { Kafka, Consumer, EachMessagePayload } from 'kafkajs';
import { PoisonMessageDetectorService } from '../services/poison-message-detector.service';
import { RetryStrategyService } from '../services/retry-strategy.service';
import { KafkaDlqProducerService } from './kafka-dlq-producer.service';

@Injectable()
export class KafkaConsumerWithDlqService implements OnModuleInit {
  private readonly logger = new Logger(KafkaConsumerWithDlqService.name);
  private consumer: Consumer;
  private readonly kafka: Kafka;
  private readonly messageFailures = new Map<string, number>();
  private readonly messageFirstFailure = new Map<string, Date>();

  constructor(
    private configService: ConfigService,
    private poisonDetector: PoisonMessageDetectorService,
    private retryStrategy: RetryStrategyService,
    private dlqProducer: KafkaDlqProducerService,
  ) {
    this.kafka = new Kafka({
      clientId: 'order-consumer',
      brokers: this.configService.get('KAFKA_BROKERS').split(','),
    });
  }

  async onModuleInit() {
    this.consumer = this.kafka.consumer({
      groupId: 'order-service-group',
      retry: {
        retries: 0, // We handle retries ourselves
      },
    });

    await this.consumer.connect();
    await this.consumer.subscribe({
      topics: ['orders.created', 'orders.updated'],
      fromBeginning: false,
    });

    await this.consumer.run({
      eachMessage: async (payload) => this.handleMessage(payload),
    });

    this.logger.log('Kafka Consumer with DLQ started');
  }

  private async handleMessage(payload: EachMessagePayload): Promise<void> {
    const { topic, partition, message } = payload;
    const messageId = message.headers?.messageId?.toString() || message.key?.toString();

    try {
      // Parse message
      const parsedMessage = JSON.parse(message.value.toString());

      // Process with retry logic
      await this.retryStrategy.executeWithRetry(
        () => this.processMessage(parsedMessage),
        {
          maxRetries: 3,
          initialDelayMs: 1000,
          maxDelayMs: 30000,
          backoffMultiplier: 2,
          jitterEnabled: true,
        },
        `Message ${messageId}`,
      );

      // Clear failure tracking on success
      this.poisonDetector.clearFailure(messageId);
      this.messageFailures.delete(messageId);
      this.messageFirstFailure.delete(messageId);

      this.logger.debug(`Successfully processed message ${messageId}`);
    } catch (error) {
      await this.handleFailure(topic, partition, message, error);
    }
  }

  private async handleFailure(topic: string, partition: number, message: any, error: Error): Promise<void> {
    const messageId = message.headers?.messageId?.toString() || message.key?.toString();

    // Record failure
    this.poisonDetector.recordFailure(messageId);
    const failureCount = (this.messageFailures.get(messageId) || 0) + 1;
    this.messageFailures.set(messageId, failureCount);

    if (!this.messageFirstFailure.has(messageId)) {
      this.messageFirstFailure.set(messageId, new Date());
    }

    const firstFailureTime = this.messageFirstFailure.get(messageId);

    // Check if message is poisoned
    const isPoisoned = this.poisonDetector.isPoisonMessage(messageId, error, {
      maxRetries: 5,
      timeWindowMinutes: 10,
      errorPatterns: ['validation failed', 'malformed', 'invalid schema', 'deserialization error'],
    });

    if (isPoisoned) {
      this.logger.error(`Poison message detected: ${messageId}. Moving to DLQ.`);

      await this.dlqProducer.sendToDlq(topic, JSON.parse(message.value.toString()), error, {
        partition,
        headers: this.convertHeaders(message.headers),
        failureCount,
        firstFailureTime,
      });

      // Clean up tracking
      this.messageFailures.delete(messageId);
      this.messageFirstFailure.delete(messageId);
    } else {
      this.logger.warn(`Message ${messageId} failed (attempt ${failureCount}). Will retry.`);
    }
  }

  private async processMessage(message: any): Promise<void> {
    // Actual business logic here
    this.logger.log(`Processing message: ${JSON.stringify(message)}`);

    // Simulate processing
    if (message.orderTotal > 1000000) {
      throw new Error('Order total exceeds maximum allowed value');
    }

    // Process order...
  }

  private convertHeaders(headers: any): Record<string, string> {
    const result: Record<string, string> = {};

    if (headers) {
      for (const [key, value] of Object.entries(headers)) {
        result[key] = value?.toString() || '';
      }
    }

    return result;
  }

  async onModuleDestroy() {
    await this.consumer.disconnect();
  }
}

RabbitMQ DLQ Setup​

// rabbitmq/rabbitmq-dlq-setup.service.ts
import { Injectable, Logger, OnModuleInit } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';
import * as amqp from 'amqplib';

@Injectable()
export class RabbitMqDlqSetupService implements OnModuleInit {
  private readonly logger = new Logger(RabbitMqDlqSetupService.name);
  private connection: amqp.Connection;
  private channel: amqp.Channel;

  constructor(private configService: ConfigService) {}

  async onModuleInit() {
    await this.setupConnection();
    await this.setupDlqInfrastructure();
  }

  private async setupConnection(): Promise<void> {
    const rabbitMqUrl = this.configService.get('RABBITMQ_URL');
    this.connection = await amqp.connect(rabbitMqUrl);
    this.channel = await this.connection.createChannel();
    this.logger.log('RabbitMQ connection established');
  }

  /**
   * Setup DLQ infrastructure with retry delays
   */
  async setupDlqInfrastructure(): Promise<void> {
    const queues = ['orders', 'payments', 'notifications'];

    for (const queueName of queues) {
      // Main queue
      await this.channel.assertQueue(queueName, {
        durable: true,
        deadLetterExchange: `${queueName}.dlx`,
        deadLetterRoutingKey: `${queueName}.dlq`,
      });

      // Dead Letter Exchange
      await this.channel.assertExchange(`${queueName}.dlx`, 'direct', {
        durable: true,
      });

      // Dead Letter Queue
      await this.channel.assertQueue(`${queueName}.dlq`, {
        durable: true,
        messageTtl: 7 * 24 * 60 * 60 * 1000, // 7 days
      });

      // Bind DLQ to DLX
      await this.channel.bindQueue(`${queueName}.dlq`, `${queueName}.dlx`, `${queueName}.dlq`);

      // Retry queue with delay
      await this.channel.assertQueue(`${queueName}.retry`, {
        durable: true,
        messageTtl: 5000, // 5 seconds
        deadLetterExchange: '', // Default exchange
        deadLetterRoutingKey: queueName, // Back to main queue
      });

      this.logger.log(`DLQ infrastructure setup completed for ${queueName}`);
    }
  }

  getChannel(): amqp.Channel {
    return this.channel;
  }

  async onModuleDestroy() {
    await this.channel.close();
    await this.connection.close();
  }
}

RabbitMQ Consumer with DLQ​

// rabbitmq/rabbitmq-consumer-with-dlq.service.ts
import { Injectable, Logger, OnModuleInit } from '@nestjs/common';
import { RabbitMqDlqSetupService } from './rabbitmq-dlq-setup.service';
import { PoisonMessageDetectorService } from '../services/poison-message-detector.service';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import { DlqMessage } from '../entities/dlq-message.entity';
import * as amqp from 'amqplib';

@Injectable()
export class RabbitMqConsumerWithDlqService implements OnModuleInit {
  private readonly logger = new Logger(RabbitMqConsumerWithDlqService.name);
  private channel: amqp.Channel;

  constructor(
    private rabbitMqSetup: RabbitMqDlqSetupService,
    private poisonDetector: PoisonMessageDetectorService,
    @InjectRepository(DlqMessage)
    private dlqRepository: Repository<DlqMessage>,
  ) {}

  async onModuleInit() {
    this.channel = this.rabbitMqSetup.getChannel();
    await this.startConsuming('orders');
  }

  private async startConsuming(queueName: string): Promise<void> {
    await this.channel.consume(
      queueName,
      async (msg) => {
        if (!msg) return;

        try {
          const content = JSON.parse(msg.content.toString());
          const messageId = msg.properties.messageId || this.generateMessageId();

          await this.processMessage(content);

          // Acknowledge successful processing
          this.channel.ack(msg);
          this.poisonDetector.clearFailure(messageId);
        } catch (error) {
          await this.handleMessageFailure(queueName, msg, error);
        }
      },
      { noAck: false },
    );

    this.logger.log(`Started consuming from queue: ${queueName}`);
  }

  private async handleMessageFailure(queueName: string, msg: amqp.ConsumeMessage, error: Error): Promise<void> {
    const messageId = msg.properties.messageId || this.generateMessageId();
    const retryCount = this.getRetryCount(msg);

    this.poisonDetector.recordFailure(messageId);

    // Check if poison message
    const isPoisoned = this.poisonDetector.isPoisonMessage(messageId, error, {
      maxRetries: 3,
      timeWindowMinutes: 5,
      errorPatterns: ['validation', 'malformed', 'invalid'],
    });

    if (isPoisoned || retryCount >= 3) {
      this.logger.error(`Moving message ${messageId} to DLQ after ${retryCount} retries`);

      // Save to database
      await this.saveToDlqDatabase(queueName, msg, error, retryCount);

      // Send to DLQ
      this.channel.sendToQueue(`${queueName}.dlq`, msg.content, {
        headers: {
          ...msg.properties.headers,
          'x-original-queue': queueName,
          'x-retry-count': retryCount,
          'x-error-type': error.constructor.name,
          'x-error-message': error.message,
          'x-failure-time': new Date().toISOString(),
        },
        persistent: true,
      });

      // Acknowledge to remove from main queue
      this.channel.ack(msg);
    } else {
      // Send to retry queue
      this.logger.warn(`Retrying message ${messageId} (attempt ${retryCount + 1})`);

      this.channel.sendToQueue(`${queueName}.retry`, msg.content, {
        headers: {
          ...msg.properties.headers,
          'x-retry-count': retryCount + 1,
        },
        persistent: true,
      });

      this.channel.ack(msg);
    }
  }

  private async saveToDlqDatabase(
    queueName: string,
    msg: amqp.ConsumeMessage,
    error: Error,
    retryCount: number,
  ): Promise<void> {
    const messageId = msg.properties.messageId || this.generateMessageId();
    const content = JSON.parse(msg.content.toString());

    const dlqMessage = this.dlqRepository.create({
      messageId,
      originalTopic: queueName,
      failureCount: retryCount,
      firstFailureTime: new Date(msg.properties.headers?.['x-first-failure'] || Date.now()),
      lastFailureTime: new Date(),
      errorType: error.constructor.name,
      errorMessage: error.message,
      stackTrace: error.stack,
      headers: msg.properties.headers || {},
      payload: content,
      status: 'pending',
    });

    await this.dlqRepository.save(dlqMessage);
  }

  private getRetryCount(msg: amqp.ConsumeMessage): number {
    return parseInt(msg.properties.headers?.['x-retry-count'] || '0');
  }

  private async processMessage(content: any): Promise<void> {
    this.logger.log(`Processing message: ${JSON.stringify(content)}`);
    // Business logic here
  }

  private generateMessageId(): string {
    return `${Date.now()}-${Math.random().toString(36).substr(2, 9)}`;
  }
}

Message Recovery Patterns​

DLQ Message Recovery Service​

// services/dlq-recovery.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import { DlqMessage } from '../entities/dlq-message.entity';
import { Kafka, Producer } from 'kafkajs';
import { ConfigService } from '@nestjs/config';

@Injectable()
export class DlqRecoveryService {
  private readonly logger = new Logger(DlqRecoveryService.name);
  private producer: Producer;

  constructor(
    @InjectRepository(DlqMessage)
    private dlqRepository: Repository<DlqMessage>,
    private configService: ConfigService,
  ) {
    const kafka = new Kafka({
      clientId: 'dlq-recovery',
      brokers: this.configService.get('KAFKA_BROKERS').split(','),
    });
    this.producer = kafka.producer();
  }

  async onModuleInit() {
    await this.producer.connect();
  }

  /**
   * Replay a single DLQ message back to original topic
   */
  async replayMessage(dlqMessageId: string): Promise<void> {
    const dlqMessage = await this.dlqRepository.findOne({
      where: { id: dlqMessageId },
    });

    if (!dlqMessage) {
      throw new Error(`DLQ message ${dlqMessageId} not found`);
    }

    if (dlqMessage.status === 'resolved') {
      throw new Error(`Message ${dlqMessageId} already resolved`);
    }

    try {
      // Send back to original topic
      await this.producer.send({
        topic: dlqMessage.originalTopic,
        messages: [
          {
            key: dlqMessage.messageId,
            value: JSON.stringify(dlqMessage.payload),
            headers: {
              ...dlqMessage.headers,
              'x-replayed': 'true',
              'x-replay-time': new Date().toISOString(),
              'x-dlq-id': dlqMessage.id,
            },
          },
        ],
      });

      // Update status
      dlqMessage.status = 'resolved';
      dlqMessage.resolvedAt = new Date();
      dlqMessage.resolutionNotes = 'Manually replayed to original topic';
      await this.dlqRepository.save(dlqMessage);

      this.logger.log(`Successfully replayed message ${dlqMessageId} to ${dlqMessage.originalTopic}`);
    } catch (error) {
      this.logger.error(`Failed to replay message ${dlqMessageId}: ${error.message}`);
      throw error;
    }
  }

  /**
   * Bulk replay messages by filter
   */
  async replayMessagesByFilter(filter: {
    errorType?: string;
    originalTopic?: string;
    createdAfter?: Date;
    createdBefore?: Date;
    limit?: number;
  }): Promise<{ success: number; failed: number }> {
    const query = this.dlqRepository.createQueryBuilder('dlq').where('dlq.status = :status', { status: 'pending' });

    if (filter.errorType) {
      query.andWhere('dlq.errorType = :errorType', { errorType: filter.errorType });
    }

    if (filter.originalTopic) {
      query.andWhere('dlq.originalTopic = :topic', { topic: filter.originalTopic });
    }

    if (filter.createdAfter) {
      query.andWhere('dlq.createdAt >= :after', { after: filter.createdAfter });
    }

    if (filter.createdBefore) {
      query.andWhere('dlq.createdAt <= :before', { before: filter.createdBefore });
    }

    if (filter.limit) {
      query.limit(filter.limit);
    }

    const messages = await query.getMany();
    let success = 0;
    let failed = 0;

    for (const message of messages) {
      try {
        await this.replayMessage(message.id);
        success++;
      } catch (error) {
        this.logger.error(`Failed to replay message ${message.id}: ${error.message}`);
        failed++;
      }
    }

    this.logger.log(`Bulk replay completed: ${success} successful, ${failed} failed`);

    return { success, failed };
  }

  /**
   * Discard a message (mark as permanently failed)
   */
  async discardMessage(dlqMessageId: string, reason: string): Promise<void> {
    const dlqMessage = await this.dlqRepository.findOne({
      where: { id: dlqMessageId },
    });

    if (!dlqMessage) {
      throw new Error(`DLQ message ${dlqMessageId} not found`);
    }

    dlqMessage.status = 'discarded';
    dlqMessage.resolvedAt = new Date();
    dlqMessage.resolutionNotes = reason;
    await this.dlqRepository.save(dlqMessage);

    this.logger.log(`Message ${dlqMessageId} discarded: ${reason}`);
  }

  /**
   * Get DLQ statistics
   */
  async getDlqStatistics(): Promise<any> {
    const stats = await this.dlqRepository
      .createQueryBuilder('dlq')
      .select('dlq.status', 'status')
      .addSelect('dlq.errorType', 'errorType')
      .addSelect('COUNT(*)', 'count')
      .groupBy('dlq.status')
      .addGroupBy('dlq.errorType')
      .getRawMany();

    const recentMessages = await this.dlqRepository.find({
      order: { createdAt: 'DESC' },
      take: 10,
    });

    return {
      statistics: stats,
      recentMessages,
      totalPending: await this.dlqRepository.count({ where: { status: 'pending' } }),
      totalResolved: await this.dlqRepository.count({ where: { status: 'resolved' } }),
      totalDiscarded: await this.dlqRepository.count({ where: { status: 'discarded' } }),
    };
  }
}

  }

    @Body()
    filter: {

      originalTopic?: string;

    const result = await this.dlqRecoveryService.replayMessagesByFilter(filter);
    return result;
  }

  }

DLQ Alerting Service​

// services/dlq-alerting.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { Cron, CronExpression } from '@nestjs/schedule';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import { DlqMessage } from '../entities/dlq-message.entity';

@Injectable()
export class DlqAlertingService {
  private readonly logger = new Logger(DlqAlertingService.name);

  constructor(
    @InjectRepository(DlqMessage)
    private dlqRepository: Repository<DlqMessage>,
  ) {}

  /**
   * Check for DLQ threshold violations every 5 minutes
   */
  @Cron(CronExpression.EVERY_5_MINUTES)
  async checkDlqThresholds(): Promise<void> {
    const pendingCount = await this.dlqRepository.count({
      where: { status: 'pending' },
    });

    // Alert if too many pending messages
    if (pendingCount > 100) {
      await this.sendAlert({
        severity: 'warning',
        title: 'High DLQ message count',
        message: `${pendingCount} messages pending in DLQ`,
        action: 'Review and replay or discard messages',
      });
    }

    // Check for old unresolved messages
    const oldMessages = await this.dlqRepository
      .createQueryBuilder('dlq')
      .where('dlq.status = :status', { status: 'pending' })
      .andWhere('dlq.createdAt < :cutoff', {
        cutoff: new Date(Date.now() - 7 * 24 * 60 * 60 * 1000), // 7 days
      })
      .getCount();

    if (oldMessages > 0) {
      await this.sendAlert({
        severity: 'warning',
        title: 'Old DLQ messages detected',
        message: `${oldMessages} messages in DLQ for more than 7 days`,
        action: 'Review and resolve old messages',
      });
    }
  }

  /**
   * Check for poison message patterns
   */
  @Cron(CronExpression.EVERY_HOUR)
  async checkPoisonMessagePatterns(): Promise<void> {
    const recentPoisonMessages = await this.dlqRepository
      .createQueryBuilder('dlq')
      .select('dlq.errorType', 'errorType')
      .addSelect('COUNT(*)', 'count')
      .where('dlq.createdAt >= :cutoff', {
        cutoff: new Date(Date.now() - 60 * 60 * 1000), // Last hour
      })
      .groupBy('dlq.errorType')
      .having('COUNT(*) > :threshold', { threshold: 10 })
      .getRawMany();

    for (const pattern of recentPoisonMessages) {
      await this.sendAlert({
        severity: 'error',
        title: 'Poison message pattern detected',
        message: `${pattern.count} messages with error type '${pattern.errorType}' in the last hour`,
        action: 'Investigate root cause and fix application code',
      });
    }
  }

  private async sendAlert(alert: { severity: string; title: string; message: string; action: string }): Promise<void> {
    this.logger.warn({
      type: 'DLQ_ALERT',
      ...alert,
    });

Error Classification​

Error Classifier​

// services/error-classifier.service.ts
import { Injectable } from '@nestjs/common';

export enum ErrorCategory {
  TRANSIENT = 'TRANSIENT', // Temporary, retry will likely succeed
  INFRASTRUCTURE = 'INFRASTRUCTURE', // Network, database, external service issues
  VALIDATION = 'VALIDATION', // Invalid input, schema errors
  BUSINESS_LOGIC = 'BUSINESS_LOGIC', // Business rule violations
  CONFIGURATION = 'CONFIGURATION', // Missing config, invalid setup
  UNKNOWN = 'UNKNOWN', // Unclassified errors
}

export interface ErrorClassification {
  category: ErrorCategory;
  retryable: boolean;
  maxRetries: number;
  backoffMultiplier: number;
  severity: 'low' | 'medium' | 'high' | 'critical';
}

@Injectable()
export class ErrorClassifierService {
  /**
   * Classify error and determine handling strategy
   */
  classifyError(error: Error): ErrorClassification {
    const message = error.message.toLowerCase();
    const errorName = error.constructor.name;

    // Transient errors - retry aggressively
    if (this.isTransientError(message, errorName)) {
      return {
        category: ErrorCategory.TRANSIENT,
        retryable: true,
        maxRetries: 5,
        backoffMultiplier: 2,
        severity: 'medium',
      };
    }

    // Infrastructure errors - retry with backoff
    if (this.isInfrastructureError(message, errorName)) {
      return {
        category: ErrorCategory.INFRASTRUCTURE,
        retryable: true,
        maxRetries: 3,
        backoffMultiplier: 3,
        severity: 'high',
      };
    }

    // Validation errors - don't retry
    if (this.isValidationError(message, errorName)) {
      return {
        category: ErrorCategory.VALIDATION,
        retryable: false,
        maxRetries: 0,
        backoffMultiplier: 1,
        severity: 'low',
      };
    }

    // Business logic errors - don't retry
    if (this.isBusinessLogicError(message, errorName)) {
      return {
        category: ErrorCategory.BUSINESS_LOGIC,
        retryable: false,
        maxRetries: 0,
        backoffMultiplier: 1,
        severity: 'medium',
      };
    }

    // Configuration errors - alert but don't retry
    if (this.isConfigurationError(message, errorName)) {
      return {
        category: ErrorCategory.CONFIGURATION,
        retryable: false,
        maxRetries: 0,
        backoffMultiplier: 1,
        severity: 'critical',
      };
    }

    // Unknown errors - retry conservatively
    return {
      category: ErrorCategory.UNKNOWN,
      retryable: true,
      maxRetries: 2,
      backoffMultiplier: 2,
      severity: 'high',
    };
  }

  private isTransientError(message: string, errorName: string): boolean {
    const patterns = [
      'timeout',
      'rate limit',
      'too many requests',
      '429',
      '503',
      'service unavailable',
      'temporarily unavailable',
    ];

    return patterns.some((pattern) => message.includes(pattern));
  }

  private isInfrastructureError(message: string, errorName: string): boolean {
    const patterns = [
      'econnrefused',
      'enotfound',
      'etimedout',
      'connection',
      'network',
      'socket',
      'database',
      'deadlock',
    ];

    return patterns.some((pattern) => message.includes(pattern));
  }

  private isValidationError(message: string, errorName: string): boolean {
    const patterns = [
      'validation',
      'invalid',
      'malformed',
      'schema',
      'required field',
      'missing',
      '400',
      'bad request',
    ];

    return patterns.some((pattern) => message.includes(pattern)) || errorName.includes('Validation');
  }

  private isBusinessLogicError(message: string, errorName: string): boolean {
    const patterns = [
      'not found',
      '404',
      'already exists',
      'duplicate',
      'unauthorized',
      '401',
      'forbidden',
      '403',
      'insufficient',
      'exceeded',
    ];

    return patterns.some((pattern) => message.includes(pattern));
  }

  private isConfigurationError(message: string, errorName: string): boolean {
    const patterns = ['configuration', 'config', 'environment variable', 'missing credential', 'invalid credential'];

    return patterns.some((pattern) => message.includes(pattern));
  }
}

Best Practices​

1. DLQ Design​

✅ Do:

  • Create separate DLQ for each main queue
  • Set retention policies on DLQ messages (7-30 days)
  • Store DLQ messages in database for analysis
  • Include comprehensive error metadata
  • Implement monitoring and alerting
  • Design for idempotent message processing

❌ Don't:

  • Use single DLQ for all queues
  • Keep messages in DLQ indefinitely
  • Lose error context and stack traces
  • Auto-replay without investigating root cause
  • Ignore DLQ metrics
  • Process messages without idempotency checks

2. Retry Strategy​

✅ Do:

  • Use exponential backoff with jitter
  • Classify errors (transient vs permanent)
  • Set maximum retry limits
  • Add delay between retries
  • Log each retry attempt
  • Track retry metrics

❌ Don't:

  • Retry immediately without delay
  • Retry all errors equally
  • Retry indefinitely
  • Skip error classification
  • Hide retry failures
  • Retry non-idempotent operations

3. Poison Message Handling​

✅ Do:

  • Detect poison messages early
  • Move to DLQ after threshold
  • Alert on poison message patterns
  • Preserve original message data
  • Document common poison message causes
  • Test with malformed messages

❌ Don't:

  • Let poison messages block queue
  • Discard without analysis
  • Ignore recurring patterns
  • Lose message context
  • Skip root cause analysis
  • Deploy without poison message tests

4. Monitoring​

✅ Do:

  • Track DLQ message count
  • Monitor retry attempts
  • Alert on threshold violations
  • Dashboard DLQ metrics
  • Track error patterns
  • Set up automated alerts

❌ Don't:

  • Deploy without monitoring
  • Ignore DLQ growth
  • Skip alerting
  • Hide error details
  • Forget to track trends
  • React only to outages

5. Recovery​

✅ Do:

  • Provide admin UI for DLQ management
  • Support bulk replay operations
  • Validate before replaying
  • Track replay success rate
  • Document recovery procedures
  • Test recovery process

❌ Don't:

  • Manual database operations
  • Replay without investigation
  • Skip validation
  • Forget to update message status
  • Deploy without recovery plan
  • Skip testing recovery

Summary​

Effective DLQ and poison message handling provides:

  • Resilience - System continues despite message failures
  • Visibility - Failed messages are tracked and analyzed
  • Recovery - Messages can be replayed after fixes
  • Throughput - Poison messages don't block processing
  • Debugging - Comprehensive error information

Key implementation points:

  • Separate DLQ for each queue
  • Exponential backoff with jitter
  • Error classification (retryable vs permanent)
  • Poison message detection (max retries, time window, error patterns)
  • Database storage for DLQ messages
  • Admin interface for recovery
  • Comprehensive monitoring and alerting
  • Kafka and RabbitMQ implementations
  • Bulk replay capabilities
  • Error categorization service

Remember: Good DLQ implementation is about failing gracefully and recovering intelligently!
