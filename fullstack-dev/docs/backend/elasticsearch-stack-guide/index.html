Elasticsearch Stack Implementation Guide

Overview​

The Elasticsearch Stack (ELK Stack) combines Elasticsearch, Logstash, and Kibana to provide powerful search, analytics, and visualization capabilities. This guide demonstrates production-ready implementations for e-commerce platforms including product search, log aggregation, analytics, and monitoring.

Key Components​

  • Elasticsearch: Distributed search and analytics engine
  • Logstash: Data processing pipeline for ingesting and transforming data
  • Kibana: Visualization and exploration platform
  • Beats: Lightweight data shippers (Filebeat, Metricbeat, APM)

Architecture​

The Elasticsearch Stack follows a distributed architecture designed for scalability, reliability, and high performance. Understanding this architecture is crucial for building production-ready search and analytics solutions.

High-Level Architecture​

Cluster Architecture​

1. Cluster Structure​

An Elasticsearch cluster consists of one or more nodes working together to store data and provide search capabilities:

  • Cluster: A collection of nodes identified by a unique cluster name
  • Node: A single server that stores data and participates in cluster operations
  • Index: A collection of documents with similar characteristics (similar to a database)
  • Shard: A subset of an index's data, enabling horizontal scaling
  • Replica: A copy of a shard for high availability and increased read throughput

2. Node Types​

Different node types serve specific purposes in the cluster:

Master-Eligible Nodes (Gold in diagram)

  • Manage cluster-wide operations
  • Track cluster state and membership
  • Handle index creation/deletion
  • Elect one master among themselves
  • Recommended: 3 dedicated master nodes for production

Data Nodes (Blue in diagram)

  • Store indexed data
  • Perform CRUD operations
  • Execute queries and aggregations
  • Handle search operations
  • Scale horizontally for increased storage and query capacity

Coordinating Nodes (Green in diagram)

  • Route requests to appropriate data nodes
  • Merge and reduce results from multiple nodes
  • Don't hold data or perform indexing
  • Act as smart load balancers
  • Reduce load on data nodes

Ingest Nodes (Purple in diagram)

  • Pre-process documents before indexing
  • Execute ingest pipelines
  • Transform and enrich data
  • Offload processing from data nodes

Machine Learning Nodes (Optional)

  • Run machine learning jobs
  • Perform anomaly detection
  • Handle forecasting operations

3. Sharding Strategy​

Shards are the fundamental units of scalability in Elasticsearch:

Primary Shards (Red in diagram)

  • Original shards containing unique portions of data
  • Number set at index creation time
  • Each document belongs to exactly one primary shard
  • Formula: shard_num = hash(routing_value) % num_primary_shards

Replica Shards (Teal in diagram)

  • Exact copies of primary shards
  • Provide high availability and fault tolerance
  • Increase read throughput
  • Can be added/removed dynamically
  • Never allocated on the same node as their primary

Best Practices:

  • Start with 1 shard per 50GB of data
  • Plan for growth: over-sharding is costly
  • Use 1-2 replicas for production (minimum)
  • Consider hot-warm-cold architecture for time-series data

4. Data Flow​

Indexing Process:

  1. Client sends document to coordinating node
  2. Coordinating node determines target shard using document ID
  3. Request forwarded to primary shard
  4. Primary shard indexes document
  5. Primary replicates to all replica shards
  6. Once replicas confirm, success returned to client

Search Process:

  1. Client sends search request to coordinating node
  2. Coordinating node broadcasts to relevant shards (primary or replica)
  3. Each shard executes query locally
  4. Results sent back to coordinating node
  5. Coordinating node merges and sorts results
  6. Final results returned to client

Ingestion Pipeline:

Beats/Logstash → Ingest Nodes → Data Nodes → Index Shards

5. High Availability​

Elasticsearch ensures high availability through:

  • Replication: Multiple copies of data across nodes
  • Shard Allocation: Never placing primary and replica on same node
  • Automatic Failover: Replica promoted to primary if node fails
  • Cluster Health: Green (all shards allocated), Yellow (primaries allocated), Red (some primaries missing)
  • Split Brain Prevention: Minimum master nodes configuration
  • Snapshot & Restore: Regular backups to external storage

6. Scaling Strategies​

Vertical Scaling:

  • Increase CPU, RAM, or disk on existing nodes
  • Limited by hardware constraints
  • Useful for resource-intensive operations

Horizontal Scaling:

  • Add more nodes to cluster
  • Elasticsearch automatically rebalances shards
  • Linear scalability for most use cases
  • Preferred approach for production

Index Lifecycle Management (ILM):

Hot → Warm → Cold → Delete
  • Hot: Actively indexed and queried (SSD, powerful nodes)
  • Warm: No longer indexed, less frequently queried (HDD, fewer resources)
  • Cold: Rarely accessed, searchable snapshots (minimal resources)
  • Delete: Remove old data based on retention policy

7. Performance Optimization​

Query Optimization:

  • Use filters instead of queries when scoring isn't needed
  • Leverage query cache for frequently used filters
  • Use appropriate shard routing for targeted searches
  • Implement pagination with search_after for deep pagination

Indexing Optimization:

  • Bulk indexing for high throughput
  • Disable replicas during initial bulk load
  • Tune refresh interval (default 1s)
  • Use separate ingest nodes for preprocessing

Hardware Considerations:

  • RAM: At least 50% for OS file cache
  • CPU: More cores for better query performance
  • Disk: SSDs for data nodes, especially hot tier
  • Network: High bandwidth for cluster communication

@Injectable()
export class SearchIndexService implements OnModuleInit {
  private readonly logger = new Logger(SearchIndexService.name);
  private readonly PRODUCT_INDEX = 'products';

  constructor(private readonly elasticsearchService: ElasticsearchService) {}

  async onModuleInit() {
    await this.createProductIndex();
  }

  async createProductIndex() {
    const indexExists = await this.elasticsearchService.indices.exists({
      index: this.PRODUCT_INDEX,
    });

    if (indexExists) {
      this.logger.log(`Index ${this.PRODUCT_INDEX} already exists`);
      return;
    }

    try {
      await this.elasticsearchService.indices.create({
        index: this.PRODUCT_INDEX,
        body: {
          settings: {
            number_of_shards: 3,
            number_of_replicas: 2,
            analysis: {
              analyzer: {
                // Custom analyzer for product names
                product_name_analyzer: {
                  type: 'custom',
                  tokenizer: 'standard',
                  filter: ['lowercase', 'asciifolding', 'product_synonym', 'edge_ngram_filter'],
                },
                // Autocomplete analyzer
                autocomplete_analyzer: {
                  type: 'custom',
                  tokenizer: 'standard',
                  filter: ['lowercase', 'autocomplete_filter'],
                },
                autocomplete_search_analyzer: {
                  type: 'custom',
                  tokenizer: 'standard',
                  filter: ['lowercase'],
                },
              },
              filter: {
                edge_ngram_filter: {
                  type: 'edge_ngram',
                  min_gram: 2,
                  max_gram: 20,
                },
                autocomplete_filter: {
                  type: 'edge_ngram',
                  min_gram: 1,
                  max_gram: 20,
                },
                product_synonym: {
                  type: 'synonym',
                  synonyms: ['phone, smartphone, mobile', 'laptop, notebook, computer', 'tv, television'],
                },
              },
            },
          },
          mappings: {
            properties: {
              id: { type: 'keyword' },
              name: {
                type: 'text',
                analyzer: 'product_name_analyzer',
                fields: {
                  keyword: { type: 'keyword' },
                  autocomplete: {
                    type: 'text',
                    analyzer: 'autocomplete_analyzer',
                    search_analyzer: 'autocomplete_search_analyzer',
                  },
                },
              },
              description: {
                type: 'text',
                analyzer: 'standard',
              },
              category: {
                type: 'keyword',
                fields: {
                  text: { type: 'text' },
                },
              },
              brand: {
                type: 'keyword',
                fields: {
                  text: { type: 'text' },
                },
              },
              price: { type: 'float' },
              salePrice: { type: 'float' },
              stock: { type: 'integer' },
              rating: { type: 'float' },
              reviewCount: { type: 'integer' },
              tags: { type: 'keyword' },
              attributes: { type: 'object', enabled: true },
              images: { type: 'keyword' },
              createdAt: { type: 'date' },
              updatedAt: { type: 'date' },
            },
          },
        },
      });

      this.logger.log(`Created index: ${this.PRODUCT_INDEX}`);
    } catch (error) {
      this.logger.error(`Failed to create index: ${error.message}`);
      throw error;
    }
  }

  async indexProduct(product: ProductDocument): Promise<void> {
    try {
      await this.elasticsearchService.index({
        index: this.PRODUCT_INDEX,
        id: product.id,
        document: product,
      });

      this.logger.log(`Indexed product: ${product.id}`);
    } catch (error) {
      this.logger.error(`Failed to index product ${product.id}: ${error.message}`);
      throw error;
    }
  }

  async bulkIndexProducts(products: ProductDocument[]): Promise<void> {
    if (products.length === 0) {
      return;
    }

    try {
      const operations = products.flatMap((product) => [
        { index: { _index: this.PRODUCT_INDEX, _id: product.id } },
        product,
      ]);

      const bulkResponse = await this.elasticsearchService.bulk({
        refresh: true,
        operations,
      });

      if (bulkResponse.errors) {
        const erroredDocuments = [];
        bulkResponse.items.forEach((action, i) => {
          const operation = Object.keys(action)[0];
          if (action[operation].error) {
            erroredDocuments.push({
              status: action[operation].status,
              error: action[operation].error,
              document: products[i],
            });
          }
        });

        this.logger.error(`Bulk indexing errors: ${JSON.stringify(erroredDocuments)}`);
      }

      this.logger.log(`Bulk indexed ${products.length} products`);
    } catch (error) {
      this.logger.error(`Bulk indexing failed: ${error.message}`);
      throw error;
    }
  }

  async deleteProduct(productId: string): Promise<void> {
    try {
      await this.elasticsearchService.delete({
        index: this.PRODUCT_INDEX,
        id: productId,
      });

      this.logger.log(`Deleted product: ${productId}`);
    } catch (error) {
      if (error.meta?.statusCode === 404) {
        this.logger.warn(`Product not found: ${productId}`);
        return;
      }
      this.logger.error(`Failed to delete product ${productId}: ${error.message}`);
      throw error;
    }
  }

  async updateProduct(productId: string, updates: Partial<ProductDocument>): Promise<void> {
    try {
      await this.elasticsearchService.update({
        index: this.PRODUCT_INDEX,
        id: productId,
        doc: updates,
      });

      this.logger.log(`Updated product: ${productId}`);
    } catch (error) {
      this.logger.error(`Failed to update product ${productId}: ${error.message}`);
      throw error;
    }
  }

  async reindexAll(products: ProductDocument[]): Promise<void> {
    this.logger.log('Starting full reindex...');

    try {
      // Delete existing index
      const indexExists = await this.elasticsearchService.indices.exists({
        index: this.PRODUCT_INDEX,
      });

      if (indexExists) {
        await this.elasticsearchService.indices.delete({
          index: this.PRODUCT_INDEX,
        });
      }

      // Create new index
      await this.createProductIndex();

      // Bulk index all products
      await this.bulkIndexProducts(products);

      this.logger.log('Full reindex completed');
    } catch (error) {
      this.logger.error(`Full reindex failed: ${error.message}`);
      throw error;
    }
  }
}
// product-search.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { ElasticsearchService } from '@nestjs/elasticsearch';

export interface SearchQuery {
  query?: string;
  category?: string;
  brand?: string;
  minPrice?: number;
  maxPrice?: number;
  minRating?: number;
  tags?: string[];
  inStock?: boolean;
  sortBy?: 'relevance' | 'price_asc' | 'price_desc' | 'rating' | 'newest';
  page?: number;
  limit?: number;
}

export interface SearchResult {
  products: any[];
  total: number;
  page: number;
  limit: number;
  aggregations?: {
    categories: Array<{ key: string; count: number }>;
    brands: Array<{ key: string; count: number }>;
    priceRanges: Array<{ key: string; count: number; from?: number; to?: number }>;
    tags: Array<{ key: string; count: number }>;
  };
}

@Injectable()
export class ProductSearchService {
  private readonly logger = new Logger(ProductSearchService.name);
  private readonly PRODUCT_INDEX = 'products';

  constructor(private readonly elasticsearchService: ElasticsearchService) {}

  async search(searchQuery: SearchQuery): Promise<SearchResult> {
    const {
      query,
      category,
      brand,
      minPrice,
      maxPrice,
      minRating,
      tags,
      inStock,
      sortBy = 'relevance',
      page = 1,
      limit = 20,
    } = searchQuery;

    const from = (page - 1) * limit;

    try {
      // Build query
      const must: any[] = [];
      const filter: any[] = [];

      // Text search
      if (query) {
        must.push({
          multi_match: {
            query,
            fields: ['name^3', 'description', 'brand^2', 'category^2', 'tags'],
            type: 'best_fields',
            fuzziness: 'AUTO',
          },
        });
      } else {
        must.push({ match_all: {} });
      }

      // Category filter
      if (category) {
        filter.push({ term: { category } });
      }

      // Brand filter
      if (brand) {
        filter.push({ term: { brand } });
      }

      // Price range filter
      if (minPrice !== undefined || maxPrice !== undefined) {
        const priceRange: any = {};
        if (minPrice !== undefined) priceRange.gte = minPrice;
        if (maxPrice !== undefined) priceRange.lte = maxPrice;
        filter.push({ range: { price: priceRange } });
      }

      // Rating filter
      if (minRating !== undefined) {
        filter.push({ range: { rating: { gte: minRating } } });
      }

      // Tags filter
      if (tags && tags.length > 0) {
        filter.push({ terms: { tags } });
      }

      // Stock filter
      if (inStock) {
        filter.push({ range: { stock: { gt: 0 } } });
      }

      // Build sort
      const sort: any[] = [];
      switch (sortBy) {
        case 'price_asc':
          sort.push({ price: 'asc' });
          break;
        case 'price_desc':
          sort.push({ price: 'desc' });
          break;
        case 'rating':
          sort.push({ rating: 'desc' }, { reviewCount: 'desc' });
          break;
        case 'newest':
          sort.push({ createdAt: 'desc' });
          break;
        default:
          sort.push('_score');
      }

      const response = await this.elasticsearchService.search({
        index: this.PRODUCT_INDEX,
        body: {
          query: {
            bool: {
              must,
              filter,
            },
          },
          sort,
          from,
          size: limit,
          aggs: {
            categories: {
              terms: { field: 'category', size: 20 },
            },
            brands: {
              terms: { field: 'brand', size: 20 },
            },
            priceRanges: {
              range: {
                field: 'price',
                ranges: [
                  { key: 'Under $25', to: 25 },
                  { key: '$25 - $50', from: 25, to: 50 },
                  { key: '$50 - $100', from: 50, to: 100 },
                  { key: '$100 - $200', from: 100, to: 200 },
                  { key: 'Over $200', from: 200 },
                ],
              },
            },
            tags: {
              terms: { field: 'tags', size: 30 },
            },
          },
        },
      });

      const hits = response.hits.hits;
      const total = typeof response.hits.total === 'number' ? response.hits.total : response.hits.total.value;

      const products = hits.map((hit) => ({
        id: hit._id,
        score: hit._score,
        ...hit._source,
      }));

      const aggregations = {
        categories: response.aggregations.categories.buckets.map((b: any) => ({
          key: b.key,
          count: b.doc_count,
        })),
        brands: response.aggregations.brands.buckets.map((b: any) => ({
          key: b.key,
          count: b.doc_count,
        })),
        priceRanges: response.aggregations.priceRanges.buckets.map((b: any) => ({
          key: b.key,
          count: b.doc_count,
          from: b.from,
          to: b.to,
        })),
        tags: response.aggregations.tags.buckets.map((b: any) => ({
          key: b.key,
          count: b.doc_count,
        })),
      };

      return {
        products,
        total,
        page,
        limit,
        aggregations,
      };
    } catch (error) {
      this.logger.error(`Search failed: ${error.message}`);
      throw error;
    }
  }

  async autocomplete(query: string, limit = 10): Promise<string[]> {
    if (!query || query.length < 2) {
      return [];
    }

    try {
      const response = await this.elasticsearchService.search({
        index: this.PRODUCT_INDEX,
        body: {
          query: {
            match: {
              'name.autocomplete': query,
            },
          },
          _source: ['name'],
          size: limit,
        },
      });

      return response.hits.hits.map((hit: any) => hit._source.name);
    } catch (error) {
      this.logger.error(`Autocomplete failed: ${error.message}`);
      return [];
    }
  }

  async getSimilarProducts(productId: string, limit = 6): Promise<any[]> {
    try {
      // Get the product
      const product = await this.elasticsearchService.get({
        index: this.PRODUCT_INDEX,
        id: productId,
      });

      const productData: any = product._source;

      // Find similar products
      const response = await this.elasticsearchService.search({
        index: this.PRODUCT_INDEX,
        body: {
          query: {
            bool: {
              must: [
                {
                  more_like_this: {
                    fields: ['name', 'description', 'tags'],
                    like: [
                      {
                        _index: this.PRODUCT_INDEX,
                        _id: productId,
                      },
                    ],
                    min_term_freq: 1,
                    max_query_terms: 12,
                  },
                },
              ],
              filter: [{ term: { category: productData.category } }],
              must_not: [{ term: { id: productId } }],
            },
          },
          size: limit,
        },
      });

      return response.hits.hits.map((hit: any) => ({
        id: hit._id,
        score: hit._score,
        ...hit._source,
      }));
    } catch (error) {
      this.logger.error(`Similar products search failed: ${error.message}`);
      return [];
    }
  }
}

// product-search.controller.ts
import { Controller, Get, Query, Param } from '@nestjs/common';
import { ProductSearchService, SearchQuery } from './product-search.service';

@Controller('api/search')
export class ProductSearchController {
  constructor(private readonly searchService: ProductSearchService) {}

  @Get('products')
  async searchProducts(
    @Query('q') query?: string,
    @Query('category') category?: string,
    @Query('brand') brand?: string,
    @Query('minPrice') minPrice?: string,
    @Query('maxPrice') maxPrice?: string,
    @Query('minRating') minRating?: string,
    @Query('tags') tags?: string,
    @Query('inStock') inStock?: string,
    @Query('sortBy') sortBy?: string,
    @Query('page') page?: string,
    @Query('limit') limit?: string,
  ) {
    const searchQuery: SearchQuery = {
      query,
      category,
      brand,
      minPrice: minPrice ? parseFloat(minPrice) : undefined,
      maxPrice: maxPrice ? parseFloat(maxPrice) : undefined,
      minRating: minRating ? parseFloat(minRating) : undefined,
      tags: tags ? tags.split(',') : undefined,
      inStock: inStock === 'true',
      sortBy: sortBy as any,
      page: page ? parseInt(page, 10) : 1,
      limit: limit ? parseInt(limit, 10) : 20,
    };

    return this.searchService.search(searchQuery);
  }

  @Get('autocomplete')
  async autocomplete(@Query('q') query: string) {
    return this.searchService.autocomplete(query);
  }

  @Get('products/:id/similar')
  async getSimilarProducts(@Param('id') productId: string) {
    return this.searchService.getSimilarProducts(productId);
  }
}

// winston-elasticsearch.config.ts
import { WinstonModule } from 'nest-winston';
import * as winston from 'winston';
import { ElasticsearchTransport } from 'winston-elasticsearch';

export const createLogger = () => {
  const esTransportOpts = {
    level: 'info',
    clientOpts: {
      node: process.env.ELASTICSEARCH_NODE || 'http://localhost:9200',
      auth: {
        username: process.env.ELASTICSEARCH_USERNAME || 'elastic',
        password: process.env.ELASTICSEARCH_PASSWORD || 'changeme',
      },
    },
    index: 'logs-ecommerce',
    transformer: (logData: any) => {
      return {
        '@timestamp': new Date().toISOString(),
        message: logData.message,
        level: logData.level,
        service: process.env.SERVICE_NAME || 'unknown',
        environment: process.env.NODE_ENV || 'development',
        ...logData.meta,
      };
    },
  };

  return WinstonModule.createLogger({
    transports: [
      // Console transport for development
      new winston.transports.Console({
        format: winston.format.combine(
          winston.format.timestamp(),
          winston.format.colorize(),
          winston.format.printf(({ timestamp, level, message, ...meta }) => {
            return `${timestamp} [${level}]: ${message} ${
              Object.keys(meta).length ? JSON.stringify(meta, null, 2) : ''
            }`;
          }),
        ),
      }),
      // Elasticsearch transport for centralized logging
      new ElasticsearchTransport(esTransportOpts),
    ],
  });
};

import { Injectable, NestInterceptor, ExecutionContext, CallHandler, Logger } from '@nestjs/common';
import { Observable } from 'rxjs';
import { tap, catchError } from 'rxjs/operators';

@Injectable()
export class LoggingInterceptor implements NestInterceptor {
  private readonly logger = new Logger(LoggingInterceptor.name);

  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    const request = context.switchToHttp().getRequest();
    const { method, url, body, headers, ip } = request;
    const userAgent = headers['user-agent'] || '';
    const startTime = Date.now();

    // Log request
    this.logger.log({
      message: 'Incoming request',
      req: {
        method,
        url,
        body,
        userAgent,
        clientIp: ip,
      },
    });

    return next.handle().pipe(
      tap((data) => {
        const response = context.switchToHttp().getResponse();
        const { statusCode } = response;
        const duration = Date.now() - startTime;

        // Log successful response
        this.logger.log({
          message: 'Request completed',
          req: { method, url },
          res: { statusCode, duration },
        });
      }),
      catchError((error) => {
        const duration = Date.now() - startTime;

        // Log error
        this.logger.error({
          message: 'Request failed',
          req: { method, url, body },
          error: {
            message: error.message,
            stack: error.stack,
            statusCode: error.status,
          },
          duration,
        });

        throw error;
      }),
    );
  }
}

  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    const request = context.switchToHttp().getRequest();
    const { method, url } = request;

    // Start a custom transaction
    const transaction = apm.startTransaction(`${method} ${url}`, 'request');

    // Add custom context
    if (transaction) {
      transaction.setCustomContext({
        userId: request.user?.id,
        sessionId: request.sessionID,
      });
    }

    return next.handle().pipe(
      tap(() => {
        // Mark transaction as successful
        if (transaction) {
          transaction.result = 'success';
          transaction.end();
        }
      }),
      catchError((error) => {
        // Capture error in APM
        if (transaction) {
          apm.captureError(error, {
            request,
            custom: {
              transactionId: transaction.id,
            },
          });
          transaction.result = 'error';
          transaction.end();
        }
        throw error;
      }),
    );
  }

                  },

                    max_num_segments: 1,
                  },
                },
              },

                min_age: '30d',

                },
              },

                min_age: '90d',
                actions: {

                },
              },
            },
          },
        },

      this.logger.error(`Failed to create ILM policy: ${error.message}`);
      throw error;
    }
  }

  @Cron('0 0 * * *') // Run daily at midnight
  async cleanupOldIndices() {
    const cutoffDate = new Date();
    cutoffDate.setDate(cutoffDate.getDate() - 90); // Keep last 90 days

    try {
      const indices = await this.elasticsearchService.cat.indices({
        format: 'json',
        h: ['index', 'creation.date'],
      });

      for (const index of indices as any[]) {
        const creationDate = new Date(parseInt(index['creation.date'], 10));

        if (creationDate < cutoffDate && index.index.startsWith('logs-')) {
          await this.elasticsearchService.indices.delete({
            index: index.index,
          });
          this.logger.log(`Deleted old index: ${index.index}`);
        }
      }
    } catch (error) {
      this.logger.error(`Failed to cleanup old indices: ${error.message}`);
    }
  }
}

        // This is more efficient for deep pagination
        track_total_hits: 10000, // Limit total hits tracking
      });

      return response;
    } catch (error) {
      this.logger.error(`Optimized search failed: ${error.message}`);
      throw error;
    }
  }

  async bulkSearch(queries: any[]) {
    // Use msearch for multiple searches in one request
    const searches = queries.flatMap((query) => [{ index: 'products' }, query]);

    try {
      const response = await this.elasticsearchService.msearch({
        body: searches,
      });

      return response.responses;
    } catch (error) {
      this.logger.error(`Bulk search failed: ${error.message}`);
      throw error;
    }
  }
}

Backup & Restore​

Elasticsearch snapshots are the primary backup mechanism. A snapshot is an incremental copy of one or more indices (or the entire cluster state) stored in a snapshot repository — GCS, S3, Azure Blob, or a shared filesystem.

Architecture​

Step 1 — Register a GCS Repository​

Install the GCS repository plugin on every node (or use the official Elasticsearch Docker image which includes it):

# If running on bare metal / custom image
bin/elasticsearch-plugin install repository-gcs

# Restart each node after install
systemctl restart elasticsearch

Create a GCS keyfile secret in the Elasticsearch keystore:

# On each node — add the GCS service account key
bin/elasticsearch-keystore add-file gcs.client.default.credentials_file \
  /path/to/gcs-service-account.json

Register the repository via the API:

PUT /_snapshot/gcs_backup
{
  "type": "gcs",
  "settings": {
    "bucket": "es-backups-prod",
    "base_path": "snapshots",
    "client": "default",
    "compress": true,
    "chunk_size": "1gb",
    "max_restore_bytes_per_sec": "500mb",
    "max_snapshot_bytes_per_sec": "500mb"
  }
}

Verify the repository:

POST /_snapshot/gcs_backup/_verify
GET /_snapshot/gcs_backup

Step 5 — Kubernetes CronJob for SLM Monitoring​

SLM handles scheduling, but you should alert on failures. This CronJob checks SLM health daily and sends an alert if the last snapshot failed:

apiVersion: batch/v1
kind: CronJob
metadata:
  name: es-slm-monitor
  namespace: production
spec:
  schedule: "0 6 * * *"   # Run at 06:00 UTC, after nightly snapshots complete
  jobTemplate:
    spec:
      template:
        spec:
          restartPolicy: OnFailure
          containers:
            - name: slm-monitor
              image: curlimages/curl:8.7.1
              env:
                - name: ES_URL
                  value: "http://elasticsearch.production.svc.cluster.local:9200"
                - name: SLACK_WEBHOOK
                  valueFrom:
                    secretKeyRef: { name: alerting-secrets, key: slack-webhook }
              command:
                - /bin/sh
                - -c
                - |
                  STATUS=$(curl -sf "$ES_URL/_slm/policy/daily-snapshots" | \
                    grep -o '"state":"[^"]*"' | head -1)
                  LAST_FAILURE=$(curl -sf "$ES_URL/_slm/stats" | \
                    grep -o '"retention_deletion_time_millis":[0-9]*')
                  if echo "$STATUS" | grep -q "FAILED"; then
                    curl -s -X POST "$SLACK_WEBHOOK" \
                      -H 'Content-Type: application/json' \
                      -d '{"text":"🚨 Elasticsearch SLM snapshot FAILED — check /_slm/policy/daily-snapshots"}'
                    exit 1
                  fi
                  echo "SLM OK: $STATUS"

Step 6 — Backup Verification (Restore Drill)​

A backup is only valid if restore works. Run a weekly automated restore drill to staging:

#!/usr/bin/env bash
# scripts/es-restore-drill.sh — run weekly in CI

set -euo pipefail

ES_STAGING="https://es-staging.internal:9200"
ES_PROD_REPO="gcs_prod_backup"

# 1. Get the latest daily snapshot name
LATEST=$(curl -sf "$ES_STAGING/_snapshot/$ES_PROD_REPO/_all?size=1&sort=start_time:desc" \
  | jq -r '.snapshots[0].snapshot')

echo "Restoring snapshot: $LATEST"

# 2. Restore products index to drill-* prefix on staging
curl -sf -X POST "$ES_STAGING/_snapshot/$ES_PROD_REPO/$LATEST/_restore" \
  -H 'Content-Type: application/json' \
  -d '{
    "indices": "products",
    "rename_pattern": "products",
    "rename_replacement": "drill-products",
    "index_settings": { "index.number_of_replicas": 0 }
  }'

# 3. Wait for green
curl -sf "$ES_STAGING/_cluster/health/drill-products?wait_for_status=green&timeout=120s"

# 4. Validate doc count matches prod
DRILL_COUNT=$(curl -sf "$ES_STAGING/drill-products/_count" | jq '.count')
PROD_COUNT=$(curl -sf "https://es-prod.internal:9200/products/_count" | jq '.count')

echo "Drill count: $DRILL_COUNT / Prod count: $PROD_COUNT"

if [ "$DRILL_COUNT" -lt $(( PROD_COUNT * 95 / 100 )) ]; then
  echo "❌ Restore drill FAILED: doc count mismatch"
  exit 1
fi

# 5. Cleanup
curl -sf -X DELETE "$ES_STAGING/drill-products"
echo "✅ Restore drill PASSED"

# 1. Disable shard allocation before upgrading
PUT /_cluster/settings
{
  "persistent": {
    "cluster.routing.allocation.enable": "primaries"
  }
}

# 2. Flush synced
POST /_flush

# 3. Update version in the ECK CR — ECK handles rolling restart one node at a time
kubectl -n elasticsearch edit elasticsearch ecommerce-es
# spec.version: 8.13.0 → 8.14.0

# 4. Monitor progress
kubectl -n elasticsearch get elasticsearch ecommerce-es -w

# 5. Re-enable shard allocation after all nodes upgraded
PUT /_cluster/settings
{
  "persistent": {
    "cluster.routing.allocation.enable": null
  }
}

Production Deployment Checklist​

Cluster sizing:

  • 3 dedicated master nodes (no data roles) for quorum
  • Minimum 3 hot data nodes + 2 warm nodes for tiered storage
  • Coordinating nodes separated for client traffic isolation
  • JVM heap = 50% of node RAM, capped at 32 GB
  • vm.max_map_count=262144 set via privileged init container

Security:

  • TLS on HTTP and transport layers (ECK auto-manages certs)
  • elastic superuser password rotated, stored in GCP Secret Manager
  • Per-service RBAC roles with least-privilege index permissions
  • Audit logging enabled
  • NetworkPolicy restricts ports 9200/9300 to authorised namespaces only

Storage:

  • Regional Persistent Disk — SSD for hot, Standard for warm
  • reclaimPolicy: Retain on StorageClass
  • ILM policy configured: hot → warm → cold → delete
  • GCS snapshot repository registered; SLM policies active

Operations:

  • Prometheus PodMonitor scraping cluster metrics
  • All alerts from the alerting table configured with PagerDuty/Slack routing
  • ArgoCD prune: false for the Elasticsearch Application
  • Rolling upgrade procedure tested in staging
  • Restore drill passing in CI
