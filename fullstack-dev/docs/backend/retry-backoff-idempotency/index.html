Retry with Backoff & Idempotency Guide

Overview​

Retry mechanisms with exponential backoff and idempotency are fundamental patterns for building resilient distributed systems. This guide covers retry strategies, backoff algorithms, jitter techniques, idempotent design patterns, retry policies, and monitoring for reliable microservices communication.

Retry Decision Tree​

// services/retry-decision.service.ts
import { Injectable, Logger } from '@nestjs/common';

export enum ErrorCategory {
  RETRYABLE = 'RETRYABLE',
  NON_RETRYABLE = 'NON_RETRYABLE',
  RATE_LIMITED = 'RATE_LIMITED',
}

export interface RetryDecision {
  shouldRetry: boolean;
  category: ErrorCategory;
  suggestedDelayMs?: number;
  reason: string;
}

@Injectable()
export class RetryDecisionService {
  private readonly logger = new Logger(RetryDecisionService.name);

  /**
   * Determine if error is retryable
   */
  shouldRetry(error: any, attemptNumber: number, maxRetries: number): RetryDecision {
    // Max retries exceeded
    if (attemptNumber >= maxRetries) {
      return {
        shouldRetry: false,
        category: ErrorCategory.NON_RETRYABLE,
        reason: 'Max retries exceeded',
      };
    }

    // HTTP status codes
    if (error.response?.status) {
      return this.handleHttpError(error.response.status, error);
    }

    // Network errors
    if (this.isNetworkError(error)) {
      return {
        shouldRetry: true,
        category: ErrorCategory.RETRYABLE,
        reason: 'Network error - temporary issue',
      };
    }

    // Database errors
    if (this.isDatabaseError(error)) {
      return {
        shouldRetry: true,
        category: ErrorCategory.RETRYABLE,
        reason: 'Database error - connection or deadlock',
      };
    }

    // Timeout errors
    if (this.isTimeoutError(error)) {
      return {
        shouldRetry: true,
        category: ErrorCategory.RETRYABLE,
        reason: 'Timeout error - service slow or unavailable',
      };
    }

    // Default: don't retry unknown errors
    return {
      shouldRetry: false,
      category: ErrorCategory.NON_RETRYABLE,
      reason: 'Unknown error type',
    };
  }

  private handleHttpError(status: number, error: any): RetryDecision {
    // 5xx errors - server errors (retryable)
    if (status >= 500 && status < 600) {
      return {
        shouldRetry: true,
        category: ErrorCategory.RETRYABLE,
        reason: `Server error ${status}`,
      };
    }

    // 429 - Rate limited (retryable with delay)
    if (status === 429) {
      const retryAfter = this.parseRetryAfter(error.response?.headers);
      return {
        shouldRetry: true,
        category: ErrorCategory.RATE_LIMITED,
        suggestedDelayMs: retryAfter,
        reason: 'Rate limited',
      };
    }

    // 408 - Request timeout (retryable)
    if (status === 408) {
      return {
        shouldRetry: true,
        category: ErrorCategory.RETRYABLE,
        reason: 'Request timeout',
      };
    }

    // 4xx errors (except 408, 429) - client errors (not retryable)
    if (status >= 400 && status < 500) {
      return {
        shouldRetry: false,
        category: ErrorCategory.NON_RETRYABLE,
        reason: `Client error ${status}`,
      };
    }

    return {
      shouldRetry: false,
      category: ErrorCategory.NON_RETRYABLE,
      reason: `HTTP ${status}`,
    };
  }

  private isNetworkError(error: any): boolean {
    const networkErrors = ['ECONNREFUSED', 'ENOTFOUND', 'ETIMEDOUT', 'ECONNRESET', 'ENETUNREACH', 'EHOSTUNREACH'];

    return (
      networkErrors.some((code) => error.code === code) ||
      error.message?.toLowerCase().includes('network') ||
      error.message?.toLowerCase().includes('connection')
    );
  }

  private isDatabaseError(error: any): boolean {
    const dbErrors = ['connection', 'deadlock', 'lock timeout', 'transaction', 'could not connect'];

    return dbErrors.some((pattern) => error.message?.toLowerCase().includes(pattern));
  }

  private isTimeoutError(error: any): boolean {
    return (
      error.code === 'ETIMEDOUT' ||
      error.message?.toLowerCase().includes('timeout') ||
      error.message?.toLowerCase().includes('timed out')
    );
  }

  private parseRetryAfter(headers: any): number {
    if (!headers || !headers['retry-after']) {
      return 5000; // Default 5 seconds
    }

    const retryAfter = headers['retry-after'];

    // If it's a number (seconds)
    if (/^\d+$/.test(retryAfter)) {
      return parseInt(retryAfter) * 1000;
    }

    // If it's a date
    const retryDate = new Date(retryAfter);
    if (!isNaN(retryDate.getTime())) {
      return Math.max(0, retryDate.getTime() - Date.now());
    }

    return 5000;
  }
}

Backoff Algorithms​

Exponential Backoff​

// services/backoff/exponential-backoff.service.ts
import { Injectable, Logger } from '@nestjs/common';

export interface ExponentialBackoffConfig {
  initialDelayMs: number;
  maxDelayMs: number;
  multiplier: number;
  maxRetries: number;
}

@Injectable()
export class ExponentialBackoffService {
  private readonly logger = new Logger(ExponentialBackoffService.name);

  /**
   * Calculate delay for exponential backoff
   * Formula: min(initialDelay * (multiplier ^ attempt), maxDelay)
   */
  calculateDelay(attemptNumber: number, config: ExponentialBackoffConfig): number {
    const delay = Math.min(config.initialDelayMs * Math.pow(config.multiplier, attemptNumber), config.maxDelayMs);

    return Math.floor(delay);
  }

  /**
   * Get delay schedule for all attempts
   */
  getDelaySchedule(config: ExponentialBackoffConfig): number[] {
    const schedule: number[] = [];

    for (let i = 0; i < config.maxRetries; i++) {
      schedule.push(this.calculateDelay(i, config));
    }

    return schedule;
  }

  /**
   * Visualize backoff schedule
   */
  visualizeSchedule(config: ExponentialBackoffConfig): void {
    const schedule = this.getDelaySchedule(config);

    this.logger.log('Exponential Backoff Schedule:');
    schedule.forEach((delay, index) => {
      this.logger.log(`  Attempt ${index + 1}: ${delay}ms (${(delay / 1000).toFixed(2)}s)`);
    });

    const totalDelay = schedule.reduce((sum, delay) => sum + delay, 0);
    this.logger.log(`  Total retry time: ${(totalDelay / 1000).toFixed(2)}s`);
  }
}

// Example delays with default config:
// Attempt 1: 1000ms (1.00s)
// Attempt 2: 2000ms (2.00s)
// Attempt 3: 4000ms (4.00s)
// Attempt 4: 8000ms (8.00s)
// Attempt 5: 16000ms (16.00s)
// Total: 31 seconds

Fibonacci Backoff​

// services/backoff/fibonacci-backoff.service.ts
import { Injectable } from '@nestjs/common';

export interface FibonacciBackoffConfig {
  baseDelayMs: number;
  maxDelayMs: number;
}

@Injectable()
export class FibonacciBackoffService {
  private fibCache = new Map<number, number>();

  /**
   * Calculate delay using Fibonacci sequence
   * Formula: fibonacci(attempt) * baseDelay
   */
  calculateDelay(attemptNumber: number, config: FibonacciBackoffConfig): number {
    const fibNumber = this.fibonacci(attemptNumber);
    const delay = Math.min(fibNumber * config.baseDelayMs, config.maxDelayMs);

    return Math.floor(delay);
  }

  private fibonacci(n: number): number {
    if (n <= 1) return 1;

    if (this.fibCache.has(n)) {
      return this.fibCache.get(n);
    }

    const result = this.fibonacci(n - 1) + this.fibonacci(n - 2);
    this.fibCache.set(n, result);
    return result;
  }
}

// Example: baseDelay=1000ms
// Attempt 0: 1000ms (1 * 1000)
// Attempt 1: 1000ms (1 * 1000)
// Attempt 2: 2000ms (2 * 1000)
// Attempt 3: 3000ms (3 * 1000)
// Attempt 4: 5000ms (5 * 1000)
// Attempt 5: 8000ms (8 * 1000)

Jitter Techniques​

Full Jitter​

// services/jitter/full-jitter.service.ts
import { Injectable } from '@nestjs/common';

@Injectable()
export class FullJitterService {
  /**
   * Full jitter: random value between 0 and calculated delay
   * Formula: random(0, delay)
   * Prevents thundering herd problem
   */
  applyJitter(delay: number): number {
    return Math.floor(Math.random() * delay);
  }
}

// Example: delay=8000ms
// Possible results: 0ms to 8000ms (uniformly distributed)

Equal Jitter​

// services/jitter/equal-jitter.service.ts
import { Injectable } from '@nestjs/common';

@Injectable()
export class EqualJitterService {
  /**
   * Equal jitter: half the delay + random half
   * Formula: delay/2 + random(0, delay/2)
   * More predictable than full jitter
   */
  applyJitter(delay: number): number {
    const half = delay / 2;
    return Math.floor(half + Math.random() * half);
  }
}

// Example: delay=8000ms
// Possible results: 4000ms to 8000ms

Decorrelated Jitter​

// services/jitter/decorrelated-jitter.service.ts
import { Injectable } from '@nestjs/common';

@Injectable()
export class DecorrelatedJitterService {
  private lastDelay = 0;

  /**
   * Decorrelated jitter: based on previous delay
   * Formula: random(baseDelay, lastDelay * 3)
   * Smooth increase in delays
   */
  applyJitter(baseDelay: number, maxDelay: number): number {
    if (this.lastDelay === 0) {
      this.lastDelay = baseDelay;
      return baseDelay;
    }

    const upperBound = Math.min(this.lastDelay * 3, maxDelay);
    this.lastDelay = Math.floor(baseDelay + Math.random() * (upperBound - baseDelay));

    return this.lastDelay;
  }

  reset(): void {
    this.lastDelay = 0;
  }
}

Retry Policies​

Retry Service with Policies​

// services/retry.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { RetryDecisionService } from './retry-decision.service';
import { ExponentialBackoffService, ExponentialBackoffConfig } from './backoff/exponential-backoff.service';
import { FullJitterService } from './jitter/full-jitter.service';

export interface RetryPolicy {
  maxRetries: number;
  backoff: ExponentialBackoffConfig;
  jitter: 'none' | 'full' | 'equal' | 'decorrelated';
  retryableErrors?: string[];
  onRetry?: (error: Error, attemptNumber: number, delay: number) => void;
  onFailure?: (error: Error, totalAttempts: number) => void;
}

@Injectable()
export class RetryService {
  private readonly logger = new Logger(RetryService.name);

  constructor(
    private retryDecision: RetryDecisionService,
    private exponentialBackoff: ExponentialBackoffService,
    private fullJitter: FullJitterService,
  ) {}

  /**
   * Execute operation with retry policy
   */
  async executeWithRetry<T>(
    operation: () => Promise<T>,
    policy: RetryPolicy,
    operationName: string = 'operation',
  ): Promise<T> {
    let lastError: Error;

    for (let attempt = 0; attempt <= policy.maxRetries; attempt++) {
      try {
        const result = await operation();

        if (attempt > 0) {
          this.logger.log(`${operationName} succeeded after ${attempt} retries`);
        }

        return result;
      } catch (error) {
        lastError = error;

        // Check if should retry
        const decision = this.retryDecision.shouldRetry(error, attempt, policy.maxRetries);

        if (!decision.shouldRetry) {
          this.logger.error(`${operationName} failed and will not retry: ${decision.reason}`);

          if (policy.onFailure) {
            policy.onFailure(error, attempt + 1);
          }

          throw error;
        }

        // Calculate delay
        let delay = decision.suggestedDelayMs || this.exponentialBackoff.calculateDelay(attempt, policy.backoff);

        // Apply jitter
        if (policy.jitter === 'full') {
          delay = this.fullJitter.applyJitter(delay);
        }

        this.logger.warn(
          `${operationName} failed (attempt ${attempt + 1}/${policy.maxRetries + 1}). Retrying in ${delay}ms. Error: ${
            error.message
          }`,
        );

        // Call retry callback
        if (policy.onRetry) {
          policy.onRetry(error, attempt + 1, delay);
        }

        // Wait before retry
        await this.sleep(delay);
      }
    }

    // All retries exhausted
    this.logger.error(`${operationName} failed after ${policy.maxRetries + 1} attempts`);

    if (policy.onFailure) {
      policy.onFailure(lastError, policy.maxRetries + 1);
    }

    throw lastError;
  }

  /**
   * Execute with custom retry condition
   */
  async executeWithCustomRetry<T>(
    operation: () => Promise<T>,
    shouldRetry: (error: Error, attempt: number) => boolean,
    maxRetries: number,
    calculateDelay: (attempt: number) => number,
  ): Promise<T> {
    let lastError: Error;

    for (let attempt = 0; attempt <= maxRetries; attempt++) {
      try {
        return await operation();
      } catch (error) {
        lastError = error;

        if (attempt === maxRetries || !shouldRetry(error, attempt)) {
          throw error;
        }

        const delay = calculateDelay(attempt);
        await this.sleep(delay);
      }
    }

    throw lastError;
  }

  private sleep(ms: number): Promise<void> {
    return new Promise((resolve) => setTimeout(resolve, ms));
  }
}

Idempotent Design Patterns​

Idempotency Key Generator​

// services/idempotency-key.service.ts
import { Injectable } from '@nestjs/common';
import { createHash } from 'crypto';

@Injectable()
export class IdempotencyKeyService {
  /**
   * Generate idempotency key from request data
   */
  generateKey(userId: string, operation: string, data: any): string {
    const payload = JSON.stringify({
      userId,
      operation,
      data,
    });

    return createHash('sha256').update(payload).digest('hex');
  }

  /**
   * Generate UUID-based key
   */
  generateUuidKey(): string {
    return `${Date.now()}-${Math.random().toString(36).substr(2, 9)}`;
  }

  /**
   * Generate key from client-provided value and server data
   */
  generateHybridKey(clientKey: string, serverData: any): string {
    const payload = JSON.stringify({
      clientKey,
      serverData,
      timestamp: Date.now(),
    });

    return createHash('sha256').update(payload).digest('hex');
  }

  /**
   * Validate idempotency key format
   */
  isValidKey(key: string): boolean {
    // Check if key is a valid SHA-256 hash (64 hex characters)
    return /^[a-f0-9]{64}$/i.test(key);
  }
}

Idempotent Service Wrapper​

// decorators/idempotent.decorator.ts
import { SetMetadata } from '@nestjs/common';

export const IDEMPOTENT_KEY = 'idempotent';

export interface IdempotentOptions {
  keyExtractor?: (args: any[]) => string;
  ttlSeconds?: number;
}

export const Idempotent = (options?: IdempotentOptions) => SetMetadata(IDEMPOTENT_KEY, options || {});

// interceptors/idempotent.interceptor.ts
import { Injectable, NestInterceptor, ExecutionContext, CallHandler, ConflictException } from '@nestjs/common';
import { Reflector } from '@nestjs/core';
import { Observable, of } from 'rxjs';
import { tap } from 'rxjs/operators';
import { IDEMPOTENT_KEY, IdempotentOptions } from '../decorators/idempotent.decorator';
import { Redis } from 'ioredis';
import { InjectRedis } from '@nestjs-modules/ioredis';

@Injectable()
export class IdempotentInterceptor implements NestInterceptor {
  constructor(private reflector: Reflector, @InjectRedis() private readonly redis: Redis) {}

  async intercept(context: ExecutionContext, next: CallHandler): Promise<Observable<any>> {
    const options = this.reflector.get<IdempotentOptions>(IDEMPOTENT_KEY, context.getHandler());

    if (!options) {
      return next.handle();
    }

    const request = context.switchToHttp().getRequest();
    const idempotencyKey = request.headers['idempotency-key'];

    if (!idempotencyKey) {
      return next.handle();
    }

    const cacheKey = `idempotent:${idempotencyKey}`;

    // Check if operation already executed
    const cached = await this.redis.get(cacheKey);

    if (cached) {
      const result = JSON.parse(cached);

      if (result.status === 'processing') {
        throw new ConflictException('Operation is currently being processed');
      }

      if (result.status === 'completed') {
        return of(result.data);
      }
    }

    // Mark as processing
    await this.redis.setex(cacheKey, options.ttlSeconds || 3600, JSON.stringify({ status: 'processing' }));

    return next.handle().pipe(
      tap(async (data) => {
        // Cache result
        await this.redis.setex(cacheKey, options.ttlSeconds || 3600, JSON.stringify({ status: 'completed', data }));
      }),
    );
  }
}

// controllers/idempotent-api.controller.ts

  }
}

HTTP Client with Retry​

Axios Client with Retry​

// services/http-client-with-retry.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { HttpService } from '@nestjs/axios';
import { firstValueFrom } from 'rxjs';
import { AxiosRequestConfig, AxiosResponse } from 'axios';
import { RetryService } from './retry.service';
import { RETRY_POLICIES } from '../config/retry-policies.config';

@Injectable()
export class HttpClientWithRetryService {
  private readonly logger = new Logger(HttpClientWithRetryService.name);

  constructor(private httpService: HttpService, private retryService: RetryService) {}

  /**
   * GET request with retry
   */
  async get<T>(url: string, config?: AxiosRequestConfig, retryPolicyName: string = 'STANDARD'): Promise<T> {
    return this.retryService.executeWithRetry(
      async () => {
        const response = await firstValueFrom(this.httpService.get<T>(url, config));
        return response.data;
      },
      {
        ...RETRY_POLICIES[retryPolicyName],
        onRetry: (error, attempt, delay) => {
          this.logger.warn(`GET ${url} failed (attempt ${attempt}). Retrying in ${delay}ms`);
        },
      },
      `GET ${url}`,
    );
  }

  /**
   * POST request with retry and idempotency
   */
  async post<T>(
    url: string,
    data: any,
    idempotencyKey: string,
    config?: AxiosRequestConfig,
    retryPolicyName: string = 'STANDARD',
  ): Promise<T> {
    const headers = {
      ...config?.headers,
      'Idempotency-Key': idempotencyKey,
    };

    return this.retryService.executeWithRetry(
      async () => {
        const response = await firstValueFrom(this.httpService.post<T>(url, data, { ...config, headers }));
        return response.data;
      },
      RETRY_POLICIES[retryPolicyName],
      `POST ${url}`,
    );
  }

  /**
   * PUT request with retry (idempotent by nature)
   */
  async put<T>(url: string, data: any, config?: AxiosRequestConfig, retryPolicyName: string = 'STANDARD'): Promise<T> {
    return this.retryService.executeWithRetry(
      async () => {
        const response = await firstValueFrom(this.httpService.put<T>(url, data, config));
        return response.data;
      },
      RETRY_POLICIES[retryPolicyName],
      `PUT ${url}`,
    );
  }

  /**
   * DELETE request with retry (idempotent by nature)
   */
  async delete<T>(url: string, config?: AxiosRequestConfig, retryPolicyName: string = 'CONSERVATIVE'): Promise<T> {
    return this.retryService.executeWithRetry(
      async () => {
        const response = await firstValueFrom(this.httpService.delete<T>(url, config));
        return response.data;
      },
      RETRY_POLICIES[retryPolicyName],
      `DELETE ${url}`,
    );
  }
}

Database Service with Retry​

// services/database-with-retry.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository, QueryFailedError } from 'typeorm';
import { RetryService } from './retry.service';

@Injectable()
export class DatabaseWithRetryService<T> {
  private readonly logger = new Logger(DatabaseWithRetryService.name);

  constructor(private retryService: RetryService, private repository: Repository<T>, private entityName: string) {}

  /**
   * Find with retry on deadlock or connection errors
   */
  async find(options?: any): Promise<T[]> {
    return this.retryService.executeWithRetry(
      () => this.repository.find(options),
      {
        maxRetries: 3,
        backoff: {
          initialDelayMs: 500,
          maxDelayMs: 5000,
          multiplier: 2,
          maxRetries: 3,
        },
        jitter: 'full',
        onRetry: (error, attempt) => {
          this.logger.warn(`Database find failed for ${this.entityName} (attempt ${attempt}): ${error.message}`);
        },
      },
      `DB find ${this.entityName}`,
    );
  }

  /**
   * Save with retry and optimistic locking
   */
  async save(entity: T): Promise<T> {
    return this.retryService.executeWithRetry(
      () => this.repository.save(entity),
      {
        maxRetries: 5,
        backoff: {
          initialDelayMs: 100,
          maxDelayMs: 2000,
          multiplier: 2,
          maxRetries: 5,
        },
        jitter: 'full',
        onRetry: (error, attempt) => {
          if (error instanceof QueryFailedError) {
            this.logger.warn(`Database save failed for ${this.entityName} - possible deadlock (attempt ${attempt})`);
          }
        },
      },
      `DB save ${this.entityName}`,
    );
  }

  /**
   * Transaction with retry
   */
  async executeInTransaction<R>(operation: (manager: any) => Promise<R>): Promise<R> {
    return this.retryService.executeWithRetry(
      () => this.repository.manager.transaction(operation),
      {
        maxRetries: 3,
        backoff: {
          initialDelayMs: 200,
          maxDelayMs: 3000,
          multiplier: 2,
          maxRetries: 3,
        },
        jitter: 'full',
      },
      `DB transaction ${this.entityName}`,
    );
  }
}

  private readonly kafka: Kafka;

    await this.consumer.run({
      eachMessage: async (payload) => this.handleMessage(payload),
    });

Retry Metrics Service​

// services/retry-metrics.service.ts
import { Injectable } from '@nestjs/common';
import { Counter, Histogram, Gauge } from 'prom-client';

@Injectable()
export class RetryMetricsService {
  private readonly retryCounter = new Counter({
    name: 'retry_attempts_total',
    help: 'Total retry attempts',
    labelNames: ['operation', 'attempt_number', 'result'],
  });

  private readonly retryDurationHistogram = new Histogram({
    name: 'retry_duration_seconds',
    help: 'Time spent in retry loops',
    labelNames: ['operation', 'result'],
    buckets: [0.1, 0.5, 1, 2, 5, 10, 30, 60],
  });

  private readonly activeRetriesGauge = new Gauge({
    name: 'retry_active_operations',
    help: 'Number of operations currently retrying',
    labelNames: ['operation'],
  });

  private readonly backoffDelayHistogram = new Histogram({
    name: 'retry_backoff_delay_seconds',
    help: 'Distribution of backoff delays',
    labelNames: ['operation'],
    buckets: [0.1, 0.5, 1, 2, 5, 10, 30],
  });

  recordRetryAttempt(operation: string, attemptNumber: number, result: 'success' | 'failure'): void {
    this.retryCounter.inc({
      operation,
      attempt_number: attemptNumber.toString(),
      result,
    });
  }

  recordRetryDuration(operation: string, durationSeconds: number, result: 'success' | 'failure'): void {
    this.retryDurationHistogram.observe({ operation, result }, durationSeconds);
  }

  incrementActiveRetries(operation: string): void {
    this.activeRetriesGauge.inc({ operation });
  }

  decrementActiveRetries(operation: string): void {
    this.activeRetriesGauge.dec({ operation });
  }

  recordBackoffDelay(operation: string, delaySeconds: number): void {
    this.backoffDelayHistogram.observe({ operation }, delaySeconds);
  }
}

Enhanced Retry Service with Metrics​

// services/retry-with-metrics.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { RetryService, RetryPolicy } from './retry.service';
import { RetryMetricsService } from './retry-metrics.service';

@Injectable()
export class RetryWithMetricsService extends RetryService {
  constructor(retryDecision: any, exponentialBackoff: any, fullJitter: any, private retryMetrics: RetryMetricsService) {
    super(retryDecision, exponentialBackoff, fullJitter);
  }

  async executeWithRetry<T>(
    operation: () => Promise<T>,
    policy: RetryPolicy,
    operationName: string = 'operation',
  ): Promise<T> {
    const startTime = Date.now();
    this.retryMetrics.incrementActiveRetries(operationName);

    try {
      const result = await super.executeWithRetry(
        operation,
        {
          ...policy,
          onRetry: (error, attempt, delay) => {
            this.retryMetrics.recordRetryAttempt(operationName, attempt, 'failure');
            this.retryMetrics.recordBackoffDelay(operationName, delay / 1000);

            if (policy.onRetry) {
              policy.onRetry(error, attempt, delay);
            }
          },
        },
        operationName,
      );

      const duration = (Date.now() - startTime) / 1000;
      this.retryMetrics.recordRetryDuration(operationName, duration, 'success');
      this.retryMetrics.recordRetryAttempt(operationName, 0, 'success');

      return result;
    } catch (error) {
      const duration = (Date.now() - startTime) / 1000;
      this.retryMetrics.recordRetryDuration(operationName, duration, 'failure');
      throw error;
    } finally {
      this.retryMetrics.decrementActiveRetries(operationName);
    }
  }
}

Best Practices​

1. Retry Strategy​

✅ Do:

  • Use exponential backoff with jitter
  • Set maximum retry limits
  • Classify errors (retryable vs non-retryable)
  • Add timeout for total retry duration
  • Log all retry attempts
  • Monitor retry metrics

❌ Don't:

  • Retry indefinitely
  • Use constant delays (causes thundering herd)
  • Retry non-retryable errors (400, 401, 404)
  • Skip error classification
  • Hide retry attempts from monitoring
  • Retry without backoff

2. Backoff Configuration​

✅ Do:

  • Start with reasonable initial delay (1-2 seconds)
  • Cap maximum delay (30-60 seconds)
  • Use multiplier of 2-3
  • Apply jitter to prevent thundering herd
  • Adjust based on operation criticality
  • Test backoff schedules

❌ Don't:

  • Use too short initial delay (<100ms)
  • Use too long maximum delay (>2 minutes)
  • Skip jitter implementation
  • Use same config for all operations
  • Forget to test retry scenarios
  • Deploy without testing backoff timing

3. Idempotency Design​

✅ Do:

  • Design idempotent operations
  • Use unique idempotency keys
  • Store operation results with TTL
  • Validate idempotency key format
  • Handle concurrent requests
  • Return cached results for duplicates

❌ Don't:

  • Assume operations are idempotent
  • Generate predictable keys
  • Store results forever
  • Skip idempotency checks
  • Ignore concurrent request handling
  • Process duplicates multiple times

4. HTTP Retries​

✅ Do:

  • Retry only idempotent methods (GET, PUT, DELETE)
  • Use idempotency keys for POST
  • Respect Retry-After headers
  • Set request timeouts
  • Use connection pooling
  • Monitor retry rates

❌ Don't:

  • Retry POST without idempotency key
  • Ignore rate limit headers
  • Skip timeout configuration
  • Create new connections per retry
  • Forget to close connections
  • Deploy without retry monitoring

5. Monitoring​

✅ Do:

  • Track retry attempts per operation
  • Monitor backoff delays
  • Alert on high retry rates
  • Dashboard retry success rates
  • Track total retry duration
  • Log retry reasons

❌ Don't:

  • Deploy without retry metrics
  • Ignore retry failure patterns
  • Skip alerting on retry storms
  • Hide retry attempts
  • Forget to track retry costs
  • React only to complete failures

Summary​

Effective retry with backoff and idempotency provides:

  • Resilience - Automatic recovery from transient failures
  • Reliability - Safe retry operations without duplicates
  • Performance - Optimal retry timing with backoff
  • Stability - Prevent thundering herd with jitter
  • Observability - Complete retry monitoring

Key implementation points:

  • Retry decision service (classify retryable errors)
  • Exponential backoff with configurable parameters
  • Full/equal/decorrelated jitter techniques
  • Retry policies for different operation types
  • Idempotency key generation and validation
  • Idempotent interceptor for API endpoints
  • HTTP client with retry and idempotency
  • Database operations with retry on deadlocks
  • Kafka consumer with retry and DLQ fallback
  • Comprehensive Prometheus metrics
  • Retry visualizations and schedules

Remember: Always design for at-least-once delivery with idempotent operations - it's more reliable than trying to achieve exactly-once!
