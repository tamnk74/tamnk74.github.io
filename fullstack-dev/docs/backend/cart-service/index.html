Cart Service

Redis-first cart: sub-millisecond reads, 24-hour TTL, cart merge on login, coupon application, and seamless transition to order checkout.

Responsibilities​

  • Store and update cart line items entirely in Redis (no DB write on add/remove)
  • Merge anonymous cart into the authenticated user's cart on login
  • Validate coupon codes via Pricing Service before applying
  • Snapshot cart contents at checkout start (prevents stale-price races)
  • Emit cart events for analytics (add-to-cart, remove, checkout-started)

Redis Data Structure​

Each cart is a Redis Hash: field = SKU, value = JSON line item.

HSET cart:{cartId}  IPHONE16-128-BLK '{"qty":1,"price":999.99,"addedAt":"2026-01-01T..."}'
EXPIRE cart:{cartId} 86400
KeyTypeTTLContents
cart:{cartId}Hash24 hSKU → {qty, price, addedAt}
cart:user:{userId}String24 hcartId for authenticated user
cart:coupon:{cartId}String24 hApplied coupon JSON

NestJS Service​

// src/cart/cart.service.ts
import { Injectable, BadRequestException } from '@nestjs/common';
import { InjectRedis } from '@liaoliaots/nestjs-redis';
import Redis from 'ioredis';
import { PricingService } from '../pricing/pricing.service';
import { CouponService } from '../pricing/coupon.service';
import { EventEmitter2 } from '@nestjs/event-emitter';

export interface LineItem {
  qty:      number;
  price:    number;
  addedAt:  string;
}

export interface CartSummary {
  cartId:    string;
  items:     Record<string, LineItem>;
  subtotal:  number;
  coupon:    { code: string; discountAmount: number } | null;
  total:     number;
}

@Injectable()
export class CartService {
  constructor(
    @InjectRedis() private readonly redis: Redis,
    private readonly pricing: PricingService,
    private readonly coupon: CouponService,
    private readonly events: EventEmitter2,
  ) {}

  async addItem(cartId: string, sku: string, qty: number): Promise<void> {
    const priceResult = await this.pricing.getEffectivePrice(sku, qty);

    const existing = await this.redis.hget(`cart:${cartId}`, sku);
    const current: LineItem = existing
      ? JSON.parse(existing)
      : { qty: 0, price: priceResult.finalPrice, addedAt: new Date().toISOString() };

    current.qty   += qty;
    current.price  = priceResult.finalPrice; // always refresh price

    await this.redis.hset(`cart:${cartId}`, sku, JSON.stringify(current));
    await this.redis.expire(`cart:${cartId}`, 86400);

    this.events.emit('cart.item_added', { cartId, sku, qty, price: current.price });
  }

  async removeItem(cartId: string, sku: string): Promise<void> {
    await this.redis.hdel(`cart:${cartId}`, sku);
  }

  async updateQty(cartId: string, sku: string, qty: number): Promise<void> {
    if (qty <= 0) return this.removeItem(cartId, sku);
    const existing = await this.redis.hget(`cart:${cartId}`, sku);
    if (!existing) throw new BadRequestException(`SKU ${sku} not in cart`);
    const item: LineItem = JSON.parse(existing);
    item.qty = qty;
    await this.redis.hset(`cart:${cartId}`, sku, JSON.stringify(item));
  }

  async getCart(cartId: string): Promise<CartSummary> {
    const [raw, couponRaw] = await Promise.all([
      this.redis.hgetall(`cart:${cartId}`),
      this.redis.get(`cart:coupon:${cartId}`),
    ]);

    const items: Record<string, LineItem> = {};
    let subtotal = 0;
    for (const [sku, json] of Object.entries(raw ?? {})) {
      const item: LineItem = JSON.parse(json);
      items[sku] = item;
      subtotal += item.price * item.qty;
    }

    const coupon = couponRaw ? JSON.parse(couponRaw) : null;
    const total = coupon
      ? Math.max(0, subtotal - coupon.discountAmount)
      : subtotal;

    return { cartId, items, subtotal, coupon, total };
  }

  async applyCoupon(
    cartId: string,
    userId: string,
    code: string,
    tempOrderId: string,
  ): Promise<void> {
    const cart = await this.getCart(cartId);
    const application = await this.coupon.validateAndApply(
      code, userId, tempOrderId, cart.subtotal
    );
    await this.redis.set(
      `cart:coupon:${cartId}`,
      JSON.stringify({ code, ...application }),
      'EX', 86400
    );
  }

  /**
   * Snapshot cart at checkout start — prevents price changing mid-checkout.
   * Returns immutable snapshot; original cart remains until order is confirmed.
   */
  async snapshotForCheckout(cartId: string): Promise<CartSummary> {
    const cart = await this.getCart(cartId);
    if (Object.keys(cart.items).length === 0) {
      throw new BadRequestException('Cannot checkout empty cart');
    }
    // Re-validate prices at snapshot time
    for (const [sku, item] of Object.entries(cart.items)) {
      const latest = await this.pricing.getEffectivePrice(sku, item.qty);
      item.price = latest.finalPrice;
    }
    return cart;
  }

  /** Merge anonymous cart into authenticated user cart on login */
  async mergeOnLogin(anonymousCartId: string, userId: string): Promise<string> {
    const userCartIdKey = `cart:user:${userId}`;
    let userCartId = await this.redis.get(userCartIdKey);

    if (!userCartId) {
      // No existing user cart — take over the anonymous cart
      userCartId = anonymousCartId;
      await this.redis.set(userCartIdKey, userCartId, 'EX', 86400);
      return userCartId;
    }

    // Merge: anonymous items into user cart (user cart wins on qty conflict)
    const anonItems = await this.redis.hgetall(`cart:${anonymousCartId}`);
    for (const [sku, json] of Object.entries(anonItems ?? {})) {
      const existing = await this.redis.hget(`cart:${userCartId}`, sku);
      if (!existing) {
        await this.redis.hset(`cart:${userCartId}`, sku, json);
      }
    }
    await this.redis.del(`cart:${anonymousCartId}`);
    return userCartId;
  }

  async clearCart(cartId: string): Promise<void> {
    await this.redis.del(`cart:${cartId}`, `cart:coupon:${cartId}`);
  }
}

REST API​

MethodPathDescription
POST/cart/{cartId}/itemsAdd item { sku, qty }
PUT/cart/{cartId}/items/{sku}Update quantity
DELETE/cart/{cartId}/items/{sku}Remove item
GET/cart/{cartId}Get cart summary with totals
POST/cart/{cartId}/couponApply coupon { code }
DELETE/cart/{cartId}/couponRemove coupon
POST/cart/mergeMerge anonymous into user cart

Failure Modes​

FailureMitigation
Redis eviction under memory pressureUse allkeys-lru policy; cart key TTL is 24 h; client re-adds items
Price change mid-checkoutsnapshotForCheckout re-fetches latest price; user sees updated total
Duplicate addItem on network retryIdempotency: re-add same SKU merges qty, not duplicates
Coupon race (two users, one shared coupon)Row-level FOR UPDATE lock in CouponService.validateAndApply
