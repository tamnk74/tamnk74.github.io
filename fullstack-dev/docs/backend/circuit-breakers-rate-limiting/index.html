Circuit Breakers & Rate Limiting Guide

Overview​

Circuit Breakers and Rate Limiting are essential resilience patterns for microservices architectures. This guide covers circuit breaker implementation, rate limiting strategies, fallback mechanisms, bulkhead patterns, and monitoring for building fault-tolerant distributed systems.

Circuit Breaker Pattern​

What is a Circuit Breaker?​

A Circuit Breaker prevents cascading failures by monitoring service calls and opening the circuit when failures exceed a threshold, allowing the system to fail fast and recover gracefully.

Circuit Breaker States​

CLOSED (Normal Operation)

  • All requests pass through to the service
  • Failures are counted
  • If failure rate exceeds threshold → OPEN

OPEN (Failing Fast)

  • Requests immediately fail without calling service
  • Prevents resource exhaustion
  • After timeout period → HALF-OPEN

HALF-OPEN (Testing Recovery)

  • Limited requests pass through
  • Tests if service has recovered
  • If successful → CLOSED
  • If failure → OPEN

Why Use Circuit Breakers?​

Benefits:

  • Prevent Cascading Failures - Stop failure propagation
  • Fast Failure - Fail immediately instead of waiting for timeout
  • Resource Protection - Prevent resource exhaustion
  • Automatic Recovery - Self-healing when service recovers
  • Improved User Experience - Return fallback responses quickly

Circuit Breaker Implementation​

Circuit Breaker Service (NestJS)​

// services/circuit-breaker.service.ts
import { Injectable, Logger } from '@nestjs/common';

export enum CircuitState {
  CLOSED = 'CLOSED',
  OPEN = 'OPEN',
  HALF_OPEN = 'HALF_OPEN',
}

export interface CircuitBreakerConfig {
  failureThreshold: number; // Number of failures to open circuit
  successThreshold: number; // Number of successes to close circuit
  timeout: number; // Milliseconds to wait before half-open
  volumeThreshold: number; // Minimum requests before evaluating
  errorThresholdPercentage: number; // Percentage of errors to trip circuit
  rollingWindowMs: number; // Time window for error calculation
}

interface CircuitStats {
  failures: number;
  successes: number;
  totalRequests: number;
  lastFailureTime?: Date;
  lastSuccessTime?: Date;
  consecutiveFailures: number;
  consecutiveSuccesses: number;
}

@Injectable()
export class CircuitBreakerService {
  private readonly logger = new Logger(CircuitBreakerService.name);
  private readonly circuits = new Map<
    string,
    {
      state: CircuitState;
      stats: CircuitStats;
      config: CircuitBreakerConfig;
      nextAttempt?: Date;
      requestTimestamps: number[];
    }
  >();

  private readonly defaultConfig: CircuitBreakerConfig = {
    failureThreshold: 5,
    successThreshold: 2,
    timeout: 60000, // 1 minute
    volumeThreshold: 10,
    errorThresholdPercentage: 50,
    rollingWindowMs: 60000, // 1 minute
  };

  /**
   * Execute operation with circuit breaker protection
   */
  async execute<T>(
    circuitName: string,
    operation: () => Promise<T>,
    fallback?: () => Promise<T>,
    config?: Partial<CircuitBreakerConfig>,
  ): Promise<T> {
    const circuitConfig = { ...this.defaultConfig, ...config };

    if (!this.circuits.has(circuitName)) {
      this.initializeCircuit(circuitName, circuitConfig);
    }

    const circuit = this.circuits.get(circuitName);

    // Check if circuit is open
    if (circuit.state === CircuitState.OPEN) {
      if (this.shouldAttemptReset(circuit)) {
        this.transitionToHalfOpen(circuitName);
      } else {
        this.logger.warn(`Circuit ${circuitName} is OPEN - failing fast`);

        if (fallback) {
          return fallback();
        }

        throw new Error(`Circuit breaker ${circuitName} is OPEN`);
      }
    }

    // Execute operation
    const startTime = Date.now();
    try {
      const result = await operation();
      this.recordSuccess(circuitName);

      this.logger.debug(`Circuit ${circuitName} - Request succeeded in ${Date.now() - startTime}ms`);

      return result;
    } catch (error) {
      this.recordFailure(circuitName, error);

      this.logger.error(`Circuit ${circuitName} - Request failed in ${Date.now() - startTime}ms: ${error.message}`);

      if (fallback) {
        this.logger.log(`Using fallback for circuit ${circuitName}`);
        return fallback();
      }

      throw error;
    }
  }

  private initializeCircuit(name: string, config: CircuitBreakerConfig): void {
    this.circuits.set(name, {
      state: CircuitState.CLOSED,
      config,
      stats: {
        failures: 0,
        successes: 0,
        totalRequests: 0,
        consecutiveFailures: 0,
        consecutiveSuccesses: 0,
      },
      requestTimestamps: [],
    });

    this.logger.log(`Initialized circuit breaker: ${name}`);
  }

  private recordSuccess(circuitName: string): void {
    const circuit = this.circuits.get(circuitName);

    circuit.stats.successes++;
    circuit.stats.totalRequests++;
    circuit.stats.consecutiveSuccesses++;
    circuit.stats.consecutiveFailures = 0;
    circuit.stats.lastSuccessTime = new Date();
    circuit.requestTimestamps.push(Date.now());

    // Clean old timestamps
    this.cleanOldTimestamps(circuit);

    // Check if we should close the circuit
    if (circuit.state === CircuitState.HALF_OPEN) {
      if (circuit.stats.consecutiveSuccesses >= circuit.config.successThreshold) {
        this.transitionToClosed(circuitName);
      }
    }
  }

  private recordFailure(circuitName: string, error: Error): void {
    const circuit = this.circuits.get(circuitName);

    circuit.stats.failures++;
    circuit.stats.totalRequests++;
    circuit.stats.consecutiveFailures++;
    circuit.stats.consecutiveSuccesses = 0;
    circuit.stats.lastFailureTime = new Date();
    circuit.requestTimestamps.push(Date.now());

    // Clean old timestamps
    this.cleanOldTimestamps(circuit);

    // Check if we should open the circuit
    if (circuit.state === CircuitState.CLOSED || circuit.state === CircuitState.HALF_OPEN) {
      if (this.shouldOpenCircuit(circuit)) {
        this.transitionToOpen(circuitName);
      }
    }
  }

  private shouldOpenCircuit(circuit: any): boolean {
    const { config, stats, requestTimestamps } = circuit;

    // Need minimum volume
    if (requestTimestamps.length < config.volumeThreshold) {
      return false;
    }

    // Check consecutive failures
    if (stats.consecutiveFailures >= config.failureThreshold) {
      return true;
    }

    // Check error percentage in rolling window
    const errorRate = (stats.failures / stats.totalRequests) * 100;
    return errorRate >= config.errorThresholdPercentage;
  }

  private shouldAttemptReset(circuit: any): boolean {
    if (!circuit.nextAttempt) {
      return true;
    }
    return Date.now() >= circuit.nextAttempt.getTime();
  }

  private transitionToOpen(circuitName: string): void {
    const circuit = this.circuits.get(circuitName);
    circuit.state = CircuitState.OPEN;
    circuit.nextAttempt = new Date(Date.now() + circuit.config.timeout);

    this.logger.warn(
      `Circuit ${circuitName} transitioned to OPEN. Next attempt at ${circuit.nextAttempt.toISOString()}`,
    );
  }

  private transitionToHalfOpen(circuitName: string): void {
    const circuit = this.circuits.get(circuitName);
    circuit.state = CircuitState.HALF_OPEN;
    circuit.stats.consecutiveSuccesses = 0;
    circuit.stats.consecutiveFailures = 0;

    this.logger.log(`Circuit ${circuitName} transitioned to HALF_OPEN`);
  }

  private transitionToClosed(circuitName: string): void {
    const circuit = this.circuits.get(circuitName);
    circuit.state = CircuitState.CLOSED;
    circuit.stats.failures = 0;
    circuit.stats.successes = 0;
    circuit.stats.totalRequests = 0;
    circuit.stats.consecutiveFailures = 0;
    circuit.stats.consecutiveSuccesses = 0;
    circuit.requestTimestamps = [];

    this.logger.log(`Circuit ${circuitName} transitioned to CLOSED`);
  }

  private cleanOldTimestamps(circuit: any): void {
    const cutoff = Date.now() - circuit.config.rollingWindowMs;
    circuit.requestTimestamps = circuit.requestTimestamps.filter((ts) => ts > cutoff);
  }

  /**
   * Get circuit status
   */
  getCircuitStatus(circuitName: string): any {
    const circuit = this.circuits.get(circuitName);

    if (!circuit) {
      return null;
    }

    return {
      name: circuitName,
      state: circuit.state,
      stats: circuit.stats,
      nextAttempt: circuit.nextAttempt,
      requestsInWindow: circuit.requestTimestamps.length,
    };
  }

  /**
   * Get all circuits status
   */
  getAllCircuitsStatus(): any[] {
    return Array.from(this.circuits.entries()).map(([name, circuit]) => ({
      name,
      state: circuit.state,
      stats: circuit.stats,
      nextAttempt: circuit.nextAttempt,
      requestsInWindow: circuit.requestTimestamps.length,
    }));
  }

  /**
   * Manually reset circuit
   */
  resetCircuit(circuitName: string): void {
    if (this.circuits.has(circuitName)) {
      this.transitionToClosed(circuitName);
      this.logger.log(`Circuit ${circuitName} manually reset`);
    }
  }
}

HTTP Client with Circuit Breaker​

// services/http-client-with-circuit-breaker.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { HttpService } from '@nestjs/axios';
import { CircuitBreakerService } from './circuit-breaker.service';
import { firstValueFrom } from 'rxjs';
import { AxiosRequestConfig, AxiosResponse } from 'axios';

@Injectable()
export class HttpClientWithCircuitBreakerService {
  private readonly logger = new Logger(HttpClientWithCircuitBreakerService.name);

  constructor(private httpService: HttpService, private circuitBreaker: CircuitBreakerService) {}

  /**
   * GET request with circuit breaker
   */
  async get<T>(url: string, config?: AxiosRequestConfig, fallbackData?: T): Promise<T> {
    const circuitName = this.getCircuitName('GET', url);

    return this.circuitBreaker.execute<T>(
      circuitName,
      async () => {
        const response = await firstValueFrom(this.httpService.get<T>(url, config));
        return response.data;
      },
      fallbackData ? async () => fallbackData : undefined,
      {
        failureThreshold: 5,
        timeout: 30000,
        errorThresholdPercentage: 50,
      },
    );
  }

  /**
   * POST request with circuit breaker
   */
  async post<T>(url: string, data: any, config?: AxiosRequestConfig, fallbackData?: T): Promise<T> {
    const circuitName = this.getCircuitName('POST', url);

    return this.circuitBreaker.execute<T>(
      circuitName,
      async () => {
        const response = await firstValueFrom(this.httpService.post<T>(url, data, config));
        return response.data;
      },
      fallbackData ? async () => fallbackData : undefined,
    );
  }

  private getCircuitName(method: string, url: string): string {
    // Extract service name from URL
    const urlObj = new URL(url);
    const serviceName = urlObj.hostname.split('.')[0];
    return `${serviceName}-${method}`;
  }
}

Rate Limiting Strategies​

Rate Limiting Algorithms​

Token Bucket Rate Limiter​

// services/rate-limiter/token-bucket.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { Redis } from 'ioredis';
import { InjectRedis } from '@nestjs-modules/ioredis';

export interface TokenBucketConfig {
  capacity: number; // Maximum tokens in bucket
  refillRate: number; // Tokens added per second
  tokensPerRequest: number; // Tokens consumed per request
}

@Injectable()
export class TokenBucketRateLimiterService {
  private readonly logger = new Logger(TokenBucketRateLimiterService.name);

  constructor(@InjectRedis() private readonly redis: Redis) {}

  /**
   * Check if request is allowed (token bucket algorithm)
   */
  async isAllowed(
    key: string,
    config: TokenBucketConfig,
  ): Promise<{ allowed: boolean; remainingTokens: number; retryAfter?: number }> {
    const bucketKey = `rate_limit:token_bucket:${key}`;
    const now = Date.now();

    // Lua script for atomic token bucket check
    const script = `
      local bucketKey = KEYS[1]
      local capacity = tonumber(ARGV[1])
      local refillRate = tonumber(ARGV[2])
      local tokensPerRequest = tonumber(ARGV[3])
      local now = tonumber(ARGV[4])
      
      local bucket = redis.call('HMGET', bucketKey, 'tokens', 'lastRefill')
      local tokens = tonumber(bucket[1]) or capacity
      local lastRefill = tonumber(bucket[2]) or now
      
      -- Calculate token refill
      local timePassed = (now - lastRefill) / 1000
      local tokensToAdd = timePassed * refillRate
      tokens = math.min(capacity, tokens + tokensToAdd)
      
      -- Check if enough tokens
      if tokens >= tokensPerRequest then
        tokens = tokens - tokensPerRequest
        redis.call('HMSET', bucketKey, 'tokens', tokens, 'lastRefill', now)
        redis.call('EXPIRE', bucketKey, 3600)
        return {1, tokens, 0}
      else
        -- Calculate retry after
        local tokensNeeded = tokensPerRequest - tokens
        local retryAfter = math.ceil(tokensNeeded / refillRate)
        return {0, tokens, retryAfter}
      end
    `;

    const result = (await this.redis.eval(
      script,
      1,
      bucketKey,
      config.capacity,
      config.refillRate,
      config.tokensPerRequest,
      now,
    )) as [number, number, number];

    const allowed = result[0] === 1;
    const remainingTokens = result[1];
    const retryAfter = result[2];

    if (!allowed) {
      this.logger.warn(`Rate limit exceeded for ${key}. Retry after ${retryAfter}s`);
    }

    return {
      allowed,
      remainingTokens,
      retryAfter: retryAfter > 0 ? retryAfter : undefined,
    };
  }
}

Sliding Window Rate Limiter​

// services/rate-limiter/sliding-window.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { Redis } from 'ioredis';
import { InjectRedis } from '@nestjs-modules/ioredis';

export interface SlidingWindowConfig {
  maxRequests: number; // Maximum requests in window
  windowMs: number; // Time window in milliseconds
}

@Injectable()
export class SlidingWindowRateLimiterService {
  private readonly logger = new Logger(SlidingWindowRateLimiterService.name);

  constructor(@InjectRedis() private readonly redis: Redis) {}

  /**
   * Check if request is allowed (sliding window algorithm)
   */
  async isAllowed(
    key: string,
    config: SlidingWindowConfig,
  ): Promise<{ allowed: boolean; remaining: number; resetAt: Date }> {
    const windowKey = `rate_limit:sliding_window:${key}`;
    const now = Date.now();
    const windowStart = now - config.windowMs;

    // Lua script for atomic sliding window check
    const script = `
      local windowKey = KEYS[1]
      local now = tonumber(ARGV[1])
      local windowStart = tonumber(ARGV[2])
      local maxRequests = tonumber(ARGV[3])
      local windowMs = tonumber(ARGV[4])
      
      -- Remove old entries
      redis.call('ZREMRANGEBYSCORE', windowKey, '-inf', windowStart)
      
      -- Count requests in window
      local count = redis.call('ZCARD', windowKey)
      
      if count < maxRequests then
        -- Add current request
        redis.call('ZADD', windowKey, now, now)
        redis.call('PEXPIRE', windowKey, windowMs)
        return {1, maxRequests - count - 1}
      else
        return {0, 0}
      end
    `;

    const result = (await this.redis.eval(
      script,
      1,
      windowKey,
      now,
      windowStart,
      config.maxRequests,
      config.windowMs,
    )) as [number, number];

    const allowed = result[0] === 1;
    const remaining = result[1];
    const resetAt = new Date(now + config.windowMs);

    if (!allowed) {
      this.logger.warn(`Rate limit exceeded for ${key}. Resets at ${resetAt.toISOString()}`);
    }

    return {
      allowed,
      remaining,
      resetAt,
    };
  }

  /**
   * Get current usage
   */
  async getUsage(key: string, windowMs: number): Promise<{ count: number; oldestRequest: Date }> {
    const windowKey = `rate_limit:sliding_window:${key}`;
    const now = Date.now();
    const windowStart = now - windowMs;

    // Remove old entries
    await this.redis.zremrangebyscore(windowKey, '-inf', windowStart);

    // Get count and oldest request
    const count = await this.redis.zcard(windowKey);
    const oldest = await this.redis.zrange(windowKey, 0, 0, 'WITHSCORES');

    return {
      count,
      oldestRequest: oldest.length > 0 ? new Date(parseInt(oldest[1])) : null,
    };
  }
}

Rate Limiting Implementation​

Rate Limiting Guard​

// guards/rate-limit.guard.ts
import { Injectable, CanActivate, ExecutionContext, HttpException, HttpStatus, Logger } from '@nestjs/common';
import { Reflector } from '@nestjs/core';
import { SlidingWindowRateLimiterService } from '../services/rate-limiter/sliding-window.service';
import { TokenBucketRateLimiterService } from '../services/rate-limiter/token-bucket.service';

export interface RateLimitOptions {
  type: 'sliding-window' | 'token-bucket';
  // Sliding window options
  maxRequests?: number;
  windowMs?: number;
  // Token bucket options
  capacity?: number;
  refillRate?: number;
  tokensPerRequest?: number;
  // Common options
  keyGenerator?: (req: any) => string;
  skipIf?: (req: any) => boolean;
}

export const RATE_LIMIT_KEY = 'rate_limit';

@Injectable()
export class RateLimitGuard implements CanActivate {
  private readonly logger = new Logger(RateLimitGuard.name);

  constructor(
    private reflector: Reflector,
    private slidingWindowLimiter: SlidingWindowRateLimiterService,
    private tokenBucketLimiter: TokenBucketRateLimiterService,
  ) {}

  async canActivate(context: ExecutionContext): Promise<boolean> {
    const options = this.reflector.get<RateLimitOptions>(RATE_LIMIT_KEY, context.getHandler());

    if (!options) {
      return true;
    }

    const request = context.switchToHttp().getRequest();

    // Check skip condition
    if (options.skipIf && options.skipIf(request)) {
      return true;
    }

    // Generate key
    const key = options.keyGenerator ? options.keyGenerator(request) : this.defaultKeyGenerator(request);

    // Apply rate limiting based on type
    if (options.type === 'sliding-window') {
      const result = await this.slidingWindowLimiter.isAllowed(key, {
        maxRequests: options.maxRequests || 100,
        windowMs: options.windowMs || 60000,
      });

      if (!result.allowed) {
        throw new HttpException(
          {
            statusCode: HttpStatus.TOO_MANY_REQUESTS,
            message: 'Rate limit exceeded',
            retryAfter: Math.ceil((result.resetAt.getTime() - Date.now()) / 1000),
          },
          HttpStatus.TOO_MANY_REQUESTS,
        );
      }

      // Add rate limit headers
      const response = context.switchToHttp().getResponse();
      response.setHeader('X-RateLimit-Limit', options.maxRequests);
      response.setHeader('X-RateLimit-Remaining', result.remaining);
      response.setHeader('X-RateLimit-Reset', Math.ceil(result.resetAt.getTime() / 1000));
    } else if (options.type === 'token-bucket') {
      const result = await this.tokenBucketLimiter.isAllowed(key, {
        capacity: options.capacity || 100,
        refillRate: options.refillRate || 10,
        tokensPerRequest: options.tokensPerRequest || 1,
      });

      if (!result.allowed) {
        throw new HttpException(
          {
            statusCode: HttpStatus.TOO_MANY_REQUESTS,
            message: 'Rate limit exceeded',
            retryAfter: result.retryAfter,
          },
          HttpStatus.TOO_MANY_REQUESTS,
        );
      }

      // Add rate limit headers
      const response = context.switchToHttp().getResponse();
      response.setHeader('X-RateLimit-Limit', options.capacity);
      response.setHeader('X-RateLimit-Remaining', Math.floor(result.remainingTokens));
    }

    return true;
  }

  private defaultKeyGenerator(request: any): string {
    // Use IP address as default key
    const ip = request.ip || request.connection.remoteAddress;
    const path = request.route?.path || request.url;
    return `${ip}:${path}`;
  }
}

import { Controller, Get, Post, Body, UseGuards, Req } from '@nestjs/common';

@UseGuards(RateLimitGuard)

  /**
   * Search endpoint - Token bucket (allows bursts)

  @RateLimit({

    capacity: 50,
    refillRate: 10, // 10 tokens per second
    tokensPerRequest: 1,

    return { results: [] };

  @Post('create')

    return { success: true };

   * Heavy operation - Lower limits
   */
  @Post('export')
  @RateLimit({
    type: 'token-bucket',
    capacity: 5,
    refillRate: 0.1, // 1 token per 10 seconds

  })
  export() {
    return { jobId: 'xxx' };
  }
}

Bulkhead Pattern​

Resource Isolation with Bulkheads​

// services/bulkhead.service.ts
import { Injectable, Logger } from '@nestjs/common';

export interface BulkheadConfig {
  maxConcurrent: number; // Maximum concurrent executions
  maxQueueSize: number; // Maximum queue size
  queueTimeoutMs: number; // Timeout for queued requests
}

interface QueuedRequest<T> {
  operation: () => Promise<T>;
  resolve: (value: T) => void;
  reject: (error: Error) => void;
  enqueuedAt: Date;
}

@Injectable()
export class BulkheadService {
  private readonly logger = new Logger(BulkheadService.name);
  private readonly bulkheads = new Map<
    string,
    {
      config: BulkheadConfig;
      running: number;
      queue: QueuedRequest<any>[];
    }
  >();

  /**
   * Execute operation with bulkhead protection
   */
  async execute<T>(bulkheadName: string, operation: () => Promise<T>, config: BulkheadConfig): Promise<T> {
    if (!this.bulkheads.has(bulkheadName)) {
      this.bulkheads.set(bulkheadName, {
        config,
        running: 0,
        queue: [],
      });
    }

    const bulkhead = this.bulkheads.get(bulkheadName);

    // Check if we can execute immediately
    if (bulkhead.running < config.maxConcurrent) {
      return this.executeImmediately(bulkheadName, operation);
    }

    // Check queue capacity
    if (bulkhead.queue.length >= config.maxQueueSize) {
      throw new Error(`Bulkhead ${bulkheadName} queue full (${config.maxQueueSize})`);
    }

    // Queue the request
    return this.enqueue<T>(bulkheadName, operation, config);
  }

  private async executeImmediately<T>(bulkheadName: string, operation: () => Promise<T>): Promise<T> {
    const bulkhead = this.bulkheads.get(bulkheadName);
    bulkhead.running++;

    try {
      const result = await operation();
      return result;
    } finally {
      bulkhead.running--;
      this.processQueue(bulkheadName);
    }
  }

  private enqueue<T>(bulkheadName: string, operation: () => Promise<T>, config: BulkheadConfig): Promise<T> {
    const bulkhead = this.bulkheads.get(bulkheadName);

    return new Promise<T>((resolve, reject) => {
      const queuedRequest: QueuedRequest<T> = {
        operation,
        resolve,
        reject,
        enqueuedAt: new Date(),
      };

      bulkhead.queue.push(queuedRequest);

      // Set timeout
      setTimeout(() => {
        const index = bulkhead.queue.indexOf(queuedRequest);
        if (index > -1) {
          bulkhead.queue.splice(index, 1);
          reject(new Error(`Bulkhead ${bulkheadName} queue timeout`));
        }
      }, config.queueTimeoutMs);

      this.logger.debug(`Request queued in bulkhead ${bulkheadName}. Queue size: ${bulkhead.queue.length}`);
    });
  }

  private async processQueue(bulkheadName: string): Promise<void> {
    const bulkhead = this.bulkheads.get(bulkheadName);

    while (bulkhead.running < bulkhead.config.maxConcurrent && bulkhead.queue.length > 0) {
      const request = bulkhead.queue.shift();

      if (!request) {
        break;
      }

      // Check timeout
      const queueTime = Date.now() - request.enqueuedAt.getTime();
      if (queueTime > bulkhead.config.queueTimeoutMs) {
        request.reject(new Error(`Bulkhead ${bulkheadName} queue timeout`));
        continue;
      }

      // Execute
      bulkhead.running++;

      request
        .operation()
        .then(request.resolve)
        .catch(request.reject)
        .finally(() => {
          bulkhead.running--;
          this.processQueue(bulkheadName);
        });
    }
  }

  /**
   * Get bulkhead status
   */
  getStatus(bulkheadName: string): any {
    const bulkhead = this.bulkheads.get(bulkheadName);

    if (!bulkhead) {
      return null;
    }

    return {
      name: bulkheadName,
      running: bulkhead.running,
      queued: bulkhead.queue.length,
      maxConcurrent: bulkhead.config.maxConcurrent,
      maxQueueSize: bulkhead.config.maxQueueSize,
    };
  }
}

// services/external-api.service.ts
import { Injectable } from '@nestjs/common';
import { BulkheadService } from './bulkhead.service';
import { CircuitBreakerService } from './circuit-breaker.service';

@Injectable()
export class ExternalApiService {
  constructor(private bulkhead: BulkheadService, private circuitBreaker: CircuitBreakerService) {}

  /**
   * Call external API with bulkhead and circuit breaker
   */
  async callExternalApi(endpoint: string, data: any): Promise<any> {
    // Bulkhead limits concurrent calls
    return this.bulkhead.execute(
      'external-api',
      async () => {
        // Circuit breaker prevents cascading failures
        return this.circuitBreaker.execute(
          'external-api',
          async () => {
            // Actual API call
            const response = await fetch(endpoint, {
              method: 'POST',
              headers: { 'Content-Type': 'application/json' },
              body: JSON.stringify(data),
            });

            return response.json();
          },
          async () => {
            // Fallback
            return { cached: true, data: [] };
          },
        );
      },
      {
        maxConcurrent: 10, // Max 10 concurrent calls
        maxQueueSize: 50, // Queue up to 50 requests
        queueTimeoutMs: 5000, // 5 second queue timeout
      },
    );
  }
}

Fallback Strategies​

// services/fallback-strategies.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { Redis } from 'ioredis';
import { InjectRedis } from '@nestjs-modules/ioredis';

@Injectable()
export class FallbackStrategiesService {
  private readonly logger = new Logger(FallbackStrategiesService.name);

  constructor(@InjectRedis() private readonly redis: Redis) {}

  /**
   * Cached fallback - Return cached data
   */
  async cachedFallback<T>(cacheKey: string, operation: () => Promise<T>, ttlSeconds: number = 3600): Promise<T> {
    try {
      const result = await operation();

      // Cache successful result
      await this.redis.setex(`fallback:${cacheKey}`, ttlSeconds, JSON.stringify(result));

      return result;
    } catch (error) {
      this.logger.warn(`Operation failed, using cached fallback for ${cacheKey}`);

      // Return cached data
      const cached = await this.redis.get(`fallback:${cacheKey}`);

      if (cached) {
        return JSON.parse(cached);
      }

      throw error;
    }
  }

  /**
   * Default value fallback
   */
  async defaultFallback<T>(operation: () => Promise<T>, defaultValue: T): Promise<T> {
    try {
      return await operation();
    } catch (error) {
      this.logger.warn(`Operation failed, using default fallback`);
      return defaultValue;
    }
  }

  /**
   * Degraded service fallback - Return limited data
   */
  async degradedFallback<T>(
    operation: () => Promise<T>,
    degradedOperation: () => Promise<Partial<T>>,
  ): Promise<T | Partial<T>> {
    try {
      return await operation();
    } catch (error) {
      this.logger.warn(`Operation failed, using degraded service`);
      return degradedOperation();
    }
  }

  /**
   * Alternative service fallback
   */
  async alternativeFallback<T>(primaryOperation: () => Promise<T>, alternativeOperation: () => Promise<T>): Promise<T> {
    try {
      return await primaryOperation();
    } catch (error) {
      this.logger.warn(`Primary service failed, using alternative`);
      return alternativeOperation();
    }
  }

  /**
   * Stale-while-revalidate fallback
   */
  async staleWhileRevalidate<T>(cacheKey: string, operation: () => Promise<T>, ttlSeconds: number = 300): Promise<T> {
    const cached = await this.redis.get(`swr:${cacheKey}`);

    if (cached) {
      // Return stale data immediately
      const staleData = JSON.parse(cached);

      // Revalidate in background
      this.revalidateInBackground(cacheKey, operation, ttlSeconds);

      return staleData;
    }

    // No cache, fetch fresh data
    const freshData = await operation();
    await this.redis.setex(`swr:${cacheKey}`, ttlSeconds, JSON.stringify(freshData));

    return freshData;
  }

  private async revalidateInBackground<T>(
    cacheKey: string,
    operation: () => Promise<T>,
    ttlSeconds: number,
  ): Promise<void> {
    try {
      const freshData = await operation();
      await this.redis.setex(`swr:${cacheKey}`, ttlSeconds, JSON.stringify(freshData));
    } catch (error) {
      this.logger.error(`Background revalidation failed for ${cacheKey}`);
    }
  }
}

Adaptive Rate Limiting​

// services/adaptive-rate-limiter.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { SlidingWindowRateLimiterService } from './rate-limiter/sliding-window.service';

@Injectable()
export class AdaptiveRateLimiterService {
  private readonly logger = new Logger(AdaptiveRateLimiterService.name);
  private readonly baselineLatency = new Map<string, number>();
  private readonly currentLimits = new Map<string, number>();

  constructor(private slidingWindowLimiter: SlidingWindowRateLimiterService) {}

  /**
   * Adjust rate limit based on system performance
   */
  async adjustRateLimit(endpoint: string, currentLatency: number, baseLimit: number): Promise<number> {
    const baseline = this.baselineLatency.get(endpoint) || currentLatency;
    this.baselineLatency.set(endpoint, baseline);

    let adjustedLimit = this.currentLimits.get(endpoint) || baseLimit;

    // If latency is 2x baseline, reduce limit by 20%
    if (currentLatency > baseline * 2) {
      adjustedLimit = Math.floor(adjustedLimit * 0.8);
      this.logger.warn(`Reducing rate limit for ${endpoint} to ${adjustedLimit} due to high latency`);
    }
    // If latency is normal and limit is below base, gradually increase
    else if (currentLatency <= baseline * 1.2 && adjustedLimit < baseLimit) {
      adjustedLimit = Math.min(baseLimit, Math.floor(adjustedLimit * 1.1));
      this.logger.log(`Increasing rate limit for ${endpoint} to ${adjustedLimit}`);
    }

    this.currentLimits.set(endpoint, adjustedLimit);
    return adjustedLimit;
  }
}

Retry with Exponential Backoff and Circuit Breaker​

// services/resilient-retry.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { CircuitBreakerService } from './circuit-breaker.service';

export interface RetryConfig {
  maxRetries: number;
  initialDelayMs: number;
  maxDelayMs: number;
  backoffMultiplier: number;
  retryableErrors: string[];
}

@Injectable()
export class ResilientRetryService {
  private readonly logger = new Logger(ResilientRetryService.name);

  constructor(private circuitBreaker: CircuitBreakerService) {}

  /**
   * Retry with exponential backoff and circuit breaker
   */
  async executeWithRetry<T>(
    circuitName: string,
    operation: () => Promise<T>,
    config: RetryConfig,
    fallback?: () => Promise<T>,
  ): Promise<T> {
    return this.circuitBreaker.execute(
      circuitName,
      async () => {
        return this.retryWithBackoff(operation, config);
      },
      fallback,
    );
  }

  private async retryWithBackoff<T>(operation: () => Promise<T>, config: RetryConfig): Promise<T> {
    let lastError: Error;

    for (let attempt = 0; attempt <= config.maxRetries; attempt++) {
      try {
        return await operation();
      } catch (error) {
        lastError = error;

        // Check if error is retryable
        const isRetryable = config.retryableErrors.some((pattern) =>
          error.message.toLowerCase().includes(pattern.toLowerCase()),
        );

        if (!isRetryable || attempt === config.maxRetries) {
          throw error;
        }

        // Calculate delay with exponential backoff
        const delay = Math.min(config.initialDelayMs * Math.pow(config.backoffMultiplier, attempt), config.maxDelayMs);

        this.logger.warn(`Retry ${attempt + 1}/${config.maxRetries} after ${delay}ms. Error: ${error.message}`);

        await this.sleep(delay);
      }
    }

    throw lastError;
  }

  private sleep(ms: number): Promise<void> {
    return new Promise((resolve) => setTimeout(resolve, ms));
  }
}

Best Practices​

1. Circuit Breaker Design​

✅ Do:

  • Set appropriate failure thresholds
  • Implement fallback strategies
  • Monitor circuit state changes
  • Use different circuits for different dependencies
  • Test circuit behavior under load
  • Log state transitions

❌ Don't:

  • Use same circuit for all services
  • Set thresholds too low (flapping)
  • Forget fallback mechanisms
  • Ignore half-open state
  • Deploy without testing
  • Share circuits across unrelated operations

2. Rate Limiting Strategy​

✅ Do:

  • Choose algorithm based on use case
  • Use sliding window for accuracy
  • Use token bucket for burst tolerance
  • Implement per-user and per-IP limits
  • Add rate limit headers to responses
  • Monitor rate limit metrics

❌ Don't:

  • Use fixed window (boundary issues)
  • Apply same limits to all endpoints
  • Forget to communicate limits to clients
  • Ignore authenticated vs anonymous users
  • Skip monitoring
  • Set limits too restrictive

3. Bulkhead Implementation​

✅ Do:

  • Isolate critical resources
  • Set appropriate concurrency limits
  • Implement queue timeouts
  • Monitor queue sizes
  • Test under load
  • Document bulkhead boundaries

❌ Don't:

  • Share thread pools across services
  • Set limits too high (no protection)
  • Forget queue limits
  • Ignore queue timeouts
  • Skip monitoring
  • Deploy without load testing

4. Fallback Mechanisms​

✅ Do:

  • Provide meaningful fallbacks
  • Cache successful responses
  • Use stale-while-revalidate
  • Return degraded service
  • Log fallback usage
  • Monitor fallback rate

❌ Don't:

  • Return empty responses
  • Use same fallback for all errors
  • Cache errors
  • Forget to invalidate cache
  • Hide fallback execution
  • Deploy without fallback testing

5. Monitoring​

✅ Do:

  • Track all resilience patterns
  • Alert on circuit opens
  • Monitor rate limit violations
  • Dashboard bulkhead usage
  • Track fallback execution rate
  • Set up automated alerts

❌ Don't:

  • Deploy without monitoring
  • Ignore circuit state changes
  • Skip rate limit metrics
  • Forget bulkhead metrics
  • Hide fallback usage
  • React only to outages

Summary​

Effective Circuit Breakers and Rate Limiting provide:

  • Resilience - Prevent cascading failures
  • Performance - Fail fast instead of waiting
  • Stability - Protect resources from overload
  • Recovery - Automatic healing when services recover
  • User Experience - Quick responses with fallbacks

Key implementation points:

  • Circuit Breaker with three states (CLOSED, OPEN, HALF-OPEN)
  • Token Bucket for burst-tolerant rate limiting
  • Sliding Window for accurate rate limiting
  • Bulkhead Pattern for resource isolation
  • Multiple fallback strategies (cached, default, degraded, alternative)
  • Comprehensive Prometheus metrics
  • Adaptive rate limiting based on system performance
  • Combined retry with circuit breaker and exponential backoff
  • Rate limiting guards and decorators for NestJS
  • HTTP and database clients with circuit breaker protection

Remember: Resilience patterns are about graceful degradation and maintaining system stability under failure!
