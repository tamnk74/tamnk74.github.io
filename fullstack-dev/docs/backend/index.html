Infrastructure Architecture​

Technology Stack Summary​

Frontend​

  • Framework: Next.js 15+ with App Router
  • UI Library: React 19+ with TypeScript
  • Styling: Tailwind CSS
  • Architecture: Module Federation for microfrontends
  • State Management: Zustand

Backend​

  • Framework: NestJS microservices
  • ORM: TypeORM
  • Authentication: JWT + Auth0 OAuth 2.0
  • API Pattern: API Gateway
  • Message Broker: Kafka/RabbitMQ

Infrastructure​

  • Container Orchestration: Google Kubernetes Engine (GKE)
  • Database: Cloud SQL (PostgreSQL)
  • Storage: Cloud Storage & Filestore
  • Caching: Redis
  • Search: Elasticsearch
  • Networking & Security: Cilium (CNI, Network Policies, Observability)

DevOps & Security​

  • CI/CD: GitHub Actions
  • GitOps: ArgoCD
  • SAST: SonarQube
  • DAST: OWASP ZAP
  • Monitoring: Datadog
  • Kubernetes Networking & Security: Cilium (eBPF-based CNI, network policies, load balancing, observability)

Architecture Patterns & Principles​

Microservices Architecture​

  • API Gateway Pattern: Single entry point for all client requests
  • Service Discovery: Dynamic service registration and discovery
  • Circuit Breaker: Fault tolerance and graceful degradation
  • Event-Driven Architecture: Asynchronous communication via message queues

Security​

  • OAuth 2.0 + JWT: Secure authentication and authorization
  • RBAC: Role-based access control
  • API Rate Limiting: Protection against abuse
  • WAF: Web Application Firewall with Cloud Armor
  • Network Segmentation & Policy Enforcement: Cilium for Kubernetes network policies, transparent service-to-service security, and deep observability

Scalability​

  • Horizontal Scaling: Auto-scaling pods based on load
  • Caching Strategy: Redis for session and data caching
  • Search Optimization: Elasticsearch for fast product search
  • CDN: Cloud Storage for static asset delivery

DevOps​

  • GitOps: Infrastructure and application deployment via Git
  • Security Scanning: SAST with SonarQube, DAST with OWASP ZAP
  • Monitoring: Comprehensive observability with Datadog
  • CI/CD: Automated testing and deployment pipelines

Infrastructure Architecture​

Cilium: Kubernetes Networking, Security, and Observability​

Cilium is an eBPF-powered cloud native networking, security, and observability solution for Kubernetes environments. In this architecture, Cilium is used as the CNI (Container Network Interface) to provide:

  • Advanced Networking: High-performance, scalable networking for microservices.
  • Network Security: Fine-grained, identity-based network policies for zero-trust security between services.
  • Load Balancing: Efficient service-to-service and ingress load balancing.
  • Observability: Deep visibility into network flows, security events, and application dependencies.

Benefits of Cilium in This Architecture​

  • Enforces network segmentation and zero-trust policies between microservices and namespaces.
  • Provides transparent encryption and monitoring of service-to-service traffic.
  • Integrates with Kubernetes NetworkPolicies and enhances them with L7 (HTTP/gRPC) awareness.
  • Enables troubleshooting and auditing of network flows with Hubble observability.

For more details and setup instructions, see the Cilium documentation.
