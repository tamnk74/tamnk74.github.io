🛡️ Security Foundations

Duration: Days 8-14
Goal: Build comprehensive understanding of security concepts and prepare for CompTIA Security+ (SY0-701)

🎯 Learning Objectives​

By the end of this week, you will understand:

  • Security principles (CIA Triad)
  • Threat actors and attack vectors
  • Cryptography fundamentals
  • Identity and access management
  • Network security controls
  • Incident response basics

📺 Primary Courses​

Option 1: Professor Messer's Security+ (Recommended)​

Platform: YouTube
Duration: ~40 hours total
Link: SY0-701 Playlist

Why Professor Messer?
  • Comprehensive coverage
  • Clear explanations
  • Free and high-quality
  • Aligned with exam objectives

Option 2: Pete Zerger's Security+​

Platform: YouTube
Link: SY0-701 Playlist

Day 8: Security Fundamentals​

  • CIA Triad (Confidentiality, Integrity, Availability)
  • Defense in depth
  • Security controls (Preventive, Detective, Corrective)
  • Risk management basics

  • Threat actors and APTs
  • Social engineering attacks
  • Malware types (viruses, worms, trojans, ransomware)
  • Vulnerability assessment

  • Symmetric vs Asymmetric encryption
  • Hashing algorithms

  • Firewalls and IDS/IPS
  • VPNs and encrypted tunnels

  • Wireless security (WPA2, WPA3)

  • Secure coding practices
  • Input validation
  • Data encryption at rest and in transit
  • DLP (Data Loss Prevention)

Day 14: Incident Response & Compliance​

  • Incident response lifecycle
  • Forensics basics

  • Business continuity and disaster recovery

🔐 Key Security Concepts​

CIA Triad​

Confidentiality

  • Protecting data from unauthorized access
  • Encryption, access controls, authentication

Integrity

  • Ensuring data accuracy and trustworthiness
  • Hashing, digital signatures, version control

Availability

  • Ensuring systems are accessible when needed
  • Redundancy, backups, DDoS protection

Security Controls​

TypePurposeExamples
PreventiveStop incidents before they occurFirewalls, Encryption, Access controls
DetectiveIdentify incidents when they occurIDS, Security monitoring, Logs
CorrectiveFix problems after detectionPatches, Backups, Incident response
DeterrentDiscourage attacksWarning banners, Security policies
CompensatingAlternative controlsManual review, Additional monitoring

Common Threats​

Social Engineering

  • Phishing (email-based)
  • Vishing (voice-based)
  • Smishing (SMS-based)
  • Pretexting
  • Baiting

Malware Types

  • Virus: Requires host file
  • Worm: Self-replicating
  • Trojan: Disguised as legitimate software
  • Ransomware: Encrypts data for ransom
  • Spyware: Steals information
  • Rootkit: Hides malicious activity

Cryptography Basics​

Symmetric Encryption (Same key for encryption/decryption)

  • AES (Advanced Encryption Standard)
  • DES/3DES (Deprecated)
  • Fast but key distribution challenge

Asymmetric Encryption (Public/Private key pair)

  • RSA
  • ECC (Elliptic Curve Cryptography)
  • Slower but secure key exchange

Hashing (One-way function)

  • SHA-256, SHA-3
  • MD5 (Deprecated)
  • Used for integrity verification

🛠️ Hands-On Practice​

Security Tools to Explore​

  1. Password Managers

    • Practice: Set up a password manager (LastPass, 1Password, Bitwarden)
    • Create strong, unique passwords

  2. Encryption Tools

    • VeraCrypt: Encrypt files and folders
    • GPG: Practice with public key encryption

  3. Security Assessment

    • OWASP ZAP: Web application security scanner
    • Nmap: Network scanner (covered in hacking module)

Practice Labs​

# Password strength testing
# Never use these on real systems without permission

# Generate strong password
openssl rand -base64 32

# Hash a password
echo -n "password123" | sha256sum

# Check SSL/TLS certificate
openssl s_client -connect google.com:443

📚 Security Frameworks​

Common Frameworks​

  • NIST Cybersecurity Framework: Identify, Protect, Detect, Respond, Recover
  • ISO 27001: Information security management
  • COBIT: IT governance framework
  • CIS Controls: 20 critical security controls

Compliance Standards​

  • PCI-DSS: Payment card industry
  • HIPAA: Healthcare data
  • GDPR: EU data protection
  • SOX: Financial reporting

✅ Practice Questions​

  1. What is the difference between symmetric and asymmetric encryption?
  2. Explain the CIA Triad and give examples of each.
  3. What are the phases of incident response?
  4. Describe three types of authentication factors.
  5. What is the difference between IDS and IPS?

  • Security+ Practice Tests: PocketPrep

🎯 Success Criteria​

By Day 14, you should be able to:

  • ✅ Explain core security principles (CIA Triad)
  • ✅ Identify threat actors and attack vectors
  • ✅ Understand cryptography basics
  • ✅ Describe authentication and authorization methods
  • ✅ Explain network security controls
  • ✅ Understand incident response process
  • ✅ Identify compliance requirements
