🔍 Traffic Analysis

Duration: Days 43-56 (2 weeks)
Goal: Master network traffic analysis, packet inspection, and intrusion detection

🎯 Learning Objectives​

By the end of these two weeks, you will:

  • Capture and analyze network packets
  • Use Wireshark for deep packet inspection
  • Master TCPdump for command-line analysis
  • Configure and use Suricata IDS/IPS
  • Identify suspicious network activity
  • Perform network forensics
  • Understand common attack patterns

🔧 Wireshark Essentials​

Common Display Filters​

# HTTP traffic
http

# Specific IP address
ip.addr == 192.168.1.100
ip.src == 192.168.1.100
ip.dst == 192.168.1.100

# Port filtering
tcp.port == 80
tcp.port == 443 or tcp.port == 8080

# Protocol filtering
dns
tls
ssh
ftp

# TCP flags
tcp.flags.syn == 1
tcp.flags.reset == 1

# HTTP methods
http.request.method == "GET"
http.request.method == "POST"

# Combinations
ip.src == 192.168.1.100 and tcp.port == 443
(http or https) and ip.addr == 10.0.0.1

# String matching
http contains "password"
dns.qry.name contains "malicious"

# Packet size
frame.len > 1000
tcp.len > 0

Following Streams​

# Follow TCP stream
Right-click packet → Follow → TCP Stream

# Follow HTTP stream
Right-click packet → Follow → HTTP Stream

# Follow TLS stream
Right-click packet → Follow → TLS Stream

# Follow UDP stream
Right-click packet → Follow → UDP Stream

Export Objects​

# Export HTTP objects
File → Export Objects → HTTP

# Export files from captures
Filter specific protocol → Export Objects

# Export packets
File → Export Specified Packets

💻 TCPdump Commands​

Basic Capture​

# Capture on interface
sudo tcpdump -i eth0

# Capture specific count
sudo tcpdump -i eth0 -c 100

# Write to file
sudo tcpdump -i eth0 -w capture.pcap

# Read from file
tcpdump -r capture.pcap

# Verbose output
sudo tcpdump -i eth0 -v
sudo tcpdump -i eth0 -vv
sudo tcpdump -i eth0 -vvv

Filtering​

# Host filtering
sudo tcpdump host 192.168.1.100
sudo tcpdump src host 192.168.1.100
sudo tcpdump dst host 192.168.1.100

# Port filtering
sudo tcpdump port 80
sudo tcpdump src port 80
sudo tcpdump dst port 80
sudo tcpdump portrange 80-443

# Protocol filtering
sudo tcpdump tcp
sudo tcpdump udp
sudo tcpdump icmp

# Network filtering
sudo tcpdump net 192.168.1.0/24

# Combinations
sudo tcpdump 'tcp port 80 and host 192.168.1.100'
sudo tcpdump 'tcp port 443 or tcp port 8443'
sudo tcpdump 'not port 22'

# Complex filters
sudo tcpdump 'tcp[tcpflags] & (tcp-syn|tcp-ack) != 0'
sudo tcpdump 'tcp[13] & 2 != 0' # SYN packets

Advanced Usage​

# Capture with timestamps
sudo tcpdump -i eth0 -tttt

# Capture with ASCII and hex
sudo tcpdump -i eth0 -X

# Capture with packet numbers
sudo tcpdump -i eth0 -#

# Capture specific size
sudo tcpdump -i eth0 -s 65535

# Rotate capture files
sudo tcpdump -i eth0 -w capture.pcap -C 100 -W 10

🛡️ Suricata Configuration​

Basic Rule Structure​

# Rule format
action protocol src_ip src_port -> dst_ip dst_port (options)

# Example rules
alert tcp any any -> 192.168.1.0/24 80 (msg:"HTTP Traffic Detected"; sid:1000001;)

alert http any any -> any any (msg:"Suspicious User Agent"; \
  http.user_agent; content:"bot"; nocase; sid:1000002;)

alert dns any any -> any any (msg:"Suspicious DNS Query"; \
  dns.query; content:"malicious.com"; nocase; sid:1000003;)

alert tls any any -> any any (msg:"Suspicious TLS Certificate"; \
  tls.subject; content:"CN=fake"; sid:1000004;)

Rule Actions​

# Alert - Generate alert
alert tcp any any -> any 22 (msg:"SSH Connection"; sid:1000005;)

# Drop - Drop packet and alert (IPS mode)
drop tcp any any -> any any (msg:"Block Malicious Traffic"; sid:1000006;)

# Reject - Send RST/ICMP unreachable
reject tcp any any -> any 80 (msg:"Reject HTTP"; sid:1000007;)

# Pass - Allow packet
pass tcp any any -> any 443 (msg:"Allow HTTPS"; sid:1000008;)

Common Rule Options​

# Content matching
content:"malware";
content:"|01 02 03|"; # Hex content
content:!"benign"; # Negation

# Case sensitivity
nocase;

# Depth and offset
depth:10;
offset:5;

# Distance and within
distance:0;
within:20;

# PCRE (Perl Compatible Regular Expressions)
pcre:"/regex-pattern/i";

# Flow
flow:to_server,established;
flow:from_server;

# Threshold
threshold:type limit, track by_src, count 5, seconds 60;

# Reference
reference:cve,2023-1234;
reference:url,example.com;

# Classification
classtype:trojan-activity;

# Priority
priority:1;

Example Configuration​

# /etc/suricata/suricata.yaml

vars:
  address-groups:
    HOME_NET: "[192.168.0.0/16]"
    EXTERNAL_NET: "!$HOME_NET"

  port-groups:
    HTTP_PORTS: "80"
    HTTPS_PORTS: "443"
    SSH_PORTS: "22"

# Rule files
default-rule-path: /etc/suricata/rules
rule-files:
  - suricata.rules
  - emerging-threats.rules
  - custom.rules

# Output
outputs:
  - fast:
      enabled: yes
      filename: fast.log
  - eve-log:
      enabled: yes
      filetype: regular
      filename: eve.json
      types:
        - alert
        - http
        - dns
        - tls
        - files

🔍 Analysis Techniques​

Identifying Attacks​

Port Scanning Detection

# Wireshark filter
tcp.flags.syn == 1 and tcp.flags.ack == 0

# TCPdump
sudo tcpdump 'tcp[tcpflags] & tcp-syn != 0 and tcp[tcpflags] & tcp-ack == 0'

DDoS Detection

# High volume of packets from single source
ip.src == x.x.x.x and frame.len < 100

# SYN flood
tcp.flags.syn == 1 and tcp.flags.ack == 0

# Statistics → Conversations

Data Exfiltration

# Large outbound transfers
ip.src == [internal] and frame.len > 1000

# Unusual protocols
dns.qry.name contains "." and dns.qry.type == 16

# HTTP POST with large data
http.request.method == "POST" and http.content_length > 10000

Malware C&C Traffic

# Beaconing (regular intervals)
# Statistics → I/O Graph

# Suspicious User-Agents
http.user_agent contains "bot" or http.user_agent contains "scan"

# Non-standard ports
http and tcp.port != 80 and tcp.port != 8080
