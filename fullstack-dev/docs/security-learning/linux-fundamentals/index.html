🐧 Linux Fundamentals

Duration: Days 15-28 (2 weeks)
Goal: Master Linux command line, shell scripting, and system administration essentials

🎯 Learning Objectives​

By the end of these two weeks, you will:

  • Navigate Linux file system confidently
  • Execute and understand command-line operations
  • Write basic shell scripts
  • Manage users, permissions, and processes
  • Configure network settings and services
  • Understand system security in Linux

📚 Primary Learning Resources​

1. Linux Journey (Interactive Tutorial)​

Platform: Web-based
Link: linuxjourney.com
Coverage: Grasshopper → Journeyman → Networker

2. Cisco NetAcad - Linux Unhatched​

Platform: Cisco NetAcad
Link: netacad.com/courses/linux-unhatched
Format: Self-paced course with labs

3. LabEx Linux Labs​

Platform: LabEx
Link: labex.io/free-labs/linux
Format: Hands-on labs in browser

📝 Two-Week Breakdown​

Week 1: Linux Basics (Days 15-21)​

Day 15: Getting Started​

  • Linux distributions overview
  • Linux file system hierarchy
  • Basic commands: ls, cd, pwd, mkdir, rm
  • File and directory operations

Day 16: File Management​

  • File permissions (read, write, execute)
  • chmod, chown, chgrp commands
  • Symbolic vs numeric permissions
  • Special permissions (SUID, SGID, Sticky bit)

Day 17: Text Processing​

  • Reading files: cat, less, more, head, tail
  • Text editors: nano, vim basics
  • Search and filter: grep, find, locate
  • Text manipulation: awk, sed, cut

Day 18: Process Management​

  • Viewing processes: ps, top, htop
  • Process control: kill, killall, pkill
  • Background jobs: &, fg, bg, jobs
  • System monitoring

Day 19: User Management​

  • Creating users: useradd, adduser
  • Modifying users: usermod, passwd
  • Group management: groupadd, groups
  • /etc/passwd and /etc/shadow

Day 20: Package Management​

  • APT (Debian/Ubuntu): apt-get, apt
  • YUM/DNF (RedHat/CentOS): yum, dnf
  • Installing, updating, removing packages
  • Repository management

Day 21: Week 1 Review​

  • Practice all commands learned
  • Complete Linux Journey "Grasshopper" section
  • Hands-on lab exercises

Week 2: Advanced Linux (Days 22-28)​

Day 22: Shell Scripting Basics​

  • Bash scripting fundamentals
  • Variables and data types
  • User input and output
  • Basic script structure

Day 23: Shell Scripting Advanced​

  • Conditional statements (if, else, elif)
  • Loops (for, while, until)
  • Functions
  • Script debugging

Day 24: Networking in Linux​

  • Network configuration: ifconfig, ip
  • Network testing: ping, traceroute, netstat
  • DNS tools: dig, nslookup, host
  • Firewall basics: iptables, ufw

Day 25: System Administration​

  • Service management: systemctl, service
  • Scheduled tasks: cron, crontab
  • Log management: /var/log/, journalctl
  • Disk management: df, du, mount

Day 26: Security Basics​

  • SSH configuration and key-based authentication
  • Firewall configuration
  • User security and sudo
  • File integrity monitoring

Day 27: System Troubleshooting​

  • Boot process understanding
  • System logs analysis
  • Performance troubleshooting
  • Common issues and fixes

Day 28: Final Review & Practice​

  • Complete all LabEx Linux labs
  • Review all topics
  • Build a practice project
  • Take assessment quiz

🛠️ Essential Linux Commands​

File System Navigation​

# Navigation
cd /path/to/directory    # Change directory
pwd                      # Print working directory
ls -la                   # List files (detailed, including hidden)

# File operations
cp source dest           # Copy
mv source dest           # Move/Rename
rm file                  # Remove file
rm -rf directory         # Remove directory recursively

# Directory operations
mkdir directory          # Create directory
rmdir directory          # Remove empty directory
touch filename           # Create empty file

File Permissions​

# View permissions
ls -l file.txt

# Change permissions (numeric)
chmod 755 script.sh      # rwxr-xr-x
chmod 644 file.txt       # rw-r--r--

# Change permissions (symbolic)
chmod u+x script.sh      # Add execute for user
chmod g-w file.txt       # Remove write for group
chmod o=r file.txt       # Set read only for others

# Change ownership
chown user:group file.txt

Text Processing​

# View files
cat file.txt             # Display entire file
less file.txt            # Page through file
head -n 10 file.txt      # First 10 lines
tail -n 10 file.txt      # Last 10 lines
tail -f log.txt          # Follow file changes

# Search
grep "pattern" file.txt  # Search in file
grep -r "pattern" .      # Recursive search
find / -name "file.txt"  # Find file by name

# Text manipulation
sed 's/old/new/g' file   # Replace text
awk '{print $1}' file    # Print first column
cut -d':' -f1 /etc/passwd # Extract fields

Process Management​

# View processes
ps aux                   # All processes
ps aux | grep apache     # Find specific process
top                      # Interactive process viewer
htop                     # Better process viewer

# Control processes
kill PID                 # Terminate process
kill -9 PID              # Force kill
killall process_name     # Kill by name
pkill pattern            # Kill by pattern

# Background jobs
command &                # Run in background
jobs                     # List background jobs
fg %1                    # Bring job to foreground
bg %1                    # Resume job in background

System Information​

# System info
uname -a                 # System information
hostname                 # System hostname
whoami                   # Current user
id                       # User ID and groups
uptime                   # System uptime

# Disk usage
df -h                    # Disk space usage
du -sh directory         # Directory size
free -h                  # Memory usage

# Network
ifconfig                 # Network interfaces (old)
ip addr                  # Network interfaces (new)
netstat -tuln            # Listening ports
ss -tuln                 # Socket statistics

📜 Basic Shell Script Template​

#!/bin/bash
# Script description
# Author: Your Name
# Date: YYYY-MM-DD

# Variables
VARIABLE="value"

# Functions
function my_function() {
    echo "Function called"
}

# Main script logic
echo "Starting script..."

# Conditional
if [ -f "/path/to/file" ]; then
    echo "File exists"
else
    echo "File does not exist"
fi

# Loop
for i in {1..5}; do
    echo "Iteration $i"
done

# Call function
my_function

echo "Script completed"

🔐 Linux Security Essentials​

User Security​

# Create user with home directory
sudo useradd -m -s /bin/bash username
sudo passwd username

# Grant sudo access
sudo usermod -aG sudo username

# Lock/unlock user
sudo passwd -l username
sudo passwd -u username

SSH Security​

# Generate SSH key
ssh-keygen -t rsa -b 4096

# Copy key to server
ssh-copy-id user@server

# SSH config (~/.ssh/config)
Host myserver
    HostName 192.168.1.100
    User username
    Port 22
    IdentityFile ~/.ssh/id_rsa

Firewall (UFW)​

# Enable firewall
sudo ufw enable

# Allow/deny ports
sudo ufw allow 22/tcp
sudo ufw deny 23/tcp

# Allow specific IP
sudo ufw allow from 192.168.1.100

# Status
sudo ufw status verbose

  • Sets up home directories
  • Generates random passwords
  • Logs all actions
