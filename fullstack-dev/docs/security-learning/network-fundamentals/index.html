📡 Network Fundamentals

Duration: Days 1-7
Goal: Build a strong foundation in networking concepts and prepare for CompTIA Network+ (N10-009)

🎯 Learning Objectives​

By the end of this week, you will understand:

  • Network architectures and topologies
  • TCP/IP protocol suite
  • Network devices (routers, switches, firewalls)
  • IP addressing and subnetting
  • Network troubleshooting fundamentals
  • Wireless networking concepts

📺 Primary Course​

Professor Messer's Network+ (N10-009)​

Platform: YouTube
Duration: ~30 hours total
Link: N10-009 Playlist

Study Approach
  • Watch 4-5 videos per day
  • Take detailed notes
  • Pause to understand concepts
  • Review previous topics daily

📝 Daily Breakdown​

Day 1: Network Fundamentals​

  • Network types (LAN, WAN, MAN, PAN)
  • Network topologies (Star, Bus, Ring, Mesh)
  • OSI Model overview
  • TCP/IP Model

Day 2: Network Devices​

  • Routers vs Switches
  • Hubs and Bridges
  • Firewalls and IDS/IPS
  • Wireless Access Points

Day 3: IP Addressing​

  • IPv4 addressing and classes
  • Subnetting basics
  • IPv6 introduction
  • DHCP and DNS

Day 4: Network Protocols​

  • TCP vs UDP
  • HTTP/HTTPS
  • FTP, SFTP, SSH
  • SMTP, POP3, IMAP

Day 5: Network Services​

  • DHCP configuration
  • DNS hierarchy
  • NTP (Network Time Protocol)
  • NAT and PAT

Day 6: Network Security​

  • Basic security concepts
  • VLANs and network segmentation
  • Port security
  • Basic firewall rules

Day 7: Review & Practice​

  • Review all topics
  • Practice subnetting calculations
  • Network troubleshooting scenarios
  • Take practice quizzes

🛠️ Hands-On Labs​

Recommended Practice​

  1. Subnetting Calculator Practice

    • Use Subnet Calculator
    • Practice subnetting different networks
    • Understand CIDR notation

  2. Packet Tracer (Optional)

    • Download Cisco Packet Tracer
    • Build basic network topologies
    • Configure routers and switches

  3. Command Line Practice

    # Windows
    ipconfig /all
    ping google.com
    tracert google.com
    nslookup google.com

    # Linux/Mac
    ifconfig
    ping google.com
    traceroute google.com
    dig google.com

📚 Key Concepts to Master​

Network Models​

  • OSI Model: Physical, Data Link, Network, Transport, Session, Presentation, Application
  • TCP/IP Model: Network Interface, Internet, Transport, Application

IP Addressing​

  • IPv4: 32-bit addresses (e.g., 192.168.1.1)
  • Subnet Mask: Defines network vs host portion
  • Default Gateway: Router for external communication
  • IPv6: 128-bit addresses (future-proofing)

✅ Practice Questions​

Test your knowledge with these questions:

  1. What is the difference between a router and a switch?
  2. Explain the difference between TCP and UDP.
  3. What is the purpose of a subnet mask?
  4. Describe the seven layers of the OSI model.
  5. How does DHCP work?

🎯 Success Criteria​

By Day 7, you should be able to:

  • ✅ Explain network topologies and architectures
  • ✅ Understand the OSI and TCP/IP models
  • ✅ Calculate subnets and understand CIDR notation
  • ✅ Identify common network protocols and ports
  • ✅ Troubleshoot basic network connectivity issues
  • ✅ Describe network security fundamentals
