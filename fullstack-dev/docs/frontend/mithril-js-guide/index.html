Mithril.js Comprehensive Guide

Overview​

Mithril.js is a modern client-side JavaScript framework for building Single Page Applications (SPAs). It is small (< 10kb gzip), fast, and provides routing and XHR utilities out of the box. Unlike other frameworks that might require large ecosystems or build steps (though build steps are recommended for production), Mithril.js is self-contained and easy to understand.

Key Features:

  • Lightweight: ~9.5kb gzipped.
  • Fast: Virtual DOM diffing is highly optimized.
  • Batteries Included: Includes routing (m.route) and XHR (m.request).
  • JavaScript-Centric: Uses standard JavaScript idioms; JSX is optional.
  • API Stability: Very stable API with few breaking changes over time.

Top 10 Common Use Cases and Architectures​

Mithril's small footprint and high performance make it suitable for a variety of scenarios where larger frameworks might be overkill.

  1. Single Page Applications (SPAs): The primary use case. Mithril handles routing and state management elegantly for complex applications.

  2. Embedded Widgets: Due to its tiny size, Mithril is perfect for embedding complex interactive widgets (like a chat box or a dynamic form) into server-rendered pages (e.g., WordPress, Rails, Django) without bloating the page load.

  3. Performance-Critical Dashboards: Mithril's rendering engine is extremely fast. For dashboards displaying real-time data or large tables, Mithril often outperforms React and Vue.

  4. Mobile Hybrid Applications: When wrapping a web app in Cordova or Capacitor, Mithril's low memory usage and fast startup time provide a more native-like feel on lower-end mobile devices.

  5. Micro-Frontends: In a micro-frontend architecture, keeping the bundle size of each "micro-app" small is crucial. Mithril is an excellent choice for individual fragments of a larger system.

  6. Legacy Code Migration: Mithril can be "mounted" to any DOM element. You can migrate a jQuery spaghetti-code application piece by piece by replacing specific DOM sections with Mithril components.

  7. Low-Bandwidth Environments: For applications targeting users with slow internet connections (e.g., 2G/3G networks), the small initial download size is a significant advantage.

  8. Educational Tooling: Its small API surface makes it an excellent framework for teaching MVC (Model-View-Controller) concepts and how Virtual DOM works under the hood without the distraction of complex build tools.

  9. Prototyping: With no build step required (just include the CDN link), developers can start prototyping complex UIs in a single HTML file instantly.

  10. Game UI Layers: For browser-based games, Mithril can handle the UI overlay (menus, inventory, HUD) efficiently without impacting the game loop's performance significantly.

Installation and Usage​

1. Installation​

Via NPM (Recommended for Production):

npm install mithril --save
# or
yarn add mithril
# or
pnpm add mithril

Via CDN (For Prototyping):

<script src="https://unpkg.com/mithril/mithril.js"></script>

2. Basic Usage​

Mithril uses a hyperscript function m() to describe the view.

Hello World:

import m from "mithril";

const root = document.body;

m.render(root, m("h1", "Hello world"));

3. Components​

Components are simple objects with a view method.

const HelloComponent = {
    view: function() {
        return m("main", [
            m("h1", { class: "title" }, "Hello from a Component"),
            m("button", {
                onclick: () => alert("Clicked!")
            }, "Click Me")
        ]);
    }
};

m.mount(document.body, HelloComponent);

4. Integration with Other Libraries​

Using JSX (Optional): You can use JSX if you configure Babel.

// .babelrc
{
    "plugins": [
        ["transform-react-jsx", {
            "pragma": "m"
        }]
    ]
}

// In your code
const view = <div class="foo">Hello</div>;

Integrating with Third-Party Libraries (e.g., Chart.js): Use lifecycle hooks oncreate and onremove.

import m from "mithril";
import Chart from "chart.js/auto";

const ChartComponent = {
    oncreate: function(vnode) {
        // vnode.dom is the real DOM element
        const ctx = vnode.dom.getContext('2d');
        this.chart = new Chart(ctx, {
            type: 'bar',
            data: vnode.attrs.data
        });
    },
    onremove: function() {
        // Cleanup to prevent memory leaks
        if (this.chart) {
            this.chart.destroy();
        }
    },
    view: function() {
        return m("canvas", { width: 400, height: 400 });
    }
};

Best Practices​

  1. Use m.request for Data Fetching: Always use Mithril's built-in m.request. It automatically triggers a redraw when the request completes, eliminating manual UI update calls.

    m.request({
        method: "GET",
        url: "/api/user/1"
    }).then(userData => {
        state.user = userData;
    });

  2. Closures for Component State: Use closure components to maintain private state. This is cleaner than attaching state to the vnode or using global variables.

    function Counter() {
        let count = 0; // Private state
        
        return {
            view: () => m("button", {
                onclick: () => count++
            }, `Count: ${count}`)
        };
    }

  3. Keys in Lists: Always provide a unique key attribute when rendering lists of items. This helps the diff engine maintain state and DOM focus correctly.

    items.map(item => m("li", { key: item.id }, item.name))

  4. Avoid Logic in Views: Keep your view functions clean. Move heavy business logic to model files or utility functions. The view should only be concerned with presentation.

  5. Use m.route for Navigation: Don't reinvent the wheel. Use Mithril's routing system for managing URLs and history state.

    m.route(document.body, "/home", {
        "/home": Home,
        "/dashboard": Dashboard,
    });

  6. Redraw Strategy: Mithril redraws automatically after event handlers and m.request. If you use third-party events (like setTimeout or WebSockets), you must call m.redraw() manually.

  7. Type Safety (TypeScript): Mithril has excellent TypeScript definitions. Use them to ensure your component attrs and state are type-safe.

Summary​

Mithril.js is a pragmatic choice for developers who value performance, simplicity, and control. It strips away the magic found in other frameworks, leaving you with just JavaScript and the DOM. Whether you are building a small widget or a large-scale enterprise application, Mithril provides the tools to do it efficiently.
