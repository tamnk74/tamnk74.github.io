Playwright Testing Setup for Micro-Frontends

A comprehensive guide to setting up and configuring Playwright for end-to-end testing in a micro-frontend architecture with Next.js 16 and Turbopack.

Why Playwright for Micro-Frontends?​

Playwright is ideal for micro-frontend testing because it:

  • ✅ Cross-Browser Testing: Test across Chromium, Firefox, and WebKit
  • ✅ Auto-wait: Automatically waits for elements to be ready
  • ✅ Network Control: Mock and intercept network requests
  • ✅ Parallel Execution: Run tests concurrently for faster feedback
  • ✅ Visual Testing: Built-in screenshot comparison
  • ✅ Multi-Context: Test cross-MFE communication easily
  • ✅ CI/CD Ready: Seamless integration with GitHub Actions

Installation​

Step 1: Install Playwright​

Install Playwright in your monorepo root or each MFE:

# Install in root for all MFEs
pnpm add -D @playwright/test -w

# Or install per MFE
cd apps/shell
pnpm add -D @playwright/test

# Install browsers
pnpm exec playwright install --with-deps

Page Object Model (POM)​

Base Page​

e2e/pages/BasePage.ts:

import { Page, Locator, expect } from '@playwright/test';

/**
 * Base Page Object containing common functionality
 */
export class BasePage {
  readonly page: Page;
  readonly header: Locator;
  readonly footer: Locator;
  readonly cartIcon: Locator;
  readonly cartCount: Locator;
  readonly userIcon: Locator;
  readonly searchInput: Locator;

  constructor(page: Page) {
    this.page = page;
    this.header = page.locator('header');
    this.footer = page.locator('footer');
    this.cartIcon = page.locator('[data-testid="cart-icon"]');
    this.cartCount = page.locator('[data-testid="cart-count"]');
    this.userIcon = page.locator('[data-testid="user-icon"]');
    this.searchInput = page.locator('[data-testid="search-input"]');
  }

  /**
   * Navigate to a specific URL
   */
  async goto(path: string = '/') {
    await this.page.goto(path);
    await this.waitForPageLoad();
  }

  /**
   * Wait for page to be fully loaded
   */
  async waitForPageLoad() {
    await this.page.waitForLoadState('networkidle');
    await this.page.waitForLoadState('domcontentloaded');
  }

  /**
   * Get cart count
   */
  async getCartCount(): Promise<number> {
    const count = await this.cartCount.textContent();
    return count ? parseInt(count, 10) : 0;
  }

  /**
   * Navigate to cart
   */
  async goToCart() {
    await this.cartIcon.click();
    await this.page.waitForURL('**/cart');
  }

  /**
   * Search for products
   */
  async search(query: string) {
    await this.searchInput.fill(query);
    await this.searchInput.press('Enter');
    await this.waitForPageLoad();
  }

  /**
   * Wait for toast notification
   */
  async waitForToast(type: 'success' | 'error' | 'info' = 'success') {
    await this.page.waitForSelector(`[data-testid="toast-${type}"]`, {
      state: 'visible',
    });
  }

  /**
   * Take screenshot with timestamp
   */
  async takeScreenshot(name: string) {
    const timestamp = new Date().toISOString().replace(/[:.]/g, '-');
    await this.page.screenshot({
      path: `screenshots/${name}-${timestamp}.png`,
      fullPage: true,
    });
  }

  /**
   * Check if element is visible
   */
  async isVisible(selector: string): Promise<boolean> {
    return await this.page.locator(selector).isVisible();
  }

  /**
   * Wait for API response
   */
  async waitForApiResponse(url: string | RegExp, status: number = 200) {
    const response = await this.page.waitForResponse(
      (response) =>
        (typeof url === 'string' ? response.url().includes(url) : url.test(response.url())) &&
        response.status() === status,
    );
    return response;
  }

  /**
   * Mock API response
   */
  async mockApiResponse(url: string | RegExp, data: any, status: number = 200) {
    await this.page.route(url, async (route) => {
      await route.fulfill({
        status,
        contentType: 'application/json',
        body: JSON.stringify(data),
      });
    });
  }
}

Products Page​

e2e/pages/ProductsPage.ts:

import { Page, Locator, expect } from '@playwright/test';
import { BasePage } from './BasePage';

export class ProductsPage extends BasePage {
  readonly productCards: Locator;
  readonly productNames: Locator;
  readonly addToCartButtons: Locator;
  readonly filterCategory: Locator;
  readonly sortDropdown: Locator;
  readonly priceRange: Locator;
  readonly loadingIndicator: Locator;

  constructor(page: Page) {
    super(page);
    this.productCards = page.locator('[data-testid="product-card"]');
    this.productNames = page.locator('[data-testid="product-name"]');
    this.addToCartButtons = page.locator('[data-testid="add-to-cart"]');
    this.filterCategory = page.locator('[data-testid="filter-category"]');
    this.sortDropdown = page.locator('[data-testid="sort-dropdown"]');
    this.priceRange = page.locator('[data-testid="price-range"]');
    this.loadingIndicator = page.locator('[data-testid="loading"]');
  }

  /**
   * Navigate to products page
   */
  async goto() {
    await super.goto('/products');
    await this.waitForProductsToLoad();
  }

  /**
   * Wait for products to load
   */
  async waitForProductsToLoad() {
    await this.page.waitForSelector('[data-testid="product-card"]', {
      state: 'visible',
    });
    await this.loadingIndicator.waitFor({ state: 'hidden' });
  }

  /**
   * Get total number of products
   */
  async getProductCount(): Promise<number> {
    return await this.productCards.count();
  }

  /**
   * Get product by index
   */
  getProduct(index: number) {
    return this.productCards.nth(index);
  }

  /**
   * Get product by name
   */
  getProductByName(name: string) {
    return this.page.locator(`[data-testid="product-card"]:has-text("${name}")`);
  }

  /**
   * Add product to cart by index
   */
  async addToCart(index: number) {
    const initialCount = await this.getCartCount();
    await this.getProduct(index).locator('[data-testid="add-to-cart"]').click();
    await this.waitForToast('success');

    // Verify cart count increased
    await expect(this.cartCount).toHaveText(String(initialCount + 1));
  }

  /**
   * Add product to cart by name
   */
  async addToCartByName(name: string) {
    const initialCount = await this.getCartCount();
    await this.getProductByName(name).locator('[data-testid="add-to-cart"]').click();
    await this.waitForToast('success');

    await expect(this.cartCount).toHaveText(String(initialCount + 1));
  }

  /**
   * Click on product to view details
   */
  async viewProductDetails(index: number) {
    await this.getProduct(index).click();
    await this.page.waitForURL(/\/products\/\w+/);
  }

  /**
   * Filter by category
   */
  async filterByCategory(category: string) {
    await this.filterCategory.selectOption(category);
    await this.waitForProductsToLoad();
  }

  /**
   * Sort products
   */
  async sortBy(option: string) {
    await this.sortDropdown.selectOption(option);
    await this.waitForProductsToLoad();
  }

  /**
   * Set price range
   */
  async setPriceRange(min: number, max: number) {
    await this.priceRange.fill(`${min}-${max}`);
    await this.page.keyboard.press('Enter');
    await this.waitForProductsToLoad();
  }

  /**
   * Get all product names
   */
  async getAllProductNames(): Promise<string[]> {
    return await this.productNames.allTextContents();
  }

  /**
   * Verify products are sorted by price
   */
  async verifyPriceSorting(order: 'asc' | 'desc') {
    const prices = await this.page.locator('[data-testid="product-price"]').allTextContents();
    const numericPrices = prices.map((p) => parseFloat(p.replace(/[^0-9.]/g, '')));

    if (order === 'asc') {
      for (let i = 1; i < numericPrices.length; i++) {
        expect(numericPrices[i]).toBeGreaterThanOrEqual(numericPrices[i - 1]);
      }
    } else {
      for (let i = 1; i < numericPrices.length; i++) {
        expect(numericPrices[i]).toBeLessThanOrEqual(numericPrices[i - 1]);
      }
    }
  }
}

import { Page, Locator, expect } from '@playwright/test';
import { BasePage } from './BasePage';

export class CartPage extends BasePage {

    this.emptyCartMessage = page.locator('[data-testid="empty-cart"]');
    this.subtotal = page.locator('[data-testid="subtotal"]');
    this.tax = page.locator('[data-testid="tax"]');
    this.total = page.locator('[data-testid="total"]');
    this.checkoutButton = page.locator('[data-testid="checkout-button"]');
    this.continueShoppingButton = page.locator('[data-testid="continue-shopping"]');
  }

  /**
   * Navigate to cart page
   */
  async goto() {
    await super.goto('/cart');
  }

  /**
   * Get number of items in cart
   */
  async getItemCount(): Promise<number> {
    return await this.cartItems.count();
  }

  /**
   * Get cart item by index
   */
  getItem(index: number) {
    return this.cartItems.nth(index);
  }

  /**
   * Get cart item by product name
   */
  getItemByName(name: string) {
    return this.page.locator(`[data-testid="cart-item"]:has-text("${name}")`);
  }

  /**
   * Update quantity for item
   */
  async updateQuantity(index: number, quantity: number) {
    const item = this.getItem(index);
    const quantityInput = item.locator('[data-testid="quantity-input"]');
    await quantityInput.fill(String(quantity));
    await this.page.keyboard.press('Enter');
    await this.waitForPageLoad();
  }

  /**
   * Remove item from cart
   */
  async removeItem(index: number) {
    const initialCount = await this.getItemCount();
    await this.getItem(index).locator('[data-testid="remove-item"]').click();

    // Wait for confirmation modal if exists
    const confirmButton = this.page.locator('[data-testid="confirm-remove"]');
    if (await confirmButton.isVisible()) {
      await confirmButton.click();
    }

    await this.waitForToast('success');

    // Verify item was removed
    if (initialCount === 1) {
      await expect(this.emptyCartMessage).toBeVisible();
    } else {
      await expect(this.cartItems).toHaveCount(initialCount - 1);
    }
  }

  /**
   * Remove item by name
   */
  async removeItemByName(name: string) {
    await this.getItemByName(name).locator('[data-testid="remove-item"]').click();
    await this.waitForToast('success');
  }

  /**
   * Get total price
   */
  async getTotalPrice(): Promise<number> {
    const text = await this.total.textContent();
    return parseFloat(text?.replace(/[^0-9.]/g, '') || '0');
  }

  /**
   * Proceed to checkout
   */
  async proceedToCheckout() {
    await this.checkoutButton.click();
    await this.page.waitForURL('**/checkout');
  }

  /**
   * Continue shopping
   */
  async continueShopping() {
    await this.continueShoppingButton.click();
    await this.page.waitForURL('**/products');
  }

  /**
   * Verify cart is empty
   */
  async verifyCartIsEmpty() {
    await expect(this.emptyCartMessage).toBeVisible();
    await expect(this.cartItems).toHaveCount(0);
  }

  /**
   * Apply coupon code
   */
  async applyCoupon(code: string) {
    await this.page.locator('[data-testid="coupon-input"]').fill(code);
    await this.page.locator('[data-testid="apply-coupon"]').click();
    await this.waitForToast('success');
  }

  /**
   * Verify discount applied
   */
  async verifyDiscountApplied(expectedDiscount: number) {
    const discount = this.page.locator('[data-testid="discount"]');
    await expect(discount).toBeVisible();
    const discountText = await discount.textContent();
    const discountAmount = parseFloat(discountText?.replace(/[^0-9.]/g, '') || '0');
    expect(discountAmount).toBe(expectedDiscount);
  }
}

import { Page, Locator, expect } from '@playwright/test';

export class CheckoutPage extends BasePage {

  async fillShippingInfo(info: ShippingInfo) {
    await this.page.locator('[name="firstName"]').fill(info.firstName);
    await this.page.locator('[name="lastName"]').fill(info.lastName);

  /**
   * Fill payment information
   */
  async fillPaymentInfo(info: PaymentInfo) {
    await this.page.locator('[name="cardNumber"]').fill(info.cardNumber);
    await this.page.locator('[name="cardName"]').fill(info.cardName);

  }

   * Place order
   */
  async placeOrder() {
    await this.placeOrderButton.click();
    await this.page.waitForURL('**/order-confirmation/**');

  async completeCheckout(shipping: ShippingInfo, payment: PaymentInfo) {
    await this.fillShippingInfo(shipping);
    await this.continueToPayment();
    await this.fillPaymentInfo(payment);

import { test, expect } from '@playwright/test';
import { ProductsPage } from '../../pages/ProductsPage';

test.describe('Product Listing', () => {
  let productsPage: ProductsPage;

  test.beforeEach(async ({ page }) => {
    productsPage = new ProductsPage(page);
    await productsPage.goto();
  });

  test('should display products', async () => {

    expect(count).toBeGreaterThan(0);
  });

  test('should add product to cart', async ({ page }) => {
    await productsPage.addToCart(0);

    expect(cartCount).toBe(1);
  });

    const productsPage = new ProductsPage(page);

    // Add product in product MFE
    await productsPage.goto();
    await productsPage.addToCart(0);

    const initialCount = await productsPage.getCartCount();
    expect(initialCount).toBe(1);

    // Open cart MFE in new tab

    const cartPage = new CartPage(cartTab);
    await cartPage.goto();

    // Verify cart has item
    const itemCount = await cartPage.getItemCount();
    expect(itemCount).toBe(1);

    // Remove item in cart MFE
    await cartPage.removeItem(0);

    // Verify count updated in product MFE
    await page.reload();
    const updatedCount = await productsPage.getCartCount();
    expect(updatedCount).toBe(0);

    await cartTab.close();
  });

  test('state persists across page reloads', async ({ page }) => {
    const productsPage = new ProductsPage(page);

    await productsPage.goto();
    await productsPage.addToCart(0);
    await productsPage.addToCart(1);

    // Reload page
    await page.reload();
    await productsPage.waitForPageLoad();

    // Verify cart count persisted
    const count = await productsPage.getCartCount();
    expect(count).toBe(2);
  });

Performance Testing​

e2e/tests/performance/metrics.spec.ts:

import { test, expect } from '@playwright/test';

test.describe('Performance Metrics', () => {
  test('measure page load time', async ({ page }) => {
    await page.goto('/products');

    const performanceMetrics = await page.evaluate(() => {
      const navigation = performance.getEntriesByType('navigation')[0] as PerformanceNavigationTiming;
      return {
        loadTime: navigation.loadEventEnd - navigation.fetchStart,
        domContentLoaded: navigation.domContentLoadedEventEnd - navigation.fetchStart,
        ttfb: navigation.responseStart - navigation.requestStart,
        domInteractive: navigation.domInteractive - navigation.fetchStart,
      };
    });

    console.log('Performance Metrics:', performanceMetrics);

    // Assert thresholds
    expect(performanceMetrics.loadTime).toBeLessThan(3000);
    expect(performanceMetrics.ttfb).toBeLessThan(600);
    expect(performanceMetrics.domInteractive).toBeLessThan(2000);
  });

  test('measure Core Web Vitals', async ({ page }) => {
    await page.goto('/products');

    // Wait for page to be interactive
    await page.waitForLoadState('networkidle');

    const webVitals = await page.evaluate(() => {
      return new Promise((resolve) => {
        const vitals: Record<string, number> = {};

        // Measure LCP
        new PerformanceObserver((list) => {
          const entries = list.getEntries();
          const lastEntry = entries[entries.length - 1];
          vitals.lcp = lastEntry.startTime;
        }).observe({ entryTypes: ['largest-contentful-paint'] });

        // Measure CLS
        new PerformanceObserver((list) => {
          let cls = 0;
          for (const entry of list.getEntries()) {
            if (!(entry as any).hadRecentInput) {
              cls += (entry as any).value;
            }
          }
          vitals.cls = cls;
        }).observe({ entryTypes: ['layout-shift'] });

        setTimeout(() => resolve(vitals), 3000);
      });
    });

    console.log('Web Vitals:', webVitals);

    // LCP should be under 2.5s (good)
    expect((webVitals as any).lcp).toBeLessThan(2500);

    // CLS should be under 0.1 (good)
    expect((webVitals as any).cls).toBeLessThan(0.1);
  });

  test('measure bundle size impact', async ({ page }) => {
    const resourceSizes: Record<string, number> = {};

    page.on('response', async (response) => {
      if (response.url().includes('.js') || response.url().includes('.css')) {
        const buffer = await response.body().catch(() => null);
        if (buffer) {
          resourceSizes[response.url()] = buffer.length;
        }
      }
    });

    await page.goto('/products');
    await page.waitForLoadState('networkidle');

    const totalSize = Object.values(resourceSizes).reduce((a, b) => a + b, 0);
    const totalSizeKB = totalSize / 1024;

    console.log(`Total bundle size: ${totalSizeKB.toFixed(2)} KB`);
    console.log('Resource breakdown:', resourceSizes);

    // Assert bundle size threshold
    expect(totalSizeKB).toBeLessThan(2000); // 2MB
  });
});

Global Setup​

e2e/global-setup.ts:

import { chromium, FullConfig } from '@playwright/test';
import path from 'path';

async function globalSetup(config: FullConfig) {
  const { baseURL, storageState } = config.projects[0].use;
  const browser = await chromium.launch();
  const page = await browser.newPage();

  // Perform authentication
  await page.goto(`${baseURL}/login`);
  await page.fill('[name="email"]', process.env.TEST_USER_EMAIL || 'test@example.com');
  await page.fill('[name="password"]', process.env.TEST_USER_PASSWORD || 'password123');
  await page.click('[data-testid="login-button"]');

  // Wait for redirect
  await page.waitForURL(`${baseURL}/`);

  // Save authentication state
  await page.context().storageState({
    path: (storageState as string) || 'playwright/.auth/user.json',
  });

  await browser.close();
}

export default globalSetup;

Best Practices​

1. Use Page Object Model​

  • Encapsulate page logic in page classes
  • Makes tests more maintainable
  • Reduces code duplication

2. Use Data Test IDs​

  • Prefer data-testid over CSS selectors
  • More stable and less brittle
  • Independent of styling changes

3. Parallel Test Execution​

  • Run tests in parallel for faster feedback
  • Use test.describe.configure({ mode: 'parallel' })
  • Be careful with shared state

4. API Mocking​

  • Mock external APIs for reliable tests
  • Control test data and scenarios
  • Faster test execution

5. Visual Regression Testing​

  • Catch unintended UI changes
  • Use screenshot comparison sparingly
  • Maintain screenshot baseline

6. Performance Monitoring​

  • Track page load times
  • Monitor Core Web Vitals
  • Set performance budgets

7. Clean Test Data​

  • Reset state between tests
  • Use beforeEach/afterEach hooks
  • Independent test execution

8. Error Handling​

  • Handle flaky tests appropriately
  • Use proper waits and timeouts
  • Retry failed tests in CI

9. Test Organization​

  • Group related tests
  • Use descriptive test names
  • Tag tests for selective execution

10. Documentation​

  • Document test scenarios
  • Explain complex test logic
  • Keep README updated

Troubleshooting​

Common Issues​

Tests are Flaky​

// Use proper waits
await page.waitForSelector('[data-testid="element"]', { state: 'visible' });
await page.waitForLoadState('networkidle');

// Increase timeout for slow operations
test.setTimeout(60000);

// Use auto-wait features
await page.click('[data-testid="button"]'); // Automatically waits

Element Not Found​

// Check if element exists
const exists = (await page.locator('[data-testid="element"]').count()) > 0;

// Wait for element
await page.waitForSelector('[data-testid="element"]', { timeout: 10000 });

// Use more specific selectors
await page.locator('[data-testid="product-card"]:has-text("Laptop")').click();

Timeout Errors​

// Increase timeout globally
test.setTimeout(60000);

// Or per action
await page.goto('/products', { timeout: 60000 });
await page.waitForSelector('[data-testid="element"]', { timeout: 10000 });
