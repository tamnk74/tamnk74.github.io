Frontend Performance Testing Guide

A comprehensive guide to measuring, monitoring, and optimizing frontend application performance with modern tools and techniques.

Why Performance Testing Matters​

Performance directly impacts:

  • 📈 User Experience: Faster sites lead to better engagement
  • 💰 Conversion Rates: 100ms delay = 1% drop in conversions
  • 🔍 SEO Rankings: Core Web Vitals are ranking factors
  • 💸 Revenue: Amazon found 100ms latency cost 1% in sales
  • 📱 Mobile Users: 53% abandon sites taking >3s to load

Performance Metrics Overview​

Core Web Vitals​

Google's essential metrics for user experience:

graph LR
    A[Core Web Vitals] --> B[LCP]
    A --> C[FID/INP]
    A --> D[CLS]

    B --> B1[Largest Contentful Paint]

    D --> D3[Target: <0.1]

Testing Tools​

1. Lighthouse​

Google's automated tool for performance, accessibility, and SEO.

Installation​

# Global installation
npm install -g lighthouse

# Or use Chrome DevTools (built-in)

Command Line Usage​

# Basic test
lighthouse https://example.com

# With specific options
lighthouse https://example.com \
  --only-categories=performance \
  --output=html \
  --output-path=./report.html \
  --view

# Mobile test
lighthouse https://example.com \
  --preset=mobile \
  --throttling.cpuSlowdownMultiplier=4

# Desktop test
lighthouse https://example.com \
  --preset=desktop \
  --screenEmulation.disabled

# Multiple runs for accuracy
lighthouse https://example.com \
  --only-categories=performance \
  --runs=5

Programmatic Usage​

scripts/lighthouse-test.js:

import lighthouse from 'lighthouse';
import * as chromeLauncher from 'chrome-launcher';
import fs from 'fs';

async function runLighthouse(url, options = {}) {
  const chrome = await chromeLauncher.launch({ chromeFlags: ['--headless'] });

  const opts = {
    logLevel: 'info',
    output: 'html',
    onlyCategories: ['performance'],
    port: chrome.port,
    ...options,
  };

  const runnerResult = await lighthouse(url, opts);

  // Extract performance metrics
  const { lhr } = runnerResult;
  const metrics = lhr.audits.metrics.details.items[0];

  const results = {
    url,
    timestamp: new Date().toISOString(),
    performance: lhr.categories.performance.score * 100,
    metrics: {
      FCP: metrics.firstContentfulPaint,
      LCP: metrics.largestContentfulPaint,
      TBT: metrics.totalBlockingTime,
      CLS: metrics.cumulativeLayoutShift,
      SI: metrics.speedIndex,
      TTI: metrics.interactive,
    },
    opportunities: lhr.audits,
  };

  // Save report
  fs.writeFileSync('lighthouse-report.html', runnerResult.report);
  fs.writeFileSync('lighthouse-results.json', JSON.stringify(results, null, 2));

  await chrome.kill();

  return results;
}

// Run test
const url = process.argv[2] || 'http://localhost:3000';
const results = await runLighthouse(url);

console.log('Performance Score:', results.performance);
console.log('Metrics:', results.metrics);

// Check if performance meets threshold
if (results.performance < 80) {
  console.error('❌ Performance score below threshold!');
  process.exit(1);
} else {
  console.log('✅ Performance score meets threshold!');
}

Using WebPageTest API​

import WebPageTest from 'webpagetest';
import fs from 'fs';

const wpt = new WebPageTest('www.webpagetest.org', process.env.WPT_API_KEY);

async function runTest(url, options = {}) {
  return new Promise((resolve, reject) => {
    const testOptions = {
      location: 'Dulles:Chrome',
      connectivity: '4G',
      runs: 3,
      video: true,
      lighthouse: true,
      ...options,
    };

    wpt.runTest(url, testOptions, (err, result) => {
      if (err) return reject(err);

      console.log('Test ID:', result.data.testId);
      console.log('Summary:', result.data.summary);

      // Poll for results
      wpt.getTestResults(result.data.testId, (err, data) => {
        if (err) return reject(err);
        resolve(data);
      });
    });
  });
}

async function analyzeResults(testId) {
  return new Promise((resolve, reject) => {
    wpt.getTestResults(testId, (err, data) => {
      if (err) return reject(err);

      const firstView = data.data.runs[1].firstView;

      const results = {
        url: data.data.url,
        testId: data.data.testId,
        summary: data.data.summary,
        metrics: {
          loadTime: firstView.loadTime,
          TTFB: firstView.TTFB,
          firstPaint: firstView.firstPaint,
          firstContentfulPaint: firstView.firstContentfulPaint,
          speedIndex: firstView.SpeedIndex,
          visualComplete: firstView.visualComplete,
          bytesIn: firstView.bytesIn,
          requests: firstView.requests,
        },
        lighthouse: data.data.lighthouse,
      };

      fs.writeFileSync('webpagetest-results.json', JSON.stringify(results, null, 2));
      resolve(results);
    });
  });
}

3. Custom Performance Monitoring​

Performance Observer API​

utils/performance-monitor.ts:

interface PerformanceMetrics {
  FCP?: number;
  LCP?: number;
  FID?: number;
  CLS?: number;
  TTFB?: number;
  navigationTiming?: PerformanceNavigationTiming;
}

class PerformanceMonitor {
  private metrics: PerformanceMetrics = {};
  private observers: PerformanceObserver[] = [];

  constructor() {
    this.observeFCP();
    this.observeLCP();
    this.observeFID();
    this.observeCLS();
    this.measureTTFB();
  }

  private observeFCP() {
    const observer = new PerformanceObserver((list) => {
      for (const entry of list.getEntries()) {
        if (entry.name === 'first-contentful-paint') {
          this.metrics.FCP = entry.startTime;
          console.log('FCP:', entry.startTime);
          this.sendMetric('FCP', entry.startTime);
        }
      }
    });
    observer.observe({ entryTypes: ['paint'] });
    this.observers.push(observer);
  }

  private observeLCP() {
    const observer = new PerformanceObserver((list) => {
      const entries = list.getEntries();
      const lastEntry = entries[entries.length - 1];
      this.metrics.LCP = lastEntry.startTime;
      console.log('LCP:', lastEntry.startTime);
      this.sendMetric('LCP', lastEntry.startTime);
    });
    observer.observe({ entryTypes: ['largest-contentful-paint'] });
    this.observers.push(observer);
  }

  private observeFID() {
    const observer = new PerformanceObserver((list) => {
      for (const entry of list.getEntries()) {
        const fidEntry = entry as PerformanceEventTiming;
        const fid = fidEntry.processingStart - fidEntry.startTime;
        this.metrics.FID = fid;
        console.log('FID:', fid);
        this.sendMetric('FID', fid);
      }
    });
    observer.observe({ entryTypes: ['first-input'] });
    this.observers.push(observer);
  }

  private observeCLS() {
    let clsValue = 0;
    const observer = new PerformanceObserver((list) => {
      for (const entry of list.getEntries()) {
        const layoutShift = entry as LayoutShift;
        if (!layoutShift.hadRecentInput) {
          clsValue += layoutShift.value;
          this.metrics.CLS = clsValue;
          console.log('CLS:', clsValue);
        }
      }
      this.sendMetric('CLS', clsValue);
    });
    observer.observe({ entryTypes: ['layout-shift'] });
    this.observers.push(observer);
  }

  private measureTTFB() {
    const navigation = performance.getEntriesByType('navigation')[0] as PerformanceNavigationTiming;

    if (navigation) {
      const ttfb = navigation.responseStart - navigation.requestStart;
      this.metrics.TTFB = ttfb;
      this.metrics.navigationTiming = navigation;
      console.log('TTFB:', ttfb);
      this.sendMetric('TTFB', ttfb);
    }
  }

  private sendMetric(name: string, value: number) {
    // Send to analytics service
    if (typeof navigator.sendBeacon === 'function') {
      const data = JSON.stringify({
        metric: name,
        value,
        url: window.location.href,
        userAgent: navigator.userAgent,
        timestamp: Date.now(),
      });

      navigator.sendBeacon('/api/metrics', data);
    }
  }

  getMetrics(): PerformanceMetrics {
    return { ...this.metrics };
  }

  getDetailedMetrics() {
    const navigation = performance.getEntriesByType('navigation')[0] as PerformanceNavigationTiming;

    return {
      ...this.metrics,
      navigationTiming: {
        dns: navigation.domainLookupEnd - navigation.domainLookupStart,
        tcp: navigation.connectEnd - navigation.connectStart,
        request: navigation.responseStart - navigation.requestStart,
        response: navigation.responseEnd - navigation.responseStart,
        domParsing: navigation.domInteractive - navigation.responseEnd,
        domContentLoaded: navigation.domContentLoadedEventEnd - navigation.domContentLoadedEventStart,
        loadComplete: navigation.loadEventEnd - navigation.loadEventStart,
        totalTime: navigation.loadEventEnd - navigation.fetchStart,
      },
      resources: this.getResourceMetrics(),
    };
  }

  private getResourceMetrics() {
    const resources = performance.getEntriesByType('resource');

    const grouped = resources.reduce((acc, resource) => {
      const entry = resource as PerformanceResourceTiming;
      const type = this.getResourceType(entry.name);

      if (!acc[type]) {
        acc[type] = { count: 0, size: 0, duration: 0 };
      }

      acc[type].count++;
      acc[type].size += entry.transferSize || 0;
      acc[type].duration += entry.duration;

      return acc;
    }, {} as Record<string, { count: number; size: number; duration: number }>);

    return grouped;
  }

  private getResourceType(url: string): string {
    if (url.includes('.js')) return 'script';
    if (url.includes('.css')) return 'stylesheet';
    if (url.match(/\.(jpg|jpeg|png|gif|webp|svg)/)) return 'image';
    if (url.match(/\.(woff|woff2|ttf|eot)/)) return 'font';
    return 'other';
  }

  disconnect() {
    this.observers.forEach((observer) => observer.disconnect());
  }
}

export default PerformanceMonitor;

Usage in Next.js App​

app/layout.tsx:

'use client';

import { useEffect } from 'react';
import PerformanceMonitor from '@/utils/performance-monitor';

export function PerformanceProvider({ children }: { children: React.ReactNode }) {
  useEffect(() => {
    const monitor = new PerformanceMonitor();

    // Report metrics after page load
    window.addEventListener('load', () => {
      setTimeout(() => {
        const metrics = monitor.getDetailedMetrics();
        console.log('Performance Metrics:', metrics);
      }, 0);
    });

    return () => {
      monitor.disconnect();
    };
  }, []);

  return <>{children}</>;
}

utils/web-vitals.ts:

import { onCLS, onFID, onFCP, onLCP, onTTFB, onINP, Metric } from 'web-vitals';

function sendToAnalytics(metric: Metric) {
  const body = JSON.stringify({
    name: metric.name,
    value: metric.value,
    rating: metric.rating,
    delta: metric.delta,
    id: metric.id,
    navigationType: metric.navigationType,
    url: window.location.href,
    userAgent: navigator.userAgent,
  });

  // Use `navigator.sendBeacon()` if available, falling back to `fetch()`
  if (navigator.sendBeacon) {
    navigator.sendBeacon('/api/analytics', body);
  } else {
    fetch('/api/analytics', {
      body,
      method: 'POST',
      keepalive: true,
      headers: {
        'Content-Type': 'application/json',
      },
    });
  }
}

export function reportWebVitals() {
  onCLS(sendToAnalytics);
  onFID(sendToAnalytics);
  onFCP(sendToAnalytics);
  onLCP(sendToAnalytics);
  onTTFB(sendToAnalytics);
  onINP(sendToAnalytics);
}

load-test.js:

import http from 'k6/http';
import { check, sleep } from 'k6';
import { Rate } from 'k6/metrics';

const errorRate = new Rate('errors');

export const options = {
  stages: [
    { duration: '1m', target: 50 }, // Ramp up to 50 users
    { duration: '3m', target: 50 }, // Stay at 50 users
    { duration: '1m', target: 100 }, // Ramp up to 100 users
    { duration: '3m', target: 100 }, // Stay at 100 users
    { duration: '1m', target: 0 }, // Ramp down
  ],
  thresholds: {
    http_req_duration: ['p(95)<500', 'p(99)<1000'],
    http_req_failed: ['rate<0.01'],
    errors: ['rate<0.1'],
  },
};

export default function () {
  // Homepage
  let res = http.get('http://localhost:3000/');
  check(res, {
    'homepage status is 200': (r) => r.status === 200,
    'homepage loads in <500ms': (r) => r.timings.duration < 500,
  }) || errorRate.add(1);

  sleep(1);

  // Products page
  res = http.get('http://localhost:3000/products');
  check(res, {
    'products status is 200': (r) => r.status === 200,
    'products loads in <1s': (r) => r.timings.duration < 1000,
  }) || errorRate.add(1);

  sleep(2);

  // API request
  res = http.post(
    'http://localhost:3000/api/cart',
    JSON.stringify({
      productId: Math.floor(Math.random() * 100) + 1,
      quantity: 1,
    }),
    {
      headers: { 'Content-Type': 'application/json' },
    },
  );
  check(res, {
    'cart API status is 200': (r) => r.status === 200,
    'cart API responds in <200ms': (r) => r.timings.duration < 200,
  }) || errorRate.add(1);

  sleep(1);
}

Performance Monitoring Dashboard​

scripts/performance-dashboard.js:

import express from 'express';
import fs from 'fs';
import path from 'path';

const app = express();
const port = 4000;

app.use(express.json());
app.use(express.static('public'));

// Store metrics
const metricsStore = [];

// Receive metrics
app.post('/api/metrics', (req, res) => {
  const metric = {
    ...req.body,
    timestamp: Date.now(),
  };

  metricsStore.push(metric);

  // Keep only last 1000 metrics
  if (metricsStore.length > 1000) {
    metricsStore.shift();
  }

  res.json({ success: true });
});

// Get metrics
app.get('/api/metrics', (req, res) => {
  const { metric, from, to } = req.query;

  let filtered = metricsStore;

  if (metric) {
    filtered = filtered.filter((m) => m.metric === metric);
  }

  if (from) {
    filtered = filtered.filter((m) => m.timestamp >= parseInt(from));
  }

  if (to) {
    filtered = filtered.filter((m) => m.timestamp <= parseInt(to));
  }

  res.json(filtered);
});

Best Practices​

1. Regular Testing​

  • Run performance tests on every deployment
  • Monitor trends over time
  • Set up alerts for regressions

2. Test on Real Devices​

  • Use actual mobile devices
  • Test on slow networks (3G, 4G)
  • Test on low-end devices

3. Set Performance Budgets​

  • Define acceptable thresholds
  • Block deployments that exceed budgets
  • Track metrics in CI/CD

4. Optimize Critical Path​

  • Minimize render-blocking resources
  • Defer non-critical JavaScript
  • Optimize CSS delivery

5. Image Optimization​

  • Use modern formats (WebP, AVIF)
  • Implement lazy loading
  • Serve responsive images

6. Code Splitting​

  • Split bundles by route
  • Lazy load components
  • Remove unused code

7. Caching Strategy​

  • Implement service workers
  • Use CDN for static assets
  • Set proper cache headers

8. Monitoring in Production​

  • Use Real User Monitoring (RUM)
  • Track error rates
  • Monitor API performance

Conclusion​

Performance testing is crucial for delivering fast, reliable web applications. By implementing:

✅ Automated performance testing in CI/CD ✅ Regular monitoring with Lighthouse and Web Vitals ✅ Load testing for scalability ✅ Bundle size analysis ✅ Performance budgets ✅ Real User Monitoring

You can ensure your frontend application delivers an excellent user experience.
