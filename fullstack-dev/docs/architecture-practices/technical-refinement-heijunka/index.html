Technical Refinement & Heijunka for Sprint Preparation

Technical refinement is the practice of completing all technical preparation for an upcoming sprint one sprint beforehand. Combined with Heijunka (leveled production), this approach ensures developers start each sprint with clear technical guidance, eliminating blockers and reducing cognitive overhead.

This guide provides a practical framework for implementing technical refinement in Next.js/NestJS projects on GCP with GitHub Actions automation.

1. Why Technical Refinement Matters​

Without Technical RefinementWith Technical Refinement
Developers spend sprint time debating architectureArchitecture decisions documented before sprint starts
Unclear requirements cause mid-sprint pivotsTechnical guidance document available on Day 1
Sprint planning overruns due to technical discussionsPlanning focuses on estimation and task breakdown
Knowledge silos form around complex featuresShared understanding through pre-written documentation
Unpredictable velocity and frequent carryoverConsistent delivery with leveled workload

2. The Heijunka Principle​

Heijunka (平準化) is a Lean manufacturing concept meaning "leveling." Applied to software development, it ensures:

  • Leveled Workload: Distribute complex and simple stories evenly across sprints
  • Reduced WIP: Technical refinement prevents work-in-progress pile-up
  • Predictable Flow: Meet defined "takt time" (cadence) for feature delivery
  • Pull System Efficiency: Developers pull pre-refined work into the sprint

Heijunka Benefits for Engineering Teams​

  1. Organize workflow to meet customer demand – Refinement aligns technical capacity with product priorities
  2. Reduce inventory costs – No overproduction of speculative designs
  3. Protect from overburden – Spikes in complexity are smoothed across sprints
  4. Meet takt time – Consistent sprint velocity through predictable work
  5. Optimal pull system – Developers pull refined, ready-to-build stories

5.1 Sprint Refinement Status Check​

# .github/workflows/refinement-status.yml
name: Sprint Refinement Status

on:
  schedule:
    # Run every Monday at 9 AM
    - cron: '0 9 * * 1'
  workflow_dispatch:

env:
  SLACK_WEBHOOK_URL: ${{ secrets.SLACK_WEBHOOK_URL }}

jobs:
  check-refinement-status:
    runs-on: ubuntu-latest

    steps:
      - uses: actions/checkout@v4

      - name: Get upcoming sprint info
        id: sprint
        run: |
          # Calculate upcoming sprint based on 2-week cycles
          CURRENT_DATE=$(date +%Y-%m-%d)
          # Logic to determine sprint number
          echo "sprint_name=Sprint $(date +%Y-%V)" >> $GITHUB_OUTPUT
          echo "sprint_start=$(date -d 'next monday' +%Y-%m-%d)" >> $GITHUB_OUTPUT

      - name: Check refinement completion
        id: check
        uses: actions/github-script@v7
        with:
          script: |
            const { data: issues } = await github.rest.issues.listForRepo({
              owner: context.repo.owner,
              repo: context.repo.repo,
              labels: 'technical-refinement',
              state: 'all'
            });

            const upcomingSprint = '${{ steps.sprint.outputs.sprint_name }}';
            const refinementIssues = issues.filter(i => 
              i.title.includes(upcomingSprint) || 
              i.body?.includes(upcomingSprint)
            );

            const completed = refinementIssues.filter(i => i.state === 'closed').length;
            const total = refinementIssues.length;
            const pending = total - completed;

            core.setOutput('completed', completed);
            core.setOutput('total', total);
            core.setOutput('pending', pending);
            core.setOutput('percentage', total > 0 ? Math.round(completed/total * 100) : 0);

      - name: Post status to Slack
        run: |
          EMOJI="✅"
          COLOR="good"

          if [ ${{ steps.check.outputs.percentage }} -lt 100 ]; then
            EMOJI="⚠️"
            COLOR="warning"
          fi

          if [ ${{ steps.check.outputs.percentage }} -lt 50 ]; then
            EMOJI="🚨"
            COLOR="danger"
          fi

          curl -X POST $SLACK_WEBHOOK_URL \
            -H 'Content-Type: application/json' \
            -d "{
              \"text\": \"$EMOJI Technical Refinement Status for ${{ steps.sprint.outputs.sprint_name }}\",
              \"attachments\": [{
                \"color\": \"$COLOR\",
                \"fields\": [
                  {\"title\": \"Completed\", \"value\": \"${{ steps.check.outputs.completed }}/${{ steps.check.outputs.total }}\", \"short\": true},
                  {\"title\": \"Progress\", \"value\": \"${{ steps.check.outputs.percentage }}%\", \"short\": true},
                  {\"title\": \"Sprint Starts\", \"value\": \"${{ steps.sprint.outputs.sprint_start }}\", \"short\": true},
                  {\"title\": \"Pending Items\", \"value\": \"${{ steps.check.outputs.pending }}\", \"short\": true}
                ]
              }]
            }"

      - name: Create reminder issues if behind
        if: steps.check.outputs.percentage < 80
        uses: actions/github-script@v7
        with:
          script: |
            const { data: issues } = await github.rest.issues.listForRepo({
              owner: context.repo.owner,
              repo: context.repo.repo,
              labels: 'technical-refinement',
              state: 'open'
            });

            for (const issue of issues) {
              await github.rest.issues.createComment({
                owner: context.repo.owner,
                repo: context.repo.repo,
                issue_number: issue.number,
                body: `⏰ **Refinement Reminder**\n\nSprint planning is approaching. Please complete this technical refinement by ${{ steps.sprint.outputs.sprint_start }}.\n\nCurrent overall progress: ${{ steps.check.outputs.percentage }}%`
              });
            }

export interface SprintRefinementStatus {
  sprintName: string;
  totalItems: number;
  completedItems: number;
  inProgressItems: number;
  pendingItems: number;
  blockedItems: number;
  completionPercentage: number;
  isOnTrack: boolean;

@Injectable()
export class RefinementService {
  private readonly logger = new Logger(RefinementService.name);

  constructor(private config: ConfigService) {}

  async getSprintRefinementStatus(sprintName: string): Promise<SprintRefinementStatus> {
    // Fetch from your project management tool (Jira, Linear, etc.)
    const items = await this.fetchRefinementItems(sprintName);

    const completed = items.filter((i) => i.status === 'completed').length;
    const inProgress = items.filter((i) => i.status === 'in-progress').length;
    const pending = items.filter((i) => i.status === 'pending').length;
    const blocked = items.filter((i) => i.status === 'blocked').length;

    const completionPercentage = items.length > 0 ? Math.round((completed / items.length) * 100) : 0;

    const sprintStart = this.calculateSprintStartDate(sprintName);
    const daysUntilSprintStart = Math.ceil((sprintStart.getTime() - Date.now()) / (1000 * 60 * 60 * 24));

    // Heijunka: On track if completion % matches timeline %
    const expectedCompletion = Math.min(
      100,
      Math.max(
        0,
        100 - (daysUntilSprintStart / 10) * 100, // 10-day refinement window
      ),
    );
    const isOnTrack = completionPercentage >= expectedCompletion - 10;

    return {
      sprintName,
      totalItems: items.length,
      completedItems: completed,
      inProgressItems: inProgress,
      pendingItems: pending,
      blockedItems: blocked,
      completionPercentage,
      isOnTrack,
      daysUntilSprintStart,
    };
  }

  async checkHeijunkaBalance(sprintName: string): Promise<{
    isBalanced: boolean;
    complexityDistribution: Record<string, number>;
    recommendation: string;
  }> {
    const items = await this.fetchRefinementItems(sprintName);

    const distribution = items.reduce((acc, item) => {
      acc[item.complexity] = (acc[item.complexity] || 0) + 1;
      return acc;
    }, {} as Record<string, number>);

    // Heijunka balance: no more than 20% XL items, at least 30% S/M items
    const total = items.length;
    const xlPercentage = ((distribution['XL'] || 0) / total) * 100;
    const smallMediumPercentage = (((distribution['S'] || 0) + (distribution['M'] || 0)) / total) * 100;

    const isBalanced = xlPercentage <= 20 && smallMediumPercentage >= 30;

    let recommendation = 'Sprint workload is well-balanced.';
    if (xlPercentage > 20) {
      recommendation = `Consider splitting XL items. Current XL: ${xlPercentage.toFixed(0)}% (target: ≤20%)`;
    } else if (smallMediumPercentage < 30) {
      recommendation = `Add more small wins. Current S+M: ${smallMediumPercentage.toFixed(0)}% (target: ≥30%)`;
    }

    return {
      isBalanced,
      complexityDistribution: distribution,
      recommendation,
    };

6.2 Refinement API Controller​

// src/sprint/sprint.controller.ts
import { Controller, Get, Param, Post, Body } from '@nestjs/common';
import { ApiTags, ApiOperation, ApiResponse } from '@nestjs/swagger';
import { RefinementService, SprintRefinementStatus } from './refinement.service';

@ApiTags('Sprint Refinement')
@Controller('api/refinement')
export class SprintController {
  constructor(private readonly refinementService: RefinementService) {}

  @Get('status/:sprintName')
  @ApiOperation({ summary: 'Get refinement status for a sprint' })
  @ApiResponse({ status: 200, description: 'Refinement status retrieved' })
  async getRefinementStatus(@Param('sprintName') sprintName: string): Promise<SprintRefinementStatus> {
    return this.refinementService.getSprintRefinementStatus(sprintName);
  }

  @Get('heijunka/:sprintName')
  @ApiOperation({ summary: 'Check Heijunka balance for sprint workload' })
  async checkHeijunkaBalance(@Param('sprintName') sprintName: string) {
    return this.refinementService.checkHeijunkaBalance(sprintName);
  }

  @Get('dashboard')
  @ApiOperation({ summary: 'Get refinement dashboard for current and next sprint' })
  async getDashboard() {
    const currentSprint = this.getCurrentSprintName();
    const nextSprint = this.getNextSprintName();

    const [currentStatus, nextStatus, heijunka] = await Promise.all([
      this.refinementService.getSprintRefinementStatus(currentSprint),
      this.refinementService.getSprintRefinementStatus(nextSprint),
      this.refinementService.checkHeijunkaBalance(nextSprint),
    ]);

    return {
      currentSprint: currentStatus,
      nextSprint: nextStatus,
      heijunkaBalance: heijunka,
      timestamp: new Date().toISOString(),
    };
  }

  private getCurrentSprintName(): string {
    const now = new Date();
    const weekNumber = this.getWeekNumber(now);
    return `Sprint ${now.getFullYear()}-${String(Math.ceil(weekNumber / 2)).padStart(2, '0')}`;
  }

  private getNextSprintName(): string {
    const now = new Date();
    const weekNumber = this.getWeekNumber(now);
    const nextSprintNumber = Math.ceil(weekNumber / 2) + 1;
    return `Sprint ${now.getFullYear()}-${String(nextSprintNumber).padStart(2, '0')}`;
  }

  private getWeekNumber(date: Date): number {
    const firstDayOfYear = new Date(date.getFullYear(), 0, 1);
    const pastDaysOfYear = (date.getTime() - firstDayOfYear.getTime()) / 86400000;
    return Math.ceil((pastDaysOfYear + firstDayOfYear.getDay() + 1) / 7);
  }
}

          <span className="text-gray-500">Blocked:</span>
          <span className="ml-2 font-medium text-red-600">{status.blockedItems}</span>
        </div>
      </div>

      {variant === 'next' && (
        <div className="mt-4 pt-4 border-t">
          <div className="flex items-center gap-2">
            <span className={status.isOnTrack ? 'text-green-600' : 'text-yellow-600'}>
              {status.isOnTrack ? '✓ On Track' : '⚠ Behind Schedule'}
            </span>
            <span className="text-gray-500">({status.daysUntilSprintStart} days until sprint)</span>
          </div>
        </div>
      )}
    </div>
  );
}

function RefinementTimeline({ daysUntilSprint }: { daysUntilSprint: number }) {
  const phases = [
    { name: 'Backlog Review', days: [1, 2], description: 'Review upcoming stories with PO' },
    { name: 'TGD Drafting', days: [3, 4, 5], description: 'Write technical guidance documents' },
    { name: 'Technical Review', days: [6, 7], description: 'Review with senior developers' },
    { name: 'Finalization', days: [8], description: 'Finalize and link to stories' },
    { name: 'Sprint Planning', days: [9, 10], description: 'Team planning with refined stories' },
  ];

  const currentDay = 10 - daysUntilSprint;

  return (
    <div className="relative">
      {phases.map((phase, index) => {
        const isActive = phase.days.includes(currentDay);
        const isComplete = phase.days[phase.days.length - 1] < currentDay;

        return (
          <div key={phase.name} className="flex items-start mb-4">
            <div
              className={`
              w-8 h-8 rounded-full flex items-center justify-center text-white text-sm
              ${isComplete ? 'bg-green-500' : isActive ? 'bg-blue-500' : 'bg-gray-300'}
            `}
            >
              {isComplete ? '✓' : index + 1}
            </div>
            <div className="ml-4">
              <h4 className={`font-medium ${isActive ? 'text-blue-600' : ''}`}>
                {phase.name}
                {isActive && <span className="ml-2 text-sm">(Current)</span>}
              </h4>
              <p className="text-sm text-gray-500">{phase.description}</p>
              <p className="text-xs text-gray-400">Days {phase.days.join('-')}</p>
            </div>
          </div>
        );
      })}
    </div>
  );
}

8.2 Cloud Function for Notifications​

// functions/refinement-notifier/src/index.ts
import { CloudFunction } from '@google-cloud/functions-framework';
import axios from 'axios';

interface NotificationPayload {
  action: 'daily_status' | 'deadline_warning' | 'blocked_items';
}

export const refinementNotifier: CloudFunction = async (req, res) => {
  const payload: NotificationPayload = req.body;

  try {
    switch (payload.action) {
      case 'daily_status':
        await sendDailyStatus();
        break;
      case 'deadline_warning':
        await sendDeadlineWarning();
        break;
      case 'blocked_items':
        await notifyBlockedItems();
        break;
    }

    res.status(200).send('Notification sent');
  } catch (error) {
    console.error('Notification failed:', error);
    res.status(500).send('Notification failed');
  }
};

async function sendDailyStatus() {
  const status = await fetchRefinementStatus();

  const blocks = [
    {
      type: 'header',
      text: {
        type: 'plain_text',
        text: `📋 Technical Refinement Status - ${status.sprintName}`,
      },
    },
    {
      type: 'section',
      fields: [
        { type: 'mrkdwn', text: `*Completed:*\n${status.completedItems}/${status.totalItems}` },
        { type: 'mrkdwn', text: `*Progress:*\n${status.completionPercentage}%` },
        { type: 'mrkdwn', text: `*Days Until Sprint:*\n${status.daysUntilSprintStart}` },
        { type: 'mrkdwn', text: `*Status:*\n${status.isOnTrack ? '✅ On Track' : '⚠️ Needs Attention'}` },
      ],
    },
  ];

  if (!status.isOnTrack) {
    blocks.push({
      type: 'section',
      text: {
        type: 'mrkdwn',
        text: `⚠️ *Action Required:* Refinement is behind schedule. ${status.pendingItems} items still pending.`,
      },
    });
  }

  await axios.post(process.env.SLACK_WEBHOOK_URL!, { blocks });
}

async function sendDeadlineWarning() {
  const status = await fetchRefinementStatus();

  if (status.completionPercentage < 80) {
    await axios.post(process.env.SLACK_WEBHOOK_URL!, {

    });

    // Also send email to architect
    await sendEmailAlert(status);
  }
}

9.2 BigQuery Analytics​

-- Refinement effectiveness analysis
SELECT
  sprint_name,
  COUNT(*) as total_stories,
  COUNTIF(had_tgd) as stories_with_tgd,
  COUNTIF(had_tgd) / COUNT(*) * 100 as tgd_coverage_pct,
  AVG(IF(had_tgd, story_points_delivered / story_points_estimated, NULL)) as tgd_delivery_ratio,
  AVG(IF(NOT had_tgd, story_points_delivered / story_points_estimated, NULL)) as no_tgd_delivery_ratio
FROM `project.dataset.sprint_stories`
WHERE sprint_end_date >= DATE_SUB(CURRENT_DATE(), INTERVAL 6 MONTH)
GROUP BY sprint_name
ORDER BY sprint_name DESC;

10. Best Practices Checklist​

For Architects​

  • Start refinement on Day 1 of the current sprint
  • Meet with PO/PPO within first 2 days to prioritize
  • Create TGD draft within 3-5 days
  • Include architecture diagrams (Mermaid/draw.io)
  • Define clear API contracts with TypeScript interfaces
  • Map acceptance criteria to implementation tasks
  • Review with senior developers before finalizing
  • Link TGD to user story before sprint planning

For Product Owners​

  • Provide prioritized backlog 2 sprints ahead
  • Participate in technical refinement sessions
  • Clarify acceptance criteria during refinement
  • Approve technical approach before sprint planning

For Development Teams​

  • Review TGDs before sprint planning
  • Raise technical concerns during refinement review
  • Provide feedback on TGD quality post-sprint
  • Flag missing guidance during development

By implementing this technical refinement process with Heijunka principles, teams achieve:

  • Predictable sprints with pre-refined, clearly documented work
  • Reduced blockers through proactive technical guidance
  • Better estimates based on understood complexity
  • Leveled workload that prevents team burnout and carryover
