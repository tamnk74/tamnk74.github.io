Technical Gaps Management

This guide provides a comprehensive framework for identifying, tracking, and reducing technical gaps in Next.js/NestJS applications deployed on GCP with GitHub Actions CI/CD pipelines.

Overview​

A technical gap is any technical issue identified and acknowledged by the Architect in the current application. Examples include anti-pattern code, performance issues, CI/CD pipelines not working appropriately, security vulnerabilities, or architectural inconsistencies.

The goal of technical gap management is to ensure that the number of gaps does not grow over time and that there is a clear, actionable plan to reduce technical debt systematically.

Knowledge Transfer (KT) Gaps for Distributed Systems​

For distributed systems (microservices, event-driven workflows, multi-team ownership), knowledge gaps are a first-class technical gap because they cause production risk and delivery delays.

Treat KT as a planned, tracked, and verifiable activity (same policy as code):

  • KT is planned when needed (project start, scope handover, new service/domain, new platform responsibility).
  • KT sessions are executed according to plan, and artifacts are recorded.
  • The team demonstrates no knowledge gaps in the covered areas (verification below).

Add this gap category to your register:

CategoryDescriptionExamplesDetection Method
Knowledge Transfer (KT)Missing/unclear operational or domain knowledge required to own a distributed system safelyService ownership unclear, no runbooks, unknown SLOs, unclear event contracts, unclear data ownershipOnboarding checklist, KT attendance + quiz, incident retros, runbook review

Typical KT topics for distributed systems:

  • Service ownership boundaries, on-call expectations, escalation paths
  • API/event contracts and versioning (backward compatibility)
  • Data ownership, migrations, consistency model (at-least-once delivery, idempotency)
  • Reliability: retries, timeouts, circuit breakers, bulkheads
  • Observability: tracing, logs, metrics, SLOs/error budgets, dashboards
  • GCP specifics: Cloud Run/GKE, Pub/Sub, Cloud SQL, Secret Manager, IAM, quotas

KT Planning Process (Agile-friendly)​

Trigger events (create a KT plan):

  • Team takes over an existing service/domain from another party
  • New platform capability is introduced (e.g., Pub/Sub, Cloud SQL HA, multi-region)
  • Major incident reveals knowledge gaps (repeat incidents, long MTTR)
  • Architectural change affecting many teams (contract changes, data model split, service extraction)

KT plan outputs (minimum):

  • Sessions list with owners, dates, attendees
  • Artifacts: recordings/slides, architecture diagrams, runbooks, “how to deploy/rollback” notes
  • Verification: short quiz or checklist signed off by tech lead/architect

KT plan template:

# Knowledge Transfer Plan — [Domain / Service]

## Context

- Why KT is needed (handover / new scope / incident learning)
- Scope (services, data stores, APIs/events)

## Sessions (timeboxed)

| Session | Topic                         | Owner          | Attendees | Date | Artifacts |
| ------- | ----------------------------- | -------------- | --------- | ---- | --------- |
| 1       | Service overview + boundaries | Outgoing owner | Team      |      | Link      |
| 2       | Deploy/rollback/on-call       | Platform       | Team      |      | Link      |
| 3       | Data ownership + migrations   | Data lead      | Team      |      | Link      |
| 4       | Observability + SLOs          | SRE/Lead       | Team      |      | Link      |

## Verification (no knowledge gaps)

- [ ] Runbook walk-through completed
- [ ] On-call “day in the life” shadowing completed
- [ ] Team can answer the quiz (or checklist) for covered topics
- [ ] Gaps found are logged as Technical Gaps with owners and due dates

Roadmap & Ownership Integration​

Because KT can impact delivery timelines, track it in the roadmap as explicit work:

  • Create an epic/task like KT: [Domain/Service] Handover and schedule it in the next sprint(s).
  • Link KT tasks to the impacted feature epics so delivery expectations reflect readiness.
  • Architect/tech leads must review KT completion before “ownership change” goes live.

Verification: “Team Has No Knowledge Gaps” (Practical Checks)​

Use lightweight, repeatable verification rather than assumptions:

  • Operational readiness: the team can deploy, rollback, and diagnose common failures.
  • Runbook coverage: P1/P2 alerts have runbooks and the team can use them.
  • Contract knowledge: team understands API/event versions and breaking-change rules.
  • Data readiness: team understands migrations/backfills and consistency model.
  • On-call readiness: primary and backup responders can triage incidents.

If any verification fails, log a KT gap as a technical gap with an owner and due date.

// Technical Gap Model
interface TechnicalGap {
  id: string;
  title: string;
  description: string;
  category: GapCategory;
  severity: SeverityLevel;
  impact: ImpactAssessment;
  effort: EffortEstimate;
  status: GapStatus;
  identifiedDate: Date;
  identifiedBy: string;
  assignee?: string;
  targetResolutionDate?: Date;
  actualResolutionDate?: Date;
  jiraTicket?: string;
  relatedFiles: string[];
  tags: string[];
}

type GapCategory =
  | 'code-quality'
  | 'performance'
  | 'security'
  | 'architecture'
  | 'infrastructure'
  | 'testing'
  | 'documentation';

type SeverityLevel = 'critical' | 'high' | 'medium' | 'low';

interface ImpactAssessment {
  userExperience: 1 | 2 | 3 | 4 | 5;
  maintainability: 1 | 2 | 3 | 4 | 5;
  scalability: 1 | 2 | 3 | 4 | 5;
  security: 1 | 2 | 3 | 4 | 5;
  overallScore: number; // Calculated average
}

type EffortEstimate = 'xs' | 's' | 'm' | 'l' | 'xl';

type GapStatus = 'identified' | 'assessed' | 'planned' | 'in-progress' | 'resolved' | 'accepted'; // Accepted = won't fix with documented reason

JQL Queries for Gap Management​

-- All open technical gaps
project = "PROJECT" AND type = "Technical Gap" AND status NOT IN (Resolved, Accepted)
ORDER BY "Technical Debt Score" DESC

-- Technical gaps by category
project = "PROJECT" AND type = "Technical Gap" AND "Gap Category" = "Performance"
AND status NOT IN (Resolved, Accepted)

-- High severity gaps needing immediate attention
project = "PROJECT" AND type = "Technical Gap" AND Severity IN (Critical, High)
AND status NOT IN (Resolved, Accepted)

-- Gaps created in last 30 days (tracking new debt)
project = "PROJECT" AND type = "Technical Gap" AND created >= -30d

-- Gaps resolved in last 30 days
project = "PROJECT" AND type = "Technical Gap" AND resolved >= -30d

-- Technical debt trend (gaps created vs resolved)
-- Use JIRA dashboard gadgets for visualization

-- Gaps by component

AND "Affected Components" = "Backend (NestJS)"

GitHub Actions for Gap Detection​

Automated Code Quality Scanning​

# .github/workflows/technical-gap-detection.yml
name: Technical Gap Detection

on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main, develop]
  schedule:
    # Weekly full scan
    - cron: '0 2 * * 1'

env:
  NODE_VERSION: '20'
  SONAR_HOST_URL: ${{ secrets.SONAR_HOST_URL }}
  SONAR_TOKEN: ${{ secrets.SONAR_TOKEN }}

jobs:
  code-quality-scan:
    name: Code Quality Analysis
    runs-on: ubuntu-latest
    outputs:
      new_issues: ${{ steps.analyze.outputs.new_issues }}
      quality_gate: ${{ steps.analyze.outputs.quality_gate }}
    steps:
      - name: Checkout Repository
        uses: actions/checkout@v4
        with:
          fetch-depth: 0 # Full history for better analysis

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: ${{ env.NODE_VERSION }}
          cache: 'pnpm'

      - name: Install Dependencies
        run: pnpm install --frozen-lockfile

      - name: Run ESLint with Report
        id: eslint
        continue-on-error: true
        run: |
          pnpm eslint . --format json --output-file eslint-report.json || true

          # Count issues by severity
          node << 'EOF'
          const fs = require('fs');
          const report = JSON.parse(fs.readFileSync('eslint-report.json', 'utf8'));

          let errors = 0, warnings = 0;
          report.forEach(file => {
            file.messages.forEach(msg => {
              if (msg.severity === 2) errors++;
              else warnings++;
            });
          });

          console.log(`ESLint: ${errors} errors, ${warnings} warnings`);
          fs.writeFileSync('eslint-summary.json', JSON.stringify({ errors, warnings }));
          EOF

      - name: Run TypeScript Strict Check
        id: typescript
        continue-on-error: true
        run: |
          pnpm tsc --noEmit --strict 2>&1 | tee typescript-report.txt || true

          # Count TypeScript errors
          ERROR_COUNT=$(grep -c "error TS" typescript-report.txt || echo "0")
          echo "typescript_errors=$ERROR_COUNT" >> $GITHUB_OUTPUT

      - name: SonarQube Analysis
        uses: SonarSource/sonarqube-scan-action@master
        env:
          SONAR_TOKEN: ${{ secrets.SONAR_TOKEN }}
          SONAR_HOST_URL: ${{ secrets.SONAR_HOST_URL }}

      - name: Check Quality Gate
        id: analyze
        uses: SonarSource/sonarqube-quality-gate-action@master
        timeout-minutes: 5
        env:
          SONAR_TOKEN: ${{ secrets.SONAR_TOKEN }}

      - name: Upload Analysis Reports
        uses: actions/upload-artifact@v4
        with:
          name: code-quality-reports
          path: |
            eslint-report.json
            eslint-summary.json
            typescript-report.txt

  dependency-analysis:
    name: Dependency Gap Analysis
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Repository
        uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: ${{ env.NODE_VERSION }}
          cache: 'pnpm'

      - name: Install Dependencies
        run: pnpm install --frozen-lockfile

      - name: Check for Outdated Dependencies
        id: outdated
        run: |
          pnpm outdated --format json > outdated-deps.json || true

          node << 'EOF'
          const fs = require('fs');
          let outdated = {};
          try {
            outdated = JSON.parse(fs.readFileSync('outdated-deps.json', 'utf8'));
          } catch (e) {
            outdated = {};
          }

          const summary = {
            total: Object.keys(outdated).length,
            major: 0,
            minor: 0,
            patch: 0
          };

          Object.entries(outdated).forEach(([pkg, info]) => {
            const current = info.current?.split('.') || [];
            const latest = info.latest?.split('.') || [];
            
            if (current[0] !== latest[0]) summary.major++;
            else if (current[1] !== latest[1]) summary.minor++;
            else summary.patch++;
          });

          console.log(`Outdated: ${summary.major} major, ${summary.minor} minor, ${summary.patch} patch`);
          fs.writeFileSync('outdated-summary.json', JSON.stringify(summary));
          EOF

      - name: Security Audit
        id: audit
        run: |
          pnpm audit --json > audit-report.json || true

          node << 'EOF'
          const fs = require('fs');
          let audit = {};
          try {
            audit = JSON.parse(fs.readFileSync('audit-report.json', 'utf8'));
          } catch (e) {
            audit = { metadata: { vulnerabilities: {} } };
          }

          const vulns = audit.metadata?.vulnerabilities || {};
          const summary = {
            critical: vulns.critical || 0,
            high: vulns.high || 0,
            moderate: vulns.moderate || 0,
            low: vulns.low || 0,
            total: (vulns.critical || 0) + (vulns.high || 0) + (vulns.moderate || 0) + (vulns.low || 0)
          };

          console.log(`Vulnerabilities: ${summary.critical} critical, ${summary.high} high, ${summary.moderate} moderate`);
          fs.writeFileSync('audit-summary.json', JSON.stringify(summary));
          EOF

      - name: Upload Dependency Reports
        uses: actions/upload-artifact@v4
        with:
          name: dependency-reports
          path: |
            outdated-deps.json
            outdated-summary.json
            audit-report.json
            audit-summary.json

  test-coverage-analysis:
    name: Test Coverage Gap Analysis
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Repository
        uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: ${{ env.NODE_VERSION }}
          cache: 'pnpm'

      - name: Install Dependencies
        run: pnpm install --frozen-lockfile

      - name: Run Tests with Coverage
        run: |
          pnpm test:cov --json --outputFile=test-results.json || true

      - name: Analyze Coverage Gaps
        run: |
          node << 'EOF'
          const fs = require('fs');

          // Read coverage summary
          const coveragePath = 'coverage/coverage-summary.json';
          if (!fs.existsSync(coveragePath)) {
            console.log('No coverage report found');
            process.exit(0);
          }

          const coverage = JSON.parse(fs.readFileSync(coveragePath, 'utf8'));
          const total = coverage.total;

          const gaps = {
            statements: {
              covered: total.statements.pct,
              threshold: 80,
              gap: Math.max(0, 80 - total.statements.pct)
            },
            branches: {
              covered: total.branches.pct,
              threshold: 70,
              gap: Math.max(0, 70 - total.branches.pct)
            },
            functions: {
              covered: total.functions.pct,
              threshold: 80,
              gap: Math.max(0, 80 - total.functions.pct)
            },
            lines: {
              covered: total.lines.pct,
              threshold: 80,
              gap: Math.max(0, 80 - total.lines.pct)
            }
          };

          // Find uncovered files
          const uncoveredFiles = [];
          Object.entries(coverage).forEach(([file, data]) => {
            if (file === 'total') return;
            if (data.statements.pct < 50) {
              uncoveredFiles.push({
                file,
                coverage: data.statements.pct
              });
            }
          });

          const report = {
            summary: gaps,
            uncoveredFiles: uncoveredFiles.slice(0, 20), // Top 20 worst
            timestamp: new Date().toISOString()
          };

          fs.writeFileSync('coverage-gaps.json', JSON.stringify(report, null, 2));
          console.log('Coverage gaps:', JSON.stringify(gaps, null, 2));
          EOF

      - name: Upload Coverage Reports
        uses: actions/upload-artifact@v4
        with:
          name: coverage-reports
          path: |
            coverage/
            coverage-gaps.json

  architecture-analysis:
    name: Architecture Gap Analysis
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Repository
        uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: ${{ env.NODE_VERSION }}
          cache: 'pnpm'

      - name: Install Dependencies
        run: pnpm install --frozen-lockfile

      - name: Check Circular Dependencies
        run: |
          npx madge --circular --extensions ts,tsx src/ > circular-deps.txt 2>&1 || true

          # Count circular dependencies
          CIRCULAR_COUNT=$(grep -c "Circular" circular-deps.txt || echo "0")
          echo "Found $CIRCULAR_COUNT circular dependency chains"
          echo "circular_deps=$CIRCULAR_COUNT" >> $GITHUB_ENV

      - name: Analyze Module Complexity
        run: |
          # Using custom script to analyze NestJS module structure
          node << 'EOF'
          const fs = require('fs');
          const path = require('path');
          const glob = require('glob');

          const moduleFiles = glob.sync('src/**/*.module.ts');
          const analysis = {
            totalModules: moduleFiles.length,
            largeModules: [], // Modules with too many providers
            missingExports: [], // Modules not exporting services properly
          };

          moduleFiles.forEach(file => {
            const content = fs.readFileSync(file, 'utf8');
            
            // Count providers
            const providersMatch = content.match(/providers:\s*\[([^\]]*)\]/s);
            if (providersMatch) {
              const providers = providersMatch[1].split(',').filter(p => p.trim()).length;
              if (providers > 10) {
                analysis.largeModules.push({ file, providers });
              }
            }
          });

          fs.writeFileSync('architecture-analysis.json', JSON.stringify(analysis, null, 2));
          console.log('Architecture analysis:', JSON.stringify(analysis, null, 2));
          EOF

      - name: Upload Architecture Reports
        uses: actions/upload-artifact@v4
        with:
          name: architecture-reports
          path: |
            circular-deps.txt
            architecture-analysis.json

  generate-gap-report:
    name: Generate Technical Gap Report
    runs-on: ubuntu-latest
    needs: [code-quality-scan, dependency-analysis, test-coverage-analysis, architecture-analysis]
    if: always()
    steps:
      - name: Download All Reports
        uses: actions/download-artifact@v4

      - name: Generate Consolidated Report
        id: report
        run: |
          node << 'EOF'
          const fs = require('fs');

          const readJsonSafe = (path) => {
            try {
              return JSON.parse(fs.readFileSync(path, 'utf8'));
            } catch (e) {
              return null;
            }
          };

          const report = {
            timestamp: new Date().toISOString(),
            codeQuality: {
              eslint: readJsonSafe('code-quality-reports/eslint-summary.json'),
            },
            dependencies: {
              outdated: readJsonSafe('dependency-reports/outdated-summary.json'),
              vulnerabilities: readJsonSafe('dependency-reports/audit-summary.json'),
            },
            coverage: readJsonSafe('coverage-reports/coverage-gaps.json'),
            architecture: readJsonSafe('architecture-reports/architecture-analysis.json'),
          };

          // Calculate overall technical debt score
          let debtScore = 0;

          if (report.codeQuality.eslint) {
            debtScore += report.codeQuality.eslint.errors * 2;
            debtScore += report.codeQuality.eslint.warnings * 0.5;
          }

          if (report.dependencies.vulnerabilities) {
            debtScore += report.dependencies.vulnerabilities.critical * 10;
            debtScore += report.dependencies.vulnerabilities.high * 5;
            debtScore += report.dependencies.vulnerabilities.moderate * 2;
          }

          if (report.dependencies.outdated) {
            debtScore += report.dependencies.outdated.major * 3;
            debtScore += report.dependencies.outdated.minor * 1;
          }

          if (report.coverage?.summary) {
            Object.values(report.coverage.summary).forEach(g => {
              if (typeof g === 'object' && g.gap) {
                debtScore += g.gap * 0.5;
              }
            });
          }

          report.overallDebtScore = Math.round(debtScore);

          fs.writeFileSync('technical-gap-report.json', JSON.stringify(report, null, 2));

          // Generate markdown report
          let md = `# Technical Gap Report\n\n`;
          md += `**Generated:** ${report.timestamp}\n`;
          md += `**Overall Debt Score:** ${report.overallDebtScore}\n\n`;

          md += `## Code Quality\n`;
          if (report.codeQuality.eslint) {
            md += `- ESLint Errors: ${report.codeQuality.eslint.errors}\n`;
            md += `- ESLint Warnings: ${report.codeQuality.eslint.warnings}\n`;
          }

          md += `\n## Dependencies\n`;
          if (report.dependencies.outdated) {
            md += `- Major Updates Available: ${report.dependencies.outdated.major}\n`;
            md += `- Minor Updates Available: ${report.dependencies.outdated.minor}\n`;
          }
          if (report.dependencies.vulnerabilities) {
            md += `- Critical Vulnerabilities: ${report.dependencies.vulnerabilities.critical}\n`;
            md += `- High Vulnerabilities: ${report.dependencies.vulnerabilities.high}\n`;
          }

          md += `\n## Test Coverage Gaps\n`;
          if (report.coverage?.summary) {
            Object.entries(report.coverage.summary).forEach(([key, val]) => {
              if (typeof val === 'object') {
                md += `- ${key}: ${val.covered.toFixed(1)}% (gap: ${val.gap.toFixed(1)}%)\n`;
              }
            });
          }

          fs.writeFileSync('technical-gap-report.md', md);
          console.log(md);

          // Set outputs for creating issues
          const hasGaps = report.overallDebtScore > 50;
          fs.appendFileSync(process.env.GITHUB_OUTPUT, `has_gaps=${hasGaps}\n`);
          fs.appendFileSync(process.env.GITHUB_OUTPUT, `debt_score=${report.overallDebtScore}\n`);
          EOF

      - name: Upload Consolidated Report
        uses: actions/upload-artifact@v4
        with:
          name: technical-gap-report
          path: |
            technical-gap-report.json
            technical-gap-report.md

      - name: Create JIRA Ticket for New Gaps
        if: steps.report.outputs.has_gaps == 'true' && github.event_name == 'schedule'
        env:
          JIRA_BASE_URL: ${{ secrets.JIRA_BASE_URL }}
          JIRA_USER: ${{ secrets.JIRA_USER }}
          JIRA_API_TOKEN: ${{ secrets.JIRA_API_TOKEN }}
        run: |

interface DetectedGap {
  category: string;
  title: string;

  severity: 'critical' | 'high' | 'medium' | 'low';
  affectedArea: string;
  detectedAt: Date;

@Injectable()
export class GapDetectorService implements OnModuleInit {
  private readonly logger = new Logger(GapDetectorService.name);
  private detectedGaps: DetectedGap[] = [];

  constructor(private readonly configService: ConfigService) {}

  async onModuleInit(): Promise<void> {
    this.logger.log('Gap detector service initialized');
  }

  @Cron(CronExpression.EVERY_HOUR)
  async runDetection(): Promise<void> {
    this.logger.log('Running technical gap detection...');

    const gaps: DetectedGap[] = [];

    // Detect performance gaps
    gaps.push(...(await this.detectPerformanceGaps()));

    // Detect memory leaks
    gaps.push(...(await this.detectMemoryGaps()));

    // Detect API response time issues
    gaps.push(...(await this.detectApiGaps()));

    // Detect database query issues
    gaps.push(...(await this.detectDatabaseGaps()));

    this.detectedGaps = gaps;
    this.logger.log(`Detected ${gaps.length} technical gaps`);
  }

  private async detectPerformanceGaps(): Promise<DetectedGap[]> {
    const gaps: DetectedGap[] = [];

    // Check event loop lag
    const eventLoopLag = await this.measureEventLoopLag();
    if (eventLoopLag > 100) {
      gaps.push({
        category: 'performance',
        title: 'High Event Loop Lag',
        description: `Event loop lag is ${eventLoopLag}ms, which may indicate blocking operations`,
        severity: eventLoopLag > 500 ? 'high' : 'medium',
        affectedArea: 'Node.js Runtime',
        detectedAt: new Date(),
        metadata: { eventLoopLag },
      });
    }

    return gaps;
  }

  private async detectMemoryGaps(): Promise<DetectedGap[]> {
    const gaps: DetectedGap[] = [];

    const memoryUsage = process.memoryUsage();
    const heapUsedMB = memoryUsage.heapUsed / 1024 / 1024;
    const heapTotalMB = memoryUsage.heapTotal / 1024 / 1024;
    const heapUsagePercent = (heapUsedMB / heapTotalMB) * 100;

    if (heapUsagePercent > 85) {
      gaps.push({
        category: 'performance',
        title: 'High Memory Usage',
        description: `Heap usage is at ${heapUsagePercent.toFixed(1)}% (${heapUsedMB.toFixed(1)}MB used)`,
        severity: heapUsagePercent > 95 ? 'critical' : 'high',
        affectedArea: 'Memory Management',
        detectedAt: new Date(),
        metadata: { heapUsedMB, heapTotalMB, heapUsagePercent },
      });
    }

    return gaps;
  }

  private async detectApiGaps(): Promise<DetectedGap[]> {
    const gaps: DetectedGap[] = [];

    // This would typically query from metrics storage
    // For demonstration, checking a hypothetical metrics endpoint
    const slowEndpoints = await this.getSlowEndpoints();

    slowEndpoints.forEach((endpoint) => {
      if (endpoint.avgResponseTime > 1000) {
        gaps.push({
          category: 'performance',
          title: `Slow API Endpoint: ${endpoint.path}`,
          description: `Average response time is ${endpoint.avgResponseTime}ms`,
          severity: endpoint.avgResponseTime > 3000 ? 'high' : 'medium',
          affectedArea: 'API Performance',
          detectedAt: new Date(),
          metadata: endpoint,
        });
      }
    });

    return gaps;
  }

  private async detectDatabaseGaps(): Promise<DetectedGap[]> {
    const gaps: DetectedGap[] = [];

    // Check for N+1 query patterns, slow queries, etc.
    const slowQueries = await this.getSlowQueries();

    slowQueries.forEach((query) => {
      if (query.avgDuration > 500) {

          affectedArea: 'Database',

          metadata: {
            queryPattern: query.pattern,
            avgDuration: query.avgDuration,
            callCount: query.callCount,
          },
        });
      }
    });

    return gaps;
  }

// src/technical-gaps/gap-reporter.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { Cron, CronExpression } from '@nestjs/schedule';
import { ConfigService } from '@nestjs/config';
import { PubSub } from '@google-cloud/pubsub';
import { GapDetectorService } from './gap-detector.service';

interface GapReport {
  timestamp: Date;
  environment: string;
  totalGaps: number;
  gapsByCategory: Record<string, number>;
  gapsBySeverity: Record<string, number>;
  trendDirection: 'increasing' | 'stable' | 'decreasing';
  details: any[];
}

@Injectable()
export class GapReporterService {
  private readonly logger = new Logger(GapReporterService.name);
  private readonly pubsub: PubSub;
  private readonly topicName: string;
  private previousGapCount = 0;

  constructor(private readonly configService: ConfigService, private readonly gapDetectorService: GapDetectorService) {
    this.pubsub = new PubSub({
      projectId: this.configService.get('GCP_PROJECT_ID'),
    });
    this.topicName = this.configService.get('GAP_REPORTS_TOPIC', 'technical-gap-reports');
  }

  @Cron(CronExpression.EVERY_DAY_AT_6AM)
  async generateDailyReport(): Promise<void> {
    this.logger.log('Generating daily technical gap report...');

    const gaps = this.gapDetectorService.getDetectedGaps();

    const report: GapReport = {
      timestamp: new Date(),
      environment: this.configService.get('NODE_ENV', 'development'),
      totalGaps: gaps.length,
      gapsByCategory: this.groupByCategory(gaps),
      gapsBySeverity: this.groupBySeverity(gaps),
      trendDirection: this.calculateTrend(gaps.length),
      details: gaps,
    };

    // Store previous count for trend calculation
    this.previousGapCount = gaps.length;

    // Publish report to Pub/Sub for processing
    await this.publishReport(report);

    this.logger.log(`Daily report generated: ${gaps.length} gaps found`);
  }

  private groupByCategory(gaps: any[]): Record<string, number> {
    return gaps.reduce((acc, gap) => {
      acc[gap.category] = (acc[gap.category] || 0) + 1;
      return acc;
    }, {});
  }

  private groupBySeverity(gaps: any[]): Record<string, number> {
    return gaps.reduce((acc, gap) => {
      acc[gap.severity] = (acc[gap.severity] || 0) + 1;
      return acc;
    }, {});
  }

  private calculateTrend(currentCount: number): 'increasing' | 'stable' | 'decreasing' {
    if (currentCount > this.previousGapCount * 1.1) return 'increasing';
    if (currentCount < this.previousGapCount * 0.9) return 'decreasing';
    return 'stable';
  }

  private async publishReport(report: GapReport): Promise<void> {
    try {
      const topic = this.pubsub.topic(this.topicName);
      await topic.publishMessage({
        data: Buffer.from(JSON.stringify(report)),
        attributes: {
          environment: report.environment,
          totalGaps: report.totalGaps.toString(),
          trend: report.trendDirection,
        },
      });
      this.logger.log('Report published to Pub/Sub');
    } catch (error) {
      this.logger.error(`Failed to publish report: ${error.message}`);
    }
  }
}

API Route for Gap Summary​

// src/app/api/admin/technical-gaps/summary/route.ts
import { NextRequest, NextResponse } from 'next/server';
import { BigQuery } from '@google-cloud/bigquery';

const bigquery = new BigQuery({
  projectId: process.env.GCP_PROJECT_ID,
});

export async function GET(request: NextRequest): Promise<NextResponse> {
  try {
    // Fetch current gap summary
    const [currentGaps] = await bigquery.query({
      query: `
        SELECT 
          category,
          severity,
          COUNT(*) as count
        FROM \`${process.env.GCP_PROJECT_ID}.technical_debt.gaps\`
        WHERE status NOT IN ('resolved', 'accepted')
        GROUP BY category, severity
      `,
    });

    // Fetch historical trend
    const [history] = await bigquery.query({
      query: `
        SELECT 
          DATE(scan_date) as date,
          total_gaps as count,
          debt_score as score
        FROM \`${process.env.GCP_PROJECT_ID}.technical_debt.daily_summary\`
        WHERE scan_date >= DATE_SUB(CURRENT_DATE(), INTERVAL 90 DAY)
        ORDER BY scan_date
      `,
    });

    // Calculate totals
    const byCategory: Record<string, number> = {};
    const bySeverity: Record<string, number> = {};
    let totalGaps = 0;

    currentGaps.forEach((row: any) => {
      byCategory[row.category] = (byCategory[row.category] || 0) + row.count;
      bySeverity[row.severity] = (bySeverity[row.severity] || 0) + row.count;
      totalGaps += row.count;
    });

    // Calculate trend
    const historyArray = history as Array<{ date: string; count: number; score: number }>;
    const latestCount = historyArray.length > 0 ? historyArray[historyArray.length - 1].count : 0;
    const weekAgoCount = historyArray.length > 7 ? historyArray[historyArray.length - 8].count : latestCount;

    const percentChange = weekAgoCount > 0 ? ((latestCount - weekAgoCount) / weekAgoCount) * 100 : 0;

    const trend = {
      direction: percentChange > 5 ? 'increasing' : percentChange < -5 ? 'decreasing' : 'stable',
      percentChange,
    };

    return NextResponse.json({
      totalGaps,
      byCategory,
      bySeverity,
      trend,
      history: historyArray.map((h) => ({
        date: h.date,
        count: h.count,
        score: h.score,
      })),
    });
  } catch (error) {
    console.error('Failed to fetch gap summary:', error);
    return NextResponse.json({ error: 'Failed to fetch gap summary' }, { status: 500 });
  }
}
