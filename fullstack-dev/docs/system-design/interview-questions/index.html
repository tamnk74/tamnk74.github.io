🎯 System Design Interview Questions

A comprehensive collection of 100+ system design interview questions commonly asked at FAANG and top tech companies.

📝 How to Use This Guide​

  1. Start with easy problems to build confidence
  2. Time yourself (45-60 minutes per problem)
  3. Draw diagrams to visualize your solution
  4. Consider trade-offs for every decision
  5. Practice explaining your thought process

🌟 Most Popular System Design Problems​

These are the most frequently asked questions across all companies:

1. Design URL Shortener (TinyURL, Bit.ly)​

Difficulty: Easy ⭐
Companies: Amazon, Google, Microsoft, Uber

Key Concepts:

  • Hashing algorithms (MD5, Base62)
  • Database design
  • Redirect mechanisms
  • Analytics tracking

Focus Areas:

  • How to generate short URLs
  • Hash collision handling
  • Custom aliases support
  • Analytics and click tracking

2. Design Twitter / X​

Difficulty: Medium ⭐⭐
Companies: Twitter, Meta, Google, Amazon

Key Concepts:

  • Timeline generation (fan-out on write vs read)
  • Tweet storage and retrieval
  • Following/follower relationships
  • Real-time updates

Focus Areas:

  • Home timeline vs user timeline
  • Handling celebrity accounts (millions of followers)
  • Trending topics algorithm
  • Media storage (images, videos)

3. Design Instagram​

Difficulty: Medium ⭐⭐
Companies: Meta, Google, Amazon

Key Concepts:

  • Photo/video upload and storage
  • News feed generation
  • Social graph
  • CDN for media delivery

Focus Areas:

  • Image processing and thumbnails
  • Feed ranking algorithm
  • Stories feature
  • Explore page recommendations

4. Design WhatsApp / Messaging System​

Difficulty: Medium ⭐⭐⭐
Companies: Meta, Google, Amazon, Microsoft

Key Concepts:

  • Real-time messaging
  • Message delivery guarantees
  • End-to-end encryption
  • Online/offline status

Focus Areas:

  • WebSocket connections
  • Message queue design
  • Group messaging
  • Message persistence
  • Push notifications

5. Design YouTube / Video Streaming​

Difficulty: Hard ⭐⭐⭐
Companies: Google, Netflix, Amazon, Meta

Key Concepts:

  • Video upload and processing
  • Adaptive bitrate streaming
  • CDN architecture
  • Recommendation system

Focus Areas:

  • Video transcoding pipeline
  • Storage optimization
  • View count system
  • Comment and like features
  • Live streaming

📖 How to Approach Each Problem​

Framework to Follow​

1. Clarify Requirements (5 min)

  • Functional requirements
  • Non-functional requirements (scale, performance)
  • Out of scope

2. High-Level Design (10 min)

  • Draw major components
  • Explain data flow
  • Identify APIs

3. Deep Dive (30 min)

  • Database schema
  • Scaling strategies
  • Trade-offs
  • Edge cases

4. Discussion (10 min)

  • Bottlenecks
  • Monitoring
  • Security
  • Future improvements

📊 Common Patterns​

Master these patterns to solve most problems:

  1. Read-Heavy vs Write-Heavy

    • Different caching strategies
    • Different database choices

  2. Real-Time vs Batch Processing

    • Stream vs batch
    • Latency requirements

  3. Strong vs Eventual Consistency

    • CAP theorem trade-offs
    • Use case dependent

  4. SQL vs NoSQL

    • Schema requirements
    • Query patterns
    • Scalability needs

  5. Synchronous vs Asynchronous

    • Message queues
    • Event-driven architecture
