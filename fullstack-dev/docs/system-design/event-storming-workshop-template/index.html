Phase 1 — Unstructured Exploration​

Goal: Get all domain events out of people's heads onto the wall.

Rules:

  • Write one event per sticky note in past tense
  • No filtering, no ordering — just dump everything
  • Flag confusion or disagreement with a 🔴 red hotspot

Phase 2 — Enforce the Timeline​

Goal: Arrange events in rough chronological order (left → right).

Checklist:

  • Events are ordered from earliest to latest
  • Gaps in the flow are identified and marked
  • Duplicate events are merged or clarified

Phase 3 — Commands & Actors​

Goal: For each event, identify the command that caused it and the actor who triggered it.

Format: [Actor] → Command → DomainEvent

ActorCommandDomain Event
CustomerPlaceOrderOrderPlaced
SystemProcessPaymentPaymentProcessed

Phase 4 — Policies & Business Rules​

Goal: Identify automated reactions between events.

Format: TriggerEvent → 🟣 "When X, then Y" → ResultingEvent

Trigger EventPolicy / RuleResulting Event
OrderPlaced"When order placed, reserve stock"StockReserved

Phase 5 — Bounded Contexts​

Goal: Draw boundaries around natural clusters of events, commands, and actors.

Boundary identification checklist:

  • Where does one team's responsibility end and another's begin?
  • Where does the same term mean different things?
  • Where are the most 🔴 hotspots concentrated?

Facilitation Reminders​

  • ⏱ Timebox each phase — use a visible timer
  • 🚫 No laptops — keep everyone present
  • 🗣 Domain experts lead — developers listen and ask questions
  • 📌 Capture, don't resolve — log hotspots, don't debate during the session
  • 🔄 Diverge first, converge later — generate broadly, then organize
  • 📅 Schedule a follow-up — don't expect one session to cover everything

Common Pitfalls​

PitfallFix
Only developers attendAlways include domain experts
Events in present tense ("OrderIsPlaced")Enforce past tense consistently
Jumping to solutions too earlyFocus on what happens, not how
Ignoring hotspotsSchedule dedicated follow-up sessions
Single long session with no breaksKeep sessions to 2–4 hours max
