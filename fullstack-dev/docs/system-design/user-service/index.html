User Service — Deep-Dive & NestJS Implementation

The User Service owns the entire identity lifecycle: account creation, credential management, multi-factor authentication (TOTP + SMS), KYC state machine, and session/token housekeeping. It is the trust boundary of the platform — every authenticated request that reaches other services carries a JWT minted here.

Responsibilities​

  1. Registration — validate input, hash credentials, create user + account rows, trigger KYC workflow.
  2. Authentication — issue short-lived JWT access tokens and rotating refresh tokens.
  3. MFA — TOTP (Google Authenticator / Authy) and SMS-OTP fallback; enforced before JWT issuance.
  4. KYC handoff — drive the KYC state machine; call the KYC/AML provider; gate trading access on approval.
  5. Account management — profile updates, notification preferences, password reset, account suspension.

import {
  Entity, PrimaryGeneratedColumn, Column, CreateDateColumn,
  UpdateDateColumn, Index,
} from 'typeorm';

export enum KycStatus {
  PENDING        = 'pending',
  IN_REVIEW      = 'in_review',
  APPROVED       = 'approved',
  REJECTED       = 'rejected',
  MANUAL_REVIEW  = 'manual_review',
  SUSPENDED      = 'suspended',
}

@Entity('users')
export class User {
  @PrimaryGeneratedColumn('uuid')
  id: string;

  /** Store only the SHA-256 hash of the email for PII minimisation; plaintext is in the KYC vault */
  @Index({ unique: true })
  @Column({ name: 'email_hash', length: 64 })
  emailHash: string;

  /** bcrypt hash — never expose via API */
  @Column({ name: 'password_hash' })
  passwordHash: string;

  @Column({ name: 'phone_hash', length: 64, nullable: true })
  phoneHash: string | null;

  @Column({ name: 'kyc_status', type: 'enum', enum: KycStatus, default: KycStatus.PENDING })
  kycStatus: KycStatus;

  @Column({ name: 'mfa_enabled', default: false })
  mfaEnabled: boolean;

  @Column({ name: 'mfa_secret', nullable: true })
  mfaSecret: string | null;   // encrypted at rest (application-level AES-256-GCM)

  @Column({ name: 'mfa_channel', type: 'varchar', nullable: true })
  mfaChannel: 'totp' | 'sms' | null;

  @CreateDateColumn({ name: 'created_at' })
  createdAt: Date;

  @UpdateDateColumn({ name: 'updated_at' })
  updatedAt: Date;
}

auth/auth.service.ts​

import {
  Injectable, UnauthorizedException, ConflictException,
  ForbiddenException, Logger,
} from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import { JwtService } from '@nestjs/jwt';
import { ConfigService } from '@nestjs/config';
import * as bcrypt from 'bcrypt';
import * as crypto from 'crypto';
import { User } from '../users/entities/user.entity';
import { TokensService } from '../tokens/tokens.service';
import { KycService } from '../kyc/kyc.service';
import { RegisterDto } from './dto/register.dto';
import { LoginDto } from './dto/login.dto';

const BCRYPT_ROUNDS = 12;

@Injectable()
export class AuthService {
  private readonly logger = new Logger(AuthService.name);

  constructor(
    @InjectRepository(User) private readonly userRepo: Repository<User>,
    private readonly jwt: JwtService,
    private readonly config: ConfigService,
    private readonly tokens: TokensService,
    private readonly kyc: KycService,
  ) {}

  // ------------------------------------------------------------------
  // Registration
  // ------------------------------------------------------------------

  async register(dto: RegisterDto): Promise<{ userId: string; kycRedirectUrl: string }> {
    const emailHash = this.sha256(dto.email.toLowerCase().trim());

    const existing = await this.userRepo.findOneBy({ emailHash });
    if (existing) throw new ConflictException('Email already registered');

    const passwordHash = await bcrypt.hash(dto.password, BCRYPT_ROUNDS);

    const user = this.userRepo.create({
      emailHash,
      passwordHash,
      phoneHash: dto.phone ? this.sha256(dto.phone) : null,
    });
    await this.userRepo.save(user);

    const { redirectUrl } = await this.kyc.initiateVerification(user.id);

    this.logger.log(`User registered userId=${user.id}`);
    return { userId: user.id, kycRedirectUrl: redirectUrl };
  }

  // ------------------------------------------------------------------
  // Login
  // ------------------------------------------------------------------

  async login(dto: LoginDto): Promise<
    | { accessToken: string; refreshToken: string }
    | { mfaRequired: true; mfaToken: string }
  > {
    const emailHash = this.sha256(dto.email.toLowerCase().trim());
    const user = await this.userRepo.findOneBy({ emailHash });

    if (!user || !(await bcrypt.compare(dto.password, user.passwordHash))) {
      // Use the same error message to prevent user enumeration
      throw new UnauthorizedException('Invalid credentials');
    }

    if (user.kycStatus !== 'approved') {
      throw new ForbiddenException('Account not yet approved for trading');
    }

    if (user.mfaEnabled) {
      const mfaToken = await this.tokens.issueMfaChallenge(user.id, user.mfaChannel!);
      return { mfaRequired: true, mfaToken };
    }

    return this.issueTokenPair(user.id);
  }

  // ------------------------------------------------------------------
  // Token rotation
  // ------------------------------------------------------------------

  async refresh(refreshToken: string) {
    const userId = await this.tokens.validateRefreshToken(refreshToken);
    await this.tokens.revokeRefreshToken(refreshToken);
    return this.issueTokenPair(userId);
  }

  async logout(refreshToken: string) {
    await this.tokens.revokeRefreshToken(refreshToken);
  }

  // ------------------------------------------------------------------
  // Helpers
  // ------------------------------------------------------------------

  private async issueTokenPair(userId: string) {
    const payload = { sub: userId };
    const accessToken  = this.jwt.sign(payload, {
      secret: this.config.getOrThrow('JWT_SECRET'),
      expiresIn: '15m',
    });
    const refreshToken = await this.tokens.issueRefreshToken(userId);
    return { accessToken, refreshToken };
  }

  private sha256(value: string): string {
    return crypto.createHash('sha256').update(value).digest('hex');
  }
}

tokens/tokens.service.ts — refresh token + MFA challenge issuance​

import { Injectable, UnauthorizedException } from '@nestjs/common';
import { InjectRedis } from '@nestjs-modules/ioredis';
import { Redis } from 'ioredis';
import { MfaService } from '../mfa/mfa.service';
import * as crypto from 'crypto';

const REFRESH_TTL_SEC  = 60 * 60 * 24 * 7;   // 7 days
const MFA_TOKEN_TTL    = 300;                  // 5 minutes

@Injectable()
export class TokensService {
  constructor(
    @InjectRedis() private readonly redis: Redis,
    private readonly mfa: MfaService,
  ) {}

  async issueRefreshToken(userId: string): Promise<string> {
    const token = crypto.randomBytes(40).toString('hex');
    const hash  = this.sha256(token);
    await this.redis.set(`refresh:${hash}`, userId, 'EX', REFRESH_TTL_SEC);
    return token;
  }

  async validateRefreshToken(token: string): Promise<string> {
    const hash   = this.sha256(token);
    const userId = await this.redis.get(`refresh:${hash}`);
    if (!userId) throw new UnauthorizedException('Refresh token invalid or expired');
    return userId;
  }

  async revokeRefreshToken(token: string): Promise<void> {
    await this.redis.del(`refresh:${this.sha256(token)}`);
  }

  async issueMfaChallenge(userId: string, channel: 'totp' | 'sms'): Promise<string> {
    const mfaToken = crypto.randomBytes(24).toString('hex');
    await this.redis.set(`mfa_challenge:${mfaToken}`, userId, 'EX', MFA_TOKEN_TTL);
    if (channel === 'sms') await this.mfa.sendSmsOtp(userId);
    return mfaToken;
  }

  async resolveMfaChallenge(mfaToken: string): Promise<string> {
    const userId = await this.redis.get(`mfa_challenge:${mfaToken}`);
    if (!userId) throw new UnauthorizedException('MFA token expired');
    await this.redis.del(`mfa_challenge:${mfaToken}`);
    return userId;
  }

  private sha256(value: string): string {
    return require('crypto').createHash('sha256').update(value).digest('hex');
  }
}

mfa/mfa.service.ts — TOTP provisioning + validation​

import { Injectable, UnauthorizedException, Logger } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import { ConfigService } from '@nestjs/config';
import * as speakeasy from 'speakeasy';
import * as qrcode from 'qrcode';
import { User } from '../users/entities/user.entity';

@Injectable()
export class MfaService {
  private readonly logger = new Logger(MfaService.name);

  constructor(
    @InjectRepository(User) private readonly userRepo: Repository<User>,
    private readonly config: ConfigService,
  ) {}

  /** Generate a new TOTP secret and return the provisioning URI + QR code PNG (data URL). */
  async provisionTotp(userId: string): Promise<{ otpauthUrl: string; qrDataUrl: string }> {
    const secret = speakeasy.generateSecret({ length: 20 });

    const otpauthUrl = speakeasy.otpauthURL({
      secret: secret.base32,
      label: `TradingApp:${userId}`,
      issuer: 'TradingApp',
    });
    const qrDataUrl = await qrcode.toDataURL(otpauthUrl);

    // Store encrypted secret (not yet confirmed — confirmed on first verify)
    await this.userRepo.update(userId, {
      mfaSecret: this.encrypt(secret.base32),
      mfaChannel: 'totp',
    });

    return { otpauthUrl, qrDataUrl };
  }

  async verifyTotp(userId: string, token: string): Promise<boolean> {
    const user = await this.userRepo.findOneByOrFail({ id: userId });
    if (!user.mfaSecret) throw new UnauthorizedException('TOTP not provisioned');

    const secret = this.decrypt(user.mfaSecret);
    const valid  = speakeasy.totp.verify({ secret, encoding: 'base32', token, window: 1 });
    if (!valid) throw new UnauthorizedException('Invalid OTP');

    // Activate MFA on first successful verify
    if (!user.mfaEnabled) {
      await this.userRepo.update(userId, { mfaEnabled: true });
    }
    return true;
  }

  async sendSmsOtp(userId: string): Promise<void> {
    // Delegated to SMS Gateway via an async job queue; not implemented inline for security
    this.logger.log(`Dispatching SMS OTP for userId=${userId}`);
  }

  private encrypt(plaintext: string): string {
    const key  = Buffer.from(this.config.getOrThrow<string>('MFA_ENCRYPTION_KEY'), 'hex');
    const iv   = require('crypto').randomBytes(12);
    const cipher = require('crypto').createCipheriv('aes-256-gcm', key, iv);
    const enc  = Buffer.concat([cipher.update(plaintext, 'utf8'), cipher.final()]);
    const tag  = cipher.getAuthTag();
    return Buffer.concat([iv, tag, enc]).toString('base64');
  }

  private decrypt(ciphertext: string): string {
    const buf    = Buffer.from(ciphertext, 'base64');
    const key    = Buffer.from(this.config.getOrThrow<string>('MFA_ENCRYPTION_KEY'), 'hex');
    const iv     = buf.subarray(0, 12);
    const tag    = buf.subarray(12, 28);
    const enc    = buf.subarray(28);
    const decipher = require('crypto').createDecipheriv('aes-256-gcm', key, iv);
    decipher.setAuthTag(tag);
    return decipher.update(enc) + decipher.final('utf8');
  }
}

kyc/kyc.service.ts — state machine + provider webhook​

import { Injectable, Logger, BadRequestException } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository, DataSource } from 'typeorm';
import { HttpService } from '@nestjs/axios';
import { ConfigService } from '@nestjs/config';
import { firstValueFrom } from 'rxjs';
import { User, KycStatus } from '../users/entities/user.entity';
import { KycEvent } from './entities/kyc-event.entity';

const KYC_TRANSITIONS: Record<string, KycStatus[]> = {
  [KycStatus.PENDING]:       [KycStatus.IN_REVIEW],
  [KycStatus.IN_REVIEW]:     [KycStatus.APPROVED, KycStatus.REJECTED, KycStatus.MANUAL_REVIEW],
  [KycStatus.MANUAL_REVIEW]: [KycStatus.APPROVED, KycStatus.REJECTED],
  [KycStatus.APPROVED]:      [KycStatus.SUSPENDED],
  [KycStatus.SUSPENDED]:     [KycStatus.APPROVED],
};

@Injectable()
export class KycService {
  private readonly logger = new Logger(KycService.name);

  constructor(
    @InjectRepository(User) private readonly userRepo: Repository<User>,
    @InjectRepository(KycEvent) private readonly kycEventRepo: Repository<KycEvent>,
    private readonly http: HttpService,
    private readonly config: ConfigService,
    private readonly dataSource: DataSource,
  ) {}

  async initiateVerification(userId: string): Promise<{ redirectUrl: string }> {
    const apiKey = this.config.getOrThrow<string>('KYC_API_KEY');
    const { data } = await firstValueFrom(
      this.http.post(
        `${this.config.getOrThrow('KYC_BASE_URL')}/verifications`,
        { reference_id: userId },
        { headers: { Authorization: `Bearer ${apiKey}` } },
      ),
    );

    await this.transition(userId, KycStatus.IN_REVIEW, {
      verificationId: data.id,
      note: 'Verification submitted to KYC provider',
    });

    return { redirectUrl: data.redirect_url };
  }

  /** Called by the webhook controller when the KYC provider posts a status update. */
  async handleWebhook(verificationId: string, providerStatus: string): Promise<void> {
    const newStatus = this.mapProviderStatus(providerStatus);

    const event = await this.kycEventRepo.findOne({
      where: { verificationId },
      relations: ['user'],
    });
    if (!event) {
      this.logger.warn(`KYC webhook for unknown verificationId=${verificationId}`);
      return;
    }

    await this.transition(event.user.id, newStatus, {
      verificationId,
      note: `Provider status: ${providerStatus}`,
    });
  }

  async adminOverride(userId: string, newStatus: KycStatus, operatorId: string): Promise<void> {
    await this.transition(userId, newStatus, { operatorId, note: 'Ops override' });
  }

  // ------------------------------------------------------------------

  private async transition(
    userId: string,
    next: KycStatus,
    meta: Record<string, unknown>,
  ): Promise<void> {
    await this.dataSource.transaction(async (manager) => {
      const user = await manager.findOneByOrFail(User, { id: userId });

      const allowed = KYC_TRANSITIONS[user.kycStatus] ?? [];
      if (!allowed.includes(next)) {
        throw new BadRequestException(
          `Invalid KYC transition ${user.kycStatus} → ${next}`,
        );
      }

      user.kycStatus = next;
      await manager.save(user);

      const evt = manager.create(KycEvent, {
        userId,
        fromStatus: user.kycStatus,
        toStatus: next,
        metadata: meta,
      });
      await manager.save(evt);
    });

    this.logger.log(`KYC transition userId=${userId} → ${next}`);
  }

  private mapProviderStatus(providerStatus: string): KycStatus {
    const map: Record<string, KycStatus> = {
      approved:       KycStatus.APPROVED,
      rejected:       KycStatus.REJECTED,
      manual_review:  KycStatus.MANUAL_REVIEW,
    };
    return map[providerStatus] ?? KycStatus.MANUAL_REVIEW;
  }
}

auth/auth.controller.ts​

import {
  Controller, Post, Body, Req, HttpCode, HttpStatus,
  Get, UseGuards,
} from '@nestjs/common';
import { Request } from 'express';
import { AuthService } from './auth.service';
import { MfaService } from '../mfa/mfa.service';
import { RegisterDto } from './dto/register.dto';
import { LoginDto } from './dto/login.dto';
import { MfaVerifyDto } from './dto/mfa-verify.dto';
import { TokensService } from '../tokens/tokens.service';
import { JwtAuthGuard } from './guards/jwt-auth.guard';
import { Public } from './decorators/public.decorator';

@Controller('auth')
export class AuthController {
  constructor(
    private readonly auth: AuthService,
    private readonly mfa: MfaService,
    private readonly tokens: TokensService,
  ) {}

  @Public()
  @Post('register')
  @HttpCode(HttpStatus.CREATED)
  register(@Body() dto: RegisterDto) {
    return this.auth.register(dto);
  }

  @Public()
  @Post('login')
  @HttpCode(HttpStatus.OK)
  login(@Body() dto: LoginDto) {
    return this.auth.login(dto);
  }

  @Public()
  @Post('mfa/verify')
  @HttpCode(HttpStatus.OK)
  async verifyMfa(@Body() dto: MfaVerifyDto) {
    const userId = await this.tokens.resolveMfaChallenge(dto.mfaToken);
    await this.mfa.verifyTotp(userId, dto.otp);
    return this.auth['issueTokenPair'](userId);
  }

  @Public()
  @Post('refresh')
  @HttpCode(HttpStatus.OK)
  refresh(@Body('refreshToken') refreshToken: string) {
    return this.auth.refresh(refreshToken);
  }

  @UseGuards(JwtAuthGuard)
  @Post('logout')
  @HttpCode(HttpStatus.NO_CONTENT)
  logout(@Body('refreshToken') refreshToken: string) {
    return this.auth.logout(refreshToken);
  }

  @UseGuards(JwtAuthGuard)
  @Post('mfa/provision-totp')
  provisionTotp(@Req() req: Request & { user: { userId: string } }) {
    return this.mfa.provisionTotp(req.user.userId);
  }
}

kyc/kyc.controller.ts — provider webhook endpoint​

import { Controller, Post, Body, Headers, UnauthorizedException, Logger } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';
import { Public } from '../auth/decorators/public.decorator';
import { KycService } from './kyc.service';
import * as crypto from 'crypto';

@Controller('kyc')
export class KycController {
  private readonly logger = new Logger(KycController.name);

  constructor(
    private readonly kyc: KycService,
    private readonly config: ConfigService,
  ) {}

  /** Webhook called by the KYC provider when verification status changes. */
  @Public()
  @Post('webhook')
  async webhook(
    @Body() body: { verification_id: string; status: string },
    @Headers('x-kyc-signature') signature: string,
  ) {
    this.verifyWebhookSignature(JSON.stringify(body), signature);
    await this.kyc.handleWebhook(body.verification_id, body.status);
    return { received: true };
  }

  private verifyWebhookSignature(payload: string, signature: string): void {
    const secret = this.config.getOrThrow<string>('KYC_WEBHOOK_SECRET');
    const expected = crypto
      .createHmac('sha256', secret)
      .update(payload)
      .digest('hex');

    // Constant-time comparison prevents timing attacks
    const sigBuffer = Buffer.from(signature ?? '', 'hex');
    const expBuffer = Buffer.from(expected, 'hex');
    if (
      sigBuffer.length !== expBuffer.length ||
      !crypto.timingSafeEqual(sigBuffer, expBuffer)
    ) {
      this.logger.warn('KYC webhook signature mismatch');
      throw new UnauthorizedException('Invalid webhook signature');
    }
  }
}

Security Controls​

ControlImplementation
Password storagebcrypt cost factor 12; never logged or returned via API
PII minimisationEmail and phone stored as SHA-256 hashes; plaintext only in KYC provider vault
MFA secret encryptionAES-256-GCM at application layer; key in GCP Secret Manager
Refresh token storageStored as SHA-256 hash in Redis; rotating on every use
JWT lifetimeAccess token: 15 min; refresh token: 7 days
KYC webhook integrityHMAC-SHA256 signature with crypto.timingSafeEqual
User enumeration preventionSame error message for "unknown email" and "wrong password"
Brute-force protectionRedis sliding-window counter per ip:email — lock after 10 failed attempts in 15 min
HTTPS onlyTLS terminated at Traefik ingress; internal plaintext only within the cluster
Secrets managementAll secrets injected from GCP Secret Manager via Workload Identity; none hardcoded

Non-Functional Requirements​

NFRTarget
Login latency (p99)≤ 200 ms (includes bcrypt compare + Redis round-trip)
Registration (p99)≤ 500 ms (includes KYC provider call)
Token refresh (p99)≤ 50 ms (Redis-only path)

Failure Modes​

FailureMitigation
Redis unavailable during loginCircuit breaker on token ops; fall back to stateless JWT-only flow (no refresh); alert on-call
KYC provider timeout on registrationRegistration succeeds; KYC retried via outbox pattern; user notified to complete KYC separately
Duplicate KYC webhook deliveryIdempotency: kyc_events table has UNIQUE(verification_id, to_status) — duplicate upsert is a no-op
MFA secret lost (user lost device)Account recovery flow: identity re-verification via KYC provider, then MFA reset by ops
bcrypt DoS via long passwordsCap input length at 128 chars before hash (class-validator @MaxLength(128))
