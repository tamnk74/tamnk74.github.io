WebSocket Gateway

The WebSocket Gateway is the persistent-connection layer between browser/mobile clients and the backend services of the stock trading platform. It is responsible for delivering real-time market quotes and live order-status updates with sub-250 ms staleness.

Responsibilities​

  1. Accept and manage long-lived WebSocket connections from authenticated clients.
  2. Multiplex multiple symbol subscriptions per connection.
  3. Fan-out quote events from the Market Data Service to all subscribed clients.
  4. Push live order-status transitions (accepted → filled / rejected) to the originating client session.
  5. Enforce per-connection rate limits and connection-count caps per user.
  6. Gracefully drain connections during rolling deployments.

C4 — Container in Context​

Connection Lifecycle​

Fan-Out Architecture​

The gateway uses a Redis Pub/Sub per-symbol channel model:

quote:AAPL  ──────► WebSocket Gateway ──────► [conn-1, conn-4, conn-9, …]
quote:TSLA  ──────► WebSocket Gateway ──────► [conn-2, conn-4, conn-7, …]
order:acct_42 ────► WebSocket Gateway ──────► [conn-3]
  • The gateway process maintains an in-memory Map<channel, Set<connection>>.
  • On Redis message arrival, it iterates the set and writes the frame to each socket.
  • A channel is subscribed at Redis level only while ≥ 1 client subscribes. Automatic unsubscribe on last-client-leaving avoids idle channel overhead.
  • Each gateway pod handles ~10k concurrent connections (Node.js single-thread + uWebSockets.js native bindings).
  • Horizontal scaling: multiple pods each subscribe to the same Redis channels. Every pod receives every message and filters to its local subscriber set.

Protocol — Message Frames​

All frames are JSON-encoded text messages.

Client → Gateway​

// Subscribe to symbols
{ "type": "subscribe", "symbols": ["AAPL", "MSFT"] }

// Unsubscribe from symbols
{ "type": "unsubscribe", "symbols": ["AAPL"] }

// Heartbeat (client ping)
{ "type": "ping" }

Gateway → Client​

// Real-time quote
{ "type": "quote", "symbol": "AAPL", "price": 192.40, "bid": 192.38, "ask": 192.42, "volume": 1234500, "ts": 1746057600000 }

// Order status transition
{ "type": "order_update", "order_id": "ord_abc123", "status": "filled", "avg_price": 192.39, "filled_qty": 100, "ts": 1746057612345 }

// Server heartbeat
{ "type": "pong" }

// Error
{ "type": "error", "code": "SYMBOL_LIMIT_EXCEEDED", "message": "Maximum 50 symbols per connection" }

Deployment​

The WebSocket Gateway is a dedicated Kubernetes Deployment separate from the API Gateway:

  • Image: lightweight Node.js 22 Alpine + uWebSockets.js native binding.
  • Resources: requests: {cpu: 250m, memory: 256Mi}, limits: {cpu: 1, memory: 512Mi}.
  • HPA: min 2, max 10 pods; scale metric: ws.connections.active > 7000 per pod.
  • Session affinity: not required — clients reconnect to any pod and re-subscribe; Redis fan-out reaches all pods.
  • terminationGracePeriodSeconds: 60 to allow the 30 s drain window.

NestJS Implementation​

The gateway is built as a standalone NestJS application using @nestjs/websockets with the ws adapter. Each concern — authentication, subscription management, Redis fan-out, rate limiting, and graceful shutdown — is isolated into its own class.

main.ts — bootstrap with WS adapter and graceful shutdown​

import { NestFactory } from '@nestjs/core';
import { WsAdapter } from '@nestjs/platform-ws';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  app.useWebSocketAdapter(new WsAdapter(app));

  // Graceful shutdown: send reconnect frame before closing
  app.enableShutdownHooks();

  await app.listen(3001);
}
bootstrap();

ws-auth.guard.ts — JWT validation on HTTP Upgrade​

Authentication happens at the handshake level via canActivate. The guard decodes the JWT from the Authorization header or token query-param and attaches claims to the socket data.

import { CanActivate, ExecutionContext, Injectable, Logger } from '@nestjs/common';
import { JwtService } from '@nestjs/jwt';
import { WsException } from '@nestjs/websockets';

@Injectable()
export class WsAuthGuard implements CanActivate {
  private readonly logger = new Logger(WsAuthGuard.name);

  constructor(private readonly jwtService: JwtService) {}

  canActivate(context: ExecutionContext): boolean {
    const client = context.switchToWs().getClient<WebSocket & { data: Record<string, unknown> }>();
    const request = (client as any).upgradeReq as Record<string, any>;

    const token = this.extractToken(request);
    if (!token) {
      client.close(1008, 'Missing or invalid Authorization');
      return false;
    }

    try {
      const payload = this.jwtService.verify<{ sub: string; accountId: string }>(token);
      // Attach claims to socket for downstream use
      client.data = { userId: payload.sub, accountId: payload.accountId };
      return true;
    } catch (err) {
      this.logger.warn(`JWT verification failed: ${(err as Error).message}`);
      client.close(1008, 'Unauthorized');
      return false;
    }
  }

  private extractToken(request: Record<string, any>): string | undefined {
    const auth: string | undefined = request.headers?.authorization;
    if (auth?.startsWith('Bearer ')) return auth.slice(7);

    // Fallback: ?token=<jwt> query-param (e.g. browser EventSource polyfill)
    const url = new URL(request.url, 'ws://localhost');
    return url.searchParams.get('token') ?? undefined;
  }
}

ws-rate-limit.guard.ts — per-connection frame rate limit​

import { CanActivate, ExecutionContext, Injectable } from '@nestjs/common';

const MAX_FRAMES_PER_SECOND = 10;

@Injectable()
export class WsRateLimitGuard implements CanActivate {
  // Per-socket counters: socket → { count, resetAt }
  private readonly counters = new WeakMap<object, { count: number; resetAt: number }>();

  canActivate(context: ExecutionContext): boolean {
    const client = context.switchToWs().getClient<object>();
    const now = Date.now();

    const entry = this.counters.get(client) ?? { count: 0, resetAt: now + 1000 };

    if (now > entry.resetAt) {
      entry.count = 0;
      entry.resetAt = now + 1000;
    }

    entry.count++;
    this.counters.set(client, entry);

    return entry.count <= MAX_FRAMES_PER_SECOND;
  }
}

ws-gateway.gateway.ts — main gateway class​

import {
  WebSocketGateway,
  WebSocketServer,
  SubscribeMessage,
  OnGatewayConnection,
  OnGatewayDisconnect,
  OnGatewayInit,
  ConnectedSocket,
  MessageBody,
  WsException,
} from '@nestjs/websockets';
import { UseGuards, UsePipes, ValidationPipe, Logger, OnApplicationShutdown } from '@nestjs/common';
import { Server } from 'ws';
import { WsAuthGuard } from './ws-auth.guard';
import { WsRateLimitGuard } from './ws-rate-limit.guard';
import { WsGatewayService } from './ws-gateway.service';
import { WsMetricsService } from '../metrics/ws-metrics.service';
import { SubscribeDto } from './dto/subscribe.dto';
import { UnsubscribeDto } from './dto/unsubscribe.dto';

type AuthedSocket = WebSocket & { data: { userId: string; accountId: string } };

@WebSocketGateway({ path: '/ws' })
@UseGuards(WsAuthGuard)
export class WsGatewayGateway
  implements OnGatewayInit, OnGatewayConnection, OnGatewayDisconnect, OnApplicationShutdown
{
  @WebSocketServer()
  server: Server;

  private readonly logger = new Logger(WsGatewayGateway.name);

  constructor(
    private readonly gatewayService: WsGatewayService,
    private readonly metrics: WsMetricsService,
  ) {}

  afterInit() {
    this.logger.log('WebSocket Gateway initialised');
  }

  handleConnection(client: AuthedSocket) {
    const { userId, accountId } = client.data;

    // Enforce max 3 concurrent connections per user
    if (!this.gatewayService.registerConnection(userId, client)) {
      client.close(1013, 'Connection limit exceeded');
      return;
    }

    // Subscribe to order-status channel for this account
    this.gatewayService.subscribe(client, [`order:${accountId}`]);
    this.metrics.incrementConnections();
    this.logger.log(`Connected: userId=${userId}`);
  }

  handleDisconnect(client: AuthedSocket) {
    this.gatewayService.removeConnection(client);
    this.metrics.decrementConnections();
    this.logger.log(`Disconnected: userId=${client.data?.userId}`);
  }

  @SubscribeMessage('subscribe')
  @UseGuards(WsRateLimitGuard)
  @UsePipes(new ValidationPipe({ transform: true, whitelist: true }))
  handleSubscribe(
    @ConnectedSocket() client: AuthedSocket,
    @MessageBody() dto: SubscribeDto,
  ) {
    const channels = dto.symbols.map((s) => `quote:${s.toUpperCase()}`);
    const ok = this.gatewayService.subscribe(client, channels);
    if (!ok) {
      throw new WsException({ code: 'SYMBOL_LIMIT_EXCEEDED', message: 'Maximum 50 symbols per connection' });
    }
  }

  @SubscribeMessage('unsubscribe')
  @UseGuards(WsRateLimitGuard)
  @UsePipes(new ValidationPipe({ transform: true, whitelist: true }))
  handleUnsubscribe(
    @ConnectedSocket() client: AuthedSocket,
    @MessageBody() dto: UnsubscribeDto,
  ) {
    const channels = dto.symbols.map((s) => `quote:${s.toUpperCase()}`);
    this.gatewayService.unsubscribe(client, channels);
  }

  @SubscribeMessage('ping')
  handlePing(@ConnectedSocket() client: AuthedSocket) {
    client.send(JSON.stringify({ type: 'pong' }));
  }

  // Called by NestJS lifecycle on SIGTERM
  async onApplicationShutdown() {
    this.logger.log('Shutdown signal received — broadcasting reconnect frame');
    const frame = JSON.stringify({ type: 'reconnect' });

    this.server.clients.forEach((client) => {
      if (client.readyState === client.OPEN) {
        client.send(frame);
      }
    });

    // 30 s drain window — Kubernetes terminationGracePeriodSeconds must be > 30
    await new Promise((resolve) => setTimeout(resolve, 30_000));
  }
}

ws-gateway.service.ts — subscription map and fan-out​

import { Injectable, Logger, OnModuleInit } from '@nestjs/common';
import { RedisPubSubService } from '../redis/redis-pubsub.service';
import { WsMetricsService } from '../metrics/ws-metrics.service';

const MAX_SYMBOLS_PER_CONNECTION = 50;
const MAX_CONNECTIONS_PER_USER = 3;
const SLOW_CLIENT_BUFFER_THRESHOLD = 512 * 1024; // 512 KB

type WsClient = WebSocket & { data: { userId: string; accountId: string } };

@Injectable()
export class WsGatewayService implements OnModuleInit {
  private readonly logger = new Logger(WsGatewayService.name);

  /** channel → Set of subscribed clients */
  private readonly channelClients = new Map<string, Set<WsClient>>();

  /** client → Set of subscribed channels */
  private readonly clientChannels = new WeakMap<WsClient, Set<string>>();

  /** userId → Set of client sockets */
  private readonly userConnections = new Map<string, Set<WsClient>>();

  constructor(
    private readonly redisPubSub: RedisPubSubService,
    private readonly metrics: WsMetricsService,
  ) {}

  onModuleInit() {
    // Receive every Redis message and fan-out to local subscribers
    this.redisPubSub.onMessage((channel, message) => {
      this.fanOut(channel, message);
    });
  }

  /**
   * Register a new connection. Returns false if the user already has
   * MAX_CONNECTIONS_PER_USER open sockets.
   */
  registerConnection(userId: string, client: WsClient): boolean {
    const existing = this.userConnections.get(userId) ?? new Set();
    if (existing.size >= MAX_CONNECTIONS_PER_USER) return false;

    existing.add(client);
    this.userConnections.set(userId, existing);
    this.clientChannels.set(client, new Set());
    return true;
  }

  /**
   * Subscribe a client to a list of channels. Returns false if the
   * total symbol count for the client would exceed MAX_SYMBOLS_PER_CONNECTION.
   */
  subscribe(client: WsClient, channels: string[]): boolean {
    const clientSubs = this.clientChannels.get(client) ?? new Set();

    // Quote channels count against symbol limit; order channels are free
    const quoteChannels = channels.filter((c) => c.startsWith('quote:'));
    const currentQuoteCount = [...clientSubs].filter((c) => c.startsWith('quote:')).length;
    if (currentQuoteCount + quoteChannels.length > MAX_SYMBOLS_PER_CONNECTION) return false;

    for (const channel of channels) {
      clientSubs.add(channel);

      if (!this.channelClients.has(channel)) {
        this.channelClients.set(channel, new Set());
        // First subscriber — register at Redis level
        this.redisPubSub.subscribe(channel).catch((err) =>
          this.logger.error(`Redis SUBSCRIBE failed for ${channel}: ${err.message}`),
        );
      }
      this.channelClients.get(channel)!.add(client);
    }

    this.clientChannels.set(client, clientSubs);
    this.metrics.setSubscriptions(this.totalSubscriptions());
    return true;
  }

  unsubscribe(client: WsClient, channels: string[]) {
    const clientSubs = this.clientChannels.get(client);
    if (!clientSubs) return;

    for (const channel of channels) {
      clientSubs.delete(channel);
      const subscribers = this.channelClients.get(channel);
      if (subscribers) {
        subscribers.delete(client);
        if (subscribers.size === 0) {
          this.channelClients.delete(channel);
          // Last subscriber — unregister at Redis level
          this.redisPubSub.unsubscribe(channel).catch((err) =>
            this.logger.error(`Redis UNSUBSCRIBE failed for ${channel}: ${err.message}`),
          );
        }
      }
    }

    this.metrics.setSubscriptions(this.totalSubscriptions());
  }

  removeConnection(client: WsClient) {
    const channels = this.clientChannels.get(client);
    if (channels) {
      this.unsubscribe(client, [...channels]);
    }
    this.clientChannels.delete(client);

    const { userId } = client.data ?? {};
    if (userId) {
      const userSet = this.userConnections.get(userId);
      if (userSet) {
        userSet.delete(client);
        if (userSet.size === 0) this.userConnections.delete(userId);
      }
    }
  }

  private fanOut(channel: string, message: string) {
    const subscribers = this.channelClients.get(channel);
    if (!subscribers || subscribers.size === 0) return;

    const start = Date.now();
    const dead: WsClient[] = [];

    for (const client of subscribers) {
      if (client.readyState !== client.OPEN) {
        dead.push(client);
        continue;
      }

      // Shed slow clients whose write buffer is oversized
      if ((client as any).bufferedAmount > SLOW_CLIENT_BUFFER_THRESHOLD) {
        this.logger.warn(`Evicting slow client userId=${client.data?.userId}`);
        this.metrics.incrementEvictions();
        client.close(1001, 'Slow client');
        dead.push(client);
        continue;
      }

      client.send(message);
      this.metrics.incrementFramesSent();
    }

    // Clean up dead sockets discovered during fan-out
    dead.forEach((c) => this.removeConnection(c));

    this.metrics.recordFanOutLag(Date.now() - start);
  }

  private totalSubscriptions(): number {
    let total = 0;
    this.channelClients.forEach((set) => (total += set.size));
    return total;
  }
}

redis/redis-pubsub.service.ts — dedicated subscriber client​

Redis Pub/Sub requires a dedicated connection that cannot issue regular commands while in subscribe mode. This service maintains two ioredis clients: one for subscribing, one for publishing.

import { Injectable, Logger, OnModuleDestroy, OnModuleInit } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';
import Redis from 'ioredis';

type MessageHandler = (channel: string, message: string) => void;

@Injectable()
export class RedisPubSubService implements OnModuleInit, OnModuleDestroy {
  private readonly logger = new Logger(RedisPubSubService.name);
  private subscriber: Redis;
  private publisher: Redis;
  private messageHandler: MessageHandler | null = null;

  /** Active channel reference counts (for multi-pod subscribe safety) */
  private readonly refCounts = new Map<string, number>();

  constructor(private readonly config: ConfigService) {}

  onModuleInit() {
    const redisUrl = this.config.getOrThrow<string>('REDIS_URL');
    const opts = { lazyConnect: true, enableReadyCheck: true };

    this.subscriber = new Redis(redisUrl, opts);
    this.publisher = new Redis(redisUrl, opts);

    this.subscriber.on('message', (channel: string, message: string) => {
      this.messageHandler?.(channel, message);
    });

    this.subscriber.on('error', (err) => {
      this.logger.error(`Redis subscriber error: ${err.message}`);
    });

    this.subscriber.connect().catch((err) =>
      this.logger.error(`Redis subscriber connect failed: ${err.message}`),
    );
    this.publisher.connect().catch((err) =>
      this.logger.error(`Redis publisher connect failed: ${err.message}`),
    );
  }

  async onModuleDestroy() {
    await this.subscriber.quit();
    await this.publisher.quit();
  }

  onMessage(handler: MessageHandler) {
    this.messageHandler = handler;
  }

  async subscribe(channel: string): Promise<void> {
    const count = (this.refCounts.get(channel) ?? 0) + 1;
    this.refCounts.set(channel, count);
    if (count === 1) {
      await this.subscriber.subscribe(channel);
      this.logger.debug(`Subscribed to Redis channel: ${channel}`);
    }
  }

  async unsubscribe(channel: string): Promise<void> {
    const count = (this.refCounts.get(channel) ?? 1) - 1;
    if (count <= 0) {
      this.refCounts.delete(channel);
      await this.subscriber.unsubscribe(channel);
      this.logger.debug(`Unsubscribed from Redis channel: ${channel}`);
    } else {
      this.refCounts.set(channel, count);
    }
  }

  async publish(channel: string, message: string): Promise<void> {
    await this.publisher.publish(channel, message);
  }
}

metrics/ws-metrics.service.ts — Prometheus metrics​

import { Injectable } from '@nestjs/common';
import { Counter, Gauge, Histogram, Registry } from 'prom-client';

@Injectable()
export class WsMetricsService {
  private readonly registry = new Registry();

  private readonly connectionsGauge = new Gauge({
    name: 'ws_connections_active',
    help: 'Current open WebSocket connections',
    registers: [this.registry],
  });

  private readonly subscriptionsGauge = new Gauge({
    name: 'ws_subscriptions_active',
    help: 'Total symbol subscriptions across all connections',
    registers: [this.registry],
  });

  private readonly framesSentCounter = new Counter({
    name: 'ws_frames_sent_total',
    help: 'Total frames written to clients',
    registers: [this.registry],
  });

  private readonly evictionsCounter = new Counter({
    name: 'ws_connections_evicted_total',
    help: 'Slow-client evictions',
    registers: [this.registry],
  });

  private readonly fanOutLagHistogram = new Histogram({
    name: 'ws_quote_fan_out_lag_ms',
    help: 'Time from Redis message receipt to last client write complete (ms)',
    buckets: [1, 5, 10, 25, 50, 100, 250],
    registers: [this.registry],
  });

  incrementConnections() { this.connectionsGauge.inc(); }
  decrementConnections() { this.connectionsGauge.dec(); }
  setSubscriptions(n: number) { this.subscriptionsGauge.set(n); }
  incrementFramesSent() { this.framesSentCounter.inc(); }
  incrementEvictions() { this.evictionsCounter.inc(); }
  recordFanOutLag(ms: number) { this.fanOutLagHistogram.observe(ms); }

  getMetrics() { return this.registry.metrics(); }
}
