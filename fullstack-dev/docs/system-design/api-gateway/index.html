API Gateway

The API Gateway is the single entry point for all HTTP/REST traffic from web and mobile clients. It handles JWT authentication, per-user rate limiting, and cross-cutting concerns (CORS, versioning, request tracing). Downstream communication to all backend services uses gRPC — giving strongly-typed contracts, binary serialisation, and built-in deadline/cancellation propagation.

Responsibilities​

  1. Authentication — validate JWT on every inbound request; reject with 401 before traffic reaches a service.
  2. Rate limiting — enforce per-user and per-endpoint request budgets using a sliding-window counter in Redis.
  3. Routing — translate inbound REST calls to typed gRPC calls on the correct downstream service.
  4. CORS — enforce allowed origins; critical for the browser trading UI.
  5. Request tracing — inject X-Request-Id and OpenTelemetry trace context on every inbound request.
  6. Global error normalisation — map all unhandled exceptions to { statusCode, message, requestId } so clients never receive raw stack traces.
  7. Versioning — URI-based (/v1/...) so breaking changes can be introduced without forcing all clients to migrate simultaneously.

main.ts​

import { NestFactory } from '@nestjs/core';
import { ValidationPipe, VersioningType, Logger } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';
import { AppModule } from './app.module';
import { GlobalExceptionFilter } from './filters/global-exception.filter';

async function bootstrap() {
  const app = await NestFactory.create(AppModule, {
    logger: ['error', 'warn', 'log'],
  });

  const config = app.get(ConfigService);

  app.useGlobalPipes(
    new ValidationPipe({ whitelist: true, forbidNonWhitelisted: true, transform: true }),
  );

  app.useGlobalFilters(new GlobalExceptionFilter());

  app.enableVersioning({ type: VersioningType.URI, defaultVersion: '1' });

  app.enableCors({
    origin: config.getOrThrow<string>('ALLOWED_ORIGINS').split(','),
    methods: ['GET', 'POST', 'PATCH', 'DELETE', 'OPTIONS'],
    allowedHeaders: ['Authorization', 'Content-Type', 'Idempotency-Key', 'X-Request-Id'],
    credentials: true,
  });

  app.enableShutdownHooks();

  await app.listen(config.get('PORT', 3000));
  Logger.log(`API Gateway listening on port ${config.get('PORT', 3000)}`);
}
bootstrap();

auth/jwt.strategy.ts​

import { Injectable, UnauthorizedException } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';
import { PassportStrategy } from '@nestjs/passport';
import { ExtractJwt, Strategy } from 'passport-jwt';

export interface JwtPayload {
  sub: string;
  accountId: string;
  roles: string[];
  iat: number;
  exp: number;
}

@Injectable()
export class JwtStrategy extends PassportStrategy(Strategy) {
  constructor(config: ConfigService) {
    super({
      jwtFromRequest: ExtractJwt.fromAuthHeaderAsBearerToken(),
      ignoreExpiration: false,
      secretOrKey: config.getOrThrow<string>('JWT_SECRET'),
      // For RS256: use secretOrKeyProvider + JWKS endpoint instead
    });
  }

  validate(payload: JwtPayload) {
    if (!payload.sub || !payload.accountId) {
      throw new UnauthorizedException('Malformed token claims');
    }
    return { userId: payload.sub, accountId: payload.accountId, roles: payload.roles };
  }
}

auth/jwt-auth.guard.ts​

import { Injectable, ExecutionContext } from '@nestjs/common';
import { Reflector } from '@nestjs/core';
import { AuthGuard } from '@nestjs/passport';
import { IS_PUBLIC_KEY } from './public.decorator';

@Injectable()
export class JwtAuthGuard extends AuthGuard('jwt') {
  constructor(private readonly reflector: Reflector) {
    super();
  }

  canActivate(context: ExecutionContext) {
    // Allow routes decorated with @Public() to skip auth
    const isPublic = this.reflector.getAllAndOverride<boolean>(IS_PUBLIC_KEY, [
      context.getHandler(),
      context.getClass(),
    ]);
    if (isPublic) return true;
    return super.canActivate(context);
  }
}
// auth/public.decorator.ts
import { SetMetadata } from '@nestjs/common';
export const IS_PUBLIC_KEY = 'isPublic';
export const Public = () => SetMetadata(IS_PUBLIC_KEY, true);

rate-limit/rate-limit.guard.ts — sliding-window in Redis​

Uses a Redis sorted set per {userId}:{endpoint} key. Each request adds the current timestamp as a member; expired members are pruned on every check.

import {
  Injectable, CanActivate, ExecutionContext,
  HttpException, HttpStatus, Inject,
} from '@nestjs/common';
import { Reflector } from '@nestjs/core';
import { Redis } from 'ioredis';
import { Request } from 'express';
import { RATE_LIMIT_KEY, RateLimitOptions } from './rate-limit.decorator';
import { REDIS_CLIENT } from '../redis/redis.module';

const DEFAULT_LIMIT = 60;       // requests
const DEFAULT_WINDOW = 60;      // seconds

@Injectable()
export class RateLimitGuard implements CanActivate {
  constructor(
    private readonly reflector: Reflector,
    @Inject(REDIS_CLIENT) private readonly redis: Redis,
  ) {}

  async canActivate(context: ExecutionContext): Promise<boolean> {
    const opts = this.reflector.getAllAndOverride<RateLimitOptions>(RATE_LIMIT_KEY, [
      context.getHandler(),
      context.getClass(),
    ]) ?? { limit: DEFAULT_LIMIT, windowSec: DEFAULT_WINDOW };

    const req = context.switchToHttp().getRequest<Request & { user?: { userId: string } }>();
    const userId = req.user?.userId ?? req.ip ?? 'anon';
    const endpoint = `${req.method}:${req.route?.path ?? req.path}`;
    const key = `ratelimit:${userId}:${endpoint}`;
    const now = Date.now();
    const windowStart = now - opts.windowSec * 1000;

    const pipeline = this.redis.pipeline();
    pipeline.zremrangebyscore(key, '-inf', windowStart);   // prune expired
    pipeline.zadd(key, now, `${now}-${Math.random()}`);    // record this request
    pipeline.zcard(key);                                    // count in window
    pipeline.expire(key, opts.windowSec);
    const results = await pipeline.exec();

    const count = results?.[2]?.[1] as number ?? 0;

    if (count > opts.limit) {
      const res = context.switchToHttp().getResponse();
      res.set('Retry-After', opts.windowSec.toString());
      throw new HttpException(
        { statusCode: 429, message: 'Too Many Requests', retryAfter: opts.windowSec },
        HttpStatus.TOO_MANY_REQUESTS,
      );
    }

    return true;
  }
}
// rate-limit/rate-limit.decorator.ts
import { SetMetadata } from '@nestjs/common';

export const RATE_LIMIT_KEY = 'rateLimit';

export interface RateLimitOptions {
  limit: number;
  windowSec: number;
}

export const RateLimit = (limit: number, windowSec = 60) =>
  SetMetadata(RATE_LIMIT_KEY, { limit, windowSec });

Usage:

tracing/tracing.interceptor.ts​

import {
  Injectable, NestInterceptor, ExecutionContext,
  CallHandler,
} from '@nestjs/common';
import { Observable, tap } from 'rxjs';
import { randomUUID } from 'crypto';
import { Request, Response } from 'express';

@Injectable()
export class TracingInterceptor implements NestInterceptor {
  intercept(context: ExecutionContext, next: CallHandler): Observable<unknown> {
    const req = context.switchToHttp().getRequest<Request>();
    const res = context.switchToHttp().getResponse<Response>();

    const requestId = (req.headers['x-request-id'] as string) ?? randomUUID();
    req.headers['x-request-id'] = requestId;

    return next.handle().pipe(
      tap(() => {
        res.set('X-Request-Id', requestId);
      }),
    );
  }
}

filters/global-exception.filter.ts​

import {
  ExceptionFilter, Catch, ArgumentsHost,
  HttpException, HttpStatus, Logger,
} from '@nestjs/common';
import { Response, Request } from 'express';

@Catch()
export class GlobalExceptionFilter implements ExceptionFilter {
  private readonly logger = new Logger(GlobalExceptionFilter.name);

  catch(exception: unknown, host: ArgumentsHost) {
    const ctx = host.switchToHttp();
    const res = ctx.getResponse<Response>();
    const req = ctx.getRequest<Request>();

    const status =
      exception instanceof HttpException
        ? exception.getStatus()
        : HttpStatus.INTERNAL_SERVER_ERROR;

    const message =
      exception instanceof HttpException
        ? (exception.getResponse() as any)?.message ?? exception.message
        : 'Internal server error';

    // Never leak stack traces to clients
    if (status >= 500) {
      this.logger.error(`Unhandled exception: ${(exception as Error)?.stack ?? exception}`);
    }

    res.status(status).json({
      statusCode: status,
      message,
      requestId: req.headers['x-request-id'],
      timestamp: new Date().toISOString(),
    });
  }
}

grpc-clients/grpc-clients.module.ts — register all gRPC stubs​

Each downstream service exposes a gRPC server. The gateway registers a typed ClientGrpc stub for each using @nestjs/microservices.

import { Module } from '@nestjs/common';
import { ClientsModule, Transport } from '@nestjs/microservices';
import { ConfigModule, ConfigService } from '@nestjs/config';
import { join } from 'path';

export const GRPC_ORDER    = 'GRPC_ORDER_CLIENT';
export const GRPC_PORTFOLIO = 'GRPC_PORTFOLIO_CLIENT';
export const GRPC_MARKET   = 'GRPC_MARKET_DATA_CLIENT';
export const GRPC_NOTIF    = 'GRPC_NOTIFICATION_CLIENT';
export const GRPC_USER     = 'GRPC_USER_CLIENT';

function grpcClient(token: string, envKey: string, protoFile: string, packageName: string) {
  return {
    name: token,
    imports: [ConfigModule],
    inject: [ConfigService],
    useFactory: (config: ConfigService) => ({
      transport: Transport.GRPC,
      options: {
        url: config.getOrThrow<string>(envKey),
        package: packageName,
        protoPath: join(__dirname, 'proto', protoFile),
        // Pass OTel trace context via gRPC metadata interceptor
        channelOptions: { 'grpc.enable_retries': 1 },
      },
    }),
  };
}

@Module({
  imports: [
    ClientsModule.registerAsync([
      grpcClient(GRPC_USER,      'USER_SERVICE_GRPC_URL',      'users.proto',         'trading.users'),
      grpcClient(GRPC_ORDER,     'ORDER_SERVICE_GRPC_URL',     'orders.proto',        'trading.orders'),
      grpcClient(GRPC_PORTFOLIO, 'PORTFOLIO_SERVICE_GRPC_URL', 'portfolio.proto',     'trading.portfolio'),
      grpcClient(GRPC_MARKET,    'MARKET_DATA_GRPC_URL',       'market-data.proto',   'trading.marketdata'),
      grpcClient(GRPC_NOTIF,     'NOTIFICATION_GRPC_URL',      'notifications.proto', 'trading.notifications'),
    ]),

})
export class GrpcClientsModule {}

grpc-clients/grpc-clients.service.ts — typed wrappers with metadata injection​

Each method wraps the raw gRPC stub call, injects OTel trace metadata, and enforces a deadline.

import { Injectable, OnModuleInit, Inject } from '@nestjs/common';
import { ClientGrpc } from '@nestjs/microservices';
import { Metadata } from '@grpc/grpc-js';
import { firstValueFrom, Observable } from 'rxjs';
import { GRPC_ORDER, GRPC_PORTFOLIO, GRPC_MARKET, GRPC_NOTIF, GRPC_USER } from './grpc-clients.module';

// ---------- interface declarations (generated from proto or hand-typed) ----------

interface OrdersGrpcService {
  createOrder(data: Record<string, unknown>, metadata: Metadata): Observable<Record<string, unknown>>;
  cancelOrder(data: Record<string, unknown>, metadata: Metadata): Observable<Record<string, unknown>>;
  listOrders(data: Record<string, unknown>, metadata: Metadata): Observable<Record<string, unknown>>;
}

interface MarketDataGrpcService {
  getQuote(data: Record<string, unknown>, metadata: Metadata): Observable<Record<string, unknown>>;
  getCandles(data: Record<string, unknown>, metadata: Metadata): Observable<Record<string, unknown>>;
}

// (similar interfaces for portfolio, notifications, users — omitted for brevity)

// ---------- service ----------

@Injectable()
export class GrpcClientsService implements OnModuleInit {
  private ordersStub: OrdersGrpcService;
  private marketDataStub: MarketDataGrpcService;

  constructor(
    @Inject(GRPC_ORDER)  private readonly orderClient: ClientGrpc,
    @Inject(GRPC_MARKET) private readonly marketClient: ClientGrpc,
  ) {}

  onModuleInit() {
    this.ordersStub     = this.orderClient.getService<OrdersGrpcService>('OrdersService');
    this.marketDataStub = this.marketClient.getService<MarketDataGrpcService>('MarketDataService');
  }

  /** Build gRPC Metadata from the current request context */
  buildMetadata(requestId: string, userId: string, accountId: string): Metadata {
    const md = new Metadata();
    md.set('x-request-id', requestId);
    md.set('x-user-id', userId);
    md.set('x-account-id', accountId);
    return md;
  }

  async createOrder(payload: Record<string, unknown>, meta: Metadata) {
    return firstValueFrom(this.ordersStub.createOrder(payload, meta));
  }

  async cancelOrder(payload: Record<string, unknown>, meta: Metadata) {
    return firstValueFrom(this.ordersStub.cancelOrder(payload, meta));
  }

  async listOrders(payload: Record<string, unknown>, meta: Metadata) {
    return firstValueFrom(this.ordersStub.listOrders(payload, meta));
  }

  async getQuote(symbol: string, meta: Metadata) {
    return firstValueFrom(this.marketDataStub.getQuote({ symbol }, meta));
  }

  async getCandles(payload: Record<string, unknown>, meta: Metadata) {
    return firstValueFrom(this.marketDataStub.getCandles(payload, meta));
  }
}

orders/orders.controller.ts — REST → gRPC translation​

import {
  Controller, Post, Get, Delete, Body, Param,
  Req, HttpCode, HttpStatus, Headers,
} from '@nestjs/common';
import { Request } from 'express';
import { RateLimit } from '../rate-limit/rate-limit.decorator';
import { GrpcClientsService } from '../grpc-clients/grpc-clients.service';
import { CreateOrderDto } from './dto/create-order.dto';

type AuthedRequest = Request & { user: { userId: string; accountId: string } };

@Controller('v1/orders')
export class OrdersController {
  constructor(private readonly grpc: GrpcClientsService) {}

  @Post()
  @HttpCode(HttpStatus.ACCEPTED)
  @RateLimit(10, 60)
  async create(
    @Req() req: AuthedRequest,
    @Body() dto: CreateOrderDto,
    @Headers('idempotency-key') idempotencyKey: string,
  ) {
    const meta = this.grpc.buildMetadata(
      req.headers['x-request-id'] as string,
      req.user.userId,
      req.user.accountId,
    );
    return this.grpc.createOrder(
      { ...dto, accountId: req.user.accountId, idempotencyKey },
      meta,
    );
  }

  @Get()
  async list(@Req() req: AuthedRequest) {
    const meta = this.grpc.buildMetadata(
      req.headers['x-request-id'] as string,
      req.user.userId,
      req.user.accountId,
    );
    return this.grpc.listOrders({ accountId: req.user.accountId }, meta);
  }

  @Delete(':id')
  async cancel(@Req() req: AuthedRequest, @Param('id') id: string) {
    const meta = this.grpc.buildMetadata(
      req.headers['x-request-id'] as string,
      req.user.userId,
      req.user.accountId,
    );
    return this.grpc.cancelOrder({ orderId: id, accountId: req.user.accountId }, meta);
  }
}

filters/grpc-exception.filter.ts — map gRPC status → HTTP status​

import { Catch, ArgumentsHost, Logger } from '@nestjs/common';
import { BaseExceptionFilter } from '@nestjs/core';
import { RpcException } from '@nestjs/microservices';
import { status as GrpcStatus } from '@grpc/grpc-js';
import { Response, Request } from 'express';

const GRPC_TO_HTTP: Record<number, number> = {
  [GrpcStatus.OK]:                  200,
  [GrpcStatus.INVALID_ARGUMENT]:    400,
  [GrpcStatus.UNAUTHENTICATED]:     401,
  [GrpcStatus.PERMISSION_DENIED]:   403,
  [GrpcStatus.NOT_FOUND]:           404,
  [GrpcStatus.ALREADY_EXISTS]:      409,
  [GrpcStatus.RESOURCE_EXHAUSTED]:  429,
  [GrpcStatus.UNIMPLEMENTED]:       501,
  [GrpcStatus.UNAVAILABLE]:         503,
  [GrpcStatus.DEADLINE_EXCEEDED]:   504,
};

@Catch(RpcException)
export class GrpcExceptionFilter extends BaseExceptionFilter {
  private readonly logger = new Logger(GrpcExceptionFilter.name);

  catch(exception: RpcException, host: ArgumentsHost) {
    const ctx  = host.switchToHttp();
    const res  = ctx.getResponse<Response>();
    const req  = ctx.getRequest<Request>();
    const err  = exception.getError() as { code?: number; message?: string };

    const httpStatus = GRPC_TO_HTTP[err.code ?? GrpcStatus.UNKNOWN] ?? 500;

    if (httpStatus >= 500) {
      this.logger.error(`gRPC error code=${err.code} msg=${err.message}`);
    }

    res.status(httpStatus).json({
      statusCode: httpStatus,
      message: err.message ?? 'Internal server error',
      requestId: req.headers['x-request-id'],
      timestamp: new Date().toISOString(),
    });
  }
}

## Security Controls

| Control | Implementation |
|---|---|
| JWT authentication | `passport-jwt` strategy — validates signature, expiry, and required claims (`sub`, `accountId`) on every non-public route |
| Public route opt-out | `@Public()` decorator sets `isPublic` metadata; `JwtAuthGuard` skips Passport for those routes. Used only for `POST /v1/auth/register` and `POST /v1/auth/login` |
| Rate limiting | Sliding-window per `userId:endpoint` in Redis — prevents brute-force and abuse |
| CORS | Strict `origin` allowlist from `ALLOWED_ORIGINS` env var; credentials: true for cookie-based refresh |
| No PII in logs | `GlobalExceptionFilter` never logs request body; `TracingInterceptor` only logs `requestId` |
| HTTPS enforcement | TLS terminated at Traefik ingress; gateway runs plain HTTP to clients inside the cluster |
| mTLS for gRPC | TLS certificates managed by Cilium / cert-manager for gateway ↔ service gRPC channels inside the cluster |
| Secrets | `JWT_SECRET` and gRPC URLs injected via GCP Secret Manager / env vars — never hardcoded |

## Rate Limit Configuration

Default limits — override per route with `@RateLimit(n, windowSec)`:

| Endpoint group | Limit | Window |
|---|---|---|
| `POST /v1/auth/login` | 10 requests | 60 s (brute-force protection) |
| `POST /v1/orders` | 10 requests | 60 s |
| `GET /v1/quotes/*` | 120 requests | 60 s |
| All other endpoints | 60 requests | 60 s |

## Observability

| Signal | Detail |
|---|---|
| Trace | Every request starts an OTel span tagged `http.method`, `http.route`, `user.id`, `request.id`; child gRPC span created per downstream call with `rpc.service`, `rpc.method` attributes |
| Metrics | `gw_requests_total{method,route,status}`, `gw_request_duration_ms{route}`, `gw_rate_limit_rejected_total{route}`, `gw_grpc_errors_total{service,grpc_code}` |
| Logs | Structured JSON: `{ requestId, userId, method, path, status, durationMs, grpcService, grpcMethod }` on response |
| Alerts | Rate-limit rejection rate > 5% of traffic; gRPC `UNAVAILABLE` / `DEADLINE_EXCEEDED` rate > 1%; p99 gateway overhead > 50 ms |
