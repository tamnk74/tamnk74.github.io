Building an Ecommerce Chatbot with Booking Capabilities

Overview​

This comprehensive guide walks you through building an AI-powered chatbot that enables users to chat naturally and make bookings on an ecommerce website. The chatbot understands user intent, handles booking workflows, manages availability, and provides a seamless conversational experience.

Key Features:

  • 🤖 Natural Language Understanding - AI-powered intent recognition and slot filling
  • 📅 Booking Management - Service/appointment scheduling with availability checks
  • 💬 Real-time Chat - WebSocket-based messaging with typing indicators
  • 🔄 Context Awareness - Multi-turn conversation handling
  • 📊 Analytics - Conversation tracking and booking insights
  • 🌐 Multi-channel - Web widget, mobile app, and API integration

Alternative Technology Stacks​

While this guide uses LangChain + OpenAI, there are several excellent alternatives for building chatbot systems. Choose based on your requirements for cost, privacy, performance, and enterprise support.

1. Anthropic Claude 3.5 Sonnet​

Best for: Advanced reasoning, safety-focused applications, complex booking logic

Advantages:

  • Superior instruction following and reasoning
  • 200K token context window
  • Strong safety guardrails
  • Excellent at maintaining conversation context
  • Better at handling edge cases

Implementation:

import Anthropic from '@anthropic-ai/sdk';

const anthropic = new Anthropic({
  apiKey: process.env.ANTHROPIC_API_KEY,
});

// In your intent.service.ts
async classifyIntent(message: string, context?: Record<string, any>): Promise<IntentResult> {
  const systemPrompt = `You are an intent classifier for a booking chatbot.
Available intents: greeting, book_service, check_availability, cancel_booking, etc.`;

  const response = await anthropic.messages.create({
    model: 'claude-3-5-sonnet-20241022',
    max_tokens: 1024,
    system: systemPrompt,
    messages: [
      {
        role: 'user',
        content: `Context: ${JSON.stringify(context)}\n\nUser message: "${message}"\n\nClassify intent and extract entities in JSON format.`
      }
    ],
  });

  return JSON.parse(response.content[0].text);
}

Pricing: 3.00/1Minputtokens,3.00/1M input tokens, 3.00/1Minputtokens,15.00/1M output tokens

2. Google Vertex AI + Gemini​

Best for: GCP users, multimodal applications (text + images), enterprise compliance

Advantages:

  • Native GCP integration
  • Multimodal support (can process service images, booking confirmations)
  • Cost-effective (0.075−0.075-0.075−0.30/1M input tokens)
  • Enterprise-grade security
  • Fast inference with Gemini Flash

Implementation:

import { VertexAI } from '@google-cloud/vertexai';

const vertexAI = new VertexAI({
  project: process.env.GCP_PROJECT_ID,
  location: 'us-central1',
});

// In your intent.service.ts
async classifyIntent(message: string, context?: Record<string, any>): Promise<IntentResult> {
  const model = vertexAI.getGenerativeModel({
    model: 'gemini-2.5-flash',
    generationConfig: {
      maxOutputTokens: 1024,
      temperature: 0,
    },
  });

  const prompt = `You are an intent classifier for a booking chatbot.
Context: ${JSON.stringify(context)}
User message: "${message}"

Classify the intent and extract entities. Return JSON only.`;

  const result = await model.generateContent(prompt);
  const response = result.response.text();
  return JSON.parse(response);
}

Pricing: Gemini Flash: 0.075/1Minput,0.075/1M input, 0.075/1Minput,0.30/1M output tokens

Related Guide: Vertex AI Gemini Guide

3. LlamaIndex + Local Models (Ollama)​

Best for: Privacy-focused deployments, cost-sensitive projects, on-premise requirements

Advantages:

  • Complete data privacy (no data leaves your infrastructure)
  • Zero API costs
  • Full control over model and updates
  • Works offline
  • Good for development and testing

Implementation:

# Install Ollama
curl -fsSL https://ollama.com/install.sh | sh

# Pull model

import { Ollama } from '@langchain/community/llms/ollama';

  baseUrl: 'http://localhost:11434',
  model: 'llama3.1:8b',
  temperature: 0,
});

async classifyIntent(message: string): Promise<IntentResult> {
  const prompt = `Classify this booking request: "${message}"
Return JSON with intent and entities.`;

  const response = await llm.invoke(prompt);
  return JSON.parse(response);
}

Recommended Models:

  • llama3.1:8b - Best balance (4.7GB)
  • mistral:7b - Fast inference (4.1GB)
  • mixtral:8x7b - High quality (26GB)

Pricing: Free (infrastructure costs only)

Related Guide: LlamaIndex + Local Models Guide

4. Azure OpenAI Service​

Best for: Microsoft ecosystem, enterprise compliance, private networking

Advantages:

  • Enterprise SLAs and support
  • Data residency options
  • Azure integration (AAD, KeyVault, Monitor)
  • Private endpoints via Azure Private Link
  • Same models as OpenAI (GPT-4, GPT-3.5)

Implementation:

import { AzureOpenAI } from 'openai';

const client = new AzureOpenAI({
  apiKey: process.env.AZURE_OPENAI_API_KEY,
  endpoint: process.env.AZURE_OPENAI_ENDPOINT,
  apiVersion: '2024-02-15-preview',
  deployment: 'gpt-4', // Your deployment name
});

async classifyIntent(message: string): Promise<IntentResult> {
  const response = await client.chat.completions.create({
    messages: [
      {
        role: 'system',
        content: 'You are an intent classifier for a booking chatbot.'
      },
      {
        role: 'user',
        content: message
      }
    ],
    temperature: 0,
    response_format: { type: 'json_object' },
  });

  return JSON.parse(response.choices[0].message.content);
}

Pricing: Same as OpenAI, with enterprise discounts available

Decision Framework​

Choose Anthropic Claude if:​

  • ✅ You need the best reasoning and instruction following
  • ✅ Handling complex, multi-step booking flows
  • ✅ Safety and compliance are priorities
  • ✅ Budget allows for premium pricing

Choose Google Gemini if:​

  • ✅ You're on GCP or want multimodal capabilities
  • ✅ Cost optimization is important
  • ✅ You need fast response times
  • ✅ Enterprise support required

Choose Local Models (Ollama) if:​

  • ✅ Data privacy is non-negotiable
  • ✅ Want to eliminate API costs
  • ✅ Have GPU infrastructure available
  • ✅ Building for on-premise deployment

Choose Azure OpenAI if:​

  • ✅ You're in Microsoft ecosystem
  • ✅ Need enterprise SLAs and compliance
  • ✅ Require private networking
  • ✅ Multi-region deployment needed

Choose vLLM if:​

  • ✅ High-volume production deployment (>1M requests/month)
  • ✅ Need performance optimization
  • ✅ Have GPU infrastructure and DevOps expertise
  • ✅ Want full control over stack

3.1 Intent Classification​

Create src/ai/intent.service.ts:

import { Injectable } from '@nestjs/common';
import { ChatOpenAI } from '@langchain/openai';
import { PromptTemplate } from '@langchain/core/prompts';
import { StructuredOutputParser } from 'langchain/output_parsers';
import { z } from 'zod';

export enum Intent {
  GREETING = 'greeting',
  BOOK_SERVICE = 'book_service',
  CHECK_AVAILABILITY = 'check_availability',
  CANCEL_BOOKING = 'cancel_booking',
  MODIFY_BOOKING = 'modify_booking',
  VIEW_BOOKINGS = 'view_bookings',
  GET_INFO = 'get_info',
  CONFIRM = 'confirm',
  DENY = 'deny',
  UNKNOWN = 'unknown',
}

interface IntentResult {
  intent: Intent;
  confidence: number;
  entities: Record<string, any>;
}

@Injectable()
export class IntentService {
  private llm: ChatOpenAI;
  private parser: StructuredOutputParser<any>;

  constructor() {
    this.llm = new ChatOpenAI({
      modelName: 'gpt-4o-mini',
      temperature: 0,
    });

    this.parser = StructuredOutputParser.fromZodSchema(
      z.object({
        intent: z.nativeEnum(Intent),
        confidence: z.number().min(0).max(1),
        entities: z.object({
          service: z.string().optional(),
          date: z.string().optional(),
          time: z.string().optional(),
          duration: z.number().optional(),
          name: z.string().optional(),
          email: z.string().optional(),
          phone: z.string().optional(),
        }),
      }),
    );
  }

  async classifyIntent(message: string, context?: Record<string, any>): Promise<IntentResult> {
    const prompt = PromptTemplate.fromTemplate(`
You are an intent classifier for an ecommerce booking chatbot.
Analyze the user message and extract the intent and relevant entities.

Available intents:
- greeting: User says hello or starts conversation
- book_service: User wants to book a service/appointment
- check_availability: User asks about available times
- cancel_booking: User wants to cancel existing booking
- modify_booking: User wants to change existing booking
- view_bookings: User wants to see their bookings
- get_info: User asks about services, prices, etc.
- confirm: User confirms an action
- deny: User declines or says no
- unknown: Cannot determine intent

Current conversation context:
{context}

User message: "{message}"

{format_instructions}
`);

    const formattedPrompt = await prompt.format({
      message,
      context: JSON.stringify(context || {}),
      format_instructions: this.parser.getFormatInstructions(),
    });

    const response = await this.llm.invoke(formattedPrompt);
    return this.parser.parse(response.content as string);
  }
}

3.2 Slot Extraction Service​

Create src/ai/slot-extractor.service.ts:

import { Injectable } from '@nestjs/common';
import { ChatOpenAI } from '@langchain/openai';
import { PromptTemplate } from '@langchain/core/prompts';
import * as dayjs from 'dayjs';
import * as customParseFormat from 'dayjs/plugin/customParseFormat';
import * as relativeTime from 'dayjs/plugin/relativeTime';

dayjs.extend(customParseFormat);
dayjs.extend(relativeTime);

export interface BookingSlots {
  service?: string;
  date?: string;
  time?: string;
  customerName?: string;
  customerEmail?: string;
  customerPhone?: string;
  notes?: string;
}

@Injectable()
export class SlotExtractorService {
  private llm: ChatOpenAI;

  constructor() {
    this.llm = new ChatOpenAI({
      modelName: 'gpt-4o-mini',
      temperature: 0,
    });
  }

  async extractSlots(message: string, existingSlots: BookingSlots = {}): Promise<BookingSlots> {
    const prompt = PromptTemplate.fromTemplate(`
Extract booking information from the user message.
Only extract information that is explicitly mentioned.
Normalize dates to YYYY-MM-DD format and times to HH:mm format.

Today's date: {today}

Existing slots: {existingSlots}

User message: "{message}"

Return a JSON object with these fields (only include fields found in the message):
- service: the service name
- date: date in YYYY-MM-DD format
- time: time in HH:mm format
- customerName: customer's full name
- customerEmail: email address
- customerPhone: phone number
- notes: any special requests

JSON output (no markdown):
`);

    const formattedPrompt = await prompt.format({
      message,
      today: dayjs().format('YYYY-MM-DD'),
      existingSlots: JSON.stringify(existingSlots),
    });

    const response = await this.llm.invoke(formattedPrompt);
    const content = (response.content as string).trim();

    try {
      const extracted = JSON.parse(content);
      return this.normalizeSlots({ ...existingSlots, ...extracted });
    } catch {
      return existingSlots;
    }
  }

  private normalizeSlots(slots: BookingSlots): BookingSlots {
    const normalized = { ...slots };

    // Normalize relative dates
    if (normalized.date) {
      const dateStr = normalized.date.toLowerCase();
      if (dateStr === 'today') {
        normalized.date = dayjs().format('YYYY-MM-DD');
      } else if (dateStr === 'tomorrow') {
        normalized.date = dayjs().add(1, 'day').format('YYYY-MM-DD');
      }
    }

    return normalized;
  }

  getMissingRequiredSlots(slots: BookingSlots): string[] {
    const required = ['service', 'date', 'time', 'customerName', 'customerEmail'];
    return required.filter((slot) => !slots[slot as keyof BookingSlots]);
  }
}

3.3 Dialog Manager​

Create src/ai/dialog-manager.service.ts:

import { Injectable } from '@nestjs/common';
import { IntentService, Intent } from './intent.service';
import { SlotExtractorService, BookingSlots } from './slot-extractor.service';
import { ResponseGeneratorService } from './response-generator.service';
import { BookingService } from '../booking/booking.service';
import { AvailabilityService } from '../booking/availability.service';

export interface DialogState {
  currentIntent: Intent;
  slots: BookingSlots;
  stage: 'collecting' | 'confirming' | 'complete';
  pendingQuestion?: string;
}

export interface DialogResponse {
  message: string;
  state: DialogState;
  actions?: Array<{
    type: 'button' | 'datepicker' | 'timepicker';
    label: string;
    value: string;
  }>;
  booking?: any;
}

@Injectable()
export class DialogManagerService {
  constructor(
    private intentService: IntentService,
    private slotExtractor: SlotExtractorService,
    private responseGenerator: ResponseGeneratorService,
    private bookingService: BookingService,
    private availabilityService: AvailabilityService,
  ) {}

  async processMessage(message: string, conversationContext: Record<string, any>): Promise<DialogResponse> {
    const state: DialogState = conversationContext.dialogState || {
      currentIntent: Intent.UNKNOWN,
      slots: {},
      stage: 'collecting',
    };

    // Classify intent
    const intentResult = await this.intentService.classifyIntent(message, conversationContext);

    // Handle confirmation/denial for pending confirmations
    if (state.stage === 'confirming') {
      if (intentResult.intent === Intent.CONFIRM) {
        return this.createBooking(state);
      } else if (intentResult.intent === Intent.DENY) {
        return {
          message: 'No problem! Would you like to book a different time or service?',
          state: { ...state, stage: 'collecting', slots: {} },
        };
      }
    }

    // Update intent if new booking flow
    if (intentResult.intent === Intent.BOOK_SERVICE) {
      state.currentIntent = Intent.BOOK_SERVICE;
    }

    // Extract slots
    const extractedSlots = await this.slotExtractor.extractSlots(message, state.slots);
    state.slots = { ...state.slots, ...extractedSlots, ...intentResult.entities };

    // Check what's missing
    const missingSlots = this.slotExtractor.getMissingRequiredSlots(state.slots);

    if (missingSlots.length === 0) {
      // All slots filled, check availability
      const isAvailable = await this.availabilityService.checkSlot(
        state.slots.date!,
        state.slots.time!,
        state.slots.service!,
      );

      if (isAvailable) {
        state.stage = 'confirming';
        const summary = this.formatBookingSummary(state.slots);
        return {
          message: `Great! Here's your booking summary:\n\n${summary}\n\nWould you like to confirm this booking?`,
          state,
          actions: [
            { type: 'button', label: 'Confirm', value: 'confirm' },
            { type: 'button', label: 'Cancel', value: 'cancel' },
          ],
        };
      } else {
        const alternatives = await this.availabilityService.getAlternativeSlots(
          state.slots.date!,
          state.slots.service!,
        );
        return {
          message: `Sorry, that time slot is not available. Here are some alternatives:\n\n${alternatives.map((s) => `• ${s}`).join('\n')}\n\nWhich time works for you?`,
          state,
          actions: alternatives.map((slot) => ({
            type: 'button' as const,
            label: slot,
            value: slot,
          })),
        };
      }
    }

    // Ask for next missing slot
    const response = await this.responseGenerator.generateSlotPrompt(missingSlots[0], state.slots);

    return { message: response, state };
  }

  private async createBooking(state: DialogState): Promise<DialogResponse> {
    try {
      const booking = await this.bookingService.createFromSlots(state.slots);
      return {
        message: `✅ Your booking is confirmed!\n\n📅 ${state.slots.date} at ${state.slots.time}\n💇 ${state.slots.service}\n\nWe've sent a confirmation email to ${state.slots.customerEmail}. See you soon!`,
        state: { ...state, stage: 'complete' },
        booking,
      };
    } catch (error) {
      return {
        message: 'Sorry, there was an error creating your booking. Please try again.',
        state: { ...state, stage: 'collecting' },
      };
    }
  }

  private formatBookingSummary(slots: BookingSlots): string {
    return `📅 Date: ${slots.date}
⏰ Time: ${slots.time}
💇 Service: ${slots.service}
👤 Name: ${slots.customerName}
📧 Email: ${slots.customerEmail}`;
  }
}

        .filter(([_, v]) => v)
        .map(([k, v]) => `${k}: ${v}`)
        .join(', ');

    }

  }

Generate a helpful, concise response for the following situation:

Intent: ${intent}
Context: ${JSON.stringify(context)}

Keep the response under 2 sentences and maintain a friendly, professional tone.
`);

import {
  WebSocketGateway,
  WebSocketServer,
  SubscribeMessage,
  OnGatewayConnection,
  OnGatewayDisconnect,
  MessageBody,
  ConnectedSocket,
} from '@nestjs/websockets';
import { Server, Socket } from 'socket.io';
import { ChatService } from './chat.service';
import { DialogManagerService } from '../ai/dialog-manager.service';
import { v4 as uuidv4 } from 'uuid';

interface ChatMessage {
  conversationId?: string;
  content: string;
  userId?: string;
}

@WebSocketGateway({
  cors: {
    origin: '*',
  },
  namespace: '/chat',
})
export class ChatGateway implements OnGatewayConnection, OnGatewayDisconnect {
  @WebSocketServer()
  server: Server;

  private activeSessions: Map<string, string> = new Map(); // socketId -> conversationId

  constructor(
    private chatService: ChatService,
    private dialogManager: DialogManagerService,
  ) {}

  async handleConnection(client: Socket) {
    console.log(`Client connected: ${client.id}`);

    // Create new conversation
    const conversationId = uuidv4();
    this.activeSessions.set(client.id, conversationId);

    await this.chatService.createConversation(conversationId, client.id);

    // Send welcome message
    client.emit('message', {
      role: 'bot',
      content: "👋 Hello! I'm your booking assistant. How can I help you today?",
      conversationId,
      timestamp: new Date().toISOString(),
    });
  }

  async handleDisconnect(client: Socket) {
    console.log(`Client disconnected: ${client.id}`);
    const conversationId = this.activeSessions.get(client.id);

    if (conversationId) {
      await this.chatService.endConversation(conversationId);
      this.activeSessions.delete(client.id);
    }
  }

  @SubscribeMessage('message')
  async handleMessage(@MessageBody() data: ChatMessage, @ConnectedSocket() client: Socket) {
    const conversationId = this.activeSessions.get(client.id);

    if (!conversationId) {
      client.emit('error', { message: 'No active conversation' });
      return;
    }

    // Emit typing indicator
    client.emit('typing', { isTyping: true });

    try {
      // Save user message
      await this.chatService.saveMessage(conversationId, 'user', data.content);

      // Get conversation context
      const context = await this.chatService.getConversationContext(conversationId);

      // Process with dialog manager
      const response = await this.dialogManager.processMessage(data.content, context);

      // Update conversation context
      await this.chatService.updateContext(conversationId, {
        dialogState: response.state,
      });

      // Save bot message
      await this.chatService.saveMessage(conversationId, 'bot', response.message, {
        intent: response.state.currentIntent,
        slots: response.state.slots,
      });

      // Stop typing indicator
      client.emit('typing', { isTyping: false });

      // Send response
      client.emit('message', {
        role: 'bot',
        content: response.message,
        conversationId,
        timestamp: new Date().toISOString(),
        actions: response.actions,
        booking: response.booking,
      });
    } catch (error) {
      client.emit('typing', { isTyping: false });
      client.emit('error', { message: 'Failed to process message' });
      console.error('Chat error:', error);
    }
  }

  @SubscribeMessage('action')
  async handleAction(@MessageBody() data: { action: string; value: string }, @ConnectedSocket() client: Socket) {
    // Handle button clicks as messages
    return this.handleMessage({ content: data.value }, client);
  }
}

import { Injectable, NotFoundException } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository, Between } from 'typeorm';
import { Booking, BookingStatus } from './entities/booking.entity';
import { Service } from './entities/service.entity';
import { BookingSlots } from '../ai/slot-extractor.service';
import { NotificationService } from '../notification/notification.service';
import * as dayjs from 'dayjs';

@Injectable()
export class BookingService {
  constructor(
    @InjectRepository(Booking)
    private bookingRepository: Repository<Booking>,
    @InjectRepository(Service)
    private serviceRepository: Repository<Service>,
    private notificationService: NotificationService,
  ) {}

  async createFromSlots(slots: BookingSlots): Promise<Booking> {
    // Find service
    const service = await this.serviceRepository.findOne({
      where: { name: slots.service, isActive: true },
    });

    if (!service) {
      throw new NotFoundException(`Service "${slots.service}" not found`);
    }

    // Parse date and time
    const scheduledAt = dayjs(`${slots.date} ${slots.time}`).toDate();

    // Create booking
    const booking = this.bookingRepository.create({
      serviceId: service.id,
      customerName: slots.customerName!,
      customerEmail: slots.customerEmail!,
      customerPhone: slots.customerPhone,
      scheduledAt,
      duration: service.duration,
      status: BookingStatus.CONFIRMED,
      notes: slots.notes,
    });

    const savedBooking = await this.bookingRepository.save(booking);

    // Send confirmation email
    await this.notificationService.sendBookingConfirmation(savedBooking, service);

    return savedBooking;
  }

  async findByDateRange(startDate: Date, endDate: Date): Promise<Booking[]> {
    return this.bookingRepository.find({
      where: {
        scheduledAt: Between(startDate, endDate),
        status: BookingStatus.CONFIRMED,
      },
      relations: ['service'],
      order: { scheduledAt: 'ASC' },
    });
  }

  async cancel(id: string): Promise<Booking> {
    const booking = await this.bookingRepository.findOne({
      where: { id },
      relations: ['service'],
    });

    if (!booking) {
      throw new NotFoundException('Booking not found');
    }

    booking.status = BookingStatus.CANCELLED;
    const savedBooking = await this.bookingRepository.save(booking);

    await this.notificationService.sendBookingCancellation(savedBooking);

    return savedBooking;
  }

  async getUpcoming(userId: string): Promise<Booking[]> {
    return this.bookingRepository.find({
      where: {
        userId,
        scheduledAt: Between(new Date(), dayjs().add(30, 'day').toDate()),
        status: BookingStatus.CONFIRMED,
      },
      relations: ['service'],
      order: { scheduledAt: 'ASC' },
    });
  }
}

Create src/booking/availability.service.ts:

import { Injectable } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository, Between } from 'typeorm';
import { Booking, BookingStatus } from './entities/booking.entity';
import { Service } from './entities/service.entity';
import * as dayjs from 'dayjs';

@Injectable()
export class AvailabilityService {
  constructor(
    @InjectRepository(Booking)
    private bookingRepository: Repository<Booking>,
    @InjectRepository(Service)
    private serviceRepository: Repository<Service>,
  ) {}

  async checkSlot(date: string, time: string, serviceName: string): Promise<boolean> {
    const service = await this.serviceRepository.findOne({
      where: { name: serviceName, isActive: true },
    });

    if (!service) return false;

    const slotStart = dayjs(`${date} ${time}`);
    const slotEnd = slotStart.add(service.duration, 'minute');

    // Check if within business hours
    const dayOfWeek = slotStart.day();
    if (!service.availability?.daysOfWeek?.includes(dayOfWeek)) {
      return false;
    }

    const startTime = dayjs(`${date} ${service.availability.startTime}`);
    const endTime = dayjs(`${date} ${service.availability.endTime}`);

    if (slotStart.isBefore(startTime) || slotEnd.isAfter(endTime)) {
      return false;
    }

    // Check for conflicting bookings
    const conflicting = await this.bookingRepository.find({
      where: {
        scheduledAt: Between(slotStart.subtract(service.duration, 'minute').toDate(), slotEnd.toDate()),
        status: BookingStatus.CONFIRMED,
      },
    });

    return conflicting.length === 0;
  }

  async getAlternativeSlots(date: string, serviceName: string, count: number = 5): Promise<string[]> {
    const service = await this.serviceRepository.findOne({
      where: { name: serviceName, isActive: true },
    });

    if (!service) return [];

    const alternatives: string[] = [];
    const startTime = dayjs(`${date} ${service.availability?.startTime || '09:00'}`);
    const endTime = dayjs(`${date} ${service.availability?.endTime || '18:00'}`);

    let currentSlot = startTime;

    while (currentSlot.isBefore(endTime) && alternatives.length < count) {
      const timeStr = currentSlot.format('HH:mm');
      const isAvailable = await this.checkSlot(date, timeStr, serviceName);

      if (isAvailable) {
        alternatives.push(timeStr);
      }

      currentSlot = currentSlot.add(30, 'minute'); // 30-min intervals
    }

    return alternatives;
  }

  async getAvailableDates(serviceName: string, startDate: string, days: number = 7): Promise<string[]> {
    const service = await this.serviceRepository.findOne({
      where: { name: serviceName, isActive: true },
    });

    if (!service) return [];

    const availableDates: string[] = [];
    let currentDate = dayjs(startDate);

    for (let i = 0; i < days; i++) {
      const dayOfWeek = currentDate.day();

      if (service.availability?.daysOfWeek?.includes(dayOfWeek)) {
        const dateStr = currentDate.format('YYYY-MM-DD');
        const slots = await this.getAlternativeSlots(dateStr, serviceName, 1);

        if (slots.length > 0) {
          availableDates.push(dateStr);
        }
      }

      currentDate = currentDate.add(1, 'day');
    }

    return availableDates;
  }
}

import React, { useState, useEffect, useRef } from 'react';
import { io, Socket } from 'socket.io-client';
import './ChatWidget.css';

interface Message {
  role: 'user' | 'bot';
  content: string;
  timestamp: string;
  actions?: Array<{
    type: 'button';
    label: string;
    value: string;

interface ChatWidgetProps {

  primaryColor?: string;

export const ChatWidget: React.FC<ChatWidgetProps> = ({
  serverUrl,
  position = 'bottom-right',
  primaryColor = '#8b5cf6',
}) => {
  const [isOpen, setIsOpen] = useState(false);
  const [messages, setMessages] = useState<Message[]>([]);
  const [input, setInput] = useState('');
  const [isTyping, setIsTyping] = useState(false);
  const [socket, setSocket] = useState<Socket | null>(null);
  const messagesEndRef = useRef<HTMLDivElement>(null);

  useEffect(() => {
    const newSocket = io(`${serverUrl}/chat`, {
      transports: ['websocket'],
    });

    newSocket.on('connect', () => {
      console.log('Connected to chat server');
    });

    newSocket.on('message', (message: Message) => {
      setMessages((prev) => [...prev, message]);
    });

    newSocket.on('typing', ({ isTyping }: { isTyping: boolean }) => {
      setIsTyping(isTyping);
    });

    newSocket.on('error', (error: { message: string }) => {
      console.error('Chat error:', error.message);
    });

    setSocket(newSocket);

    return () => {
      newSocket.close();
    };

    messagesEndRef.current?.scrollIntoView({ behavior: 'smooth' });

    const userMessage: Message = {
      role: 'user',
      content: input,
      timestamp: new Date().toISOString(),
    };

    setMessages((prev) => [...prev, userMessage]);
    socket.emit('message', { content: input });
    setInput('');

    if (!socket) return;

    const userMessage: Message = {
      role: 'user',
      content: value,
      timestamp: new Date().toISOString(),
    };

    setMessages((prev) => [...prev, userMessage]);
    socket.emit('action', { action: 'click', value });
  };

    if (e.key === 'Enter' && !e.shiftKey) {
      e.preventDefault();
      sendMessage();
    }
  };

          </svg>
        )}
      </button>

      {/* Chat Window */}
      {isOpen && (
        <div className="chat-window">
          <div className="chat-header" style={{ backgroundColor: primaryColor }}>
            <span>💬 Booking Assistant</span>
          </div>

          <div className="chat-messages">
            {messages.map((msg, idx) => (
              <div key={idx} className={`message ${msg.role}`}>
                <div className="message-content">{msg.content}</div>
                {msg.actions && (
                  <div className="message-actions">

                      </button>
                    ))}
                  </div>
                )}
              </div>
            ))}
            {isTyping && (
              <div className="message bot">
                <div className="typing-indicator">
                  <span></span>
                  <span></span>
                  <span></span>
                </div>
              </div>
            )}
            <div ref={messagesEndRef} />
          </div>

            <input
              type="text"
              value={input}
              onChange={(e) => setInput(e.target.value)}
              onKeyPress={handleKeyPress}
              placeholder="Type your message..."
            />
            <button onClick={sendMessage} style={{ backgroundColor: primaryColor }}>
              Send
            </button>
          </div>
        </div>
      )}
    </div>
  );
};

Step 9: Testing with Playwright​

Create e2e/chat-booking.spec.ts:

import { test, expect } from '@playwright/test';

test.describe('Chatbot Booking Flow', () => {
  test.beforeEach(async ({ page }) => {
    await page.goto('/');
  });

  test('should complete full booking flow', async ({ page }) => {
    // Open chat widget
    await page.click('.chat-toggle');
    await expect(page.locator('.chat-window')).toBeVisible();

    // Wait for welcome message
    await expect(page.locator('.message.bot')).toContainText('Hello');

    // Start booking
    await page.fill('.chat-input input', 'I want to book a haircut');
    await page.click('.chat-input button');

    // Wait for bot response asking for date
    await expect(page.locator('.message.bot').last()).toContainText('date', {
      timeout: 10000,
    });

    // Provide date
    await page.fill('.chat-input input', 'tomorrow');
    await page.click('.chat-input button');

    // Wait for time prompt
    await expect(page.locator('.message.bot').last()).toContainText('time', {
      timeout: 10000,
    });

    // Provide time
    await page.fill('.chat-input input', '2pm');
    await page.click('.chat-input button');

    // Provide name
    await page.fill('.chat-input input', 'John Doe');
    await page.click('.chat-input button');

    // Provide email
    await page.fill('.chat-input input', 'john@example.com');
    await page.click('.chat-input button');

    // Wait for confirmation
    await expect(page.locator('.message.bot').last()).toContainText('confirm', {
      timeout: 10000,
    });

    // Click confirm button
    await page.click('.action-button:has-text("Confirm")');

    // Verify booking success
    await expect(page.locator('.message.bot').last()).toContainText('confirmed', { timeout: 10000 });
  });

  test('should handle unavailable slots', async ({ page }) => {
    await page.click('.chat-toggle');

    await page.fill('.chat-input input', 'Book a haircut for today at 11pm');
    await page.click('.chat-input button');

    // Should offer alternatives
    await expect(page.locator('.message.bot').last()).toContainText('alternative', { timeout: 10000 });
  });
});
