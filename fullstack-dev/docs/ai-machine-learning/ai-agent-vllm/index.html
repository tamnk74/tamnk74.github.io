Building AI Document Wiki Agent with vLLM

Overview​

This guide demonstrates building a production-grade, high-performance AI documentation agent using vLLM - a fast and easy-to-use library for LLM inference and serving. vLLM achieves high throughput serving with efficient memory management and continuous batching.

Pros:

  • ✅ Extremely high throughput (up to 24x faster than HuggingFace Transformers)
  • ✅ Efficient memory usage with PagedAttention
  • ✅ Supports continuous batching for multiple concurrent users
  • ✅ Production-ready with OpenAI-compatible API
  • ✅ Easy scaling and deployment
  • ✅ Supports quantization (AWQ, GPTQ, SqueezeLLM)

Cons:

  • ❌ Requires GPU (CUDA required)
  • ❌ More complex setup than simple solutions
  • ❌ Limited to supported model architectures
  • ❌ Higher resource requirements than basic inference

Prerequisites​

  • GPU: NVIDIA GPU with compute capability 7.0+ (V100, T4, A100, etc.)
  • CUDA: Version 11.8 or higher
  • Memory: 16GB+ VRAM for 7B models, 32GB+ for 13B models
  • Python: 3.8 to 3.11
  • OS: Linux (Ubuntu 20.04+) or Windows with WSL2

Step 4: Document Ingestion​

Create src/ingestion/ingest.py:

import os
from pathlib import Path
from typing import List
from qdrant_client import QdrantClient
from qdrant_client.models import Distance, VectorParams, PointStruct
from fastembed import TextEmbedding
import json
from tqdm import tqdm

class DocumentIngestion:
    def __init__(self, config: dict):
        self.config = config
        self.embedding_model = TextEmbedding(
            model_name=config['embedding_model']
        )
        self.qdrant = QdrantClient(
            host=config['qdrant_host'],
            port=config['qdrant_port']
        )
        self.collection_name = config['collection_name']

    def load_documents(self, docs_path: str) -> List[dict]:
        """Load documents from directory"""
        documents = []
        docs_dir = Path(docs_path)

        for file_path in docs_dir.rglob("*.md"):
            with open(file_path, 'r', encoding='utf-8') as f:
                content = f.read()
                documents.append({
                    'content': content,
                    'source': str(file_path),
                    'type': 'markdown'
                })

        print(f"Loaded {len(documents)} documents")
        return documents

    def chunk_documents(self, documents: List[dict],
                       chunk_size: int = 512) -> List[dict]:
        """Split documents into chunks"""
        chunks = []

        for doc in documents:
            content = doc['content']
            words = content.split()

            for i in range(0, len(words), chunk_size - 50):
                chunk_text = ' '.join(words[i:i + chunk_size])
                chunks.append({
                    'text': chunk_text,
                    'source': doc['source'],
                    'chunk_id': len(chunks)
                })

        print(f"Created {len(chunks)} chunks")
        return chunks

    def create_collection(self):
        """Create or recreate Qdrant collection"""
        try:
            self.qdrant.delete_collection(self.collection_name)
        except:
            pass

        self.qdrant.create_collection(
            collection_name=self.collection_name,
            vectors_config=VectorParams(
                size=384,  # BGE-small dimension
                distance=Distance.COSINE
            )
        )
        print(f"Collection '{self.collection_name}' created")

    def ingest(self, docs_path: str):
        """Main ingestion pipeline"""
        # Load and chunk
        documents = self.load_documents(docs_path)
        chunks = self.chunk_documents(documents)

        # Create collection
        self.create_collection()

        # Embed and store
        texts = [chunk['text'] for chunk in chunks]
        print("Generating embeddings...")

        batch_size = 32
        for i in tqdm(range(0, len(texts), batch_size)):
            batch_texts = texts[i:i + batch_size]
            batch_chunks = chunks[i:i + batch_size]

            # Generate embeddings
            embeddings = list(self.embedding_model.embed(batch_texts))

            # Prepare points
            points = []
            for j, (embedding, chunk) in enumerate(zip(embeddings, batch_chunks)):
                points.append(
                    PointStruct(
                        id=i + j,
                        vector=embedding.tolist(),
                        payload={
                            'text': chunk['text'],
                            'source': chunk['source'],
                            'chunk_id': chunk['chunk_id']
                        }
                    )
                )

            # Upload to Qdrant
            self.qdrant.upsert(
                collection_name=self.collection_name,
                points=points
            )

        print("✓ Ingestion complete!")

if __name__ == "__main__":
    from dotenv import load_dotenv
    load_dotenv()

    config = {
        'embedding_model': os.getenv('EMBEDDING_MODEL'),
        'qdrant_host': os.getenv('QDRANT_HOST'),
        'qdrant_port': int(os.getenv('QDRANT_PORT')),
        'collection_name': os.getenv('QDRANT_COLLECTION')
    }

    ingestion = DocumentIngestion(config)
    ingestion.ingest('./data/documents')

Step 5: Query Engine with vLLM​

Create src/api/query_engine.py:

import httpx
from typing import List, Dict
from qdrant_client import QdrantClient
from fastembed import TextEmbedding

class VLLMQueryEngine:
    def __init__(self, config: dict):
        self.config = config
        self.vllm_url = f"http://{config['vllm_host']}:{config['vllm_port']}/v1"
        self.embedding_model = TextEmbedding(
            model_name=config['embedding_model']
        )
        self.qdrant = QdrantClient(
            host=config['qdrant_host'],
            port=config['qdrant_port']
        )
        self.collection_name = config['collection_name']

    async def retrieve_context(self, query: str, k: int = 4) -> List[Dict]:
        """Retrieve relevant documents"""
        # Embed query
        query_vector = list(self.embedding_model.embed([query]))[0]

        # Search in Qdrant
        results = self.qdrant.search(
            collection_name=self.collection_name,
            query_vector=query_vector.tolist(),
            limit=k
        )

        return [
            {
                'text': hit.payload['text'],
                'source': hit.payload['source'],
                'score': hit.score
            }
            for hit in results
        ]

    def build_prompt(self, query: str, context: List[Dict]) -> str:
        """Build RAG prompt"""
        context_str = "\n\n".join([
            f"[Document {i+1}] (Source: {doc['source']}, Relevance: {doc['score']:.2%})\n{doc['text']}"
            for i, doc in enumerate(context)
        ])

        prompt = f"""You are an AI assistant that answers questions about a software project based on its documentation.

Context from documentation:
{context_str}

Question: {query}

Instructions:
- Answer based only on the context provided
- Be accurate and concise
- If you cannot find the answer in the context, say so clearly
- Do not make up information

Answer:"""

        return prompt

    async def query(self, question: str, stream: bool = False) -> Dict:
        """Query the agent"""
        # Retrieve context
        context = await self.retrieve_context(question)

        # Build prompt
        prompt = self.build_prompt(question, context)

        # Call vLLM
        async with httpx.AsyncClient(timeout=60.0) as client:
            response = await client.post(
                f"{self.vllm_url}/completions",
                json={
                    "model": "agent-model",
                    "prompt": prompt,
                    "max_tokens": 512,
                    "temperature": 0.2,
                    "top_p": 0.95,
                    "stream": stream
                }
            )

            if stream:
                return response

            result = response.json()

            return {
                'answer': result['choices'][0]['text'].strip(),
                'sources': context,
                'model': result['model'],
                'usage': result['usage']
            }

Step 6: FastAPI Server​

Create src/api/server.py:

import os
from fastapi import FastAPI, HTTPException, Request
from fastapi.middleware.cors import CORSMiddleware
from fastapi.responses import StreamingResponse
from pydantic import BaseModel
from typing import Optional, List
import redis
import json
import hashlib
from dotenv import load_dotenv

from query_engine import VLLMQueryEngine

load_dotenv()

app = FastAPI(title="vLLM Document Agent API")

# CORS
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

# Redis cache
redis_client = redis.Redis(
    host=os.getenv('REDIS_HOST', 'localhost'),
    port=int(os.getenv('REDIS_PORT', 6379)),
    decode_responses=True
)

# Initialize query engine
config = {
    'vllm_host': os.getenv('VLLM_HOST'),
    'vllm_port': os.getenv('VLLM_PORT'),
    'embedding_model': os.getenv('EMBEDDING_MODEL'),
    'qdrant_host': os.getenv('QDRANT_HOST'),
    'qdrant_port': int(os.getenv('QDRANT_PORT')),
    'collection_name': os.getenv('QDRANT_COLLECTION')
}

query_engine = VLLMQueryEngine(config)

class QueryRequest(BaseModel):
    question: str
    stream: Optional[bool] = False
    use_cache: Optional[bool] = True

class QueryResponse(BaseModel):
    answer: str
    sources: List[dict]
    cached: bool = False

@app.get("/health")
async def health():
    return {"status": "healthy", "service": "vllm-doc-agent"}

@app.post("/api/query", response_model=QueryResponse)
async def query(request: QueryRequest):
    try:
        # Check cache
        if request.use_cache:
            cache_key = hashlib.md5(request.question.encode()).hexdigest()
            cached = redis_client.get(cache_key)

            if cached:
                result = json.loads(cached)
                result['cached'] = True
                return result

        # Query engine
        result = await query_engine.query(request.question, stream=False)
        result['cached'] = False

        # Cache result
        if request.use_cache:
            redis_client.setex(
                cache_key,
                int(os.getenv('CACHE_TTL', 3600)),
                json.dumps({
                    'answer': result['answer'],
                    'sources': result['sources']
                })
            )

        return result

    except Exception as e:
        raise HTTPException(status_code=500, detail=str(e))

@app.post("/api/query/stream")
async def query_stream(request: QueryRequest):
    """Streaming response endpoint"""
    async def generate():
        response = await query_engine.query(request.question, stream=True)
        async for chunk in response.aiter_bytes():
            yield chunk

    return StreamingResponse(generate(), media_type="text/event-stream")

if __name__ == "__main__":
    import uvicorn
    uvicorn.run(
        app,
        host="0.0.0.0",
        port=int(os.getenv('API_PORT', 8080)),
        workers=int(os.getenv('API_WORKERS', 4))
    )

    depends_on:
      - vllm-server

volumes:
  qdrant_data:
  redis_data:

Monitoring​

Create src/utils/metrics.py:

from prometheus_client import Counter, Histogram, Gauge
import time

# Metrics
query_counter = Counter('queries_total', 'Total queries processed')
query_duration = Histogram('query_duration_seconds', 'Query duration')
active_requests = Gauge('active_requests', 'Number of active requests')
cache_hits = Counter('cache_hits_total', 'Total cache hits')

class MetricsMiddleware:
    async def __call__(self, request, call_next):
        active_requests.inc()
        start_time = time.time()

        response = await call_next(request)

        duration = time.time() - start_time
        query_duration.observe(duration)
        query_counter.inc()
        active_requests.dec()

        return response

Troubleshooting​

Issue: Out of Memory​

Solutions:

  • Reduce --gpu-memory-utilization (try 0.8)
  • Use quantized models (AWQ/GPTQ)
  • Reduce --max-model-len
  • Use smaller model (7B instead of 13B)

Issue: Slow Performance​

Solutions:

  • Enable continuous batching (default in vLLM)
  • Increase --max-num-batched-tokens
  • Use tensor parallelism with multiple GPUs
  • Enable CUDA graphs: --enable-cuda-graph

Issue: High Latency​

Solutions:

  • Enable Redis caching
  • Use FastEmbed for faster embeddings
  • Optimize chunk size and retrieval count
  • Pre-warm the model with dummy requests

Benchmarks​

Typical performance on NVIDIA A100:

  • Throughput: 2,000+ tokens/second
  • Latency: 50-200ms (first token)
  • Concurrent Users: 50-100 simultaneous
  • Memory Usage: 8-12GB VRAM (7B model)
  • Cost Efficiency: ~10x cheaper than API services

The combination of vLLM + Qdrant + FastEmbed offers an excellent balance of performance, cost, and quality for production AI agents.
