Building an AI Agent for Project Documentation Wiki

Overview​

This guide walks you through building an intelligent AI agent that can understand and answer questions about your project documentation, requirements, and codebase. The agent uses Retrieval-Augmented Generation (RAG) to provide accurate, context-aware responses based on your project's specific documentation.

Why Build a Documentation AI Agent?​

  • Instant Access: Get immediate answers to questions about project requirements, architecture, and implementation details
  • Onboarding: Help new team members quickly understand the project structure and conventions
  • Consistency: Ensure everyone gets the same accurate information from the source documentation
  • Time Savings: Reduce time spent searching through documentation and asking team members
  • Living Documentation: Automatically stays updated as you add or modify documentation

Architecture Overview​

Key Components​

  1. Document Ingestion Pipeline: Processes and chunks documentation files
  2. Vector Database: Stores document embeddings for efficient retrieval
  3. Embedding Model: Converts text to vector representations
  4. Retrieval System: Finds relevant document chunks for queries
  5. LLM (Large Language Model): Generates natural language answers
  6. Query Interface: User-facing chat or API interface

2. Add Semantic Caching​

Cache similar questions to save API costs:

import { createHash } from 'crypto';

class QueryCache {
  constructor(similarityThreshold = 0.95) {
    this.cache = new Map();
    this.embeddings = new OpenAIEmbeddings();
    this.threshold = similarityThreshold;
  }

  async checkCache(question) {
    const questionEmbedding = await this.embeddings.embedQuery(question);

    for (const [cachedQ, data] of this.cache.entries()) {
      const similarity = this.cosineSimilarity(questionEmbedding, data.embedding);

      if (similarity >= this.threshold) {
        console.log(`Cache hit! Similarity: ${similarity}`);
        return data.answer;
      }
    }

    return null;
  }

  async addToCache(question, answer) {
    const embedding = await this.embeddings.embedQuery(question);
    this.cache.set(question, { answer, embedding });
  }

  cosineSimilarity(a, b) {
    const dotProduct = a.reduce((sum, val, i) => sum + val * b[i], 0);
    const magnitudeA = Math.sqrt(a.reduce((sum, val) => sum + val * val, 0));
    const magnitudeB = Math.sqrt(b.reduce((sum, val) => sum + val * val, 0));
    return dotProduct / (magnitudeA * magnitudeB);
  }
}

3. Add Multi-Query Retrieval​

Generate multiple variations of the query for better retrieval:

import { LLMChain } from 'langchain/chains';

async function generateQueryVariations(question, llm, count = 3) {
  const prompt = PromptTemplate.fromTemplate(`
Generate ${count} different variations of the following question to improve document retrieval.
Each variation should ask the same thing but with different wording or perspective.

Original question: {question}

Variations (one per line):
`);

  const chain = new LLMChain({ llm, prompt });
  const result = await chain.call({ question });

  return result.text
    .split('\n')
    .filter((line) => line.trim())
    .slice(0, count);
}

async function multiQueryRetrieval(question, vectorStore) {
  const queries = await generateQueryVariations(question, llm);
  queries.unshift(question); // Include original

  const allDocs = [];
  for (const query of queries) {
    const docs = await vectorStore.similaritySearch(query, 2);
    allDocs.push(...docs);
  }

  // Deduplicate based on content
  const unique = [...new Map(allDocs.map((doc) => [doc.pageContent, doc])).values()];

  return unique;
}

4. Add Hybrid Search (Keyword + Semantic)​

Combine traditional keyword search with semantic search:

import { BM25Retriever } from 'langchain/retrievers/bm25';

class HybridRetriever {
  constructor(vectorStore, documents) {
    this.vectorStore = vectorStore;
    this.bm25 = new BM25Retriever({ documents, k: 4 });
  }

  async retrieve(query, k = 4) {
    // Get results from both retrievers
    const semanticDocs = await this.vectorStore.similaritySearch(query, k);
    const keywordDocs = await this.bm25.getRelevantDocuments(query);

    // Combine and re-rank
    const combined = this.reciprocalRankFusion([semanticDocs, keywordDocs], k);

    return combined;
  }

  reciprocalRankFusion(docLists, k = 60) {
    const scores = new Map();

    docLists.forEach((docs) => {
      docs.forEach((doc, index) => {
        const score = 1 / (k + index + 1);
        const key = doc.pageContent;
        scores.set(key, (scores.get(key) || 0) + score);
      });
    });

    return Array.from(scores.entries())
      .sort((a, b) => b[1] - a[1])
      .map(([content]) => docLists[0].find((d) => d.pageContent === content))
      .filter(Boolean);
  }
}

5. Add Monitoring and Analytics​

Track usage and performance:

class AgentAnalytics {
  constructor() {
    this.metrics = {
      queries: [],
      avgResponseTime: 0,
      totalQueries: 0,
      failedQueries: 0,
    };
  }

  logQuery(question, answer, responseTime, sources) {
    this.metrics.queries.push({
      question,
      answer,
      responseTime,
      sourcesCount: sources.length,
      timestamp: new Date(),
    });

    this.metrics.totalQueries++;
    this.metrics.avgResponseTime =
      (this.metrics.avgResponseTime * (this.metrics.totalQueries - 1) + responseTime) / this.metrics.totalQueries;
  }

  logError(question, error) {
    this.metrics.failedQueries++;
    console.error(`Query failed: ${question}`, error);
  }

  getStats() {
    return {
      totalQueries: this.metrics.totalQueries,
      failedQueries: this.metrics.failedQueries,
      successRate:
        (((this.metrics.totalQueries - this.metrics.failedQueries) / this.metrics.totalQueries) * 100).toFixed(2) + '%',
      avgResponseTime: this.metrics.avgResponseTime.toFixed(2) + 'ms',
      recentQueries: this.metrics.queries.slice(-10),
    };
  }
}

Building a Web Interface​

Simple React Frontend​

// src/frontend/App.jsx
import React, { useState } from 'react';
import './App.css';

function App() {
  const [question, setQuestion] = useState('');
  const [messages, setMessages] = useState([]);
  const [loading, setLoading] = useState(false);
  const [sessionId] = useState(() => `session_${Date.now()}`);

  const askQuestion = async () => {
    if (!question.trim()) return;

    // Add user message
    setMessages((prev) => [...prev, { role: 'user', content: question }]);
    setLoading(true);

    try {
      const response = await fetch('http://localhost:3000/api/query', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ question, sessionId }),
      });

      const data = await response.json();

      if (data.success) {
        setMessages((prev) => [
          ...prev,
          {
            role: 'assistant',
            content: data.data.answer,
            sources: data.data.sources,
          },
        ]);
      }
    } catch (error) {
      console.error('Error:', error);
    } finally {
      setLoading(false);
      setQuestion('');
    }
  };

  return (
    <div className="App">
      <header>
        <h1>📚 Project Documentation AI Agent</h1>
      </header>

      <div className="chat-container">
        {messages.map((msg, index) => (
          <div key={index} className={`message ${msg.role}`}>
            <div className="content">{msg.content}</div>
            {msg.sources && (
              <div className="sources">
                <strong>Sources:</strong>
                {msg.sources.map((src, i) => (
                  <div key={i} className="source">
                    {src.source} ({(src.relevance * 100).toFixed(1)}%)
                  </div>
                ))}
              </div>
            )}
          </div>
        ))}
        {loading && <div className="loading">Thinking...</div>}
      </div>

      <div className="input-container">
        <input
          type="text"
          value={question}
          onChange={(e) => setQuestion(e.target.value)}
          onKeyPress={(e) => e.key === 'Enter' && askQuestion()}
          placeholder="Ask anything about your project..."
          disabled={loading}
        />
        <button onClick={askQuestion} disabled={loading || !question.trim()}>
          Send
        </button>
      </div>
    </div>
  );
}

export default App;

4. Error Handling​

class RobustQueryEngine extends QueryEngine {
  async ask(question, options = {}) {
    const maxRetries = 3;
    let lastError;

    for (let i = 0; i < maxRetries; i++) {
      try {
        return await super.ask(question, options);
      } catch (error) {
        lastError = error;
        console.warn(`Attempt ${i + 1} failed:`, error.message);

        if (error.message.includes('rate limit')) {
          await this.sleep(Math.pow(2, i) * 1000); // Exponential backoff
        } else {
          throw error; // Don't retry non-rate-limit errors
        }
      }
    }

    throw lastError;
  }

  sleep(ms) {
    return new Promise((resolve) => setTimeout(resolve, ms));
  }
}

Troubleshooting​

Common Issues​

  1. "No relevant documents found"

    • Check if ingestion completed successfully
    • Verify vector database path is correct
    • Try different chunking parameters

  2. "Rate limit exceeded"

    • Implement retry logic with exponential backoff
    • Consider caching frequent queries
    • Use local models for development

  3. Poor answer quality

    • Adjust chunk size and overlap
    • Improve document structure
    • Refine system prompts
    • Increase number of retrieved chunks (k parameter)

  4. Slow responses

    • Enable caching
    • Use smaller embedding models
    • Optimize chunk retrieval
    • Consider using GPT-3.5 instead of GPT-4
