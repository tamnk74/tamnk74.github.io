Sample Use Case: RAG Customer Support Bot with vLLM Docker

This guide demonstrates a complete, hands-on example of building a RAG-powered customer support chatbot using the official vllm/vllm-openai Docker image. This setup provides an OpenAI-compatible API endpoint for high-performance LLM inference.

🎯 Use Case Overview​

Scenario: Build a customer support chatbot that can answer questions about product documentation, troubleshooting guides, and FAQs using a locally-hosted LLM with RAG (Retrieval-Augmented Generation).

Why vLLM Docker?

  • ✅ Easy deployment with Docker (no complex CUDA setup)
  • ✅ OpenAI-compatible API (drop-in replacement)
  • ✅ High-throughput inference with PagedAttention
  • ✅ Production-ready with automatic batching
  • ✅ Supports multiple concurrent users

📋 Prerequisites​

  • Docker with GPU support (NVIDIA Container Toolkit)
  • NVIDIA GPU with 16GB+ VRAM (for 7B models)
  • 8GB+ RAM for vector database and embeddings
  • 10GB+ disk space for model downloads

🏗️ Architecture​

🚀 Step 1: Start vLLM Docker Container​

First, let's start the vLLM server using Docker:

# Pull the latest vLLM OpenAI image
docker pull vllm/vllm-openai:latest

# Run vLLM with Mistral-7B-Instruct
docker run --runtime nvidia --gpus all \
    -v ~/.cache/huggingface:/root/.cache/huggingface \
    -p 8080:8000 \
    --ipc=host \
    vllm/vllm-openai:latest \
    --model mistralai/Mistral-7B-Instruct-v0.2 \
    --dtype half \
    --max-model-len 4096 \
    --gpu-memory-utilization 0.9

Parameters Explained:

  • --runtime nvidia --gpus all: Enable GPU access
  • -v ~/.cache/huggingface:/root/.cache/huggingface: Cache models locally
  • -p 8080:8000: Map container port 8000 to host port 8080
  • --ipc=host: Improved shared memory for PyTorch
  • --model: HuggingFace model to load
  • --dtype half: Use FP16 for faster inference
  • --max-model-len: Maximum context length
  • --gpu-memory-utilization: GPU memory to use (0.0-1.0)

Alternative: Using Docker Compose​

Create docker-compose.yml:

version: '3.8'

services:
  vllm:
    image: vllm/vllm-openai:latest
    runtime: nvidia
    environment:
      - NVIDIA_VISIBLE_DEVICES=all
    ports:
      - "8080:8000"
    volumes:
      - ~/.cache/huggingface:/root/.cache/huggingface
    command: >
      --model mistralai/Mistral-7B-Instruct-v0.2
      --dtype half
      --max-model-len 4096
      --gpu-memory-utilization 0.9
      --served-model-name support-bot
    shm_size: '8gb'
    deploy:
      resources:
        reservations:
          devices:
            - driver: nvidia
              count: all
              capabilities: [gpu]

  chromadb:
    image: chromadb/chroma:latest
    ports:
      - "8001:8000"
    volumes:
      - ./chroma_data:/chroma/chroma
    environment:
      - IS_PERSISTENT=TRUE

docker-compose up -d

🔧 Step 3: Build RAG Application​

Create rag_support_bot.py:

import os
from typing import List, Dict
import chromadb
from chromadb.utils import embedding_functions
from openai import OpenAI
from pathlib import Path

class RAGSupportBot:
    def __init__(
        self,
        vllm_url: str = "http://localhost:8080/v1",
        chroma_path: str = "./chroma_db",
        model_name: str = "mistralai/Mistral-7B-Instruct-v0.2"
    ):
        """Initialize RAG Support Bot"""
        # OpenAI client pointing to vLLM
        self.client = OpenAI(
            base_url=vllm_url,
            api_key="EMPTY"  # vLLM doesn't require API key
        )
        self.model_name = model_name
        
        # Initialize ChromaDB
        self.chroma_client = chromadb.PersistentClient(path=chroma_path)
        
        # Use sentence-transformers for embeddings
        self.embedding_function = embedding_functions.SentenceTransformerEmbeddingFunction(
            model_name="all-MiniLM-L6-v2"
        )
        
        # Create or get collection
        self.collection = self.chroma_client.get_or_create_collection(
            name="support_docs",
            embedding_function=self.embedding_function,
            metadata={"description": "Customer support knowledge base"}
        )
    
    def ingest_documents(self, docs_path: str):
        """Load documents into vector database"""
        docs_dir = Path(docs_path)
        documents = []
        metadatas = []
        ids = []
        
        for idx, file_path in enumerate(docs_dir.glob("*.txt")):
            with open(file_path, 'r', encoding='utf-8') as f:
                content = f.read()
                
                # Split into chunks (simple paragraph-based splitting)
                chunks = [chunk.strip() for chunk in content.split('\n\n') if chunk.strip()]
                
                for chunk_idx, chunk in enumerate(chunks):
                    documents.append(chunk)
                    metadatas.append({
                        "source": file_path.name,
                        "chunk_id": chunk_idx
                    })
                    ids.append(f"{file_path.stem}_{chunk_idx}")
        
        # Add to ChromaDB
        self.collection.add(
            documents=documents,
            metadatas=metadatas,
            ids=ids
        )
        
        print(f"✓ Ingested {len(documents)} document chunks from {docs_path}")
    
    def retrieve_context(self, query: str, n_results: int = 3) -> List[Dict]:
        """Retrieve relevant documents"""
        results = self.collection.query(
            query_texts=[query],
            n_results=n_results
        )
        
        contexts = []
        if results['documents'] and results['documents'][0]:
            for doc, metadata in zip(results['documents'][0], results['metadatas'][0]):
                contexts.append({
                    'text': doc,
                    'source': metadata['source']
                })
        
        return contexts
    
    def build_prompt(self, query: str, contexts: List[Dict]) -> str:
        """Build RAG prompt"""
        context_text = "\n\n".join([
            f"[Source: {ctx['source']}]\n{ctx['text']}"
            for ctx in contexts
        ])
        
        prompt = f"""<s>[INST] You are a helpful customer support assistant for X1000 routers. 
Answer the customer's question based ONLY on the provided documentation.
If you cannot find the answer in the documentation, say "I don't have that information in my knowledge base. Please contact our support team."

Documentation:
{context_text}

Customer Question: {query}

Provide a clear, friendly, and helpful answer. [/INST]"""
        
        return prompt
    
    def query(self, question: str, stream: bool = False) -> Dict:
        """Query the RAG bot"""
        # 1. Retrieve relevant context
        contexts = self.retrieve_context(question)
        
        if not contexts:
            return {
                'answer': "I couldn't find relevant information. Please contact support.",
                'sources': []
            }
        
        # 2. Build prompt with context
        prompt = self.build_prompt(question, contexts)
        
        # 3. Generate response using vLLM
        response = self.client.completions.create(
            model=self.model_name,
            prompt=prompt,
            max_tokens=300,
            temperature=0.3,
            top_p=0.9,
            stream=stream
        )
        
        if stream:
            return response
        
        answer = response.choices[0].text.strip()
        
        return {
            'answer': answer,
            'sources': [ctx['source'] for ctx in contexts],
            'contexts': contexts
        }
    
    def chat(self):
        """Interactive chat loop"""
        print("🤖 Customer Support Bot Ready!")
        print("Ask questions about the X1000 router. Type 'quit' to exit.\n")
        
        while True:
            question = input("You: ").strip()
            
            if question.lower() in ['quit', 'exit', 'q']:
                print("Goodbye!")
                break
            
            if not question:
                continue
            
            print("\n🔍 Searching knowledge base...")
            result = self.query(question)
            
            print(f"\n🤖 Bot: {result['answer']}")
            print(f"\n📚 Sources: {', '.join(result['sources'])}\n")
            print("-" * 80)


if __name__ == "__main__":
    # Initialize bot
    bot = RAGSupportBot(
        vllm_url="http://localhost:8080/v1",
        chroma_path="./chroma_db"
    )
    
    # Ingest knowledge base (run once)
    if not Path("./chroma_db").exists():
        print("📚 Ingesting knowledge base...")
        bot.ingest_documents("./customer_support_kb")
    
    # Start interactive chat
    bot.chat()

🔥 Step 5: Create REST API (Optional)​

Create api_server.py for a web API:

from fastapi import FastAPI, HTTPException
from pydantic import BaseModel
from rag_support_bot import RAGSupportBot
from pathlib import Path

app = FastAPI(title="Support Bot API")

# Initialize bot
bot = RAGSupportBot()
if not Path("./chroma_db").exists():
    bot.ingest_documents("./customer_support_kb")

class QueryRequest(BaseModel):
    question: str

class QueryResponse(BaseModel):
    answer: str
    sources: list[str]

@app.post("/query", response_model=QueryResponse)
async def query(request: QueryRequest):
    """Query the support bot"""
    try:
        result = bot.query(request.question)
        return QueryResponse(
            answer=result['answer'],
            sources=result['sources']
        )
    except Exception as e:
        raise HTTPException(status_code=500, detail=str(e))

@app.get("/health")
async def health():
    return {"status": "healthy"}

if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="0.0.0.0", port=8000)

Install FastAPI:

pip install fastapi uvicorn

Run the API:

python api_server.py

Test it:

  -d '{"question": "How do I set up WiFi?"}'

Enable Streaming Responses​

Update rag_support_bot.py:

def query_stream(self, question: str):
    """Query with streaming response"""
    contexts = self.retrieve_context(question)
    prompt = self.build_prompt(question, contexts)
    
    stream = self.client.completions.create(
        model=self.model_name,
        prompt=prompt,
        max_tokens=300,
        temperature=0.3,
        stream=True
    )
    
    print("\n🤖 Bot: ", end="", flush=True)
    for chunk in stream:
        if chunk.choices[0].text:
            print(chunk.choices[0].text, end="", flush=True)
    print("\n")

🐛 Troubleshooting​

Issue: "CUDA out of memory"​

Solution:

# Reduce GPU memory utilization
--gpu-memory-utilization 0.7

# Or use smaller model
--model mistralai/Mistral-7B-Instruct-v0.1

# Or use quantization
--quantization awq

Issue: "Model download is slow"​

Solution:

# Pre-download model
huggingface-cli download mistralai/Mistral-7B-Instruct-v0.2

# Use local cache
-v ~/.cache/huggingface:/root/.cache/huggingface

Issue: Container exits immediately​

Solution:

# Check logs
docker logs <container_id>

# Verify NVIDIA runtime
docker run --rm --runtime=nvidia nvidia/cuda:11.8.0-base-ubuntu22.04 nvidia-smi
