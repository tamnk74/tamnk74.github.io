Building AI Document Wiki Agent with LlamaIndex + Local Models

Overview​

This guide shows you how to build a completely local and privacy-focused AI documentation agent using LlamaIndex with local LLM models through Ollama. Perfect for sensitive projects or cost-conscious implementations.

Pros:

  • ✅ Complete privacy - data never leaves your infrastructure
  • ✅ No API costs after initial setup
  • ✅ Full control over models and responses
  • ✅ Works offline
  • ✅ No vendor lock-in

Cons:

  • ❌ Requires significant computational resources (GPU recommended)
  • ❌ Setup is more complex
  • ❌ Response quality may be lower than GPT-4
  • ❌ Slower response times (depending on hardware)

Prerequisites​

  • Node.js 18+ or Python 3.10+
  • At least 16GB RAM (32GB recommended)
  • GPU with 8GB+ VRAM (optional but highly recommended)
  • Docker (for Ollama) or direct Ollama installation

Step 1: Install Ollama & Download Models​

Install Ollama​

# macOS
brew install ollama

# Linux
curl -fsSL https://ollama.com/install.sh | sh

# Windows (WSL2)
curl -fsSL https://ollama.com/install.sh | sh

Start Ollama Service​

ollama serve

Download Models​

# Download Llama 2 7B (good balance of speed/quality)
ollama pull llama2

# Or use Mistral 7B (faster, good quality)
ollama pull mistral

# For better quality (requires more resources)
ollama pull llama2:13b

# For embeddings
ollama pull nomic-embed-text

Step 4: Document Ingestion​

Create src/ingestion/loader.py:

import os
from pathlib import Path
from typing import List
from llama_index.core import SimpleDirectoryReader, Document
from llama_index.core.node_parser import SentenceSplitter

class DocumentLoader:
    def __init__(self, docs_path: str):
        self.docs_path = Path(docs_path)

    def load_documents(self) -> List[Document]:
        """Load all documents from the docs directory"""
        print(f"Loading documents from {self.docs_path}...")

        # Load documents
        reader = SimpleDirectoryReader(
            input_dir=str(self.docs_path),
            recursive=True,
            required_exts=[".md", ".txt", ".pdf", ".docx"],
        )

        documents = reader.load_data()
        print(f"Loaded {len(documents)} documents")

        return documents

    def load_code_files(self, code_path: str, extensions: List[str] = None) -> List[Document]:
        """Load code files"""
        if extensions is None:
            extensions = [".py", ".js", ".ts", ".jsx", ".tsx"]

        print(f"Loading code files from {code_path}...")

        reader = SimpleDirectoryReader(
            input_dir=code_path,
            recursive=True,
            required_exts=extensions,
        )

        documents = reader.load_data()

        # Add metadata
        for doc in documents:
            doc.metadata["type"] = "code"

        print(f"Loaded {len(documents)} code files")

        return documents

class DocumentProcessor:
    def __init__(self, chunk_size: int = 512, chunk_overlap: int = 50):
        self.splitter = SentenceSplitter(
            chunk_size=chunk_size,
            chunk_overlap=chunk_overlap,
        )

    def process_documents(self, documents: List[Document]) -> List[Document]:
        """Split documents into chunks"""
        print(f"Processing {len(documents)} documents...")

        nodes = self.splitter.get_nodes_from_documents(documents)

        print(f"Created {len(nodes)} chunks")

        return nodes

Step 5: Vector Store Setup​

Create src/ingestion/vector_store.py:

import os
from typing import List
from llama_index.core import VectorStoreIndex, StorageContext, load_index_from_storage
from llama_index.core.schema import Document
from llama_index.vector_stores.qdrant import QdrantVectorStore
from llama_index.embeddings.ollama import OllamaEmbedding
from qdrant_client import QdrantClient

class VectorStoreManager:
    def __init__(self, config: dict):
        self.qdrant_path = config.get("qdrant_path", "./data/qdrant_db")
        self.collection_name = config.get("collection_name", "project_docs")
        self.embedding_model = config.get("embedding_model", "nomic-embed-text")
        self.ollama_base_url = config.get("ollama_base_url", "http://localhost:11434")

        # Initialize embedding model
        self.embed_model = OllamaEmbedding(
            model_name=self.embedding_model,
            base_url=self.ollama_base_url,
        )

        # Initialize Qdrant client
        self.client = QdrantClient(path=self.qdrant_path)

        self.index = None

    def create_index(self, nodes: List[Document]):
        """Create a new vector index"""
        print(f"Creating vector index with {len(nodes)} nodes...")

        # Create vector store
        vector_store = QdrantVectorStore(
            client=self.client,
            collection_name=self.collection_name,
        )

        storage_context = StorageContext.from_defaults(vector_store=vector_store)

        # Create index
        self.index = VectorStoreIndex(
            nodes,
            storage_context=storage_context,
            embed_model=self.embed_model,
            show_progress=True,
        )

        # Persist index
        self.index.storage_context.persist(persist_dir=f"{self.qdrant_path}/storage")

        print("Index created and persisted successfully")

        return self.index

    def load_index(self):
        """Load existing index"""
        print("Loading existing index...")

        vector_store = QdrantVectorStore(
            client=self.client,
            collection_name=self.collection_name,
        )

        storage_context = StorageContext.from_defaults(
            vector_store=vector_store,
            persist_dir=f"{self.qdrant_path}/storage"
        )

        self.index = load_index_from_storage(
            storage_context,
            embed_model=self.embed_model,
        )

        print("Index loaded successfully")

        return self.index

    def get_index(self):
        """Get the current index"""
        return self.index

Step 6: Ingestion Script​

Create src/ingest.py:

import os
from dotenv import load_dotenv
from ingestion.loader import DocumentLoader, DocumentProcessor
from ingestion.vector_store import VectorStoreManager

load_dotenv()

def main():
    print("=== Starting Document Ingestion ===\n")

    # Configuration
    config = {
        "qdrant_path": os.getenv("QDRANT_PATH", "./data/qdrant_db"),
        "collection_name": os.getenv("COLLECTION_NAME", "project_docs"),
        "embedding_model": os.getenv("EMBEDDING_MODEL", "nomic-embed-text"),
        "ollama_base_url": os.getenv("OLLAMA_BASE_URL", "http://localhost:11434"),
    }

    # Load documents
    docs_path = os.getenv("DOCS_PATH", "./docs")
    loader = DocumentLoader(docs_path)
    documents = loader.load_documents()

    # Optionally load code files
    if os.getenv("INCLUDE_CODE", "false").lower() == "true":
        code_path = os.getenv("CODE_PATH", "./src")
        code_docs = loader.load_code_files(code_path)
        documents.extend(code_docs)

    print(f"\nTotal documents loaded: {len(documents)}\n")

    # Process documents
    chunk_size = int(os.getenv("CHUNK_SIZE", "512"))
    chunk_overlap = int(os.getenv("CHUNK_OVERLAP", "50"))
    processor = DocumentProcessor(chunk_size, chunk_overlap)
    nodes = processor.process_documents(documents)

    print(f"\nTotal chunks created: {len(nodes)}\n")

    # Create vector store
    vector_store = VectorStoreManager(config)
    vector_store.create_index(nodes)

    print("\n=== Ingestion Complete ===")
    print(f"✓ Processed {len(documents)} documents")
    print(f"✓ Created {len(nodes)} chunks")
    print(f"✓ Stored in collection: {config['collection_name']}")

if __name__ == "__main__":
    main()

Step 7: Query Engine​

Create src/retrieval/query_engine.py:

import os
from llama_index.core import Settings
from llama_index.llms.ollama import Ollama
from llama_index.embeddings.ollama import OllamaEmbedding
from llama_index.core.query_engine import RetrieverQueryEngine
from llama_index.core.prompts import PromptTemplate

class QueryEngine:
    def __init__(self, index, config: dict):
        self.index = index
        self.config = config

        # Initialize LLM
        self.llm = Ollama(
            model=config.get("llm_model", "llama2"),
            base_url=config.get("ollama_base_url", "http://localhost:11434"),
            temperature=float(config.get("temperature", 0.2)),
            context_window=int(config.get("context_window", 4096)),
            request_timeout=120.0,
        )

        # Initialize embedding model
        self.embed_model = OllamaEmbedding(
            model_name=config.get("embedding_model", "nomic-embed-text"),
            base_url=config.get("ollama_base_url", "http://localhost:11434"),
        )

        # Set global settings
        Settings.llm = self.llm
        Settings.embed_model = self.embed_model

        # Create custom prompt
        self.qa_prompt = self._create_prompt_template()

        # Create query engine
        self.query_engine = self.index.as_query_engine(
            similarity_top_k=4,
            text_qa_template=self.qa_prompt,
        )

    def _create_prompt_template(self):
        """Create custom prompt template"""
        template = (
            "You are an AI assistant helping answer questions about a software project "
            "based on its documentation.\n\n"
            "Context information is below:\n"
            "---------------------\n"
            "{context_str}\n"
            "---------------------\n\n"
            "Using the context above, answer the following question. "
            "If you cannot find the answer in the context, say so clearly. "
            "Do not make up information.\n\n"
            "Question: {query_str}\n"
            "Answer: "
        )

        return PromptTemplate(template)

    def query(self, question: str) -> dict:
        """Query the engine"""
        print(f"\nQuery: {question}")

        response = self.query_engine.query(question)

        # Extract sources
        sources = []
        if hasattr(response, 'source_nodes'):
            for node in response.source_nodes:
                sources.append({
                    "text": node.text[:200] + "...",
                    "score": node.score,
                    "metadata": node.metadata,
                })

        return {
            "question": question,
            "answer": str(response),
            "sources": sources,
        }

Step 8: FastAPI Server​

Create src/api/server.py:

import os
from dotenv import load_dotenv
from fastapi import FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware
from pydantic import BaseModel
from typing import Optional, List
import uvicorn

from ingestion.vector_store import VectorStoreManager
from retrieval.query_engine import QueryEngine

load_dotenv()

app = FastAPI(title="AI Document Wiki Agent (Local)")

# CORS
app.add_middleware(
    CORSMiddleware,
    allow_origins=[os.getenv("CORS_ORIGIN", "*")],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

# Request/Response models
class QueryRequest(BaseModel):
    question: str
    sessionId: Optional[str] = None

class QueryResponse(BaseModel):
    success: bool
    data: dict
    sessionId: Optional[str] = None

# Initialize query engine
config = {
    "qdrant_path": os.getenv("QDRANT_PATH", "./data/qdrant_db"),
    "collection_name": os.getenv("COLLECTION_NAME", "project_docs"),
    "embedding_model": os.getenv("EMBEDDING_MODEL", "nomic-embed-text"),
    "llm_model": os.getenv("LLM_MODEL", "llama2"),
    "ollama_base_url": os.getenv("OLLAMA_BASE_URL", "http://localhost:11434"),
    "temperature": os.getenv("TEMPERATURE", "0.2"),
    "context_window": os.getenv("CONTEXT_WINDOW", "4096"),
}

vector_store = VectorStoreManager(config)
index = vector_store.load_index()
query_engine = QueryEngine(index, config)

# Session storage
sessions = {}

@app.get("/health")
async def health():
    return {"status": "ok"}

@app.post("/api/query", response_model=QueryResponse)
async def query(request: QueryRequest):
    try:
        if not request.question:
            raise HTTPException(status_code=400, detail="Question is required")

        # Get response
        result = query_engine.query(request.question)

        # Store in session
        if request.sessionId:
            if request.sessionId not in sessions:
                sessions[request.sessionId] = []
            sessions[request.sessionId].append({
                "role": "user",
                "content": request.question
            })
            sessions[request.sessionId].append({
                "role": "assistant",
                "content": result["answer"]
            })

        return QueryResponse(
            success=True,
            data=result,
            sessionId=request.sessionId
        )

    except Exception as e:
        raise HTTPException(status_code=500, detail=str(e))

@app.post("/api/session/clear")
async def clear_session(sessionId: str):
    if sessionId in sessions:
        del sessions[sessionId]
    return {"success": True}

if __name__ == "__main__":
    port = int(os.getenv("PORT", 8000))
    print(f"\n🚀 AI Document Wiki Agent (Local) running on port {port}")
    print("📚 Using Ollama for local inference")
    print(f"🤖 Model: {config['llm_model']}")

    uvicorn.run(app, host="0.0.0.0", port=port)

Step 9: CLI Interface​

Create src/cli.py:

import os
from dotenv import load_dotenv
from ingestion.vector_store import VectorStoreManager
from retrieval.query_engine import QueryEngine

load_dotenv()

def main():
    print("\n=== AI Document Wiki Agent (Local) ===")
    print("Using Ollama for local inference\n")

    # Configuration
    config = {
        "qdrant_path": os.getenv("QDRANT_PATH", "./data/qdrant_db"),
        "collection_name": os.getenv("COLLECTION_NAME", "project_docs"),
        "embedding_model": os.getenv("EMBEDDING_MODEL", "nomic-embed-text"),
        "llm_model": os.getenv("LLM_MODEL", "llama2"),
        "ollama_base_url": os.getenv("OLLAMA_BASE_URL", "http://localhost:11434"),
        "temperature": os.getenv("TEMPERATURE", "0.2"),
        "context_window": os.getenv("CONTEXT_WINDOW", "4096"),
    }

    print("Initializing...")
    vector_store = VectorStoreManager(config)
    index = vector_store.load_index()
    query_engine = QueryEngine(index, config)
    print("✓ Ready to answer your questions!\n")

    print('Type "exit" to quit, "clear" to clear history\n')

    while True:
        question = input("You: ").strip()

        if not question:
            continue

        if question.lower() in ["exit", "quit"]:
            print("\nGoodbye!\n")
            break

        if question.lower() == "clear":
            print("\n✓ Chat history cleared\n")
            continue

        try:
            print("\nThinking...\n")
            result = query_engine.query(question)

            print(f"Agent: {result['answer']}\n")

            if result['sources']:
                print("Sources:")
                for i, source in enumerate(result['sources'], 1):
                    score = source.get('score', 0)
                    print(f"  {i}. Relevance: {score:.2%}")
                print()

        except Exception as e:
            print(f"Error: {str(e)}\n")

if __name__ == "__main__":
    main()

Performance Optimization​

Use Quantized Models​

# Download quantized versions for better performance
ollama pull llama2:7b-q4_0  # 4-bit quantized
ollama pull mistral:7b-q4_K_M

GPU Acceleration​

Ollama automatically uses GPU if available. Verify:

# Check if GPU is being used
nvidia-smi  # For NVIDIA GPUs

Optimize Chunk Size​

# Smaller chunks for faster processing
CHUNK_SIZE=512
CHUNK_OVERLAP=50

Model Recommendations​

Best for Speed (4-8GB VRAM)​

  • mistral:7b - Fast, good quality
  • llama2:7b - Reliable, well-tested

Best for Quality (16GB+ VRAM)​

  • llama2:13b - Better reasoning
  • mixtral:8x7b - High quality

Best for Low Resources (CPU only)​

  • phi-2 - Small but capable
  • tinyllama - Very fast, basic quality

Troubleshooting​

Issue: Slow Responses​

Solutions:

  • Use quantized models (q4_0, q4_K_M)
  • Reduce chunk size and retrieval count
  • Ensure GPU is being utilized
  • Use smaller models (7B instead of 13B)

Issue: Out of Memory​

Solutions:

  • Use smaller models
  • Reduce context window
  • Close other applications
  • Use quantized models

Issue: Poor Answer Quality​

Solutions:

  • Use larger models (13B, 70B)
  • Increase number of retrieved chunks
  • Improve document structure
  • Refine prompts
