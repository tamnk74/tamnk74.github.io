HTTP Caching Headers Guide for Next.js and NestJS

Complete guide to implementing proper Cache-Control and HTTP caching headers in Next.js frontend and NestJS backend applications.

Overview​

HTTP caching is crucial for:

  • Performance: Reduce server load and bandwidth
  • User Experience: Faster page loads and interactions
  • Cost Efficiency: Lower CDN and hosting costs
  • Scalability: Handle more users with same infrastructure

This guide covers caching strategies for both client (Next.js) and server (NestJS) applications.

Understanding Cache-Control Headers​

Basic Syntax​

Cache-Control: <directive>[, <directive>]*

Common Directives​

DirectiveDescriptionUse Case
publicCan be cached by any cache (browser, CDN, proxy)Static assets, public content
privateOnly cached by browser (not CDN/proxy)User-specific data
no-cacheMust revalidate with server before usingDynamic content
no-storeNever cache, always fetch from serverSensitive data
max-age=<seconds>Cache duration in secondsAll cacheable content
s-maxage=<seconds>CDN/shared cache durationCDN cached content
must-revalidateMust check with server when staleCritical content
immutableNever needs revalidation (append hash to URL)Versioned assets
stale-while-revalidate=<seconds>Serve stale while fetching freshBetter UX
stale-if-error=<seconds>Serve stale if server errorResilience

Cache Header Examples​

# Static assets with versioning (1 year)
Cache-Control: public, max-age=31536000, immutable

# HTML pages (5 minutes, revalidate)
Cache-Control: public, max-age=300, must-revalidate

# API responses (10 seconds, private)
Cache-Control: private, max-age=10

# User-specific data (don't cache)
Cache-Control: private, no-cache, no-store, must-revalidate

# CDN cached content (1 hour browser, 1 day CDN)
Cache-Control: public, max-age=3600, s-maxage=86400

# Stale content strategies
Cache-Control: public, max-age=60, stale-while-revalidate=300

Next.js Caching Implementation​

1. Static Assets Caching​

Next.js automatically handles static assets in /public folder:

// next.config.js
module.exports = {
  async headers() {
    return [
      // Cache static assets forever (use content hashing)
      {
        source: '/static/:path*',
        headers: [
          {
            key: 'Cache-Control',
            value: 'public, max-age=31536000, immutable',
          },
        ],
      },
      // Cache images with long TTL
      {
        source: '/images/:path*',
        headers: [
          {
            key: 'Cache-Control',
            value: 'public, max-age=31536000, immutable',
          },
        ],
      },
      // Cache fonts forever
      {
        source: '/fonts/:path*',
        headers: [
          {
            key: 'Cache-Control',
            value: 'public, max-age=31536000, immutable',
          },
        ],
      },
      // Cache JS/CSS with versioning
      {
        source: '/:path*.{js,css,woff,woff2,eot,ttf,otf}',
        headers: [
          {
            key: 'Cache-Control',
            value: 'public, max-age=31536000, immutable',
          },
        ],
      },
    ];
  },
};

On-Demand Revalidation:

// app/api/revalidate/route.ts
import { revalidatePath, revalidateTag } from 'next/cache';
import { NextRequest, NextResponse } from 'next/server';

export async function POST(request: NextRequest) {
  const secret = request.nextUrl.searchParams.get('secret');

  if (secret !== process.env.REVALIDATE_SECRET) {
    return NextResponse.json({ message: 'Invalid secret' }, { status: 401 });
  }

  const path = request.nextUrl.searchParams.get('path');
  const tag = request.nextUrl.searchParams.get('tag');

  if (path) {
    revalidatePath(path);
    return NextResponse.json({ revalidated: true, path });
  }

  if (tag) {
    revalidateTag(tag);
    return NextResponse.json({ revalidated: true, tag });
  }

  return NextResponse.json({ message: 'Missing path or tag' }, { status: 400 });
}

4. Fetch Caching (Server Components)​

// app/products/page.tsx

// Default: cached with revalidation
async function getProducts() {
  const res = await fetch('https://api.example.com/products', {
    next: { revalidate: 3600 }, // Revalidate every hour
  });
  return res.json();
}

// Cache with tags for on-demand revalidation
async function getProduct(id: string) {
  const res = await fetch(`https://api.example.com/products/${id}`, {
    next: {
      revalidate: 3600,
      tags: ['product', `product-${id}`],
    },
  });
  return res.json();
}

// No caching (always fresh)
async function getUser() {
  const res = await fetch('https://api.example.com/user', {
    cache: 'no-store',
  });
  return res.json();
}

// Force cache (never revalidates)
async function getStaticData() {
  const res = await fetch('https://api.example.com/static', {
    cache: 'force-cache',
  });
  return res.json();
}

export default async function ProductsPage() {
  const products = await getProducts();
  return <div>{/* Render products */}</div>;
}

5. Middleware Caching Headers​

// middleware.ts
import { NextResponse } from 'next/server';
import type { NextRequest } from 'next/server';

export function middleware(request: NextRequest) {
  const response = NextResponse.next();

  // Cache static pages
  if (request.nextUrl.pathname.startsWith('/blog')) {
    response.headers.set('Cache-Control', 'public, max-age=300, s-maxage=600, stale-while-revalidate=300');
  }

  // Don't cache authenticated routes
  if (request.nextUrl.pathname.startsWith('/dashboard')) {
    response.headers.set('Cache-Control', 'private, no-cache, no-store, must-revalidate');
  }

  return response;
}

export const config = {
  matcher: ['/blog/:path*', '/dashboard/:path*'],
};

NestJS Caching Implementation​

1. Response Headers Interceptor​

// src/common/interceptors/cache-control.interceptor.ts
import { Injectable, NestInterceptor, ExecutionContext, CallHandler } from '@nestjs/common';
import { Observable } from 'rxjs';
import { tap } from 'rxjs/operators';
import { Response } from 'express';

@Injectable()
export class CacheControlInterceptor implements NestInterceptor {
  constructor(private readonly cacheControl: string) {}

  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    const response = context.switchToHttp().getResponse<Response>();

    return next.handle().pipe(
      tap(() => {
        response.setHeader('Cache-Control', this.cacheControl);
      }),
    );
  }
}

2. Custom Cache Decorator​

// src/common/decorators/cache-control.decorator.ts
import { SetMetadata } from '@nestjs/common';

export const CACHE_CONTROL_KEY = 'cache-control';

export interface CacheControlOptions {
  public?: boolean;
  private?: boolean;
  maxAge?: number;
  sMaxAge?: number;
  noCache?: boolean;
  noStore?: boolean;
  mustRevalidate?: boolean;
  immutable?: boolean;
  staleWhileRevalidate?: number;
  staleIfError?: number;
}

export const CacheControl = (options: CacheControlOptions) => {
  const directives: string[] = [];

  if (options.public) directives.push('public');
  if (options.private) directives.push('private');
  if (options.noCache) directives.push('no-cache');
  if (options.noStore) directives.push('no-store');
  if (options.mustRevalidate) directives.push('must-revalidate');
  if (options.immutable) directives.push('immutable');
  if (options.maxAge !== undefined) directives.push(`max-age=${options.maxAge}`);
  if (options.sMaxAge !== undefined) directives.push(`s-maxage=${options.sMaxAge}`);
  if (options.staleWhileRevalidate !== undefined) {
    directives.push(`stale-while-revalidate=${options.staleWhileRevalidate}`);
  }
  if (options.staleIfError !== undefined) {
    directives.push(`stale-if-error=${options.staleIfError}`);
  }

  return SetMetadata(CACHE_CONTROL_KEY, directives.join(', '));
};

3. Cache Control Guard/Interceptor​

// src/common/interceptors/apply-cache-control.interceptor.ts
import { Injectable, NestInterceptor, ExecutionContext, CallHandler } from '@nestjs/common';
import { Reflector } from '@nestjs/core';
import { Observable } from 'rxjs';
import { tap } from 'rxjs/operators';
import { Response } from 'express';
import { CACHE_CONTROL_KEY } from '../decorators/cache-control.decorator';

@Injectable()
export class ApplyCacheControlInterceptor implements NestInterceptor {
  constructor(private reflector: Reflector) {}

  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    const cacheControl = this.reflector.getAllAndOverride<string>(CACHE_CONTROL_KEY, [
      context.getHandler(),
      context.getClass(),
    ]);

    if (!cacheControl) {
      return next.handle();
    }

    const response = context.switchToHttp().getResponse<Response>();

    return next.handle().pipe(
      tap(() => {
        response.setHeader('Cache-Control', cacheControl);
      }),
    );
  }
}

import { Controller, Get, Param } from '@nestjs/common';
import { CacheControl } from '../common/decorators/cache-control.decorator';

@Controller('api/products')
export class ProductsController {
  constructor(private readonly productsService: ProductsService) {}

  // Public product list - cache for 5 minutes in browser, 1 hour in CDN
  @Get()
  @CacheControl({
    public: true,
    maxAge: 300,

    staleWhileRevalidate: 600,
  })
  async findAll() {
    return this.productsService.findAll();
  }

  // Individual product - cache for 1 hour
  @Get(':id')
  @CacheControl({
    public: true,
    maxAge: 3600,
    staleWhileRevalidate: 1800,

  async findOne(@Param('id') id: string) {
    return this.productsService.findOne(id);
  }

  // Static categories - cache for 1 day
  @Get('categories')
  @CacheControl({

    maxAge: 86400,

5. Static Files Configuration​

// src/main.ts
import { NestFactory } from '@nestjs/core';
import { NestExpressApplication } from '@nestjs/platform-express';
import { join } from 'path';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create<NestExpressApplication>(AppModule);

  // Serve static files with caching
  app.useStaticAssets(join(__dirname, '..', 'public'), {
    prefix: '/public/',
    maxAge: '1y', // Cache for 1 year
    immutable: true,
    setHeaders: (res, path) => {
      // Different cache strategies based on file type
      if (path.endsWith('.html')) {
        res.setHeader('Cache-Control', 'public, max-age=0, must-revalidate');
      } else if (path.match(/\.(js|css|woff2?|eot|ttf|otf)$/)) {
        res.setHeader('Cache-Control', 'public, max-age=31536000, immutable');
      } else if (path.match(/\.(jpg|jpeg|png|gif|svg|ico)$/)) {
        res.setHeader('Cache-Control', 'public, max-age=86400');
      }
    },
  });

  await app.listen(3000);
}
bootstrap();

7. Conditional Caching Based on Content​

// src/common/interceptors/smart-cache.interceptor.ts
import { Injectable, NestInterceptor, ExecutionContext, CallHandler } from '@nestjs/common';
import { Observable } from 'rxjs';
import { tap } from 'rxjs/operators';
import { Response } from 'express';

@Injectable()
export class SmartCacheInterceptor implements NestInterceptor {
  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    const request = context.switchToHttp().getRequest();
    const response = context.switchToHttp().getResponse<Response>();

    return next.handle().pipe(
      tap((data) => {
        // Don't cache if user is authenticated
        if (request.user) {
          response.setHeader('Cache-Control', 'private, max-age=300, must-revalidate');
          return;
        }

        // Don't cache error responses
        if (response.statusCode >= 400) {
          response.setHeader('Cache-Control', 'no-store, no-cache');
          return;
        }

        // Cache successful public responses
        if (response.statusCode === 200) {
          response.setHeader('Cache-Control', 'public, max-age=600, s-maxage=3600, stale-while-revalidate=1800');
        }
      }),
    );
  }
}

Additional Cache Headers​

Vary Header​

// Next.js
return NextResponse.json(data, {
  headers: {
    'Cache-Control': 'public, max-age=300',
    'Vary': 'Accept-Encoding, Authorization, Accept-Language',
  },
});

// NestJS
@Header('Vary', 'Accept-Encoding, Authorization, Accept-Language')
@CacheControl({ public: true, maxAge: 300 })

Use Vary when cache should differ based on:

  • Accept-Encoding: Different compressed versions
  • Authorization: Different content for authenticated users
  • Accept-Language: Different languages
  • Accept: Different content types (JSON, XML, etc.)

ETag Support​

// NestJS with ETag
import { Etag } from '@nestjs/common';

@Get()
@CacheControl({ public: true, maxAge: 3600 })
@Header('ETag', 'computed-etag-value')
async getData(@Req() req, @Res() res) {
  const data = await this.service.getData();
  const etag = computeETag(data);

  // Check If-None-Match header
  if (req.headers['if-none-match'] === etag) {
    return res.status(304).send();
  }

  res.setHeader('ETag', etag);
  return res.json(data);
}

Last-Modified Header​

// NestJS
@Get()
async getData(@Req() req, @Res() res) {
  const data = await this.service.getData();
  const lastModified = data.updatedAt;

  // Check If-Modified-Since header
  const ifModifiedSince = req.headers['if-modified-since'];
  if (ifModifiedSince && new Date(ifModifiedSince) >= lastModified) {
    return res.status(304).send();
  }

  res.setHeader('Last-Modified', lastModified.toUTCString());
  res.setHeader('Cache-Control', 'public, max-age=3600, must-revalidate');
  return res.json(data);
}

Best Practices Checklist​

Static Assets​

  • Cache forever with immutable (31536000 seconds / 1 year)
  • Use content-based versioning (hashes in filenames)
  • Set public directive
  • Configure CDN for global distribution

HTML Pages​

  • Short cache with revalidation (0-300 seconds)
  • Use must-revalidate for critical content
  • Implement stale-while-revalidate for better UX
  • Set appropriate s-maxage for CDN

API Endpoints​

  • Public data: public, max-age=X, s-maxage=Y
  • User-specific: private, max-age=X
  • Sensitive data: no-store, no-cache
  • Add Vary header when appropriate

Images​

  • Use Next.js Image component (automatic optimization)
  • Set long cache TTL (86400+ seconds)
  • Use stale-while-revalidate
  • Configure CDN image transformations

Security​

  • Never cache sensitive data
  • Use private for user-specific content
  • Set no-store for payment/financial data
  • Implement proper authentication checks

Performance​

  • Use stale-while-revalidate for better UX
  • Configure appropriate max-age values
  • Implement on-demand revalidation
  • Monitor cache hit rates

Complete Example Project Structure​

// next.config.js (Next.js Frontend)
module.exports = {
  async headers() {
    return [
      {
        source: '/:path*.{js,css,woff,woff2}',
        headers: [{ key: 'Cache-Control', value: 'public, max-age=31536000, immutable' }],
      },
      {
        source: '/images/:path*',
        headers: [{ key: 'Cache-Control', value: 'public, max-age=86400, stale-while-revalidate=604800' }],
      },
    ];
  },
};

// app/api/products/route.ts (Next.js API)
export async function GET() {
  const products = await getProducts();
  return NextResponse.json(products, {
    headers: {
      'Cache-Control': 'public, max-age=300, s-maxage=3600, stale-while-revalidate=600',
    },
  });
}

// src/products/products.controller.ts (NestJS Backend)
@Controller('api/products')
export class ProductsController {
  @Get()
  @CacheControl({
    public: true,
    maxAge: 300,
    sMaxAge: 3600,
    staleWhileRevalidate: 600,
  })
  async findAll() {
    return this.productsService.findAll();
  }
}

Troubleshooting​

Cache Not Working​

  1. Check headers in browser:

    curl -I https://your-api.com/endpoint

  2. Verify CDN configuration:

    • Check CDN cache settings
    • Verify origin headers are being passed through

  3. Check for cache-busting:

    • Ensure URLs aren't changing unexpectedly
    • Verify query parameters aren't preventing caching

Content Not Updating​

  1. Clear cache:

    # Cloudflare
    curl -X POST "https://api.cloudflare.com/client/v4/zones/{zone_id}/purge_cache"

    # Vercel
    vercel env pull

  2. Implement on-demand revalidation:

    // Next.js
    await revalidatePath('/products');
    await revalidateTag('products');

  3. Check max-age values:

    • Ensure they're not too long
    • Use stale-while-revalidate for fresh content

Conclusion​

Proper HTTP caching implementation requires:

  1. Next.js Frontend:

    • Use built-in static optimization
    • Configure headers in next.config.js
    • Implement ISR for dynamic content
    • Use next/image for automatic image caching

  2. NestJS Backend:

    • Create reusable decorators and interceptors
    • Set appropriate headers per endpoint
    • Differentiate public vs. private content
    • Implement conditional requests (ETag, Last-Modified)

  3. Best Practices:

    • Cache static assets forever (with versioning)
    • Use short cache for HTML pages
    • Implement stale-while-revalidate
    • Never cache sensitive data
    • Monitor and test regularly

By following this guide, you'll achieve:

  • ⚡ 50-80% reduction in bandwidth
  • 🚀 2-5x faster page loads
  • 💰 Lower hosting and CDN costs
  • 😊 Better user experience

Remember: The best cache is the one that's never noticed by users but significantly improves performance!
