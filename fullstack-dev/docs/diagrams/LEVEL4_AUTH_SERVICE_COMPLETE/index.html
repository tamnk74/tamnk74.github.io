🔍 Key Components Represented​

📋 Controllers Layer​

  • AuthController: REST endpoints for authentication
    • login(), register(), refresh(), logout(), validateToken()

⚙️ Services Layer​

  • AuthService: Core authentication business logic
  • JwtService: JWT token management
  • Auth0Service: OAuth integration

🔐 Strategies Layer​

  • JwtStrategy: Passport JWT validation
  • Auth0Strategy: Passport OAuth validation

💾 Repository Layer​

  • UserRepository: Database operations
    • findByEmail(), findById(), create(), update()

📊 Entity Layer​

  • User Entity: Database model with TypeORM decorators

🎨 Visual Representation Approaches​

1. Component Architecture (level4_auth_service_code.py)​

  • Uses AWS/Generic icons to represent different types of components
  • Shows clear layer separation with clusters
  • Emphasizes dependency relationships
  • Best for understanding overall architecture

2. Class Structure (level4_auth_service_classes.py)​

  • Focuses on TypeScript/NestJS specific annotations
  • Shows decorator usage (@Injectable, @Controller, @Entity)
  • Emphasizes OOP relationships
  • Best for developers familiar with NestJS

  • Shows execution sequences numbered 1-6
  • Demonstrates request/response cycles
  • Highlights external API calls vs internal operations
  • Best for understanding runtime behavior

🚀 Usage​

Generate Individual Auth Service Diagrams:​

cd docs/diagrams
source venv/bin/activate

# Generate specific diagram
python level4_auth_service_code.py
python level4_auth_service_classes.py
python level4_auth_service_flow.py

Generate All Diagrams (Including Auth Service):​

cd docs/diagrams
./generate_all.sh
