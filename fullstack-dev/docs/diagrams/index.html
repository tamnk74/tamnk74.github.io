E-commerce Architecture Diagrams

This directory contains Python scripts that generate architecture diagrams using the diagrams library.

Prerequisites​

  1. Install Python 3.7 or higher

  2. Install Graphviz:

    # macOS
    brew install graphviz

    # Ubuntu/Debian
    sudo apt-get install graphviz

    # Windows
    # Download from https://graphviz.org/download/

  3. Set up virtual environment and install dependencies:

    # Create virtual environment
    python3 -m venv venv

    # Activate virtual environment
    source venv/bin/activate  # On macOS/Linux
    # OR
    venv\Scripts\activate     # On Windows

    # Install required packages
    pip install -r requirements.txt

Quick Start​

Generate all diagrams with these commands:

cd docs/backend/diagrams
source venv/bin/activate  # Activate virtual environment
python level1_system_context.py
python level2_container_diagram.py
python level3_api_gateway_components.py
python infrastructure_architecture.py
python performance_monitoring.py

Generated Diagrams​

1. System Context Diagram (Level 1)​

File: level1_system_context.py

Shows the high-level system context with external actors and systems interacting with the e-commerce platform.

Usage:

python level1_system_context.py

Output: level1_system_context.png

2. Container Diagram (Level 2)​

File: level2_container_diagram.py

Details the major containers (web applications, microservices, databases) and their relationships.

Usage:

python level2_container_diagram.py

Output: level2_container_diagram.png

3. API Gateway Components (Level 3)​

File: level3_api_gateway_components.py

Breaks down the API Gateway container into its internal components (controllers, middleware, services, security).

Usage:

python level3_api_gateway_components.py

Output: level3_api_gateway_components.png

4. Auth Service Code Architecture (Level 4)​

File: level4_auth_service_code.py

Shows the detailed code architecture of the Auth Service with component relationships and dependencies.

Usage:

python level4_auth_service_code.py

Output: level4_auth_service_code.png

5. Auth Service Classes (Level 4)​

File: level4_auth_service_classes.py

Detailed TypeScript/NestJS class structure with decorators, methods, and dependencies.

Usage:

python level4_auth_service_classes.py

Output: level4_auth_service_classes.png

6. Auth Service Method Flow (Level 4)​

File: level4_auth_service_flow.py

Shows the execution flow and method interactions for authentication processes.

Usage:

python level4_auth_service_flow.py

Output: level4_auth_service_flow.png

7. Infrastructure Architecture​

File: infrastructure_architecture.py

Shows the complete GCP infrastructure setup including GKE clusters, managed services, and external integrations.

Usage:

python infrastructure_architecture.py

Output: infrastructure_architecture.png

8. Performance Monitoring​

File: performance_monitoring.py

Illustrates the performance monitoring and testing architecture with observability tools.

Usage:

python performance_monitoring.py

Output: performance_monitoring.png

Running All Diagrams​

To generate all diagrams at once:

# Make sure you're in the diagrams directory
cd docs/backend/diagrams

# Run all scripts
python level1_system_context.py
python level2_container_diagram.py
python level3_api_gateway_components.py
python infrastructure_architecture.py
python performance_monitoring.py

Or create a simple script:

#!/bin/bash
for script in *.py; do
    echo "Generating diagram from $script..."
    python "$script"
done
echo "All diagrams generated!"

Customization​

Each script can be customized by:

  • Modifying the graph_attr dictionary for styling
  • Changing icon types by importing different diagram components
  • Adjusting node labels and relationships
  • Adding or removing components as needed

Available Icon Categories​

The diagrams library provides icons for:

  • AWS: diagrams.aws.*
  • GCP: diagrams.gcp.*
  • Azure: diagrams.azure.*
  • Kubernetes: diagrams.k8s.*
  • Programming: diagrams.programming.*
  • On-Premise: diagrams.onprem.*
  • Generic: diagrams.generic.*

Output Formats​

By default, diagrams are generated as PNG files. You can change the format by modifying the filename parameter:

with Diagram("Title", filename="diagram.svg", show=False):
    # diagram code

Supported formats: PNG, SVG, PDF, DOT

Notes​

  • The show=False parameter prevents the diagram from automatically opening after generation
  • All scripts use splines="ortho" for cleaner orthogonal line routing
  • Font sizes and padding can be adjusted in the graph_attr dictionary
  • Icons are chosen to best represent the actual technologies used in the architecture
