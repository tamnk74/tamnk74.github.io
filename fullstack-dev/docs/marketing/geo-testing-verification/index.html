Testing & Verifying Your GEO Implementation

Overview​

This guide provides comprehensive testing strategies and verification methods to ensure your Generative Engine Optimization (GEO) implementation is working correctly and delivering results.

Quick Verification Checklist​

Before diving into detailed testing, run through this quick checklist:

  • Structured data validates without errors
  • Robots.txt allows AI crawlers
  • Sitemap.xml is generated and accessible
  • Metadata appears correctly in page source
  • Content has clear heading hierarchy
  • All images have descriptive alt text
  • Schema.org markup is present on all pages
  • Mobile responsiveness works properly
  • Page load times are under 3 seconds
  • No console errors in browser

Schema.org Validator​

Online Tool:

https://validator.schema.org/

Automated Testing:

Create scripts/validate-schema.ts:

import * as cheerio from 'cheerio';
import fetch from 'node-fetch';

interface SchemaValidation {
  url: string;
  valid: boolean;
  schemas: string[];
  errors: string[];
}

async function validatePageSchema(url: string): Promise<SchemaValidation> {
  const response = await fetch(url);
  const html = await response.text();
  const $ = cheerio.load(html);

  const schemas: string[] = [];
  const errors: string[] = [];

  // Find all JSON-LD scripts
  $('script[type="application/ld+json"]').each((_, element) => {
    try {
      const jsonLd = JSON.parse($(element).html() || '{}');

      // Check for required @context
      if (!jsonLd['@context']) {
        errors.push('Missing @context in schema');
      }

      // Check for @type
      if (!jsonLd['@type']) {
        errors.push('Missing @type in schema');
      } else {
        schemas.push(jsonLd['@type']);
      }

      // Validate Article schema
      if (jsonLd['@type'] === 'Article') {
        if (!jsonLd.headline) errors.push('Article missing headline');
        if (!jsonLd.author) errors.push('Article missing author');
        if (!jsonLd.datePublished) errors.push('Article missing datePublished');
      }

      // Validate FAQPage schema
      if (jsonLd['@type'] === 'FAQPage') {
        if (!jsonLd.mainEntity) errors.push('FAQPage missing mainEntity');
      }
    } catch (e) {
      errors.push(`Invalid JSON-LD: ${e.message}`);
    }
  });

  return {
    url,
    valid: errors.length === 0,
    schemas,
    errors,
  };
}

async function runValidation() {
  const pages = ['http://localhost:3000', 'http://localhost:3000/articles/example', 'http://localhost:3000/faq'];

  console.log('🔍 Validating Schema.org markup...\n');

  for (const page of pages) {
    const result = await validatePageSchema(page);

    console.log(`\n📄 ${result.url}`);
    console.log(`Status: ${result.valid ? '✅ Valid' : '❌ Invalid'}`);
    console.log(`Schemas found: ${result.schemas.join(', ') || 'None'}`);

    if (result.errors.length > 0) {
      console.log('Errors:');
      result.errors.forEach((error) => console.log(`  - ${error}`));
    }
  }
}

runValidation();

Manual Metadata Check​

Create scripts/check-metadata.ts:

import * as cheerio from 'cheerio';
import fetch from 'node-fetch';

interface MetadataCheck {
  url: string;
  title: boolean;
  description: boolean;
  canonical: boolean;
  ogTitle: boolean;
  ogDescription: boolean;
  ogImage: boolean;
  twitterCard: boolean;
  author: boolean;
  datePublished: boolean;
  issues: string[];
}

async function checkMetadata(url: string): Promise<MetadataCheck> {
  const response = await fetch(url);
  const html = await response.text();
  const $ = cheerio.load(html);

  const issues: string[] = [];

  const check: MetadataCheck = {
    url,
    title: !!$('title').text(),
    description: !!$('meta[name="description"]').attr('content'),
    canonical: !!$('link[rel="canonical"]').attr('href'),
    ogTitle: !!$('meta[property="og:title"]').attr('content'),
    ogDescription: !!$('meta[property="og:description"]').attr('content'),
    ogImage: !!$('meta[property="og:image"]').attr('content'),
    twitterCard: !!$('meta[name="twitter:card"]').attr('content'),
    author: !!$('meta[name="author"]').attr('content'),
    datePublished: !!$('meta[property="article:published_time"]').attr('content'),
    issues,
  };

  // Check for issues
  if (!check.title) issues.push('Missing <title> tag');
  if (!check.description) issues.push('Missing meta description');
  if (!check.canonical) issues.push('Missing canonical URL');
  if (!check.ogTitle) issues.push('Missing og:title');
  if (!check.ogImage) issues.push('Missing og:image');

  // Check title length
  const titleText = $('title').text();
  if (titleText.length < 30) issues.push('Title too short (< 30 chars)');
  if (titleText.length > 60) issues.push('Title too long (> 60 chars)');

  // Check description length
  const descText = $('meta[name="description"]').attr('content') || '';
  if (descText.length < 120) issues.push('Description too short (< 120 chars)');
  if (descText.length > 160) issues.push('Description too long (> 160 chars)');

  return check;
}

async function runMetadataCheck() {
  const pages = ['http://localhost:3000', 'http://localhost:3000/articles/example'];

  console.log('🔍 Checking Metadata...\n');

  for (const page of pages) {
    const result = await checkMetadata(page);

    console.log(`\n📄 ${result.url}`);
    console.log(`✓ Title: ${result.title ? '✅' : '❌'}`);
    console.log(`✓ Description: ${result.description ? '✅' : '❌'}`);
    console.log(`✓ Canonical: ${result.canonical ? '✅' : '❌'}`);
    console.log(`✓ OpenGraph Title: ${result.ogTitle ? '✅' : '❌'}`);
    console.log(`✓ OpenGraph Image: ${result.ogImage ? '✅' : '❌'}`);
    console.log(`✓ Twitter Card: ${result.twitterCard ? '✅' : '❌'}`);

    if (result.issues.length > 0) {
      console.log('\n⚠️  Issues:');
      result.issues.forEach((issue) => console.log(`   - ${issue}`));
    }
  }
}

3. Robots.txt & Sitemap Testing​

Test Robots.txt​

Create scripts/test-robots.ts:

import fs from 'fs';
import path from 'path';

interface RobotsTest {
  crawler: string;
  allowed: boolean;
  reason: string;
}

function testRobotsTxt(): RobotsTest[] {
  const robotsPath = path.join(process.cwd(), 'public', 'robots.txt');

  if (!fs.existsSync(robotsPath)) {
    console.error('❌ robots.txt not found!');
    return [];
  }

  const robotsTxt = fs.readFileSync(robotsPath, 'utf-8');

  const aiCrawlers = ['GPTBot', 'Google-Extended', 'CCBot', 'anthropic-ai', 'Claude-Web', 'cohere-ai'];

  const results: RobotsTest[] = [];

  console.log('🤖 Testing robots.txt for AI crawlers...\n');

  aiCrawlers.forEach((crawler) => {
    // Check if crawler is explicitly allowed
    const allowPattern = new RegExp(`User-agent:\\s*${crawler}[\\s\\S]*?Allow:\\s*/`, 'i');
    const disallowPattern = new RegExp(`User-agent:\\s*${crawler}[\\s\\S]*?Disallow:\\s*/`, 'i');

    let allowed = false;
    let reason = '';

    if (allowPattern.test(robotsTxt)) {
      allowed = true;
      reason = 'Explicitly allowed';
    } else if (disallowPattern.test(robotsTxt)) {
      allowed = false;
      reason = 'Explicitly disallowed';
    } else if (robotsTxt.includes('User-agent: *') && robotsTxt.includes('Allow: /')) {
      allowed = true;
      reason = 'Allowed via wildcard';
    } else {
      allowed = false;
      reason = 'Not configured';
    }

    results.push({ crawler, allowed, reason });

    const status = allowed ? '✅' : '❌';
    console.log(`${status} ${crawler}: ${reason}`);
  });

  // Check for sitemap
  if (robotsTxt.includes('Sitemap:')) {
    console.log('\n✅ Sitemap URL found in robots.txt');
  } else {
    console.log('\n⚠️  No sitemap URL in robots.txt');
  }

  return results;
}

import fetch from 'node-fetch';
import * as cheerio from 'cheerio';

async function validateSitemap(sitemapUrl: string) {
  console.log(`🗺️  Validating sitemap: ${sitemapUrl}\n`);

  try {
    const response = await fetch(sitemapUrl);
    const xml = await response.text();
    const $ = cheerio.load(xml, { xmlMode: true });

    const urls = $('url');
    console.log(`✅ Found ${urls.length} URLs in sitemap\n`);

    // Check each URL
    urls.each((index, element) => {
      const loc = $(element).find('loc').text();
      const lastmod = $(element).find('lastmod').text();
      const priority = $(element).find('priority').text();
      const changefreq = $(element).find('changefreq').text();

      console.log(`${index + 1}. ${loc}`);
      if (lastmod) console.log(`   Last Modified: ${lastmod}`);
      if (priority) console.log(`   Priority: ${priority}`);
      if (changefreq) console.log(`   Change Frequency: ${changefreq}`);
      console.log('');
    });

    // Validate structure
    const issues: string[] = [];

    urls.each((_, element) => {
      const loc = $(element).find('loc').text();
      if (!loc) {
        issues.push('URL missing <loc> tag');
      }
      if (!loc.startsWith('http://') && !loc.startsWith('https://')) {
        issues.push(`Invalid URL format: ${loc}`);
      }
    });

    if (issues.length > 0) {
      console.log('⚠️  Issues found:');
      issues.forEach((issue) => console.log(`   - ${issue}`));
    } else {
      console.log('✅ Sitemap is valid!');
    }
  } catch (error) {
    console.error('❌ Error validating sitemap:', error.message);
  }
}

4. Content Structure Testing​

Heading Hierarchy Validator​

Create scripts/test-headings.ts:

import * as cheerio from 'cheerio';
import fetch from 'node-fetch';

interface HeadingStructure {
  level: number;
  text: string;
  id?: string;
}

async function validateHeadingHierarchy(url: string) {
  const response = await fetch(url);
  const html = await response.text();
  const $ = cheerio.load(html);

  const headings: HeadingStructure[] = [];

  $('h1, h2, h3, h4, h5, h6').each((_, element) => {
    const tag = element.tagName;
    const level = parseInt(tag[1]);
    const text = $(element).text().trim();
    const id = $(element).attr('id');

    headings.push({ level, text, id });
  });

  console.log(`📋 Heading Structure for ${url}\n`);

  const issues: string[] = [];

  // Check for single H1
  const h1Count = headings.filter((h) => h.level === 1).length;
  if (h1Count === 0) {
    issues.push('Missing H1 heading');
  } else if (h1Count > 1) {
    issues.push(`Multiple H1 headings found (${h1Count})`);
  }

  // Check hierarchy
  let previousLevel = 0;
  headings.forEach((heading, index) => {
    const indent = '  '.repeat(heading.level - 1);
    console.log(`${indent}H${heading.level}: ${heading.text}`);

    if (heading.id) {
      console.log(`${indent}     (id: ${heading.id})`);
    } else {
      issues.push(`H${heading.level} missing ID: "${heading.text}"`);
    }

    // Check if skipping levels
    if (heading.level - previousLevel > 1 && previousLevel !== 0) {
      issues.push(`Skipped heading level from H${previousLevel} to H${heading.level}`);
    }

    previousLevel = heading.level;
  });

  console.log('');

  if (issues.length > 0) {
    console.log('⚠️  Issues:');
    issues.forEach((issue) => console.log(`   - ${issue}`));
  } else {
    console.log('✅ Heading hierarchy is valid!');
  }

  return { headings, issues };
}

validateHeadingHierarchy('http://localhost:3000/articles/example');

import puppeteer from 'puppeteer';

async function measureWebVitals(url: string) {
  console.log(`⚡ Measuring Web Vitals for: ${url}\n`);

  const browser = await puppeteer.launch();
  const page = await browser.newPage();

  // Enable performance metrics
  await page.goto(url, { waitUntil: 'networkidle0' });

  const metrics = await page.evaluate(() => {
    return new Promise((resolve) => {
      new PerformanceObserver((list) => {
        const entries = list.getEntries();
        const vitals: any = {};

        entries.forEach((entry: any) => {
          if (entry.name === 'first-contentful-paint') {
            vitals.FCP = entry.startTime;
          }
          if (entry.entryType === 'largest-contentful-paint') {
            vitals.LCP = entry.startTime;
          }
          if (entry.entryType === 'layout-shift') {
            vitals.CLS = entry.value;
          }
        });

        resolve(vitals);
      }).observe({ entryTypes: ['paint', 'largest-contentful-paint', 'layout-shift'] });

      setTimeout(() => resolve({}), 5000);
    });
  });

  console.log('Core Web Vitals:');
  console.log(`  FCP: ${metrics.FCP ? (metrics.FCP / 1000).toFixed(2) + 's' : 'N/A'} (Good: < 1.8s)`);
  console.log(`  LCP: ${metrics.LCP ? (metrics.LCP / 1000).toFixed(2) + 's' : 'N/A'} (Good: < 2.5s)`);
  console.log(`  CLS: ${metrics.CLS || 'N/A'} (Good: < 0.1)`);

  await browser.close();

  return metrics;
}

import fetch from 'node-fetch';

async function simulateAICrawler(url: string, crawler: string) {
  const userAgents: Record<string, string> = {
    GPTBot: 'Mozilla/5.0 AppleWebKit/537.36 (KHTML, like Gecko; compatible; GPTBot/1.0; +https://openai.com/gptbot)',
    'Google-Extended': 'Mozilla/5.0 (compatible; Google-Extended/1.0; +https://www.google.com/bot.html)',
    CCBot: 'CCBot/2.0 (https://commoncrawl.org/faq/)',
    'anthropic-ai': 'anthropic-ai',
  };

  console.log(`🤖 Simulating ${crawler} crawling ${url}\n`);

  try {
    const response = await fetch(url, {
      headers: {
        'User-Agent': userAgents[crawler] || userAgents.GPTBot,
      },
    });

    console.log(`Status: ${response.status} ${response.statusText}`);
    console.log(`Content-Type: ${response.headers.get('content-type')}`);
    console.log(`Content-Length: ${response.headers.get('content-length')}`);

    if (response.status === 200) {
      console.log('✅ Page accessible to AI crawler');

      const html = await response.text();

      // Check for key AI-friendly elements
      const hasJsonLd = html.includes('application/ld+json');
      const hasStructuredHeadings = /<h[1-6]/.test(html);

      console.log(`  Meta Description: ${hasMetaDescription ? '✅' : '❌'}`);
    } else {
      console.log('❌ Page not accessible');
    }
  } catch (error) {
    console.error('❌ Error:', error.message);
  }
}

10. Production Monitoring​

Set Up Monitoring​

Create src/lib/monitoring.ts:

interface GEOMetrics {
  aiReferrals: number;
  schemaErrors: number;
  avgPageLoad: number;
  mobileScore: number;
}

export class GEOMonitor {
  private metrics: GEOMetrics = {
    aiReferrals: 0,
    schemaErrors: 0,
    avgPageLoad: 0,
    mobileScore: 0,
  };

  trackAIReferral(referrer: string) {
    const aiSources = ['chat.openai.com', 'gemini.google.com', 'claude.ai', 'perplexity.ai'];

    if (aiSources.some((source) => referrer.includes(source))) {
      this.metrics.aiReferrals++;

      // Send to analytics
      if (typeof window !== 'undefined' && window.gtag) {
        window.gtag('event', 'ai_referral', {
          event_category: 'GEO',
          event_label: referrer,
          value: 1,
        });
      }
    }
  }

  trackSchemaError(error: string) {
    this.metrics.schemaErrors++;
    console.error('Schema Error:', error);

    // Send to error tracking
    if (typeof window !== 'undefined' && window.gtag) {
      window.gtag('event', 'exception', {
        description: `Schema Error: ${error}`,
        fatal: false,
      });
    }
  }

  trackPageLoad(duration: number) {
    this.metrics.avgPageLoad = (this.metrics.avgPageLoad + duration) / 2;

    if (typeof window !== 'undefined' && window.gtag) {
      window.gtag('event', 'timing_complete', {
        name: 'page_load',
        value: duration,
        event_category: 'GEO Performance',
      });
    }
  }

  getMetrics(): GEOMetrics {
    return { ...this.metrics };
  }
}

export const geoMonitor = new GEOMonitor();

11. Real-World Testing Checklist​

Pre-Launch Checklist​

  • All pages validated with Google Rich Results Test
  • Schema.org validator shows no errors
  • robots.txt allows all AI crawlers
  • sitemap.xml is accessible and valid
  • All images have descriptive alt text
  • Heading hierarchy is logical (single H1, no skipped levels)
  • Meta descriptions are 120-160 characters
  • Page titles are 30-60 characters
  • Mobile responsiveness tested on multiple devices
  • Core Web Vitals meet targets (LCP < 2.5s, FID < 100ms, CLS < 0.1)
  • Accessibility score > 90 (Lighthouse)
  • All internal links work
  • Canonical URLs are correct
  • OpenGraph images are 1200x630px
  • JSON-LD is valid on all pages

Post-Launch Monitoring​

# Weekly checks
npm run test:geo

# Monitor in production
- Check Google Search Console for schema errors
- Track AI referrals in analytics
- Monitor Core Web Vitals
- Review accessibility reports
- Check for broken links
- Validate sitemap updates

Conclusion​

Regular testing ensures your GEO implementation remains effective. Set up automated tests in your CI/CD pipeline and monitor key metrics in production. The combination of automated testing and manual verification will help you maintain AI-friendly, high-quality content that performs well with both users and AI systems.

Testing Frequency Recommendations:

  • Daily: Automated schema validation
  • Weekly: Full GEO test suite
  • Monthly: Manual audit of top pages
  • Quarterly: Comprehensive review and updates
