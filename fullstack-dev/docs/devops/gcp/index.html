Google Cloud Platform (GCP) DevOps Guides

This section contains comprehensive guides for deploying and managing applications on Google Cloud Platform using Kubernetes and other GCP services.

Available Guides​

Kubernetes & GKE​

  • GKE Cluster Setup Guide - Comprehensive guide for setting up Google Kubernetes Engine clusters from scratch, including Standard and Autopilot clusters, security configuration, and best practices.
  • GKE Ingress Setup Guide - Complete guide for setting up ingress controllers in Google Kubernetes Engine, including both GKE Ingress (Google Cloud Load Balancer) and NGINX Ingress Controller options.
  • Deploy NestJS Apps to Kubernetes as Jobs and CronJobs - Complete guide to deploying NestJS applications as Kubernetes Jobs for one-time tasks and CronJobs for scheduled operations. Covers application structure, Docker optimization, Job configurations (one-time, parallel, indexed), CronJob schedules, configuration management with ConfigMaps and Secrets, logging and monitoring with Prometheus, CI/CD integration with GitHub Actions, and production best practices for batch processing and scheduled tasks.

Microservices & Infrastructure as Code​

  • Comprehensive Microservices Architecture with Terraform - Complete Infrastructure as Code solution for deploying production-ready microservices applications on GCP using GKE, Artifact Registry, Secret Manager, Cloud Run, Cloud Storage, Cloud SQL, Redis Memorystore, Pub/Sub, and Filestore with Terraform.

Serverless & Cloud Functions​

  • Deploy Cloud Functions with Node.js and GitHub Actions - Complete guide to deploying Google Cloud Functions using Node.js with automated CI/CD pipelines via GitHub Actions. Covers function types (HTTP, Pub/Sub, Cloud Storage, Scheduled), local development with Functions Framework, environment management with Secret Manager, multi-environment deployments, monitoring and logging, and production best practices including traffic splitting and gradual rollouts.
  • Deploy Cloud Run with Node.js and GitHub Actions - Comprehensive guide to deploying containerized Node.js applications to Cloud Run with automated GitHub Actions workflows. Covers Docker optimization, multi-stage builds, local testing, Artifact Registry, Secret Manager integration, custom domains, SSL certificates, VPC connectivity, Cloud SQL integration, blue-green and canary deployments, monitoring with Cloud Logging and Cloud Monitoring, and production-ready patterns for scalable serverless containers.

Infrastructure & Core Concepts​

  • GCP Project Management - Complete guide to creating and managing GCP projects, including project hierarchy, resource organization, IAM configuration, billing management, organization policies, service accounts, monitoring setup, and advanced multi-project automation with Terraform and Python.
  • GCP Global Infrastructure - Complete guide to GCP's global infrastructure including regions, zones, edge locations, network architecture, high availability patterns, disaster recovery strategies, and best practices for multi-region deployments.
  • GCP VPC Networking - Comprehensive guide to Virtual Private Cloud networking covering VPC concepts, subnets and CIDR notation, IP addressing, firewall rules and network tags, Cloud NAT for outbound internet access, Cloud VPN for hybrid connectivity, and all seven types of GCP load balancers with complete configuration examples.

Architecture & Design Patterns​

  • GCP Architecture Patterns - Top 20 most common web application architectures on GCP with detailed Mermaid diagrams. Covers static websites, three-tier apps, serverless, multi-region, real-time applications, e-commerce, CMS, SaaS, mobile backends, APIs, microservices, event-driven, data pipelines, hybrid cloud, IoT, machine learning, video streaming, gaming, batch processing, and progressive web apps. Includes architecture selection guide and best practices.

Certification & Learning​

  • Google Cloud Professional Cloud Architect - Complete Learning Guide - Comprehensive hands-on learning guide with practical examples and exercises for every topic in the Professional Cloud Architect certification roadmap. Includes code examples, real-world scenarios, and step-by-step tutorials for all GCP services.
  • Google Cloud Professional DevOps Engineer - Complete Learning Guide - Complete learning guide for the Professional DevOps Engineer certification. Covers CI/CD pipelines, SRE practices, monitoring and observability, service mesh, security, cost optimization, and hands-on projects. Includes practical examples, code samples, and exam preparation strategies.

🎯 Roadmap to Google Cloud Professional Cloud Architect Certification​

Overview​

The Google Cloud Professional Cloud Architect certification validates your ability to design, develop, and manage robust, secure, scalable, highly available, and dynamic solutions to drive business objectives using Google Cloud technologies.

Exam Details:

  • Duration: 2 hours
  • Format: Multiple choice and multiple select questions
  • Cost: $200 USD
  • Validity: 2 years
  • Language: English, Japanese, Spanish, Portuguese
  • Delivery: Online or at a test center

Certification Roadmap​

Phase 1: Foundation (2-3 months)​

1.1 Cloud Computing Fundamentals​

Learn:

  • Cloud computing concepts (IaaS, PaaS, SaaS)
  • Cloud deployment models (Public, Private, Hybrid, Multi-cloud)
  • Virtualization and containerization basics
  • Networking fundamentals (TCP/IP, DNS, Load Balancing)
  • Security basics (IAM, encryption, compliance)

Resources:

  • 📚 Cloud Computing Basics - Coursera
  • 📚 Introduction to Cloud Infrastructure Technologies - edX
  • 📖 Google Cloud Documentation - Getting Started

Practice:

# Set up your first GCP account
# Create a free tier project
# Explore the GCP Console
# Install gcloud CLI and configure it

1.2 Google Cloud Fundamentals​

Learn:

  • GCP global infrastructure (Regions, Zones)
  • Core GCP services overview
  • GCP pricing and billing concepts
  • GCP Console navigation
  • Cloud Shell and gcloud CLI

Resources:

  • 📚 Google Cloud Fundamentals: Core Infrastructure (Coursera/Qwiklabs)
  • 📚 GCP Essentials - Qwiklabs Quest
  • 🎥 Google Cloud YouTube Channel

Hands-On Labs:

  • Create and manage GCP projects
  • Use Cloud Console, Cloud Shell, and gcloud CLI
  • Explore IAM roles and permissions
  • Set up billing alerts and budgets

1.3 Networking Basics​

Learn:

  • Virtual Private Cloud (VPC) concepts
  • Subnets, IP addressing, and CIDR notation
  • Firewall rules and network tags
  • Cloud NAT and Cloud VPN
  • Load Balancing types

Practice:

# Create a custom VPC network
gcloud compute networks create my-vpc --subnet-mode=custom

# Create subnets in different regions
gcloud compute networks subnets create subnet-us-east \
  --network=my-vpc \
  --region=us-east1 \
  --range=10.0.1.0/24

# Set up firewall rules
gcloud compute firewall-rules create allow-ssh \
  --network=my-vpc \
  --allow=tcp:22 \
  --source-ranges=0.0.0.0/0

Phase 2: Associate Level (2-3 months)​

2.1 Compute Services​

Master:

  • Compute Engine: VMs, instance templates, managed instance groups
  • App Engine: Standard and Flexible environments
  • Cloud Run: Serverless containers
  • Cloud Functions: Event-driven serverless
  • GKE: Kubernetes basics

Resources:

  • 📚 Architecting with Google Compute Engine
  • 📚 Qwiklabs: Deploy and Manage Cloud Environments

Hands-On Projects:

  • Deploy a multi-tier web application on Compute Engine
  • Create auto-scaling managed instance groups
  • Deploy containerized apps on Cloud Run
  • Set up a simple GKE cluster

2.2 Storage Services​

Master:

  • Cloud Storage: Buckets, storage classes, lifecycle policies
  • Cloud SQL: MySQL, PostgreSQL managed databases
  • Cloud Spanner: Global distributed database
  • Firestore: NoSQL document database
  • Bigtable: NoSQL wide-column database
  • Persistent Disk: Block storage

Practice:

# Create Cloud Storage bucket with lifecycle policy
gsutil mb -c STANDARD -l us-central1 gs://my-bucket-name/

# Create Cloud SQL instance
gcloud sql instances create my-instance \
  --database-version=POSTGRES_14 \
  --tier=db-f1-micro \
  --region=us-central1

# Set up automated backups
gcloud sql backups create \
  --instance=my-instance \
  --description="Weekly backup"

2.3 Identity and Access Management​

Master:

  • IAM concepts: Users, Groups, Service Accounts
  • Predefined and custom roles
  • IAM policies and conditions
  • Organization policies
  • Resource hierarchy

Hands-On:

  • Create service accounts with minimal permissions
  • Implement least privilege principle
  • Set up organization policies
  • Use IAM Recommender

Phase 3: Professional Level (3-4 months)​

3.1 Designing and Planning​

Study Areas:

  • Business and technical requirements analysis
  • Application design patterns (microservices, event-driven, serverless)
  • Data processing design (batch, streaming, ML pipelines)
  • Migration strategies (lift-and-shift, re-platform, re-architect)
  • Compliance and regulatory requirements (HIPAA, PCI-DSS, GDPR)

Key Topics:

  • Solution design methodology
  • High-level architecture diagrams (C4 model)
  • Technology selection criteria
  • Cost-benefit analysis
  • ROI calculations

Resources:

  • 📚 Preparing for Google Cloud Architect Exam
  • 📖 Cloud Architecture Center
  • 📖 Google Cloud Architecture Framework

3.2 Managing and Provisioning Infrastructure​

Master:

  • Infrastructure as Code (Terraform, Deployment Manager)
  • Configuration management
  • Container orchestration with GKE
  • CI/CD pipelines (Cloud Build, Artifact Registry)
  • GitOps workflows

Practice Projects:

# Example: Terraform GKE cluster
resource "google_container_cluster" "primary" {
  name     = "production-cluster"
  location = "us-central1"

  initial_node_count = 1

  node_config {
    machine_type = "e2-medium"
    oauth_scopes = [
      "https://www.googleapis.com/auth/cloud-platform"
    ]
  }

  workload_identity_config {
    workload_pool = "${var.project_id}.svc.id.goog"
  }

  addons_config {
    http_load_balancing {
      disabled = false
    }
    horizontal_pod_autoscaling {
      disabled = false
    }
  }
}

3.3 Security and Compliance​

Master:

  • Encryption at rest and in transit
  • Secret Manager and KMS
  • VPC Service Controls
  • Binary Authorization
  • Security Command Center
  • Cloud Armor (WAF, DDoS protection)
  • Certificate Manager
  • Identity-Aware Proxy (IAP)

Hands-On:

# Enable Binary Authorization
gcloud container clusters update CLUSTER_NAME \
  --enable-binauthz

# Create a KMS key ring and key
gcloud kms keyrings create my-keyring --location=global

gcloud kms keys create my-key \
  --location=global \
  --keyring=my-keyring \
  --purpose=encryption

# Store secrets
gcloud secrets create my-secret \
  --replication-policy="automatic" \
  --data-file=/path/to/secret.txt

Master:

  • VPC network design and subnetting
  • Hybrid connectivity (Cloud VPN, Interconnect)
  • Load Balancing (Global, Regional, Internal)

  • Network security (Cloud IDS, Cloud NAT)

3.5 Monitoring, Logging, and Observability​

Master:

  • Cloud Monitoring (metrics, dashboards, alerts)
  • Cloud Logging (log aggregation, queries, exports)
  • Cloud Trace (distributed tracing)
  • Cloud Profiler (performance profiling)
  • Error Reporting
  • SLIs, SLOs, SLAs design
  • Uptime checks and synthetic monitoring

Practice:

# Example: Monitoring alert policy
apiVersion: monitoring.coreos.com/v1
kind: PrometheusRule
metadata:
  name: high-error-rate
spec:
  groups:
    - name: error-alerts
      rules:
        - alert: HighErrorRate
          expr: rate(http_requests_total{status="500"}[5m]) > 0.05
          for: 10m
          annotations:
            summary: 'High error rate detected'

Tips for Success​

Study Tips​

  1. Hands-On Practice is Critical

    • Theory alone is not enough
    • Build real projects using GCP services
    • Practice with gcloud CLI commands
    • Use Cloud Console regularly

  2. Understand WHY, Not Just HOW

    • Understand architectural decisions
    • Know when to use which service
    • Compare alternatives (e.g., Cloud Run vs. GKE vs. App Engine)
    • Understand trade-offs (cost, performance, complexity)

  3. Master Core Services First

    • Compute: Compute Engine, GKE, Cloud Run
    • Storage: Cloud Storage, Cloud SQL, Firestore
    • Networking: VPC, Load Balancing, Cloud CDN
    • Security: IAM, VPC Service Controls, KMS

  4. Think Like an Architect

    • Consider scalability, availability, reliability
    • Balance cost vs. performance
    • Design for security from the start
    • Plan for disaster recovery
    • Consider operational complexity

Exam Tips​

  1. Question Strategy

    • Read the question stem carefully
    • Identify keywords: "MOST cost-effective", "LEAST operational overhead", "MOST secure"
    • Eliminate obviously wrong answers first
    • Consider GCP-native solutions over third-party when appropriate
    • Think about managed services vs. self-managed

  2. Time Management

    • 50 questions in 120 minutes = ~2.4 minutes per question
    • Don't spend more than 2 minutes on any question
    • Flag difficult questions and return later
    • Reserve 15-20 minutes for review

  3. Common Pitfalls to Avoid

    • Over-engineering solutions
    • Choosing legacy services over modern alternatives
    • Ignoring cost optimization
    • Forgetting about compliance requirements
    • Not considering operational overhead

Prerequisites for GCP Guides​

Before following any GCP guides in this section, ensure you have:

  1. Google Cloud Account: Access to a Google Cloud Platform account
  2. Project Setup: A GCP project with billing enabled
  3. gcloud CLI: Google Cloud SDK installed and configured
  4. kubectl: Kubernetes command-line tool installed
  5. Required APIs: Relevant GCP APIs enabled for your project

Common GCP APIs to Enable​

# Enable commonly used APIs
gcloud services enable compute.googleapis.com
gcloud services enable container.googleapis.com
gcloud services enable certificatemanager.googleapis.com
gcloud services enable dns.googleapis.com

Authentication Setup​

# Authenticate with Google Cloud
gcloud auth login

# Set your project
gcloud config set project YOUR_PROJECT_ID

# Get kubectl credentials for your cluster
gcloud container clusters get-credentials CLUSTER_NAME --zone=ZONE --project=PROJECT_ID
