GCP Project Management: Create and Manage Projects

Overview​

Google Cloud Platform (GCP) projects are the fundamental organizational units that contain all your GCP resources. Understanding how to create and manage projects effectively is essential for maintaining organized, secure, and cost-effective cloud infrastructure.

What is a GCP Project?​

A GCP project is a logical container that:

  • Organizes Resources: Groups related cloud resources (VMs, databases, storage, etc.)
  • Manages Billing: Tracks and manages costs for all resources within the project
  • Controls Access: Provides IAM boundary for permissions and security policies
  • Isolates Environments: Separates development, staging, and production workloads
  • Enables APIs: Manages which Google Cloud APIs are enabled

Project Hierarchy​

Key Concepts​

Project Identifiers​

Every GCP project has three identifiers:

  1. Project Name: Human-readable name (can be changed)

    • Example: Production Web Application
    • Used for display purposes

  2. Project ID: Globally unique identifier (permanent, cannot be changed)

    • Example: prod-webapp-2024
    • Must be 6-30 characters (lowercase letters, numbers, hyphens)
    • Used in API calls and resource URLs

  3. Project Number: Automatically assigned numeric ID (permanent)

    • Example: 123456789012
    • Used internally by GCP services

Resource Hierarchy Levels​

Organization (example.com)
    └── Folders (Production, Development, Teams)
        └── Projects (individual workload containers)
            └── Resources (VMs, databases, storage buckets)

Creating GCP Projects​

Method 1: Using Google Cloud Console​

Step-by-Step Guide​

  1. Navigate to Project Selector

    • Go to Google Cloud Console
    • Click on the project dropdown at the top
    • Click "New Project"

  2. Configure Project Details

    Project Name: My Production Application
    Project ID: my-prod-app-2024 (or auto-generated)
    Organization: example.com (if applicable)
    Location: production-folder (if using folders)

  3. Set Billing Account

    • Select appropriate billing account
    • Configure budget alerts

  4. Click "Create"

    • Wait for project creation (usually 30-60 seconds)

Method 2: Using gcloud CLI​

Basic Project Creation​

# Set your organization ID (if applicable)
export ORG_ID="123456789012"

# Create a new project
gcloud projects create my-prod-app-2024 \
  --name="My Production Application" \
  --organization=${ORG_ID}

# Verify project creation
gcloud projects describe my-prod-app-2024

Create Project with Folder​

# List available folders
gcloud resource-manager folders list --organization=${ORG_ID}

# Create project in specific folder

gcloud projects create my-prod-app-2024 \
  --name="My Production Application" \
  --folder=${FOLDER_ID}

# List available billing accounts
gcloud billing accounts list

# Get your billing account ID
export BILLING_ACCOUNT_ID="01ABCD-234567-89ABCD"

# Link billing account to project
gcloud billing projects link my-prod-app-2024 \
  --billing-account=${BILLING_ACCOUNT_ID}

# Verify billing is enabled
gcloud billing projects describe my-prod-app-2024

Method 4: Using Python API Client​

# project_manager.py
from google.cloud import resourcemanager_v3
from google.api_core import retry
import time

class GCPProjectManager:
    """Manages GCP project creation and configuration"""

    def __init__(self, organization_id=None, folder_id=None):
        self.client = resourcemanager_v3.ProjectsClient()
        self.organization_id = organization_id
        self.folder_id = folder_id

    def create_project(self, project_id, display_name, labels=None):
        """
        Create a new GCP project

        Args:
            project_id: Unique project ID (6-30 chars)
            display_name: Human-readable project name
            labels: Dictionary of project labels

        Returns:
            Project object
        """
        # Prepare project request
        project = resourcemanager_v3.Project()
        project.project_id = project_id
        project.display_name = display_name

        # Set parent (organization or folder)
        if self.folder_id:
            project.parent = f"folders/{self.folder_id}"
        elif self.organization_id:
            project.parent = f"organizations/{self.organization_id}"

        # Add labels
        if labels:
            project.labels = labels

        # Create project
        request = resourcemanager_v3.CreateProjectRequest(project=project)

        try:
            operation = self.client.create_project(request=request)
            print(f"Creating project {project_id}...")

            # Wait for operation to complete
            result = operation.result(timeout=300)
            print(f"✅ Project {project_id} created successfully")
            return result

        except Exception as e:
            print(f"❌ Error creating project: {e}")
            raise

    def get_project(self, project_id):
        """Get project details"""
        name = f"projects/{project_id}"
        request = resourcemanager_v3.GetProjectRequest(name=name)

        try:
            project = self.client.get_project(request=request)
            return project
        except Exception as e:
            print(f"❌ Error getting project: {e}")
            return None

    def list_projects(self, parent=None):
        """List all projects in organization or folder"""
        if parent is None:
            if self.folder_id:
                parent = f"folders/{self.folder_id}"
            elif self.organization_id:
                parent = f"organizations/{self.organization_id}"

        request = resourcemanager_v3.ListProjectsRequest(parent=parent)

        try:
            projects = self.client.list_projects(request=request)
            return list(projects)
        except Exception as e:
            print(f"❌ Error listing projects: {e}")
            return []

    def update_project(self, project_id, display_name=None, labels=None):
        """Update project properties"""
        project = self.get_project(project_id)

        if not project:
            print(f"❌ Project {project_id} not found")
            return None

        update_mask = []

        if display_name:
            project.display_name = display_name
            update_mask.append("display_name")

        if labels:
            project.labels = labels
            update_mask.append("labels")

        if not update_mask:
            print("⚠️ No updates specified")
            return project

        request = resourcemanager_v3.UpdateProjectRequest(
            project=project,
            update_mask={"paths": update_mask}
        )

        try:
            updated_project = self.client.update_project(request=request)
            print(f"✅ Project {project_id} updated successfully")
            return updated_project
        except Exception as e:
            print(f"❌ Error updating project: {e}")
            return None

    def delete_project(self, project_id):
        """Delete a project (move to trash)"""
        name = f"projects/{project_id}"
        request = resourcemanager_v3.DeleteProjectRequest(name=name)

        try:
            operation = self.client.delete_project(request=request)
            operation.result(timeout=300)
            print(f"✅ Project {project_id} deleted (moved to trash)")
            return True
        except Exception as e:
            print(f"❌ Error deleting project: {e}")
            return False

    def undelete_project(self, project_id):
        """Restore a deleted project from trash"""
        name = f"projects/{project_id}"
        request = resourcemanager_v3.UndeleteProjectRequest(name=name)

        try:
            operation = self.client.undelete_project(request=request)
            operation.result(timeout=300)
            print(f"✅ Project {project_id} restored from trash")
            return True
        except Exception as e:
            print(f"❌ Error undeleting project: {e}")
            return False


# Usage example

IAM and Access Control​

Grant Project-Level IAM Roles​

# Grant user Editor role
gcloud projects add-iam-policy-binding my-prod-app-2024 \
  --member="user:developer@example.com" \
  --role="roles/editor"

# Grant group Viewer role
gcloud projects add-iam-policy-binding my-prod-app-2024 \
  --member="group:team@example.com" \
  --role="roles/viewer"

# Grant service account specific role
gcloud projects add-iam-policy-binding my-prod-app-2024 \
  --member="serviceAccount:terraform@my-prod-app-2024.iam.gserviceaccount.com" \
  --role="roles/owner"

# Grant role with condition
gcloud projects add-iam-policy-binding my-prod-app-2024 \
  --member="user:contractor@example.com" \
  --role="roles/editor" \
  --condition='expression=request.time < timestamp("2024-12-31T23:59:59Z"),title=Temporary Access,description=Access expires on Dec 31, 2024'

View and Export IAM Policies​

# Get IAM policy
gcloud projects get-iam-policy my-prod-app-2024

# Export to file
gcloud projects get-iam-policy my-prod-app-2024 \
  --format=yaml > project-iam-policy.yaml

# List members with specific role
gcloud projects get-iam-policy my-prod-app-2024 \
  --flatten="bindings[].members" \
  --filter="bindings.role:roles/owner" \
  --format="table(bindings.members)"

Remove IAM Bindings​

# Remove user from role
gcloud projects remove-iam-policy-binding my-prod-app-2024 \
  --member="user:developer@example.com" \
  --role="roles/editor"

# Remove all members from role
gcloud projects get-iam-policy my-prod-app-2024 \
  --format=json | \
  jq -r '.bindings[] | select(.role=="roles/editor") | .members[]' | \
  while read member; do
    gcloud projects remove-iam-policy-binding my-prod-app-2024 \
      --member="$member" \
      --role="roles/editor"
  done

Multi-Project Setup Script​

#!/bin/bash
# create-project-suite.sh
# Creates a complete suite of projects for an application

set -e

# Configuration
APP_NAME="myapp"
ORG_ID="123456789012"
BILLING_ACCOUNT="01ABCD-234567-89ABCD"
REGION="us-central1"
ZONE="us-central1-a"

# Project IDs
PROD_PROJECT="${APP_NAME}-prod"
STAGING_PROJECT="${APP_NAME}-staging"
DEV_PROJECT="${APP_NAME}-dev"
SHARED_PROJECT="${APP_NAME}-shared"

# Common APIs to enable
COMMON_APIS=(
  "compute.googleapis.com"
  "container.googleapis.com"
  "storage.googleapis.com"
  "cloudresourcemanager.googleapis.com"
  "iam.googleapis.com"
  "monitoring.googleapis.com"
  "logging.googleapis.com"
  "cloudkms.googleapis.com"
  "secretmanager.googleapis.com"
)

# Function to create and configure project
create_project() {
  local project_id=$1
  local env=$2

  echo "Creating project: ${project_id}"

  # Create project
  gcloud projects create ${project_id} \
    --name="${APP_NAME} ${env}" \
    --organization=${ORG_ID} \
    --labels=environment=${env},app=${APP_NAME}

  # Link billing
  gcloud billing projects link ${project_id} \
    --billing-account=${BILLING_ACCOUNT}

  # Enable APIs
  echo "Enabling APIs for ${project_id}..."
  for api in "${COMMON_APIS[@]}"; do
    gcloud services enable ${api} --project=${project_id}
  done

  # Set default region/zone
  gcloud config set project ${project_id}
  gcloud config set compute/region ${REGION}
  gcloud config set compute/zone ${ZONE}

  # Create service account for Terraform
  gcloud iam service-accounts create terraform \
    --display-name="Terraform Service Account" \
    --project=${project_id}

  # Grant roles to Terraform service account
  gcloud projects add-iam-policy-binding ${project_id} \
    --member="serviceAccount:terraform@${project_id}.iam.gserviceaccount.com" \
    --role="roles/editor"

  # Create log bucket
  gsutil mb -p ${project_id} -c STANDARD -l ${REGION} \
    gs://${project_id}-logs

  # Set up log sink
  gcloud logging sinks create storage-sink \
    storage.googleapis.com/${project_id}-logs \
    --log-filter='severity >= ERROR' \
    --project=${project_id}

  echo "✅ Project ${project_id} created and configured"
}

# Create all projects
echo "🚀 Starting multi-project setup for ${APP_NAME}"

create_project ${PROD_PROJECT} "production"
create_project ${STAGING_PROJECT} "staging"
create_project ${DEV_PROJECT} "development"
create_project ${SHARED_PROJECT} "shared"

echo "✅ All projects created successfully!"

# Summary
echo ""
echo "📋 Project Summary:"
echo "  Production:  ${PROD_PROJECT}"
echo "  Staging:     ${STAGING_PROJECT}"
echo "  Development: ${DEV_PROJECT}"
echo "  Shared:      ${SHARED_PROJECT}"
echo ""
echo "🔐 Next steps:"
echo "  1. Configure IAM permissions for team members"
echo "  2. Set up VPC and networking"
echo "  3. Configure Shared VPC (if needed)"
echo "  4. Set up monitoring and alerting"
echo "  5. Deploy applications"

Shared VPC Configuration​

#!/bin/bash
# setup-shared-vpc.sh
# Configure Shared VPC across projects

# Host project (shared networking)
HOST_PROJECT="myapp-shared"

# Service projects
PROD_PROJECT="myapp-prod"
STAGING_PROJECT="myapp-staging"
DEV_PROJECT="myapp-dev"

# Enable host project
echo "Enabling Shared VPC on host project..."
gcloud compute shared-vpc enable ${HOST_PROJECT}

# Attach service projects
echo "Attaching service projects..."
gcloud compute shared-vpc associated-projects add ${PROD_PROJECT} \
  --host-project=${HOST_PROJECT}

gcloud compute shared-vpc associated-projects add ${STAGING_PROJECT} \
  --host-project=${HOST_PROJECT}

gcloud compute shared-vpc associated-projects add ${DEV_PROJECT} \
  --host-project=${HOST_PROJECT}

# Create shared VPC network
echo "Creating shared VPC network..."
gcloud compute networks create shared-vpc \
  --subnet-mode=custom \
  --project=${HOST_PROJECT}

# Create subnets for each environment
gcloud compute networks subnets create prod-subnet \
  --network=shared-vpc \
  --region=us-central1 \
  --range=10.0.0.0/24 \
  --enable-private-ip-google-access \
  --project=${HOST_PROJECT}

gcloud compute networks subnets create staging-subnet \
  --network=shared-vpc \
  --region=us-central1 \
  --range=10.0.1.0/24 \
  --enable-private-ip-google-access \
  --project=${HOST_PROJECT}

gcloud compute networks subnets create dev-subnet \
  --network=shared-vpc \
  --region=us-central1 \
  --range=10.0.2.0/24 \
  --enable-private-ip-google-access \
  --project=${HOST_PROJECT}

# Configure firewall rules
echo "Creating firewall rules..."
gcloud compute firewall-rules create allow-internal \
  --network=shared-vpc \
  --allow=tcp,udp,icmp \
  --source-ranges=10.0.0.0/16 \
  --project=${HOST_PROJECT}

gcloud compute firewall-rules create allow-ssh \
  --network=shared-vpc \
  --allow=tcp:22 \
  --source-ranges=35.235.240.0/20 \
  --project=${HOST_PROJECT}

# Grant service project admins subnet IAM roles
for project in ${PROD_PROJECT} ${STAGING_PROJECT} ${DEV_PROJECT}; do
  # Get service project admins
  gcloud projects get-iam-policy ${project} \
    --flatten="bindings[].members" \
    --filter="bindings.role:roles/editor" \
    --format="value(bindings.members)" | \
  while read member; do
    # Grant compute.networkUser role on shared subnet
    subnet_name=$(echo ${project} | cut -d'-' -f2)-subnet
    gcloud compute networks subnets add-iam-policy-binding ${subnet_name} \
      --region=us-central1 \
      --member="${member}" \
      --role="roles/compute.networkUser" \
      --project=${HOST_PROJECT}
  done
done

echo "✅ Shared VPC configuration complete!"

Project Inventory and Audit Script​

#!/usr/bin/env python3
# project_inventory.py
# Generate comprehensive inventory of all GCP projects

from google.cloud import resourcemanager_v3, billing_v1
from google.cloud import compute_v1
from google.cloud import storage
import pandas as pd
from datetime import datetime
import json

class ProjectInventory:
    """Generate comprehensive project inventory and reports"""

    def __init__(self, organization_id):
        self.organization_id = organization_id
        self.projects_client = resourcemanager_v3.ProjectsClient()
        self.billing_client = billing_v1.CloudBillingClient()
        self.compute_client = compute_v1.InstancesClient()
        self.storage_client = storage.Client()
        self.inventory = []

    def list_all_projects(self):
        """List all projects in organization"""
        parent = f"organizations/{self.organization_id}"
        request = resourcemanager_v3.ListProjectsRequest(parent=parent)

        projects = self.projects_client.list_projects(request=request)
        return list(projects)

    def get_project_billing(self, project_id):
        """Get billing information for project"""
        name = f"projects/{project_id}/billingInfo"

        try:
            billing_info = self.billing_client.get_project_billing_info(name=name)
            return {
                'billing_enabled': billing_info.billing_enabled,
                'billing_account': billing_info.billing_account_name
            }
        except Exception as e:
            return {
                'billing_enabled': False,
                'billing_account': 'N/A',
                'error': str(e)
            }

    def count_compute_instances(self, project_id):
        """Count running compute instances"""
        try:
            zones = ['us-central1-a', 'us-central1-b', 'us-east1-b', 'europe-west1-b']
            total = 0

            for zone in zones:
                try:
                    request = compute_v1.ListInstancesRequest(
                        project=project_id,
                        zone=zone
                    )
                    instances = self.compute_client.list(request=request)
                    total += len(list(instances))
                except:
                    continue

            return total
        except Exception as e:
            return 0

    def count_storage_buckets(self, project_id):
        """Count storage buckets"""
        try:
            buckets = list(self.storage_client.list_buckets(project=project_id))
            return len(buckets)
        except Exception as e:
            return 0

    def analyze_project(self, project):
        """Comprehensive project analysis"""
        project_id = project.project_id

        print(f"Analyzing project: {project_id}")

        # Get billing info
        billing = self.get_project_billing(project_id)

        # Count resources
        compute_instances = self.count_compute_instances(project_id)
        storage_buckets = self.count_storage_buckets(project_id)

        # Extract labels
        labels = dict(project.labels) if project.labels else {}

        return {
            'project_id': project_id,
            'project_name': project.display_name,
            'project_number': project.name.split('/')[-1],
            'state': project.state.name,
            'parent': project.parent,
            'billing_enabled': billing['billing_enabled'],
            'billing_account': billing.get('billing_account', 'N/A'),
            'compute_instances': compute_instances,
            'storage_buckets': storage_buckets,
            'environment': labels.get('environment', 'unknown'),
            'team': labels.get('team', 'unknown'),
            'cost_center': labels.get('cost_center', 'unknown'),
            'labels': json.dumps(labels),
            'created_at': project.create_time.strftime('%Y-%m-%d') if project.create_time else 'unknown'
        }

    def generate_report(self):
        """Generate comprehensive inventory report"""
        projects = self.list_all_projects()

        print(f"\n📊 Found {len(projects)} projects. Analyzing...\n")

        for project in projects:
            project_data = self.analyze_project(project)
            self.inventory.append(project_data)

        # Create DataFrame
        df = pd.DataFrame(self.inventory)

        # Save to CSV
        timestamp = datetime.now().strftime('%Y%m%d_%H%M%S')
        csv_filename = f'project_inventory_{timestamp}.csv'
        df.to_csv(csv_filename, index=False)

        # Save to Excel with formatting
        excel_filename = f'project_inventory_{timestamp}.xlsx'
        with pd.ExcelWriter(excel_filename, engine='openpyxl') as writer:
            df.to_excel(writer, sheet_name='Projects', index=False)

            # Summary sheet
            summary_data = {
                'Metric': [
                    'Total Projects',
                    'Active Projects',
                    'Deleted Projects',
                    'Projects with Billing',
                    'Total Compute Instances',
                    'Total Storage Buckets',
                    'Production Projects',
                    'Development Projects',
                    'Staging Projects'
                ],
                'Count': [
                    len(df),
                    len(df[df['state'] == 'ACTIVE']),
                    len(df[df['state'] == 'DELETE_REQUESTED']),
                    len(df[df['billing_enabled'] == True]),
                    df['compute_instances'].sum(),
                    df['storage_buckets'].sum(),
                    len(df[df['environment'] == 'production']),
                    len(df[df['environment'] == 'development']),
                    len(df[df['environment'] == 'staging'])
                ]
            }
            summary_df = pd.DataFrame(summary_data)
            summary_df.to_excel(writer, sheet_name='Summary', index=False)

        print(f"\n✅ Reports generated:")
        print(f"  📄 CSV: {csv_filename}")
        print(f"  📊 Excel: {excel_filename}")

        # Print summary
        self.print_summary(df)

        return df

    def print_summary(self, df):
        """Print summary statistics"""
        print("\n" + "="*60)
        print("PROJECT INVENTORY SUMMARY")
        print("="*60)
        print(f"Total Projects: {len(df)}")
        print(f"Active Projects: {len(df[df['state'] == 'ACTIVE'])}")
        print(f"Projects with Billing: {len(df[df['billing_enabled'] == True])}")
        print(f"\nEnvironment Breakdown:")
        print(df['environment'].value_counts().to_string())
        print(f"\nTotal Resources:")
        print(f"  Compute Instances: {df['compute_instances'].sum()}")
        print(f"  Storage Buckets: {df['storage_buckets'].sum()}")
        print(f"\nTop 5 Projects by Compute Instances:")
        print(df.nlargest(5, 'compute_instances')[['project_id', 'compute_instances']].to_string(index=False))
        print("="*60 + "\n")


# Run inventory
if __name__ == "__main__":
    import sys

    if len(sys.argv) < 2:
        print("Usage: python project_inventory.py <organization_id>")
        sys.exit(1)

    org_id = sys.argv[1]

    print(f"🔍 Generating project inventory for organization: {org_id}\n")

    inventory = ProjectInventory(org_id)
    inventory.generate_report()

3. Security Best Practices​

✅ Do:

  • Use service accounts with minimal permissions
  • Enable organization policies
  • Implement least privilege access
  • Use Cloud Identity for user management
  • Enable audit logging
  • Use VPC Service Controls for sensitive data
  • Implement binary authorization for containers
  • Use Secret Manager for sensitive data
  • Enable OS Login on Compute Engine instances
  • Use Workload Identity for GKE

❌ Don't:

  • Share service account keys
  • Grant Owner role unless necessary
  • Disable audit logging
  • Use default service accounts
  • Store secrets in environment variables
  • Allow public bucket access without review
  • Skip organization policies
  • Use wildcard firewall rules
  • Grant project-level IAM when resource-level is sufficient

Troubleshooting​

Common Issues and Solutions​

1. Billing Not Enabled​

# Error: "Billing has not been enabled for this project"

# Solution:
gcloud billing accounts list
gcloud billing projects link ${PROJECT_ID} \
  --billing-account=${BILLING_ACCOUNT_ID}

2. API Not Enabled​

# Error: "API [service.googleapis.com] not enabled on project"

# Solution:
gcloud services enable service.googleapis.com --project=${PROJECT_ID}

# Enable multiple APIs at once
gcloud services enable \
  compute.googleapis.com \
  container.googleapis.com \
  storage.googleapis.com \
  --project=${PROJECT_ID}

3. Insufficient Permissions​

# Error: "User does not have permission to access project"

# Solution: Grant appropriate IAM role
gcloud projects add-iam-policy-binding ${PROJECT_ID} \
  --member="user:email@example.com" \
  --role="roles/viewer"

4. Quota Exceeded​

# Error: "Quota exceeded for quota metric 'Instances' and limit 'Instances per project'"

# Solution: Request quota increase
# 1. Go to: IAM & Admin > Quotas
# 2. Filter for the quota
# 3. Select and click "EDIT QUOTAS"
# 4. Enter new limit and submit request

# Or use gcloud (alpha)
gcloud alpha services quota update \
  --service=compute.googleapis.com \
  --consumer=projects/${PROJECT_ID} \
  --metric=compute.googleapis.com/instances \
  --value=100

5. Project ID Already Exists​

# Error: "Project ID already exists"

# Solution: Choose a different project ID
# Project IDs must be globally unique across all GCP

gcloud projects create ${PROJECT_ID}-v2 \
  --name="My Project V2"

6. Cannot Delete Project with Active Resources​

# Error: "The project has active resources"

# Solution: Delete all resources first
