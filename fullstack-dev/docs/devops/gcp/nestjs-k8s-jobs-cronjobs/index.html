Introduction​

Kubernetes Jobs and CronJobs are essential for running batch processing, data migrations, scheduled tasks, and maintenance operations. This guide covers:

  • Jobs: Run-to-completion tasks that execute once and terminate
  • CronJobs: Scheduled tasks that run at specified intervals
  • NestJS Integration: How to structure NestJS applications for job execution
  • Production Patterns: Error handling, retries, monitoring, and scaling

Prerequisites​

  • Kubernetes cluster (GKE, EKS, or local with Minikube/Kind)
  • kubectl configured
  • Docker installed
  • Node.js 18+ and NestJS CLI
  • Basic understanding of Kubernetes concepts

Understanding Kubernetes Jobs and CronJobs​

Kubernetes Jobs​

A Job creates one or more Pods and ensures they successfully terminate. Jobs are ideal for:

  • Database migrations
  • Data processing tasks
  • One-time imports/exports
  • Cleanup operations

Key Features:

  • Runs until successful completion
  • Automatic retry on failure
  • Parallel execution support
  • Completion tracking

Kubernetes CronJobs​

A CronJob creates Jobs on a recurring schedule using cron format. Perfect for:

  • Scheduled reports
  • Periodic data synchronization
  • Automated backups
  • Cache warming
  • Cleanup tasks

Key Features:

  • Cron schedule syntax
  • Concurrency control
  • History limits
  • Deadline management

Main Application (main.ts)​

import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { Logger } from '@nestjs/common';

async function bootstrap() {
  const logger = new Logger('Bootstrap');

  const app = await NestFactory.create(AppModule, {
    logger: ['error', 'warn', 'log', 'debug', 'verbose'],
  });

  // For jobs, we don't need to listen on a port
  // Jobs will execute and exit
  logger.log('Application initialized for job execution');

  await app.init();

  return app;
}

Job Runner (job-runner.ts)​

import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { Logger } from '@nestjs/common';

async function runJob() {
  const logger = new Logger('JobRunner');

  try {
    logger.log('Starting job execution...');

    const app = await NestFactory.createApplicationContext(AppModule, {
      logger: ['error', 'warn', 'log', 'debug'],
    });

    // Get job name from environment variable or command line
    const jobName = process.env.JOB_NAME || process.argv[2];

    if (!jobName) {
      throw new Error('JOB_NAME environment variable or argument is required');
    }

    logger.log(`Executing job: ${jobName}`);

    // Get the job service based on job name
    const jobsModule = app.select(JobsModule);

    switch (jobName) {
      case 'database-migration':
        const migrationJob = jobsModule.get(DatabaseMigrationJob);
        await migrationJob.execute();
        break;
      case 'data-export':
        const exportJob = jobsModule.get(DataExportJob);
        await exportJob.execute();
        break;
      case 'cleanup':
        const cleanupJob = jobsModule.get(CleanupJob);
        await cleanupJob.execute();
        break;
      default:
        throw new Error(`Unknown job: ${jobName}`);
    }

    logger.log(`Job ${jobName} completed successfully`);
    await app.close();
    process.exit(0);
  } catch (error) {
    logger.error(`Job failed: ${error.message}`, error.stack);
    process.exit(1);
  }
}

runJob();

import { Injectable, Logger } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';

@Injectable()
export class DatabaseMigrationJob {
  private readonly logger = new Logger(DatabaseMigrationJob.name);

  constructor(private configService: ConfigService) {}

  async execute(): Promise<void> {
    this.logger.log('Starting database migration...');

    const startTime = Date.now();
    let recordsProcessed = 0;

    try {
      // Get configuration
      const batchSize = this.configService.get<number>('BATCH_SIZE', 1000);
      const maxRetries = this.configService.get<number>('MAX_RETRIES', 3);

      this.logger.log(`Configuration: batchSize=${batchSize}, maxRetries=${maxRetries}`);

      // Simulate migration logic
      // In real scenario, connect to database and perform migration

      // Example: Process records in batches
      const totalRecords = 10000; // Get from database

      for (let offset = 0; offset < totalRecords; offset += batchSize) {
        await this.processBatch(offset, batchSize, maxRetries);
        recordsProcessed += Math.min(batchSize, totalRecords - offset);

        // Log progress
        const progress = ((recordsProcessed / totalRecords) * 100).toFixed(2);
        this.logger.log(`Progress: ${recordsProcessed}/${totalRecords} (${progress}%)`);
      }

      const duration = Date.now() - startTime;
      this.logger.log(`Migration completed successfully in ${duration}ms`);
      this.logger.log(`Total records processed: ${recordsProcessed}`);
    } catch (error) {
      this.logger.error(`Migration failed: ${error.message}`, error.stack);
      throw error;
    }
  }

  private async processBatch(offset: number, batchSize: number, maxRetries: number): Promise<void> {
    let retries = 0;

    while (retries < maxRetries) {
      try {
        // Simulate batch processing
        await this.delay(100);

        // Your actual migration logic here
        this.logger.debug(`Processed batch: offset=${offset}, size=${batchSize}`);
        return;
      } catch (error) {
        retries++;
        this.logger.warn(`Batch processing failed (attempt ${retries}/${maxRetries}): ${error.message}`);

        if (retries >= maxRetries) {
          throw error;
        }

        // Exponential backoff
        await this.delay(Math.pow(2, retries) * 1000);
      }
    }
  }

  private delay(ms: number): Promise<void> {
    return new Promise((resolve) => setTimeout(resolve, ms));
  }
}

Example Job: Data Export (jobs/data-export.job.ts)​

import { Injectable, Logger } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';
import * as fs from 'fs/promises';
import * as path from 'path';

@Injectable()
export class DataExportJob {
  private readonly logger = new Logger(DataExportJob.name);

  constructor(private configService: ConfigService) {}

  async execute(): Promise<void> {
    this.logger.log('Starting data export...');

    const startTime = Date.now();

    try {
      const exportFormat = this.configService.get<string>('EXPORT_FORMAT', 'csv');
      const exportPath = this.configService.get<string>('EXPORT_PATH', '/tmp/exports');
      const timestamp = new Date().toISOString().replace(/[:.]/g, '-');
      const filename = `export-${timestamp}.${exportFormat}`;
      const fullPath = path.join(exportPath, filename);

      this.logger.log(`Exporting to: ${fullPath}`);

      // Create export directory if it doesn't exist
      await fs.mkdir(exportPath, { recursive: true });

      // Fetch data (example)
      const data = await this.fetchData();

      // Export based on format
      switch (exportFormat) {
        case 'csv':
          await this.exportToCSV(data, fullPath);
          break;
        case 'json':
          await this.exportToJSON(data, fullPath);
          break;
        default:
          throw new Error(`Unsupported export format: ${exportFormat}`);
      }

      const stats = await fs.stat(fullPath);
      const duration = Date.now() - startTime;

      this.logger.log(`Export completed successfully in ${duration}ms`);
      this.logger.log(`File size: ${(stats.size / 1024 / 1024).toFixed(2)} MB`);
      this.logger.log(`Records exported: ${data.length}`);
    } catch (error) {
      this.logger.error(`Export failed: ${error.message}`, error.stack);
      throw error;
    }
  }

  private async fetchData(): Promise<any[]> {
    // Simulate data fetching
    this.logger.log('Fetching data from database...');
    await this.delay(500);

    // Return mock data
    return Array.from({ length: 1000 }, (_, i) => ({
      id: i + 1,
      name: `Record ${i + 1}`,
      createdAt: new Date().toISOString(),
    }));
  }

  private async exportToCSV(data: any[], filepath: string): Promise<void> {
    this.logger.log('Converting to CSV format...');

    if (data.length === 0) {
      throw new Error('No data to export');
    }

    // Create CSV header
    const headers = Object.keys(data[0]).join(',');

    // Create CSV rows
    const rows = data.map((row) =>
      Object.values(row)
        .map((val) => `"${val}"`)
        .join(','),
    );

    const csv = [headers, ...rows].join('\n');

    await fs.writeFile(filepath, csv, 'utf-8');
    this.logger.log('CSV export completed');
  }

  private async exportToJSON(data: any[], filepath: string): Promise<void> {
    this.logger.log('Converting to JSON format...');

    const json = JSON.stringify(data, null, 2);
    await fs.writeFile(filepath, json, 'utf-8');

    this.logger.log('JSON export completed');
  }

  private delay(ms: number): Promise<void> {
    return new Promise((resolve) => setTimeout(resolve, ms));
  }
}

Example Job: Cleanup (jobs/cleanup.job.ts)​

import { Injectable, Logger } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';

@Injectable()
export class CleanupJob {
  private readonly logger = new Logger(CleanupJob.name);

  constructor(private configService: ConfigService) {}

  async execute(): Promise<void> {
    this.logger.log('Starting cleanup job...');

    const startTime = Date.now();
    let totalDeleted = 0;

    try {
      const retentionDays = this.configService.get<number>('RETENTION_DAYS', 30);
      const cutoffDate = new Date();
      cutoffDate.setDate(cutoffDate.getDate() - retentionDays);

      this.logger.log(`Cleaning up records older than: ${cutoffDate.toISOString()}`);

      // Clean up old logs
      const logsDeleted = await this.cleanupOldLogs(cutoffDate);
      totalDeleted += logsDeleted;

      // Clean up temporary files
      const filesDeleted = await this.cleanupTempFiles(cutoffDate);
      totalDeleted += filesDeleted;

      // Clean up expired sessions
      const sessionsDeleted = await this.cleanupExpiredSessions(cutoffDate);
      totalDeleted += sessionsDeleted;

      const duration = Date.now() - startTime;
      this.logger.log(`Cleanup completed successfully in ${duration}ms`);
      this.logger.log(`Total items deleted: ${totalDeleted}`);
    } catch (error) {
      this.logger.error(`Cleanup failed: ${error.message}`, error.stack);
      throw error;
    }
  }

  private async cleanupOldLogs(cutoffDate: Date): Promise<number> {
    this.logger.log('Cleaning up old logs...');

    // Simulate cleanup
    await this.delay(200);
    const deleted = Math.floor(Math.random() * 100);

    this.logger.log(`Deleted ${deleted} old log entries`);

  private async cleanupTempFiles(cutoffDate: Date): Promise<number> {

}

Building Docker Images​

Multi-Stage Dockerfile​

Create an optimized Dockerfile for job execution:

# Build stage
FROM node:18-alpine AS builder

WORKDIR /app

# Copy package files
COPY package*.json ./

# Install dependencies
RUN npm ci --only=production && \
    npm cache clean --force

# Copy source code
COPY . .

# Build application
RUN npm run build

# Production stage
FROM node:18-alpine

# Install dumb-init for proper signal handling
RUN apk add --no-cache dumb-init

# Create non-root user
RUN addgroup -g 1001 -S nodejs && \
    adduser -S nestjs -u 1001

WORKDIR /app

# Copy dependencies and built application
COPY --from=builder --chown=nestjs:nodejs /app/node_modules ./node_modules
COPY --from=builder --chown=nestjs:nodejs /app/dist ./dist
COPY --from=builder --chown=nestjs:nodejs /app/package*.json ./

# Switch to non-root user
USER nestjs

# Use dumb-init to handle signals properly
ENTRYPOINT ["dumb-init", "--"]

# Default command (can be overridden by Kubernetes)
CMD ["node", "dist/job-runner.js"]

Kubernetes Jobs​

Basic Job (k8s/jobs/migration.job.yaml)​

apiVersion: batch/v1
kind: Job
metadata:
  name: database-migration
  namespace: default
  labels:
    app: nestjs-jobs
    job-type: migration
spec:
  # Job will be deleted 1 hour after completion
  ttlSecondsAfterFinished: 3600

  # Number of retries before marking as failed
  backoffLimit: 3

  # Maximum time for job to complete
  activeDeadlineSeconds: 1800 # 30 minutes

  template:
    metadata:
      labels:
        app: nestjs-jobs
        job-type: migration
    spec:
      restartPolicy: OnFailure

      # Service account for accessing GCP resources
      serviceAccountName: nestjs-jobs-sa

      containers:
        - name: migration
          image: gcr.io/YOUR_PROJECT_ID/nestjs-jobs:latest
          imagePullPolicy: Always

          # Override default command
          command: ['node', 'dist/job-runner.js']

          env:
            - name: JOB_NAME
              value: 'database-migration'
            - name: NODE_ENV
              value: 'production'
            - name: BATCH_SIZE
              value: '1000'
            - name: MAX_RETRIES
              value: '3'

          # Resource limits
          resources:
            requests:
              memory: '256Mi'
              cpu: '250m'
            limits:
              memory: '512Mi'
              cpu: '500m'

          # Liveness and readiness probes not needed for jobs
          # but you can add a startup probe if needed

      # Node selector for specific node pools
      nodeSelector:
        workload-type: batch

Kubernetes CronJobs​

Daily Report CronJob (k8s/cronjobs/daily-report.cronjob.yaml)​

apiVersion: batch/v1
kind: CronJob
metadata:
  name: daily-report
  namespace: default
  labels:
    app: nestjs-jobs
    job-type: report
spec:
  # Run at 2 AM every day
  schedule: '0 2 * * *'

  # Timezone support (Kubernetes 1.25+)
  timeZone: 'America/New_York'

  # Keep last 3 successful and 1 failed jobs
  successfulJobsHistoryLimit: 3
  failedJobsHistoryLimit: 1

  # Don't start new job if previous is still running
  concurrencyPolicy: Forbid

  # Don't start if missed by more than 100 seconds
  startingDeadlineSeconds: 100

  jobTemplate:
    metadata:
      labels:
        app: nestjs-jobs
        job-type: report
    spec:
      ttlSecondsAfterFinished: 86400 # 24 hours
      backoffLimit: 2
      activeDeadlineSeconds: 1800

      template:
        spec:
          restartPolicy: OnFailure
          serviceAccountName: nestjs-jobs-sa

          containers:
            - name: report-generator
              image: gcr.io/YOUR_PROJECT_ID/nestjs-jobs:latest

              env:
                - name: JOB_NAME
                  value: 'daily-report'
                - name: NODE_ENV
                  value: 'production'
                - name: REPORT_DATE
                  value: "$(date -d 'yesterday' '+%Y-%m-%d')"

              envFrom:
                - configMapRef:
                    name: job-config
                - secretRef:
                    name: job-secrets

              resources:
                requests:
                  memory: '512Mi'
                  cpu: '500m'
                limits:
                  memory: '1Gi'
                  cpu: '1000m'

Job Metrics with Prometheus​

// src/jobs/metrics.service.ts
import { Injectable } from '@nestjs/common';
import { Counter, Histogram, register } from 'prom-client';

@Injectable()
export class MetricsService {
  private readonly jobDuration: Histogram;
  private readonly jobTotal: Counter;
  private readonly jobErrors: Counter;

  constructor() {
    this.jobDuration = new Histogram({
      name: 'job_duration_seconds',
      help: 'Duration of job execution in seconds',
      labelNames: ['job_name', 'status'],
      buckets: [1, 5, 10, 30, 60, 300, 600, 1800, 3600],
    });

    this.jobTotal = new Counter({
      name: 'job_executions_total',
      help: 'Total number of job executions',
      labelNames: ['job_name', 'status'],
    });

    this.jobErrors = new Counter({
      name: 'job_errors_total',
      help: 'Total number of job errors',
      labelNames: ['job_name', 'error_type'],
    });
  }

  recordJobDuration(jobName: string, duration: number, status: string) {
    this.jobDuration.labels(jobName, status).observe(duration);
  }

  incrementJobTotal(jobName: string, status: string) {
    this.jobTotal.labels(jobName, status).inc();
  }

  incrementJobErrors(jobName: string, errorType: string) {
    this.jobErrors.labels(jobName, errorType).inc();
  }

  getMetrics(): string {
    return register.metrics();
  }
}

Update Job Runner with Metrics​

// src/job-runner.ts (updated)
import { MetricsService } from './jobs/metrics.service';

async function runJob() {
  const logger = new Logger('JobRunner');
  const startTime = Date.now();
  let status = 'success';

  try {
    const app = await NestFactory.createApplicationContext(AppModule);
    const metricsService = app.get(MetricsService);
    const jobName = process.env.JOB_NAME || process.argv[2];

    // ... job execution logic ...

    const duration = (Date.now() - startTime) / 1000;
    metricsService.recordJobDuration(jobName, duration, status);
    metricsService.incrementJobTotal(jobName, status);

    await app.close();
    process.exit(0);
  } catch (error) {
    status = 'failed';
    const duration = (Date.now() - startTime) / 1000;

    metricsService.recordJobDuration(jobName, duration, status);
    metricsService.incrementJobTotal(jobName, status);
    metricsService.incrementJobErrors(jobName, error.name);

    logger.error(`Job failed: ${error.message}`, error.stack);
    process.exit(1);
  }
}

  } catch (error) {

3. Idempotency​

// Make jobs idempotent
async execute(): Promise<void> {
  const lockKey = `job:${this.jobName}:${this.runId}`;

  // Acquire lock
  const acquired = await this.acquireLock(lockKey);
  if (!acquired) {
    this.logger.warn('Job already running, skipping');
    return;
  }

  try {
    // Check if already completed
    if (await this.isCompleted()) {
      this.logger.log('Job already completed, skipping');
      return;
    }

    // Execute job
    await this.doWork();

    // Mark as completed
    await this.markCompleted();
  } finally {
    await this.releaseLock(lockKey);
  }
}
