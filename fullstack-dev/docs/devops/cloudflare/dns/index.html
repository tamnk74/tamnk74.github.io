Cloudflare DNS Configuration Guide

This guide will walk you through the process of configuring DNS on Cloudflare for your domain.

Overview​

Cloudflare DNS provides fast, secure, and reliable DNS resolution with built-in DDoS protection, WAF, and CDN capabilities. When you use Cloudflare as your DNS provider, your DNS records are propagated across Cloudflare's global network, improving speed and reliability.

Prerequisites​

  • A Cloudflare account (sign up here)
  • A registered domain name
  • Access to your domain registrar's control panel

Key Concepts​

DNS Records​

DNS records contain information about your domain and are used to make your website or application available to visitors and other web services. Common record types include:

  • A Record: Maps a domain to an IPv4 address
  • AAAA Record: Maps a domain to an IPv6 address
  • CNAME Record: Maps a domain to another domain (canonical name)
  • MX Record: Specifies mail servers for your domain
  • TXT Record: Stores text information, often used for verification and security

Nameservers​

Nameservers are authoritative DNS servers that respond to queries about your domain. When you use Cloudflare DNS, you'll update your domain's nameservers to point to Cloudflare's nameservers.

Proxy Status​

Cloudflare offers two proxy modes for A, AAAA, and CNAME records:

  • Proxied (Orange Cloud): Traffic routes through Cloudflare's network, enabling CDN, DDoS protection, WAF, and other security features. Cloudflare responds with anycast IPs.
  • DNS Only (Grey Cloud): DNS resolution only, traffic goes directly to your origin server without Cloudflare's protection features.

Getting Started​

Step 1: Add Your Domain to Cloudflare​

  1. Log in to your Cloudflare dashboard
  2. Click Add a Site or Add Domain
  3. Enter your domain name (e.g., example.com)
  4. Click Add Site
  5. Select your plan (Free, Pro, Business, or Enterprise)

Step 2: Review and Import DNS Records​

Cloudflare will automatically scan and import your existing DNS records:

  1. Review the imported DNS records
  2. Add any missing records manually
  3. Remove any incorrect or unnecessary records
  4. Verify that all critical records are present:
    • A/AAAA records for your main domain and www subdomain
    • MX records for email
    • Any CNAME records for subdomains
    • TXT records for domain verification and email authentication (SPF, DKIM, DMARC)
warning

Make sure all necessary DNS records are configured before updating nameservers. If you activate Cloudflare without proper DNS records, your domain may become unreachable.

Step 3: Update Nameservers​

  1. Cloudflare will provide you with two nameserver addresses (e.g., alice.ns.cloudflare.com and bob.ns.cloudflare.com)
  2. Log in to your domain registrar's control panel
  3. Find the nameserver settings (often under "DNS Management" or "Domain Settings")
  4. Replace existing nameservers with the Cloudflare nameservers
  5. Save the changes
info

Nameserver changes can take up to 24-48 hours to propagate globally, though they often complete within a few hours.

Step 4: Verify Nameserver Update​

  1. Return to your Cloudflare dashboard
  2. Click Done, check nameservers
  3. Cloudflare will verify the nameserver update
  4. You'll receive an email confirmation when your site is active on Cloudflare

You can also manually check nameserver propagation using:

# Check current nameservers
dig NS example.com

# Or using nslookup
nslookup -type=NS example.com

Managing DNS Records​

Creating DNS Records​

Via Dashboard​

  1. Log in to Cloudflare dashboard
  2. Select your domain
  3. Navigate to DNS > Records
  4. Click Add Record
  5. Select the record type
  6. Enter the required information:
    • Name: Subdomain or @ for root domain
    • Content: IP address, domain, or text value
    • Proxy status: Toggle between proxied and DNS-only
    • TTL: Time to live (Auto recommended for proxied records)
  7. Click Save

Example: Adding an A Record​

Type: A
Name: @
IPv4 address: 192.0.2.1
Proxy status: Proxied (Orange Cloud)
TTL: Auto

Example: Adding a CNAME Record​

Type: CNAME
Name: www
Target: example.com
Proxy status: Proxied (Orange Cloud)
TTL: Auto

Example: Adding an MX Record​

Type: MX
Name: @
Mail server: mail.example.com
Priority: 10
TTL: Auto

Via API​

You can also manage DNS records using the Cloudflare API:

curl -X POST "https://api.cloudflare.com/client/v4/zones/{zone_id}/dns_records" \
  -H "Authorization: Bearer {api_token}" \
  -H "Content-Type: application/json" \
  --data '{
    "type": "A",
    "name": "example.com",
    "content": "192.0.2.1",
    "ttl": 1,
    "proxied": true
  }'

Common DNS Configurations​

Configure Root Domain and WWW​

# Root domain
Type: A
Name: @
Content: 192.0.2.1
Proxied: Yes

# WWW subdomain
Type: CNAME
Name: www
Content: example.com
Proxied: Yes

Configure Email (MX Records)​

Type: MX
Name: @
Content: mail.example.com
Priority: 10

Type: A
Name: mail
Content: 192.0.2.2
Proxied: No (Email should not be proxied)

Configure Subdomain​

Type: A
Name: blog
Content: 192.0.2.3
Proxied: Yes

Configure Domain Verification (TXT Record)​

Type: TXT
Name: @
Content: "v=spf1 include:_spf.example.com ~all"

Best Practices​

1. Use Proxied Records for HTTP/HTTPS Traffic​

Enable the orange cloud (proxied) for web traffic to benefit from:

  • CDN and caching
  • DDoS protection
  • WAF (Web Application Firewall)
  • SSL/TLS encryption

2. Don't Proxy Non-HTTP Services​

Keep these services in DNS-only mode (grey cloud):

  • Email (MX records)
  • FTP
  • SSH
  • Custom protocols

3. Set Appropriate TTL Values​

  • Use Auto for proxied records (Cloudflare optimizes automatically)
  • Use lower TTL (300-3600 seconds) when making frequent changes
  • Use higher TTL (86400 seconds) for stable records to improve performance

4. Implement Email Authentication​

Add SPF, DKIM, and DMARC records to prevent email spoofing:

# SPF Record
Type: TXT
Name: @
Content: "v=spf1 include:_spf.google.com ~all"

# DMARC Record
Type: TXT
Name: _dmarc
Content: "v=DMARC1; p=quarantine; rua=mailto:dmarc@example.com"

5. Regular DNS Audits​

  • Review DNS records periodically
  • Remove unused or outdated records
  • Verify all records are correctly configured
  • Check for security records (CAA, DMARC, etc.)

Advanced Features​

DNSSEC​

DNSSEC adds cryptographic signatures to DNS records to prevent DNS spoofing:

  1. Go to DNS > Settings
  2. Enable DNSSEC
  3. Add the DS record to your domain registrar

Secondary DNS​

Configure Cloudflare as a secondary DNS provider for redundancy:

  1. Go to DNS > Settings
  2. Enable Secondary DNS
  3. Configure zone transfers

DNS Analytics​

Monitor DNS queries and performance:

  1. Navigate to Analytics > DNS
  2. View query statistics, response times, and geographic distribution

Troubleshooting​

Domain Not Resolving​

  1. Verify nameservers are correctly updated at your registrar
  2. Check DNS record configuration
  3. Wait for DNS propagation (up to 48 hours)
  4. Use online tools like WhatsMyDNS.net

Email Not Working​

  1. Ensure MX records are configured correctly
  2. Verify mail server A/AAAA records exist
  3. Check that email-related records are not proxied (grey cloud)
  4. Verify SPF and DMARC records

SSL/TLS Errors​

  1. Check SSL/TLS settings in Cloudflare dashboard
  2. Ensure you're using appropriate SSL mode (Full or Full Strict recommended)
  3. Verify origin server has valid SSL certificate

Checking DNS Resolution​

# Check DNS resolution
dig example.com

# Check specific record type
dig A example.com
dig MX example.com
dig TXT example.com

# Check from specific nameserver
dig @alice.ns.cloudflare.com example.com

# Trace DNS resolution path
dig +trace example.com

Next Steps​

After configuring DNS:

  1. Enable SSL/TLS encryption
  2. Configure security settings (WAF, DDoS protection)
  3. Set up page rules for caching and redirects
  4. Configure Cloudflare Workers for edge computing
  5. Monitor analytics and performance metrics
