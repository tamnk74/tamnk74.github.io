Cilium Setup Instructions

Cilium is a powerful, eBPF-based networking, security, and observability solution for Kubernetes. Follow these steps to install and configure Cilium in your GKE or any Kubernetes cluster.

Prerequisites​

  • A running Kubernetes cluster (GKE, EKS, AKS, or self-managed)
  • kubectl configured for your cluster
  • Helm (recommended for installation)

1. Install Cilium CLI​

curl -L --remote-name https://github.com/cilium/cilium-cli/releases/latest/download/cilium-darwin-arm64.tar.gz
tar xzvf cilium-darwin-arm64.tar.gz
sudo mv cilium /usr/local/bin

For other platforms, see the Cilium CLI installation guide.

2. Install Cilium with Helm​

Add the Cilium Helm repository:

helm repo add cilium https://helm.cilium.io/
helm repo update

Install Cilium (basic example):

helm install cilium cilium/cilium --version 1.15.0 \
	--namespace kube-system \
	--set kubeProxyReplacement=strict \
	--set k8sServiceHost=<API_SERVER> \
	--set k8sServicePort=443

Replace <API_SERVER> with your Kubernetes API server address if required.

For GKE, see Cilium on GKE guide.

3. Verify Cilium Installation​

cilium status

You should see all components healthy.

4. Enable Hubble Observability (Optional)​

helm upgrade cilium cilium/cilium --namespace kube-system --reuse-values \
	--set hubble.relay.enabled=true \
	--set hubble.ui.enabled=true

cilium hubble enable
cilium hubble port-forward&

Access the Hubble UI at http://localhost:12000/.

5. Apply Network Policies (Example)​

apiVersion: cilium.io/v2
kind: CiliumNetworkPolicy
metadata:
	name: allow-frontend-to-backend
spec:
	endpointSelector:
		matchLabels:
			app: backend
	ingress:
	- fromEndpoints:
		- matchLabels:
				app: frontend

References​

Usage Examples​

1. Inspect Network Flows with Hubble CLI​

cilium hubble observe --namespace default --follow

This command streams live network flow logs for the default namespace.

2. List All Cilium Network Policies​

kubectl get ciliumnetworkpolicies -A

3. Example: Deny All Traffic Except from Frontend​

apiVersion: cilium.io/v2
kind: CiliumNetworkPolicy
metadata:
	name: backend-deny-all-except-frontend
spec:
	endpointSelector:
		matchLabels:
			app: backend
	ingress:
		- fromEndpoints:
				- matchLabels:
						app: frontend
	egress:
		- toEndpoints:
				- matchLabels:
						app: database

4. Example: L7 HTTP Policy (Allow Only GET)​

apiVersion: cilium.io/v2
kind: CiliumNetworkPolicy
metadata:
	name: allow-get-only
spec:
	endpointSelector:
		matchLabels:
			app: api
	ingress:
		- toPorts:
				- ports:
						- port: "80"
							protocol: TCP
					rules:
						http:
							- method: "GET"

5. Example: Audit All DNS Requests​

apiVersion: cilium.io/v2
kind: CiliumNetworkPolicy
metadata:
	name: audit-dns
spec:
	endpointSelector: {}
	egress:
		- toPorts:
				- ports:
						- port: "53"
							protocol: ANY
					rules:
						dns:
							- matchPattern: ".*"
	egressDeny:
		- toPorts:
				- ports:
						- port: "53"
							protocol: ANY
