Google Cloud Services Overview​

This comprehensive overview covers all major Google Cloud Platform services, organized by category, to help you understand the full GCP ecosystem and how different services integrate with Cloud Storage.

🖥️ Compute Services​

Compute Engine​

Description: Virtual machines running in Google's data centers.

Key Features:

  • Custom machine types
  • Preemptible VMs for cost savings
  • Live migration with zero downtime
  • GPU and TPU support

Storage Integration:

# Mount Cloud Storage bucket to VM using Cloud Storage FUSE
gcsfuse my-bucket /mnt/gcs-bucket

# Create VM with attached persistent disk
gcloud compute instances create my-vm \
  --machine-type=n2-standard-4 \
  --zone=us-central1-a \
  --boot-disk-size=50GB \
  --create-disk=size=500GB,type=pd-ssd

Use Cases: Web servers, batch processing, legacy applications

Google Kubernetes Engine (GKE)​

Description: Managed Kubernetes service for containerized applications.

Key Features:

  • Autopilot mode (fully managed)
  • Multi-cluster management
  • Binary Authorization
  • Workload Identity for secure service access

Storage Integration:

# PersistentVolume using Cloud Storage
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: gcs-pvc
spec:
  accessModes:
    - ReadWriteMany
  storageClassName: gcsfuse-csi
  resources:
    requests:
      storage: 100Gi
---
# Use GCS bucket in pod
apiVersion: v1
kind: Pod
metadata:
  name: app-pod
spec:
  containers:
    - name: app
      image: my-app:latest
      volumeMounts:
        - name: gcs-volume
          mountPath: /data
  volumes:
    - name: gcs-volume
      persistentVolumeClaim:
        claimName: gcs-pvc

Use Cases: Microservices, CI/CD, ML training, multi-region apps

App Engine​

Description: Fully managed serverless platform for apps.

Key Features:

  • Auto-scaling
  • Multiple language runtimes
  • Built-in services (memcache, task queues)
  • Version management

Storage Integration:

# Python App Engine with Cloud Storage
from google.cloud import storage
from flask import Flask, request

app = Flask(__name__)
storage_client = storage.Client()

@app.route('/upload', methods=['POST'])
def upload_file():
    file = request.files['file']
    bucket = storage_client.bucket('my-app-uploads')
    blob = bucket.blob(f'uploads/{file.filename}')
    blob.upload_from_file(file)
    return {'url': blob.public_url}

Use Cases: Web applications, APIs, mobile backends

Cloud Functions​

Description: Event-driven serverless compute platform.

Key Features:

  • Auto-scaling from zero
  • Event triggers (HTTP, Pub/Sub, Storage)
  • Multiple language support
  • Pay per execution

Storage Integration:

// Trigger on Cloud Storage upload
import { CloudEvent } from '@google-cloud/functions-framework';

export async function processUpload(cloudEvent: CloudEvent) {
  const file = cloudEvent.data;
  console.log(`File uploaded: ${file.name}`);

  // Process file...
}

Use Cases: Data processing, webhooks, event handlers

Cloud Run​

Description: Fully managed compute platform for containerized apps.

Key Features:

  • Serverless containers
  • Auto-scaling to zero
  • Custom domains and SSL
  • WebSocket support

Storage Integration:

# Cloud Run service with GCS access
apiVersion: serving.knative.dev/v1
kind: Service
metadata:
  name: file-processor
spec:
  template:
    metadata:
      annotations:
        autoscaling.knative.dev/maxScale: '100'
    spec:
      serviceAccountName: processor-sa@project.iam.gserviceaccount.com
      containers:
        - image: gcr.io/project/processor:latest
          env:
            - name: BUCKET_NAME
              value: 'processed-files'
          resources:
            limits:
              memory: '2Gi'
              cpu: '2'

Use Cases: APIs, background jobs, web applications

💾 Storage & Database Services​

Cloud Storage​

Description: Object storage for unstructured data.

Storage Classes:

# Standard - Frequent access
gsutil mb -c STANDARD gs://hot-data

# Nearline - Access ~1/month
gsutil mb -c NEARLINE gs://warm-data

# Coldline - Access ~1/quarter
gsutil mb -c COLDLINE gs://cold-data

# Archive - Access <1/year
gsutil mb -c ARCHIVE gs://archive-data

Features:

  • 11 9's durability
  • Lifecycle management
  • Object versioning
  • Requester Pays

Cloud SQL​

Description: Fully managed relational databases (MySQL, PostgreSQL, SQL Server).

Key Features:

  • Automatic backups
  • High availability
  • Read replicas
  • Point-in-time recovery

Integration Example:

// Export Cloud SQL to Cloud Storage
import { google } from 'googleapis';

const sqladmin = google.sqladmin('v1beta4');

async function exportDatabase() {
  await sqladmin.instances.export({
    project: 'my-project',
    instance: 'my-instance',
    requestBody: {
      exportContext: {
        kind: 'sql#exportContext',
        fileType: 'SQL',
        uri: 'gs://backups/database-export.sql',
        databases: ['production'],
      },
    },
  });
}

Cloud Spanner​

Description: Globally distributed, strongly consistent database.

Key Features:

  • Horizontal scaling
  • ACID transactions
  • 99.999% availability
  • Multi-region replication

Backup to Storage:

# Create backup
gcloud spanner backups create my-backup \
  --instance=my-instance \
  --database=my-database \
  --retention-period=7d

# Export to Cloud Storage
gcloud spanner databases export \
  --instance=my-instance \
  --database=my-database \
  --destination=gs://exports/spanner-export

Firestore​

Description: NoSQL document database for mobile, web, and server development.

Key Features:

  • Real-time sync
  • Offline support
  • Flexible querying
  • Security rules

Backup Integration:

# Schedule Firestore backups to GCS
gcloud firestore export gs://firestore-backups \
  --collection-ids=users,orders,products

Bigtable​

Description: NoSQL wide-column database for analytics and ML.

Key Features:

  • Petabyte scale
  • Sub-10ms latency
  • HBase compatible
  • Time-series data

Data Import from GCS:

# Import data from Cloud Storage
gcloud bigtable instances tables create my-table \
  --instance=my-instance

# Import from CSV in GCS
gcloud bigtable instances tables import \
  --instance=my-instance \
  --table=my-table \
  --source=gs://imports/data.csv

Memorystore​

Description: Fully managed Redis and Memcached.

Key Features:

  • High availability
  • Auto-failover
  • In-memory performance
  • VPC peering

Use Case: Session storage, caching Cloud Storage metadata

📊 Data Analytics & Big Data​

BigQuery​

Description: Serverless, highly scalable data warehouse.

Key Features:

  • Petabyte-scale analysis
  • Machine learning (BQML)
  • Real-time analytics
  • Standard SQL
