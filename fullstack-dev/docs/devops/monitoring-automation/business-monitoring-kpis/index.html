Business Monitoring & KPI Observability

Business Monitoring is the proactive, process-oriented oversight of user and revenue flows. By mapping critical indicators (conversion rate, number of sold items, active users, average response time, etc.) and publishing them in real time, engineering teams spot regressions quickly, keep business stakeholders informed, and reduce defects caused by misunderstandings of business targets. This guide shows how to implement Business Monitoring for a Next.js frontend and NestJS backend on Google Cloud Platform (GCP) with GitHub Actions automation.

3. Instrumentation Patterns​

3.1 Next.js Frontend Metrics​

// app/api/metrics/route.ts (Next.js 13+)
import { NextRequest, NextResponse } from 'next/server';
import { enqueueBusinessEvent } from '@/lib/pubsub';

export async function POST(req: NextRequest) {
  const body = await req.json();
  const businessEvent = {
    sessionId: body.sessionId,
    eventType: body.eventType, // cart_viewed, checkout_started, order_completed, etc.
    payload: body.payload,
    metadata: {
      url: req.nextUrl.pathname,
      releasedAt: process.env.NEXT_PUBLIC_RELEASE_SHA,
    },
    timestamp: new Date().toISOString(),
  };

  await enqueueBusinessEvent(businessEvent);
  return NextResponse.json({ ok: true });
}
// lib/pubsub.ts
import { PubSub } from '@google-cloud/pubsub';

const pubsub = new PubSub({ projectId: process.env.GCP_PROJECT_ID });
const topicName = process.env.BUSINESS_TOPIC || 'business-metrics';

export async function enqueueBusinessEvent(event: Record<string, unknown>) {
  await pubsub.topic(topicName).publishMessage({
    json: event,
  });
}

Client-side hook (Next.js):

// hooks/useBusinessMetric.ts
import { useCallback } from 'react';

export function useBusinessMetric() {
  return useCallback(async (eventType: string, payload: Record<string, unknown>) => {
    await fetch('/api/metrics', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        sessionId: window.sessionStorage.getItem('sid'),
        eventType,
        payload,
      }),
      keepalive: true,
    });
  }, []);
}

3.2 NestJS Domain Events​

// src/orders/order-events.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { PubSub } from '@google-cloud/pubsub';

@Injectable()
export class OrderEventsService {
  private readonly logger = new Logger(OrderEventsService.name);
  private readonly pubsub = new PubSub({ projectId: process.env.GCP_PROJECT_ID });
  private readonly topic = this.pubsub.topic(process.env.BUSINESS_TOPIC);

  async publishOrderCompleted(event: {
    orderId: string;
    items: number;
    amount: number;
    userId: string;
    source: string;
  }) {
    const payload = {
      ...event,
      eventType: 'order_completed',
      releasedAt: process.env.RELEASE_SHA,
      timestamp: new Date().toISOString(),
    };

    try {
      await this.topic.publishMessage({ json: payload });
    } catch (error) {
      this.logger.error('Failed to publish order event', error);
    }
  }
}

4. GCP Data Pipeline​

  1. Pub/Sub Topic business-metrics: collects events from Next.js and NestJS.
  2. Dataflow Streaming Job: enriches events (geolocation, device type), calculates rolling windows, writes to BigQuery partitioned tables.
  3. BigQuery: stores raw and aggregated tables (events_raw, kpi_minute_aggregate).
  4. Looker Studio / Looker: renders dashboards with real-time tiles.
  5. Cloud Monitoring Custom Metrics: exposed via Cloud Monitoring API for alerting on conversion rate, items sold, etc.

5.2 Auto-Notification Cloud Function​

Reuse the webhook pattern from automated remediation but tailor the message:

// functions/business-alerts/src/index.ts
import { CloudFunction } from '@google-cloud/functions-framework';
import axios from 'axios';

export const notifyBusiness: CloudFunction = async (req, res) => {
  const { incident } = req.body;

  if (incident.state !== 'open') {
    res.status(200).send('No action');
    return;
  }

  const message = {
    text: `🚨 KPI Alert: ${incident.metric.displayName}`,
    attachments: [
      {
        color: 'danger',
        fields: [
          { title: 'Triggered At', value: incident.started_at, short: true },
          { title: 'URL', value: incident.url, short: true },
        ],
      },
    ],
  };

  await axios.post(process.env.SLACK_WEBHOOK_URL, message);
  res.status(200).send('Notified');
};

9. Security & Governance​

  • IAM: separate service accounts for ingestion, processing, dashboarding.
  • PII Handling: hash user identifiers before publishing events (sha256(userId + salt)).
  • Access Policies: Looker dashboards behind IAM/SSO groups; GitHub Actions secrets stored in GCP Secret Manager.
  • Audit Logs: enable Data Access logs for BigQuery and Pub/Sub to trace KPI tampering.
  • SLO Tracking: treat KPI freshness (e.g., data delay smaller than 120 seconds) as an SLO with error budgets.

10. Operational Runbook​

  1. KPI Alert Received

    • Confirm dashboard last updated time.
    • Check release metadata for recent deploys.
    • Use NestJS /metrics/business endpoint for raw numbers.

  2. Stakeholder Notification

    • Auto Slack message includes severity, impacted KPI, recommended playbook.
    • If SEV1, GitHub Actions pipeline pauses further deployments until KPI returns to baseline.

  3. Post-Incident Review

    • Export BigQuery query for affected interval.
    • Tag release in Git history (git tag kpi-incident-<date>).
    • Update alert thresholds or instrumentation gaps.

11. Team Autonomy & Actionable Response​

A critical aspect of Business Monitoring is empowering the development team with autonomy to take immediate action when KPIs indicate problems—without waiting for management approval or business sign-off for predefined responses.

11.1 Why Team Autonomy Matters​

Without AutonomyWith Autonomy
Alert fires → wait for approval → hours of revenue lossAlert fires → predefined action executed → minutes to resolution
Developers feel disconnected from business impactDevelopers own outcomes end-to-end
Stakeholders learn about issues after customers complainStakeholders are proactively informed with context

11.3 NestJS Action Controller​

Expose endpoints that the team (or automation) can invoke to take business-impacting actions:

// src/business-actions/business-actions.controller.ts
import { Controller, Post, Body, UseGuards } from '@nestjs/common';
import { BusinessActionsService } from './business-actions.service';
import { OnCallGuard } from '../auth/oncall.guard';
import { AuditLog } from '../decorators/audit-log.decorator';

@Controller('business-actions')
@UseGuards(OnCallGuard)
export class BusinessActionsController {
  constructor(private readonly actions: BusinessActionsService) {}

  @Post('notify-stakeholder')
  @AuditLog('STAKEHOLDER_NOTIFICATION')
  async notifyStakeholder(@Body() body: { kpi: string; severity: string; message: string; incidentId: string }) {
    return this.actions.notifyBusinessOwner(body);
  }

  @Post('pause-experiments')
  @AuditLog('EXPERIMENTS_PAUSED')
  async pauseExperiments(@Body() body: { reason: string; incidentId: string }) {
    return this.actions.pauseAllExperiments(body);
  }

  @Post('rollback-frontend')
  @AuditLog('FRONTEND_ROLLBACK')
  async rollbackFrontend(@Body() body: { targetVersion: string; incidentId: string }) {
    return this.actions.triggerFrontendRollback(body);
  }

  @Post('switch-payment-provider')
  @AuditLog('PAYMENT_PROVIDER_SWITCH')
  async switchPaymentProvider(@Body() body: { fromProvider: string; toProvider: string; incidentId: string }) {
    return this.actions.switchPaymentProvider(body);
  }
}
// src/business-actions/business-actions.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';
import axios from 'axios';

@Injectable()
export class BusinessActionsService {
  private readonly logger = new Logger(BusinessActionsService.name);

  constructor(private config: ConfigService) {}

  async notifyBusinessOwner(params: { kpi: string; severity: string; message: string; incidentId: string }) {
    const escalation = this.config.get(`kpi_escalations.${params.kpi}`);
    const recipients = [escalation.owners.primary];

    if (params.severity === 'critical') {
      recipients.push(escalation.owners.secondary);
    }

    // Send Slack DM to business owner
    await axios.post(this.config.get('SLACK_WEBHOOK_URL'), {
      channel: escalation.owners.primary,
      text: `🚨 *KPI Alert: ${params.kpi}*`,
      attachments: [
        {
          color: params.severity === 'critical' ? 'danger' : 'warning',
          fields: [
            { title: 'Severity', value: params.severity, short: true },
            { title: 'Incident', value: params.incidentId, short: true },
            { title: 'Message', value: params.message },
            { title: 'Action Required', value: 'Review dashboard and acknowledge' },
          ],
        },
      ],
    });

    // Send email via SendGrid
    await this.sendEmail(recipients, params);

    this.logger.log(`Notified stakeholders for ${params.kpi}: ${recipients.join(', ')}`);
    return { notified: recipients, timestamp: new Date().toISOString() };
  }

  async pauseAllExperiments(params: { reason: string; incidentId: string }) {
    // Call experiment platform API (e.g., LaunchDarkly, Split, internal)
    const response = await axios.post(
      `${this.config.get('EXPERIMENT_API_URL')}/experiments/pause-all`,
      {
        reason: params.reason,
        incidentId: params.incidentId,
        pausedBy: 'automated-kpi-response',
      },
      {
        headers: { Authorization: `Bearer ${this.config.get('EXPERIMENT_API_TOKEN')}` },
      },
    );

    this.logger.warn(`Paused all experiments due to: ${params.reason}`);
    return response.data;
  }

  async triggerFrontendRollback(params: { targetVersion: string; incidentId: string }) {
    // Trigger GitHub Actions workflow for rollback
    await axios.post(
      `https://api.github.com/repos/${this.config.get('GITHUB_REPO')}/actions/workflows/rollback.yml/dispatches`,
      {
        ref: 'main',
        inputs: {
          target_version: params.targetVersion,
          incident_id: params.incidentId,
        },
      },
      {
        headers: {
          Authorization: `Bearer ${this.config.get('GITHUB_TOKEN')}`,
          Accept: 'application/vnd.github.v3+json',
        },
      },
    );

    this.logger.warn(`Triggered frontend rollback to ${params.targetVersion}`);
    return { triggered: true, version: params.targetVersion };
  }

  async switchPaymentProvider(params: { fromProvider: string; toProvider: string; incidentId: string }) {
    // Update feature flag or config to switch provider
    await axios.patch(`${this.config.get('CONFIG_API_URL')}/settings/payment-provider`, {
      activeProvider: params.toProvider,
      previousProvider: params.fromProvider,
      reason: `Automatic switch due to incident ${params.incidentId}`,
    });

    this.logger.warn(`Switched payment provider: ${params.fromProvider} → ${params.toProvider}`);
    return { switched: true, activeProvider: params.toProvider };
  }

  private async sendEmail(recipients: string[], params: any) {
    // SendGrid or similar email service
  }
}

# .github/workflows/kpi-autonomous-response.yml
name: KPI Autonomous Response

on:
  repository_dispatch:
    types: [kpi_alert]
  workflow_dispatch:
    inputs:
      kpi_name:
        description: 'KPI that triggered alert'
        required: true
      severity:
        description: 'Alert severity (warning/critical)'
        required: true
      incident_id:
        description: 'Incident tracking ID'
        required: true

env:
  GCP_PROJECT_ID: ${{ secrets.GCP_PROJECT_ID }}

jobs:
  evaluate-and-respond:
    runs-on: ubuntu-latest
    permissions:
      contents: read
      id-token: write
      actions: write

    steps:
      - uses: actions/checkout@v4

      - name: Authenticate to Google Cloud
        uses: google-github-actions/auth@v2
        with:
          workload_identity_provider: ${{ secrets.WIF_PROVIDER }}
          service_account: ${{ secrets.WIF_SERVICE_ACCOUNT }}

      - name: Load escalation config
        id: config
        run: |
          KPI="${{ github.event.client_payload.kpi_name || inputs.kpi_name }}"
          SEVERITY="${{ github.event.client_payload.severity || inputs.severity }}"

          # Extract autonomous actions for this KPI
          ACTIONS=$(yq ".kpi_escalations.${KPI}.autonomous_actions" config/escalation-matrix.yaml)
          echo "actions=$ACTIONS" >> $GITHUB_OUTPUT
          echo "kpi=$KPI" >> $GITHUB_OUTPUT
          echo "severity=$SEVERITY" >> $GITHUB_OUTPUT

      - name: Notify business stakeholders
        if: always()
        run: |
          curl -X POST "${{ secrets.API_URL }}/business-actions/notify-stakeholder" \
            -H "Content-Type: application/json" \
            -H "Authorization: Bearer ${{ secrets.ONCALL_TOKEN }}" \
            -d '{
              "kpi": "${{ steps.config.outputs.kpi }}",
              "severity": "${{ steps.config.outputs.severity }}",
              "message": "Automated alert: ${{ steps.config.outputs.kpi }} exceeded threshold",
              "incidentId": "${{ github.event.client_payload.incident_id || inputs.incident_id }}"
            }'

      - name: Pause experiments (if conversion drop)
        if: contains(steps.config.outputs.actions, 'pause_experiments')
        run: |
          curl -X POST "${{ secrets.API_URL }}/business-actions/pause-experiments" \
            -H "Content-Type: application/json" \
            -H "Authorization: Bearer ${{ secrets.ONCALL_TOKEN }}" \
            -d '{
              "reason": "KPI alert: ${{ steps.config.outputs.kpi }}",
              "incidentId": "${{ github.event.client_payload.incident_id || inputs.incident_id }}"
            }'

      - name: Rollback frontend (if critical)
        if: steps.config.outputs.severity == 'critical' && contains(steps.config.outputs.actions, 'rollback_frontend')
        run: |
          # Get last known good version
          LAST_GOOD=$(gcloud run revisions list --service=nextjs-web --region=us-central1 \
            --filter="status.conditions.status=True" --limit=2 --format="value(name)" | tail -1)

          curl -X POST "${{ secrets.API_URL }}/business-actions/rollback-frontend" \
            -H "Content-Type: application/json" \
            -H "Authorization: Bearer ${{ secrets.ONCALL_TOKEN }}" \
            -d "{
              \"targetVersion\": \"$LAST_GOOD\",
              \"incidentId\": \"${{ github.event.client_payload.incident_id || inputs.incident_id }}\"
            }"

      - name: Create incident ticket
        run: |
          gh issue create \
            --title "KPI Incident: ${{ steps.config.outputs.kpi }} - ${{ steps.config.outputs.severity }}" \
            --body "## Incident Details
            - **KPI**: ${{ steps.config.outputs.kpi }}
            - **Severity**: ${{ steps.config.outputs.severity }}
            - **Incident ID**: ${{ github.event.client_payload.incident_id || inputs.incident_id }}
            - **Autonomous Actions Taken**: ${{ steps.config.outputs.actions }}
            - **Timestamp**: $(date -u +%Y-%m-%dT%H:%M:%SZ)
            
            ## Next Steps
            - [ ] Review dashboard
            - [ ] Validate autonomous actions
            - [ ] Communicate with stakeholders
            - [ ] Post-incident review scheduled" \
            --label "incident,kpi-alert,${{ steps.config.outputs.severity }}"
        env:
          GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}

11.5 Next.js Action Dashboard​

// app/admin/actions/page.tsx
'use client';

import { useState } from 'react';
import useSWR from 'swr';

const fetcher = (url: string) => fetch(url).then((r) => r.json());

export default function ActionDashboard() {
  const { data: kpis } = useSWR('/api/metrics/business', fetcher, { refreshInterval: 10000 });
  const [loading, setLoading] = useState<string | null>(null);

  const executeAction = async (action: string, params: Record<string, unknown>) => {
    setLoading(action);
    try {
      const res = await fetch(`/api/business-actions/${action}`, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(params),
      });
      const data = await res.json();
      alert(`Action "${action}" executed successfully`);
      console.log(data);

      alert(`Action "${action}" failed`);
      console.error(err);

      setLoading(null);
    }
  };

  return (
    <div className="p-6 space-y-8">
      <h1 className="text-2xl font-bold">Business Action Center</h1>

        {kpis?.metrics?.map((m: any) => (
          <div
            key={m.name}

              m.status === 'critical'
                ? 'border-red-500 bg-red-50'
                : m.status === 'warning'
                ? 'border-yellow-500 bg-yellow-50'
                : 'border-green-500 bg-green-50'
            }`}
          >
            <h3 className="font-semibold">{m.name}</h3>
            <p className="text-3xl">{m.value}</p>
            <p className="text-sm">Threshold: {m.threshold}</p>
          </div>
        ))}
      </section>

      {/* Action Buttons */}

          <button
            onClick={() =>
              executeAction('notify-stakeholder', {
                kpi: 'conversion_rate',
                severity: 'warning',
                message: 'Manual escalation from action dashboard',
                incidentId: `manual-${Date.now()}`,
              })
            }
            disabled={loading === 'notify-stakeholder'}
            className="px-4 py-2 bg-blue-600 text-white rounded hover:bg-blue-700 disabled:opacity-50"
          >
            {loading === 'notify-stakeholder' ? 'Notifying...' : '📧 Notify Stakeholders'}
          </button>

          <button
            onClick={() =>
              executeAction('pause-experiments', {
                reason: 'Manual pause from action dashboard',
                incidentId: `manual-${Date.now()}`,
              })
            }
            disabled={loading === 'pause-experiments'}
            className="px-4 py-2 bg-yellow-600 text-white rounded hover:bg-yellow-700 disabled:opacity-50"
          >
            {loading === 'pause-experiments' ? 'Pausing...' : '⏸️ Pause Experiments'}
          </button>

          <button
            onClick={() => {
              const version = prompt('Enter target version to rollback:');
              if (version) {
                executeAction('rollback-frontend', {
                  targetVersion: version,
                  incidentId: `manual-${Date.now()}`,
                });
              }
            }}
            disabled={loading === 'rollback-frontend'}
            className="px-4 py-2 bg-orange-600 text-white rounded hover:bg-orange-700 disabled:opacity-50"
          >
            {loading === 'rollback-frontend' ? 'Rolling back...' : '⏪ Rollback Frontend'}
          </button>

          <button
            onClick={() =>
              executeAction('switch-payment-provider', {
                fromProvider: 'stripe',
                toProvider: 'paypal',
                incidentId: `manual-${Date.now()}`,
              })
            }
            disabled={loading === 'switch-payment-provider'}
            className="px-4 py-2 bg-red-600 text-white rounded hover:bg-red-700 disabled:opacity-50"
          >
            {loading === 'switch-payment-provider' ? 'Switching...' : '💳 Switch Payment Provider'}
          </button>
        </div>
      </section>

      {/* Audit Log */}
      <section>
        <h2 className="text-xl font-semibold mb-2">Recent Actions</h2>
        <table className="w-full border-collapse border">
          <thead>
            <tr className="bg-gray-100">
              <th className="border p-2 text-left">Timestamp</th>
              <th className="border p-2 text-left">Action</th>
              <th className="border p-2 text-left">Triggered By</th>
              <th className="border p-2 text-left">Incident ID</th>
            </tr>
          </thead>
          <tbody>{/* Populated from audit log API */}</tbody>
        </table>
      </section>
    </div>
  );
}

11.6 Governance & Guardrails​

Even with autonomy, maintain guardrails:

ControlImplementation
Audit TrailAll actions logged to BigQuery with actor, timestamp, incident ID
Rate LimitingMax 3 autonomous actions per incident before human review required
Approval GatesHigh-impact actions (disable checkout) require Slack approval from 2+ team leads
Rollback WindowAny autonomous action can be reverted within 15 minutes via dashboard
Blast RadiusAutonomous actions scoped to single region/service; global changes need approval
// src/decorators/audit-log.decorator.ts
import { SetMetadata } from '@nestjs/common';

export const AUDIT_KEY = 'audit_action';
export const AuditLog = (action: string) => SetMetadata(AUDIT_KEY, action);

// src/interceptors/audit.interceptor.ts
import { Injectable, NestInterceptor, ExecutionContext, CallHandler } from '@nestjs/common';
import { Reflector } from '@nestjs/core';
import { Observable, tap } from 'rxjs';
import { BigQuery } from '@google-cloud/bigquery';

@Injectable()
export class AuditInterceptor implements NestInterceptor {
  private bigquery = new BigQuery();

  constructor(private reflector: Reflector) {}

  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    const action = this.reflector.get<string>('audit_action', context.getHandler());
    if (!action) return next.handle();

    const request = context.switchToHttp().getRequest();
    const startTime = Date.now();

    return next.handle().pipe(
      tap(async (response) => {
        await this.bigquery
          .dataset('audit')
          .table('business_actions')
          .insert([
            {
              action,
              actor: request.user?.email || 'system',
              incidentId: request.body?.incidentId,
              params: JSON.stringify(request.body),
              response: JSON.stringify(response),
              durationMs: Date.now() - startTime,
              timestamp: new Date().toISOString(),
            },
          ]);
      }),
    );
  }
}
