Dependency Injection

Dependency Injection (DI) is a design pattern used to implement Inversion of Control (IoC), allowing the creation of dependent objects outside of a class and providing those objects to a class in different ways.

Problem​

When classes create their own dependencies directly:

  • Tight Coupling: Classes are tightly coupled to specific implementations, making it difficult to change dependencies without modifying the class itself.
  • Testing Difficulties: Hard to unit test classes because you cannot easily replace dependencies with mock objects or test doubles.
  • Code Reusability: Classes become less reusable as they're bound to specific implementations of their dependencies.
  • Violation of SOLID Principles: Particularly violates the Dependency Inversion Principle and Single Responsibility Principle.
  • Hidden Dependencies: Dependencies are hidden inside the class, making it unclear what the class needs to function.

Example of problematic code:

class UserService {
  private database: MySQLDatabase;
  private logger: FileLogger;

  constructor() {
    this.database = new MySQLDatabase(); // Hard-coded dependency
    this.logger = new FileLogger(); // Hard-coded dependency
  }

  getUser(id: string) {
    this.logger.log('Fetching user');
    return this.database.query(`SELECT * FROM users WHERE id = ${id}`);
  }
}

Solution​

Dependency Injection solves these problems by:

  1. Externalizing Dependencies: Dependencies are created outside the class and injected through constructor, setter methods, or interfaces.
  2. Programming to Interfaces: Classes depend on abstractions (interfaces) rather than concrete implementations.
  3. Inversion of Control: The control of creating and managing dependencies is inverted from the class to an external entity (IoC container or manual injection).
  4. Flexibility: Easy to swap implementations without changing the class code.
  5. Testability: Dependencies can be easily mocked or stubbed for testing.

There are three main types of Dependency Injection:

  • Constructor Injection: Dependencies are provided through the class constructor.
  • Setter Injection: Dependencies are provided through setter methods.
  • Interface Injection: The dependency provides an injector method that will inject the dependency into any client passed to it.

How to Implement​

1. Constructor Injection (Recommended)​

// Step 1: Define interface
interface IDatabase {
  query(sql: string): Promise<any>;
}

// Step 2: Create implementations
class MySQLDatabase implements IDatabase {
  async query(sql: string): Promise<any> {
    // MySQL specific implementation
    return [];
  }
}

class PostgreSQLDatabase implements IDatabase {
  async query(sql: string): Promise<any> {
    // PostgreSQL specific implementation
    return [];
  }
}

// Step 3: Inject through constructor
class UserService {
  constructor(private database: IDatabase) {}

  async getUser(id: string) {
    return this.database.query(`SELECT * FROM users WHERE id = ${id}`);
  }
}

// Step 4: Use it
const mysqlDb = new MySQLDatabase();
const userService = new UserService(mysqlDb); // Inject dependency

2. Setter Injection​

class UserService {
  private database?: IDatabase;

  setDatabase(database: IDatabase) {
    this.database = database;
  }

  async getUser(id: string) {
    if (!this.database) {
      throw new Error('Database not set');
    }
    return this.database.query(`SELECT * FROM users WHERE id = ${id}`);
  }
}

// Usage
const userService = new UserService();
userService.setDatabase(new MySQLDatabase());

3. Property Injection​

class UserService {
  @Inject('IDatabase')
  private database!: IDatabase;

  async getUser(id: string) {
    return this.database.query(`SELECT * FROM users WHERE id = ${id}`);
  }
}

4. Using DI Container​

// Simple DI Container
class Container {
  private services: Map<string, any> = new Map();

  register(name: string, service: any) {
    this.services.set(name, service);
  }

  resolve<T>(name: string): T {
    const service = this.services.get(name);
    if (!service) {
      throw new Error(`Service ${name} not found`);
    }
    return service;
  }
}

// Setup
const container = new Container();
container.register('database', new MySQLDatabase());
container.register('userService', new UserService(container.resolve('database')));

// Usage
const userService = container.resolve<UserService>('userService');

    this.logger.log(`User registered successfully: ${user.id}`);
    return user;
  }

  async getUserById(id: string): Promise<User> {
    const user = await this.userRepository.findById(id);
    if (!user) {
      throw new Error('User not found');
    }
    return user;
  }

    const user = await this.userRepository.findById(id);
    if (!user) {
      throw new Error('User not found');
    }

    await this.userRepository.delete(id);

    // Send goodbye email
    await this.emailService.sendEmail(
      user.email,
      'Account Deleted',
      `Goodbye ${user.name}, your account has been deleted.`,
    );

    this.logger.log(`User deleted: ${id}`);
  }
}

// ============= DI Container =============
class DIContainer {
  private services: Map<string, any> = new Map();
  private singletons: Map<string, any> = new Map();

  register(name: string, factory: (container: DIContainer) => any, singleton: boolean = false) {
    this.services.set(name, { factory, singleton });
  }

  resolve<T>(name: string): T {
    const service = this.services.get(name);
    if (!service) {
      throw new Error(`Service ${name} not registered`);
    }

    if (service.singleton) {
      if (!this.singletons.has(name)) {
        this.singletons.set(name, service.factory(this));
      }
      return this.singletons.get(name);
    }

    return service.factory(this);
  }
}

// ============= Application Setup =============
function setupContainer(): DIContainer {
  const container = new DIContainer();

  // Register logger (singleton)
  container.register('logger', () => new ConsoleLogger(), true);

  // Register database (singleton)
  container.register(
    'database',
    (c) => new PostgreSQLDatabase('localhost', 5432, 'myapp', c.resolve<ILogger>('logger')),
    true,
  );

  // Register email service (singleton)
  container.register(
    'emailService',
    (c) => new SMTPEmailService('smtp.example.com', 587, c.resolve<ILogger>('logger')),
    true,
  );

  // Register repository
  container.register(
    'userRepository',
    (c) => new UserRepository(c.resolve<IDatabase>('database'), c.resolve<ILogger>('logger')),
  );

  // Register service
  container.register(
    'userService',
    (c) =>
      new UserService(
        c.resolve<IUserRepository>('userRepository'),
        c.resolve<IEmailService>('emailService'),
        c.resolve<ILogger>('logger'),
      ),
  );

  return container;
}

// ============= Usage =============
async function main() {
  const container = setupContainer();

  // Get database and connect
  const database = container.resolve<IDatabase>('database');
  await database.connect();

  // Get user service
  const userService = container.resolve<UserService>('userService');

  // Register a new user
  try {
    const user = await userService.registerUser('john@example.com', 'John Doe');
    console.log('User created:', user);

    // Get user by ID
    const fetchedUser = await userService.getUserById(user.id);
    console.log('User fetched:', fetchedUser);

    // Delete user
    await userService.deleteUser(user.id);
    console.log('User deleted');
  } catch (error) {
    console.error('Error:', error);
  } finally {
    await database.disconnect();
  }
}

// Run the application
main().catch(console.error);

Example with Decorators (TypeScript)​

// Decorator-based DI (similar to Angular/NestJS)
function Injectable() {
  return function (target: any) {
    // Mark class as injectable
    Reflect.defineMetadata('injectable', true, target);
  };
}

function Inject(token: string) {
  return function (target: any, propertyKey: string, parameterIndex: number) {
    const existingInjections = Reflect.getMetadata('injections', target) || [];
    existingInjections.push({ index: parameterIndex, token });
    Reflect.defineMetadata('injections', existingInjections, target);
  };
}

@Injectable()
class LoggerService {
  log(message: string) {
    console.log(message);
  }
}

@Injectable()
class UserService {
  constructor(@Inject('LoggerService') private logger: LoggerService) {}

  getUser(id: string) {
    this.logger.log(`Getting user ${id}`);
    return { id, name: 'John' };
  }
}

Pros and Cons​

ProsCons
✓ Loose Coupling: Classes are decoupled from their dependencies, making the system more flexible.✗ Complexity: Adds additional complexity to the codebase, especially for small projects.
✓ Testability: Easy to unit test by injecting mock dependencies.✗ Learning Curve: Developers need to understand DI concepts and frameworks.
✓ Maintainability: Changes to dependencies don't require changes to dependent classes.✗ Runtime Errors: Some errors that could be caught at compile time may only appear at runtime.
✓ Reusability: Classes can be reused with different implementations of dependencies.✗ Configuration Overhead: Requires configuration and setup of the DI container.
✓ Single Responsibility: Classes focus on their core responsibility, not on creating dependencies.✗ Debugging Difficulty: Can be harder to trace the flow of dependencies in complex applications.
✓ Open/Closed Principle: Open for extension but closed for modification.✗ Performance Overhead: DI containers may introduce slight performance overhead.
✓ Dependency Inversion Principle: High-level modules don't depend on low-level modules.✗ Over-engineering: Can be overkill for simple applications with few dependencies.
✓ Configuration Flexibility: Easy to configure different implementations for different environments.✗ Magic Behavior: Framework-based DI can feel like "magic" and hide what's actually happening.

1. Web Application Services​

Injecting database connections, authentication services, and loggers into HTTP handlers.

JavaScript/TypeScript Implementation:

// Express.js with DI
import express from 'express';

interface IAuthService {
  validateToken(token: string): Promise<boolean>;
  getUserFromToken(token: string): Promise<User>;
}

class JWTAuthService implements IAuthService {
  constructor(private secret: string, private logger: ILogger) {}

  async validateToken(token: string): Promise<boolean> {
    this.logger.log('Validating JWT token');
    // JWT validation logic
    return true;
  }

  async getUserFromToken(token: string): Promise<User> {
    // Extract user from token
    return { id: '1', email: 'user@example.com', name: 'User' };
  }
}

class UserController {
  constructor(private userService: UserService, private authService: IAuthService, private logger: ILogger) {}

  async getUser(req: express.Request, res: express.Response) {
    try {
      const token = req.headers.authorization?.split(' ')[1];
      if (!token || !(await this.authService.validateToken(token))) {
        return res.status(401).json({ error: 'Unauthorized' });
      }

      const userId = req.params.id;
      const user = await this.userService.getUserById(userId);
      res.json(user);
    } catch (error) {
      this.logger.error(`Error fetching user: ${error}`);
      res.status(500).json({ error: 'Internal server error' });
    }
  }

  async createUser(req: express.Request, res: express.Response) {
    try {
      const { email, name } = req.body;
      const user = await this.userService.registerUser(email, name);
      res.status(201).json(user);
    } catch (error) {
      this.logger.error(`Error creating user: ${error}`);
      res.status(500).json({ error: 'Internal server error' });
    }
  }
}

// Setup
const container = setupContainer();
const userController = new UserController(
  container.resolve('userService'),
  container.resolve('authService'),
  container.resolve('logger'),
);

const app = express();
app.get('/users/:id', (req, res) => userController.getUser(req, res));
app.post('/users', (req, res) => userController.createUser(req, res));

class MockDatabase implements IDatabase {

  public errors: string[] = [];

    this.logs.push(message);

describe('UserService', () => {
  let userService: UserService;
  let mockDatabase: MockDatabase;
  let mockEmailService: MockEmailService;
  let mockLogger: MockLogger;

    mockEmailService = new MockEmailService();
    mockLogger = new MockLogger();

    userService = new UserService(mockRepository, mockEmailService, mockLogger);

3. Multi-Tenant Applications​

Injecting tenant-specific configurations and services.

interface ITenantContext {
  getTenantId(): string;
  getDatabaseConnection(): IDatabase;
  getConfiguration(): TenantConfig;
}

interface TenantConfig {
  features: string[];
  limits: {
    maxUsers: number;
    maxStorage: number;
  };
  branding: {
    logo: string;
    primaryColor: string;
  };
}

class TenantContext implements ITenantContext {
  constructor(private tenantId: string, private database: IDatabase, private config: TenantConfig) {}

  getTenantId(): string {
    return this.tenantId;
  }

  getDatabaseConnection(): IDatabase {
    return this.database;
  }

  getConfiguration(): TenantConfig {
    return this.config;
  }
}

class TenantAwareUserService {
  constructor(private tenantContext: ITenantContext, private baseUserService: UserService, private logger: ILogger) {}

  async registerUser(email: string, name: string): Promise<User> {
    const config = this.tenantContext.getConfiguration();
    const tenantId = this.tenantContext.getTenantId();

    // Check tenant-specific limits
    const existingUsers = await this.baseUserService.getUserCount();
    if (existingUsers >= config.limits.maxUsers) {
      throw new Error('Tenant user limit reached');
    }

    this.logger.log(`Registering user for tenant: ${tenantId}`);
    return this.baseUserService.registerUser(email, name);
  }
}

// Middleware to inject tenant context
function tenantMiddleware(req: express.Request, res: express.Response, next: express.NextFunction) {
  const tenantId = req.headers['x-tenant-id'] as string;

  if (!tenantId) {
    return res.status(400).json({ error: 'Tenant ID required' });
  }

  // Get tenant-specific database and config
  const tenantDb = getTenantDatabase(tenantId);
  const tenantConfig = getTenantConfig(tenantId);

  // Create tenant context
  req.tenantContext = new TenantContext(tenantId, tenantDb, tenantConfig);
  next();
}

4. Plugin Architecture​

Injecting plugins dynamically based on configuration.

TypeScript Implementation:

interface IPlugin {
  name: string;
  initialize(): Promise<void>;
  execute(context: any): Promise<any>;
  shutdown(): Promise<void>;
}

class AnalyticsPlugin implements IPlugin {
  name = 'analytics';

  constructor(private apiKey: string, private logger: ILogger) {}

  async initialize(): Promise<void> {
    this.logger.log('Analytics plugin initialized');
  }

  async execute(context: any): Promise<any> {
    // Track event
    this.logger.log(`Tracking event: ${context.event}`);
  }

  async shutdown(): Promise<void> {
    this.logger.log('Analytics plugin shutdown');
  }
}

class CachePlugin implements IPlugin {
  name = 'cache';
  private cache: Map<string, any> = new Map();

  constructor(private ttl: number, private logger: ILogger) {}

  async initialize(): Promise<void> {
    this.logger.log('Cache plugin initialized');
  }

  async execute(context: any): Promise<any> {
    if (context.action === 'get') {
      return this.cache.get(context.key);
    } else if (context.action === 'set') {
      this.cache.set(context.key, context.value);
    }
  }

  async shutdown(): Promise<void> {
    this.cache.clear();
    this.logger.log('Cache plugin shutdown');
  }
}

class PluginManager {
  private plugins: Map<string, IPlugin> = new Map();

  constructor(private logger: ILogger) {}

  async registerPlugin(plugin: IPlugin): Promise<void> {
    await plugin.initialize();
    this.plugins.set(plugin.name, plugin);
    this.logger.log(`Plugin registered: ${plugin.name}`);
  }

  async executePlugin(name: string, context: any): Promise<any> {
    const plugin = this.plugins.get(name);
    if (!plugin) {
      throw new Error(`Plugin not found: ${name}`);
    }
    return plugin.execute(context);
  }

  async shutdown(): Promise<void> {
    for (const plugin of this.plugins.values()) {
      await plugin.shutdown();
    }
    this.plugins.clear();
  }
}

// Application with plugins
class Application {
  constructor(private pluginManager: PluginManager, private logger: ILogger) {}

  async start(): Promise<void> {
    this.logger.log('Application starting...');

    // Plugins are injected based on configuration
    const config = loadConfiguration();

    if (config.analytics.enabled) {
      await this.pluginManager.registerPlugin(new AnalyticsPlugin(config.analytics.apiKey, this.logger));
    }

    if (config.cache.enabled) {
      await this.pluginManager.registerPlugin(new CachePlugin(config.cache.ttl, this.logger));
    }
  }
}

type Environment = 'development' | 'staging' | 'production';

interface IConfigService {
  get<T>(key: string): T;
  getAll(): Record<string, any>;
}

class DevelopmentConfigService implements IConfigService {
  private config = {
    apiUrl: 'http://localhost:3000',
    databaseUrl: 'postgresql://localhost:5432/dev',
    logLevel: 'debug',
    enableDebugTools: true,
  };

  get<T>(key: string): T {
    return this.config[key] as T;
  }

  getAll(): Record<string, any> {
    return this.config;
  }
}

class ProductionConfigService implements IConfigService {
  private config = {
    apiUrl: 'https://api.production.com',
    databaseUrl: process.env.DATABASE_URL,
    logLevel: 'error',
    enableDebugTools: false,
  };

  get<T>(key: string): T {
    return this.config[key] as T;
  }

  getAll(): Record<string, any> {
    return this.config;
  }
}

function createConfigService(env: Environment): IConfigService {
  switch (env) {
    case 'development':
      return new DevelopmentConfigService();
    case 'production':
      return new ProductionConfigService();
    default:
      return new DevelopmentConfigService();
  }
}

// Container setup based on environment
function setupEnvironmentContainer(env: Environment): DIContainer {
  const container = new DIContainer();

  // Environment-specific config
  container.register('config', () => createConfigService(env), true);

  // Environment-specific logger
  if (env === 'development') {
    container.register('logger', () => new ConsoleLogger(), true);
  } else {
    container.register(
      'logger',
      (c) => {
        const config = c.resolve<IConfigService>('config');
        return new FileLogger(config.get<string>('logFile'));
      },
      true,

7. Event-Driven Architecture​

Injecting event emitters and handlers.

TypeScript Implementation:

interface IEventEmitter {
  emit(event: string, data: any): void;
  on(event: string, handler: (data: any) => void): void;
  off(event: string, handler: (data: any) => void): void;
}

class EventEmitter implements IEventEmitter {
  private events: Map<string, Array<(data: any) => void>> = new Map();

  emit(event: string, data: any): void {
    const handlers = this.events.get(event) || [];
    handlers.forEach((handler) => handler(data));
  }

  on(event: string, handler: (data: any) => void): void {
    if (!this.events.has(event)) {
      this.events.set(event, []);
    }
    this.events.get(event)!.push(handler);
  }

  off(event: string, handler: (data: any) => void): void {
    const handlers = this.events.get(event) || [];
    const index = handlers.indexOf(handler);
    if (index > -1) {
      handlers.splice(index, 1);
    }
  }
}

class UserRegisteredHandler {
  constructor(private emailService: IEmailService, private logger: ILogger) {}

  async handle(data: any): Promise<void> {
    this.logger.log(`Handling UserRegistered event for ${data.email}`);
    await this.emailService.sendEmail(data.email, 'Welcome!', `Welcome ${data.name}!`);
  }
}

class UserActivityLogger {
  constructor(private logger: ILogger) {}

  handle(data: any): void {
    this.logger.log(`User activity: ${data.action} by ${data.userId}`);
  }
}

class EventDrivenUserService {
  constructor(private userRepository: IUserRepository, private eventEmitter: IEventEmitter, private logger: ILogger) {}

  async registerUser(email: string, name: string): Promise<User> {
    const user = await this.userRepository.create({ email, name, createdAt: new Date() });

    // Emit event instead of directly sending email
    this.eventEmitter.emit('user.registered', {
      userId: user.id,
      email: user.email,
      name: user.name,
    });

    return user;
  }
}

// Setup event handlers
function setupEventDrivenContainer(): DIContainer {
  const container = new DIContainer();

  container.register('logger', () => new ConsoleLogger(), true);
  container.register('eventEmitter', () => new EventEmitter(), true);

  container.register(
    'emailService',
    (c) => new SMTPEmailService('smtp.example.com', 587, c.resolve<ILogger>('logger')),
    true,
  );

  // Register event handlers
  container.register(
    'userRegisteredHandler',
    (c) => new UserRegisteredHandler(c.resolve<IEmailService>('emailService'), c.resolve<ILogger>('logger')),
  );

  container.register('userActivityLogger', (c) => new UserActivityLogger(c.resolve<ILogger>('logger')));

  // Wire up event handlers
  const eventEmitter = container.resolve<IEventEmitter>('eventEmitter');
  const userRegisteredHandler = container.resolve<UserRegisteredHandler>('userRegisteredHandler');
  const userActivityLogger = container.resolve<UserActivityLogger>('userActivityLogger');

  eventEmitter.on('user.registered', (data) => userRegisteredHandler.handle(data));
  eventEmitter.on('user.registered', (data) => userActivityLogger.handle(data));

  return container;
}

interface ICache {
  get<T>(key: string): Promise<T | null>;
  set(key: string, value: any, ttl?: number): Promise<void>;
  delete(key: string): Promise<void>;
  clear(): Promise<void>;
}

class MemoryCache implements ICache {
  private cache: Map<string, { value: any; expiry: number }> = new Map();

  async get<T>(key: string): Promise<T | null> {
    const item = this.cache.get(key);
    if (!item) return null;

    if (Date.now() > item.expiry) {
      this.cache.delete(key);
      return null;
    }

    return item.value as T;
  }

  async set(key: string, value: any, ttl: number = 3600000): Promise<void> {
    this.cache.set(key, {
      value,
      expiry: Date.now() + ttl,
    });
  }

  async delete(key: string): Promise<void> {
    this.cache.delete(key);
  }

  async clear(): Promise<void> {

  }
}

class CachedUserService {
  constructor(private userService: UserService, private cache: ICache, private logger: ILogger) {}

  async getUserById(id: string): Promise<User> {
    const cacheKey = `user:${id}`;

    // Try cache first
    const cached = await this.cache.get<User>(cacheKey);
    if (cached) {
      this.logger.log(`Cache hit for user ${id}`);
      return cached;
    }

    // Cache miss - fetch from service
    this.logger.log(`Cache miss for user ${id}`);
    const user = await this.userService.getUserById(id);

    // Store in cache
    await this.cache.set(cacheKey, user, 300000); // 5 minutes

    return user;
  }
}

function setupCacheContainer(cacheType: 'memory' | 'redis'): DIContainer {
  const container = new DIContainer();

  container.register('logger', () => new ConsoleLogger(), true);

  if (cacheType === 'redis') {

          {}, // Redis client
          c.resolve<ILogger>('logger'),
        ),
      true,
    );
  } else {
    container.register('cache', () => new MemoryCache(), true);
  }

  return container;

10. Monitoring and Observability​

Injecting telemetry, metrics, and tracing services.

TypeScript Implementation:

interface IMetrics {
  increment(metric: string, tags?: Record<string, string>): void;
  gauge(metric: string, value: number, tags?: Record<string, string>): void;
  timing(metric: string, duration: number, tags?: Record<string, string>): void;
}

interface ITracing {
  startSpan(name: string): Span;
}

interface Span {
  setTag(key: string, value: any): void;
  finish(): void;
}

class DatadogMetrics implements IMetrics {
  constructor(private apiKey: string) {}

  increment(metric: string, tags?: Record<string, string>): void {
    console.log(`[Datadog] Incrementing ${metric}`, tags);
    // Send to Datadog
  }

  gauge(metric: string, value: number, tags?: Record<string, string>): void {
    console.log(`[Datadog] Gauge ${metric}: ${value}`, tags);
  }

  timing(metric: string, duration: number, tags?: Record<string, string>): void {
    console.log(`[Datadog] Timing ${metric}: ${duration}ms`, tags);
  }
}

class JaegerTracing implements ITracing {
  startSpan(name: string): Span {
    console.log(`[Jaeger] Starting span: ${name}`);
    return {
      setTag: (key, value) => console.log(`[Jaeger] Tag: ${key}=${value}`),
      finish: () => console.log(`[Jaeger] Span finished`),
    };
  }
}

class ObservableUserService {
  constructor(
    private userService: UserService,
    private metrics: IMetrics,
    private tracing: ITracing,
    private logger: ILogger,
  ) {}

  async registerUser(email: string, name: string): Promise<User> {
    const span = this.tracing.startSpan('registerUser');
    span.setTag('email', email);

    const startTime = Date.now();

    try {
      this.metrics.increment('user.registration.attempt');

      const user = await this.userService.registerUser(email, name);

      this.metrics.increment('user.registration.success');
      this.metrics.timing('user.registration.duration', Date.now() - startTime);

      span.setTag('userId', user.id);
      span.finish();

      return user;
    } catch (error) {
      this.metrics.increment('user.registration.failure', {
        error: error.message,
      });

      span.setTag('error', true);
      span.setTag('error.message', error.message);
      span.finish();

      throw error;
    }
  }

  async getUserById(id: string): Promise<User> {
    const span = this.tracing.startSpan('getUserById');
    span.setTag('userId', id);

    try {
      this.metrics.increment('user.fetch.attempt');
      const user = await this.userService.getUserById(id);
      this.metrics.increment('user.fetch.success');
      span.finish();
      return user;
    } catch (error) {
      this.metrics.increment('user.fetch.failure');
      span.setTag('error', true);
      span.finish();
      throw error;
    }
  }
}

// Setup observability
function setupObservabilityContainer(): DIContainer {
  const container = new DIContainer();

  container.register('logger', () => new ConsoleLogger(), true);
  container.register('metrics', () => new DatadogMetrics('api-key'), true);
  container.register('tracing', () => new JaegerTracing(), true);

  container.register(
    'observableUserService',
    (c) =>
      new ObservableUserService(
        c.resolve<UserService>('userService'),
        c.resolve<IMetrics>('metrics'),
        c.resolve<ITracing>('tracing'),
        c.resolve<ILogger>('logger'),
      ),
  );

  return container;
}

Summary​

Dependency Injection is a powerful design pattern that promotes loose coupling, testability, and maintainability in your applications. By injecting dependencies rather than hard-coding them, you create more flexible and modular code that's easier to test, maintain, and extend.

Key takeaways:

  • Use constructor injection as the primary method for required dependencies
  • Depend on interfaces/abstractions rather than concrete implementations
  • Use DI containers for complex applications with many dependencies
  • Apply DI consistently across your application architecture
  • Remember that DI adds complexity, so evaluate if it's appropriate for your project size
